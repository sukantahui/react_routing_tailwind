2. THEORETICAL FOUNDATIONS & MATHEMATICAL MODELS
--------------------------------------------------------------------------------
In advanced computer systems and micro-architectures:
- Architectural Invariant: Governed by formal ISA specifications, datapath state equations,
  and hardware performance laws.
- Micro-Architectural Dynamics: Execution optimization through pipelining, caching,
  speculative branching, and multi-core memory consistency models.
- Mathematical Metrics:
  * Speedup (Amdahl's Law): S = 1 / [(1 - P) + (P / N)]
  * CPI (Cycles Per Instruction): CPI_ideal + Stall_Cycles_per_Instruction
  * Average Memory Access Time: AMAT = Hit_Time + (Miss_Rate * Miss_Penalty)

5. SENIOR ARCHITECTURAL PITFALLS & BEST PRACTICES
--------------------------------------------------------------------------------
- PITFALL: False Sharing in multi-threaded SMP code when independent variables share
  a single 64-byte cache line, causing continuous MESI bus invalidation traffic.
- PITFALL: Branch Misprediction Penalties in deep pipelines (15 to 20 clock cycle flushes).
- BEST PRACTICE: Use branchless algorithms and conditional moves (CMOV) in critical loops.
- BEST PRACTICE: Align memory structures to native cache line boundaries (alignas(64)).
