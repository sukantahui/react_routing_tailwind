1. CORE CONCEPT: THE OCTAL (BASE-8) NUMBER SYSTEM
--------------------------------------------------------------------------------
The Octal number system is a base-8 positional radix system ($r = 8$) utilizing
eight discrete symbols:

    Symbol Set: {0, 1, 2, 3, 4, 5, 6, 7}  (Digits '8' and '9' are illegal!)

Positional Weights:
- Integer Powers of 8:
  $8^0 = 1$
  $8^1 = 8$
  $8^2 = 64$
  $8^3 = 512$
  $8^4 = 4096$
- Fractional Powers of 8:
  $8^{-1} = 1/8 = 0.125$
  $8^{-2} = 1/64 = 0.015625$
  $8^{-3} = 1/512 \approx 0.001953125$

2. DECIMAL TO OCTAL CONVERSION ALGORITHMS
--------------------------------------------------------------------------------
A. INTEGER PART (SUCCESSIVE DIVISION BY 8):
   - Divide integer $N$ by 8.
   - Record the remainder ($0 \le R \le 7$).
   - Divide the quotient by 8 and repeat until quotient is 0.
   - Read remainders in reverse order (BOTTOM-UP):
     First remainder = Least Significant Digit (LSD / $8^0$).
     Last remainder = Most Significant Digit (MSD / $8^{k-1}$).

B. FRACTIONAL PART (SUCCESSIVE MULTIPLICATION BY 8):
   - Multiply fractional part by 8.
   - Record the generated integer digit ($0 \le d \le 7$).
   - Repeat with the remaining fraction until 0 or desired precision.
   - Read integer carries TOP-DOWN (First carry = $8^{-1}$ digit).

C. THE BINARY SHORTCUT HIGHWAY (Decimal -> Binary -> 3-Bit Grouping -> Octal):
   - Convert Decimal to Binary.
   - Group bits in sets of 3 from the radix point.
   - Map each 3-bit group to its octal digit ($000=0 \dots 111=7$).

3. CONCRETE STEP-BY-STEP WORKED EXAMPLES
--------------------------------------------------------------------------------
Example 1: Convert Decimal $359_{10}$ to Octal
- Division Steps:
  $359 \div 8 = 44 \quad R = 7 \quad (\text{LSD, } 8^0)$
   $44 \div 8 =  5 \quad R = 4 \quad (8^1)$
    $5 \div 8 =  0 \quad R = 5 \quad (\text{MSD, } 8^2)$
  Read Bottom-Up: $(547)_8$
  Verification: $5 \times 64 + 4 \times 8 + 7 \times 1 = 320 + 32 + 7 = 359_{10}$. Verified!

Example 2: Convert Decimal Fraction $(0.4375)_{10}$ to Octal
- Multiplication Steps:
  $0.4375 \times 8 = 3.5000 \to \text{Integer Carry } 3 \quad (\text{MSD } 8^{-1})$
  $0.5000 \times 8 = 4.0000 \to \text{Integer Carry } 4 \quad (\text{Fraction}=0!)$
  Read Top-Down: $(0.34)_8$
  Verification: $3/8 + 4/64 = 0.375 + 0.0625 = 0.4375_{10}$. Verified!

Example 3: Convert Mixed Number $(94.625)_{10}$ to Octal
- Integer 94:
  $94 \div 8 = 11 \quad R = 6$
  $11 \div 8 =  1 \quad R = 3$
   $1 \div 8 =  0 \quad R = 1 \implies (136)_8$
- Fraction 0.625:
  $0.625 \times 8 = 5.000 \implies (0.5)_8$
- Combined: $(94.625)_{10} = (136.5)_8$

5. COMMON BEGINNER PITFALLS & BEST PRACTICES
--------------------------------------------------------------------------------
- PITFALL: Writing digit '8' or '9' in an octal result (Base 8 only allows 0-7).
- PITFALL: Forgetting that in C/C++/Python, a leading zero indicates an octal literal (`0755 != 755`).
- BEST PRACTICE: Use powers of 8 ($512, 64, 8, 1$) for quick mental verification.
- BEST PRACTICE: For complex conversions, converting through 3-bit binary groups is faster and less prone to division arithmetic slips.
