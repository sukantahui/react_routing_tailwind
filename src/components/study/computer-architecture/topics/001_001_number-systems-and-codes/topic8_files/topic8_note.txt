1. EXECUTIVE OVERVIEW & MATHEMATICAL FOUNDATIONS
--------------------------------------------------------------------------------
In computer engineering, selecting the appropriate bit-width (n) for variables,
data buses, and memory address registers is a fundamental design decision. An
n-bit register provides exactly 2^n distinct binary states. How those 2^n states
are mapped onto the mathematical number line determines the representation's
dynamic range, symmetry, and zero properties.

--------------------------------------------------------------------------------
2. MASTER RANGE FORMULAS ACROSS ALL ENCODINGS
--------------------------------------------------------------------------------
For an arbitrary bit-width n:

1. UNSIGNED BINARY:
   - Minimum: 0
   - Maximum: +(2^n - 1)
   - Dynamic Range: [0 to 2^n - 1]
   - Total Unique Values: 2^n
   - Symmetrical: No (Purely non-negative)

2. SIGN-MAGNITUDE:
   - Minimum: -(2^(n-1) - 1)
   - Maximum: +(2^(n-1) - 1)
   - Dynamic Range: [-(2^(n-1) - 1) to +(2^(n-1) - 1)]
   - Total Unique Values: 2^n - 1 (Two zeros: +0 and -0)
   - Symmetrical: Yes (Perfect symmetry around zero)

3. 1'S COMPLEMENT:
   - Minimum: -(2^(n-1) - 1)
   - Maximum: +(2^(n-1) - 1)
   - Dynamic Range: [-(2^(n-1) - 1) to +(2^(n-1) - 1)]
   - Total Unique Values: 2^n - 1 (Two zeros: +0 and -0)
   - Symmetrical: Yes (Perfect symmetry around zero)

4. 2'S COMPLEMENT (Industry Standard):
   - Minimum: -2^(n-1)
   - Maximum: +(2^(n-1) - 1)
   - Dynamic Range: [-2^(n-1) to +2^(n-1) - 1]
   - Total Unique Values: 2^n (Single unique zero: 0000...0)
   - Symmetrical: No (Asymmetric: exactly one extra negative number)

5. EXCESS-K (BIASED FORMAT):
   - Dynamic Range: [-K to +(2^n - 1 - K)]
   - Used for IEEE-754 floating-point exponent fields (e.g. Excess-127 for 8 bits).

4. HOW TO CALCULATE MINIMUM BIT-WIDTH REQUIRED
--------------------------------------------------------------------------------
To find the minimum bits (n) required to represent a decimal integer D:

A. FOR UNSIGNED NUMBERS (D >= 0):
   n = ceil( log2(D + 1) )
   Example: To store D = 500:
   n = ceil( log2(501) ) = ceil( 8.968 ) = 9 bits. (Range: 0 to 511).

B. FOR SIGNED 2'S COMPLEMENT NUMBERS:
   - If D > 0: n = ceil( log2(D + 1) ) + 1
     Example: To store D = +500:
     n = ceil( log2(501) ) + 1 = 9 + 1 = 10 bits. (Range: -512 to +511).
   - If D < 0: n = ceil( log2(|D|) ) + 1
     Example: To store D = -512:
     n = ceil( log2(512) ) + 1 = 9 + 1 = 10 bits. (Range: -512 to +511).

5. FAMOUS REAL-WORLD RANGE OVERFLOW: THE YEAR 2038 PROBLEM
--------------------------------------------------------------------------------
Unix systems traditionally count time as a signed 32-bit integer (time_t) representing
seconds elapsed since the Unix Epoch (1970-01-01 00:00:00 UTC).
- Maximum 32-bit signed value = +2,147,483,647 seconds.
- Date of Rollover: 2038-01-19 03:14:07 UTC.
- At 03:14:08 UTC, the timestamp overflows to -2,147,483,648, wrapping the system
  clock back to the year 1901 (1901-12-13 20:45:52 UTC)!
- Solution: Modern operating systems upgrade time_t to 64-bit signed integers, extending
  the time horizon to 292 billion years into the future.
