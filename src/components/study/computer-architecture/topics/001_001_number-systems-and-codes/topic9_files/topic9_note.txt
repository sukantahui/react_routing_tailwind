1. EXECUTIVE OVERVIEW & FOUNDATIONAL RULES
--------------------------------------------------------------------------------
Binary arithmetic with signed numbers is the fundamental operational mode of modern
ALUs. In a 2's complement system, ALL subtraction operations are converted into
standard binary additions:
  A - B = A + (-B) = A + (2's Complement of B)

CORE HARDWARE ARITHMETIC RULES:
1. Negative numbers are ALWAYS encoded in 2's Complement before addition.
2. The ALU performs standard unsigned binary full-adder addition across all bits.
3. Any END CARRY generated out of the Most Significant Bit (MSB) is DISCARDED.
4. The result is automatically in correct 2's complement form (if positive, MSB=0;
   if negative, MSB=1).

--------------------------------------------------------------------------------
2. THE FOUR FUNDAMENTAL SIGNED ARITHMETIC CASES
--------------------------------------------------------------------------------

CASE 1: POSITIVE + POSITIVE  (e.g., +45 + +20 = +65)
  +45:  0010 1101
  +20:  0001 0100
  Sum:  0011 1101 = +65 (MSB=0, No Carry, No Overflow)

CASE 2: POSITIVE + NEGATIVE with |A| > |B|  (e.g., +45 + -20 = +25)
  +45:  0010 1101
  -20:  1110 1100 (2's comp of 20)
  Sum: 1 0001 1001 (Discard End Carry 1!)
  Result: 0001 1001 = +25 (MSB=0, Positive)

CASE 3: POSITIVE + NEGATIVE with |A| < |B|  (e.g., +20 + -45 = -25)
  +20:  0001 0100
  -45:  1101 0011 (2's comp of 45)
  Sum:  1110 0111 (No End Carry, MSB=1 → Negative!)
  Magnitude Check: Invert (00011000) + 1 = 00011001 = 25 → Result = -25.

CASE 4: NEGATIVE + NEGATIVE  (e.g., -20 + -45 = -65)
  -20:  1110 1100
  -45:  1101 0011
  Sum: 1 1011 1111 (Discard End Carry 1!, MSB=1 → Negative!)
  Magnitude Check: Invert (01000000) + 1 = 01000001 = 65 → Result = -65.

--------------------------------------------------------------------------------
3. MULTI-PRECISION SIGNED ARITHMETIC (ADD-WITH-CARRY)
--------------------------------------------------------------------------------
When registers cannot hold a large number in a single word (e.g. adding 64-bit numbers
on a 32-bit CPU, or 128-bit numbers on a 64-bit CPU):
1. Step 1: Add the Least Significant Words (LSW) using standard `ADD`.
2. Step 2: Add the Most Significant Words (MSW) using `ADC` (Add with Carry), which
   computes `MSW_A + MSW_B + Carry_from_LSW`.
3. Sign extension is applied to the upper word to preserve signed 2's complement value.

--------------------------------------------------------------------------------
4. HARDWARE STATUS FLAGS GENERATED
--------------------------------------------------------------------------------
After every arithmetic operation, the ALU updates 4 status bits in the EFLAGS/CPSR:
- ZERO FLAG (ZF): Set to 1 if every bit of the result is 0.
- SIGN FLAG (SF): Set to 1 if MSB of result is 1 (negative result).
- CARRY FLAG (CF): Set to 1 if addition generated a carry out of the MSB (unsigned overflow).
- OVERFLOW FLAG (OF): Set to 1 if signed arithmetic exceeded range (C_in(MSB) != C_out(MSB)).
