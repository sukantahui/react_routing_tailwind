1. EXECUTIVE OVERVIEW & HARDWARE FOUNDATION
--------------------------------------------------------------------------------
2's Complement is the universal standard for representing signed integers in all
modern computer microprocessors (x86-64, ARM, RISC-V, MIPS, PowerPC). It solves
every major defect of Sign-Magnitude and 1's Complement:
1. It possesses a UNIQUE ZERO (no +0 and -0 confusion).
2. It allows SUBTRACTION to be performed using the EXACT SAME physical adder circuit
   as addition, simply by inverting the second operand and setting Carry-In = 1.
3. Any end carry out of the MSB is SIMPLY DISCARDED by hardware (no slow end-around
   carry feedback loops).

--------------------------------------------------------------------------------
2. METHODS TO COMPUTE 2'S COMPLEMENT
--------------------------------------------------------------------------------
For an n-bit binary number N:

METHOD A: STANDARD TWO-STEP RULE (Invert and Add 1)
1. Invert all bits of the positive binary number (1's complement).
2. Add 1 to the Least Significant Bit (LSB).
   Formula: 2's_Comp(N) = 1's_Comp(N) + 1 = 2^n - N

METHOD B: SENIOR HARDWARE SHORTCUT (Right-to-Left Inspection)
1. Start from the rightmost bit (LSB) and move leftwards.
2. Copy all trailing zeros and the FIRST '1' bit EXACTLY as they are.
3. Invert all remaining bits to the left of that first '1'!
   Example: For 0011 0100 (+52)
   - Trailing bits up to first '1': ...100 (kept as 100)
   - Invert remaining left bits (00110): 11001
   - Result: 1100 1100 (-52). Instantaneous!

3. MATHEMATICAL WEIGHT FORMULA & NUMERICAL RANGE
--------------------------------------------------------------------------------
For an n-bit 2's Complement integer:
  V = (-b_{n-1} * 2^(n-1)) + Sum_{i=0}^{n-2} (b_i * 2^i)

DYNAMIC RANGE:
  Range: [-2^(n-1) to +2^(n-1) - 1]
  Total distinct values = 2^n

RANGE EXAMPLES:
  8-bit:  [-128 to +127]
  16-bit: [-32,768 to +32,767]
  32-bit: [-2,147,483,648 to +2,147,483,647]
  64-bit: [-9,223,372,036,854,775,808 to +9,223,372,036,854,775,807]

THE SPECIAL ASYMMETRIC VALUE (-2^(n-1)):
In 8-bit, 1000 0000 = -128. Negating -128 in 8-bit 2's complement causes an
overflow because +128 cannot fit in 8 bits!

4. STEP-BY-STEP WORKED EXAMPLES
--------------------------------------------------------------------------------

EXAMPLE 1: Convert Decimal -43 to 8-Bit 2's Complement
--------------------------------------------------------------------------------
Step 1: Positive 43 in binary:  00101011
Step 2: Invert all bits (1's):  11010100
Step 3: Add 1 to LSB:          11010101 = -43 (Hex: 0xD5)

Verification via Positional Weights:
  -128 + 64 + 0 + 16 + 0 + 4 + 0 + 1 = -128 + 85 = -43. [VERIFIED ✓]

EXAMPLE 2: Perform (+55) - (+25) using 8-Bit 2's Complement
--------------------------------------------------------------------------------
+55 = 00110111
+25 = 00011001 → 2's complement (-25) = 11100111

Addition:
    00110111  (+55)
  + 11100111  (-25 in 2's comp)
  ----------
  1 00011110  (Discard End Carry 1!)

Result: 00011110 = 16 + 8 + 4 + 2 = +30. Correct! (55 - 25 = 30)

5. UNIFIED HARDWARE ADDER / SUBTRACTOR CIRCUIT
--------------------------------------------------------------------------------
Modern CPU ALUs use an n-bit Full Adder with XOR gates on the second input:
- When Control Signal M = 0 (Addition):
  - XOR passes B unchanged (B XOR 0 = B).
  - Carry-In (C_in) = 0.
  - Output = A + B.
- When Control Signal M = 1 (Subtraction):
  - XOR inverts B (B XOR 1 = NOT B = 1's complement of B).
  - Carry-In (C_in) = 1.
  - Output = A + NOT(B) + 1 = A + 2's_Comp(B) = A - B!
