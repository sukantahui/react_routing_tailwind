1. THEORETICAL FOUNDATION: DECIMAL TO BINARY MAPPING
--------------------------------------------------------------------------------
In digital computer hardware, every decimal integer and real number must be
transduced into a sequence of binary digits (bits $\in \{0, 1\}$) representing
transistor gate voltage levels.

There are two primary algorithms to convert Decimal to Binary:

A. SUCCESSIVE DIVISION BY 2 (Standard Hardware/Software Algorithm for Integers):
   - Divide the integer $N$ by 2.
   - Record the remainder ($R \in \{0, 1\}$).
   - Divide the quotient by 2 and repeat until quotient equals 0.
   - Read remainders BOTTOM-UP: The first remainder produced is the Least Significant Bit (LSB / $2^0$),
     and the last remainder produced is the Most Significant Bit (MSB / $2^{k-1}$).

B. POWER-OF-2 DECOMPOSITION (Fast Mental Math / Hardware Bit-Masking Shortcut):
   - Identify the largest power of 2 that is $\le N$.
   - Place a '1' in that bit position and subtract the power of 2 from $N$.
   - Repeat for the remainder until $N = 0$.
   - Fill all unused intermediate bit positions with '0'.

2. FRACTIONAL DECIMAL TO BINARY CONVERSION (SUCCESSIVE MULTIPLICATION)
--------------------------------------------------------------------------------
For the fractional component ($0 < F < 1$):
- Multiply the fraction by 2.
- The integer part generated (0 or 1) is the next binary fractional digit ($b_{-1}, b_{-2}, \dots$).
- Discard the integer part and repeat with the remaining fractional part.
- Stop when the fraction becomes 0.000 or when desired bit-precision (e.g. 23 bits for IEEE single precision) is achieved.
- Read integer carries TOP-DOWN (First carry = $b_{-1}$, weight 0.5; second carry = $b_{-2}$, weight 0.25).

3. CONCRETE STEP-BY-STEP WORKED EXAMPLES
--------------------------------------------------------------------------------
Example 1: Convert Integer $156_{10}$ to Binary
- Successive Division:
  156 / 2 = 78  rem 0  (LSB, Bit 0)
   78 / 2 = 39  rem 0  (Bit 1)
   39 / 2 = 19  rem 1  (Bit 2)
   19 / 2 =  9  rem 1  (Bit 3)
    9 / 2 =  4  rem 1  (Bit 4)
    4 / 2 =  2  rem 0  (Bit 5)
    2 / 2 =  1  rem 0  (Bit 6)
    1 / 2 =  0  rem 1  (MSB, Bit 7)
  Read Bottom-Up: $(10011100)_2$

- Power-of-2 Verification:
  $156 = 128 + 16 + 8 + 4 = 2^7 + 2^4 + 2^3 + 2^2$
  Bit 7=1, Bit 6=0, Bit 5=0, Bit 4=1, Bit 3=1, Bit 2=1, Bit 1=0, Bit 0=0
  Result: $(10011100)_2$. Match confirmed!

Example 2: Convert Fractional $(0.8125)_{10}$ to Binary
- Successive Multiplication:
  $0.8125 \times 2 = 1.6250 \to \text{Integer Carry } 1 \quad (\text{MSB } b_{-1})$
  $0.6250 \times 2 = 1.2500 \to \text{Integer Carry } 1 \quad (b_{-2})$
  $0.2500 \times 2 = 0.5000 \to \text{Integer Carry } 0 \quad (b_{-3})$
  $0.5000 \times 2 = 1.0000 \to \text{Integer Carry } 1 \quad (b_{-4}, \text{Fraction}=0!)$
  Read Top-Down: $(0.1101)_2$
  Verification: $1/2 + 1/4 + 0/8 + 1/16 = 0.5 + 0.25 + 0.0625 = 0.8125_{10}$.

5. COMMON BEGINNER PITFALLS & BEST PRACTICES
--------------------------------------------------------------------------------
- PITFALL: Reversing the order of remainders (reading top-to-bottom instead of bottom-up).
- PITFALL: Assuming all decimal fractions terminate in binary (e.g. $0.2_{10} = 0.00110011\dots_2$ is non-terminating).
- BEST PRACTICE: For fast manual calculation, always test powers of 2 ($128, 64, 32, 16, 8, 4, 2, 1$) from left to right.
- BEST PRACTICE: When converting fractions, check the remainder precision requirement to avoid infinite loop locks.
