1. EXECUTIVE OVERVIEW & ARCHITECTURAL IMPORTANCE
--------------------------------------------------------------------------------
The D Flip-Flop (Data or Delay Flip-Flop) is the single most widely used sequential
storage element in modern computing. It forms the core foundation of:
- CPU General-Purpose Registers (EAX, RBX, R0..R31)
- Pipeline Latches (IF/ID, ID/EX, EX/MEM, MEM/WB)
- High-speed SRAM memory cells and cache tag arrays
- Shift registers and FIFO buffers

2. DERIVATION FROM SR FLIP-FLOP & THE NAND GATE SCHEMATIC
--------------------------------------------------------------------------------
Why was the D Flip-Flop created?
In an SR Flip-Flop, applying S = 1 and R = 1 simultaneously produces a forbidden/invalid
state that causes race conditions and metastability.

To permanently eliminate this failure mode by architectural design:
- Input D is connected directly to Set (S = D).
- The inverted complement of D is connected to Reset (R = ~D).
- Because D and ~D can never both be 1 at the same time, the invalid condition (S.R = 1)
  is MATHEMATICALLY IMPOSSIBLE!

Internal NAND Logic Structure:
  Input Stage:
    - Data Pin (D)
    - Clock Pin (CLK)
    - Inverter Gate: D_bar = ~D
    - Gate 1 (Top Steering NAND): S' = ~(D . CLK)
    - Gate 2 (Bottom Steering NAND): R' = ~(D_bar . CLK)

  Storage Latch Stage:
    - Gate 3 (Top Cross-Coupled NAND): Q = ~(S' . Q_bar)
    - Gate 4 (Bottom Cross-Coupled NAND): Q_bar = ~(R' . Q)

3. TRUTH TABLE & STATE TRANSITIONS
--------------------------------------------------------------------------------
+-----+-----+---------+-------------+------------------------------------+
| CLK |  D  | Q(t+1)  | Q_bar(t+1)  | Functional State / Hardware Action |
+-----+-----+---------+-------------+------------------------------------+
|  0  |  X  |  Q(t)   |  Q_bar(t)   | Memory Hold (Clock Inactive)       |
|  1  |  0  |    0    |      1      | Reset State (Stores 0)             |
|  1  |  1  |    1    |      0      | Set State (Stores 1)               |
+-----+-----+---------+-------------+------------------------------------+

4. MATHEMATICAL FORMULATION
--------------------------------------------------------------------------------
Characteristic Table:
  D  Q(t) | Q(t+1)
  0   0   |   0   (Reset)
  0   1   |   0   (Reset)
  1   0   |   1   (Set)
  1   1   |   1   (Set)

Characteristic Equation:
  Q(t+1) = D
  (The next state equals the data input during the active clock window).

Excitation Table:
  Q(t) -> Q(t+1) | D
    0  ->   0    | 0
    0  ->   1    | 1
    1  ->   0    | 0
    1  ->   1    | 1
  (In D Flip-Flops, the excitation input D is always identical to the desired next state Q(t+1)).

5. TIMING PARAMETERS & INVARIANTS
--------------------------------------------------------------------------------
1. Setup Time (t_su): Minimum time data input D must remain stable BEFORE the active clock edge.
2. Hold Time (t_h): Minimum time data input D must remain stable AFTER the active clock edge.
3. Propagation Delay (t_pd): Time elapsed from clock transition until output Q stabilizes.
Violating t_su or t_h causes the internal feedback latch to enter metastability.
