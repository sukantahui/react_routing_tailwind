1. CHARACTERISTIC TABLE VS EXCITATION TABLE: THE FUNDAMENTAL DIFFERENCE
--------------------------------------------------------------------------------
A. Characteristic Table (Analysis Tool):
   - Definition: Answers "Given Present State Q(t) and Inputs, what is Next State Q(t+1)?"
   - Purpose: Used for analyzing the behavior of existing sequential circuits.
   - Input Columns: Flip-Flop Inputs + Present State Q(t)
   - Output Column: Next State Q(t+1)

B. Excitation Table (Design & Synthesis Tool):
   - Definition: Answers "To cause a transition from Q(t) → Q(t+1), what Inputs are required?"
   - Purpose: Used by design engineers to synthesize counters, registers, and FSMs.
   - Input Columns: Present State Q(t) + Next State Q(t+1)
   - Output Columns: Required Flip-Flop Inputs (S, R / J, K / D / T)

2. MASTER EXCITATION TABLES FOR ALL 4 FLIP-FLOPS
--------------------------------------------------------------------------------
  Transition   |  SR Flip-Flop  |  JK Flip-Flop  |  D Flip-Flop  |  T Flip-Flop
  Q(t) → Q(t+1) |   S      R     |   J      K     |       D       |       T
  ---------------+----------------+----------------+---------------+---------------
    0  →   0    |   0      X     |   0      X     |       0       |       0
    0  →   1    |   1      0     |   1      X     |       1       |       1
    1  →   0    |   0      1     |   X      1     |       0       |       1
    1  →   1    |   X      0     |   X      0     |       1       |       0

3. EXAM MNEMONICS & SHORTCUT TRICKS
--------------------------------------------------------------------------------
A. JK Flip-Flop Trick:
   - J column always reads downward: 0, 1, X, X
   - K column always reads downward: X, X, 1, 0 (Reverse of J!)
B. D Flip-Flop Trick:
   - D is always identical to the Next State: D = Q(t+1).
C. T Flip-Flop Trick:
   - T is the XOR of Present State and Next State: T = Q(t) ^ Q(t+1).
     (If state stays same → T=0; if state toggles → T=1).
D. SR Flip-Flop Trick:
   - To make Q=0 → S=0, R=X; to make Q=1 → S=X, R=0.

4. STEP-BY-STEP FLIP-FLOP CONVERSION METHODOLOGY
--------------------------------------------------------------------------------
Suppose we want to convert AVAILABLE Flip-Flop (A) into TARGET Flip-Flop (B):
Step 1: Write down the Characteristic Table for the TARGET Flip-Flop.
Step 2: Append the Excitation Table columns of the AVAILABLE Flip-Flop based on
        the Q(t) and Q(t+1) columns.
Step 3: Draw Karnaugh Maps (K-Maps) for each input of the available flip-flop.
Step 4: Group 1s and Don't Cares (X) to derive minimal Boolean equations.
Step 5: Draw the combinational logic hardware driving the available flip-flop inputs.
