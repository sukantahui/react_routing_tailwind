1. DISCRETE SUMMATIONS IN LOOP ANALYSIS
--------------------------------------------------------------------------------
• Arithmetic Series (Dependent Loop `for i=1..n; for j=1..i`):
    Sum_{i=1 to n} i = 1 + 2 + 3 + ... + n = n*(n + 1)/2 = O(n^2)

• Sum of Squares (`for i=1..n; for j=1..i^2`):
    Sum_{i=1 to n} i^2 = n*(n + 1)*(2n + 1)/6 = O(n^3)

• Geometric Series (`for i=1; i<=n; i*=2`):
    1 + 2 + 4 + 8 + ... + 2^k <= n   =>  k = log2(n) iterations → O(log n)

• Standard Harmonic Series:
    H_n = 1 + 1/2 + 1/3 + 1/4 + ... + 1/n = ln(n) + O(1) = Θ(log n)

• Prime Harmonic Series (Sieve of Eratosthenes):
    Sum_{p <= n, p is prime} (n / p) = n * (ln(ln(n)) + M) = O(n log log n)

2. COMMON LOOP PATTERNS & COMPLEXITIES
--------------------------------------------------------------------------------
C Code Pattern                                 Time Complexity
--------------------------------------------------------------------------------
for (int i = 0; i < n; i += c)                O(n) [Linear]
for (int i = 0; i < n; i *= 2)                O(log2 n) [Logarithmic]
for (int i = n; i > 0; i /= 2)                O(log2 n) [Logarithmic]
for (int i = 1; i * i <= n; i++)              O(sqrt(n)) [Square Root]
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j += i)           O(n log n) [Harmonic Loop]
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++)              O(n^2) [Quadratic]

3. HARMONIC NESTED LOOP DERIVATION
--------------------------------------------------------------------------------
Consider:
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j += i) {
            // Inner loop executes n/i times
        }
    }
Total Operations:
    T(n) = n/1 + n/2 + n/3 + ... + n/n = n * (1 + 1/2 + ... + 1/n) = n * H_n = O(n log n)
