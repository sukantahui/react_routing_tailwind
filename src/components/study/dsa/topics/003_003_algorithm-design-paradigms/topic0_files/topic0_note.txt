1. ALGORITHM DESIGN PARADIGMS SUMMARY
--------------------------------------------------------------------------------
Paradigm                Key Invariant                       Example Problems
--------------------------------------------------------------------------------
Greedy                  Locally optimal choice at each step Fractional Knapsack, Prim's, Huffman
Dynamic Programming     Overlapping subproblem memoization  0/1 Knapsack, LCS, Shortest Path
Backtracking            State-space tree pruning            N-Queens, Sudoku, Maze Navigation
Divide and Conquer      Independent subproblem splitting   Merge Sort, Quick Sort, Binary Search

2. DP VS GREEDY COMPARISON
--------------------------------------------------------------------------------
- Fractional Knapsack: Greedy strategy works (Sort by Value / Weight ratio).
- 0/1 Knapsack: Greedy fails. Dynamic Programming required (O(n * W) table).
