1. DOUBLY LINKED LIST NODE IN C
--------------------------------------------------------------------------------
struct Node {
    int data;
    struct Node *prev;
    struct Node *next;
};

2. DELETION ADVANTAGE
--------------------------------------------------------------------------------
Given `Node *del`:
  if (del->prev) del->prev->next = del->next;
  if (del->next) del->next->prev = del->prev;
  free(del);
Time Complexity: O(1) direct pointer deletion!
