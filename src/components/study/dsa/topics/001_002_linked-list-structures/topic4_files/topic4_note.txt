--------------------------------------------------------------------------------
struct Term {
    int coeff;
    int exp;
    struct Term *next;
};

2. ADDITION LOGIC
--------------------------------------------------------------------------------
Compare exponents exp1 vs exp2:
- exp1 > exp2: Copy P1 term, advance P1.
- exp1 < exp2: Copy P2 term, advance P2.
- exp1 == exp2: Sum coefficients, advance both P1 and P2.
