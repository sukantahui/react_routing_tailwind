1. THE INCOMPLETE TYPE PROBLEM & POINTER INDIRECTION
--------------------------------------------------------------------------------
Illegal Direct Embedding:
    struct Node {
        int data;
        struct Node next; // COMPILE ERROR: field has incomplete type
    };
    Reason: A struct cannot contain a full instance of itself because its 
    size would be infinite (recursive memory calculation: 4 + 4 + 4... = inf).

Valid Self-Referential Pointer:
    typedef struct Node {
        int data;           // 4 bytes payload
        struct Node *next;  // 8 bytes (fixed 64-bit virtual memory address)
    } Node;
    Reason: Regardless of struct payload, an address pointer is ALWAYS 8 bytes
    on 64-bit (or 4 bytes on 32-bit). The compiler knows the size immediately.

2. HARDWARE MEMORY ALIGNMENT & STRUCT PADDING (64-BIT x86-64)
--------------------------------------------------------------------------------
Why sizeof(Node) is 16 Bytes (Not 12 Bytes):
    Offset 0x00 .. 0x03 : int data              (4 Bytes)
    Offset 0x04 .. 0x07 : COMPILER PADDING HOLE (4 Bytes - Unused alignment)
    Offset 0x08 .. 0x0F : struct Node *next     (8 Bytes - 64-bit pointer)
    Total Allocated Size: 16 Bytes

Hardware Rationale:
    CPUs fetch memory in 8-byte word blocks across the 64-bit data bus.
    Unaligned 8-byte pointers crossing boundary words require two bus cycles 
    and bit shifts. Padding guarantees single-cycle memory reads.

3. WHAT IS A HEAP NODE? (FORMAL DEFINITION & MEMORY MODEL)
--------------------------------------------------------------------------------
Definition:
    A "Heap Node" is an independently allocated, persistent memory chunk 
    instantiated within the Heap Memory Segment via malloc(sizeof(Node)).
    It encapsulates:
      1. Data payload (e.g. 4-byte int).
      2. Hardware alignment padding (e.g. 4-byte hole).
      3. Self-referential address pointer (8-byte struct Node *next).
      4. An invisible glibc chunk header (8 bytes) tracking allocation metadata.

Stack vs. Heap Contrast:
    - Stack Variable (`Node *head`): 8-byte pointer living in function frame.
    - Heap Node: 16-byte struct living in dynamic heap RAM, persisting until
      explicitly released via free().

4. DYNAMIC HEAP ALLOCATION VIA malloc() & DEFENSIVE GUARDS
--------------------------------------------------------------------------------
Node Creation Pattern:
    Node* createNode(int value) {
        Node *newNode = (Node *)malloc(sizeof(*newNode)); // Best practice
        if (newNode == NULL) {
            fprintf(stderr, "[PANIC] OS Heap Allocation Failed!\n");
            exit(EXIT_FAILURE);
        }
        newNode->data = value;
        newNode->next = NULL; // Sentinel termination
        return newNode;
    }

Rule of Ownership & Lifecycle:
    - Stack variables disappear when the function frame pops.
    - Heap nodes persist in dynamic RAM until explicitly released with free().

4. THE NULL SENTINEL & MMU VIRTUAL PAGE 0 TRAP
--------------------------------------------------------------------------------
- NULL is defined as ((void*)0) or 0x0.
- Virtual Page 0 (0x0000000000000000 to 0x0000000000000FFF) is deliberately
  unmapped and protected by OS kernels (Linux, Windows, macOS).
- Dereferencing NULL (e.g. NULL->next) causes a hardware Memory Management 
  Unit (MMU) Page Fault, raising SIGSEGV (Signal 11 / Segmentation Fault).
- Sentinel Invariant: Every terminated chain must end with tail->next = NULL.

5. ZERO-LEAK SAFE DEALLOCATION PROTOCOL
--------------------------------------------------------------------------------
Never free current node before reading next:
    // 🚫 BUGGY (Use-After-Free):
    // free(curr); curr = curr->next;

    // ✅ DEFENSIVE ZERO-LEAK CLEANUP:
    void freeList(Node **headRef) {
        Node *curr = *headRef;
        Node *temp = NULL;
        while (curr != NULL) {
            temp = curr->next; // 1. Save downstream pointer
            free(curr);        // 2. Release current heap block
            curr = temp;       // 3. Advance to saved pointer
        }
        *headRef = NULL;       // 4. Neutralize dangling head pointer
    }
