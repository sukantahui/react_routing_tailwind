1. WHAT IS A SPARSE MATRIX?
--------------------------------------------------------------------------------
A Sparse Matrix is a matrix in which the overwhelming majority of elements 
are zeroes (typically > 80% to 99.9% zeros).

Sparsity Formula:
  Sparsity = (Number of Zero Elements) / (Total Elements [Rows * Cols])

Storage Problem with Standard 2D Arrays:
- Allocating a full 2D array of size M x N wastes (M * N * sizeof(int)) bytes.
- In high-dimensional data (e.g. 100,000 x 100,000 matrix), 40 GB of RAM is 
  consumed holding empty zeros!


2. 3-TUPLE (COORDINATE LIST - COO) REPRESENTATION
--------------------------------------------------------------------------------
A Sparse Matrix is stored as a 1D array of 3-Tuples: `Term triplet[MAX_TERMS]`
where each `Term` contains `{ int row, int col, int val }`.

- Index [0] (Header Term):
    triplet[0].row = Total Rows in original matrix (M)
    triplet[0].col = Total Columns in original matrix (N)
    triplet[0].val = Total number of Non-Zero elements (NZ)

- Indices [1 .. NZ]:
    triplet[i] = { row_index, col_index, non_zero_value }

- Invariant: Elements MUST be stored sorted in strict Row-Major order 
  (first by row index ascending, then by column index ascending).

Memory Comparison:
  Standard 2D Array :  (Rows * Cols) * 4 bytes
  3-Tuple Format    :  (NZ + 1) * 3 * 4 bytes
  Memory Saved      :  Up to 99.9% in highly sparse matrices.


3. SIMPLE TRANSPOSE ALGORITHM
--------------------------------------------------------------------------------
To transpose a sparse matrix, `row` and `col` coordinates swap, but the 
resulting array MUST be sorted by the new row indices (old column indices).

- Algorithm:
  For each column `c` from 0 to `Cols - 1`:
      Scan all `NZ` elements in `a[]`.
      If `a[i].col == c`, append `{ a[i].col, a[i].row, a[i].val }` to `b[]`.

- Complexity:
  Time Complexity  : O(Cols * NZ)  (Worst case: O(R * C^2))
  Space Complexity : O(1) auxiliary space.


4. FAST TRANSPOSE ALGORITHM
--------------------------------------------------------------------------------
Fast Transpose achieves O(Cols + NZ) linear time by using Prefix-Sum 
frequency indexing (Counting Sort principle).

- Step 1: Initialize `total[Cols]` with 0.
  Count occurrences of each column index:
    for (i = 1; i <= NZ; i++) total[a[i].col]++;   -> O(NZ)

- Step 2: Compute Starting Positions `starting_pos[Cols]`:
    starting_pos[0] = 1;
    for (c = 1; c < Cols; c++) 
        starting_pos[c] = starting_pos[c - 1] + total[c - 1];  -> O(Cols)

- Step 3: Single-Pass Direct Migration:
    for (i = 1; i <= NZ; i++) {
        j = starting_pos[a[i].col]++;
        b[j].row = a[i].col;
        b[j].col = a[i].row;
        b[j].val = a[i].val;
    }                                              -> O(NZ)

- Complexity:
  Time Complexity  : O(Cols + NZ) linear time.
  Auxiliary Space  : O(Cols) for `total[]` and `starting_pos[]` arrays.


5. ALGORITHM COMPARISON SUMMARY
--------------------------------------------------------------------------------
Metric              Simple Transpose            Fast Transpose
--------------------------------------------------------------------------------
Time Complexity     O(Cols * NZ)                O(Cols + NZ)
Auxiliary Space     O(1)                        O(Cols)
Passes over Data    Cols passes                 1 single pass
Core Technique      Exhaustive Linear Scan      Prefix Sum / Bucket Indexing
Ideal For           Very small matrices         Industrial & Large-scale sparse
