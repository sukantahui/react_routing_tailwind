1. PROBING FORMULAS
--------------------------------------------------------------------------------
Linear Probing:    index = (h(k) + i) % TableSize
Quadratic Probing: index = (h(k) + c1*i + c2*i^2) % TableSize
Double Hashing:    index = (h1(k) + i * h2(k)) % TableSize
