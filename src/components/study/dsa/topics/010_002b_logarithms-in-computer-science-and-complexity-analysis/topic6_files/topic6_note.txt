1. HARDWARE BIT-SCAN INSTRUCTION: __builtin_clz(N)
--------------------------------------------------------------------------------
Modern CPUs (Intel x86, AMD, ARM) have dedicated hardware instructions to find
the most significant bit in a single clock cycle:
  - x86: BSR (Bit Scan Reverse) / LZCNT (Leading Zero Count)
  - ARM: CLZ (Count Leading Zeros)

In GCC / Clang C:
  int fast_log2 = 31 - __builtin_clz(n);

This computes floor(log_2(n)) in O(1) time without any floating point division
or loop iterations!
