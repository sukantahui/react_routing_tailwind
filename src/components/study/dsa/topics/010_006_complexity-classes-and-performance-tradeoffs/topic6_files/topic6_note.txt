1. CONCEPT OVERVIEW & THEORETICAL FOUNDATIONS
--------------------------------------------------------------------------------
Topic Title: Classroom Lab Dialogue: Hardware Profiling (Valgrind, Cachegrind, gprof) vs Theoretical Big-O Curves
Course Module: Complexity Classes (P, NP, NP-Complete) & Real-World Engineering Trade-Offs

Core Principles:
  • Memory Integrity: Strict bounds checking on all array indices and pointers.
  • Time Invariants: Asymptotically optimal step execution.
  • Space Optimization: Minimal auxiliary allocation to leverage CPU cache lines.

2. ASYMPTOTIC COMPLEXITY ANALYSIS
--------------------------------------------------------------------------------
Operation / Phase         Time Complexity       Auxiliary Space
--------------------------------------------------------------------------------
Primary Execution         O(N) or O(log N)      O(1) / O(N)
Memory Allocation         O(1)                  O(N) total block
Teardown / Cleanup        O(1) or O(N)          O(1)

3. MEMORY SAFETY & POINTER INVARIANTS
--------------------------------------------------------------------------------
[✓] Check pointer return after malloc(): `if (!ptr) { exit(EXIT_FAILURE); }`
[✓] Neutralize pointers post-deallocation: `free(ptr); ptr = NULL;`
[✓] Never access memory outside allocated boundaries: `0 <= index < capacity`
