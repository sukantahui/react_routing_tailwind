1. NON-COMPARISON SORTS COMPLEXITY
--------------------------------------------------------------------------------
Algorithm       Time Complexity     Space Complexity    Constraint
--------------------------------------------------------------------------------
Counting Sort   O(n + k)            O(n + k)            Small integer range [0..k]
Radix Sort      O(d * (n + k))      O(n + k)            Fixed digit length d
Bucket Sort     O(n + k) avg        O(n + k)            Uniform distribution [0,1)
