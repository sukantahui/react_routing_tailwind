1. SHUNTING-YARD ALGORITHM RULES
--------------------------------------------------------------------------------
1. Operands → Output string immediately.
2. '(' → Push to operator stack.
3. ')' → Pop stack to output string until '(' is encountered. Pop '('.
4. Operator op → Pop stack operators of higher/equal precedence to output string, then push op.
