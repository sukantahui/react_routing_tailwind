1. HEAP SORT ALGORITHM STEPS
--------------------------------------------------------------------------------
1. Build Max Heap from unsorted 1D array: O(n)
2. Swap root arr[0] with last element arr[i].
3. Reduce heap size by 1 and call heapify(arr, i, 0): O(log n)
4. Repeat for all elements → Guaranteed O(n log n) Time, O(1) Space.
