1. FORMAL DEFINITIONS OF ASYMPTOTIC NOTATIONS
--------------------------------------------------------------------------------
Given algorithm execution step function f(n) and reference bounding function g(n):

• Big-O (O) - Asymptotic Upper Bound:
    f(n) = O(g(n))  <=>  There exist positive constants c > 0 and n0 >= 1 such that
                         0 <= f(n) <= c * g(n)  for all n >= n0.

• Big-Omega (Ω) - Asymptotic Lower Bound:
    f(n) = Ω(g(n))  <=>  There exist positive constants c > 0 and n0 >= 1 such that
                         0 <= c * g(n) <= f(n)  for all n >= n0.

• Big-Theta (Θ) - Tight Asymptotic Bound:
    f(n) = Θ(g(n))  <=>  f(n) = O(g(n)) AND f(n) = Ω(g(n)).
                         0 <= c1 * g(n) <= f(n) <= c2 * g(n)  for all n >= n0.

• Little-o (o) - Strict Non-Tight Upper Bound:
    f(n) = o(g(n))  <=>  lim_{n -> inf} [ f(n) / g(n) ] = 0.

• Little-omega (ω) - Strict Non-Tight Lower Bound:
    f(n) = ω(g(n))  <=>  lim_{n -> inf} [ f(n) / g(n) ] = inf.

2. THE COMPLEXITY HIERARCHY (GROWTH RATES)
--------------------------------------------------------------------------------
Order                     Notation           Operations for N = 1,000,000
--------------------------------------------------------------------------------
Constant                  O(1)               1 operation
Logarithmic               O(log2 N)          ~20 operations
Square Root               O(sqrt(N))         1,000 operations
Linear                    O(N)               1,000,000 operations
Linearithmic              O(N log2 N)        ~20,000,000 operations
Quadratic                 O(N^2)             10^12 operations (Unscalable)
Cubic                     O(N^3)             10^18 operations (Unscalable)
Exponential               O(2^N)             2^1000000 (Physical impossibility)
Factorial                 O(N!)              (Exceeds atoms in the universe)

3. RAM MACHINE MODEL ASSUMPTIONS
--------------------------------------------------------------------------------
In standard algorithm analysis:
  • Arithmetic operations (+, -, *, /, %) take O(1) constant step cost.
  • Pointer dereference and array index reads `arr[i]` take O(1) step cost.
  • Memory allocation and function calls take O(1) step cost.

4. STEP-BY-STEP PROOF EXAMPLE
--------------------------------------------------------------------------------
Prove that `3n^2 + 5n + 7 = O(n^2)`:
  For all n >= 1:
    5n <= 5n^2
    7  <= 7n^2
  Therefore:
    3n^2 + 5n + 7 <= 3n^2 + 5n^2 + 7n^2 = 15n^2
  Choosing constant c = 15 and n0 = 1:
    0 <= 3n^2 + 5n + 7 <= 15 * n^2  for all n >= 1.
  Hence, 3n^2 + 5n + 7 = O(n^2) is rigorously proven!
