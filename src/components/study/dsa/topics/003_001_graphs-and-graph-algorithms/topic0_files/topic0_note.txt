1. GRAPH REPRESENTATION COMPARISON
--------------------------------------------------------------------------------
Representation    Space Complexity    Edge Lookup    Ideal Use Case
--------------------------------------------------------------------------------
Adjacency Matrix  O(V^2)              O(1)           Dense Graphs (E ~ V^2)
Adjacency List    O(V + E)            O(degree)      Sparse Graphs (E << V^2)

2. GRAPH TRAVERSAL ALGORITHMS
--------------------------------------------------------------------------------
- Breadth-First Search (BFS): Queue-based level-order traversal. O(V + E) time.
- Depth-First Search (DFS): Stack/Recursion-based deep branch traversal. O(V + E) time.

3. SHORTEST PATH & SPANNING TREES
--------------------------------------------------------------------------------
- Dijkstra's Algorithm: Single-Source Shortest Path (Non-negative weights). O(E log V).
- Bellman-Ford: Single-Source Shortest Path (Handles negative weights & cycles). O(V * E).
- Kruskal's MST: Greedy edge selection using Disjoint Set Union (DSU). O(E log E).
- Prim's MST: Greedy vertex expansion using Min-Heap. O(E log V).
