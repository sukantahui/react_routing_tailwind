1. SHELL SORT GAP SEQUENCES
--------------------------------------------------------------------------------
- Shell's original sequence: N/2, N/4, ..., 1
- Knuth's sequence: (3^k - 1) / 2 -> 1, 4, 13, 40, 121... (O(n^(3/2)) time)

2. HYBRID ENTERPRISE SORTS
--------------------------------------------------------------------------------
- TimSort: Hybrid Insertion Sort (for small runs) + Merge Sort (Python, Java, V8 JS).
- IntroSort: Hybrid Quick Sort + Heap Sort fallback (to avoid O(n^2)) + Insertion Sort (C++ std::sort).
