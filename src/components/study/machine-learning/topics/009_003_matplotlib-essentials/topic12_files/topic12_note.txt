2. GROUPED MULTI-SUBJECT ARCHITECTURE:
   - Calculate numeric centers: `x = np.arange(len(students))`
   - Symmetric offsets: `x - width`, `x`, `x + width`
   - Explicit axis tick binding: `ax.set_xticks(x); ax.set_xticklabels(students)`
   - Annotation with `ax.bar_label(rects, padding=2)`

3. RADAR / SPIDER PLOT IMPLEMENTATION:
   - Uses polar projection: `fig, ax = plt.subplots(subplot_kw=dict(polar=True))`
   - Angles generation: `angles = [n / N * 2 * np.pi for n in range(N)]`
   - Closing the loop: Append `angles[:1]` and `scores[:1]` so the line polygon connects back to the start.
   - Fill polygon: `ax.fill(angles, scores, alpha=0.25)`

4. DECISION INSIGHTS FOR INSTRUCTORS:
   - Grouped bars identify subjects needing remedial sessions.
   - Line plots identify high velocity vs plateauing students.
   - Radar charts provide holistic student diagnostic profiles.
