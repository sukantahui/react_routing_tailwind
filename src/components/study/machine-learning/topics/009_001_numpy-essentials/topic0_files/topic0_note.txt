WHAT IS NUMPY?
--------------
NumPy (Numerical Python) is the foundational scientific computing
library for Python. It was created by Travis Oliphant in 2005 and
is the backbone of almost every data science and ML library today,
including Pandas, Scikit-learn, TensorFlow, and SciPy.

NumPy provides:
  - A powerful N-dimensional array object (ndarray)
  - Mathematical functions that operate on entire arrays
  - Broadcasting for operations on differently-shaped arrays
  - Linear algebra, Fourier transforms, and random number tools
  - A C-language backend for near-hardware speed

WHY DO WE NEED NUMPY?
---------------------
Python lists are flexible but SLOW for numerical computation:
  - Python list: stores objects, has overhead per element
  - NumPy ndarray: stores typed data in contiguous C memory
  - Speedup: NumPy is typically 10x to 100x faster than Python loops

Example of speed difference:
  Pure Python: for i in range(1_000_000): x[i] * 2   → ~200ms
  NumPy:       arr * 2                                 → ~2ms

WHERE IS NUMPY USED IN ML?
--------------------------
1. Feature matrices (X) are NumPy arrays
2. Target vectors (y) are NumPy arrays
3. Model weights and gradients are stored as NumPy arrays
4. All Scikit-learn models accept NumPy arrays as input
5. Pandas DataFrames are built on NumPy arrays internally

NUMPY IN THE ML PIPELINE:
  Raw Data → Pandas DataFrame → .values → NumPy ndarray → Model

CORE NUMPY MODULES:
  numpy           → main namespace (np.array, np.zeros, etc.)
  numpy.linalg    → linear algebra (matrix operations)
  numpy.random    → random number generation
  numpy.fft       → Fast Fourier Transform
  numpy.ma        → masked arrays for missing data

REAL-WORLD APPLICATIONS:
  - Image data: a 28×28 grayscale image is a (28,28) NumPy array
  - Audio data: sound samples stored as 1D NumPy arrays
  - Sensor data: temperature readings as time-series NumPy arrays
  - NLP: word embeddings stored as (vocab_size, embedding_dim) arrays
  - Finance: stock price history as 1D or 2D NumPy arrays

HISTORICAL NOTE:
  - 1995: Numeric (predecessor) created by Jim Hugunin
  - 2001: SciPy built on Numeric
  - 2005: NumPy created as unified successor by Travis Oliphant
  - 2006: NumPy 1.0 released
  - Today: NumPy is used by NASA, CERN, Google, and academic labs

KEY VOCABULARY:
  ndarray   → N-dimensional array (the core object)
  axis      → a dimension of the array
  shape     → tuple describing the size of each axis
  dtype     → data type of elements (int32, float64, etc.)
  vectorize → performing operations on entire arrays at once
