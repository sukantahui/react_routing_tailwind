========================================================
NUMPY ESSENTIALS — TOPIC 4: ARRAY CREATION FUNCTIONS
np.zeros, np.ones, np.arange, np.linspace
========================================================

ARRAY CREATION FUNCTIONS:
These create arrays of a specified shape without needing input data.

np.zeros(shape, dtype=float64)
  → Array filled with 0.0
  → Use: initializing weight matrices in ML
  np.zeros((3, 4))   → 3×4 matrix of zeros

np.ones(shape, dtype=float64)
  → Array filled with 1.0
  → Use: bias initialization, mask creation
  np.ones((5,))      → [1. 1. 1. 1. 1.]

np.full(shape, fill_value)
  → Array filled with any constant
  np.full((3,3), 7)  → 3×3 matrix of 7s

np.eye(N)
  → N×N identity matrix (1s on diagonal, 0s elsewhere)
  → Use: linear algebra operations
  np.eye(3)  → [[1,0,0],[0,1,0],[0,0,1]]

np.arange(start, stop, step)
  → Like Python range() but returns ndarray
  → Integer or float steps
  np.arange(0, 10, 2)  → [0, 2, 4, 6, 8]
  np.arange(0, 1, 0.1) → [0.0, 0.1, 0.2, ..., 0.9]
  NOTE: stop is EXCLUSIVE (like Python range)

np.linspace(start, stop, num)
  → num evenly spaced floats from start to stop (INCLUSIVE)
  → Use: plotting, creating test inputs
  np.linspace(0, 1, 5)   → [0.0, 0.25, 0.5, 0.75, 1.0]
  np.linspace(0, 10, 11) → [0, 1, 2, ..., 10]

arange vs linspace:
  np.arange(0, 1, 0.1)   → step-based, may have floating-point issues
  np.linspace(0, 1, 11)  → count-based, exact endpoint control

QUICK REVISION:
  □ np.zeros(shape)        → all zeros
  □ np.ones(shape)         → all ones
  □ np.eye(N)              → identity matrix
  □ np.arange(start,stop)  → step-based sequence
  □ np.linspace(a,b,N)     → N evenly spaced including endpoints
