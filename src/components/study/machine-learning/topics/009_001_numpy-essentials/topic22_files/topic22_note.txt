1. CORE NUMPY ESSENTIALS FOR ML INTERVIEWS
-------------------------------------------
- Q1: Why is NumPy fast compared to Python lists?
  * Homogeneous data types: Eliminates Python object header overhead and dynamic type dispatching.
  * Contiguous memory allocation: Maximizes CPU cache locality (L1/L2/L3 cache hits).
  * Vectorized C/Fortran SIMD implementations (AVX2, AVX-512, BLAS, LAPACK).

- Q2: What is the difference between a View and a Copy?
  * View: A new array object sharing the same underlying memory buffer (modifications mutate original array). Produced by basic slicing `arr[1:4]`, `arr.T`, and `arr.ravel()`.
  * Copy: A completely new memory allocation. Produced by fancy indexing `arr[[0, 2]]`, boolean indexing `arr[arr > 5]`, and `arr.flatten()`.

- Q3: Explain NumPy Broadcasting Rules.
  1. Pad shorter shapes with 1 on the left until dimensions match.
  2. Along each dimension from right to left, shapes must either be equal OR one of them must be 1.
  3. Dimensions of size 1 are stretched to match the larger size without data replication.

- Q4: Difference between A * B, np.dot(A, B), and A @ B.
  * `A * B`: Element-wise (Hadamard) product.
  * `np.dot(A, B)`: 1D vector dot product, 2D matrix multiplication.
  * `A @ B` / `np.matmul(A, B)`: Standard matrix multiplication operator supporting multi-dimensional batch stacks.

- Q5: What is the difference between np.sum(arr, axis=0) and axis=1?
  * `axis=0`: Collapses rows (computes stats down columns, producing per-feature stats).
  * `axis=1`: Collapses columns (computes stats across rows, producing per-sample stats).
