1. WHAT IS A SCIKIT-LEARN PIPELINE?
--------------------------------------------------------------------------------
A `Pipeline` chains multiple sequential data transformation steps with a final machine learning estimator into a single composite object.

CORE RULES OF A PIPELINE:
1. Every intermediate step (all except the last) MUST be a Transformer implementing `.fit()` and `.transform()`.
2. The final step can be an Estimator, Classifier, Regressor, Clusterer, or Transformer.
3. Calling `pipe.fit(X, y)` triggers `.fit_transform()` sequentially down the chain and `.fit()` on the final estimator.
4. Calling `pipe.predict(X_new)` automatically applies `.transform()` through all intermediate steps before calling `.predict()` on the final estimator.

2. WHY USE PIPELINES? (THE 3 MAJOR BENEFITS)
--------------------------------------------------------------------------------
A. Elimination of Data Leakage:
   - When tuning models with `cross_val_score()` or `GridSearchCV`, preprocessing parameters (like mean and variance in `StandardScaler`) are re-fitted strictly on the training folds, never seeing the validation fold!

B. Production Deployment & Clean Code:
   - Bundles all imputation, scaling, one-hot encoding, and model weights into one serialized pickle/joblib file.
   - Raw production JSON payloads can be passed straight to `pipeline.predict()`.

C. Code Modularity & Readability:
   - Replaces dozens of fragmented preprocessing variables (`X_train_imp_scaled_enc`) with a single pipeline object.

3. CONVENIENT SHORTHAND: `make_pipeline()`
--------------------------------------------------------------------------------
- Standard syntax:
  `Pipeline([('scaler', StandardScaler()), ('clf', LogisticRegression())])`
- Shorthand syntax:
  `make_pipeline(StandardScaler(), LogisticRegression())`
  (Automatically assigns lowercase class names as step keys: `'standardscaler'`, `'logisticregression'`).

4. ACCESSING INTERMEDIATE PARAMETERS & HYPERPARAMETER TUNING
--------------------------------------------------------------------------------
- Access step object: `pipe.named_steps['scaler'].mean_`
- Parameter naming convention for GridSearchCV / RandomizedSearchCV:
  Use double underscore `<step_name>__<parameter_name>`:
  `param_grid = {'classifier__C': [0.1, 1, 10], 'scaler__with_mean': [True, False]}`
