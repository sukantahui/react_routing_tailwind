1. PLAIN VECTOR CONCEPT (FOUNDATIONS)
-------------------------------------------------------------------------------
Before discussing Machine Learning feature vectors, we must understand plain vectors:

A. SCALAR vs. VECTOR:
   - Scalar: A single real number having MAGNITUDE ONLY, but no direction.
     Examples: Temperature (32°C), Mass (65 kg), Speed (40 km/h).
   - Vector: A quantity possessing BOTH MAGNITUDE (length) AND DIRECTION.
     Examples: Velocity (40 km/h East), Displacement (5 km to Barrackpore), Force (10 N downward).

B. GEOMETRIC REPRESENTATION:
   - A directed line segment (arrow) starting at initial point (tail/origin)
     and ending at terminal point (head/tip).
   - Arrow length = Magnitude ||v||.
   - Arrowhead = Direction angle theta.

C. ALGEBRAIC REPRESENTATION:
   - 2D Vector: v = [v_x, v_y]^T = v_x * i + v_y * j (Arrow on 2D plane).
   - 3D Vector: v = [v_x, v_y, v_z]^T (Arrow in 3D space).

2. THE BRIDGE TO MACHINE LEARNING FEATURE VECTORS
-------------------------------------------------------------------------------
- In Physics: Vector dimensions represent physical spatial axes (X, Y, Z).
- In Machine Learning: Vector dimensions represent observation features
  (e.g., [Age, Salary (₹), Credit Score, Existing Debt]).

  Feature Vector x = [x_1, x_2, ..., x_d]^T in R^d

Every single data instance (a row in a dataset) is represented as a feature vector!

3. CORE VECTOR OPERATIONS IN MACHINE LEARNING
-------------------------------------------------------------------------------
1. Vector Addition / Subtraction:
   x +/- y = [x_1 +/- y_1, x_2 +/- y_2, ..., x_d +/- y_d]^T
   (Used in updating centroids in K-Means, gradient descent parameter updates)

2. Scalar Multiplication:
   c * x = [c * x_1, c * x_2, ..., c * x_d]^T
   (Used in scaling feature magnitudes, learning rate updates)

3. Dot Product (Inner Product):
   a . b = a^T * b = sum_{i=1}^d (a_i * b_i) = ||a|| * ||b|| * cos(theta)
   (Used in Linear Regression predictions y_hat = w^T * x + b, Support Vector Machines)

4. Euclidean Norm (L2 Length):
   ||x||_2 = sqrt( sum_{i=1}^d x_i^2 )
   (Used in measuring vector magnitude, feature scaling, Euclidean distance calculations)

5. Cosine Similarity:
   cos(theta) = (a . b) / (||a|| * ||b||)
   (Used in NLP document similarity, recommendation systems, semantic search)

5. SUMMARY & GOLDEN RULE
-------------------------------------------------------------------------------

extend these arrows to multi-dimensional feature spaces, allowing Machine Learning
algorithms to compute predictions, distances, and angles!" — Teacher
