1. EXECUTIVE DEFINITIONS & MATHEMATICAL TAXONOMY
-----------------------------------------------------------------------------
Numerical (Quantitative) data represents measurable amounts and counts. Within
the numerical domain, variables are strictly bifurcated into two mathematical species:

A. DISCRETE VARIABLES (Countable Isolated Values):
   - Definition: A variable whose support X is a countable set (finite or countably infinite).
   - Values exist as isolated points on the real number line separated by distinct gaps.
   - Arithmetic Structure: Typically non-negative integers Z_{>=0} = {0, 1, 2, ...}.
     (Non-integers are also discrete if countably finite with fixed increments, e.g. shoe sizes).
   - Key Rule: Cannot take arbitrary intermediate fractional values.
     (e.g., A household cannot have 2.37 children; a hospital cannot record 4.8 emergency visits).
   - Examples:
     * Number of prior hospital admissions (0, 1, 2, 3...)
     * Number of daily customer purchases at Barrackpore retail store
     * Number of network packet retransmission timeouts
     * Number of active credit cards held by an applicant

B. CONTINUOUS VARIABLES (Measurable Unbroken Continuum):
   - Definition: A variable whose support X is an uncountable interval (a, b) subset of R.
   - Values form an unbroken spectrum where, between any two arbitrary points x1 and x2,
     there exist infinitely many possible intermediate real numbers.
   - Physical Nature: Limited only by the precision of the measuring instrument (thermometer,
     stopwatch, digital scale, laser spectrometer).
   - Examples:
     * Patient Body Temperature: 36.65 °C, 37.82 °C
     * Serum Creatinine Concentration: 1.14 mg/dL
     * Real Estate Flat Price: ₹64.85 Lakhs
     * Vehicle Velocity: 54.32 km/h
     * Server Response Latency: 14.28 milliseconds

2. PROBABILITY FOUNDATIONS: PMF VS PDF
-----------------------------------------------------------------------------

A. DISCRETE PROBABILITY: PROBABILITY MASS FUNCTION (PMF):
   - Formalism: P(X = x_k) = p_k where 0 <= p_k <= 1 and ∑_{k} p_k = 1.0.
   - Direct Probabilities: Evaluates exact point probabilities.
     (e.g., The probability a patient has exactly 2 previous visits is P(X = 2) = 0.24).
   - Cumulative Distribution Function (CDF): F(x) = P(X <= x) = ∑_{x_k <= x} P(X = x_k).
     Forms a piece-wise constant staircase step function with jump discontinuities at each discrete point.

B. CONTINUOUS PROBABILITY: PROBABILITY DENSITY FUNCTION (PDF):
   - Formalism: f(x) >= 0 where ∫_{-∞}^{∞} f(x) dx = 1.0.
   - THE ZERO-PROBABILITY PARADOX:
     In a continuous distribution, the probability of obtaining an exact single real number
     is mathematically zero:
       P(X = x_0) = ∫_{x_0}^{x_0} f(x) dx = 0
     (e.g., The probability that a patient weighs exactly 68.000000000... kg is zero!).
   - Continuous probability is defined ONLY over an interval [a, b]:
       P(a <= X <= b) = ∫_a^b f(x) dx  (Area under the continuous curve)
   - Cumulative Distribution Function (CDF): F(x) = ∫_{-∞}^x f(t) dt.
     Forms a smooth, continuous, strictly non-decreasing S-curve.

3. COMMON STATISTICAL DISTRIBUTIONS
-----------------------------------------------------------------------------

DISCRETE DISTRIBUTIONS:
  1. Bernoulli: Binary trial {0, 1} with parameter p.
  2. Binomial: Number of successes k in n independent trials: P(X=k) = C(n,k) p^k (1-p)^{n-k}.
  3. Poisson: Number of rare discrete events occurring in a fixed interval:
       P(X = k) = (λ^k * e^-λ) / k!  (Property: E[X] = Var(X) = λ).
  4. Negative Binomial: Number of failures before r successes; relaxes Poisson equidispersion.
  5. Geometric: Number of Bernoulli trials required to achieve the first single success.

CONTINUOUS DISTRIBUTIONS:
  1. Gaussian Normal: Symmetrical bell curve N(μ, σ²):
       f(x) = [1 / (σ √(2π))] * exp(-0.5 ((x - μ) / σ)²).
  2. Continuous Uniform: Flat density across interval [a, b]: f(x) = 1 / (b - a).
  3. Exponential: Continuous waiting time between Poisson events: f(t) = λ e^{-λ t}.
  4. Log-Normal: Continuous variable whose natural logarithm is normally distributed (e.g. income).

4. MODELING HAZARDS: PREDICTING DISCRETE COUNTS
-----------------------------------------------------------------------------

Why Ordinary Least Squares (OLS) Fails on Count Targets:
  1. Prediction of Negative Counts:
     Linear regression y = w^T x + b assumes unbounded real output y in R. For low-risk
     or healthy observations, OLS frequently predicts negative numbers (e.g. -1.4 visits),
     which is physical nonsense.
  2. Heteroscedasticity (Non-Constant Variance):
     OLS assumes homoscedasticity (constant residual variance σ²). In count data, variance
     naturally expands as the mean count increases (Poisson property: Var(Y) = E[Y]).
  3. Non-Gaussian Errors:
     Residuals of small discrete counts are skewed, discrete, and zero-inflated, violating
     Gaussian normality.

The Solution: Generalized Linear Models (GLMs):
  * Poisson Regression:
    Uses the logarithmic link function:
      ln(λ) = w^T x + b  ⟹  λ = exp(w^T x + b)
    Because the exponential function exp(z) is strictly positive for all real inputs z,
    predicted counts are guaranteed to be non-negative (λ > 0).
  * Negative Binomial Regression:
    Used when Overdispersion is present (empirical Var(Y) >> E[Y]). Adds a dispersion
    parameter α to model unobserved population clustering.

5. CONTINUOUS DISCRETIZATION & BINNING TECHNIQUES
-----------------------------------------------------------------------------
Discretization transforms continuous real numbers into discrete ordinal intervals or bins:

A. EQUAL-WIDTH BINNING:
   - Divides the range [min, max] into K intervals of identical width:
       Width = (max - min) / K
   - Hazard: If data is heavily skewed (e.g. wealth, salaries), most observations crowd
     into the lowest bin, leaving high-value bins completely empty.

B. EQUAL-FREQUENCY (QUANTILE) BINNING:
   - Uses empirical percentiles so that each bin contains exactly N / K observations.
   - Mitigates skewness and produces balanced categorical groups regardless of outliers.

C. THE DISCRETIZATION TRADE-OFF:
   * Benefits: Eliminates outlier leverage; linear models can learn step-wise non-linear trends.
   * Drawbacks: Destroys fine-grained numerical variance; creates artificial boundary cliffs
     (e.g., treating age 59 and 18 identically in an '<60' bin, while separating 59 and 60).

6. REAL-WORLD REGIONAL INDUSTRIAL CASE STUDIES
-----------------------------------------------------------------------------
Case 1: Kolkata Metro Railway Turnstile Flow Analytics (Dum Dum Station)
  * Discrete Variable: Turnstile passenger swipes per minute (Poisson arrival process).
  * Continuous Variable: Train transit duration between Dum Dum and Esplanade (minutes with decimals).
  * Architecture: Station queue models use Poisson regression for turnstile congestion,
    while physical transit dispatch uses continuous physics acceleration equations.

Case 2: Healthcare Emergency Triage at Barrackpore Medicare
  * Discrete Feature: Number of chronic prescription medications (0, 1, 2, 3...).
  * Continuous Feature: Serum creatinine level (mg/dL) and core body temperature (°C).
  * Engineering Audit: Replaced an intern's linear model that predicted negative hospital visits
    with a Poisson GLM, eliminating flawed clinical forecasts.

Case 3: WBSEDCL Electricity Grid Sub-station Monitoring
  * Discrete Feature: Number of transformer tripping events per month.
  * Continuous Feature: Aggregate power load (Megawatts, MW).
  * Implementation: Equal-frequency quantile binning used to establish 4 tariff demand tiers
    (Base, Normal, Peak, Critical Overload).

7. COMMON ENGINEERING PITFALLS & PRACTICAL CHECKLIST
-----------------------------------------------------------------------------
[!] Pitfall 1: Fitting OLS linear regression on small integer counts.
    Always inspect target distribution; if y in Z_{>=0}, use Poisson or Negative Binomial GLMs.

[!] Pitfall 2: Computing empirical Mode on continuous float data without binning.
    Continuous floats measured with 6 decimal places rarely repeat; bin data or use KDE peak.

[!] Pitfall 3: Indiscriminate discretization of continuous variables.
    Do not bin continuous features unless domain rules dictate explicit step-thresholds.

[!] Pitfall 4: Imputing discrete count missing values with Mean.
    Mean imputation produces fractional counts (e.g. 1.8 children); use Median or Mode.
