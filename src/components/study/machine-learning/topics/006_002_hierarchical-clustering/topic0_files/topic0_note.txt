1. OVERVIEW & CONCEPT DEFINITION
-------------------------------------------------------------------------------
Understand the foundational principles of hierarchical clustering. Learn how nested partitioning constructs tree structures without pre-specifying cluster count K, contrasting bottom-up and top-down paradigms.

Concept Name: Hierarchical Clustering

2. KEY THEORETICAL PRINCIPLES
-------------------------------------------------------------------------------
- Hierarchical structure represented via binary tree (Dendrogram).
- Does not require pre-specifying cluster count K prior to training.
- Monotonicity: Height values increase monotonically up the tree without inversions.
- Distance Metrics: Supports Euclidean, Manhattan, Cosine, and Mahalanobis distances.
- Linkage Rules: Single (Min), Complete (Max), Average (UPGMA), and Ward's Minimum Variance.

3. ALGORITHMIC LIFECYCLE
-------------------------------------------------------------------------------
Step 1: Construct initial N x N pairwise dissimilarity matrix D.
Step 2: Find smallest inter-cluster distance entry min D(C_A, C_B).
Step 3: Merge clusters C_A and C_B into a new combined cluster C_AB.
Step 4: Update distance matrix using Lance-Williams recurrence relation.
Step 5: Repeat until a single root cluster containing all N objects remains.
