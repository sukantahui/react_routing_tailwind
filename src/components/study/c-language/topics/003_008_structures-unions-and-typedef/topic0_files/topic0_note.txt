1. CORE CONCEPTS
--------------------------------------------------------------------------------
- Struct: Groups heterogeneous data members.
- Pointer Access: sptr->member is equivalent to (*sptr).member.
- Structure Padding: Compiler inserts padding bytes for word alignment.
- Union: Shared memory overlay for all members (size = max member size).
