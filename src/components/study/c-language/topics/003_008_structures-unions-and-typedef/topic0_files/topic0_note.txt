1. CONCEPT SUMMARY
-------------------------------------------------------------------------------
Understand user-defined heterogeneous data types in C. Learn structure declaration syntax, Designated Initializers, memory layouts, and dot (.) member access operator mechanics.

2. KEY ARCHITECTURAL PRINCIPLES
-------------------------------------------------------------------------------
A C Structure (struct) groups variables of different data types (int, char array, float) into a contiguous block of memory.

3. CLASSROOM SCENARIO (BARRACKPORE LAB)
-------------------------------------------------------------------------------
When Swadeep asked how to represent a complex student record with roll number, name, and marks without creating 3 separate arrays, Sukanta Hui introduced C structures as a single unified memory package.
