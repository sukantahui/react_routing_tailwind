1. CORE CONCEPTS
--------------------------------------------------------------------------------
- Null Terminator: '\0' (ASCII 0) marks end of char array.
- Functions: strlen, strcpy, strcat, strcmp, strstr, fgets.
- Never use gets(); use fgets(buffer, sizeof(buffer), stdin) instead.
