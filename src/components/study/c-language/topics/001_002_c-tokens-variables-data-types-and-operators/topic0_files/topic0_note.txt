1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- C Data Types:
  * char: 1 byte (-128 to 127 or 0 to 255)
  * int: usually 4 bytes (-2,147,483,648 to 2,147,483,647)
  * float: 4 bytes (IEEE 754 single precision)
  * double: 8 bytes (IEEE 754 double precision)

- Bitwise Operators:
  &  (Bitwise AND)
  |  (Bitwise OR)
  ^  (Bitwise XOR)
  ~  (Bitwise NOT / One's Complement)
  << (Shift Left - Multiply by 2^N)
  >> (Shift Right - Divide by 2^N)

2. ESSENTIAL CHECKLIST
--------------------------------------------------------------------------------
[✓] Use (float) casting before dividing integer expressions to prevent truncated integer division.
[✓] Use sizeof operator instead of hardcoding byte sizes.
