1. CORE CONCEPTS
--------------------------------------------------------------------------------
- Address-of (&): Obtains memory address of a variable.
- Dereference (*): Accesses value stored at memory address.
- Pointer Arithmetic: Scaled by sizeof(type).
- Void Pointer (void*): Generic pointer holding any memory address.
