1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- C is a compiled, procedural systems language created by Dennis Ritchie in 1972.
- GCC Compilation Pipeline Phases:
  1. Preprocessing (gcc -E): Expands #include, #define macros, strips comments. (.c -> .i)
  2. Compilation   (gcc -S): Translates preprocessed C into assembly language. (.i -> .s)
  3. Assembly      (gcc -c): Assembles assembly code into machine object code. (.s -> .o)
  4. Linking       (gcc -o): Links object code with standard libraries to build executable. (.o -> binary)

- Program Entry Point:
  int main(void) {
      printf("Hello World!\n");
      return 0; // 0 = EXIT_SUCCESS
  }
