1. FORMAT SPECIFIERS
--------------------------------------------------------------------------------
- %d : Signed decimal integer
- %f : Floating-point number (%.2f for 2 decimal places)
- %c : Character (%c with leading space skips whitespace)
- %s : String (character array pointer)
- %p : Hexadecimal pointer RAM address
