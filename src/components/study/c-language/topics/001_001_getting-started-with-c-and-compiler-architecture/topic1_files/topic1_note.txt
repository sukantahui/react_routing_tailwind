1. CORE CONCEPTS & CHRONOLOGY
--------------------------------------------------------------------------------
- 1972: Birth of C at Bell Labs by Dennis Ritchie for Unix OS on PDP-11.
- 1978: K&R C - Informal reference book standard by Kernighan & Ritchie.
- 1989/1990: ANSI C89 / ISO C90 - First formal standard (prototypes, void*).
- 1999: ISO C99 - // comments, for(int i=0;..), <stdint.h>, <stdbool.h>, inline.
- 2011: ISO C11 - Multi-threading (<threads.h>), _Static_assert, static safety.
- 2017: ISO C17 - Maintenance defect fix release.
- 2023: ISO C23 - Binary literals (0b), typeof, constexpr, auto type inference.

2. COMPILER FLAG SELECTION
--------------------------------------------------------------------------------
- Strict C99 Standard  : gcc -std=c99 -Wall -Wextra main.c -o main
- Strict C11 Standard  : gcc -std=c11 -Wall -Wextra main.c -o main
- GNU C11 Extensions   : gcc -std=gnu11 -Wall -Wextra main.c -o main

3. ESSENTIAL CHECKLIST
--------------------------------------------------------------------------------
[✓] Always pass -std=c99 or -std=c11 flag during compilation.
[✓] Prefer <stdint.h> fixed-width types for portable bit precision.
