1. CORE CONCEPTS
--------------------------------------------------------------------------------
- Macros (#define): Function-like and object-like text replacement.
- Stringizing (#): Converts macro parameter to string literal.
- Token Concatenation (##): Merges two tokens into a single identifier.
- Header Guards: #ifndef MYHEADER_H / #define MYHEADER_H / #endif prevents double inclusions.
