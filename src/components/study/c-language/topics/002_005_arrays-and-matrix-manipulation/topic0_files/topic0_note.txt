1. CORE CONCEPTS
--------------------------------------------------------------------------------
- 1D Array: Fixed size, zero-indexed, contiguous RAM block.
- 2D Matrix: Row-major order contiguous memory layout.
- Matrix Transpose: Swap element matrix[i][j] into transpose[j][i].
