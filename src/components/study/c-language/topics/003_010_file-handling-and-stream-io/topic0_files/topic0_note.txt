1. CORE CONCEPTS
--------------------------------------------------------------------------------
- FILE* handle: Opaque stream pointer.
- Modes: "r" (read), "w" (overwrite write), "a" (append), "rb"/"wb" (binary).
- Text I/O: fprintf, fscanf, fgets, fputs.
- Binary I/O: fread, fwrite.
- File positioning: fseek, ftell, rewind.
