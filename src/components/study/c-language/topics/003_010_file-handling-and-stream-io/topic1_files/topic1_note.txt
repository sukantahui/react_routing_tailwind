1. FOPEN() MODES MASTER CHEAT SHEET
--------------------------------------------------------------------------------
Mode | Purpose          | If File Exists?        | If File Missing? | Initial Cursor
-----+------------------+------------------------+------------------+---------------
"r"  | Read text        | Reads from start       | FAILS (NULL)     | Beginning
"w"  | Write text       | TRUNCATES (Erase to 0) | CREATES new      | Beginning
"a"  | Append text      | Appends to end         | CREATES new      | End
"r+" | Read & Write     | Preserves existing data| FAILS (NULL)     | Beginning
"w+" | Read & Write     | TRUNCATES to 0         | CREATES new      | Beginning
"a+" | Read & Append    | Appends to end         | CREATES new      | End
"rb" | Binary Read      | Raw bytes read         | FAILS (NULL)     | Beginning
"wb" | Binary Write     | Raw bytes write        | CREATES new      | Beginning
"ab" | Binary Append    | Raw bytes append       | CREATES new      | End


2. DEFENSIVE FILE OPENING PATTERN
--------------------------------------------------------------------------------
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        perror("Error opening data.txt");
        return 1; // Or handle failure gracefully
    }
    // Perform file operations...
    fclose(fp);
    fp = NULL; // Neutralize pointer!


3. CORE RULES FOR FILE HANDLING HYGIENE
--------------------------------------------------------------------------------
[1] Always check for NULL after calling fopen().
[2] "w" mode immediately destroys all existing contents in the file!
[3] Use "a" mode when you want to log new entries without losing past records.
[4] Always include 'b' (e.g. "rb", "wb") when reading/writing binary or structs.
[5] Always close every opened stream with fclose(fp) before program exit.
