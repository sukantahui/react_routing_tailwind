1. CORE CONCEPTS
--------------------------------------------------------------------------------
- malloc(bytes): Heap block allocation (uninitialized).
- calloc(num, size): Zero-initialized heap allocation.
- realloc(ptr, new_bytes): Resizes existing heap block.
- free(ptr): Deallocates memory and sets ptr = NULL.
