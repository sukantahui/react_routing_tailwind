1. CORE CONCEPTS
--------------------------------------------------------------------------------
- Node Structure: struct Node { int data; struct Node *next; };
- Insertion: Node **headRef double pointer parameter.
- Traversal: Loop curr = curr->next until curr == NULL.
- Deallocation: Free each node pointer iteratively.
