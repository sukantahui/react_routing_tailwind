1. TEACHER'S INTUITIVE BREAKDOWN FOR BEGINNERS:
--------------------------------------------------------------------------------
Q: How do we combine control flow and loops for real software?
A: Real-world programs are built by combining 3 architectural pillars:
   1. State Machine / Menu Navigation -> do-while loop + switch-case
   2. Data Verification & Security Guards -> if-else + boundary checks
   3. Repetitive Mathematical & Pattern Processing -> for and while loops
