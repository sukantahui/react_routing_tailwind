1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a fitness coach telling you to do 10 pushups. You start counting: 1... 2... 3... At every pushup, you check: 'Have I reached 10 yet?' If no, you do another pushup. When you complete the 10th pushup, you stop. That is exactly how a for loop works in programming: you set a starting point, check a boundary condition, and update your counter on every lap!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The 3 Parts of a Classic for Loop:
for (Initialization; Condition; Final Expression) {
  // Code executed on each lap (Iteration)
}
- Part 1 (Initialization): Runs ONCE before the loop starts (e.g. let i = 1).
- Part 2 (Condition): Checked BEFORE every lap. If true, the loop body runs; if false, the loop terminates immediately (e.g. i <= 10).
- Part 3 (Final Expression): Runs AFTER every lap to update the counter (e.g. i++).

2. How the Engine Executes Each Lap:
Lap 1: let i = 1 → is 1 <= 10? (Yes) → Run body → i++ (i becomes 2).
Lap 2: is 2 <= 10? (Yes) → Run body → i++ (i becomes 3).
...
Lap 10: is 10 <= 10? (Yes) → Run body → i++ (i becomes 11).
Lap 11: is 11 <= 10? (No! False) → Loop ends!

3. Counting Backwards:
You can also count down by initializing high and decrementing:
for (let i = 10; i >= 1; i--)

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Multiplication Table Generator ---
let number = 7;
console.log("=== Table of " + number + " ===");

for (let i = 1; i <= 10; i++) {
  console.log(number + " x " + i + " = " + (number * i));
}

Teacher's Note on Example 1:
The loop iterates 10 times, computing 7 x i on each cycle.

--- Example 2: Summing Numbers from 1 to 100 ---
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log("Sum of numbers from 1 to 100 is:", sum); // 5050

Teacher's Note on Example 2:
The accumulator variable 'sum' adds each value of 'i' sequentially.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] The Infinite Loop Trap: If your condition never becomes false (e.g. for (let i = 1; i >= 0; i++)), the loop will run forever and freeze your browser!

[!] Using var for loop counter: Always use let i = 0. Using var creates scope leak issues.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• The classic for loop consists of Initialization, Condition, and Step Update.
• Ideal when you know in advance how many times to repeat.
• Always use 'let' for the loop counter variable.
