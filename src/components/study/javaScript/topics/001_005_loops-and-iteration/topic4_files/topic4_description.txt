1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine looking through a student's personal backpack. You want to list the items that belong specifically to the student (pencil box, notebook, water bottle). But what if the bag also inherited a label stitched by the manufacturer? for...in is a special loop designed to inspect every named property inside an object, but we must use a guard so we don't accidentally inspect inherited manufacturer properties!

--------------------------------------------------------------------------------
Swadeep had a student profile object: { name: 'Swadeep', roll: 101, city: 'Barrackpore' }. He wanted to print all property names and values. He tried using a classic for (let i=0; ...) loop, but objects don't have numeric 0, 1, 2 indices! I introduced him to the for...in loop: for (let key in student) { console.log(key, student[key]); }. 3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is for...in?
A loop designed specifically to iterate over the enumerable property keys of an object.

2. Syntax:
for (let key in object) {
  console.log("Key:", key, "Value:", object[key]);
}

3. Why Avoid for...in for Arrays:
- for...in iterates over arbitrary property names in non-guaranteed order.
- It returns keys as strings ("0", "1"), not numbers.
- Always use for or for...of for Arrays; reserve for...in for Objects!

4. Guarding against Prototype Pollution:
Use Object.hasOwn(obj, key) to verify that the property belongs directly to the object itself rather than its prototype chain.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Iterating an Object with for...in ---
let studentProfile = {
  name: "Swadeep",
  roll: 101,
  course: "JavaScript Pro",
  center: "Barrackpore"
};

for (let key in studentProfile) {
  if (Object.hasOwn(studentProfile, key)) {
    console.log(key + " → " + studentProfile[key]);
  }
}

Teacher's Note on Example 1:
for...in loops through every property key in the studentProfile object.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using for...in on arrays: for...in is slow on arrays and may return keys out of order. Use for...of for arrays.

[!] Accessing properties with dot notation inside for...in: Writing obj.key searches for a literal property named 'key'. Always use bracket notation obj[key]!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• for...in iterates over object property keys.
• Always use bracket notation obj[key] to read dynamic property values.
• Use Object.hasOwn(obj, key) to guard against inherited prototype properties.
