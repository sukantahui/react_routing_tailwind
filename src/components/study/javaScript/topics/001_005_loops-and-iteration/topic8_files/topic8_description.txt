3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The 4 Loop Types Compared:
- Classic for: Best when you need index math, reverse counting (`i--`), or custom stepping (`i += 2`). Supports `break` and `continue`.
- for...of: Best for iterating over values of Arrays, Strings, Sets, and Maps. Modern, clean, and supports `break`.
- for...in: Iterates over property keys of Objects. (Avoid for Arrays!).
- arr.forEach(): Functional callback iteration. Cannot be stopped with `break`.

2. Performance & Readability:
Use `for...of` by default for array values; use classic `for` when manual index control is needed; use `for...in` for object keys.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Comparing All 4 Iteration Methods ---
const students = ['Swadeep', 'Tuhina', 'Abhronila'];

// 1. for...of (Cleanest for array values):
for (let student of students) {
  console.log('Student (for...of):', student);
}

// 2. Classic for (When index control is needed):
for (let i = 0; i < students.length; i += 2) {
  console.log('Every Alternate Student:', students[i]);
}

Teacher's Note on Example 1:
Choose the iteration style tailored to your specific traversal requirements.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using for...in for arrays: for...in returns string keys ('0', '1') and can iterate prototype properties out of order.

[!] Attempting break inside forEach: 'break' inside forEach throws a SyntaxError.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Use `for...of` for array and iterable values.
• Use `for...in` for object property keys.
• Use classic `for` when custom index stepping or reverse iteration is required.
