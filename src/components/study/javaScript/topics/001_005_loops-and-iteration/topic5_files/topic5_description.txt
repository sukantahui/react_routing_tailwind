3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is for...of?
Introduced in ES6, for...of iterates directly over the VALUES of any Iterable data structure (Arrays, Strings, Sets, Maps, NodeLists).

2. for...in vs for...of (The Golden Distinction):
- for...in → Iterates over KEYS / PROPERTY NAMES (for Objects).
- for...of → Iterates over VALUES directly (for Arrays and Iterables).

3. Iterating Strings:
You can use for...of to loop over every individual character in a string:
for (let char of "JS") { console.log(char); }

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Iterating Arrays and Strings with for...of ---
let students = ["Swadeep", "Tuhina", "Abhronila", "Debangshu"];

console.log("=== Student Attendance ===");
for (let student of students) {
  console.log("Present:", student);
}

console.log("=== Spelling Out Barrackpore ===");
for (let letter of "BKP") {
  console.log("Letter:", letter);
}

Teacher's Note on Example 1:
for...of retrieves values directly without needing an index counter.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using for...of on plain Objects: Plain objects are not iterable by default. Writing for (let x of { a: 1 }) throws a TypeError: object is not iterable.

[!] Confusing for...in with for...of: Remember: 'in' gives index/keys; 'of' gives the actual objects/values.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• for...of iterates directly over values in Arrays, Strings, Sets, and Maps.
• Clean, modern, and eliminates manual index management.
• Use for...in for object keys; use for...of for array values.
