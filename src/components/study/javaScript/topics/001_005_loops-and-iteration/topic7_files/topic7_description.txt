3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Algorithmic Loop Toolkit:
Every complex algorithm is built from simple foundational loop patterns:
- Accumulator Pattern: Summing or multiplying values across iterations (sum += i).
- Filtering Pattern: Checking a condition and collecting matching items.
- Search & Sentinel Pattern: Scanning until a match is found and breaking early.
- Min / Max Extrema Pattern: Tracking the highest or lowest value seen so far.
- Nested Loop Pattern: Processing 2D grids, tables, or coordinate systems.

--- Example 1: Cash Denomination Dispenser (Bank ATM Algorithm) ---
function dispenseCash(amount) {
  console.log("=== Dispensing Cash for ₹" + amount + " ===");
  
  // Available notes in descending order:
  let notes = [500, 200, 100, 50, 20, 10];
  
  for (let note of notes) {
    if (amount >= note) {
      let count = Math.floor(amount / note);
      amount %= note; // Remaining amount
      console.log("₹" + note + " Notes : " + count);
    }
  }
  
  if (amount > 0) {
    console.log("Remaining un-dispensed change: ₹" + amount);
  }
}

dispenseCash(3870);

Teacher's Note on Example 1:
Uses a for...of loop and modulo arithmetic to dispense optimal currency notes.

--- Example 2: Student Marks Statistics (Min, Max, Average) ---
let marksList = [78, 92, 45, 88, 64, 99, 53];

let total = 0;
let highest = marksList[0];
let lowest = marksList[0];

for (let mark of marksList) {
  total += mark;
  if (mark > highest) highest = mark;
  if (mark < lowest) lowest = mark;
}

let average = total / marksList.length;

console.log("Class Highest:", highest);
console.log("Class Lowest:", lowest);
console.log("Class Average:", average.toFixed(1));

Teacher's Note on Example 2:
Single-pass loop tracking min, max, and sum accumulators simultaneously.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
