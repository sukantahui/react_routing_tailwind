1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about a Formula 1 racing car. If you add 50 kg of unnecessary luggage into the cockpit, every lap around the track will be fractions of a second slower. In computing, when a loop runs 10,000,000 times inside a game engine or high-traffic server, small inefficiencies like recalculating values inside the loop condition can slow down your entire application.

--------------------------------------------------------------------------------
Abhronila was running a search loop across a dataset of 100,000 items. Inside her loop condition, she was performing an expensive calculation on every single lap. 3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Key Loop Optimization Techniques:
- Hoist Invariants: Never calculate static values inside the loop condition. Calculate them once before the loop begins.
- Cache Length: In older engines, caching array length (let len = arr.length) prevented property lookups.
- Avoid Memory Allocation Inside Tight Loops: Declare reusable variables outside the loop body rather than creating new variables millions of times.
- Early Break: Exit the loop the moment your target item or solution is found.

2. Infinite Loop Prevention (Safety Guards):
Always implement a maximum iteration safety counter when running dynamic while loops:
let safetyCounter = 0;
while (condition) {
  if (++safetyCounter > 10000) {
    console.error("Infinite loop detected! Aborting.");
    break;
  }
}

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Optimized Loop with Safety Guard ---
let maxLimit = 1000;
let counter = 0;
let safetyGuard = 0;

console.time("LoopBenchmark");
while (counter < maxLimit) {
  counter += 5;
  
  // Safety Guard against infinite loops:
  if (++safetyGuard > 5000) {
    console.error("Safety guard triggered!");
    break;
  }
}
console.timeEnd("LoopBenchmark");
console.log("Final Counter:", counter);

Teacher's Note on Example 1:
The safety guard ensures that unexpected conditions never lock up the CPU indefinitely.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Premature optimization: Write clear, readable loops first; only optimize hot loops that process massive data.

[!] Infinite while loops without safety breaks: Always double-check your loop termination criteria.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Hoist static calculations outside the loop header.
• Use early break to stop searching once the result is found.
• Use safety counters to guard against infinite while loops.
