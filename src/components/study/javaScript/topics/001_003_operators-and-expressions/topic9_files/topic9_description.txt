3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The in Operator:
Tests whether a specified property key exists in an object or its prototype chain: `'name' in obj` → true.

2. The delete Operator:
Removes a property from an object: `delete obj.prop`.

3. The typeof Operator:
Returns a string indicating the data type of the unevaluated operand.

4. The instanceof Operator:
Tests whether an object has a constructor's prototype in its chain.

5. The void Operator:
Evaluates an expression and returns `undefined`: `void 0`.

6. The Comma Operator (,):
Evaluates multiple expressions from left to right and returns the value of the LAST expression.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Using in, delete, and void ---
const student = { name: 'Swadeep', roll: 101 };

// 1. in operator
console.log('Is name present?', 'name' in student); // true

// 2. delete operator
delete student.roll;
console.log('Is roll present after delete?', 'roll' in student); // false

// 3. void operator
console.log('void 0 result:', void 0); // undefined

Teacher's Note on Example 1:
Demonstrates relational existence checks, property deletion, and void expressions.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using in with array values: `5 in ['a', 'b']` checks if index 5 exists, NOT if the value 5 is in the array!

[!] Overusing comma operator: Chaining expressions with commas makes code difficult to read.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• `in` checks property key existence in objects.
• `delete` excises properties from objects.
• `void` evaluates expressions and returns undefined.
