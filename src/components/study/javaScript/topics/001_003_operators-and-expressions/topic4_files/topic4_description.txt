--------------------------------------------------------------------------------
Think about an express toll booth on a highway. If you have an electronic Fastag, you take the green lane; otherwise, you take the cash lane. You don't need a 10-page manual for such a quick choice. The Ternary Operator is a compact, one-line decision tool for quick binary choices.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Syntax of the Ternary Operator:
condition ? expressionIfTrue : expressionIfFalse

2. When to Use:
- Setting a variable based on a single condition.
- Inline text display (e.g. in string templates).

3. Anti-Pattern (What to AVOID):
- Deeply nested ternaries: a ? b : c ? d : e ? f : g (Never do this!).
- Performing side effects or long multi-line logic inside a ternary.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Simple Clean Ternary Assignment ---
let temperature = 32;
let weather = temperature > 30 ? "Hot" : "Pleasant";
console.log("Today is:", weather); // "Hot"

Teacher's Note on Example 1:
The condition temperature > 30 is true, so 'Hot' is returned.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Nesting multiple ternaries: Nested ternaries ruin code readability. Use if/else or switch instead.

[!] Using ternary as a statement replacement: Don't write condition ? doSomething() : doOther(). Use an if statement.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Ternary operator is a concise expression: condition ? trueVal : falseVal.
• Ideal for simple variable assignments and template strings.
• Avoid nesting ternaries to preserve code readability.
