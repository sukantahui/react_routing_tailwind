--------------------------------------------------------------------------------

Bitwise operators let you manipulate individual binary bits directly at the CPU level.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. How Bitwise Operators Work:
JavaScript converts numbers to 32-bit signed integers, performs the bit-level operation, and returns a standard number.

2. Core Bitwise Operators:
- Bitwise AND (&): 1 if both bits are 1.
- Bitwise OR (|): 1 if either bit is 1.
- Bitwise XOR (^): 1 if bits are different.
- Bitwise NOT (~): Inverts all bits.
- Left Shift (<<): Shifts bits left (multiplies by powers of 2).
- Sign-Propagating Right Shift (>>): Shifts bits right (divides by 2).
- Zero-Fill Right Shift (>>>): Shifts right filling with zeros.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Permission Flag System with Bitwise Operators ---
const READ = 1;    // 0001
const WRITE = 2;   // 0010
const EXECUTE = 4; // 0100

// Assign Read + Write permission:
let userPermission = READ | WRITE; // 3 (0011)

// Check if user has WRITE permission:
let canWrite = (userPermission & WRITE) !== 0;
console.log("Can write?", canWrite); // true

// Check if user has EXECUTE permission:
let canExec = (userPermission & EXECUTE) !== 0;
console.log("Can execute?", canExec); // false

Teacher's Note on Example 1:
Bitwise masks allow storing and checking multiple boolean flags in a single compact integer.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using bitwise operators on BigInt or floats: Bitwise operators truncate decimal parts, converting numbers to 32-bit integers.

[!] Confusing & with &&: & is bitwise AND; && is logical short-circuit AND.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Bitwise operators operate directly on 32-bit binary representations.
• Used for high-speed permission masks, graphics, and performance optimization.
• Bitwise left shift (<< 1) quickly doubles an integer; right shift (>> 1) halves it.
