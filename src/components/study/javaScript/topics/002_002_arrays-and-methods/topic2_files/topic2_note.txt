3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Maximum Call Stack / Argument Limit with Spread: `arr.push(...largeArray)` throws `RangeError: Maximum call stack size exceeded` if `largeArray` has > 65,536 elements.
[!] Accidental Mutation of State: Calling `push` or `pop` directly on component state breaks immutability.
[!] Sparse Hole Re-Indexing: `shift()` shifts empty holes, preserving holey de-optimizations.

Example 5: Senior Pro Pattern
function batchPush(target, source, chunkSize = 10000) {
  for (let i = 0; i < source.length; i += chunkSize) {
    target.push(...source.slice(i, i + chunkSize));
  }
  return target.length;
}
const bigArr = [];
batchPush(bigArr, Array.from({ length: 150000 }, (_, i) => i));
console.log("Big Array Length:", bigArr.length); // 150000
