1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think of a loaf of sandwich bread. 'slice()' is like taking your kitchen knife to cut 3 slices for breakfast—the original loaf remains safe in your breadbox, and you get a separate copy on your plate (Immutable). 'splice()' is like a surgeon operating directly on the patient—cutting out old tissue, stitching new tissue directly into the wound, permanently altering the patient (Mutating)!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Tuhina wanted to extract the top 2 ranked students from a leaderboard array without modifying the original contest list. She used splice(0, 2) instead of slice(0, 2), and was shocked when her original leaderboard lost its top 2 students! I showed her the Golden Rule on the whiteboard: 'slice() makes a fresh copy (Safe); splice() mutates the original array in place (Destructive)'.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. arr.slice(start, end) — Safe / Immutable:
- Extracts a shallow copy of a portion of an array from start up to (but not including) end.
- Negative indices count backwards from the end (e.g. arr.slice(-2) gets last 2 items).
- Leaves the original array completely untouched.

2. arr.splice(start, deleteCount, item1, item2, ...) — Mutating / In-Place:
- Modifies the original array by removing deleteCount elements starting at start, and optionally inserting replacement items.
- Returns an array of the deleted elements.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Comparing slice vs splice ---
let original = ['A', 'B', 'C', 'D', 'E'];

// 1. slice: Non-mutating copy
let sliced = original.slice(1, 4);
console.log('Sliced copy:', sliced);   // ['B', 'C', 'D']
console.log('Original intact:', original); // ['A', 'B', 'C', 'D', 'E']

// 2. splice: In-place surgery (Remove 'C', insert 'X', 'Y')
let deleted = original.splice(2, 1, 'X', 'Y');
console.log('Deleted items:', deleted);    // ['C']
console.log('Original mutated:', original); // ['A', 'B', 'X', 'Y', 'D', 'E']

Teacher's Note on Example 1:
slice preserves original data; splice modifies the array in place.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Confusing slice and splice: Slice = Sub-copy; Splice = Surgery (mutation).

[!] Forgetting splice second argument is deleteCount, NOT end index: splice(1, 3) removes 3 elements starting at index 1.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• arr.slice(start, end) returns a shallow copy without mutation.
• arr.splice(start, count, ...items) modifies the original array directly.
• Prefer slice() for immutability and functional programming.
