1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think of regular JavaScript arrays as flexible grocery bags where you can toss in a banana, a water bottle, a book, and a shoe all mixed together. But inside a high-speed graphics card or audio processing chip, memory must be a rigid steel egg carton where every single slot holds an exact 8-bit or 32-bit binary number with zero overhead. That is ArrayBuffers and TypedArrays!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Tuhina asked: 'Sir, how do browser games render 60 frames per second of 3D graphics or process live microphone audio without lagging?' I showed her `ArrayBuffer` and `Uint8Array`. I explained that regular JavaScript arrays are flexible objects, whereas TypedArrays represent raw contiguous binary memory buffers used by WebGL, Web Audio, and WebSockets for extreme performance.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. ArrayBuffer:
A fixed-length raw binary data buffer in memory (cannot be read or written directly without a view).

2. TypedArray Views:
Provide typed access to the buffer:
- Int8Array / Uint8Array (8-bit signed/unsigned integers)
- Int16Array / Uint16Array (16-bit integers)
- Int32Array / Uint32Array (32-bit integers)
- Float32Array / Float64Array (32-bit / 64-bit floating point numbers)

3. DataView:
A low-level view that allows reading and writing heterogeneous binary numbers with explicit Endianness (Little-Endian / Big-Endian) control.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Creating and Inspecting a TypedArray ---
// Allocate 8 bytes of raw binary memory
const buffer = new ArrayBuffer(8);

// Create an 8-bit unsigned integer view (holds 8 numbers from 0 to 255)
const byteView = new Uint8Array(buffer);
byteView[0] = 42;
byteView[1] = 255;

console.log('Byte 0:', byteView[0]); // 42
console.log('Byte 1:', byteView[1]); // 255
console.log('Buffer byte length:', buffer.byteLength); // 8

Teacher's Note on Example 1:
TypedArrays operate directly over raw binary ArrayBuffers in fixed memory.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Overflow wrapping in Uint8Array: Storing 256 in a Uint8Array wraps around to 0 without throwing an error.

[!] TypedArrays are fixed length: You cannot push() or pop() on a TypedArray.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• ArrayBuffers allocate raw binary memory chunks.
• TypedArrays (Uint8Array, Float32Array) view and manipulate binary data efficiently.
• Used extensively in WebGL graphics, audio streams, and binary file parsing.
