3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] TypeError: Cannot read properties of undefined (reading 'col'): Accessing `matrix[r][c]` when row `r` is out of bounds.
[!] Shared Reference Mutation Trap: Using `fill()` with nested arrays creates shared reference pointers across all rows.
[!] Jagged Array Inconsistencies: JavaScript arrays of arrays can have uneven row lengths unless strictly enforced.
