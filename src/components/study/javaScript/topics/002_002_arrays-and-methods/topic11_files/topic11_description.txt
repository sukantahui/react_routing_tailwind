3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Array.from(arrayLike, mapFn):
Creates a new, shallow-copied Array instance from an iterable or array-like object (e.g. Strings, Sets, Maps, NodeLists, arguments).
- Optional mapping function: `Array.from({ length: 5 }, (_, i) => i + 1)` creates `[1, 2, 3, 4, 5]`!

2. Array.of(...elements):
Creates a new Array instance from arguments.
- Fixes the classic `Array(5)` constructor trap (which creates 5 empty holes instead of `[5]`). `Array.of(5)` reliably creates `[5]`.

3. Array.isArray(value):
The only 100% reliable way in JavaScript to check if a variable is an array (since `typeof []` returns `'object'`).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Generating Ranges and Type Checking ---
// 1. Generate range 1 to 5 with Array.from:
const range = Array.from({ length: 5 }, (_, idx) => idx + 1);
console.log('Generated Range:', range); // [1, 2, 3, 4, 5]

// 2. Safe Array Type Checking:
console.log('Is range an array?', Array.isArray(range)); // true
console.log('Is null an array?', Array.isArray(null));   // false

// 3. Array.of vs Array constructor:
console.log(Array.of(3)); // [3]
console.log(Array(3));    // [ <3 empty items> ]

Teacher's Note on Example 1:
Array.from generates sequences; Array.isArray reliably verifies arrays.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using typeof to check for arrays: typeof [] returns 'object'. Always use Array.isArray(x).

[!] Using new Array(5): new Array(5) creates empty slots rather than a single number 5. Use Array.of(5).

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Array.from() converts iterables and array-likes into true arrays with optional mapping.
• Array.of() creates arrays from arguments avoiding single-number constructor traps.
• Array.isArray() is the standard reliable test for arrays.
