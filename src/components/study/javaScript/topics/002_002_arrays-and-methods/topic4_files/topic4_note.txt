3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Null & Undefined in join(): `join()` coerces `null` and `undefined` to empty strings `""` rather than `"null"`.
[!] Symbol.isConcatSpreadable Override: Setting `obj[Symbol.isConcatSpreadable] = true` forces `concat()` to flatten custom objects as if they were arrays.
[!] Spread on Non-Iterables: Attempting to spread a non-iterable primitive (`...null` in array literal) throws TypeError.

Q1: What is the primary role of Non-Mutating Array Combinations — concat(), join(), Spread Operator?
A1: Combine, concatenate, and serialize arrays without mutation: concat vs spread operator performance, string joining, and custom delimiters.

Q2: How does V8 optimize array memory for this operation?

Q3: What common bug occurs with junior developers?
A3: Spreading Massive Arrays in Tight Loops: Repeatedly spreading arrays `arr = [...arr, item]` creates O(N^2) garbage collection churn.

Q4: What is the Senior Pro recommended pattern?
A4: Use push() during construction, freeze or return copy at end: Build efficiently, then freeze for immutability.
