3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is map()?
A Higher-Order Function that creates a BRAND NEW array populated with the results of calling a provided callback function on every single element in the original array.

2. Key Invariants:
- Strict 1-to-1 Relationship: If the input array has 5 items, map() ALWAYS returns an array of exactly 5 items.
- Non-Mutating: Leaves the original array 100% unchanged.

3. Callback Parameters: (element, index, array) => { ... }

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Transforming Prices with 18% GST ---
const basePrices = [1000, 2500, 4000];

const pricesWithGst = basePrices.map(price => price * 1.18);

console.log('Original prices:', basePrices); // [1000, 2500, 4000]
console.log('Prices with GST:', pricesWithGst); // [1180, 2950, 4720]

Teacher's Note on Example 1:
map transforms every number in basePrices into its GST-inclusive value.

--- Example 2: Formatting Student Names ---
const names = ['swadeep', 'tuhina', 'abhronila'];
const capitalized = names.map(n => n.charAt(0).toUpperCase() + n.slice(1));
console.log(capitalized); // ['Swadeep', 'Tuhina', 'Abhronila']

Teacher's Note on Example 2:
map seamlessly cleans and capitalizes string entries.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using map when you don't return anything: If you just want to run side effects (like console.log), use forEach. map() expects a returned value.

[!] The parseInt trap: ['1', '2', '3'].map(parseInt) produces [1, NaN, NaN] because map passes (item, index) and parseInt accepts (string, radix)!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• map() transforms an array into a new array of the exact same length.
• Always returns a new array; never mutates the original.
• Use map when each input element corresponds to an output element.
