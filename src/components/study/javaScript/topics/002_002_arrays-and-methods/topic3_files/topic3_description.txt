1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine searching for a book in the Barrackpore Public Library. If you ask 'Do we have a book titled JavaScript?' and just want a Yes/No answer, you use `includes()`. If you want to know which shelf number it sits on, you use `indexOf()`. But if you want to find the first book with more than 500 pages and a 5-star review, you use `find()` with a search condition!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Abhronila had an array of student marks: [35, 42, 88, 92, 45]. She wanted to find the first student who scored distinction marks (>= 80). She tried using `indexOf(80)` which returned -1 because no one scored exactly 80. I introduced her to `find()`: `marks.find(m => m >= 80)`. It immediately returned 88! 3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Primitive Value Search (Strict Equality ===):
- arr.includes(val): Returns true if value exists, false otherwise (correctly handles NaN!).
- arr.indexOf(val): Returns first index of val, or -1 if not found.
- arr.lastIndexOf(val): Returns last index of val searching backwards.

2. Predicate Search (Functions with Conditions):
- arr.find(predicateFn): Returns the FIRST element matching the condition, or undefined.
- arr.findIndex(predicateFn): Returns the index of the first match, or -1.
- arr.findLast(predicateFn) [ES2023]: Searches backwards and returns the last match.
- arr.findLastIndex(predicateFn) [ES2023]: Returns the index of the last match searching backwards.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Primitive Search vs Predicate Search ---
let cities = ['Barrackpore', 'Kolkata', 'Shyamnagar', 'Kolkata'];

console.log('Includes Kolkata?', cities.includes('Kolkata')); // true
console.log('First Kolkata index:', cities.indexOf('Kolkata')); // 1
console.log('Last Kolkata index:', cities.lastIndexOf('Kolkata')); // 3

let scores = [45, 62, 85, 94, 73];
let firstDistinction = scores.find(score => score >= 80);
let distinctionIndex = scores.findIndex(score => score >= 80);

console.log('First distinction score:', firstDistinction); // 85
console.log('At index:', distinctionIndex); // 2

Teacher's Note on Example 1:
includes/indexOf match exact values; find/findIndex match boolean predicate conditions.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] indexOf cannot find NaN: [NaN].indexOf(NaN) is -1. Use [NaN].includes(NaN) which correctly returns true.

[!] find returns undefined on no match: Always check if the result is undefined before reading properties.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• includes() returns boolean; indexOf() returns index number or -1.
• find() and findIndex() search using custom predicate functions.
• findLast() and findLastIndex() search backwards from the end.
