3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Object Reference Duplication in fill(): `new Array(3).fill({})` fills with the EXACT SAME object reference across all slots; mutating one mutates all.
[!] Negative Index Wrapping: Negative indices wrap relative to `length` (`arr.slice(-2)` grabs last 2 items).
[!] splice() Return Trap: `splice()` returns the DELETED items, not the modified array.
