1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: Deconstruct JavaScript array sorting: in-place mutation, the default lexicographical (Unicode) sort trap, custom comparator math, V8 TimSort mechanics, and stable sorting guarantees.
- Classroom Experience: Swadeep sorted `[10, 5, 40, 25, 100]` with `arr.sort()` and got `[10, 100, 25, 40, 5]`.
- Solution: Sukanta Hui explained that without a comparator, `sort()` converts elements to strings and compares UTF-16 code units; numerical sorting requires `(a, b) => a - b`.
- Core Invariant: Mastering array methods ensures high-performance, immutable data processing.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Numeric Subtraction Overflow Trap: `a - b` can overflow/underflow with extreme numbers (Infinity or -Infinity) or produce NaN with undefined.
[!] String Locale Traps: Accented characters and regional alphabets require `localeCompare()`.
[!] In-Place Mutation: `arr.sort()` mutates the original array; use `toSorted()` or `[...arr].sort()` for immutability.
