3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] De-Optimization Irreversibility: Once an array transitions to HOLEY or DICTIONARY mode in V8, it can never transition back to PACKED mode.
[!] delete arr[i] Penalty: Using `delete` on an array element creates an empty hole and causes immediate de-optimization.
[!] in Operator on Holes vs Undefined: `i in sparseArr` returns `false` for holes, but `true` if `arr[i] = undefined`.
