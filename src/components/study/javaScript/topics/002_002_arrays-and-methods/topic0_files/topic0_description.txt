1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a long train arriving at Barrackpore railway station. Each train coach has a clear numbered slot (Coach 0, Coach 1, Coach 2...). If all coaches are connected solidly in order without missing cars, that is a Dense Array. But if someone unhitches coaches 3 and 4 leaving an empty gap on the tracks, that is a Sparse Array! In JavaScript, arrays are ordered, indexed lists of values.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Debangshu created an array: let scores = [90, 85, 78]; Then he wrote: scores[100] = 99; When he logged scores.length, it printed 101! He asked: 'Sir, I only added 4 numbers, why is the length 101?' I drew the memory slots on the whiteboard. I showed him that jumping from index 2 to index 100 created 97 empty slots ('holes') in the array, converting it from a fast dense array into a slower sparse array. Debangshu learned why we always add elements sequentially.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is an Array?
An ordered, zero-indexed list of values stored in a single variable container.

2. Dense vs Sparse Arrays:
- Dense Array: Contiguous memory slots with no empty gaps (e.g. [10, 20, 30]). V8 engine optimizes these into high-speed C++ arrays.
- Sparse Array: Contains unallocated 'holes' (e.g. let arr = []; arr[10] = 5). Slower dictionary-backed lookup.

3. Zero-Based Indexing:
The first element is at index [0], the second at [1], and the last at [arr.length - 1].

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Creating and Inspecting Dense Arrays ---
let studentList = ['Swadeep', 'Tuhina', 'Abhronila', 'Debangshu'];

console.log('First student:', studentList[0]); // 'Swadeep'
console.log('Total students:', studentList.length); // 4
console.log('Last student:', studentList[studentList.length - 1]); // 'Debangshu'

Teacher's Note on Example 1:
Arrays store elements at sequential numeric indices starting from 0.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accessing out-of-bounds index: Reading arr[99] when array has 3 elements returns undefined without throwing an error.

[!] Assigning far-away indices: arr[50] = 'x' creates 49 empty holes and bloats arr.length.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• JavaScript arrays are zero-indexed and dynamic.
• Keep arrays dense (continuous) for maximum V8 engine performance.
• Use arr.length to inspect element count.
