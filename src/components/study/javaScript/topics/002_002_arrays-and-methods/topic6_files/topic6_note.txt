3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] forEach() Cannot Break: Neither `break` nor `return` will stop a `forEach()` loop from running through all remaining items.
[!] Async in forEach() Failure: Passing an `async` function to `forEach()` does NOT await promises; iterations run concurrently without waiting.
[!] for...in on Arrays Anti-Pattern: `for...in` iterates arbitrary string properties and prototype keys in non-deterministic order.

function isPalindrome(arr) {
  for (let i = 0, j = arr.length - 1; i < j; i++, j--) {
    if (arr[i] !== arr[j]) return false;
  }
  return true;
}
