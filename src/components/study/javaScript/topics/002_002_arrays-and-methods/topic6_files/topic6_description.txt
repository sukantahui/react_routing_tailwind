3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is reduce()?
A method that executes a reducer function on each element of the array, passing the result from the previous calculation, ultimately resulting in a single output value.

2. Syntax:
arr.reduce((accumulator, currentValue, currentIndex, array) => { ... }, initialValue)

3. The Essential Rule of Initial Value:
ALWAYS provide an explicit initialValue (e.g. 0 for sums, {} for objects, [] for arrays). Without it, reduce uses the 1st element as the accumulator and skips the first iteration (which crashes on empty arrays!).

4. reduceRight():
Identical to reduce, but processes elements from right-to-left (end to beginning).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Summing and Finding Maximum with reduce ---
const transactionAmounts = [150, 800, 450, 1200, 300];

// 1. Calculating Total Sum
const totalRevenue = transactionAmounts.reduce((acc, curr) => acc + curr, 0);
console.log('Total Revenue: ₹' + totalRevenue); // ₹2900

// 2. Finding Highest Transaction
const maxTransaction = transactionAmounts.reduce((max, curr) => curr > max ? curr : max, transactionAmounts[0]);
console.log('Highest Transaction: ₹' + maxTransaction); // ₹1200

Teacher's Note on Example 1:
The accumulator carries the running state through every iteration.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Omitting the initial value: Calling [].reduce((a, b) => a + b) without an initial value throws a TypeError: Reduce of empty array with no initial value.

[!] Forgetting to return the accumulator: If your callback doesn't return acc, the next iteration receives undefined!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• reduce() aggregates an array into a single value (number, string, object, or array).
• Always supply an explicit initial value as the second argument.
• The accumulator carries state from one iteration to the next.
