1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine writing on an official certificate. If you make a mistake and scratch out words directly with a pen, the original certificate is ruined (Mutating). But if you place a fresh photocopy on your desk and make your edits there, the original master document in the vault remains pristine and safe. ES2023 introduced 4 non-mutating array methods that always return fresh copies!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The ES2023 Non-Mutating Quartet:
- toReversed(): Returns a reversed copy without touching original.
- toSorted(compareFn): Returns a sorted copy without touching original.
- toSpliced(start, deleteCount, ...items): Returns a modified copy without mutating original.
- with(index, value): Returns a copy with the element at index replaced by value.

2. Why Immutability Matters:
In modern frontend state management (like React and Redux), mutating state in place prevents change detection. Non-mutating methods guarantee clean state updates.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Using ES2023 Non-Mutating Methods ---
const original = ['Barrackpore', 'Kolkata', 'Dumdum'];

// 1. toReversed
const reversed = original.toReversed();
console.log('Reversed:', reversed); // ['Dumdum', 'Kolkata', 'Barrackpore']

// 2. with (Replace index 1 without mutating)
const updated = original.with(1, 'Salt Lake');
console.log('Updated Copy:', updated); // ['Barrackpore', 'Salt Lake', 'Dumdum']
console.log('Original intact:', original); // ['Barrackpore', 'Kolkata', 'Dumdum']

Teacher's Note on Example 1:
ES2023 methods produce transformed copies while leaving original arrays unchanged.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming .with() mutates: with() does NOT modify original array; it returns a new copy.

[!] Negative index in .with(): with(-1, val) updates the last element, but index must be within range [-length, length - 1].

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• ES2023 added toReversed, toSorted, toSpliced, and with.
• All 4 methods return new copies without mutating the original array.
• Essential for modern immutable React and functional code.
