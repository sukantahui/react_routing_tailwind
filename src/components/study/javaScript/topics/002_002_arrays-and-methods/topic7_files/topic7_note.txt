1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: Transform data structures using map, flat, and flatMap: recursive array flattening with depth controls, 1-to-N transformations, and building immutable pipelines.
- Classroom Experience: Debangshu mapped an array of orders to an array of item lists and ended up with a nested `[[Item], [Item]]` array, then struggled to filter individual items.
- Solution: Sukanta Hui introduced `flatMap()`, which maps each element and flattens the resulting array by depth 1 in a single optimized pass.
- Core Invariant: Mastering array methods ensures high-performance, immutable data processing.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] flat() Cleans Sparse Holes: `flat()` automatically removes empty holes from sparse arrays.
[!] flatMap() Depth Limit: `flatMap()` only flattens by exactly 1 level; deeper nesting requires `.flat(Infinity)`.
[!] map() Mutating In-Place: Mutating object properties inside `map` callbacks breaks immutability.

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS
--------------------------------------------------------------------------------
- Secret 1: Simultaneous Map and Filter via flatMap()
  By returning an empty array `[]` to drop items or `[transformed]` to keep items, `flatMap()` can map and filter in a single pass.
- Secret 2: Prevent array de-optimization by avoiding delete operations on indices.
- Secret 3: Leverage ES2023 immutable methods for clean state management.
