3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. arr.flat(depth):
Creates a new array with all sub-array elements concatenated into it recursively up to the specified depth.
- Default depth is 1.
- Use Infinity to flatten all nesting levels completely: `arr.flat(Infinity)`.
- Also removes empty holes in sparse arrays!

2. arr.flatMap(callbackFn):
Combines `map()` and `flat(1)` into a single, highly efficient operation. Maps each element using a transformation function and then flattens the result by depth 1.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Flattening Nested Arrays and Using flatMap ---
const batchGroups = [[1, 2], [3, 4], [5, [6, 7]]];

// Deep flattening with Infinity:
const allStudents = batchGroups.flat(Infinity);
console.log('Flat student list:', allStudents); // [1, 2, 3, 4, 5, 6, 7]

// flatMap: Splitting words in sentences
const sentences = ['Hello Barrackpore', 'Welcome to JavaScript'];
const allWords = sentences.flatMap(s => s.split(' '));
console.log('All words:', allWords); // ['Hello', 'Barrackpore', 'Welcome', 'to', 'JavaScript']

Teacher's Note on Example 1:
flat un-nests multi-dimensional arrays; flatMap transforms and flattens in one pass.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Forgetting depth parameter in flat(): flat() defaults to depth 1. If you have 3 nested levels, flat() only unwraps the first layer.

[!] flatMap only flattens depth 1: flatMap cannot flatten depth 2 or deeper.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• flat(depth) un-nests arrays (use Infinity for total flattening).
• flatMap(fn) maps and flattens depth 1 in a single performant pass.
• Both methods return brand new arrays without mutating the original.
