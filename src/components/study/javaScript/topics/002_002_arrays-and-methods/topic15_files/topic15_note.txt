3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Circular Parent References in Trees: If node A references parent B and B references parent A, naive recursive tree traversals lock in an infinite loop.
[!] Missing Root Identifiers: Orphaned nodes with non-existent parent IDs get dropped unless handled defensively.
[!] Large Array Memory Pressures: Paginating million-row arrays in memory requires lazy generators rather than eager slicing.
