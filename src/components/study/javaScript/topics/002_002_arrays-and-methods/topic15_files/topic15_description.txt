4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Complete Pipeline: Top 3 Passing Scores with GST Calculation ---
const rawScores = [35, 88, 92, 45, 28, 76, 95, 82];

// Pipeline: Filter passing (>=40) -> Sort descending -> Take top 3
const top3Passing = rawScores
  .filter(score => score >= 40)
  .toSorted((a, b) => b - a)
  .slice(0, 3);

console.log('Top 3 Passing Scores:', top3Passing); // [95, 92, 88]

Teacher's Note on Example 1:
Chaining filter, toSorted, and slice creates a clean, declarative data pipeline.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Over-chaining array methods on huge datasets: Chaining 5 maps and filters creates 5 intermediate arrays. Combine them inside reduce() for huge data.

[!] Mutating original arrays in pipelines: Always use non-mutating methods (toSorted, slice, filter, map).
