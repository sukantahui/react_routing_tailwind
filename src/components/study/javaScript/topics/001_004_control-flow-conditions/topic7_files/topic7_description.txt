4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Tiered Shipping Fee Calculator ---
function calculateShipping(orderAmount, isPrimeMember, distanceKm) {
  // Guard: Invalid order
  if (orderAmount <= 0) return "Invalid Order Amount";
  
  // Rule 1: Prime members get free shipping under 50km
  if (isPrimeMember && distanceKm <= 50) {
    return 0;
  }
  
  // Rule 2: High value orders (> ₹1000) get free shipping
  if (orderAmount >= 1000) {
    return 0;
  }
  
  // Rule 3: Tiered distance calculation
  let baseFee = 50;
  if (distanceKm > 20) {
    baseFee += (distanceKm - 20) * 2; // ₹2 extra per km beyond 20km
  }
  
  return baseFee;
}

console.log("Shipping for ₹1500 order:", "₹" + calculateShipping(1500, false, 30)); // ₹0
console.log("Shipping for ₹400 order (25km):", "₹" + calculateShipping(400, false, 25)); // ₹60

Teacher's Note on Example 1:
A real-world e-commerce shipping calculation combining membership, order threshold, and distance tiers.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Mixing UI rendering with decision logic: Keep calculations in pure functions that return clean values.

[!] Hardcoding numbers without descriptive variable names: Use named constants (e.g. BASE_SHIPPING_FEE) for clarity.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------

• Follow the 3-step pipeline: Validate -> Evaluate -> Return.
