1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about choosing between a bicycle and a car. If you are just traveling 200 meters down Shibtala road to buy a loaf of bread, taking a bicycle is quick and easy (Ternary). But if you are carrying 5 passengers and luggage on a long journey, you need a full car (If-Else). Choosing between ternary and if-else is all about choosing the right vehicle for the complexity of the task.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Swadeep had a piece of code that determined a discount based on student status, age, coupon code, and day of the week. He tried to write the whole thing as a single 150-character ternary expression. When Abhronila tried to read it, she couldn't understand where one condition ended and the next began. I showed Swadeep how converting it back to an if...else if structure made each business rule crystal clear. We established the team rule: 'Use ternary for single-line value assignments; use if-else for multi-branch business logic.'

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Comparative Trade-offs:
- Ternary (? :): An Expression. It returns a value. Great for variable assignments, inline template literals, and simple true/false decisions.
- If-Else: A Statement. It executes blocks of instructions. Great for multiple branches, complex logic, performing side-effects, and multi-line operations.

2. Readability Rules:
- If a condition fits on one line and just assigns a value -> Use Ternary.
- If you have more than 2 branches or need to execute multiple steps -> Use If-Else.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Clean Decision Comparison ---
// When Ternary shines (simple value assignment):
let isWeekend = true;
let alarmTime = isWeekend ? "8:00 AM" : "6:00 AM";
console.log("Alarm set for:", alarmTime);

// When If-Else shines (multi-step action):
let accountBalance = 500;
let withdrawAmount = 200;

if (withdrawAmount <= accountBalance) {
  accountBalance -= withdrawAmount;
  console.log("Withdrawal successful! Remaining: ₹" + accountBalance);
} else {
  console.log("Insufficient funds!");
}

Teacher's Note on Example 1:
Use ternary for direct value selection and if-else for multi-step transactional logic.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using nested ternaries to look clever: Clever code is hard to maintain; clear code is professional.

[!] Using if-else when a simple ternary assignment is cleaner.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Ternaries are expressions that return values for simple binary decisions.
• If-else statements handle multi-step actions and complex branches.
• Prioritize team readability over cleverness.
