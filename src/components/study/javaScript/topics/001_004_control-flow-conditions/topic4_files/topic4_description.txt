3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is Defensive Programming?
The practice of anticipating edge cases, validating input data, and gracefully handling missing or invalid states before performing core operations.

2. Core Defensive Strategies:
- Type Validation: Verify inputs using typeof before doing math or string manipulation.
- Null & Undefined Guards: Check if variables are populated before reading them.
- Default Invariant Assignment: Use ?? to guarantee variables always have safe fallback values.
- Fallback Error Branches: Always provide a safe else or default branch that reports issues gracefully.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Defensive Bill Calculator ---
function calculateElectricityBill(units) {
  // Defensive Guard: Check for missing or invalid input
  if (units === null || units === undefined || typeof units !== "number" || units < 0) {
    console.warn("Invalid units provided! Defaulting to 0 units.");
    units = 0;
  }
  
  let ratePerUnit = 7.5;
  let total = units * ratePerUnit;
  console.log("Calculated Bill: ₹" + total.toFixed(2));
}

calculateElectricityBill(120);  // Normal: ₹900.00
calculateElectricityBill(null); // Defensive: Warning logged, safe output ₹0.00

Teacher's Note on Example 1:
Defensive guards intercept invalid inputs at the start and prevent runtime calculation errors.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming input data is always valid: Never trust user input or external data without validation.

[!] Crashing silently: When an input is invalid, log a meaningful warning so you can debug the cause.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Defensive programming prevents crashes by validating inputs early.
• Check for null, undefined, and incorrect types at the top of operations.
• Always provide safe fallbacks and helpful warning messages.
