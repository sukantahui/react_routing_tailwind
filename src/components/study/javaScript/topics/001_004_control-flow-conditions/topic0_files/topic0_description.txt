2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Debangshu was building a grading system for students. He wrote 4 separate if statements without else. Even after a student got an 'A' grade in the first check, his program kept checking if they got a 'B', 'C', and 'D', doing unnecessary work! I showed him how an if...else if...else chain stops searching the instant it finds its first matching condition. The entire class tested the grading ladder with different marks.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Basic if Statement:
Executes a block of code ONLY if the condition evaluates to truthy.

2. The if...else Statement:
Provides an alternate fallback path when the condition is false.

3. The if...else if...else Ladder:
Tests multiple conditions in top-to-bottom sequence. As soon as ONE condition evaluates to true, its block executes and the entire rest of the chain is skipped.

4. Nested Conditionals:
Placing an if-statement inside another if-statement. (Use sparingly to avoid deeply nested 'arrow code'!).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Clean Grading Decision Ladder ---
let marks = 82;
let grade;

if (marks >= 90) {
  grade = "A+";
} else if (marks >= 80) {
  grade = "A";
} else if (marks >= 70) {
  grade = "B";
} else if (marks >= 40) {
  grade = "Pass";
} else {
  grade = "Fail";
}

console.log("Student Grade:", grade); // "A"

Teacher's Note on Example 1:
The ladder evaluates from top to bottom and stops at the first true condition (marks >= 80).

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Ordering conditions incorrectly in numeric ladders: If you check marks >= 40 first, an 95-mark student will get 'Pass' instead of 'A+'! Always order ranges from highest to lowest or lowest to highest.

[!] Accidentally placing a semicolon after if (condition); : Writing if (x > 5); { ... } terminates the if statement immediately!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• if / else if / else allows branching decision logic.
• Chain stops evaluating after the first truthy condition.
• Structure numeric range checks in proper descending or ascending order.
