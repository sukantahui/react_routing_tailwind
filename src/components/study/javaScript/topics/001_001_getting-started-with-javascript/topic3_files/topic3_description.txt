3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Visual Studio Code (VS Code):
The industry-standard code editor. Essential extensions for JavaScript beginners:
- Prettier - Code Formatter (automatically formats code on save)
- ESLint (catches syntax and logic mistakes early)
- Live Server (automatically refreshes your browser when you save HTML/JS files)

2. Chrome DevTools Console:
Your immediate testing ground inside the browser:
- Press F12 (or Right-Click → Inspect → Click 'Console').
- You can type single lines of JavaScript and press Enter to see instant results.
- Errors appear in red with exact line numbers pointing to the problem.

3. Node.js and npm:
- Node.js lets you run JavaScript files outside the browser via your terminal (node filename.js).
- npm (Node Package Manager) allows you to install helpful tools and libraries created by other developers worldwide.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Running JavaScript in Node.js via Terminal ---
// Save this in a file named test.js:
console.log("Running directly via Node.js runtime!");

// In your terminal, run:
// node test.js

Teacher's Note on Example 1:
Node.js runs the file directly from top to bottom and prints the output in your terminal window.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Writing code without checking the console: Always keep DevTools open so you catch errors the moment they happen.

[!] Ignoring red squiggly lines in VS Code: VS Code underlines syntax errors in red before you even run your program.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• VS Code provides syntax highlighting, auto-completion, and instant error detection.
• Chrome DevTools Console is your interactive live feedback environment.
• Node.js runs JavaScript on your local machine outside the web browser.
