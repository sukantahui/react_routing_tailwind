1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Purpose: Modern software engineering requires a standardized, deterministic, and 
  efficient development setup.
- Core Developer Tooling Components:
  1. Visual Studio Code (VS Code): Industry-standard code editor with powerful IntelliSense, 
     integrated terminal, debugging engine, and extensions ecosystem.
  2. Web Browsers & DevTools: Google Chrome / Microsoft Edge for running code, testing 
     Console output, inspecting the DOM tree, and profiling network performance.
  3. Live Server Extension (Ritwick Dey): Local HTTP development server providing 
     instant automatic reload over WebSocket connections upon file saves.
  4. Code Quality Tooling: Prettier (code formatter) and ESLint (static analysis linter).

2. IN-DEPTH TECHNICAL KNOW-HOW & ENGINE RUNTIME MECHANICS
--------------------------------------------------------------------------------
- Why file:// Protocol Fails Modern Web Development:
  * Security Origin (Origin: null): Browsers isolate local files opened via file:/// 
    with a null origin, blocking cross-origin AJAX/Fetch requests.
  * ES Modules Blocked: <script type="module"> fails under file:// due to strict CORS rules.
  * Web Workers & Service Workers: Require a valid HTTP/HTTPS origin (e.g. http://127.0.0.1:5500).
- How Live Server Operates Internally:
  * Spawns a local Node.js HTTP server listening on port 5500.
  * Injects a lightweight client-side WebSocket script tag into every served HTML document.
  * Watches local disk files for changes via file system change watchers (fs.watch).
  * Upon file save, sends a reload message over the WebSocket, instructing the browser 
    to reload the page without manual F5 refreshes.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] CORS policy: Cross origin requests are only supported for protocol schemes: http, data, https.
    Occurs when attempting to fetch local JSON files from a file:/// URL. Fix: Use Live Server.
[!] Browser Cache Stale Script Trap: Browsers may serve cached versions of .js files. 
    Use Hard Reload (Ctrl + Shift + R / Cmd + Shift + R) or Disable Cache in DevTools Network tab.
[!] Port Conflict: If port 5500 is occupied, Live Server automatically binds to 5501 or 5502.

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS

  Chrome DevTools without switching back to your editor.

7. INTERVIEW & VIVA QUICK-FIRE KNOWLEDGE POINTS
--------------------------------------------------------------------------------
Q1: Why is Live Server necessary instead of double-clicking an HTML file?
A1: Live Server runs a local HTTP web server, allowing ES Modules, Fetch API, and CORS 
    requests to function properly without browser security blocks.

Q2: What is the purpose of Prettier and ESLint in a JavaScript project?
A2: Prettier enforces consistent code formatting (spacing, quotes, indentation); ESLint catches 
    syntax errors, undeclared variables, and anti-patterns.

Q3: What causes a CORS error when loading local files?
A3: The browser treats file:/// URLs as having an opaque 'null' origin, which violates the 
    Same-Origin Policy for XMLHttpRequests and Fetch calls.

Q4: What is DevTools and how do you open it?
A4: DevTools is the built-in browser developer suite for debugging; opened via F12, 
    Ctrl + Shift + I (Windows), or Cmd + Option + I (Mac).
