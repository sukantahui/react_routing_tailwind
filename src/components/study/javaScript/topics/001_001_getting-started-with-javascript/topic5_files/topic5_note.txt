1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Beyond Simple Logging: The Console API is a comprehensive diagnostic interface 
  provided by the host environment (Browser / Node.js) for runtime inspection, 
  tabular data formatting, execution timers, and call stack tracing.
- Core Console Methods:
  1. Standard Output: console.log(), console.info(), console.warn(), console.error()
  2. Data Structures: console.table() (tabular array/object rendering), console.dir()
  3. Hierarchy & Organization: console.group(), console.groupCollapsed(), console.groupEnd()
  4. Diagnostics & Metrics: console.time(), console.timeEnd(), console.timeLog(), 
     console.count(), console.countReset(), console.assert(), console.trace(), console.clear()
- DevTools Interactive Debugging:
  * Breakpoints: Pause code execution at specific line numbers to inspect lexical scope variables.
  * Conditional Breakpoints: Pause only when a specific expression evaluates to true (e.g. i === 50).
  * 'debugger' Statement: Programmatic breakpoint that halts execution when DevTools is open.

2. IN-DEPTH TECHNICAL KNOW-HOW & ENGINE RUNTIME MECHANICS
--------------------------------------------------------------------------------
- The Live Object Mutation Trap:
  * In browser DevTools, when you log an object (console.log(obj)), the console displays 
    a reference pointer. If the object properties mutate later in the script, expanding 
    the object triangle in DevTools shows the *mutated* state, not the state at the moment 
    of logging!
  * Solution: Snapshot the object at log time using:
    console.log(JSON.parse(JSON.stringify(obj))) or console.log(structuredClone(obj)).
- Format Specifiers in Console:
  * %s : String replacement
  * %d or %i : Integer formatting
  * %f : Floating-point number formatting
  * %o or %O : DOM element or JavaScript object inspection
  * %c : Custom CSS styling applied to console message

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Production Console Leaks: Leaving thousands of console.log statements in production 
    retains references to objects in memory, preventing Garbage Collection and leaking RAM.
[!] console.assert() Quirk: console.assert(condition, msg) logs ONLY if the condition is FALSE. 
    It does not throw an exception or halt execution.
[!] Asynchronous Console Evaluation: Different browsers handle console buffer flushing with 
    varying asynchronous timings. Never rely on console.log for precision timing; use console.time().

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS
--------------------------------------------------------------------------------
- Custom %c CSS Styling: Style console messages with gradient badges and colored warnings:
  console.log('%c Sukanta Hui JS Master %c READY ', 'background:#f59e0b;color:#000;font-weight:bold;', 'background:#0f172a;color:#38bdf8;');
- console.table Column Filtering: Pass a second argument array of column keys to filter 
  wide datasets into crisp, readable tables: console.table(users, ['id', 'name', 'role']).
- Conditional Breakpoints: Right-click line number in DevTools Sources -> Add Conditional Breakpoint.

5. PRACTICAL ENTERPRISE USE-CASES & CODE EXAMPLES
--------------------------------------------------------------------------------
Example 1: Measuring Execution Time of an Algorithm
console.time("SortBenchmark");
const sorted = hugeArray.sort((a, b) => a - b);
console.timeEnd("SortBenchmark"); // Outputs: SortBenchmark: 12.4ms

Example 2: Tabular Logging of Filtered Columns
const team = [
  { id: 1, name: "Swadeep", role: "Frontend", active: true },
  { id: 2, name: "Tuhina", role: "Backend", active: true }
];
console.table(team, ["id", "name", "role"]);

Example 3: Safe Immutable Object Logging
function logSnapshot(label, data) {
  console.log(label, JSON.parse(JSON.stringify(data)));
}

Example 4: Programmatic Breakpoint in Conditional Flow
function processPayment(amount) {
  if (amount <= 0 || isNaN(amount)) {
    // debugger; // Automatically pauses DevTools on invalid payment inputs!
    console.error("Invalid amount detected:", amount);
  }
}

Example 5: Call Stack Error Diagnostics
function validateUserSession(user) {
  if (!user || !user.token) {
    console.trace("Missing user session token!");
  }
}

7. INTERVIEW & VIVA QUICK-FIRE KNOWLEDGE POINTS
--------------------------------------------------------------------------------
Q1: What is the difference between console.log(), console.warn(), and console.error()?
A1: console.log outputs standard text; console.warn prints a yellow warning box with stack trace; 
    console.error prints a prominent red error box with full stack trace.

Q2: What is the 'Live Object Mutation Trap' in browser DevTools?
A2: Logging an object outputs a memory reference; expanding the object later displays its 
    mutated state at expansion time, not its original state at logging time.

Q3: How does the 'debugger' statement work in JavaScript?
A3: If DevTools is open, the 'debugger' keyword pauses execution like a breakpoint, allowing 
    step-by-step variable inspection; if DevTools is closed, it is ignored without effect.

Q4: How do you measure code execution speed using the Console API?
A4: Call console.time("label") before the code and console.timeEnd("label") after; the browser 
    calculates and logs the elapsed time in milliseconds.
