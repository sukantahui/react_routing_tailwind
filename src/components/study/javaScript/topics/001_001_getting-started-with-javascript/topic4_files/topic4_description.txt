3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is the console Object?
The console object provides access to the browser's or runtime's debugging interface.

2. Essential Console Methods:
- console.log(...): General information and value inspection.
- console.warn(...): Prints a yellow warning box with a stack trace.
- console.error(...): Prints a red error box highlighting critical failures.
- console.table(...): Renders structured data in a clean, tabular grid format.
- console.group(...) & console.groupEnd(): Indents related log messages together.
- console.time('label') & console.timeEnd('label'): Measures the exact elapsed execution time in milliseconds.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Using Different Console Logging Levels ---
console.log("Normal informational message");
console.warn("Warning: Student marks not verified yet");
console.error("Error: Connection to database failed");

Teacher's Note on Example 1:
Different log levels color-code messages in DevTools so you can filter important alerts easily.

--- Example 2: Measuring Execution Time with console.time ---
console.time("ComputationTimer");
let total = 100 + 200 + 300;
console.log("Total is:", total);
console.timeEnd("ComputationTimer");

Teacher's Note on Example 2:
console.time and console.timeEnd output the exact number of milliseconds taken between the two markers.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Leaving hundreds of console.log statements in production code: While debugging, logs are helpful, but clean them up before publishing your app.

[!] Mismatched timer labels: The label string inside console.time('A') and console.timeEnd('A') must match exactly.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• console.log is the primary diagnostic tool for inspecting variable values and program flow.
• Use console.warn and console.error for specialized message formatting.
• Use console.time/console.timeEnd to measure performance in milliseconds.
