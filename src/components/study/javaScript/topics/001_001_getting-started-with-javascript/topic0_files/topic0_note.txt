1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: JavaScript is a high-level, dynamically typed, multi-paradigm, 
  single-threaded, prototype-based programming language with first-class functions 
  and a non-blocking asynchronous event loop concurrency model.
- History & Origin: Created in May 1995 by Brendan Eich at Netscape Communications 
  under the initial code name "Mocha", subsequently named "LiveScript", and finally 
  renamed to "JavaScript". Standardized by Ecma International under the formal 
  ECMAScript (ECMA-262) technical specification.
- Where It Runs (Execution Hosts):
  1. Client-Side Web Browsers: Google Chrome, Microsoft Edge, Mozilla Firefox, 
     Apple Safari, Opera, Brave.
  2. Server-Side & Headless Runtimes: Node.js (V8 + Libuv), Deno (V8 + Tokio), 
     Bun (JavaScriptCore + Zig).
  3. Mobile & Desktop Cross-Platform Engines: React Native (Hermes), Electron 
     (V8/Chromium), Tauri (Webview2 / WebKit).
  4. Embedded & IoT Microcontrollers: QuickJS, Duktape, Espruino.

2. IN-DEPTH TECHNICAL KNOW-HOW & ENGINE RUNTIME MECHANICS
--------------------------------------------------------------------------------
- Modern JIT (Just-In-Time) Compiler Pipeline (e.g. Google V8):
  1. Lexical Analysis & Tokenizer: Source code is scanned into stream of syntactic tokens.
  2. Parser: Tokens are validated into an AST (Abstract Syntax Tree).
  3. Ignition Interpreter: AST is compiled into concise, register-based Ignition Bytecode.
  4. Type Profiling & Inline Caching (IC): Gathers runtime type feedback at call sites.
  5. TurboFan JIT Optimizer: Frequently executed "hot code" bytecodes are compiled into 
     highly optimized native machine code.
  6. Deoptimization: If speculative type assumptions fail (e.g., number passes string), 
     TurboFan bails out back to Ignition bytecode.
- Execution Context Memory Model:
  * Call Stack: Stores execution context frames, primitive values (numbers, booleans, 
    small strings, null, undefined, symbols, bigints), and reference pointers.
  * Memory Heap: Large unstructured memory region where objects, arrays, functions, 
    closures, and DOM nodes are allocated dynamically.
- Global Scope Standardization:
  * ES2020 introduced 'globalThis', unifying 'window' (Browser), 'self' (Web Worker), 
    and 'global' (Node.js).

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] ReferenceError: window is not defined: Thrown when executing browser-specific 
    APIs in server-side Node.js / Bun runtimes.
[!] ReferenceError: process is not defined: Thrown when executing Node-specific 
    APIs directly inside standard browser window threads.
[!] Call Stack Freezing: Because JS is single-threaded, running long synchronous 
    CPU loops (e.g., while(true) {}) completely starves the event loop, freezing UI rendering.
[!] Primitive Value Immutability: Primitives cannot hold custom attached properties. 
    (e.g., let n = 10; n.flag = true; console.log(n.flag) -> undefined).

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS
--------------------------------------------------------------------------------
- globalThis Universal Standard (ES2020): Access the global execution environment 
  consistently across Node.js, Deno, Bun, Browser tabs, and Web Workers.
- V8 DevTools Console Magic: In Chrome DevTools, $0 refers to currently inspected DOM element, 
  $_ evaluates to the last evaluated expression, and console.table() outputs tabular data.
- Engine Monomorphism Secret: TurboFan optimizes function calls up to 100x faster if 
  passed object arguments maintain identical hidden class property shapes and order.

const isBrowser = !isServer;
console.log("Environment:", isServer ? "Server/Node" : "Client/Browser");

Example 3: Event Loop Microtask vs Macrotask Order
console.log("1. Sync Callstack");
setTimeout(() => console.log("3. Macrotask Timer"), 0);
Promise.resolve().then(() => console.log("2. Microtask Promise"));

Example 4: Memory Reference Mutation Trap
const original = { student: "Swadeep", center: "Barrackpore" };
const clone = Object.assign({}, original); // Shallow clone avoids mutation
clone.student = "Tuhina";
console.log(original.student); // "Swadeep" preserved

Example 5: Non-Blocking Chunked Processing
function processLargeDataAsync(data, callback) {
  setTimeout(() => {
    const processed = data.map(x => x * 2);
    callback(processed);
  }, 0);
}

7. INTERVIEW & VIVA QUICK-FIRE KNOWLEDGE POINTS
--------------------------------------------------------------------------------
Q1: Is JavaScript an interpreted or compiled language?
A1: JavaScript uses Just-In-Time (JIT) compilation. The engine parses source to AST, 
    generates bytecode via an interpreter (Ignition), and optimizes hot code to machine 
    instructions (TurboFan).

Q2: Why is JavaScript single-threaded, and how does it handle concurrency?
A2: JavaScript has a single Call Stack and executes one instruction at a time. It achieves 
    concurrency through an asynchronous Event Loop with Web APIs/Libuv offloading tasks.

Q3: What is the difference between Call Stack and Memory Heap?
A3: Call Stack stores execution contexts and primitive values in LIFO order; Memory Heap 
    allocates dynamic objects, arrays, and closures with garbage collection.

Q4: What is 'globalThis' and why was it introduced in ES2020?
A4: 'globalThis' provides a universal standard to reference the global scope regardless of 
    whether code is running in a browser, Node.js, or Web Worker.
