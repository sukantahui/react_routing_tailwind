3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Where Does JavaScript Live?
Traditionally, JavaScript lived only inside web browsers (like Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge). Whenever you open a webpage, the browser downloads the JavaScript file and executes it using an embedded engine.
For example:
- Google Chrome uses the 'V8' engine.
- Apple Safari uses 'JavaScriptCore' (Nitro).
- Mozilla Firefox uses 'SpiderMonkey'.

2. JavaScript Beyond the Browser:
In 2009, an engineer named Ryan Dahl took Google's V8 engine out of the browser and wrapped it in C++ to run directly on your computer's operating system. This became Node.js! Today, JavaScript runs everywhere:
- Inside web browsers (interactive user interfaces)
- On web servers via Node.js, Deno, and Bun (APIs, databases)
- On microcontrollers and IoT devices

3. Key Characteristics to Understand Today:
- High-Level: You don't have to manage raw computer memory manually.
- Dynamically Typed: You don't need to specify if a variable is a number or text when creating it.
- Single-Threaded: It processes one task at a time in an orderly sequence.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Simple Greeting in the Browser Console ---
// Open your browser Console (Press F12 → Console tab)
// Type this single line and press Enter:
console.log("Welcome to Barrackpore Coding Lab!");

Teacher's Note on Example 1:
The console.log() command tells the JavaScript engine to output a message directly to your developer screen.

--- Example 2: Basic Arithmetic Calculation ---
// Calculating the total fees for a course
console.log(5000 + 900); // Outputs: 5900

Teacher's Note on Example 2:
JavaScript immediately computes mathematical additions and prints the final result.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Confusing Java with JavaScript: Java and JavaScript are two completely different languages, just like Car and Carpet are two completely different things!

[!] Expecting HTML/CSS to do calculations: Only JavaScript has the computational logic to calculate, compare, and manipulate data.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• HTML is structure, CSS is presentation, and JavaScript is interactive behavior.
• JavaScript runs in web browsers and on computers via runtime environments like Node.js.
• Engines like Google V8 translate your JavaScript code into fast machine instructions.
