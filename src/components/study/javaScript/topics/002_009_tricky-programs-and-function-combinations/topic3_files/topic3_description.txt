3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Debounce:
Postpones execution until `delay` milliseconds have elapsed since the LAST time the function was invoked. (Use for search bars, auto-saving drafts).

2. Throttle:
Guarantees the function is executed at most once every `limit` milliseconds, regardless of how frequently it is triggered. (Use for window resizing, scrolling, game loops).

3. Enterprise Controls:
- `cancel()`: Clears the pending timer.
- `flush()`: Immediately executes any pending invocation without waiting for the timer to expire.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Production Debounce Implementation with Cancel ---
function debounce(fn, delay) {
  let timerId = null;
  
  const debounced = function(...args) {
    if (timerId) clearTimeout(timerId);
    timerId = setTimeout(() => {
      fn.apply(this, args);
      timerId = null;
    }, delay);
  };
  
  debounced.cancel = () => {
    if (timerId) {
      clearTimeout(timerId);
      timerId = null;
    }
  };
  
  return debounced;
}

const logSearch = debounce((query) => console.log('Searching API for:', query), 300);
logSearch('B');
logSearch('Bar');
logSearch('Barrackpore'); // Only this last call executes after 300ms!

Teacher's Note on Example 1:
Debounce resets the timer on each invocation, firing only after activity pauses.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Re-creating debounced functions inside React render loops: In React components, wrap debounced functions in `useCallback` or `useMemo` so the timer isn't re-instantiated on every render.

[!] Losing `this` context: Always use `fn.apply(this, args)` inside the timer callback.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Debounce fires once after activity settles; Throttle fires at fixed rate intervals.
• Debounce search inputs and auto-save; Throttle scroll and resize events.
• Provide `.cancel()` and `.flush()` for complete UI lifecycle control.
