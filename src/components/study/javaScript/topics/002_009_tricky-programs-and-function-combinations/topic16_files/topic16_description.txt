1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about an airport security checkpoint: Passenger enters → Station 1 (Ticket Check) → Station 2 (Luggage X-Ray) → Station 3 (Body Scan) → Station 4 (Boarding Gate). Each security officer inspects the passenger and calls 'NEXT' (`next()`) to pass the passenger to the next station. Any station can reject the passenger or add a security stamp. In JavaScript, this is the Onion Middleware Pattern!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Onion Middleware Model:
Middleware functions execute in sequence, with each middleware receiving a `context` object and a `next` function.
- When `await next()` is called, execution pauses in the current middleware and jumps to the next middleware.
- When downstream middlewares finish, control flows back up through the outer middlewares (like layers of an onion!).

2. The Dispatch Composition Engine:
Recursively chains functions using `dispatch(index)` returning Promises.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Onion Middleware Engine from Scratch ---
class OnionPipeline {
  constructor() {
    this.middlewares = [];
  }
  
  use(fn) {
    this.middlewares.push(fn);
    return this;
  }
  
  execute(context) {
    const dispatch = (i) => {
      if (i >= this.middlewares.length) return Promise.resolve();
      const fn = this.middlewares[i];
      try {
        return Promise.resolve(fn(context, () => dispatch(i + 1)));
      } catch (err) {
        return Promise.reject(err);
      }
    };
    return dispatch(0);
  }
}

const app = new OnionPipeline();

// Layer 1: Performance Timer
app.use(async (ctx, next) => {
  console.log('-> Layer 1: Start Timer');
  ctx.startTime = Date.now();
  await next();
  console.log(`<- Layer 1: End Timer (${Date.now() - ctx.startTime}ms)`);
});

// Layer 2: Authentication Check
app.use(async (ctx, next) => {
  console.log('-> Layer 2: Auth Check Passed');
  ctx.user = 'Swadeep';
  await next();
  console.log('<- Layer 2: Auth Cleanup');
});

// Layer 3: Core Business Action
app.use(async (ctx) => {
  console.log(`=== Core Action: Generating Certificate for ${ctx.user} ===`);
});

app.execute({});

Teacher's Note on Example 1:
Demonstrates the complete Express/Koa onion middleware architecture from scratch.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Calling `next()` multiple times in the same middleware: Calling `next()` twice in one middleware creates duplicate downstream branches and race conditions. Always enforce single invocation.

[!] Forgetting to await `next()`: In async middleware, omitting `await next()` breaks downstream timing and error bubbling.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Middleware patterns enable modular request interception and pipeline processing.
• The Onion architecture executes downstream and unwinds upstream around `await next()`.
• The foundational architectural pattern behind Express, Koa, Redux, and Axios interceptors.
