1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine climbing a ladder with 100,000 rungs. If you try to stand on every single rung simultaneously (Pushing 100,000 stack frames onto the Call Stack), the ladder collapses under the weight (`RangeError: Maximum call stack size exceeded`). But if you step onto a trampoline, bounce up, let the previous step disappear, and land on a single flat platform over and over in a loop, you can climb 1,000,000 steps without breaking the ladder! That is Trampolining.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Tuhina wrote a recursive function to compute the sum of 100,000 numbers. Her browser crashed with a Maximum Call Stack Size Exceeded error. 3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Stack Overflow Problem:
Standard recursive calls push a new stack frame for each call. Most JavaScript engines have a limit of ~10,000 frames before crashing.

2. What is a Trampoline?
A control-flow wrapper that repeatedly executes functions that return other functions ('thunks') until a non-function value is returned.

3. Constant O(1) Stack Space:
Because the previous function returns before the next thunk is called, the Call Stack never grows beyond 1 frame!

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Deep Recursion with Trampoline ---
// Universal Trampoline Runner:
function trampoline(fn) {
  return function(...args) {
    let result = fn(...args);
    while (typeof result === 'function') {
      result = result(); // Unwrap thunk in flat loop
    }
    return result;
  };
}

// Trampoline-Safe Recursive Factorial:
const safeFactorial = trampoline(function fact(n, acc = 1n) {
  if (n <= 1n) return acc;
  return () => fact(n - 1n, acc * BigInt(n)); // Returns a Thunk!
});

console.log('5! =', safeFactorial(5n));
console.log('20! =', safeFactorial(20n));

Teacher's Note on Example 1:
The trampoline loop unwraps recursive thunks in constant O(1) stack space.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Performing operations outside the thunk: `return 1 + (() => fn())` is NOT tail-safe. The thunk itself must be returned directly.

[!] Accidentally returning a standard function as data: If your algorithm intends to return a genuine function as the final result, wrap it in an object to distinguish from a thunk.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Trampolining executes deep recursive algorithms in O(1) flat stack space.
• Recursive steps return zero-argument Thunks (`() => nextCall(...)`).
• Completely eliminates `RangeError: Maximum call stack size exceeded`.
