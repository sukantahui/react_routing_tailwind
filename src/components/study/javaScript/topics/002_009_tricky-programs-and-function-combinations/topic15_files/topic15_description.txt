--------------------------------------------------------------------------------

If a naive photographer tries to take a photo of Person A, and then photos of everyone Person A references, they will photograph A, then B, then A, then B in an infinite recursive loop until the camera explodes! To clone circular graphs safely, the photographer keeps a guestbook of already-photographed faces (a WeakMap tracker)!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Circular Reference Problem:
Objects with cyclic references (`a.self = a`) cause infinite loops in `JSON.stringify` and naive deep-clone functions.

2. The WeakMap Graph Tracking Pattern:
- Maintain a `WeakMap` of `(originalObject → clonedObject)`.
- Before cloning an object, check `if (hashTable.has(obj)) return hashTable.get(obj)`.
- Instantly resolves circular references and preserves graph topology in O(N) linear time.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Circular-Safe Deep Clone Function ---
function deepCloneCircular(obj, hash = new WeakMap()) {
  // 1. Return primitives and null directly:
  if (obj === null || typeof obj !== 'object') return obj;
  
  // 2. Handle Dates and RegExps:
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  
  // 3. Return existing clone if circular reference detected:
  if (hash.has(obj)) return hash.get(obj);
  
  // 4. Create fresh container and record in hash:
  const clone = Array.isArray(obj) ? [] : Object.create(Object.getPrototypeOf(obj));
  hash.set(obj, clone);
  
  // 5. Recursively clone properties:
  for (let key of Reflect.ownKeys(obj)) {
    clone[key] = deepCloneCircular(obj[key], hash);
  }
  return clone;
}

const nodeA = { name: 'Node A' };
const nodeB = { name: 'Node B' };
nodeA.link = nodeB;
nodeB.link = nodeA; // Circular reference!

const clonedGraph = deepCloneCircular(nodeA);
console.log('Cloned successfully without stack overflow:', clonedGraph.name);
console.log('Circular link preserved?', clonedGraph.link.link === clonedGraph); // true!

Teacher's Note on Example 1:
WeakMap tracks already-cloned references to preserve cyclic graph structures.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using standard Map instead of WeakMap: WeakMap allows garbage collection and handles complex cyclic graphs with zero memory leaks.

[!] Forgetting Symbol keys: Use `Reflect.ownKeys(obj)` to clone both string keys and Symbol keys.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Cyclic graphs cause infinite recursion in naive deep cloning.
• WeakMap tracks visited object references to resolve circular relationships.
• Supports complex state structures, graphs, and linked data.
