3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Synchronous Pipe and Compose:
- `pipe(...fns)`: Left-to-right execution: `initialVal → fn1 → fn2 → fn3`.
- `compose(...fns)`: Right-to-left execution: `fn3(fn2(fn1(initialVal)))`.

2. Asynchronous Pipe Engine (`pipeAsync`):
- Uses `reduce()` with `async/await` to chain Promise-returning functions sequentially:
`const pipeAsync = (...fns) => input => fns.reduce(async (accPromise, fn) => fn(await accPromise), input);`

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Universal Synchronous & Asynchronous Pipeline Engine ---
// 1. Synchronous Pipe Engine:
const pipe = (...fns) => input => fns.reduce((acc, fn) => fn(acc), input);

const cleanText = pipe(
  str => str.trim(),
  str => str.toUpperCase(),
  str => `[BARRACKPORE] ${str}`
);
console.log(cleanText('   javascript masterclass   '));

// 2. Asynchronous Pipeline Engine:
const pipeAsync = (...fns) => input => fns.reduce(async (acc, fn) => fn(await acc), input);

const asyncWorkflow = pipeAsync(
  async (userId) => ({ id: userId, score: 85 }),
  async (user) => ({ ...user, grade: user.score >= 80 ? 'A' : 'B' }),
  async (user) => `Student #${user.id} Awarded Grade: ${user.grade}`
);

asyncWorkflow(101).then(console.log);

Teacher's Note on Example 1:
pipe processes data synchronously; pipeAsync resolves each step's Promise sequentially.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Passing non-unary functions into a pipeline: Intermediate pipeline functions must accept exactly one argument (the output of the previous step).

[!] Forgetting to await inside pipeAsync: Failing to await `acc` in reduce causes subsequent functions to receive unresolved Promises.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• `pipe()` executes functions left-to-right; `compose()` right-to-left.
• `pipeAsync()` combines synchronous and asynchronous Promise functions.
• Foundation for functional data pipelines and enterprise middleware.
