1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: Architect clean data transformation pipelines using function composition (compose: right-to-left) and forward piping (pipe: left-to-right), with both synchronous and asynchronous support.
- Classroom Experience: Tuhina nested 5 mathematical functions `format(round(calculateTax(applyDiscount(price))))` and struggled to read, debug, and trace values across intermediate steps.
- Solution: Sukanta Hui refactored the pipeline using `pipe(applyDiscount, calculateTax, round, format)`, creating a clean, readable left-to-right execution stream.
- Core Invariant: Understanding this topic guarantees predictable runtime execution
  and robust software architecture.

2. IN-DEPTH TECHNICAL KNOW-HOW & ENGINE RUNTIME MECHANICS
--------------------------------------------------------------------------------
- Execution Context Lifecycle: Creation Phase (records allocated) vs Execution Phase.
- Memory Management: Allocates lexical environments in the V8 Heap.
- Spec Abstract Operations: ToPrimitive, GetValue, and Declarative Environment Lookups.
- V8 Optimization: TurboFan optimizes predictable, monomorphic call-sites.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Unary Constraint Violation: All intermediate functions in a composition pipeline must be unary (accepting exactly one input and returning one output).
[!] Unhandled Promise Rejections in Async Pipelines: Failing to catch errors in an async pipe halts the entire pipeline midway.
[!] Type Mismatch Between Stages: If function N outputs a string but function N+1 expects an array, runtime TypeErrors occur.

Example 5: Senior Hidden Gem Pattern
const pipeAsync = (...fns) => (initialValue) =>
  fns.reduce(
    async (accPromise, fn) => fn(await accPromise),
    Promise.resolve(initialValue)
  );

const fetchUser = async (id) => ({ id, name: "swadeep" });
const enrichRole = async (user) => ({ ...user, role: "Admin" });
const formatBadge = (user) => `[${user.role}] ${user.name.toUpperCase()}`;

const buildBadge = pipeAsync(fetchUser, enrichRole, formatBadge);
buildBadge(101).then(console.log); // "[ADMIN] SWADEEP"
