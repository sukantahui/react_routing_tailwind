3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is Function Composition?
Combining two or more pure functions to produce a new function. Mathematically: (f ∘ g)(x) = f(g(x)).

2. Pipe (Left-to-Right Data Flow):
- Evaluates functions in natural reading order (Function 1 -> Function 2 -> Function 3).
- Formula: const pipe = (...fns) => input => fns.reduce((acc, fn) => fn(acc), input);

3. Compose (Right-to-Left Data Flow):
- Evaluates from right-to-left (standard mathematical composition).
- Formula: const compose = (...fns) => input => fns.reduceRight((acc, fn) => fn(acc), input);

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Building a Left-to-Right Text Pipe ---
// Small pure building blocks:
const trimText = str => str.trim();
const toLower = str => str.toLowerCase();
const wrapInTags = str => '<span>' + str + '</span>';

// Universal Pipe function:
const pipe = (...fns) => initialValue => fns.reduce((acc, fn) => fn(acc), initialValue);

// Create composite pipeline:
const processUserTag = pipe(trimText, toLower, wrapInTags);

console.log(processUserTag('   SWADEEP HUI   ')); // '<span>swadeep hui</span>'

Teacher's Note on Example 1:
pipe executes trim -> toLower -> wrapInTags in left-to-right sequence.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Passing multi-argument functions in the middle of a pipe: Intermediate functions in a composition pipeline must be unary (accepting exactly one input and returning one output).

[!] Mutating values inside pipeline functions: Keep all pipeline functions completely pure.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Pipe connects functions left-to-right (f -> g -> h).
• Compose connects functions right-to-left (h ∘ g ∘ f).
• Build complex data pipelines from small, single-purpose pure functions.
