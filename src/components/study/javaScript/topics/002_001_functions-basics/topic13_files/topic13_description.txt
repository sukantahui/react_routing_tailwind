3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is a Tail Call?
A function call is in 'tail position' if it is the very last action executed by the function before returning.
- Not a Tail Call: return n * fact(n - 1); (Multiplication happens AFTER fact returns).
- Tail Call: return fact(n - 1, acc * n); (Nothing left to do after fact returns!).

2. The Trampoline Pattern:
A technique to execute deep recursion safely in engines that don't support native TCO. Instead of calling itself directly, the recursive step returns a zero-argument function ('thunk') that a flat while-loop unwraps in O(1) constant stack space.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Stack-Safe Trampoline Runner ---
// Universal Trampoline Runner
function trampoline(fn) {
  return function(...args) {
    let result = fn(...args);
    while (typeof result === 'function') {
      result = result();
    }
    return result;
  };
}

// Trampoline-safe sum
const safeSum = trampoline(function sum(n, acc = 0) {
  if (n === 0) return acc;
  return () => sum(n - 1, acc + n); // Returns a thunk!
});

console.log('Safe sum of 10,000:', safeSum(10000)); // 50005000 (No stack overflow!)

Teacher's Note on Example 1:
The trampoline loop executes thousands of recursive steps in O(1) flat stack space.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming all JS engines support native TCO: Most engines (like V8) do not enable TCO by default; use trampolines or iterative loops for deep recursion.

[!] Performing math after the recursive call: return 1 + fn() is NOT in tail position.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Tail Call Optimization reuses the current stack frame when the call is in tail position.
• Trampolining converts recursion into a flat while-loop using thunks.
• Use trampolines or loops for deep recursive calculations.
