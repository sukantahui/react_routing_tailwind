3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] TypeError on 'new () => {}': Calling `new` on an arrow function throws `TypeError: fn is not a constructor` because arrow functions lack a `prototype` property.
[!] Loss of Context in Object Methods: Defining object methods as arrow functions binds `this` to the enclosing scope (often global or module), breaking object state access.
[!] Lack of arguments Object: Referencing `arguments` inside an arrow function refers to the outer standard function's arguments, not the arrow function's.
