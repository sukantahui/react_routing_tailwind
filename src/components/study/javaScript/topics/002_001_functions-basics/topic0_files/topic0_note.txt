- Definition: Master the fundamental distinctions between function declarations and function expressions in JavaScript, including V8 hoisting mechanics, lexical binding, and anonymous vs named function expressions.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] ReferenceError (TDZ): Calling a `const` or `let` function expression before its declaration line.
[!] TypeError (var invocation): Invoking a `var` function expression before initialization produces `TypeError: fn is not a function` because var holds `undefined`.
[!] Block Scope Hoisting Quirks: In non-strict mode, function declarations inside if blocks have browser-dependent hoisting behaviors; in strict mode they are block-scoped.

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS
--------------------------------------------------------------------------------
- Secret 1: Named Function Expression (NFE) Scope Immutability & Stack Traces
  When defining a Named Function Expression `const f = function helper() {}`, the name `helper` is bound as an immutable identifier available ONLY inside the function's own body, preventing external pollution while providing clean stack traces.
- Secret 2: Defensive programming with guard clauses prevents deep pyramid nesting.
- Secret 3: Proper scope hygiene eliminates unexpected memory retention in closures.
