3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Automatic Semicolon Insertion (ASI) on Return: Placing a newline after `return` causes JS to insert a semicolon, returning `undefined` instead of the expression below.
[!] Finally Block Return Override: A `return` inside a `finally` block unconditionally overrides any `return` or `throw` in the preceding `try` or `catch` block.
[!] Returning Object Literals from Arrow Functions: Returning `{ key: val }` without parentheses is parsed as a function block, returning `undefined`.

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS
--------------------------------------------------------------------------------
- Secret 1: Finally Block Return Hijacking & Exception Suppression
  The ECMAScript specification guarantees that `finally` blocks always execute before context teardown; an explicit return inside `finally` discards any pending exception or previous return value.
- Secret 2: Defensive programming with guard clauses prevents deep pyramid nesting.
- Secret 3: Proper scope hygiene eliminates unexpected memory retention in closures.
