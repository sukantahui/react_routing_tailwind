3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] SyntaxError on Leading Declaration: Omitting the enclosing grouping parentheses `(` causes parser SyntaxError.
[!] ASI Preceding Line Collision: If the line preceding an IIFE lacks a semicolon, the parser attempts to call the previous expression with the IIFE as arguments.
[!] Memory Leak in Retained Closures: If an IIFE returns an object referencing large arrays in its private scope, that memory is retained indefinitely.

7. INTERVIEW & VIVA QUICK-FIRE KNOWLEDGE POINTS
--------------------------------------------------------------------------------
Q1: What is the primary purpose of IIFE (Immediately Invoked Function Expressions) & Private Scope Encapsulation?
A1: Master IIFE syntax and runtime execution: preventing global namespace pollution, creating private closures, and understanding module patterns before ES modules.

Q2: How does the V8 engine execute this under the hood?
A2: It resolves bindings via the Lexical Environment Record and executes on the Call Stack.

Q3: What common bug do junior developers encounter here?
A3: Omitting Semicolons Before an IIFE: ASI does not insert a semicolon before an opening parenthesis, causing runtime collisions with preceding statements.

Q4: What is the Senior Pro recommendation?
A4: Defensive Semicolon Prefixing: Always terminate statements with semicolons or prefix IIFEs with a defensive semicolon `;(function() {})()`.
