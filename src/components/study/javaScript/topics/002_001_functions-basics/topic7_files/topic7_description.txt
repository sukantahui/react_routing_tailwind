3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is an IIFE?
An Immediately Invoked Function Expression (pronounced 'iffy') is a JavaScript function that runs as soon as it is defined.

2. Syntax:
(function() {
  // Private variables live here!
  let privateSecret = '42';
  console.log('IIFE executed immediately!');
})();
- The outer parentheses ( ... ) turn the function into an expression.
- The trailing () immediately invokes the function.

3. Why Use IIFEs?
- Data Privacy & Encapsulation: Variables declared inside cannot be accessed from the outside.
- Prevents Global Namespace Pollution: Keeps the global scope completely clean.
- Historical importance: Before ES6 modules existed, IIFEs were the primary module system of the web.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Creating a Private Counter with IIFE ---
const myLabAccount = (function() {
  let balance = 5000; // Completely private variable!
  
  return {
    getBalance: function() {
      return 'Current Balance: ₹' + balance;
    },
    deposit: function(amount) {
      balance += amount;
      return 'Deposited ₹' + amount;
    }
  };
})();

console.log(myLabAccount.getBalance()); // ₹5000
console.log(myLabAccount.deposit(1500));
console.log(myLabAccount.getBalance()); // ₹6500

Teacher's Note on Example 1:
The IIFE executes once and returns an interface object while keeping balance private.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Missing semicolon before an IIFE: If the previous statement lacks a semicolon, JS might try to execute previousStatement(...)(), causing a TypeError.

[!] Overusing IIFE when ES modules are available: In modern ES6 projects with import/export, modules handle file isolation automatically.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• IIFE runs immediately upon creation: (function() { ... })();
• Creates private local scope and prevents global pollution.
• Foundation of the Module Pattern in JavaScript.
