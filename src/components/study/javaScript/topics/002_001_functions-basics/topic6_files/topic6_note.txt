- Definition: Leverage JavaScript's first-class function nature: passing functions as arguments, returning functions from functions, and architecting reusable higher-order utilities.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Immediate Invocation Trap: Passing `fn()` instead of `fn` causes the return value to be passed instead of the callable function.
[!] Loss of Context in Callbacks: Passing an un-bound object method as a callback causes `this` to lose its original object context.
[!] Callback Hell (Inversion of Control): Deeply nested asynchronous callbacks make error handling and stack tracing brittle.

4. 💎 SPECIAL LANGUAGE FEATURES & SENIOR PRO SECRETS

  HOFs can intercept, instrument, and time any arbitrary function without modifying its internal implementation.
- Secret 2: Defensive programming with guard clauses prevents deep pyramid nesting.
- Secret 3: Proper scope hygiene eliminates unexpected memory retention in closures.

function withPerformanceMetrics(fn) {
  return function(...args) {
    const start = performance.now();
    const result = fn.apply(this, args);
    const duration = (performance.now() - start).toFixed(3);
    console.log(`[METRIC] ${fn.name || 'Anonymous'} executed in ${duration}ms`);
    return result;
  };
}
const heavyCalc = withPerformanceMetrics(function computePrimes(limit) {
  return limit * limit;
});

7. INTERVIEW & VIVA QUICK-FIRE KNOWLEDGE POINTS

Q1: What is the primary purpose of First-Class Functions, Callbacks & Higher-Order Functions (HOFs)?
A1: Leverage JavaScript's first-class function nature: passing functions as arguments, returning functions from functions, and architecting reusable higher-order utilities.

Q2: How does the V8 engine execute this under the hood?
A2: It resolves bindings via the Lexical Environment Record and executes on the Call Stack.

Q3: What common bug do junior developers encounter here?
A3: Accidentally Invoking Callbacks During Registration: Calling `element.addEventListener('click', handleClick())` binds the return value instead of the handler.

Q4: What is the Senior Pro recommendation?
A4: Pass Function Identifier or Arrow Wrapper: Pass the bare function name or an arrow wrapper if passing custom parameters.
