1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: Understand how JavaScript resolves identifiers through the scope chain: global scope, module scope, function scope, and ES6 block scope with let and const.
- Classroom Experience: Debangshu declared a `var` loop variable inside a block and discovered it leaked across the entire outer function, overwriting another index variable.
- Solution: Sukanta Hui explained how `var` attaches to the nearest Function Environment Record, while `let` and `const` create a new Declarative Environment Record for every block.
- Core Invariant: Understanding this topic guarantees predictable runtime execution
  and robust software architecture.

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] ReferenceError (Identifier Not Found): Traversing the entire scope chain to the Global object without finding the identifier throws ReferenceError in strict mode.
[!] Accidental Global Leak (Sloppy Mode): Assigning to an undeclared variable (`x = 10`) in non-strict mode creates a property on the global object.
[!] Shadowing Pitfalls: Declaring a local variable with the exact same name as an outer variable masks access to the outer identifier.
