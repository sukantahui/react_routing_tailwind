3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is Scope?
Scope defines the current context of execution in which values and expressions are 'visible' or can be referenced.

2. The Three Levels of Scope in JavaScript:
a) Global Scope: Variables declared outside any function or block are accessible everywhere in the file.
b) Function Scope: Variables declared inside a function are private to that function and cannot be accessed from the outside.
c) Block Scope (ES6): Variables declared with let and const inside curly braces { ... } exist only inside that block.

3. Lexical Scoping & The Scope Chain:
JavaScript resolves variables lexically (based on where code is physically written in the file). If a variable is not found in the immediate local scope, the engine looks outwards to the parent scope, repeating all the way up to the Global scope.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Visualizing the Scope Chain ---
let institute = 'Coder & AccoTax'; // Global Scope

function outerBranch() {
  let branch = 'Barrackpore'; // Function Scope
  
  function innerClassroom() {
    let room = 'Lab 1'; // Nested Scope
    // Has access to room, branch, AND institute!
    console.log(institute + ' → ' + branch + ' → ' + room);
  }
  
  innerClassroom();
}

outerBranch();

Teacher's Note on Example 1:
Inner scopes can access outer variables, but outer scopes cannot access inner variables.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Polluting the global scope: Declaring too many global variables causes naming collisions. Keep variables inside functions/modules.

[!] Thinking var is block-scoped: var ignores if/for blocks; only let and const respect block scope.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Scope controls variable visibility and lifetime.
• let and const provide block scope; functions create private function scopes.
• The scope chain searches outwards from inner to outer until the global scope is reached.
