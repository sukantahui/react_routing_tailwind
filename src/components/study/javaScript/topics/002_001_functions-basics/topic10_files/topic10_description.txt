3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is Currying?
Transforming a function with multiple arguments (e.g. f(a, b, c)) into a sequence of nesting functions that each take a single argument (e.g. f(a)(b)(c)).

2. What is Partial Application?
Fixing a few arguments of a function in advance, producing a new function that takes the remaining arguments.

3. Benefits of Currying:
- Highly reusable, configurable functions.
- Eliminates parameter repetition.
- Makes functional composition clean and modular.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Currying a Logger Function ---
// Curried logger: prefix => message
const createLogger = prefix => message => console.log('[' + prefix + '] ' + message);

const infoLog = createLogger('INFO');
const errorLog = createLogger('ERROR - BARRACKPORE LAB');

infoLog('Server started on port 5000');
infoLog('Student Swadeep logged in');
errorLog('Database connection timeout');

Teacher's Note on Example 1:
createLogger pre-fixes the tag prefix, returning a specialized logging function.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Over-currying simple utility functions: If a function is simple and always called with all arguments at once, standard parameters are clearer.

[!] Arity mismatch with default parameters: Automatic curry helpers rely on fn.length, which excludes default parameters.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Currying converts f(a, b) into f(a)(b).
• Partial application pre-fills some arguments to create specialized functions.
• Enables clean configurator and logging patterns.
