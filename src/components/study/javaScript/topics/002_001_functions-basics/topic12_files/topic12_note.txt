3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] RangeError: Maximum call stack size exceeded: Infinite recursion or recursion depth exceeding the V8 stack limit (~10k frames).
[!] Exponential Time Complexity (O(2^N)): Naive recursive algorithms (e.g. un-memoized Fibonacci) trigger catastrophic performance degradation.
[!] Stack Memory Exhaustion: Large objects held in recursive activation frames prevent garbage collection until the entire chain unwinds.

function findKeys(obj, prefix = "", result = []) {
  for (const [key, value] of Object.entries(obj)) {
    const path = prefix ? `${prefix}.${key}` : key;
    if (value !== null && typeof value === "object" && !Array.isArray(value)) {
      findKeys(value, path, result);
    } else {
      result.push({ path, value });
    }
  }
  return result;
}
