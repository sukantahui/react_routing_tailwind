3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] ReferenceError in Parameter Scope: Accessing a parameter to the right before it is initialized (e.g. `function(a = b, b = 1)`).
[!] arguments Object Desync in Strict Mode: In strict mode or with default parameters, modifying a parameter does not mutate `arguments[0]`.
[!] Null vs Undefined Default Bypass: Passing `null` does NOT trigger default values; only `undefined` triggers default initialization.

Q2: How does the V8 engine execute this under the hood?
A2: It resolves bindings via the Lexical Environment Record and executes on the Call Stack.

Q3: What common bug do junior developers encounter here?
A3: Mutating the arguments Object in Non-Strict Mode: In non-strict mode, reassigning parameters mutates `arguments` array indices, causing confusing side effects.

A4: Use Rest Parameters & Pure Immutability: Always collect dynamic arguments into rest arrays and treat parameters as immutable.
