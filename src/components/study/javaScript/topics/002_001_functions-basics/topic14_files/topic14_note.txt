1. TOPIC OVERVIEW & DETAILED CONCEPT DISCUSSION
--------------------------------------------------------------------------------
- Definition: Inspect and defend constructor invocations using the ES6 new.target meta-property: preventing un-newed constructor invocations, building abstract base classes, and managing instantiation.
- Classroom Experience: Abhronila called a constructor function `User('Swadeep', 'Admin')` without the `new` keyword, polluting the global `window` object with `window.name = 'Swadeep'`.
- Solution: Sukanta Hui introduced `new.target`, showing that inside a function invoked with `new`, `new.target` references the constructor function; when called normally, it is `undefined`.
- Core Invariant: Understanding this topic guarantees predictable runtime execution

3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] SyntaxError Outside Functions: Using `new.target` in top-level script code outside of a function or class constructor throws SyntaxError.
[!] Global Mutation on Un-Newed Call: In non-strict mode, calling a constructor without `new` mutates the global object.
[!] Abstract Class Instantiation Error: Instantiating an abstract class directly should throw a custom Error when `new.target === AbstractClass`.
