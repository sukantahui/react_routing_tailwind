1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a freelance doctor in Barrackpore who has medical knowledge and tools, but works across 3 different hospitals (Hospital A, Hospital B, Hospital C). When the doctor enters Hospital A, they operate on Hospital A's patients. In JavaScript, call(), apply(), and bind() allow a function to borrow an object and execute in that object's context (this).

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The 'this' Context Problem:
Normally, a method's 'this' points to the object before the dot (e.g. student.print()). But standalone functions default their 'this' to undefined (strict mode) or window.

2. The Three Context Modifiers:
- call(thisArg, arg1, arg2, ...): Invokes the function IMMEDIATELY with 'this' explicitly set to thisArg. Arguments are passed individually.
- apply(thisArg, [argsArray]): Invokes the function IMMEDIATELY with 'this' set to thisArg. Arguments are passed as an Array.
- bind(thisArg, arg1, ...): Does NOT invoke the function immediately! Returns a brand new function with 'this' permanently bound to thisArg for future execution.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Using call, apply, and bind ---
function introduce(greeting, city) {
  console.log(greeting + '! My name is ' + this.name + ' from ' + city + '.');
}

const student1 = { name: 'Swadeep' };
const student2 = { name: 'Tuhina' };

// 1. call (arguments comma-separated):
introduce.call(student1, 'Hello', 'Barrackpore');

// 2. apply (arguments in an array):
introduce.apply(student2, ['Namaste', 'Kolkata']);

// 3. bind (returns a new bound function for later):
const introduceSwadeep = introduce.bind(student1, 'Welcome');
introduceSwadeep('Shibtala Lab');

Teacher's Note on Example 1:
call and apply execute immediately; bind returns a permanently bound reusable function.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using call/apply on Arrow Functions: Arrow functions have lexical 'this' that can never be overridden by call, apply, or bind!

[!] Confusing call with apply: Remember: Call is Comma-separated; Apply takes an Array.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• call(this, a, b) invokes immediately with individual arguments.
• apply(this, [a, b]) invokes immediately with an array of arguments.
• bind(this, a) returns a new function with locked 'this' context for later execution.
