1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a backpack that you carry with you everywhere you go. Even after you leave your school building (the outer function finishes executing and is destroyed), everything you packed inside your backpack (variables from the outer scope) stays safely with you wherever you travel. A Closure is a function that carries its parent scope's backpack wherever it goes in your program!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is a Closure?
A closure is the combination of a function bundled together with references to its surrounding state (its Lexical Environment). In JavaScript, every function forms a closure over its lexical parent scope.

2. Why Closures are Magical:
Even after an outer function has returned and its execution context has been popped off the Call Stack, any inner functions that reference outer variables keep that Environment Record alive in the Memory Heap.

3. Practical Real-World Uses:
- Data Privacy (Private variables)
- Factory Functions
- Event Handlers & Callbacks retaining state
- Function Currying & Memoization

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Private Bank Account via Closure ---
function createBankAccount(initialDeposit) {
  let balance = initialDeposit; // Private state protected by closure!
  
  return {
    checkBalance: () => 'Current Balance: ₹' + balance,
    deposit: amount => {
      balance += amount;
      return 'Deposited: ₹' + amount;
    },
    withdraw: amount => {
      if (amount > balance) return 'Insufficient funds!';
      balance -= amount;
      return 'Withdrew: ₹' + amount;
    }
  };
}

const account = createBankAccount(2000);
console.log(account.deposit(500));
console.log(account.withdraw(800));
console.log(account.checkBalance()); // ₹1700

Teacher's Note on Example 1:
The returned methods form closures over the private 'balance' variable.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accidental memory leaks: Retaining massive data in closures when they are no longer needed prevents garbage collection.

[!] The classic for-loop var closure trap: Using var in loops causes all callbacks to share the same variable; always use let!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• A closure allows an inner function to access an outer function's scope even after the outer function has closed.
• Enables true data privacy and encapsulation in JavaScript.
• Closures are one of JavaScript's most powerful architectural features.
