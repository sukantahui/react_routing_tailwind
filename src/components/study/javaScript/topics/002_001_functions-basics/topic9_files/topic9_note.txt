3. EXCEPTIONS, CORNER CASES, COERCIONS & QUIRKS
--------------------------------------------------------------------------------
[!] Memory Leak via Unreleased Handlers: Closures registered as event listeners or timers retain entire outer scope references if never unregistered.
[!] Accidental Variable Sharing: Multiple closures created in the same scope share the exact same mutable variable binding.
[!] Circular Reference Traps: Closures capturing DOM elements while DOM elements reference the closure function can delay cleanup in older engines.
