3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. JSON.stringify(value, replacer, space):
Converts JavaScript objects into standard JSON strings.
- `replacer`: An array of allowed keys or a filter function `(key, val) => ...`.
- `space`: Number of indentation spaces for pretty-printing (e.g. `2` or `4`).

2. JSON.parse(text, reviver):
Parses a JSON string back into a JavaScript object.
- `reviver`: Transformation function `(key, val) => ...` to revive Dates, BigInts, or custom classes.

3. JSON Limitations:
JSON cannot natively serialize Functions, `undefined`, `Symbol`, or Circular References.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: JSON Pretty Printing, Filtering Replacer & Date Reviver ---
const studentRecord = {
  id: 101,
  name: 'Swadeep',
  secretPin: '4091',
  joinedAt: new Date()
};

// 1. Stringify with whitelist replacer (hide secretPin) & 2-space indentation:
const jsonStr = JSON.stringify(studentRecord, ['id', 'name', 'joinedAt'], 2);
console.log('Pretty JSON:\n' + jsonStr);

// 2. Parse back with reviver to reconstruct Date object:
const parsed = JSON.parse(jsonStr, (key, value) => {
  if (key === 'joinedAt') return new Date(value);
  return value;
});

console.log('Revived Year:', parsed.joinedAt.getFullYear());

Teacher's Note on Example 1:
Replacers and revivers enable custom filtering and accurate type reconstruction.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Circular JSON reference error: `const a = {}; a.self = a; JSON.stringify(a);` throws TypeError: Converting circular structure to JSON.

[!] Losing undefined and functions: Properties with `undefined` or function values are silently omitted by `JSON.stringify()`.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• `JSON.stringify()` converts objects to JSON strings with replacer and indentation options.
• `JSON.parse()` parses JSON strings with revivers for restoring complex types.
• Universal data interchange format for REST APIs and file storage.
