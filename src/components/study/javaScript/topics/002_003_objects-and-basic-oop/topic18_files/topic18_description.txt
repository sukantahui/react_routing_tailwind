3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Private Class Fields (#name) [ES2022]:
- Declared with a leading `#` symbol before the constructor.
- 100% inaccessible and invisible from outside the class body.
- Cannot be accessed via bracket notation (`obj['#field']` does NOT work!).

2. Private Methods & Accessors:
- Private method: `#calculateInternalTax() { ... }`
- Private getter/setter: `get #secret() { ... }`

3. Hard Privacy vs Soft Privacy:
- Soft privacy (`_name`): A naming convention only; completely public at runtime.
- Hard privacy (`#name`): Enforced at the engine compiler level by V8.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: True Encapsulation with Private Fields and Methods ---
class SecureAccount {
  // Private field:
  #balance = 0;
  #accountNumber;
  
  constructor(accNum, initialDeposit) {
    this.#accountNumber = accNum;
    this.#balance = initialDeposit;
  }
  
  deposit(amount) {
    if (amount <= 0) throw new Error('Deposit must be positive');
    this.#balance += amount;
    this.#logTransaction('DEPOSIT', amount);
    return `Deposited ₹${amount}`;
  }
  
  getBalance() {
    return `Account ${this.#accountNumber} Balance: ₹${this.#balance}`;
  }
  
  // Private helper method:
  #logTransaction(type, amount) {
    console.log(`[AUDIT LOG] ${type}: ₹${amount}`);
  }
}

const acc = new SecureAccount('AC-9942', 5000);
acc.deposit(1500);
console.log(acc.getBalance());
// acc.#balance; // SyntaxError: Private field '#balance' must be declared in an enclosing class!

Teacher's Note on Example 1:
Private fields with # are strictly inaccessible from outside the class.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accessing private field with brackets: `obj['#field']` returns undefined; private fields are NOT standard object properties.

[!] Accessing private field on un-instantiated objects: Throws a TypeError.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Private fields (`#prop`) provide compile-time hard encapsulation in JavaScript.
• Private methods (`#method()`) encapsulate internal helper logic.
• Replaces old soft underscore `_prop` conventions with true language-level security.
