1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine holding two identical physical ₹100 currency notes. If you ask 'Are these the exact same physical piece of paper?' (Reference Equality: `===`), the answer is NO. But if you ask 'Do they hold the exact same monetary value and serial characteristics?' (Deep Structural Equality: `deepEqual`), the answer is YES. In JavaScript, comparing objects by value requires recursive Deep Equality verification!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Reference vs Value Equality:
- `obj1 === obj2`: Tests if both variables point to the EXACT same memory address in the Heap.
- Deep Equality: Recursively inspects that both objects have the exact same keys, values, nested objects, and arrays.

2. The Deep Equal Algorithm Steps:
1. If `a === b`, return true (handles identical primitives and identical references).
2. If either is null or not an object, return false.
3. Compare `Object.keys(a).length === Object.keys(b).length`.
4. For every key in `a`, check if `key in b` and recursively evaluate `deepEqual(a[key], b[key])`.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Recursive Deep Equality Function ---
function deepEqual(objA, objB) {
  // 1. Primitive / identical reference equality:
  if (objA === objB) return true;
  
  // 2. Null or non-object checks:
  if (objA === null || typeof objA !== 'object' ||
      objB === null || typeof objB !== 'object') {
    return false;
  }
  
  // 3. Compare key counts:
  const keysA = Object.keys(objA);
  const keysB = Object.keys(objB);
  if (keysA.length !== keysB.length) return false;
  
  // 4. Recursively verify all keys and values:
  for (let key of keysA) {
    if (!Object.hasOwn(objB, key)) return false;
    if (!deepEqual(objA[key], objB[key])) return false;
  }
  
  return true;
}

const record1 = { name: 'Swadeep', scores: [90, 95], details: { city: 'Barrackpore' } };
const record2 = { name: 'Swadeep', scores: [90, 95], details: { city: 'Barrackpore' } };

console.log('Strict === comparison:', record1 === record2); // false
console.log('Deep Equality check:', deepEqual(record1, record2)); // true!

Teacher's Note on Example 1:
Recursive deep equality verifies nested structures and primitive values thoroughly.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Circular references in deep comparison: Objects referencing themselves (`a.self = a`) cause infinite recursive stack overflows unless a WeakSet is used to track visited objects.

[!] Comparing Dates and RegExps: Dates must be compared via `getTime()`.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• `===` compares object memory references; `deepEqual` compares nested values.
• Recursive key-by-key comparison verifies structural equivalence.
• Essential for unit testing, state diffing, and caching algorithms.
