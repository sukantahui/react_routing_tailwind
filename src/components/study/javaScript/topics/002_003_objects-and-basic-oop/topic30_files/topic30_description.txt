1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a physical student file cabinet in the school registrar's office. Whenever a student registers, you store their file in the cabinet so it survives when the office closes for the night. Web Storage (`localStorage`) is that browser file cabinet that preserves user preferences, carts, and authentication tokens across browser restarts!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Abhronila saved an array of students to `localStorage`: `localStorage.setItem('students', students)`. When she read it back with `localStorage.getItem('students')`, it returned `'[object Object]'`! She cried: 'Where did my students go?' I explained that `localStorage` ONLY stores strings! If you don't serialize with `JSON.stringify()`, JavaScript coerces the object to a broken string. We built a clean `StorageWrapper` class that automatically stringifies and parses JSON safely.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Web Storage Fundamentals:
- `localStorage`: Persists data permanently with no expiration date across browser restarts (~5MB limit per origin).
- `sessionStorage`: Persists data only for the duration of the current browser tab session.

2. Key Methods:
- `setItem(key, stringValue)`
- `getItem(key)`
- `removeItem(key)`
- `clear()`

3. Safe Serialization Wrapper Pattern:
A typed helper module that wraps `try...catch`, automatic JSON serialization, and fallback handling.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Robust LocalStorage JSON Wrapper ---
const Storage = {
  set(key, value) {
    try {
      const serialized = JSON.stringify(value);
      // localStorage.setItem(key, serialized);
      console.log(`[Storage] Saved ${key} ->`, serialized);
    } catch (err) {
      console.error('Storage serialization failed:', err);
    }
  },
  
  get(key, fallbackValue = null) {
    try {
      // const item = localStorage.getItem(key);
      const item = JSON.stringify({ name: 'Swadeep', roll: 101 }); // Mocking storage read
      return item ? JSON.parse(item) : fallbackValue;
    } catch (err) {
      console.error('Storage parse failed:', err);
      return fallbackValue;
    }
  }
};

Storage.set('activeUser', { name: 'Swadeep', role: 'Student' });
console.log('Retrieved User:', Storage.get('activeUser'));

Teacher's Note on Example 1:
Storage wrappers ensure consistent JSON serialization and error resilience.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Storing un-serialized objects: `localStorage.setItem('key', obj)` saves `'[object Object]'`. Always use `JSON.stringify()`.

[!] QuotaExceededError: LocalStorage has a ~5MB limit; catching errors prevents storage crashes when disk is full.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Web Storage stores key-value strings permanently (localStorage) or per session (sessionStorage).
• Always serialize objects with `JSON.stringify()` before saving.
• Use helper wrappers with `try...catch` for reliable parsing and fallback handling.
