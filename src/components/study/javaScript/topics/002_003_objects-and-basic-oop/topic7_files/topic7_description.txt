1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about duplicating a student identity card. If you photocopy the paper card, you get an independent sheet. But if the card has a physical key attached with a string (a nested object reference), copying the card still leaves both cards tethered to the exact same physical key! That is the difference between Shallow Copy and Deep Copy.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Swadeep cloned a student profile using object spread: `let copy = { ...student };`. When he changed `copy.name = 'Swadeep Pro'`, the original stayed safe. But when he changed `copy.marks.math = 100`, the original student's math marks changed to 100 too! Swadeep asked why. I demonstrated how spread only copies the top-level keys; nested objects remain shared memory references in the heap. I introduced `structuredClone()` to create 100% independent deep copies.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Shallow Copy (Spread `{ ...obj }` or `Object.assign({}, obj)`):
- Copies top-level primitive properties by value.
- Copies nested object/array properties by reference (shared pointers).

2. Deep Copy (structuredClone(obj)) — Modern Standard:
- Recursively clones every nested level in memory.
- Guarantees complete isolation of nested objects and arrays.

3. When to Use Which:
- Use Spread `{ ...obj }` for flat objects (1 level deep).
- Use `structuredClone(obj)` whenever objects contain nested objects, arrays, or Dates.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Shallow Copy vs Deep Clone ---
const original = {
  name: 'Swadeep',
  scores: { math: 85, js: 92 }
};

// 1. Shallow Copy with Spread
const shallow = { ...original };
shallow.scores.math = 99; // Mutates original.scores too!
console.log('Original math after shallow update:', original.scores.math); // 99 (Unintended side effect!)

// 2. Deep Copy with structuredClone
const deep = structuredClone(original);
deep.scores.math = 70; // Safe!
console.log('Original math after deep update:', original.scores.math); // 99 (Untouched!)

Teacher's Note on Example 1:
structuredClone protects nested state from unintended shared mutations.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming spread deep copies: Spread is strictly 1-level shallow.

[!] Using JSON.parse(JSON.stringify(obj)): Corrupts Date objects to strings and deletes functions/undefined. Always use structuredClone.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Spread `{ ...obj }` is fast and ideal for flat objects.
• Use `structuredClone(obj)` for nested object structures.
• Preventing shared reference mutations is critical in React and state management.
