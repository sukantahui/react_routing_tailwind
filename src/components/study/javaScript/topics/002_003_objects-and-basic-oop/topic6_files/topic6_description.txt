3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Object Reflection Methods:
- Object.keys(obj): Returns an array of own enumerable property names (strings).
- Object.values(obj): Returns an array of own enumerable property values.
- Object.entries(obj): Returns an array of `[key, value]` pairs.
- Object.fromEntries(iterable): Transforms an array of `[key, value]` pairs back into an Object!

2. Why Prefer Object.entries() over for...in:
`for...in` iterates over inherited prototype properties and requires `Object.hasOwn` guards. `Object.entries()` returns a clean array containing only own properties that works directly with modern array methods.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Converting, Transforming, and Reconstructing Objects ---
const coursePrices = {
  JavaScript: 4000,
  React: 5500,
  NodeJS: 5000
};

// 1. Get all keys and values:
console.log('Courses:', Object.keys(coursePrices));   // ['JavaScript', 'React', 'NodeJS']
console.log('Prices:', Object.values(coursePrices));   // [4000, 5500, 5000]

// 2. Transform Object via entries → map → fromEntries (Add 10% tax):
const pricesWithTax = Object.fromEntries(
  Object.entries(coursePrices).map(([course, price]) => [course, price * 1.10])
);

console.log('Prices with Tax:', pricesWithTax);

Teacher's Note on Example 1:
Object.entries and fromEntries enable full functional transformations on objects.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming Object.keys preserves numeric insertion order: JavaScript sorts numeric keys in ascending order first before string keys.

[!] Using for...in without prototype guards: Always prefer Object.keys() or Object.entries() for reliable iteration.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Object.keys(), Object.values(), and Object.entries() convert objects into arrays.
• Object.fromEntries() converts [key, value] pairs back into an object.
• Essential for transforming, filtering, and mapping dictionary objects.
