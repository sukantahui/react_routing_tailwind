3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is the `instanceof` Operator?
`obj instanceof Constructor` returns `true` if `Constructor.prototype` appears anywhere in the prototype chain of `obj`.

2. How It Works Internally:
Walks up `Object.getPrototypeOf(obj)` comparing against `Constructor.prototype` until it finds a match or reaches `null`.

3. Customizing instanceof with Symbol.hasInstance (ES6):
You can customize `instanceof` behavior for any class by defining a static `[Symbol.hasInstance](instance)` method!

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Verifying Hierarchy with instanceof ---
class Person {}
class Student extends Person {}
class Instructor extends Person {}

const swadeep = new Student();

console.log(swadeep instanceof Student);    // true
console.log(swadeep instanceof Person);     // true (Inherits from Person)
console.log(swadeep instanceof Instructor); // false
console.log(swadeep instanceof Object);     // true (Everything inherits from Object)

Teacher's Note on Example 1:
instanceof traverses the prototype chain to verify inheritance ancestry.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Cross-realm iframe trap: An array created inside an iframe will return `arr instanceof Array === false` in the parent window because each window has its own distinct `Array.prototype`! Always use `Array.isArray(arr)` for arrays.

[!] Primitive values with instanceof: `'hello' instanceof String` is `false` (primitives are not object instances).

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• `obj instanceof Class` checks if `Class.prototype` exists in `obj`'s prototype chain.
• Returns true for direct instances and all inherited parent superclasses.
• Use `Array.isArray()` instead of `instanceof Array` to prevent cross-frame bugs.
