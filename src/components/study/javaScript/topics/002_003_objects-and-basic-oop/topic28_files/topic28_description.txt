1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about updating your user profile on a website. You submit a partial update: `{ contact: { phone: '9876543210' } }`. You don't want the server to delete your existing `email` and `city` inside the contact object! If you use shallow `Object.assign()`, the nested `contact` object gets completely overwritten. You need Deep Recursive Merging to merge nested properties cleanly without losing existing data!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Tuhina had default app settings: `{ theme: 'dark', notifications: { email: true, sms: false } }`. A user submitted an update `{ notifications: { sms: true } }`. When Tuhina used `{ ...defaultSettings, ...userSettings }`, the new notifications object completely wiped out `email: true`! I taught her Deep Merging: recursively traversing nested objects so only modified sub-keys are updated while preserving untouched sub-keys.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Shallow Merge vs Deep Merge:
- Shallow Merge (`Object.assign({}, a, b)`): Replaces entire top-level properties. If `b.contact` exists, `a.contact` is completely replaced.
- Deep Merge: If both `a[key]` and `b[key]` are objects, it merges their inner keys recursively.

2. Practical Uses:
- Merging user preferences with default configurations.
- Applying partial updates (PATCH requests) to application state.
- Managing complex multi-level settings hierarchies.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Recursive Deep Merge Function ---
function deepMerge(target, source) {
  const output = { ...target };
  
  for (let key in source) {
    if (Object.hasOwn(source, key)) {
      if (source[key] && typeof source[key] === 'object' && !Array.isArray(source[key])) {
        output[key] = deepMerge(target[key] ?? {}, source[key]);
      } else {
        output[key] = source[key];
      }
    }
  }
  return output;
}

const defaultCfg = { theme: 'dark', alert: { sound: true, email: true } };
const userPatch = { alert: { sound: false } };

const finalCfg = deepMerge(defaultCfg, userPatch);
console.log('Merged Config:', finalCfg);
// { theme: 'dark', alert: { sound: false, email: true } } (email preserved!)

Teacher's Note on Example 1:
Deep merge preserves untouched nested properties while updating specified overrides.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Overwriting arrays in deep merges: Decide whether arrays should be concatenated `[...a, ...b]` or replaced `b` based on business requirements.

[!] Mutating the target object: Always build and return a fresh merged copy.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Deep merging recursively merges nested objects without overwriting sibling keys.
• Essential for configuration defaults, partial state patching, and settings managers.
• Always preserve immutability by returning a fresh clone.
