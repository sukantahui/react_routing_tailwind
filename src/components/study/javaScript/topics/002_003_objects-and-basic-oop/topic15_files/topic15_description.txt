3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is an ES6 Class?
Introduced in ES6 (2015), `class` provides clean, declarative syntax for constructor functions and prototypal inheritance.

2. Anatomy of a Class:
- `constructor(...args)`: The initialization method invoked by `new`.
- Instance Methods: Methods placed directly inside the class body are automatically attached to `Class.prototype`!
- Class Expressions: `const Student = class { ... };`.

3. Key Class Invariants:
- Classes ALWAYS execute in Strict Mode (`'use strict'`).
- Classes are NOT hoisted (must be declared before instantiation).
- Classes CANNOT be called without `new` (throws `TypeError: Class constructor cannot be invoked without 'new'`).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Building an ES6 Student Class ---
class LabStudent {
  constructor(name, roll, course) {
    this.name = name;
    this.roll = roll;
    this.course = course;
    this.isEnrolled = true;
  }
  
  // Automatically attached to LabStudent.prototype:
  getSummary() {
    return `${this.name} (Roll #${this.roll}) - Enrolled in ${this.course}`;
  }
  
  markAbsent() {
    this.isEnrolled = false;
    return `${this.name} marked inactive.`;
  }
}

const student = new LabStudent('Swadeep', 101, 'JavaScript Pro');
console.log(student.getSummary());
console.log('Is method on prototype?', student.getSummary === LabStudent.prototype.getSummary); // true

Teacher's Note on Example 1:
ES6 class methods are automatically added to the class prototype cleanly.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Calling a class without `new`: `const s = LabStudent('Swadeep')` throws a TypeError. Classes strictly enforce `new`.

[!] Expecting class declarations to be hoisted: Unlike function declarations, class declarations cannot be accessed before their declaration line.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• ES6 classes provide modern, readable syntax over prototypal inheritance.
• Methods defined inside class bodies are automatically attached to the prototype.
• Classes strictly require `new` and run in strict mode automatically.
