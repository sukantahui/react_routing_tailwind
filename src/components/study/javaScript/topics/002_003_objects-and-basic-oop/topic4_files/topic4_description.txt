3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Optional Chaining (?.) [ES2020]:
Short-circuits and returns `undefined` if the operand before `?.` is `null` or `undefined`, preventing runtime crashes.
- Property access: `obj?.prop`
- Bracket access: `obj?.[dynamicKey]`
- Method invocation: `obj?.method?.()`

2. Nullish Coalescing (??) Pairing:
Combine `?.` with `??` to provide safe default values whenever optional chaining resolves to undefined or null.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Safe Deep Navigation with ?. and ?? ---
const studentRecord = {
  name: 'Swadeep',
  contact: {
    email: 'swadeep@lab.com'
    // address is missing
  }
};

// Safe navigation with fallback:
const city = studentRecord?.contact?.address?.city ?? 'Barrackpore Lab (Default)';
console.log('City:', city); // 'Barrackpore Lab (Default)'

// Safe method execution:
const result = studentRecord?.sendEmail?.() ?? 'No notification method available';
console.log('Method Result:', result);

Teacher's Note on Example 1:
Optional chaining halts evaluation safely when meeting null/undefined.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Overusing ?. on guaranteed references: Only use `?.` on references that might actually be null or undefined. Overusing it masks underlying architectural bugs.

[!] Using ?. for assignment: Writing `obj?.prop = 5;` is a SyntaxError (invalid left-hand side assignment).

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Optional Chaining `?.` prevents 'Cannot read properties of undefined' crashes.
• Works with properties `?.prop`, brackets `?.[key]`, and methods `?.()`.
• Pair `?.` with `??` for resilient defensive data retrieval.
