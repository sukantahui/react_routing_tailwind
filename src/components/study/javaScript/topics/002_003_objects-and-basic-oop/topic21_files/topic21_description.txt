3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The 4 Pillars of OOP:
1. Encapsulation: Bundling data and methods together inside objects while hiding internal private state (`#fields`).
2. Abstraction: Hiding internal complexity and exposing only a clean, simple public interface.
3. Inheritance: Reusing existing code and establishing parent-child relationships (`extends`).
4. Polymorphism: Allowing different classes to implement the same interface with customized behaviors.

2. Clean Code Invariant:
Design objects so they are self-contained, cohesive, and protect their own internal invariants.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: The 4 Pillars in a Unified System ---
// 1. Abstraction & Encapsulation
class DigitalWallet {
  #balance = 0; // Encapsulated private state
  
  deposit(amt) {
    if (amt > 0) this.#balance += amt;
  }
  
  // Abstracted simple interface (hides raw calculation):
  getBalance() {
    return `₹${this.#balance}`;
  }
}

// 3. Inheritance & 4. Polymorphism
class PremiumWallet extends DigitalWallet {
  deposit(amt) {
    super.deposit(amt * 1.05); // 5% cashback bonus on deposit!
  }
}

const wallet = new PremiumWallet();
wallet.deposit(1000);
console.log('Wallet Balance:', wallet.getBalance()); // '₹1050'

Teacher's Note on Example 1:
Demonstrates encapsulation (#balance), abstraction (getBalance), inheritance (extends), and polymorphism (overridden deposit).

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Over-engineering simple tasks: Don't create 5 levels of class hierarchies for a 3-line calculation; use pure functions where appropriate.

[!] Leaking internal state: Never expose raw mutable arrays or internal references directly without defensive copies.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Encapsulation protects private state; Abstraction exposes simple interfaces.
• Inheritance reuses common behavior; Polymorphism allows specialized responses.
• The 4 pillars guide scalable enterprise software architecture.
