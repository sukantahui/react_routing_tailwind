3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is a Proxy?
An object that wraps another target object and intercepts fundamental operations (property lookup, assignment, enumeration, function invocation) using 'Traps'.

2. The Traps Architecture:
- `get(target, prop, receiver)`: Intercepts reading properties.
- `set(target, prop, val, receiver)`: Intercepts writing properties.
- `has(target, prop)`: Intercepts the `in` operator.
- `deleteProperty(target, prop)`: Intercepts `delete`.
- `apply(target, thisArg, args)`: Intercepts function calls.

3. The Reflect API:
A built-in global object that provides methods for interceptable JavaScript operations, mirroring proxy traps with matching signatures (e.g. `Reflect.set(target, prop, val)`).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Dynamic Validation and Auditing with Proxy & Reflect ---
const student = { name: 'Swadeep', marks: 85 };

const auditedStudent = new Proxy(student, {
  get(target, prop) {
    console.log(`[ACCESS LOG] Reading property: ${String(prop)}`);
    return Reflect.get(target, prop);
  },
  set(target, prop, value) {
    if (prop === 'marks' && (value < 0 || value > 100)) {
      throw new RangeError('Marks must be between 0 and 100!');
    }
    console.log(`[AUDIT LOG] Setting ${String(prop)} = ${value}`);
    return Reflect.set(target, prop, value);
  }
});

console.log(auditedStudent.name);
auditedStudent.marks = 95;
// auditedStudent.marks = 150; // Throws RangeError!

Teacher's Note on Example 1:
Proxies intercept low-level operations for reactivity, logging, and validation.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Forgetting to return a boolean from set trap: The `set` trap MUST return `true` to signal success in strict mode; returning false or undefined throws a TypeError.

[!] Proxy identity comparison: `proxy === target` is `false` because the proxy is a wrapper object.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Proxy wraps objects to intercept and customize low-level engine operations.
• Reflect provides standardized counterparts for forwarding trapped calls.
• The underlying engine behind modern reactivity (Vue 3, MobX, validation layers).
