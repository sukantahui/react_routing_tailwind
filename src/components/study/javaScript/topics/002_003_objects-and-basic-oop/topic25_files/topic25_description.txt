3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Symbols as Object Keys:
- Guaranteed unique: `const id = Symbol('id'); obj[id] = 123;`
- Hidden from `Object.keys()` and `for...in` (accessible only via `Object.getOwnPropertySymbols()`).

2. Well-Known Symbols (Customizing Engine Protocols):
- Symbol.iterator: Defines the default iterator for `for...of` and spread `[...]`.
- Symbol.toPrimitive: Customizes how an object converts to a primitive (number, string, default).
- Symbol.toStringTag: Customizes `Object.prototype.toString.call(obj)` output.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Making a Custom Object Iterable with Symbol.iterator ---
const codingBatch = {
  batchName: 'Barrackpore JS Masterclass',
  students: ['Swadeep', 'Tuhina', 'Abhronila', 'Debangshu'],
  
  // Well-Known Symbol for Iteration Protocol:
  *[Symbol.iterator]() {
    for (let student of this.students) {
      yield student;
    }
  }
};

// Custom object now iterates seamlessly in for...of!
for (let student of codingBatch) {
  console.log('Enrolled:', student);
}

Teacher's Note on Example 1:
Symbol.iterator enables native for...of iteration on custom objects.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] JSON.stringify ignores Symbols: Symbols as keys or values are omitted by JSON.stringify().

[!] Using `new Symbol()`: Symbol is a primitive factory, not a constructor. Writing `new Symbol()` throws a TypeError.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Symbols prevent property key collisions in libraries and plugins.
• Well-Known Symbols (`Symbol.iterator`, `Symbol.toPrimitive`) hook into engine protocols.
• Inspect symbol keys using `Object.getOwnPropertySymbols(obj)`.
