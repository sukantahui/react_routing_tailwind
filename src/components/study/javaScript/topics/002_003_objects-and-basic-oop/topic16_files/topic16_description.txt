1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a factory that manufactures automobiles. An individual car has its own license plate, color, and odometer mileage (Instance properties). But the factory office itself keeps track of the 'Total Number of Cars Manufactured Worldwide' (Static property). You don't ask an individual car for the total worldwide manufacturing count; you ask the factory directly! In JavaScript, `static` properties and methods belong to the Class itself, not to individual instances.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What are Static Members?
Properties and methods defined with the `static` keyword that are attached directly to the constructor function/class object itself, rather than to instances.
- Called directly on the class: `ClassName.staticMethod()`.
- Not accessible via `instance.staticMethod()`.

2. Common Uses of Static Members:
- Factory functions: `User.createGuest()`
- Cache registries: `Student.allEnrolled`
- Mathematical / utility helpers: `Math.max()`, `Number.isNaN()`

3. Static Initialization Blocks (ES2022):
`static { ... }` runs once when the class is loaded to perform complex static configuration.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Class Counter & Static Factory Method ---
class StudentAccount {
  // Static property shared across the entire class:
  static totalAccounts = 0;
  
  constructor(name, initialDeposit) {
    this.name = name;
    this.balance = initialDeposit;
    StudentAccount.totalAccounts += 1; // Increment class counter
  }
  
  // Static Factory Method:
  static createTrialAccount(name) {
    return new StudentAccount(name, 500); // Gives ₹500 starter bonus
  }
}

const acc1 = new StudentAccount('Swadeep', 2000);
const acc2 = StudentAccount.createTrialAccount('Tuhina');

console.log('Total Accounts Created:', StudentAccount.totalAccounts); // 2
console.log('Tuhina Balance:', acc2.balance); // 500

Teacher's Note on Example 1:
Static methods and properties live on the class constructor itself.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accessing static methods from an instance: `acc1.createTrialAccount()` throws a TypeError (undefined). Always call via `StudentAccount.createTrialAccount()`.

[!] `this` inside static methods: Inside a static method, `this` points to the Class itself, not an instance.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Static methods and properties belong to the class, not instances.
• Ideal for factory creators, caches, and utility functions.
• Static blocks (`static { ... }`) execute once during class definition.
