1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about an entrance gate at an amusement park. If you have a valid ticket, the light turns GREEN and the gate opens. If you have an expired ticket, an empty pocket, or a counterfeit pass, the light turns RED and the gate stays locked. In JavaScript, every single value in existence—whether it is a number, a piece of text, or empty air—is treated as either Green (Truthy) or Red (Falsy) when evaluated.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Swadeep wrote an if-statement to check if a user typed their name:
let username = '';
if (username) {
  console.log('Welcome!');
} else {
  console.log('Please enter your name!');
}
He asked: 'Sir, username is a string, not a true/false boolean, so how did JavaScript know to jump to the else branch?' I wrote the famous '8 Falsy Values' on the whiteboard. I explained that an empty string "" has no content, so JavaScript automatically coerces it to false. Once Swadeep understood truthy and falsy rules, he realized he could write clean, concise guard checks without redundant code.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Pure Booleans:
A boolean has only two possible states: true or false.

2. The 8 Falsy Values in JavaScript (Memorize These!):
Everything else in JavaScript is Truthy! The only 8 values that coerce to false are:
1. false (the boolean itself)
2. 0 (the number zero)
3. -0 (negative zero)
4. 0n (BigInt zero)
5. "" or '' (empty string)
6. null (intentional absence)
7. undefined (uninitialized value)
8. NaN (Not-a-Number)

3. Truthy Values (Common Surprises):
- "0" (a string containing zero is TRUTHY because it is not empty!)
- "false" (a string containing 'false' is TRUTHY!)
- [] (empty array is TRUTHY)
- {} (empty object is TRUTHY)

4. Explicit Boolean Conversion:
Use Boolean(val) or the double exclamation mark !!val to explicitly convert any value to true or false.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Testing Truthy and Falsy Values ---
console.log(Boolean(""));        // false (empty string)
console.log(Boolean("Swadeep"));  // true (non-empty string)
console.log(Boolean(0));          // false (number zero)
console.log(Boolean(100));        // true (non-zero number)
console.log(Boolean(null));       // false (null)
console.log(Boolean("0"));        // true! (non-empty string)

Teacher's Note on Example 1:
Boolean() explicitly converts any value to true or false based on truthy/falsy rules.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming '0' or 'false' in quotes is falsy: Any non-empty string is truthy in JavaScript!

[!] Confusing empty arrays [] with falsy: Objects and arrays are always truthy.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• There are only 8 falsy values in JavaScript (false, 0, -0, 0n, '', null, undefined, NaN).
• Every other value in the entire language is truthy.
• Use !!val or Boolean(val) for explicit conversion.
