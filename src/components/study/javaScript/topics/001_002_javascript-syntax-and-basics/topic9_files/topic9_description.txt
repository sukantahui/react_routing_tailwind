1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a currency exchange counter where you deliberately hand over cash and ask for Euros (Explicit Conversion). Compare that to buying groceries where the shopkeeper automatically assumes your pocket coupon can be converted to 50 rupees without asking you (Implicit Coercion). In JavaScript, Explicit Conversion is safe and predictable; Implicit Coercion can produce surprising quirks if not understood!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Abhronila had `'10' + 20` resulting in `'1020'`, while `'10' - 5` resulted in `5`! She asked: 'Why did plus concatenate but minus subtract?' I explained the Coercion Algorithm on the whiteboard: The `+` operator prefers String concatenation if either operand is text, whereas `-`, `*`, `/` only exist in mathematics and always coerce strings to Numbers. I taught the class to always use explicit conversions (`Number(x)`, `String(x)`, `Boolean(x)`).

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Explicit Conversion (Best Practice):
- `Number('42')` → 42
- `String(100)` → '100'
- `Boolean(1)` → true

2. Implicit Coercion Rules:
- String Coercion: `str + any` → converts any to string.
- Number Coercion: `str - num`, `str * num` → converts str to number.
- Boolean Coercion: In `if (val)`, evaluates truthy/falsy rules.

3. Common Coercion Quirks:
- `+true` → 1, `+false` → 0, `+null` → 0, `+undefined` → NaN.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Explicit vs Implicit Conversions ---
let input = '500';

// Safe Explicit Conversion:
let numericFee = Number(input);
let totalWithFee = numericFee + 100;
console.log('Explicit Total: ₹' + totalWithFee); // ₹600

// Risky Implicit Concatenation:
let brokenTotal = input + 100;
console.log('Implicit Result:', brokenTotal); // '500100'

Teacher's Note on Example 1:
Explicit conversions prevent unintended string concatenation bugs.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Relying on implicit coercion in calculations: Always use Number(val) or parseInt(val).

[!] Converting null vs undefined: Number(null) is 0, but Number(undefined) is NaN.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Explicit conversion (`Number()`, `String()`, `Boolean()`) makes code predictable.
• The `+` operator coerces to string if one operand is a string.
• Arithmetic operators (-, *, /) always coerce operands to numbers.
