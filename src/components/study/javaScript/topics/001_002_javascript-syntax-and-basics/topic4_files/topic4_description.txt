3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Three Ways to Create Strings:
- Single quotes: 'Hello'
- Double quotes: "Hello"
- Template Literals (Backticks): `Hello ${name}`

2. Powers of Template Literals:
- String Interpolation: Inject any JavaScript variable or calculation directly using ${...}.
- Multi-line Strings: Press Enter inside backticks to create clean multi-line text without messy \n escape characters.

3. Essential String Methods:
- str.length: Returns character count.
- str.toUpperCase() / str.toLowerCase(): Changes case.
- str.trim(): Removes whitespace from ends.
- str.includes("text"): Checks if substring exists (true/false).
- str.indexOf("text"): Returns first position index.
- str.slice(start, end): Extracts a section of text.
- str.replace("old", "new"): Replaces characters.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Template Literal Formatting ---
let student = "Swadeep";
let course = "JavaScript Pro";
let fees = 5000;
let gst = fees * 0.18;

let invoice = `Receipt:
Student: ${student}
Course: ${course}
Total with 18% GST: ₹${fees + gst}`;

console.log(invoice);

Teacher's Note on Example 1:
Template literals seamlessly interpolate variables and calculations across multiple lines.

--- Example 2: Practical String Cleaning ---
let rawInput = "   barrackpore   ";
let cleanCity = rawInput.trim().toUpperCase();
console.log("Clean City:", cleanCity); // "BARRACKPORE"

Teacher's Note on Example 2:
Chaining trim() and toUpperCase() sanitizes user input.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Strings are immutable: Calling str.toUpperCase() does NOT modify the original string; it returns a brand new string.

[!] Using single or double quotes for ${...}: String interpolation ONLY works inside backticks.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Use backticks with ${...} for clean, readable string formatting.
• String methods (.trim(), .slice(), .includes()) help sanitize and inspect text.
• Strings in JavaScript can never be mutated in place; methods return new strings.
