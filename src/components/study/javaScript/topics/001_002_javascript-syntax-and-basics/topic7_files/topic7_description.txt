3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is a Symbol?
Introduced in ES6, Symbol is a primitive data type used to create guaranteed unique identifiers.

2. Creating Symbols:
const sym1 = Symbol("description");
Every call to Symbol() produces a completely distinct unique value, even with the identical description.

3. Global Symbol Registry:
- Symbol.for("key"): Searches the global registry; if it exists, it returns it; otherwise, it creates it.
- Symbol.keyFor(sym): Retrieves the string key for a global symbol.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Guaranteed Uniqueness of Symbols ---
const symA = Symbol("apiKey");
const symB = Symbol("apiKey");

console.log(symA === symB); // false! Every Symbol is unique.
console.log(typeof symA);   // "symbol"

Teacher's Note on Example 1:
Even with the same description string, symbols are completely unique and never equal.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Using new Symbol(): Symbol is a primitive factory function, not a constructor. Writing new Symbol() throws a TypeError!

[!] Expecting symbols to auto-convert to strings: String concatenation like 'ID: ' + sym throws a TypeError. Use sym.toString() or String(sym).

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Symbols are immutable, 100% unique primitive identifiers.
• They prevent key collisions in complex applications.
• Always create symbols using Symbol('desc') without the 'new' keyword.
