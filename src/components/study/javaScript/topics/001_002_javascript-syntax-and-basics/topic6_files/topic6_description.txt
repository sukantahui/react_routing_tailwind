3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Undefined (The Engine's Default):
- When a variable is declared without a value: let x; → x is undefined.
- When a function doesn't return anything, it returns undefined.

2. Null (The Developer's Choice):
- Represents the intentional absence of an object or value.
- let currentUser = null; (means 'no user is currently logged in').

3. Comparison:
- Loose Equality: null == undefined is true (both represent empty).
- Strict Equality: null === undefined is false (different types!).

4. The typeof Quirks:
- typeof undefined → "undefined"
- typeof null → "object" (Historic bug in the original C implementation of JS in 1995!).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Demonstrating Null vs Undefined ---
let studentRoll;
console.log("Unassigned variable:", studentRoll); // undefined

let selectedCourse = null;
console.log("Intentionally empty course:", selectedCourse); // null

console.log("Loose equality check:", studentRoll == selectedCourse);  // true
console.log("Strict equality check:", studentRoll === selectedCourse); // false

Teacher's Note on Example 1:
null and undefined are loosely equal in value but strictly different in type.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assigning undefined manually: Avoid doing let x = undefined. If you want to declare an empty variable, use let x = null.

[!] Relying on typeof null === 'null': typeof null returns 'object'. To check for null, write x === null.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• undefined means variable declared but not assigned a value.
• null means intentionally emptied by the developer.
• typeof null is 'object' due to a historic 1995 legacy quirk.
