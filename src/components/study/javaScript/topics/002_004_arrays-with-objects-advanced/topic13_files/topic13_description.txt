1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine sorting a delivery basket of fresh fruits into kitchen bowls: all apples in the Apple Bowl, all bananas in the Banana Bowl, all oranges in the Orange Bowl. In old JavaScript, grouping an array of items by category required writing custom reduce functions. In modern ECMAScript (ES2024), `Object.groupBy()` and `Map.groupBy()` are official built-in tools that do this in a single line!

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Abhronila had a student dataset and wanted to group students by their enrolled course ('JavaScript', 'React', 'Python'). I introduced the modern ES2024 method: `Object.groupBy(students, s => s.course)`. In one clean line, JavaScript grouped all students into `{ JavaScript: [...], React: [...] }`. Abhronila cheered: 'We don't need external libraries or custom reduce boilerplate anymore!'

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Object.groupBy(items, callbackFn) [ES2024]:
Groups elements of an iterable into a null-prototype object according to the string key returned by the callback function.

2. Map.groupBy(items, callbackFn) [ES2024]:
Groups elements into a JavaScript `Map` instance. Ideal when grouping keys are complex objects or non-string values.

3. Benefits:
- Standardized native performance.
- Eliminates third-party utility libraries (like Lodash groupBy).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Grouping Students by Course and Passing Status with Object.groupBy ---
const studentBatch = [
  { name: 'Swadeep', course: 'JavaScript', score: 85 },
  { name: 'Tuhina', course: 'React', score: 92 },
  { name: 'Abhronila', course: 'JavaScript', score: 38 },
  { name: 'Debangshu', course: 'React', score: 75 }
];

// Group by Course:
const byCourse = Object.groupBy(studentBatch, s => s.course);
console.log('Grouped by Course:', byCourse);

// Group by Pass / Fail Status:
const byPerformance = Object.groupBy(studentBatch, s => s.score >= 40 ? 'Passed' : 'NeedsHelp');
console.log('Grouped by Performance:', byPerformance);

Teacher's Note on Example 1:
Object.groupBy partitions the array into categorized object buckets.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Object.groupBy returns a null-prototype object: The returned object has no Object.prototype methods (like .hasOwnProperty).

[!] Using Object.groupBy in legacy environments: Ensure your environment supports ES2024 (Node 21+, Chrome 117+) or provide a polyfill.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Object.groupBy() groups arrays into object buckets based on string keys.
• Map.groupBy() groups into Map instances supporting arbitrary key types.
• Official ES2024 standard replacing custom reduce groupBy boilerplate.
