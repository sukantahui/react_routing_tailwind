2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Swadeep asked during lab: 'Sir, why don't we store student names in one array `['Swadeep', 'Tuhina']` and student fees in another array `[5000, 6000]`?' I explained that bundling related properties together into an Object and storing those Objects in an Array keeps data unified, relational, and 100% bug-free.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is an Array of Objects?
A collection data structure where each element in the array is a JavaScript Object containing multiple key-value pairs.

2. Real-World Schemas:
- E-commerce: Array of Products [{ id: 1, title: 'Laptop', price: 55000, stock: 12 }, ...]
- Banking: Array of Transactions [{ txnId: 'TX101', amount: 1500, type: 'CR' }, ...]
- Education: Array of Students [{ roll: 101, name: 'Swadeep', marks: 88 }, ...]

3. Schema Consistency:
In enterprise systems, every object in the collection should adhere to a consistent shape (schema), avoiding missing or differently named keys.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Modeling a Student Directory ---
const studentDirectory = [
  { id: 101, name: 'Swadeep', course: 'JavaScript', marks: 85, isPaid: true },
  { id: 102, name: 'Tuhina', course: 'React', marks: 92, isPaid: true },
  { id: 103, name: 'Abhronila', course: 'Node.js', marks: 78, isPaid: false },
  { id: 104, name: 'Debangshu', course: 'JavaScript', marks: 95, isPaid: true }
];

console.log('Total Enrolled Students:', studentDirectory.length); // 4
console.log('First Student Course:', studentDirectory[0].course); // 'JavaScript'

Teacher's Note on Example 1:
An array of objects models structured records with clear relational attributes.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Inconsistent key names: Having { name: 'A' } in one object and { studentName: 'B' } in another breaks iteration loops.

[!] Parallel arrays anti-pattern: Never use separate arrays for related attributes (e.g. names[], ages[]); always use an array of objects.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Arrays of objects represent database records, tables, and API responses.
• Each object represents an entity; the array represents the collection.
• Maintain consistent schemas across all objects in the collection.
