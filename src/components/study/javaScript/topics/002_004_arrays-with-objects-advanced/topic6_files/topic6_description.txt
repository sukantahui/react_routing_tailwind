3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. What is a Frequency Counter?
A pattern that uses an object dictionary `{ [key]: count }` to tally occurrences of items, categories, or status values across a dataset in single-pass O(N) time.

2. The Core Idiom:
`acc[key] = (acc[key] ?? 0) + 1`
- If key doesn't exist yet, it defaults to 0 and adds 1.
- If key exists, it increments the existing count.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Course Enrollment & City Frequency Distribution ---
const enrollments = [
  { name: 'Swadeep', city: 'Barrackpore', course: 'JS' },
  { name: 'Tuhina', city: 'Kolkata', course: 'React' },
  { name: 'Abhronila', city: 'Barrackpore', course: 'JS' },
  { name: 'Debangshu', city: 'Shyamnagar', course: 'React' },
  { name: 'Sourav', city: 'Barrackpore', course: 'JS' }
];

// Tally students by city:
const cityDistribution = enrollments.reduce((acc, { city }) => {
  acc[city] = (acc[city] ?? 0) + 1;
  return acc;
}, {});

console.log('City Distribution:', cityDistribution);
// { Barrackpore: 3, Kolkata: 1, Shyamnagar: 1 }

Teacher's Note on Example 1:
reduce accumulates categorical counts into a clean distribution histogram.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accessing undefined properties without fallback: Writing `acc[key] += 1` when `acc[key]` is undefined results in `NaN`! Always use `(acc[key] ?? 0) + 1`.

[!] Using Object keys with numbers: Numeric object keys are sorted in ascending order by JavaScript engines.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Frequency counters count category occurrences in single-pass O(N) time.
• The pattern `acc[key] = (acc[key] ?? 0) + 1` creates self-initializing tally objects.
• Essential for dashboards, reports, analytics, and interview coding challenges.
