1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine a hospital patient directory with 2,000 admitted patients. When an emergency arrives, the triage nurse searches by Patient ID 'P-4089' or blood group 'AB-'. They need to find that exact patient record in a millisecond. In JavaScript, `find()` and `findIndex()` let you locate specific object records in an array instantly based on unique IDs or property values.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Searching Objects by Property Value:
- arr.find(predicateFn): Returns the FIRST object matching the condition, or undefined if no match.
- arr.findIndex(predicateFn): Returns the array index (0, 1, 2...) of the first matching object, or -1.
- arr.findLast(predicateFn) [ES2023]: Searches from the end backwards and returns the LAST matching object.
- arr.findLastIndex(predicateFn) [ES2023]: Returns the index of the last matching object.

2. Guarding Against Missing Items:
Always verify that `find()` returned an object before accessing properties (e.g. `user?.name` or `if (user) { ... }`).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Locating Student by ID and Most Recent Transaction ---
const ledger = [
  { id: 1, user: 'Swadeep', action: 'LOGIN', time: '10:00 AM' },
  { id: 2, user: 'Tuhina', action: 'SUBMIT_TEST', time: '10:15 AM' },
  { id: 3, user: 'Swadeep', action: 'LOGOUT', time: '10:45 AM' }
];

// Find first login of Swadeep:
const firstAction = ledger.find(item => item.user === 'Swadeep');
console.log('First action:', firstAction.action); // 'LOGIN'

// Find most recent action of Swadeep (Search backwards):
const lastAction = ledger.findLast(item => item.user === 'Swadeep');
console.log('Most recent action:', lastAction.action); // 'LOGOUT'

Teacher's Note on Example 1:
find retrieves the first match from the top; findLast retrieves the newest match from the end.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Accessing properties on undefined: If `find()` finds no match, `const u = arr.find(...); u.name` throws a TypeError! Always use optional chaining `u?.name`.

[!] Using indexOf on object arrays: `arr.indexOf({ id: 1 })` always returns -1 because objects are compared by reference, not by content. Use `findIndex()` instead!

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• find() locates the first matching object; findLast() locates the last.
• findIndex() returns the numeric index or -1.
• Never use indexOf for objects; always use findIndex with a predicate.
