1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Think about an automated coffee bean processing factory. Stage 1 (Filter): The machine filters out small unripened beans and twigs. Stage 2 (Sort): The high-grade beans are sorted by size and weight. Stage 3 (Map): The beans are roasted, ground, and packaged into airtight foil packets. The input is raw dirty beans; the output is gourmet packaged coffee. In JavaScript, chaining `filter().toSorted().map()` is the ultimate data pipeline!

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The 3-Stage Pipeline Architecture:
- Stage 1 (Filter): Reduce dataset size by eliminating irrelevant records.
- Stage 2 (Sort): Arrange records in the desired order (highest marks, latest date, lowest price).
- Stage 3 (Map): Project and format each surviving record into the required display or payload shape.

2. Why this Order Matters:
Filtering FIRST reduces the number of items that need to be sorted in Stage 2, saving significant CPU comparison cycles!

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Top 3 Paid Honor Students Award Pipeline ---
const allStudents = [
  { id: 1, name: 'Swadeep', marks: 88, feePaid: true },
  { id: 2, name: 'Tuhina', marks: 95, feePaid: true },
  { id: 3, name: 'Abhronila', marks: 92, feePaid: false }, // Unpaid
  { id: 4, name: 'Debangshu', marks: 98, feePaid: true },
  { id: 5, name: 'Rahul', marks: 65, feePaid: true }
];

const honorRoll = allStudents
  .filter(s => s.feePaid && s.marks >= 80) // 1. Filter qualified students
  .toSorted((a, b) => b.marks - a.marks)  // 2. Sort by marks descending
  .slice(0, 3)                            // 3. Take Top 3
  .map((s, index) => `#${index + 1} ${s.name} (${s.marks} Marks)`); // 4. Format

console.log('Top Honor Roll:', honorRoll);

Teacher's Note on Example 1:
Chaining filter -> toSorted -> slice -> map produces an end-to-end data pipeline.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Sorting before filtering: Sorting 10,000 items and then filtering out 9,000 is wasteful. Filter first to minimize sorting overhead.

[!] Mutating original arrays in intermediate steps: Use .toSorted() rather than .sort() so your source dataset remains intact.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Filter first to reduce volume, then sort, then map to reshape.
• Method chaining produces declarative, readable enterprise code.
• Always preserve source immutability.
