3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Multi-Criteria Filtering:
Combining multiple boolean conditions using `&&` (AND) and `||` (OR) inside the `filter()` callback function.

2. Dynamic Filter Predicates:
Building dynamic filter functions where criteria can be optionally toggled (e.g. if category filter is selected, filter by category; otherwise show all).

3. Immutability:
`filter()` creates a new array of matching object references without mutating the original list.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Dynamic Multi-Criteria E-Commerce Search ---
const products = [
  { id: 1, name: 'Gaming Laptop', price: 75000, rating: 4.8, inStock: true },
  { id: 2, name: 'Wireless Mouse', price: 1200, rating: 4.2, inStock: false },
  { id: 3, name: 'Mechanical Keyboard', price: 3500, rating: 4.6, inStock: true },
  { id: 4, name: 'Budget Monitor', price: 8500, rating: 3.9, inStock: true }
];

// Filter: Price < 10000 AND Rating >= 4.0 AND InStock === true
const matchedProducts = products.filter(p => 
  p.price < 10000 && 
  p.rating >= 4.0 && 
  p.inStock
);

console.log('Filtered Products:', matchedProducts);

Teacher's Note on Example 1:
Compound boolean predicates filter the collection across multiple simultaneous constraints.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Operator precedence errors: Mixing `&&` and `||` without parentheses causes subtle logic bugs. Always write `(a || b) && c`.

[!] Shallow filtering mutation: The filtered array contains references to the original objects; mutating a filtered object mutates the original object.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• filter() extracts records matching multi-criteria conditions.
• Use parentheses `(p.cat === 'A' || p.cat === 'B') && p.price < 100` for clarity.
• Powers real-world search, catalog filtering, and permission audits.
