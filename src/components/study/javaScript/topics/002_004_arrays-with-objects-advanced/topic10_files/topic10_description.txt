3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. The Universal Pagination Formula:
For a given `pageNumber` (1-indexed) and `pageSize` (e.g. 10 items per page):
- `startIndex = (pageNumber - 1) * pageSize`
- `endIndex = startIndex + pageSize`
- `pageItems = arr.slice(startIndex, endIndex)`
- `totalPages = Math.ceil(arr.length / pageSize)`

2. Array Chunking Algorithm:
Dividing a large array into an array of smaller sub-arrays of fixed size N (e.g. chunks of 5).

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Clean Pagination Function with Page Metadata ---
function getPaginatedData(items, page = 1, pageSize = 2) {
  const totalItems = items.length;
  const totalPages = Math.ceil(totalItems / pageSize);
  const startIndex = (page - 1) * pageSize;
  const data = items.slice(startIndex, startIndex + pageSize);
  
  return {
    currentPage: page,
    pageSize,
    totalItems,
    totalPages,
    hasNextPage: page < totalPages,
    hasPrevPage: page > 1,
    data
  };
}

const students = ['Swadeep', 'Tuhina', 'Abhronila', 'Debangshu', 'Sourav'];
console.log('Page 1:', getPaginatedData(students, 1, 2));
console.log('Page 2:', getPaginatedData(students, 2, 2));

Teacher's Note on Example 1:
slice() extracts exactly the window of records requested by the UI page.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] 0-indexed vs 1-indexed page confusion: If page is 1-indexed, start is `(page - 1) * size`. If page is 0-indexed, start is `page * size`.

[!] Out of bounds page requests: When page exceeds totalPages, slice() cleanly returns an empty array `[]`.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Pagination slices large datasets into manageable UI windows.
• Formula: `startIndex = (page - 1) * pageSize`.
• Always return pagination metadata (totalPages, hasNextPage) for UI controls.
