1. THE REAL-WORLD HOOK & INTUITIVE ANALOGY
--------------------------------------------------------------------------------
Imagine giving your friend a photocopy of a student list. If the photocopy lists student names and their phone numbers, your friend can write notes on their paper without changing your original master sheet. But what if your photocopy contains a web link (a reference pointer) to a live shared Google Doc? If your friend edits the Google Doc, your master data is modified too! That is Shallow Copy vs Deep Copy.

2. BARRACKPORE LAB CLASSROOM SCENARIO & PERSONAL IMPROVISATION
--------------------------------------------------------------------------------
Swadeep cloned a student array using spread: `let copy = [...students]`. He modified a nested address object: `copy[0].address.city = 'Kolkata'`. Suddenly, the city changed in his original `students` array too! Swadeep cried out: 'Sir, I spread the array with `[...]`, why did the original change?' I drew memory pointers on the board to show that spread only copies the top-level array; nested objects are still shared references! I introduced native `structuredClone(students)` which deep-copies every nested level.

3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Shallow Copy ([...arr] or arr.slice()):
Copies the top-level array container, but any nested objects or inner arrays inside still share the same memory references.

2. Deep Copy (structuredClone(arr)) — Modern Standard (ES2022):
Recursively clones every nested object, array, Date, and Map, ensuring 100% memory isolation.

3. Legacy JSON Hack: `JSON.parse(JSON.stringify(arr))`:
Works for basic data, but loses Functions, undefined, Symbols, and corrupts Dates into strings. Always prefer native `structuredClone()`.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Shallow Copy vs Deep structuredClone ---
const original = [
  { name: 'Swadeep', details: { city: 'Barrackpore', badge: 'Gold' } }
];

// 1. Deep Clone with native structuredClone:
const deepCopied = structuredClone(original);
deepCopied[0].details.city = 'London';

console.log('Original city stays safe:', original[0].details.city); // 'Barrackpore'
console.log('Cloned city updated:', deepCopied[0].details.city);   // 'London'

Teacher's Note on Example 1:
structuredClone creates complete, independent memory copies of nested data.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Assuming spread [...] deep-copies nested objects: Spread is strictly shallow.

[!] structuredClone with functions: structuredClone cannot clone objects containing functions (throws DOMException DataCloneError).

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• Spread and slice only create shallow copies.
• Use native structuredClone() for 100% independent deep copies of nested collections.
• Crucial for preventing accidental data mutations in state management.
