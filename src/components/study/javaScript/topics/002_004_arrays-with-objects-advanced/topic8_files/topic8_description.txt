3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Nested Collections:
Real-world data structures often contain arrays inside objects (e.g. User.orders[], Post.comments[], Batch.students[]).

2. flatMap() for Nested Extraction:
Maps each parent object to its child array and automatically flattens the result by 1 level.

3. Relational Joins (Joining Two Datasets):
Joining an array of Students with an array of Courses based on a matching foreign key `courseId` using `find()` or a lookup Map.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Relational Join: Students joined with Course Information ---
const courses = [
  { id: 'C1', title: 'JavaScript Mastery', fee: 4000 },
  { id: 'C2', title: 'React Frontend Pro', fee: 5500 }
];

const students = [
  { name: 'Swadeep', courseId: 'C1' },
  { name: 'Tuhina', courseId: 'C2' },
  { name: 'Debangshu', courseId: 'C1' }
];

// Relational Join: Combine student with course details
const enrichedStudents = students.map(student => {
  const courseInfo = courses.find(c => c.id === student.courseId);
  return {
    ...student,
    courseTitle: courseInfo?.title ?? 'Unknown Course',
    courseFee: courseInfo?.fee ?? 0
  };
});

console.log(enrichedStudents);

Teacher's Note on Example 1:
Simulates an SQL INNER JOIN in JavaScript by looking up related records by ID.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] O(N * M) performance on huge joins: Using `find()` inside `map()` over 100,000 items is slow. Pre-index the courses into a Map for instant O(1) lookup.

[!] Missing matching keys: Always handle missing foreign keys gracefully with fallback values.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• flatMap() unwraps nested array properties into flat lists.
• Relational joins combine related collections using shared foreign keys.
• Use Map lookups for high-speed joins on large collections.
