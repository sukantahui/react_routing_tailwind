4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Complete Enterprise Pipeline: Student Analytics Summary ---
const rawBatch = [
  { id: 1, name: 'Swadeep', course: 'JS', marks: 88, paid: true },
  { id: 2, name: 'Tuhina', course: 'React', marks: 95, paid: true },
  { id: 3, name: 'Abhronila', course: 'JS', marks: 92, paid: true },
  { id: 4, name: 'Debangshu', course: 'React', marks: 78, paid: false }
];

// Enterprise Pipeline: Paid only → Sorted by marks → Grouped by Course
const qualifiedStudents = rawBatch
  .filter(s => s.paid)
  .toSorted((a, b) => b.marks - a.marks);

const courseGroups = Object.groupBy(qualifiedStudents, s => s.course);
console.log('Processed Analytics:', courseGroups);

Teacher's Note on Example 1:
Combines filter, toSorted, and Object.groupBy into a complete analytics pipeline.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Mixing UI rendering code into data pipelines: Always keep data pipelines pure and separated into reusable business logic modules.

[!] Ignoring edge cases on empty arrays: Ensure pipelines gracefully handle empty input collections.
