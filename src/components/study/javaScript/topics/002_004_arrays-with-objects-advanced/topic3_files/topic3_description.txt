3. STEP-BY-STEP CONCEPTUAL BREAKDOWN (WHITEBOARD EXPLANATION)
--------------------------------------------------------------------------------
1. Object Accumulator Pattern:
Using an Object `{ ... }` as the initial accumulator in `reduce()`, allowing you to track multiple metrics simultaneously in a single iteration.

2. Group-By Aggregations:
Aggregating totals grouped by a specific category (e.g. Total sales grouped by city: `{ Barrackpore: 50000, Kolkata: 120000 }`).

3. Performance Advantage:
Single-pass O(N) execution is significantly faster than chaining multiple separate map/filter/sum passes over large datasets.

4. GROUNDED PRACTICAL CODE EXAMPLES (PROGRESSIVE LEARNING)
--------------------------------------------------------------------------------
--- Example 1: Single-Pass Multi-Metric Financial Summary ---
const transactions = [
  { id: 'T1', amount: 5000, tax: 900, category: 'Course Fee' },
  { id: 'T2', amount: 1500, tax: 270, category: 'Books' },
  { id: 'T3', amount: 3500, tax: 630, category: 'Course Fee' }
];

const summary = transactions.reduce((acc, txn) => {
  acc.grossRevenue += txn.amount;
  acc.totalTax += txn.tax;
  acc.transactionCount += 1;
  return acc;
}, { grossRevenue: 0, totalTax: 0, transactionCount: 0 });

console.log('Financial Summary:', summary);

Teacher's Note on Example 1:
The object accumulator tracks revenue, tax, and count simultaneously in one pass.

5. COMMON TRAPS, ROOKIE MISTAKES & SENIOR PRO BEST PRACTICES
--------------------------------------------------------------------------------
[!] Forgetting to return acc: Inside the reduce callback, failing to write `return acc;` breaks the next iteration.

[!] Mutating a shared global initial value: Always pass a fresh inline object `{ total: 0 }` as the initial value.

6. KEY TAKEAWAYS & REVISION SUMMARY
--------------------------------------------------------------------------------
• reduce() can accumulate into numbers, objects, or arrays.
• Use object accumulators to calculate multiple summary statistics in a single pass.
• Single-pass reduction is ideal for high-performance financial reporting.
