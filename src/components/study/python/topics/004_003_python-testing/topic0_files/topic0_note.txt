1. THE VALUE OF AUTOMATED TESTING
--------------------------------------------------------------------------------
  Manual 'print()' testing fails because:
  - It is slow, non-repeatable, and human error-prone.
  - It cannot run automatically inside Continuous Integration (CI) pipelines.
  - It leaves no permanent regression shield when codebase changes.

  Automated tests provide:
  - Rapid sub-second feedback during development.
  - Regression detection: alerts instantly when a bug is introduced.
  - Living executable documentation of system requirements.

--------------------------------------------------------------------------------
2. BASIC ASSERTION CONTRACTS IN PYTHON
--------------------------------------------------------------------------------
  def calculate_scholarship(score: float, base_fee: float) → float:
      if score >= 90.0:
          return base_fee * 0.50 # 50% waiver
      elif score >= 75.0:
          return base_fee * 0.25 # 25% waiver
      return 0.0

  # Automated Test Verification Contract
  assert calculate_scholarship(95.0, 10000.0) == 5000.0, "Failed 90%+ tier"
  assert calculate_scholarship(80.0, 10000.0) == 2500.0, "Failed 75%+ tier"
  assert calculate_scholarship(60.0, 10000.0) == 0.0,    "Failed below 75% tier"
