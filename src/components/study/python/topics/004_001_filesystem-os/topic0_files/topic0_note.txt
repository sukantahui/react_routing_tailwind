1. ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------
  * os.getenv("DB_URL", "fallback")   : Safe read with fallback (No KeyError)
  * os.environ["KEY"] = "val"         : Sets environment variable for process
  * os.environ.setdefault("K", "v")   : Sets only if not already present

--------------------------------------------------------------------------------
2. CWD & FILESYSTEM QUERIES
--------------------------------------------------------------------------------
  * os.getcwd()                       : Returns absolute path of current working dir
  * os.path.exists(path)              : Checks if file/folder exists
  * os.path.isfile(path)              : True if regular file
  * os.path.isdir(path)               : True if directory
  * os.path.getsize(path)             : File size in bytes
  * os.stat(path)                     : Full low-level filesystem inode metadata

--------------------------------------------------------------------------------
3. DIRECTORY CRUD & PERMISSIONS
--------------------------------------------------------------------------------
  * os.makedirs(path, exist_ok=True)  : Recursively creates directory tree safely
  * os.replace(src, dst)              : Atomic cross-platform file replacement
  * os.access(path, os.R_OK | os.W_OK): Tests read/write permissions
