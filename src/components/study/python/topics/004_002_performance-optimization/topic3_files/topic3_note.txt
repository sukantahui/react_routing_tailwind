1. CPROFILE EXECUTION RECIPES
--------------------------------------------------------------------------------
  # Programmatic Profiling:
  profiler = cProfile.Profile()
  profiler.enable()
  my_heavy_function()
  profiler.disable()

  # Format and sort with pstats:
  stats = pstats.Stats(profiler)
  stats.strip_dirs()
  stats.sort_stats(pstats.SortKey.CUMULATIVE)
  stats.print_stats(10)

--------------------------------------------------------------------------------
2. CPROFILE METRICS CHEATSHEET
--------------------------------------------------------------------------------
  * ncalls  : Number of times the function was called
  * tottime : Time spent IN the function body itself (excluding sub-calls)
  * percall : tottime / ncalls (Average time per call)
  * cumtime : Time spent IN the function AND ALL ITS CHILDREN
  * percall : cumtime / ncalls (Average cumulative time per call)

--------------------------------------------------------------------------------
