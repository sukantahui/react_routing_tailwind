2. PYTHON IDIOM SPEED CHEATSHEET
--------------------------------------------------------------------------------
  * String Formatting  : f"{a} {b}" > " " + b > "%s %s" > "{}".format()
  * Dict Creation      : {} literal > dict() constructor (No global lookup)
  * List Creation      : [] literal > list() constructor
  * Emptiness Check    : if not seq: > if len(seq) == 0:
  * Sequence Filtering : [x for x in seq if cond] > for loop with .append()
