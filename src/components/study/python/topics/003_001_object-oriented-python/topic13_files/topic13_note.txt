1. DEFINING AN ABSTRACT BASE CLASS
--------------------------------------------------------------------------------
  from abc import ABC, abstractmethod

  class BaseConnector(ABC):
      @abstractmethod
      def connect(self) -> bool:
          pass

      @property
      @abstractmethod
      def provider_name(self) -> str:
          pass

--------------------------------------------------------------------------------
2. INSTANTIATION BLOCKER
--------------------------------------------------------------------------------
  Attempting to instantiate `BaseConnector()` directly or a subclass that fails
  to override every `@abstractmethod` raises:
  -> TypeError: Can't instantiate abstract class SubClass with abstract methods

--------------------------------------------------------------------------------
3. VIRTUAL SUBCLASSES VIA REGISTER()
--------------------------------------------------------------------------------
  BaseConnector.register(ExternalThirdPartyClass)
  # Now issubclass(ExternalThirdPartyClass, BaseConnector) returns True!
