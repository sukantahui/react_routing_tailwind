TITLE: Topic 12: Magic / Dunder Methods: __str__, __repr__, __len__, __eq__, __add__
LEVEL: Advanced
DIFFICULTY: Medium

OVERVIEW:
Comprehensive master guide to Python's Magic / Dunder (Double Underscore) Methods and the Python Data Model. Deep dive into string representations (`__str__` vs `__repr__`), rich comparison operators (`__eq__`, `__lt__`, `__gt__`, `@functools.total_ordering`), object hashability (`__hash__`), emulating sequence and container protocols (`__len__`, `__getitem__`, `__setitem__`, `__delitem__`, `__contains__`, `__iter__`), arithmetic and reflected operators (`__add__`, `__radd__`, `__iadd__`, `__mul__`), creating stateful callable objects / functors via `__call__`, and an enterprise smart student batch and fee ledger container case study.

CORE CONCEPTS:
1. The Python Data Model & Magic / Dunder Methods
2. String Representations: __str__ (User-facing) vs __repr__ (Developer-facing / eval-ready)
3. Object Equality & Comparison: __eq__, __lt__, __le__, __gt__, __ge__
4. Simplifying Comparisons with @functools.total_ordering
5. Hashability Protocol: __hash__ for Set and Dictionary Key Support
6. Container & Sequence Protocols: __len__, __getitem__, __setitem__, __delitem__
7. Membership Testing (__contains__) and Iteration (__iter__)
8. Arithmetic Operators: __add__, Reflected __radd__, In-Place __iadd__
9. Callable Objects & Functors via __call__
10. Case Study: Production Academic Batch Ledger System

REAL-WORLD SCENARIOS:
- Building domain-driven containers that seamlessly support native Python syntax (len(batch), batch[0], student in batch)
- Implementing stateful pricing functors and discount coupon calculators called like functions (coupon(price))
- Merging disparate data batches cleanly using the '+' operator (__add__)
- Designing clean, unambiguous, and eval-ready __repr__ implementations for production logging and observability
