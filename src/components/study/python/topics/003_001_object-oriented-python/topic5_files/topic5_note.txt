1. THE THREE METHOD TYPES AT A GLANCE
--------------------------------------------------------------------------------
  Method Type        Decorator       First Parameter    Can Access
  ------------------------------------------------------------------------------
  Instance Method    (None)          self (Instance)    Instance & Class State
  Class Method       @classmethod    cls (Class)        Class State only (Factories)
  Static Method      @staticmethod   (None)             Neither (Pure Utility)

--------------------------------------------------------------------------------
2. ALTERNATIVE CONSTRUCTOR FACTORY PATTERN
--------------------------------------------------------------------------------
  class Course:
      def __init__(self, title, fee):
          self.title = title
          self.fee = fee

      @classmethod
      def from_dict(cls, data: dict):
          # cls(...) ensures subclass polymorphism when inherited!
          return cls(title=data['title'], fee=data['fee'])

--------------------------------------------------------------------------------
3. STATIC METHOD UTILITY PATTERN
--------------------------------------------------------------------------------
  class TaxUtils:
      @staticmethod
      def calculate_gst(amount: float, rate: float = 18.0) -> float:
          return amount * (rate / 100)
