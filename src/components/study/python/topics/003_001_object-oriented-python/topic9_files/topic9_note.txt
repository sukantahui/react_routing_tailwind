1. EXTENDING VS REPLACING PARENT BEHAVIOR
--------------------------------------------------------------------------------
  • EXTENDING (Recommended for layered behavior):
      class Child(Parent):
          def process(self):
              super().process()  # Runs parent logic first
              print("Child custom logic")

  • REPLACING (Completely overrides parent):
      class Child(Parent):
          def process(self):
              print("Child exclusive logic")  # Ignores parent

--------------------------------------------------------------------------------
2. THE TRUE NATURE OF super()
--------------------------------------------------------------------------------
  In Python, `super()` does NOT mean "call my direct lexical parent".
  It means: "Search the MRO (Method Resolution Order) of the active instance,
  and invoke the method on the NEXT class in that sequence!"

3. COOPERATIVE CONSTRUCTOR WITH **kwargs
--------------------------------------------------------------------------------
  class MixinA:
      def __init__(self, key_a=None, **kwargs):
          super().__init__(**kwargs)
          self.key_a = key_a
