1. SYNCHRONOUS (TIME.SLEEP) VS ASYNCHRONOUS (ONTIMER)
--------------------------------------------------------------------------------
- `time.sleep(seconds)`:
  Pauses the entire Python thread. Good for linear procedural demos, but can freeze
  GUI event processing if delays are long.

- `screen.ontimer(callback, delay_ms)`:
  Schedules a Python function to run after `delay_ms` milliseconds inside Tkinter's
  asynchronous event loop. Keeps keyboard and mouse handlers completely non-blocking!

2. RECURSIVE ONTIMER LOOP PATTERN
--------------------------------------------------------------------------------
def game_tick():
    # 1. Update & Render Frame
    screen.update()
    # 2. Schedule next tick in 16 ms (~60 FPS)
    screen.ontimer(game_tick, 16)

3. FRAMERATE-INDEPENDENT DELTA TIME (DT)
--------------------------------------------------------------------------------
By multiplying speed by actual elapsed seconds (`dt`), movement speeds stay
identical across fast 240Hz monitors and slow low-power laptops:
`x += speed_in_pixels_per_second * dt`
