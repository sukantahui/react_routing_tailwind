1. WHAT IS BOUNDARY COLLISION DETECTION?
--------------------------------------------------------------------------------
Boundary detection checks whether an object's bounding geometry has intersected
or exceeded the edges of the active display canvas or arena box.

2. THE 3 MANDATORY STEPS OF WALL BOUNCING
--------------------------------------------------------------------------------
1. Overlap Condition with Radius Offset:
   `if x + radius >= max_x:`

2. Position Snapping (Anti-Tunneling Correction):
   `x = max_x - radius` (Prevents the ball from getting stuck inside the wall)

3. Velocity Reflection:
   `vx = -vx` (Reverses horizontal momentum while preserving vertical motion)

3. BOUNCE VS TOROIDAL SCREEN WRAPPING
--------------------------------------------------------------------------------
- Bouncing (Pong / Billiards): Velocity flips direction (`vx = -vx`).
- Toroidal Wrapping (Asteroids / Pac-Man): Object teleports seamlessly to opposite edge:
  `if x > max_x: x = min_x`
