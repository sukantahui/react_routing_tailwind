1. WHAT IS FRAME-BASED ANIMATION?
--------------------------------------------------------------------------------
Animation is an optical illusion created by rendering a rapid sequence of static
images (frames). The human visual system blends individual frames into continuous
fluid motion via the persistence of vision phenomenon.

2. THE 4-STAGE CORE GAME / ANIMATION LOOP
--------------------------------------------------------------------------------
Every animated game and simulation executes this identical 4-stage cycle per frame:
1. `t.clear()`: Erases the previous frame geometry from the back buffer.
2. Update State: Updates mathematical physics variables (`x += vx`, `theta += omega`).
3. Render Frame: Draws the new scene objects at their updated coordinates.
4. Flush & Pace: Calls `screen.update()` and sleeps `time.sleep(1/FPS)`.

3. STANDARD FRAME RATES & FRAME DELTA BUDGETS
--------------------------------------------------------------------------------
- 15 FPS: 66.6 ms per frame (Stuttery, low-power mode)
- 30 FPS: 33.3 ms per frame (Standard video playback)
- 60 FPS: 16.6 ms per frame (Standard modern fluid gaming budget)
