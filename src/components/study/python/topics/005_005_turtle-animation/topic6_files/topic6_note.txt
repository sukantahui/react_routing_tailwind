1. WHAT IS MULTI-ENTITY SYNCHRONIZATION?
--------------------------------------------------------------------------------
Multi-entity synchronization coordinates dozens or hundreds of autonomous
moving objects (bullets, enemies, planets, particles) within a single unified
60 FPS frame cycle.

2. THE ENTITY-LIST ARCHITECTURE
--------------------------------------------------------------------------------
1. Store entities in a Python list of dictionaries or class instances:
   `entities = [{'x': 0, 'y': 0, 'vx': 4, 'vy': 3, 'color': '#38bdf8'}, ...]`

2. In the 60 FPS loop:
   - Clear canvas once (`t.clear()`)
   - Loop over all entities: update physics and draw
   - Filter/despawn dead entities (`[e for e in entities if e['alive']]`)
   - Flush buffer once (`screen.update()`)

3. SCALING TO 100+ ENTITIES AT 60 FPS
--------------------------------------------------------------------------------
By using a single turtle cursor with `screen.tracer(0)` and pure math lists,
Python can effortlessly animate 500+ particles simultaneously with rock-solid 60 FPS.
