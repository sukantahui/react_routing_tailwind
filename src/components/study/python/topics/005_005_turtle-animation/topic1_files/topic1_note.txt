1. WHAT IS DOUBLE BUFFERING?
--------------------------------------------------------------------------------
Double-buffering uses two memory stores to render graphics:
- Back Buffer (Invisible RAM): Where all intermediate lines, fills, and shapes are drawn.
- Front Buffer (Visible Screen): What the user sees on their monitor.
- `screen.update()`: Swaps or copies the back buffer to the front buffer in one atomic operation.

2. TRACER MODES IN TURTLE GRAPHICS
--------------------------------------------------------------------------------
- `screen.tracer(1)` (Default):
  Refreshes the canvas on every single draw command. Extremely slow; causes visible tearing.

- `screen.tracer(n)` (Batching):
  Refreshes the canvas once every `n` drawing commands. Ideal for progressive generative art.

- `screen.tracer(0)` (Manual Double-Buffering):
  Disables automatic screen refreshes entirely. Drawing happens at raw CPU speeds in memory.
  Requires calling `screen.update()` manually to display completed frames.
