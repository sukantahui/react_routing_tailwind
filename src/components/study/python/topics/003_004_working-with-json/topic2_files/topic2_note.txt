--------------------------------------------------------------------------------
1. json.dumps() VS json.dump()
--------------------------------------------------------------------------------
  • `json.dumps(obj)` : Returns a JSON-formatted string in memory.
  • `json.dump(obj, f)` : Streams JSON directly into an open file/stream object.

--------------------------------------------------------------------------------
2. FORMATTING & MINIFICATION RECIPES
--------------------------------------------------------------------------------
  • Pretty-Print : `json.dumps(data, indent=4, sort_keys=True)`
  • Minified     : `json.dumps(data, separators=(",", ":"), sort_keys=True)`
  • Canonical    : Deterministic output for SHA-256 signatures and hashing.

--------------------------------------------------------------------------------
3. ATOMIC FILE PERSISTENCE PATTERN
--------------------------------------------------------------------------------
  temp_fd, temp_path = tempfile.mkstemp(dir=target_dir)
