1. KEY COERCION & skipkeys
--------------------------------------------------------------------------------
  • JSON keys MUST be strings.
  • Python int/float/bool keys are automatically coerced to strings: {101: "A"} -> {"101": "A"}
  • Tuple keys raise TypeError unless `skipkeys=True` is passed: `json.dumps(d, skipkeys=True)`

--------------------------------------------------------------------------------
2. SPECIAL FLOATS: NaN & INFINITY
--------------------------------------------------------------------------------
  • Default `json.dumps()` emits unquoted `NaN` (Illegal in strict RFC 8259).
  • Use `allow_nan=False` to raise ValueError and enforce strict compliance.

--------------------------------------------------------------------------------
3. ROUND-TRIP MUTATIONS
--------------------------------------------------------------------------------
  • `tuple` (1, 2)  ---> `list` [1, 2]
  • `dict` {101: v} ---> `dict` {"101": v}
