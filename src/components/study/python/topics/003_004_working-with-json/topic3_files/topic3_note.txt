1. json.loads() VS json.load()
--------------------------------------------------------------------------------
  • `json.loads(s)` : Parses in-memory string or bytes into Python objects.
  • `json.load(f)`  : Parses directly from an open file/stream object.

--------------------------------------------------------------------------------
2. HIGH-PRECISION FINANCIAL DECODING
--------------------------------------------------------------------------------
  from decimal import Decimal
  doc = json.loads(payload, parse_float=Decimal)
  # Prevents IEEE-754 binary floating-point roundoff drift!

3. PINPOINTING JSONDecodeError
--------------------------------------------------------------------------------
  try:
      data = json.loads(corrupt_str)
  except json.JSONDecodeError as e:
