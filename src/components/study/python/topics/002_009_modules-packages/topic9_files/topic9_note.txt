--------------------------------------------------------------------------------
3. LAYERED REQUIREMENTS ARCHITECTURE (BEST PRACTICE)
--------------------------------------------------------------------------------
  • `requirements/base.txt`: Core shared app packages (FastAPI, Requests, SQLAlchemy)
  • `requirements/dev.txt`:  `-r base.txt` + testing tools (pytest, black, flake8)
  • `requirements/prod.txt`: `-r base.txt` + production servers (gunicorn, sentry)

--------------------------------------------------------------------------------
4. INSTALLATION & AUDIT COMMANDS
--------------------------------------------------------------------------------
  • Install Dev:   python -m pip install -r requirements/dev.txt
  • Install Prod:  python -m pip install --no-cache-dir -r requirements/prod.txt
  • Verify Health: python -m pip check
