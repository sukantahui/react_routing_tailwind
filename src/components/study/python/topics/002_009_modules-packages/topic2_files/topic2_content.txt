TITLE: Topic 2: Built-in standard library modules: math, random, datetime, sys, os
LEVEL: Intermediate
DIFFICULTY: Medium

OVERVIEW:
Comprehensive guide to Python's built-in "Batteries Included" standard library modules. Focuses on the 5 essential pillar modules: `math` (precision mathematics, roots, gcd, float comparison with isclose), `random` (pseudo-random generation, choices, sampling, seeding vs cryptographically secure `secrets`), `datetime` (date, time, timedelta arithmetic, formatting with strftime, and parsing with strptime), `sys` (interpreter metadata, sys.argv, sys.platform, memory footprint inspection via sys.getsizeof), and `os` (operating system bridge, os.getcwd, directory listings, environment variables via os.environ, and robust cross-platform path handling with os.path.join).

CORE CONCEPTS:
1. math Module: sqrt, ceil, floor, gcd, factorial, isclose(), constants (pi, e)
2. random Module: randint, choice, sample, shuffle, uniform, seeding for reproducibility
3. secrets Module: Cryptographically secure tokens and OTP generation
4. datetime Module: date, time, datetime objects, and timedelta arithmetic
5. Date Parsing & Formatting: strftime (Date to Str) vs strptime (Str to Date)
6. time Module: Epoch timestamps, delays (sleep), and precision timers (perf_counter)
7. sys Module: CLI arguments (sys.argv), platform, version, sys.exit(), sys.getsizeof()
8. os Module: Working directory (os.getcwd), directory inspection (os.listdir), environment variables (os.environ)
9. os.path Module: Cross-platform path construction (os.path.join) vs string concatenation
10. Integrated Systems: Combining all 5 pillars in production diagnostic and lottery pipelines

REAL-WORLD SCENARIOS:
- Building scheduled billing and invoice due-date engines with timedelta arithmetic
- Conducting verifiable, audit-proof student scholarship draws using seeded random samplers
- Designing cross-platform command-line tools that adapt dynamically to Windows, Linux, and macOS
- Generating cryptographically secure authentication tokens and 6-digit SMS OTPs
