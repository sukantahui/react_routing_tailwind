1. WHAT IS DRY IN GRAPHICS PROGRAMMING?
--------------------------------------------------------------------------------
DRY stands for "Don't Repeat Yourself". Every unique visual concept (e.g. how a
window, roof, tree, or star is drawn) should exist in exactly one authoritative function.

2. THE 4 PILLARS OF CLEAN GRAPHICAL CODE
--------------------------------------------------------------------------------
1. Single Responsibility Principle (SRP):
   A function should do one thing well (`draw_door` only draws a door).

2. Data-Driven Separation:
   Keep layout coordinates in data lists/dictionaries; keep rendering in functions.

3. Configuration Constants:
   Define global colors, screen sizes, and themes as UPPERCASE constants at top of file.

4. Verifiable Invariants & Unit Testing:
   Ensure functions never leak state by asserting `t.pos() == initial_pos`.
