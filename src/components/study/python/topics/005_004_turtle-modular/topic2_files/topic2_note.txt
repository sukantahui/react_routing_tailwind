1. THE PROBLEM OF STATE MUTATION
--------------------------------------------------------------------------------
In procedural turtle programming, calling a helper function often alters the turtle's:
- Position `(x, y)`
- Heading angle
- Pen status (up/down)
- Stroke and fill colors
- Stroke width (pensize)

If the helper function does not restore these values, subsequent caller commands
will draw in the wrong location at an unpredictable angle.

2. THE 3 STATE RESTORATION STRATEGIES
--------------------------------------------------------------------------------
Strategy 1: Manual Variable Capture & Restore
Capture `pos = t.position()`, `head = t.heading()`, `is_down = t.isdown()`.
Restore with `t.penup(); t.goto(pos); t.setheading(head); if is_down: t.pendown()`.

Strategy 2: Context Manager Pattern (Pythonic)
```python
@contextmanager
def preserve_turtle(t):
    state = (t.position(), t.heading(), t.isdown(), t.pencolor(), t.pensize())
    try:
        yield t
    finally:
        # restore all state elements
```

Strategy 3: Stack-Based Push/Pop Architecture
Essential for recursive hierarchies (fractal trees, L-systems).
`push_state(t, stack)` saves the snapshot before descending;
`pop_state(t, stack)` restores it upon returning.
