1. WHAT IS SCENE GRAPH COMPOSITION?
--------------------------------------------------------------------------------
Complex environments (townscapes, mountain ranges, procedural cities) are constructed
by combining individual modular drawing functions into an ordered pipeline.
Instead of random drawing order, professional graphics follow a Layered Z-Index hierarchy.

2. THE 5-LAYER Z-INDEX RENDERING PIPELINE
--------------------------------------------------------------------------------
1. Layer 0 (Backdrop): Sky gradient, Sun, Moon, Starfields.
2. Layer 1 (Far Distance): Distant mountains, hazy horizons.
3. Layer 2 (Midground): Rolling hills, riverbanks, forest silhouettes.
4. Layer 3 (Subject Architecture): Houses, skyscrapers, bridges.
5. Layer 4 (Foreground Props): Streetlamps, pine trees, roads, pedestrians.

3. PROCEDURAL PARAMETRIC GENERATION
--------------------------------------------------------------------------------
By using `random.randint()` or mathematical functions inside coordinate loops,
a single `draw_skyscraper()` or `draw_tree()` function can generate infinite
unique city skylines and lush nature scenes with deterministic seeds (`random.seed()`).
