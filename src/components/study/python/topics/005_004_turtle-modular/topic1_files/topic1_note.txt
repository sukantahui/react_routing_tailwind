1. WHAT IS PARAMETERIZATION?
--------------------------------------------------------------------------------
Parameterization is the practice of replacing fixed constants in drawing algorithms
with variable function inputs. A fully parameterized graphical function controls:
- Translation: `(x, y)` coordinate position
- Scaling: `size`, `radius`, or `scale_factor`
- Rotation: `rotation` or `heading_angle`
- Appearance: `fill_color`, `border_color`, `pensize`

2. THE 3 CORE AFFINE TRANSFORMATIONS IN TURTLE
--------------------------------------------------------------------------------
1. Translation (Positioning):
   `t.penup(); t.goto(x, y); t.pendown()`

2. Rotation (Orientation):
   `t.setheading(rotation)`

3. Scaling (Dilation):
   Multiplying every `forward()` distance and `radius` by a proportional scale multiplier.
