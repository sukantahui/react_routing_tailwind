1. WHAT IS A GRAPHICS LIBRARY MODULE?
--------------------------------------------------------------------------------
A Python graphics library module (e.g. `icons.py` or `custom_shapes.py`) is a
dedicated `.py` file containing standardized, reusable drawing functions that can
be imported across multiple separate game, visualization, or UI applications:
`from icons import draw_gear, draw_shield, draw_heart`

2. PRINCIPLES OF PROFESSIONAL LIBRARY DESIGN
--------------------------------------------------------------------------------
1. Standardized Function Signatures:
   Always follow `(t, x, y, size/radius, fill_color, border_color, ...)`.

2. Zero Top-Level Execution:
   Protect interactive showcase code inside `if __name__ == '__main__':`.
   When the file is imported by a client, it should define functions silently
   without opening a Turtle window.

3. Clear Docstrings:
   Every function should document coordinate anchors, default values, and visual features.

4. Component Decoupling:
   Functions should only draw geometry—they should never assume screen size or call
   `turtle.done()` or `screen.update()`.
