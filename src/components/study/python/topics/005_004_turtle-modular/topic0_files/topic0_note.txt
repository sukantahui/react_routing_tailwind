1. THE PHILOSOPHY OF FUNCTIONAL MODULARITY
--------------------------------------------------------------------------------
In beginner code, drawing operations are written sequentially in hundreds of
repetitive lines. If a scene requires 10 houses, beginners copy-paste code 10 times.
Functional modularity replaces this with parameterized reusable functions:
`def draw_house(t, x, y, size, wall_color, roof_color):`

2. PRINCIPLES OF ROBUST DRAWING FUNCTIONS
--------------------------------------------------------------------------------
1. Parameterize Geometry:
   Take turtle instance `t`, origin `(x, y)`, and dimensions (`size`, `width`, `height`).

2. Enforce Isolation & Determinism:
   Always lift the pen before moving to (x, y) with `penup()`, set heading `setheading(0)`,
   and put `pendown()` to guarantee no unintentional stray lines or skewed rotations.

3. Composite Architecture:
   Build complex objects (houses, cars, trees) by calling simpler atomic functions
   (`draw_rectangle`, `draw_triangle`, `draw_circle`).

4. Separation of Concerns:
   Keep drawing logic inside functions; keep screen setup, orchestration, and loop
   coordinates inside `main()`.
