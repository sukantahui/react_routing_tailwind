1. WHAT IS A STAR POLYGON?
--------------------------------------------------------------------------------
A regular star polygon is denoted by the Schläfli symbol {p/q}:
- p = number of vertices (points)
- q = density / step stride (how many vertices to skip when connecting lines)
- Condition: q and p must be coprime (gcd(p, q) == 1), and 1 < q < p/2.

2. STAR POLYGON ANGLE THEOREMS
--------------------------------------------------------------------------------
1. Exterior Turn Angle:
   theta = (q * 360) / p

2. Pentagram {5/2} (Classic 5-Pointed Star):
   - p = 5, q = 2
   - theta = (2 * 360) / 5 = 144°
   - Internal tip angle: 180° - 144° = 36°

3. Heptagrams {7/2} and {7/3}:
   - {7/2}: theta = (2 * 360) / 7 = 102.86° (wide star)
   - {7/3}: theta = (3 * 360) / 7 = 154.29° (acute sharp star)

4. Octagram {8/3}:
   - theta = (3 * 360) / 8 = 135°

3. COMPOUND STARS & ISLAMIC GEOMETRY
--------------------------------------------------------------------------------
When gcd(p, q) > 1, the star decomposes into multiple overlapping polygons:
- {6/2} = 2 overlapping triangles (Hexagram / Star of David)
- {8/2} = 2 overlapping squares (Octagram / Rub el Hizb)
