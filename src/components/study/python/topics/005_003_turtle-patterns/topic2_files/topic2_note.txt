1. WHAT ARE NESTED LOOPS IN GRAPHICS?
--------------------------------------------------------------------------------
A nested loop consists of one loop placed inside the body of another loop.
In computational geometry:
- Outer Loop: Controls global layout (radial rotations, grid rows, scale layers).
- Inner Loop: Draws the local geometric primitive (polygon edges, circle arcs, petals).

2. COMMON NESTED LOOP ARCHITECTURES
--------------------------------------------------------------------------------
Architecture 1: Radial Rosettes & Mandalas
  Outer Loop: for spoke in range(N):
                # Inner Loop:
                for side in range(sides):
                    t.forward(len)
                    t.left(360 / sides)
                t.left(360 / N)

Architecture 2: 2D Matrix Grids (Rows & Columns)
  Outer Loop: for r in range(rows):
                # Inner Loop:
                for c in range(cols):
                    t.goto(x0 + c * dx, y0 - r * dy)
                    draw_cell()

Architecture 3: Dynamic Expanding Vortices
  Outer Loop: for i in range(count):
                # Inner Loop:
                for _ in range(4):
                    t.forward(i * scale)
                    t.left(90)
                t.left(twist_angle)

3. COMPLEXITY & PERFORMANCE
--------------------------------------------------------------------------------
- If outer loop runs `M` times and inner loop runs `N` times, the inner body
  executes `M * N` total times.
- For large grids (e.g. 50x50 = 2,500 shapes), always enable `screen.tracer(0)`
  and flush with `screen.update()`.
