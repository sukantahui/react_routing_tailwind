1. WHY OPTIMIZATION MATTERS IN TURTLE GRAPHICS
--------------------------------------------------------------------------------
By default, Python Turtle animates every individual drawing step with a timer
delay and redraws the cursor sprite. In loops with 1,000+ iterations:
- Default execution: 2 to 10 minutes (UI freezes, canvas lag).
- Optimized execution: < 0.05 seconds (instantaneous GPU render).

2. THE 4 GOLDEN PERFORMANCE PILLARS
--------------------------------------------------------------------------------
1. `screen.tracer(0)`:
   Disables automatic canvas redraws. Intermediate drawing occurs in memory.

2. `screen.update()`:
   Forces an instantaneous single-frame buffer flush to the screen.

3. `t.hideturtle()`:
   Suppresses cursor sprite transformation and repaint calculations.

4. Object Reuse (`t.clear()` vs new `Turtle()`):
   Never instantiate new Turtle objects inside loops. Reuse a single instance
   and clear canvas geometry between frames.

3. BATCHING RENDERING STRATEGY
--------------------------------------------------------------------------------
For progressive live generative art:
- `screen.tracer(50)` updates the canvas once every 50 draw calls, providing
  both smooth progressive visualization and high execution speed.
