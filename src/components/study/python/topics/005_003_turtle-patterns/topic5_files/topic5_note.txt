1. THE HSV COLOR MODEL IN PYTHON GRAPHICS
--------------------------------------------------------------------------------
The standard RGB model requires adjusting 3 channels simultaneously to change
colors. The HSV model simplifies color gradients into:
- Hue (H): 0.0 to 1.0 (Angular position around the color spectrum wheel).
- Saturation (S): 0.0 (grayscale) to 1.0 (vibrant pure color).
- Value / Brightness (V): 0.0 (pure black) to 1.0 (full brightness).

2. PYTHON's `colorsys` MODULE
--------------------------------------------------------------------------------
Python includes the built-in `colorsys` library:
```python
import colorsys

# Convert HSV float [0.0, 1.0] to RGB float [0.0, 1.0]
r, g, b = colorsys.hsv_to_rgb(hue, saturation, value)
t.color(r, g, b)  # Works directly because default turtle colormode is 1.0!
```

3. LINEAR COLOR INTERPOLATION (LERP)
--------------------------------------------------------------------------------
To transition smoothly between any two custom colors C1 and C2 over `N` steps:
`factor = i / (N - 1)` (ranges from 0.0 to 1.0)
`color = C1 + (C2 - C1) * factor`

4. SPECTRUM MAPPING STRATEGIES
--------------------------------------------------------------------------------
1. Spiral Hue Cycle: `hue = i / total_steps`
2. Multi-Cycle Rainbow: `hue = (i * frequency) % 1.0`
3. Radial Spoke Spectrum: `hue = spoke_index / total_spokes`
