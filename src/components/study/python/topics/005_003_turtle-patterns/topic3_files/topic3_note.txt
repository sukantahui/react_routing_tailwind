1. WHAT IS A SPIRAL?
--------------------------------------------------------------------------------
A spiral is a curve that emanates from a central origin point, moving farther
away as it revolves around the point.

2. MAJOR TYPES OF SPIRALS
--------------------------------------------------------------------------------
1. Archimedean Spiral:
   - Polar Equation: r = a * theta
   - Characteristics: Constant distance between successive coil turnings.
   - Turtle Implementation:
     ```python
     for i in range(steps):
         t.forward(i * step_size)
         t.left(turn_angle)
     ```

2. Polygonal Spiral (Square / Hex Spiral):
   - Created by using an angle slightly larger than a regular polygon angle.
   - 91° turn -> 4-arm square spiral vortex
   - 61° turn -> 6-arm hexagonal spiral vortex
   - 121° turn -> 3-arm triangular spiral vortex

3. Logarithmic / Golden Spiral (Fibonacci):
   - Polar Equation: r = a * e^(b * theta)
   - Characteristics: Distance between coils expands exponentially (Golden Ratio phi = 1.618).
   - Approximated by chaining quarter-circle arcs of Fibonacci radii:
     `t.circle(fib_radius, 90)`

3. RADIAL SYMMETRY MECHANICS
--------------------------------------------------------------------------------
Combining multiple spiral arms radiating from the origin creates multi-armed
galaxies, pinwheels, and radial vortex mandalas.
