1. EXECUTIVE SUMMARY & LEARNING OUTCOMES
--------------------------------------------------------------------------------
This master tutorial provides deep theoretical and hands-on mastery over writing
data to persistent storage in Python. Students will master:
  • The file.write(string) method and its integer return value (character count).
  • The file.writelines(iterable) method, return type None, and newline discipline.
  • File modes comparison: 'w' (overwrite) vs 'a' (append) vs 'x' (exclusive create)
    vs 'w+' (truncate & read/write) vs 'a+' (append & read).
  • Explicit newline management ('\n') vs automated formatting.
  • Python I/O RAM buffering, user-space buffer flushing (file.flush()), and
    hardware synchronization (os.fsync()).
  • The Atomic File Write pattern (temp staging file + os.replace) for zero-data-loss.
  • Common pitfalls: TypeError on numbers, merged lines, unintentional wipes.

3. FILE OPENING MODES MATRIX
--------------------------------------------------------------------------------
Mode  | Creates File? | Truncates Existing? | Pointer Start | Read Allowed? | Write Allowed?
──────┼───────────────┼─────────────────────┼───────────────┼───────────────┼───────────────
'w'   | Yes           | YES (Wipes to 0B)   | Beginning (0) | No            | Yes
'a'   | Yes           | NO (Preserves data) | End of File   | No            | Yes (Append)
'x'   | Yes           | Error if exists!    | Beginning (0) | No            | Yes (Exclusive)
'w+'  | Yes           | YES (Wipes to 0B)   | Beginning (0) | Yes           | Yes
'a+'  | Yes           | NO (Preserves data) | End of File   | Yes (seek)    | Yes (Append)
'r+'  | No (Error)    | NO (Overwrites pos) | Beginning (0) | Yes           | Yes

--- EXAMPLE 1: write() Basics & Character Counting ---
```python
with open("student_welcome.txt", mode="w", encoding="utf-8") as f:
    f.write("=== CODER & ACCOTAX ADMISSIONS ===\n")
    name = "Mamata"
    center = "Barrackpore"

```

--- EXAMPLE 2: Batch Writing with writelines() & Generator ---
```python
students = ["Mamata", "Debangshu", "Susmita", "Mahima"]
# Format list with explicit newlines
lines = [f"Student: {name} (Coder & AccoTax)\n" for name in students]

with open("merit_list.txt", mode="w", encoding="utf-8") as f:
    f.writelines(lines)
    # Memory efficient generator stream for huge datasets:
    f.writelines(f"Audit #{i:04d} Passed\n" for i in range(1, 1001))
```

--- EXAMPLE 5: Safe Atomic File Writing Pattern ---
```python
import tempfile, os

def atomic_write(target_path, data):
    dir_name = os.path.dirname(target_path) or "."
    with tempfile.NamedTemporaryFile("w", encoding="utf-8", dir=dir_name, delete=False) as tf:
        tf.write(data)
        tf.flush()
        os.fsync(tf.fileno())
        temp_name = tf.name
    os.replace(temp_name, target_path)  # Atomic filesystem replacement
```

6. COMMON BEGINNER PITFALLS & SOLUTIONS
--------------------------------------------------------------------------------
❌ Pitfall 1: Forgetting '\n' in write()
   f.write("Mamata")
   f.write("Barrackpore")
   -> Produces "MamataBarrackpore" on one line!
   ✓ Fix: Always include f.write("Mamata\n").

❌ Pitfall 2: Passing non-strings to write()
   f.write(4500)
   -> Raises TypeError: write() argument must be str, not int.
   ✓ Fix: f.write(f"₹{4500}\n") or f.write(str(4500) + "\n").

❌ Pitfall 3: Assuming writelines() adds newlines
   f.writelines(["Mamata", "Debangshu"])
   -> Produces "MamataDebangshu".
   ✓ Fix: f.writelines([f"{item}\n" for item in items]).

❌ Pitfall 4: Unintentionally using 'w' instead of 'a'
   Opening an audit log with 'w' destroys all historical logs!
   ✓ Fix: Always use mode='a' for logs and cumulative records.

❌ Pitfall 5: Leaving file unclosed or missing 'with' statement
   If power fails or exception occurs, buffered data in RAM is permanently lost.
   ✓ Fix: Always use 'with open(...) as f:' and f.flush() for critical logs.

7. STUDENT MINI CHECKLIST (REMEMBER FOR EXAMS & INTERVIEWS)
--------------------------------------------------------------------------------
 [ ] write(s) returns character count; writelines(seq) returns None.
 [ ] Neither write() nor writelines() inserts newlines automatically.
 [ ] Mode 'w' wipes existing file immediately; mode 'a' preserves and appends to end.
 [ ] Mode 'x' protects against overwriting by raising FileExistsError if file exists.
 [ ] Always specify encoding="utf-8" for universal currency (₹) and character safety.
 [ ] Use file.flush() and os.fsync() when crash resilience and real-time viewing matter.
 [ ] Use atomic writes (temp file + os.replace) for critical configuration files.
