TOPIC 10: Writing Files: write(), writelines(), appending data
MODULE: 002_008_file-handling
TRACK: Python from Basic to Pro
AUTHOR: Sukanta Hui (Coder & AccoTax, Barrackpore)

SUMMARY:
This topic covers the mechanics of writing and appending data to text files in Python.
It explores the write() method, character counting, writelines() batch streaming,
newline handling discipline, file opening modes ('w', 'a', 'x', 'w+', 'a+'),
I/O memory buffering, file.flush(), os.fsync(), and safe atomic file replacement patterns.

KEY METHODS:
1. file.write(str) -> int (returns count of characters written)
2. file.writelines(iterable) -> None (writes sequence of strings without adding newlines)
3. file.flush() -> None (flushes internal Python memory buffer to OS stream)
4. os.fsync(fd) -> None (forces OS kernel buffer to physical disk storage)
5. os.replace(src, dst) -> None (atomic filesystem swap)

EXAMPLES PROVIDED:
- example1_write_basics.py: write() method, return value character counting, f-string formatting, and newline management.
- example2_writelines_lists.py: writelines() batch writing, generator expressions, and memory efficiency.

- example4_csv_manual_writer.py: structured CSV data generation and formatted ASCII report cards.
- example5_buffering_and_flush.py: RAM buffering, file.flush(), and real-time telemetry logging.
- example6_safe_atomic_write.py: production atomic file updates using tempfile and os.replace.
