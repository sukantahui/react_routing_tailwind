1. EXECUTIVE OVERVIEW & BINARY I/O FOUNDATIONS
--------------------------------------------------------------------------------
In modern software engineering, not all data is plain text. Images (PNG, JPEG),
multimedia audio/video, compressed archives (ZIP, GZ), database payloads, and
network packets are raw streams of 8-bit integers (0 to 255).

Python 3 provides two dedicated native types for binary data:
  1. bytes: Immutable sequence of integers (0-255). Once created, cannot be mutated.
  2. bytearray: Mutable sequence of integers (0-255). Allows in-place element
     assignment, slicing replacement, append(), and extend() without RAM copying.

Key Modes for Binary I/O:
  +------+--------------------------------------------------------------------+
  | Mode | Behavior Description                                               |
  +------+--------------------------------------------------------------------+
  | 'rb' | Read-only binary stream. Returns `bytes` objects.                  |
  | 'wb' | Write-only binary stream. Truncates or creates file. Accepts bytes.|
  | 'ab' | Append binary stream. Writes always append to EOF.                |
  |'rb+' | Read and Write in-place without truncating file.                   |
  |'wb+' | Read and Write fresh file (truncates to 0 bytes on open).          |
  +------+--------------------------------------------------------------------+

2. STRING VS BYTES: THE UNICODE BRIDGE
--------------------------------------------------------------------------------
  * Unicode String (str)  --->  .encode('utf-8')  --->  Raw Bytes (bytes)
  * Raw Bytes (bytes)     --->  .decode('utf-8')  --->  Unicode String (str)

CRITICAL RULE:
  - b[0] returns an INTEGER (e.g. 65 for b'A').
  - b[0:1] returns a BYTES object (e.g. b'A').
  - ba[0] = 74 directly mutates the byte in-place.

5. SENIOR PITFALLS & BEST PRACTICES
--------------------------------------------------------------------------------
- PITFALL: Opening binary files in text mode ('r' or 'w').
  CURE: Always use 'rb', 'wb', or 'ab' for non-text data.
- PITFALL: Assigning values outside 0-255 to bytearray (ba[0] = 300).
  CURE: Ensure all integer assignments are within 0 <= val <= 255.
- PITFALL: Loading gigabyte binary files entirely into RAM with f.read().
  CURE: Always stream in 64KB or 1MB chunks using iter(lambda: f.read(chunk), b'').
- PITFALL: Assuming b[0] returns a bytes object.
  CURE: Remember b[0] returns an integer; use b[0:1] for a bytes slice.
