5. SENIOR PITFALLS & BEST PRACTICES
--------------------------------------------------------------------------------
- PITFALL: Mutable default arguments in functions (def fn(a, lst=[])).
  CURE: Always use None as the default argument (def fn(a, lst=None): if lst is None: lst = []).
- PITFALL: Catching bare Exception: blocks without specific error types.
  CURE: Always catch specific exceptions (e.g., KeyError, ValueError, FileNotFoundError).
- BEST PRACTICE: Follow PEP 8 naming conventions and use type annotations (mypy compliance).
- BEST PRACTICE: Use context managers (with open(...) as f:) for deterministic resource cleanup.
