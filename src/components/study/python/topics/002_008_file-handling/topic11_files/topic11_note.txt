1. EXECUTIVE OVERVIEW & 3-TIER OPERATING SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
In Python, every opened file maintains an internal cursor called the "File Pointer"
or "Stream Offset". This pointer keeps track of the exact byte offset where the next
read or write operation will take place.

The 3-Tier Operating System I/O Stack:
  [Tier 1: Python io Layer]
    -> io.TextIOWrapper / io.BufferedReader (Manages 8KB user-space RAM cache)
  [Tier 2: Process File Descriptor Table]
    -> Integer file descriptor handles (fd = 3) mapped to lseek() system call
  [Tier 3: Kernel Open File Table & Vnode]
    -> Hardware 64-bit cursor offset (f_pos) on physical NVMe/SSD storage

Key Functions:
  * file.tell() -> int:
    Returns current byte position (0-indexed) of the file cursor.
  * file.seek(offset, whence=0) -> int:
    Repositions the cursor to `offset` relative to `whence`. Returns the new position.

Whence Parameter Constants:
  +---------------+--------------------+---------------------------------------+
  | Value / Const | Reference Anchor   | Description                           |
  +---------------+--------------------+---------------------------------------+
  | 0 / SEEK_SET  | Beginning of File  | Absolute offset from byte 0 (Default) |
  | 1 / SEEK_CUR  | Current Cursor Pos | Relative shift from current pointer   |
  | 2 / SEEK_END  | End of File (EOF)  | Relative offset from EOF (e.g. -20)   |
  +---------------+--------------------+---------------------------------------+

Mathematical Formalism:
  - whence=0 (SEEK_SET): New_Pos = offset                    (offset >= 0)
  - whence=1 (SEEK_CUR): New_Pos = Current_Position + offset
  - whence=2 (SEEK_END): New_Pos = Total_File_Size + offset  (offset <= 0)

2. THE 4 FUNDAMENTAL LAWS OF TEXT MODE VS BINARY MODE
--------------------------------------------------------------------------------
LAW #1: The Opaque Token Law (Text Mode tell())
  - In Python 3 text mode, tell() returns an opaque integer cookie encoding decoder
    state flags rather than simple character counts. Never perform arithmetic on it!

LAW #2: The Multi-Byte Unicode Boundary Law
  - UTF-8 characters span 1 to 4 bytes. English letters = 1 byte, Bengali/Rupee (₹)
    = 3 bytes, Emojis = 4 bytes. Seeking into the middle of a 3-byte character
    causes immediate UnicodeDecodeError!

LAW #3: The Windows CRLF Translation Law
  - On Windows, CRLF ('\r\n') takes 2 bytes on disk but 1 char in memory ('\n').
    Always use newline='' when byte accuracy is required.

LAW #4: The Binary Mode Arithmetic Law
  - In binary mode ('rb' / 'rb+'), all text decoders are disabled. True relative
    seeking (+/- offsets) with SEEK_CUR and SEEK_END is 100% mathematically exact.

3. 10 SIMPLE SCENARIOS & EXAMPLES CHEAT SHEET
--------------------------------------------------------------------------------
1. Rewind to Start:
   f.seek(0)  # Resets cursor back to byte 0 for multi-pass scans.

2. Measure File Size in Bytes:
   with open('data.bin', 'rb') as f:
       f.seek(0, 2)
       size = f.tell()  # Returns total byte length

3. Skip Metadata Banners:
   for _ in range(4): f.readline()  # Skip comment lines
   data_start = f.tell()             # Save bookmark

4. In-Place Field Update ('r+' mode):
   with open('ledger.txt', 'r+', encoding='utf-8') as f:
       f.seek(status_offset)
       f.write('APPROVED')

5. Multi-Pass Analysis without Reopening:
   count = sum(1 for _ in f)
   f.seek(0)  # Rewind to compute average in pass 2

6. Binary Relative Seeking (SEEK_CUR):
   with open('records.dat', 'rb') as f:
       f.seek(16, 0)   # Skip header
       f.seek(4, 1)    # Skip 4 bytes forward from current pos

7. Read Last N Bytes from EOF (SEEK_END):
   with open('app.log', 'rb') as f:
       f.seek(-100, 2) # Read trailing 100 bytes of log
       tail_data = f.read()

8. Fast Line Indexing for O(1) Random Access:
   index = {line_no: f.tell() ...}
   f.seek(index[500]) # Instant jump to line 500

9. Unicode Multi-Byte Safety:

10. Fixed-Width Binary Struct Records:

5. SENIOR PITFALLS & PRE-FLIGHT CHECKLIST
--------------------------------------------------------------------------------
- [ ] Use binary mode ('rb'/'rb+') whenever calculating relative byte offsets.
- [ ] In text mode, strictly restrict seek() targets to 0, EOF, or tell() cookies.
- [ ] In 'r+' mode, pad replacement strings to match exact field byte widths.
- [ ] On Windows CSV files, specify newline='' to prevent CRLF offset distortion.
- [ ] In multi-threaded programs, guard shared file descriptors with threading.Lock().
- [ ] Verify random access capability using file.seekable().
