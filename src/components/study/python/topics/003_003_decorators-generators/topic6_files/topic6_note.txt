1. ITERABLE VS ITERATOR
--------------------------------------------------------------------------------
  • Iterable : Object implementing `__iter__()` returning an iterator (e.g. list, tuple, dict).
  • Iterator : Object implementing `__iter__()` returning self, and `__next__()` returning elements.

--------------------------------------------------------------------------------
2. HOW PYTHON'S `for` LOOP RUNS
--------------------------------------------------------------------------------
  iterator = iter(iterable)
  while True:
      try:
          item = next(iterator)
          # Process item
      except StopIteration:
          break

--------------------------------------------------------------------------------
3. SENTINEL PROTOCOL: `iter(callable, sentinel)`
--------------------------------------------------------------------------------
  # Reads 4KB chunks until end of file (b""):
  for chunk in iter(lambda: f.read(4096), b""):
      process(chunk)
