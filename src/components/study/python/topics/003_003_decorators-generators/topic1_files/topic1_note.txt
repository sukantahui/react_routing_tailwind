1. THE LEGB SCOPE RESOLUTION RULE
--------------------------------------------------------------------------------
  • L (Local)     : Inside current function
  • E (Enclosing) : Inside parent functions (def inside def)
  • G (Global)    : Top-level module variables
  • B (Built-in)  : Python built-in names (len, range, max)

--------------------------------------------------------------------------------
2. CLOSURE ANATOMY
--------------------------------------------------------------------------------
  A closure remembers values in enclosing scopes even after the outer function
  finishes execution!
  Inspected via: `fn.__closure__[0].cell_contents`

--------------------------------------------------------------------------------
3. THE `nonlocal` KEYWORD
--------------------------------------------------------------------------------
  def make_counter():
      count = 0
      def increment():
          nonlocal count  # Mandatory to mutate enclosing variable!
          count += 1
          return count
      return increment
