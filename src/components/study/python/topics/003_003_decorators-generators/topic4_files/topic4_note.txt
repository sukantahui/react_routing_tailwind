1. THE 3-TIER DECORATOR FACTORY BLUEPRINT
--------------------------------------------------------------------------------
  # Tier 1: Factory (takes decorator parameters)
  def repeat(num_times: int = 3):
      # Tier 2: Decorator (takes target function)
      def decorator(func):
          # Tier 3: Wrapper (takes runtime arguments)
          @functools.wraps(func)
          def wrapper(*args, **kwargs):
              for _ in range(num_times):
                  result = func(*args, **kwargs)
              return result
          return wrapper
      return decorator

--------------------------------------------------------------------------------
2. HOW `@repeat(3)` EVALUATES
--------------------------------------------------------------------------------
  @repeat(3)
  def greet(): pass

  # Step 2: greet = dec(greet)
