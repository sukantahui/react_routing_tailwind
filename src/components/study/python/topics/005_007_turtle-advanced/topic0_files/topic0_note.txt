1. WHAT IS RECURSION VISUALLY?
--------------------------------------------------------------------------------
Recursion in computer graphics is the process where a function draws a geometric shape
and then invokes a smaller, transformed clone of itself.
This generates self-similar patterns known as FRACTALS (trees, snowflakes, spirals).

2. THE TWO MANDATORY PILLARS OF RECURSION
--------------------------------------------------------------------------------
1. The Base Case (The Guard):
   A stopping condition (`if depth == 0 or size < 5: return`) that halts further calls.
   Without a base case, the function calls itself indefinitely, causing `RecursionError: maximum recursion depth exceeded`.

2. The Recursive Step (The Progression):
   Calls the function with reduced arguments (`draw(size * 0.75, depth - 1)`),
   guaranteeing mathematical convergence toward the base case.

3. WINDING VS UNWINDING PHASES
--------------------------------------------------------------------------------
- Winding Phase: The function dives deeper into memory, pushing new frames onto the Call Stack.
- Unwinding Phase: After hitting the base case, returns bubble back up the stack.
