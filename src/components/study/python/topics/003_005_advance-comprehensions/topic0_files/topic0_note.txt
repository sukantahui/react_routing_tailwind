1. THE THREE COMPREHENSION CONTAINERS
--------------------------------------------------------------------------------
  * List Comprehension : [x * 2 for x in seq if x > 0]
  * Dict Comprehension : {k: v for k, v in pairs if v > 0}
  * Set Comprehension  : {x.upper() for x in seq}  (Auto-Deduplicated)

--------------------------------------------------------------------------------
2. FILTERING IF vs TERNARY IF-ELSE
--------------------------------------------------------------------------------
  * Filtering (Subset)      : [x for x in seq if x >= 50]
  * Transformation (All)    : ["PASS" if x >= 50 else "FAIL" for x in seq]
  * Combined (Both)         : [A if cond1 else B for x in seq if filter_cond]

--------------------------------------------------------------------------------
3. DICTIONARY INVERSION
--------------------------------------------------------------------------------
  * 1-to-1 Inversion : {v: k for k, v in orig_dict.items()}
  * 1-to-Many Group  : {val: [k for k, v in d.items() if v == val] for val in set(d.values())}
