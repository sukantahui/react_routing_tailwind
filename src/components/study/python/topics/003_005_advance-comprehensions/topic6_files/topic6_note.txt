1. PURE FUNCTION INVARIANTS
--------------------------------------------------------------------------------
  * Deterministic: Same input ALWAYS returns exact same output
  * Zero Side-Effects: Never mutates arguments, globals, or external I/O
  * Referential Transparency: func(x) can be replaced with its returned value

--------------------------------------------------------------------------------
2. FROZEN DATACLASS & COPY-ON-WRITE
--------------------------------------------------------------------------------
  @dataclass(frozen=True)
  class Student:
      id: str
      fee: Decimal
      badges: Tuple[str, ...] = ()

  # Update without mutating:
  updated_student = dataclasses.replace(student, fee=new_fee)

3. FUNCTIONAL STATE REDUCER
--------------------------------------------------------------------------------
  def reducer(state: State, action: Action) -> State:
      return {**state, "balance": state["balance"] + action["amount"]}
