1. SHORT-CIRCUIT EVALUATION
--------------------------------------------------------------------------------
  * any(generator) : Halts immediately on the FIRST True value
  * all(generator) : Halts immediately on the FIRST False value

--------------------------------------------------------------------------------
2. VACUOUS TRUTH ON EMPTY LISTS
--------------------------------------------------------------------------------
  * all([]) == True   (Vacuously True: every element in empty set passes)
  * any([]) == False  (False: no element exists to pass)
  * Defensive Check: if seq and all(cond for x in seq): ...

--------------------------------------------------------------------------------
3. GENERATOR VS LIST COMPREHENSION TRAP
--------------------------------------------------------------------------------
  * Correct   : any(check(x) for x in stream)    # O(1) Memory, short-circuits
  * DANGEROUS : any([check(x) for x in stream])  # O(N) Memory, NO short-circuit!
