1. ESSENTIAL PDB DEBUGGER COMMANDS
--------------------------------------------------------------------------------
  • n (next)     : Execute current line, stop at next line in same function.
  • s (step)     : Step into the function call on the current line.
  • c (continue) : Resume execution until the next breakpoint.
  • q (quit)     : Abort debugging session and terminate program.
  • p <expr>     : Evaluate and print value of variable or expression.
  • w (where)    : Print the entire call stack with current frame arrow.
  • u (up)       : Move current frame up one level in the call stack.
  • d (down)     : Move current frame down one level in the call stack.
  • l (list)     : Show 11 lines of source code around current line.

--------------------------------------------------------------------------------
2. SETTING BREAKPOINTS (PYTHON 3.7+)
--------------------------------------------------------------------------------
  def calculate(val):
      breakpoint()  # Drops directly into interactive (Pdb) prompt!
      return val * 2

3. POST-MORTEM DEBUGGING
--------------------------------------------------------------------------------
  $ python -m pdb my_script.py
