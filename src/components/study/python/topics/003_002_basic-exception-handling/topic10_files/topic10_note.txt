--------------------------------------------------------------------------------
1. THE FUNDAMENTAL GOLDEN RULE
--------------------------------------------------------------------------------
  • Use `raise`  : For all public function input validation, user inputs, auth.
  • Use `assert` : For internal programmer sanity checks, postconditions, invariants.

--------------------------------------------------------------------------------
2. THE PYTHON `-O` FLAG (WHY ASSERTS DISAPPEAR)
--------------------------------------------------------------------------------
  Running `python -O script.py` sets `__debug__ = False` and completely removes
  every `assert` statement from bytecode during compilation!
  -> Therefore, never use assert for security or business validations!

--------------------------------------------------------------------------------
3. THE TUPLE TRAP
--------------------------------------------------------------------------------
  ❌ BAD  : assert (score >= 0, "Error")  # Non-empty tuple -> ALWAYS TRUE!
  ✓ GOOD : assert score >= 0, "Error"    # Evaluates boolean properly
