2. EAFP VS LBYL
--------------------------------------------------------------------------------
  • EAFP (Pythonic): try: return data[key] except KeyError: return None
  • LBYL (Cautious): if key in data: return data[key] else: return None

--------------------------------------------------------------------------------
3. THE 5 CARDINAL RULES OF PYTHON EXCEPTION HANDLING
--------------------------------------------------------------------------------
  1. Never use bare `except:` or `except Exception: pass` (Silent Swallow).
  2. Always catch the most specific exception class first.
  3. Validate public inputs with `raise` (Fail-Fast); check math with `assert`.
  4. Use `raise ... from e` when wrapping low-level errors into domain exceptions.
  5. Always maintain clean atomic rollback guarantees in financial/data writes.
