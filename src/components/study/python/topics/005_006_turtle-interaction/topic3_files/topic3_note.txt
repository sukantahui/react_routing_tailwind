1. SCREEN.ONCLICK VS TURTLE.ONCLICK
--------------------------------------------------------------------------------
- `screen.onclick(fun, btn=1)`:
  Global listener. Fires whenever the user clicks anywhere on the canvas background.
  Useful for drawing tools, spawning objects, or global UI clicks.

- `turtle.onclick(fun, btn=1)`:
  Object-specific listener. Fires ONLY when the user clicks directly on that
  particular Turtle's visible shape polygon.
  Useful for buttons, interactive NPCs, targets, and draggable sprites!

2. MULTI-BUTTON MOUSE DISPATCHING
--------------------------------------------------------------------------------
- `btn=1`: Left mouse button (primary action / draw)
- `btn=2`: Middle mouse button / scroll wheel click (auxiliary / clear)
- `btn=3`: Right mouse button (context menu / alt-fire / secondary action)

3. COORDINATE PARAMETERS
--------------------------------------------------------------------------------
Both `screen.onclick` and `turtle.onclick` pass the exact `(x, y)` canvas coordinates
of the click event directly into the bound callback function: `def on_click(x, y):`
