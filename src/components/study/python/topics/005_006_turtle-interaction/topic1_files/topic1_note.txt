1. WHAT IS WINDOW FOCUS?
--------------------------------------------------------------------------------
In modern windowed operating systems (Windows, macOS, Linux), multiple applications
exist simultaneously on screen, but only ONE window can hold Keyboard Focus at any time.
The OS directs physical keyboard keystrokes exclusively to the active focused window.

2. WHAT DOES SCREEN.LISTEN() DO?
--------------------------------------------------------------------------------
- Tells Tkinter's internal canvas widget to request and claim operating system
  keyboard focus (`canvas.focus_force()`).
- Without calling `screen.listen()`, the window displays graphics normally,
  but completely ignores all keyboard event handlers (`onkey`, `onkeypress`).

3. THE AUTO-REFOCUS BEST PRACTICE
--------------------------------------------------------------------------------
If a user clicks outside the window and returns, focus may be dropped.
Best practice: Add `screen.listen()` inside your mouse click handlers so that
any user click immediately re-claims keyboard focus!
