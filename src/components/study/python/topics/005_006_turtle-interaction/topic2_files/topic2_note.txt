1. ONKEY VS ONKEYPRESS VS ONKEYRELEASE
--------------------------------------------------------------------------------
- `screen.onkeypress(fun, key)`:
  Fires immediately when the physical key is pressed down.

- `screen.onkeyrelease(fun, key)`:
  Fires when the user releases the physical key.

- `screen.onkey(fun, key)`:
  In modern Python Turtle, acts as a convenience alias for `onkeyrelease` or `onkeypress`.

2. STACCATO VS CONTINUOUS MULTI-KEY STATE TRACKING
--------------------------------------------------------------------------------
- Beginner Anti-Pattern (Staccato):
  Directly calling `t.forward(10)` inside `onkeypress`. Causes a 500ms OS key-repeat
  stutter and cannot handle diagonal multi-key movement (e.g. Up + Right).

- Professional Best Practice (Key State Dictionary):
  Set `keys['Up'] = True` on press and `keys['Up'] = False` on release.
  A 60 FPS `ontimer` physics loop checks active keys and applies smooth velocity!

3. COMMON KEYSYM STRINGS
--------------------------------------------------------------------------------
- Arrows: `"Up"`, `"Down"`, `"Left"`, `"Right"`
- Controls: `"space"`, `"Return"`, `"Escape"`, `"Tab"`, `"BackSpace"`
- Characters: `"w"`, `"a"`, `"s"`, `"d"` (case-sensitive!)
