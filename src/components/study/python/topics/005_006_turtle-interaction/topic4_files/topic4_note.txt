1. WHAT IS TURTLE.ONDRAG()?
--------------------------------------------------------------------------------
`turtle.ondrag(fun, btn=1)` binds a callback function that executes continuously
as the user clicks and drags that specific turtle across the canvas.
The callback automatically receives the mouse's current `(x, y)` Cartesian coordinates.

2. PREVENTING EVENT QUEUE BUILDUP (THE UNBIND-REBIND PATTERN)
--------------------------------------------------------------------------------
Moving a turtle takes several milliseconds. If the user drags rapidly, thousands of
drag events flood the queue, causing lag.
Best Practice Pattern:
```python
def on_drag(x, y):
    t.ondrag(None)      # Temporarily pause drag events
    t.goto(x, y)        # Perform move
    t.ondrag(on_drag)   # Re-enable drag events
```

3. DRAG CONSTRAINTS & GRID SNAPPING
--------------------------------------------------------------------------------
- 1D Axis Sliders: Clamp `x` between `[min_x, max_x]` and lock `y = 0`.
- Snap to Grid: `snap_x = round(x / grid_size) * grid_size`.
