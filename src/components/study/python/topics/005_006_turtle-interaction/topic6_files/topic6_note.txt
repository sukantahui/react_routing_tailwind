1. WHAT IS A FINITE STATE MACHINE (FSM)?
--------------------------------------------------------------------------------
A Finite State Machine organizes application lifecycle into discrete states:
1. `MENU`: Title screen, character selection, instructions.
2. `PLAYING`: Active 60 FPS physics, player controls, collision detection.
3. `PAUSED`: Physics frozen, modal pause overlay displayed.
4. `GAME_OVER`: High score display, stats summary, restart prompt.

2. STATE-DRIVEN INPUT ROUTING
--------------------------------------------------------------------------------
Rather than creating separate key bindings for every screen, a single key handler
checks the active state and routes accordingly:
```python
def handle_space():
    if state == "MENU": start_game()
    elif state == "PLAYING": pause_game()
    elif state == "PAUSED": resume_game()
    elif state == "GAME_OVER": restart_game()
```

3. STATE-SPECIFIC RENDERING PASSES
--------------------------------------------------------------------------------
Inside the 60 FPS loop, branch rendering based on `current_state`.
When in `PAUSED`, render frozen world graphics followed by a dim modal dialog box.
