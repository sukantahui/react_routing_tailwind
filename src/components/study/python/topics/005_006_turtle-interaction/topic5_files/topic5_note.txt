1. ROTATIONAL STEERING & INERTIA (ASTEROIDS MODEL)
--------------------------------------------------------------------------------
- Heading Angle: `angle += turn_speed` (Left/Right keys)
- Thrust Acceleration: `vx += math.cos(rad) * thrust`, `vy += math.sin(rad) * thrust`
- Friction / Damping: `vx *= 0.985`, `vy *= 0.985` (Prevents runaway infinite velocity)

2. TRIGONOMETRIC MOUSE AIMING (ARTILLERY TURRETS)
--------------------------------------------------------------------------------
To point a cannon or weapon directly toward mouse coordinates `(mx, my)`:
```python
dx = mx - turret_x
dy = my - turret_y
aim_angle = math.degrees(math.atan2(dy, dx))
```

3. DIFFERENTIAL TANK DRIVE
--------------------------------------------------------------------------------
- Linear Velocity: `(v_left + v_right) / 2.0`
- Angular Velocity: `(v_right - v_left) * scale`
Allows turning in place (skid steering) and zero-radius pivot turns.
