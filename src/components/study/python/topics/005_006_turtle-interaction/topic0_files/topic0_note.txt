1. SEQUENTIAL VS EVENT-DRIVEN PARADIGM
--------------------------------------------------------------------------------
- Sequential Programming:
  Code runs top-to-bottom in a strict, predetermined linear sequence.

- Event-Driven Programming:
  Program registers callback handlers for specific events (clicks, keypresses, timers)
  and hands execution over to an Event Dispatcher Loop (`screen.mainloop()`).
  The user's actions dictate when and in what order code executes!

2. THE EVENT-DRIVEN TRIAD
--------------------------------------------------------------------------------
1. Event: An external action (e.g. Mouse click at `(x, y)`, Keypress `'space'`).
2. Listener / Binding: Connects an event type to a Python function reference:
   `screen.onclick(handle_click)`
3. Callback Function: The Python function executed asynchronously when the event fires.

3. FIRST-CLASS FUNCTIONS & CALLBACK RULES
--------------------------------------------------------------------------------
- Pass the function name WITHOUT parentheses:
  `screen.onclick(my_function)`  -> CORRECT (Passes reference)
  `screen.onclick(my_function())` -> BUG (Calls immediately and passes None)
