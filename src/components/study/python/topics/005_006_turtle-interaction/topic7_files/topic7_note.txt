1. TWO BUTTON ARCHITECTURES IN TURTLE
--------------------------------------------------------------------------------
1. Bounding Box Manager (`screen.onclick` + Geometry Math):
   - Define buttons as dictionary structs `{'id': 'play', 'x': -100, 'y': 0, 'w': 200, 'h': 50}`
   - In `screen.onclick(x, y)`: test `btn['x'] <= x <= btn['x'] + btn['w']`
   - Advantage: Infinite buttons drawn with 1 turtle; perfect for toolbars and menus.

2. Turtle Sprite Buttons (`turtle.onclick`):
   - Instantiate a `turtle.Turtle()`, set `shapesize(2.5, 6)`
   - Attach `t.onclick(handler)`
   - Advantage: Automatic polygon hit testing and tactile depression animations!

2. TACTILE COMPRESSION ANIMATION
--------------------------------------------------------------------------------
When a button is clicked, shrink its dimensions temporarily:
`btn.shapesize(2.2, 5.5)` → `screen.ontimer(lambda: btn.shapesize(2.5, 6), 100)`
This gives the user immediate visual and tactile feedback.

3. BUILDING A COMPLETE UI TOOLBAR
--------------------------------------------------------------------------------

a persistent bottom-docked dashboard ribbon.
