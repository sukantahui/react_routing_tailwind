1. CPYTHON RUNTIME INTERNALS CHEATSHEET
--------------------------------------------------------------------------------
  1. Memory Management:
     - Primary: Reference Counting (freed immediately when count reaches 0)
     - Secondary: Generational Cyclic Garbage Collector (Gen 0, 1, 2 for circular refs)
  
  2. GIL (Global Interpreter Lock):
     - A mutex that prevents multiple native threads from executing Python bytecodes simultaneously
     - I/O-bound tasks: Use threading or asyncio (GIL released during OS I/O calls)
     - CPU-bound tasks: Use multiprocessing (separate processes, separate GILs, separate memory)

  3. MRO (Method Resolution Order):
     - Uses C3 Linearization algorithm to determine method inheritance order
     - Check order via: ClassName.__mro__ or ClassName.mro()

2. CLASSIC CODING CHALLENGES
--------------------------------------------------------------------------------
  1. LRU Cache (Least Recently Used) in O(1):
     from collections import OrderedDict
     class LRUCache:
         def __init__(self, capacity: int):
             self.cap = capacity
             self.cache = OrderedDict()
         def get(self, key):
             if key not in self.cache: return -1
             self.cache.move_to_end(key)
             return self.cache[key]
         def put(self, key, val):
             if key in self.cache: self.cache.move_to_end(key)
             self.cache[key] = val
             if len(self.cache) > self.cap: self.cache.popitem(last=False)
