1. THE PROFESSIONAL SRC/ DIRECTORY LAYOUT
--------------------------------------------------------------------------------
  my_project/
  ├── pyproject.toml              # Modern build & packaging manifest (PEP 621)
  ├── README.md                   # Project overview & quickstart instructions
  ├── LICENSE                     # MIT / Apache 2.0 open-source license
  ├── .gitignore                  # Ignore .venv, __pycache__, .coverage, .env
  ├── .env.example                # Sample environment variables template
  ├── src/                        # SOURCE DIRECTORY (Prevents accidental imports!)
  │   └── my_package/             # Core Python package namespace
  │       ├── __init__.py         # Package version & public API exports (__all__)
  │       ├── __main__.py         # Allows: python -m my_package
  │       ├── config.py           # Dataclass environment configuration
  │       ├── models/             # Domain entities (Data classes, Enums)
  │       ├── repositories/       # Database queries & storage persistence
  │       ├── services/           # Business logic & calculation rules
  │       └── cli/                # CLI commands & user interfaces
  └── tests/                      # AUTOMATED TEST SUITE
      ├── conftest.py             # Shared pytest fixtures
      ├── unit/                   # Fast isolated unit tests
      └── integration/            # Multi-component & database tests
