1. ENTERPRISE LOGGING STANDARDS
--------------------------------------------------------------------------------
  1. Standard Log Levels:
     - DEBUG (10): Detailed diagnostic information for developers
     - INFO (20): Normal confirmation of application operations
     - WARNING (30): Unexpected events that did not halt execution
     - ERROR (40): Operation failed due to an error (e.g. payment failed)
     - CRITICAL (50): Severe crash or outage requiring immediate alert

  2. Rotating File Handlers:
     from logging.handlers import RotatingFileHandler
     handler = RotatingFileHandler("app.log", maxBytes=5_000_000, backupCount=5)

2. CUSTOM EXCEPTION HIERARCHY
--------------------------------------------------------------------------------
  class InstitutionalError(Exception):
      """Base exception for all domain errors."""
      def __init__(self, message: str, code: str = "GENERIC_ERROR"):
          super().__init__(message)
          self.code = code

  class StudentNotFoundError(InstitutionalError):
      def __init__(self, sid: str):
          super().__init__(f"Student '{sid}' not found.", code="STUDENT_NOT_FOUND")
