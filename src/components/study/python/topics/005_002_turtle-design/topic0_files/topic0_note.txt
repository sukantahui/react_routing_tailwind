1. WHAT IS PEN CONTROL IN TURTLE GRAPHICS?
--------------------------------------------------------------------------------
By default, whenever a Turtle moves across the screen, it leaves a continuous
trail behind it (as if dragging an active pen against paper). Pen control allows
programmers to manipulate this drawing behavior dynamically:

1. `t.penup()` (or `t.up()`, `t.pu()`):
   - Lifts the virtual pen off the canvas.
   - Any subsequent movement (`forward`, `goto`, `setposition`) will change
     the turtle's coordinates WITHOUT leaving a visible line.

2. `t.pendown()` (or `t.down()`, `t.pd()`):
   - Lowers the virtual pen back onto the canvas.
   - Movement commands will resume drawing lines.

3. `t.pensize(width)` (or `t.width(width)`):
   - Sets the line thickness in integer pixels (e.g., `pensize(5)` draws a
     5-pixel wide stroke).

4. `t.isdown()`:
   - Returns boolean `True` if the pen is currently drawing, or `False` if lifted.

2. CORE USE CASES OF PEN CONTROL
--------------------------------------------------------------------------------
1. Disconnected Shapes (Island Hopping):
   Moving the turtle to separate quadrants of the screen to draw multiple
   independent figures without trailing connecting lines.

2. Dashed and Dotted Lines:
   Iteratively toggling `pendown()` (move 20px) and `penup()` (move 15px) inside
   a loop to create perforated borders and technical gridlines.

3. Dynamic Line Width Gradients:
   Increasing or decreasing `pensize(i)` inside iterative spiraling loops to create
   calligraphic or 3D depth illusions.

3. GOLDEN RULES FOR CLEAN PEN MANAGEMENT
--------------------------------------------------------------------------------
- Always pair repositioning with `penup()` -> `goto(x, y)` -> `pendown()`.
- Check `t.isdown()` before running nested subroutines if a function requires
  restoring the original pen state.
- Set `pensize()` before starting complex geometric loops for consistent stroke weight.
