1. OOP TURTLE INSTANTIATION VS PROCEDURAL SINGLETON
--------------------------------------------------------------------------------
  Procedural Singleton (Amateur):
    import turtle
    turtle.forward(100) # Operates on hidden global anonymous singleton

  Object-Oriented Architecture (Pro):
    import turtle
    t1 = turtle.Turtle() # Instance 1 (e.g. Mamata's Pen)
    t2 = turtle.Turtle() # Instance 2 (e.g. Mahima's Pen)
    
    t1.color("cyan")
    t2.color("magenta")
    t1.forward(100)
    t2.backward(100)

2. TURTLE LIFECYCLE & STATE ATTRIBUTES
--------------------------------------------------------------------------------
  - t.shape("turtle")   -> Built-in shapes: "arrow", "turtle", "circle", "square", "triangle", "classic"
  - t.shapesize(2, 2)   -> Multiplies turtle cursor width and length (stretch_wid, stretch_len)
  - t.clone()           -> Creates an exact duplicate turtle with identical position, heading & pen
  - t.hideturtle()      -> Makes cursor invisible for crisp vector art rendering
  - t.showturtle()      -> Restores cursor visibility
