1. SCREEN CONFIGURATION METHODS
--------------------------------------------------------------------------------
  1. screen.setup(width, height, startx, starty):
     - Sets the physical OS window dimensions and screen positioning.
     - Integers represent pixels (e.g. width=800, height=600).
     - Floats represent fraction of user display screen (e.g. width=0.75 -> 75% of monitor).
     - startx, starty define top-left corner coordinates on the physical monitor.

  2. screen.title("Text"):
     - Sets the OS window bar title.

  3. screen.bgcolor(color):
     - Sets background color. Supports named strings ("black"), Hex ("#0f172a"),
       or RGB tuples with screen.colormode(255).

  4. screen.screensize(canvwidth, canvheight, bg):
     - Sets the internal virtual drawing canvas dimensions (adds scrollbars if larger
       than physical window viewport).
