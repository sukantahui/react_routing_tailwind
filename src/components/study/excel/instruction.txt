4. REACT 19 & TAILWIND CSS TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
• Strict React 19 Function Components:
    - Pure JavaScript functions only (NO class components).
    - Use standard hooks (`useState`, `useEffect`, `useRef`, `useMemo`, `useCallback`) intentionally.
    - No unnecessary re-renders or missing dependency warnings.
• Tailwind CSS Guidelines:
    - Latest Tailwind CSS with NO external plugins, NO tailwind.config.js requirements.
    - Zero-config animations using Tailwind arbitrary values (e.g. `animate-[fadeIn_0.6s_ease-out]`).
    - Use inline `<style>` keyframes scoped to the component when custom animations are needed.
    - MUST support `motion-safe` for accessibility.
    - Use `clsx` for dynamic class composition to avoid messy backtick strings:
        import clsx from "clsx";
• Visual & Layout Rules:
    - DARK MODE BY DEFAULT: Main wrapper `dark bg-slate-950 text-slate-100 min-h-screen py-8 px-4 sm:px-6 lg:px-8`.
    - SINGLE-COLUMN VERTICAL FLOW: Stack all cards and sections one after another (`max-w-5xl mx-auto space-y-10`).
      Do NOT create cramped horizontal multi-column splits for primary reading content.
    - NEVER USE `opacity-0` (Prevents invisible text if JavaScript animation observer fails).
    - Subtle hover elevation and soft glow borders on cards (`hover:border-sky-500/40 transition-all duration-300`).

8. GENERATION & WORKFLOW PROTOCOL
--------------------------------------------------------------------------------
1. Read the topic list from the module in `excel-basic-to-advanced.json`.
2. Generate the common module workbook `.xlsx` inside `excel_files/[module_name].xlsx` using `generate_sheets.cjs` with dedicated sheets for each topic.
3. Generate ONE topic at a time (e.g. `Topic0.jsx`) with the embedded `handleDownload` button, `ExcelFileLoader`, and its companion `topic0_files/topic0_questions.js` (30 questions).
4. Ensure every single file is 100% complete, fully articulated (no `// TODO` or truncated sections), and ready for production copy-pasting.
5. Wait for confirmation before advancing to the next sequential topic (`Topic1.jsx`, `Topic2.jsx`, etc.).
