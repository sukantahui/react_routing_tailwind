PRIMARY CONCEPT:

TEACHER'S ADVICE:
Congratulations on completing What-If Analysis and Optimization! You have built the Markowitz Nobel-Prize winning portfolio model right inside Excel. You now possess world-class financial engineering capabilities.

COMMON TRAPS TO AVOID:
- Selecting Simplex LP for Portfolio Variance (Fails): Portfolio variance contains quadratic terms (`w1*w2*Cov12`), which are non-linear; Simplex LP throws 'Linearly Conditions not satisfied'. → Fix: Always select GRG Nonlinear engine for Markowitz portfolio variance optimization.
- Omitting the 100% Budget Constraint (Sum of Weights = 1): Forgetting `SUM(Weights) = 1` allows Solver to achieve low risk by investing ₹0, or high returns by investing 500% capital. → Fix: Add the mandatory equality constraint: `TotalWeightCell = 1.0`.
- Non-Positive-Definite Covariance Matrix: Using inconsistent historical time windows creates mathematically corrupted covariance matrices where variance returns negative numbers. → Fix: Calculate covariance using Excel's native `=COVARIANCE.S()` across synchronized historical date ranges.
