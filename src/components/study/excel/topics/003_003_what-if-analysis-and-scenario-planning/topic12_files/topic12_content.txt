5. TROUBLESHOOTING & COMMON ERRORS
• Omitting Market Demand Ceilings:
  Root Cause: Solver allocates 100% of factory capacity to the single highest-margin product, producing 50,000 units when market demand is only 5,000.
  Diagnostic Fix: Add `Production <= MaxMarketDemand` constraints for every product.
• Fractional Unit Outputs in Physical Goods:
  Root Cause: Producing 1,420.65 units of heavy industrial valves.
  Diagnostic Fix: Add Integer (`int`) constraint to decision variable cells.
• Failing to Save Solver Model on Sheet:
  Root Cause: Reopening the sheet later and finding Solver settings blank.
  Diagnostic Fix: Solver > Options > 'Save Model' to store configuration parameters directly in worksheet cells.

6. PRO TIPS & SHORTCUTS
• Save Solver Model (Solver > Options > Save Model): Stores entire optimization configuration permanently in worksheet cells.
• Clean 3-Block Layout (Unit Margins -> Variables -> Constraint Matrix): The industrial standard layout for optimization workbooks.
• Capacity Slack Column (=Available - Used): Visual indicator showing remaining unused capacity for each resource.
