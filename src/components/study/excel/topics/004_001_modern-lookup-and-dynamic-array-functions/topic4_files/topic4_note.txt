Topic: Sorting Spilled Arrays Dynamically with SORT (Single Index, Ascending/Descending)
Module: 004_001_modern-lookup-and-dynamic-array-functions
Instructor: Sukanta Hui (Coder & AccoTax)

Key Formula Signature:
=SORT(array, [sort_index], [sort_order], [by_col])

Arguments Breakdown:
1. `array` (Required): The data matrix or spilled array reference to sort.
2. `[sort_index]` (Optional): Number indicating the row/column to sort by (1-based index, default: 1).
3. `[sort_order]` (Optional):
   • `1` (Default): Ascending order (A to Z, smallest to largest).
   • `-1`: Descending order (Z to A, largest to smallest).
4. `[by_col]` (Optional):
   • `FALSE` / Omitted (Default): Sorts vertically by rows.
   • `TRUE`: Sorts horizontally by columns.

Core Architectural Insights:
- Non-Destructive: Original records stay unaltered; the sorted view is projected dynamically.
- Composable: Pairs with UNIQUE and FILTER (`=SORT(UNIQUE(FILTER(...)), 2, -1)`).
- Elastic: Downstream formulas referencing `J2#` reflect dynamic sort ranking live.
