5. TROUBLESHOOTING & COMMON ERRORS
• Unpivoting Selected Columns Instead of 'Unpivot Other Columns':
  Root Cause: Using 'Unpivot Columns' hardcodes column names; when next month's data arrives, the query fails.
  Diagnostic Fix: Always select fixed ID columns and click 'Unpivot Other Columns'.
• Leaving Dirty 'Changed Type' Steps Hardcoding Deleted Columns:
  Root Cause: Auto-generated Changed Type step referencing deleted columns breaking refresh.
  Diagnostic Fix: Clean up intermediate M-code steps before publishing queries.
• Loading Massive Data to Worksheet Grid Instead of Data Model Only:
  Root Cause: Loading 5 million rows into Excel crashes sheet row limit (1,048,576).
  Diagnostic Fix: Select 'Only Create Connection' and check 'Add this data to the Data Model'.

6. PRO TIPS & SHORTCUTS
• Unpivot Other Columns (Right-click ID cols > Unpivot Other Columns): Dynamic unpivoting that automatically handles new months.
• Load to Data Model Only (Close & Load To > Only Create Connection + Data Model): Handles multi-million row datasets with zero worksheet lag.
• View Advanced Editor (Home > Advanced Editor): Inspects and edits underlying Power Query M-Code.
