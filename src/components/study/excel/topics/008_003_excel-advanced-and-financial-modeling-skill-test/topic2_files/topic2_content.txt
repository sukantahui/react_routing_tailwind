2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: What-If Suite: Data Table: Data > What-If Analysis > Data Table (Row/Col Input) | Solver: Objective Min/Max, Changing Cells, Constraints

3. CORE TECHNICAL MECHANICS
1. Two-Variable Sensitivity Data Tables:
   Evaluates project Net Profit across 50 combinations of Price and Sales Volume simultaneously in an instant matrix.

2. Excel Solver Linear Programming:
   Maximizes Profit (`Objective: Max`) by adjusting production quantities (`Changing Cells`) subject to raw material and labor constraints (`<= Available`).

3. Goal Seek Back-Solving:
   Calculates exact required sales volume to achieve a target break-even profit margin.

5. TROUBLESHOOTING & COMMON ERRORS
• Reversing Row and Column Input Cells in Two-Variable Data Table:
  Root Cause: Swapping row/column inputs produces a matrix of completely inverted nonsensical numbers.
  Diagnostic Fix: Ensure Row Input Cell matches top header variable; Column Input Cell matches left header variable.
• Unbounded Solver Models (Infinite Profit / Crash):
  Root Cause: Forgetting to add non-negativity constraint (`Make Unconstrained Variables Non-Negative`).
  Diagnostic Fix: Always check 'Make Unconstrained Variables Non-Negative' in Solver.
• Data Table Formulas Not Recalculating:
  Root Cause: Excel calculation options set to 'Automatic Except for Data Tables'.
  Diagnostic Fix: Press F9 or set Calculation Options to Automatic.

6. PRO TIPS & SHORTCUTS
• Two-Variable Data Table (Data > What-If Analysis > Data Table): Instantly generates 2D sensitivity matrix.
• Top-Left Corner Formula (Link top-left cell of Data Table to Output Cell): Mandatory setup for Two-Variable Data Tables.
• Simplex LP in Solver (Select 'Simplex LP' for linear models): Fastest, guaranteed optimal solution for linear optimization.
