Dynamic Array Spilling & Array Reshaping Test is an essential evaluation milestone in spreadsheet mastery, data modeling rigor, and executive reporting.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Dynamic Arrays: =CHOOSEROWS(SORTBY(FILTER(Data, Cond), SortKey, -1), 1, 2, 3) | =TOCOL(Range, 1) | =WRAPROWS(Vector, 4) | =LET(...)

3. CORE TECHNICAL MECHANICS
1. Vectorized Dynamic Array Spilling:
   Single formula in top-left cell computes and spills across entire dynamic range (`#` spill operator).

2. Grid Reshaping (TOCOL / WRAPROWS):
   `=TOCOL(Range, 1)` flattens 2D matrices into single clean columns; `=WRAPROWS(Vector, 4)` wraps 1D lists into structured multi-column tables.

3. Column/Row Slicing (CHOOSEROWS / CHOOSECOLS):
   Extracts specific columns or top-N rows dynamically without writing multiple helper formulas.

5. TROUBLESHOOTING & COMMON ERRORS
• Spill Blockage Collision (#SPILL! Error):
  Root Cause: Non-empty cells or text blocking the dynamic array spill path.
  Diagnostic Fix: Clear all cells below and to the right of the formula cell.
• Forgetting Empty String Ignore Flag in TOCOL:
  Root Cause: `TOCOL(Range)` keeping blank rows.
  Diagnostic Fix: Pass `ignore = 1` to skip blanks: `=TOCOL(Range, 1)`.
• Referencing Single Cell Instead of Spill Range (#):
  Root Cause: Writing `=SUM(E2)` instead of `=SUM(E2#)` to reference the entire spilled array.
  Diagnostic Fix: Use the `#` spill operator: `=SUM(E2#)`.

6. PRO TIPS & SHORTCUTS
• The Spill Operator (#) (E2# (References entire spilled range)): Dynamic referencing that automatically sizes to array bounds.
• Flatten 2D to 1D (=TOCOL(Range, 1)): Flattens matrix into 1 column, ignoring blanks.
• Slice Top Rows (=CHOOSEROWS(SortedArray, 1, 2, 3)): Extracts top-N ranks dynamically.
