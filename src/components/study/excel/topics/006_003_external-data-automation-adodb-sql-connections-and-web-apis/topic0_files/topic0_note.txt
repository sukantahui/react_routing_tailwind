KEY FORMULA / SYNTAX:
ADODB Architecture: Set conn = CreateObject("ADODB.Connection") | Set rs = CreateObject("ADODB.Recordset") | conn.Open connStr | rs.Open sql, conn

PRIMARY CONCEPT:
Understanding ActiveX Data Objects (ADODB) architecture in Excel VBA: establishing database connections, executing server-side SQL queries, and streaming relational recordsets directly into RAM

TEACHER'S ADVICE:
ADODB gives Excel infinite power. You don't need to ask IT for CSV exports—you can write 5 lines of VBA, connect directly to SQL Server or MySQL, and pull exactly the data you need in 1 second.

COMMON TRAPS TO AVOID:
- Missing OLE DB / ODBC Driver on Client PC: Running ADO code on a computer that lacks the MySQL or PostgreSQL ODBC driver throws 'Data source name not found'. -> Fix: Verify driver installation or use standard Microsoft OLE DB providers for SQL Server / Access.
- Leaving Database Connections Open (Connection Leak): Forgetting to close `conn.Close` exhausts available connection pool sockets on the database server. -> Fix: Always close connections in clean-up blocks: `rs.Close: Set rs = Nothing: conn.Close: Set conn = Nothing`.
- Hardcoding Passwords in Plaintext VBA Modules: Writing `Password=MySecret123;` directly in VBA code exposes database credentials to anyone viewing the module. -> Fix: Store connection strings in protected configuration sheets or use Windows Integrated Authentication (`Trusted_Connection=Yes;`).
