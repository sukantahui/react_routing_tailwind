1. EXECUTIVE OVERVIEW
Executing SQL Queries (SELECT, INSERT, UPDATE, DELETE) directly from Excel VBA is an essential discipline in enterprise database engineering, cloud systems integration, and full-stack financial automation.
It provides the core protocols required to connect Excel directly to enterprise relational databases, query closed workbooks via SQL, and consume cloud REST APIs.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: SQL Execution: conn.Execute "INSERT INTO Table (Col1) VALUES ('Val1')" | conn.Execute "UPDATE Table SET Col1 = 'NewVal' WHERE ID = 101"

3. CORE TECHNICAL MECHANICS
1. The `conn.Execute` Command Pipeline:
   Dispatches non-query SQL statements (INSERT, UPDATE, DELETE) directly to the database engine with zero recordset overhead.

2. Tracking Affected Rows (`RecordsAffected`):
   `conn.Execute sqlStr, recordsAffected`. Returns the exact count of rows inserted, updated, or deleted by the query.

3. Atomic Batch Data Manipulation:
   Allows updating 50,000 customer records on the database server with a single SQL statement in milliseconds without pulling rows to Excel.

5. TROUBLESHOOTING & COMMON ERRORS
• Unsanitized Single Quotes in String Values (Syntax Error):
  Root Cause: Inserting a company name like `O'Reilly Steel` breaks SQL syntax (`'O'Reilly Steel'`), throwing runtime error.
  Diagnostic Fix: Sanitize strings by escaping single quotes: `Replace(strName, "'", "''")`.
• Accidental Table Wiping (Missing WHERE Clause):
  Root Cause: Executing `UPDATE Customers SET Status = 'Inactive'` without a `WHERE` clause updates the ENTIRE database table!
  Diagnostic Fix: Always double-check `WHERE` clauses before executing non-query SQL commands.
• SQL Type Mismatch on Dates and Decimals:
  Root Cause: Formatting dates with slashes (`12/04/2026`) instead of ISO standard format (`'2026-04-12'`).
  Diagnostic Fix: Format SQL dates strictly in ISO standard: `Format(myDate, "yyyy-mm-dd")`.

6. PRO TIPS & SHORTCUTS
• Escape Single Quotes (Replace(str, "'", "''")): Mandatory sanitizer to prevent SQL syntax errors.
• ISO Standard Date Format (Format(myDate, "yyyy-mm-dd")): Guarantees reliable date parsing across all database engines.
• Records Affected Counter (conn.Execute sql, lngRows: MsgBox lngRows & " rows updated!"): Provides instant feedback on affected record counts.
