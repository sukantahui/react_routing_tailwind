KEY FORMULA / SYNTAX:
ETL Pipeline: Extract (ADO SQL / REST API) → Transform (VBA RAM Array Cleansing) → Load (CopyFromRecordset / Staging Sheet)

PRIMARY CONCEPT:
Engineering enterprise Extract, Transform, and Load (ETL) data pipelines in Excel VBA: extracting from heterogeneous databases, normalizing data in RAM, and staging for financial models

TEACHER'S ADVICE:
Building an automated ETL pipeline is what transforms Excel into enterprise BI software. You extract from SQL Server, extract from MySQL, fetch live exchange rates from an API, clean everything in RAM, and load a perfect dashboard in 5 seconds.

COMMON TRAPS TO AVOID:
- Single Source Failure Halting Entire Pipeline: Database #2 timing out crashes the macro before extracting Database #3. → Fix: Wrap each extraction source in independent error-handling blocks so healthy sources continue processing.
- Inconsistent Date/Currency Formats Across Sources: Database A using US dates (MM/DD/YYYY) while Database B uses UK dates (DD/MM/YYYY). → Fix: Normalize all dates into ISO standard (`YYYY-MM-DD`) during the Transformation phase.
- Memory Leaks Across Multi-Database Loops: Failing to close and deallocate connection objects between loop iterations. → Fix: Explicitly close and set connections to Nothing after each source extraction.
