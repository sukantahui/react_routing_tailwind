5. TROUBLESHOOTING & COMMON ERRORS
• API Rate Limit Exhaustion (HTTP 429 Too Many Requests):
  Root Cause: Running the fetcher in a tight loop calling the API 1,000 times per minute, getting IP-blocked by the provider.
  Diagnostic Fix: Cache API responses locally and enforce a minimum 5-minute refresh interval.
• Unchecked API Provider Schema Changes:
  Root Cause: API provider renaming a JSON field breaks hardcoded key references.
  Diagnostic Fix: Include defensive key verification (`If json.Exists("rate") Then ...`).
• Crashing on No Internet Connection:
  Root Cause: Network disconnection throwing unhandled runtime error on `.Send`.
  Diagnostic Fix: Wrap `.Send` in structured error handling alerting the user to check internet connectivity.

6. PRO TIPS & SHORTCUTS
• Application.OnTime Scheduling (Application.OnTime Now + TimeValue("00:15:00"), "FetchLiveRates"): Schedules automated recurring background data refreshes.
• Local Cache Safeguard (Store last known good rate in cell): Ensures dashboard remains functional even when offline.
• Status 200 Verification (Verify http.Status = 200 before parsing): Guarantees robust execution across intermittent network drops.
