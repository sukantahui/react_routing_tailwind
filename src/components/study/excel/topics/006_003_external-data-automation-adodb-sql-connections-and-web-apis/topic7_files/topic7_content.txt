1. EXECUTIVE OVERVIEW
Parsing JSON responses in VBA using lightweight parser classes is an essential discipline in enterprise database engineering, cloud systems integration, and full-stack financial automation.
It provides the core protocols required to connect Excel directly to enterprise relational databases, query closed workbooks via SQL, and consume cloud REST APIs.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: JSON Parsing: Set json = JsonConverter.ParseJson(http.responseText) | Val = json("rates")("INR") | Loop: For Each item In json("data"): ... : Next item

3. CORE TECHNICAL MECHANICS
1. The JSON-to-VBA Object Mapping:
   JSON Objects (`{ "key": "value" }`) map to `Scripting.Dictionary`; JSON Arrays (`[ 1, 2, 3 ]`) map to VBA `Collection` objects.

2. Accessing Nested JSON Attributes:
   Traverses nested hierarchies intuitively: `dblRate = json("data")("rates")("INR")`.

3. Iterating JSON Array Collections:
   Loops through lists of objects: `For Each item In json("items"): ws.Cells(r, 1).Value = item("name"): r = r + 1: Next item`.

5. TROUBLESHOOTING & COMMON ERRORS
• Dictionary vs Collection Indexing Confusion:
  Root Cause: Attempting to access a Dictionary with numeric index `json(1)` or a Collection with a string key `json("name")` throws runtime error.
  Diagnostic Fix: Use string keys `dict("key")` for Objects `{}`; use numeric index or `For Each` for Arrays `[]`.
• Missing Scripting Runtime Reference for Dictionaries:
  Root Cause: JSON parsers relying on `Scripting.Dictionary` failing if reference is missing.
  Diagnostic Fix: Enable `Microsoft Scripting Runtime` or use late-bound Dictionary objects.
• Crashing on Null or Missing JSON Keys:
  Root Cause: Accessing a key that does not exist in the API response.
  Diagnostic Fix: Check if key exists: `If json.Exists("key") Then ...`.

6. PRO TIPS & SHORTCUTS
• VBA-JSON Library Standard (JsonConverter.ParseJson(responseText)): The open-source gold standard for JSON parsing in VBA.
• Nested Key Access (json("level1")("level2")("field")): Traverses nested JSON trees seamlessly.
• Array Loop Pattern (For Each rowItem In json("records") ... Next): Dumps JSON arrays directly into worksheet rows.
