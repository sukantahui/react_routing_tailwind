COMMON TRAPS TO AVOID:
- Leaking Connection Handles: Leaving connection objects unclosed. → Fix: Always close connections and set objects to Nothing.
- Vulnerable Concatenated SQL: Failing to parameterize dynamic query inputs. → Fix: Use `ADODB.Command` with parameters.
- Unprotected Network Failures: Missing error handlers on HTTP web requests. → Fix: Wrap all network calls in defensive error recovery blocks.
