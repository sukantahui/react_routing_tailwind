5. TROUBLESHOOTING & COMMON ERRORS
• Leaking Connection Handles:
  Root Cause: Leaving connection objects unclosed.
  Diagnostic Fix: Always close connections and set objects to Nothing.
• Vulnerable Concatenated SQL:
  Root Cause: Failing to parameterize dynamic query inputs.
  Diagnostic Fix: Use `ADODB.Command` with parameters.
• Unprotected Network Failures:
  Root Cause: Missing error handlers on HTTP web requests.
  Diagnostic Fix: Wrap all network calls in defensive error recovery blocks.

6. PRO TIPS & SHORTCUTS
• Universal Connection Pattern (Open → Execute → Process → Close → Set Nothing): The foundational pattern for all database automation.
• Fastest Data Ingestion (CopyFromRecordset for tabular data): Sub-second extraction across millions of data points.
• Security First (Parameterized queries + Windows Auth): Non-negotiable corporate standards.
