COMMON TRAPS TO AVOID:
- Exporting PDF Before Background Query Refresh Completes: Calling PDF export while Power Query is still asynchronously calculating in background produces stale PDF reports. → Fix: Disable Background Refresh on queries or wait for calculation completion.
- Hardcoding Output File Paths to Local Folders: Script breaking when executed on another user's machine. → Fix: Use `ThisWorkbook.Path & "\Reports\"` or prompt user for destination directory.
- Leaving ScreenUpdating Disabled on Error: Macro crash leaving Excel UI frozen. → Fix: Include structured error handling resetting `Application.ScreenUpdating = True`.
