5. TROUBLESHOOTING & COMMON ERRORS
• Exporting PDF Before Background Query Refresh Completes:
  Root Cause: Calling PDF export while Power Query is still asynchronously calculating in background produces stale PDF reports.
  Diagnostic Fix: Disable Background Refresh on queries or wait for calculation completion.
• Hardcoding Output File Paths to Local Folders:
  Root Cause: Script breaking when executed on another user's machine.
  Diagnostic Fix: Use `ThisWorkbook.Path & "\Reports\"` or prompt user for destination directory.
• Leaving ScreenUpdating Disabled on Error:
  Root Cause: Macro crash leaving Excel UI frozen.
  Diagnostic Fix: Include structured error handling resetting `Application.ScreenUpdating = True`.

6. PRO TIPS & SHORTCUTS
• Disable Background Refresh (Connection Properties > Uncheck 'Enable background refresh'): Guarantees data finishes refreshing before PDF export.
• 1-Click Action Button (Assign Master Controller to sleek rounded shape button): Delivers an intuitive software experience for end-users.
• Timestamped Filenames ("Report_" & Format(Now, "yyyymmdd_hhnn") & ".pdf"): Prevents accidental file overwriting on network drives.
