5. TROUBLESHOOTING & COMMON ERRORS
• Creating Many-to-Many Relationships Without Bridge Tables:
  Root Cause: Duplicate keys in dimension tables creating ambiguous relationships.
  Diagnostic Fix: Ensure dimension tables contain 100% unique primary keys.
• Using Bi-Directional Cross-Filtering Indiscriminately:
  Root Cause: Bi-directional relationships causing unpredictable filter propagation and calculation performance degradation.
  Diagnostic Fix: Keep relationships strictly single-directional (1-to-many).
• Omitting Continuous Date Table for Time Intelligence:
  Root Cause: Time intelligence DAX functions returning `#ERROR` on missing calendar dates.
  Diagnostic Fix: Generate complete contiguous Date table in Power Query or DAX.

6. PRO TIPS & SHORTCUTS
• Single-Directional Relationships (1:Many Unidirectional Standard): Guarantees clean, predictable filter context flow.
• Use Explicit DAX Measures (Always write explicit measures with =SUMX or =DIVIDE): Lightweight, reusable, and high-performance.
• Mark as Date Table (Design > Mark as Date Table): Enables all DAX Time Intelligence functions.
