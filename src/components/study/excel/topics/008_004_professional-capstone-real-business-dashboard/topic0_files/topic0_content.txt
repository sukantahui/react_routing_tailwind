5. TROUBLESHOOTING & COMMON ERRORS
• Building Dashboards Without Clear Business Question Alignment:
  Root Cause: Designing 20 pretty charts that answer zero actionable business questions.
  Diagnostic Fix: Define top 5 executive business questions before placing a single chart.
• Single Giant Flat Table Architecture (Anti-Pattern):
  Root Cause: Creating an unmaintainable 50-column flat table instead of a clean Star Schema.
  Diagnostic Fix: Separate data into 1 Fact table and dedicated Dimension lookup tables.
• Underestimating Data Cleansing Complexity:
  Root Cause: Assuming raw corporate ERP data is clean and formatted.
  Diagnostic Fix: Build robust Power Query ETL pipelines to sanitize all inputs.

6. PRO TIPS & SHORTCUTS
• Star Schema Design (1 Fact Table + Dimension Tables): The universal gold standard for Power Pivot data modeling.
• Define Core KPIs First (Revenue, Gross Margin, Net Margin, Growth %): Anchors all dashboard metrics to C-Suite priorities.
• Single Page HUD (Fit all key metrics on one 1080p screen): Eliminates scrolling and delivers instant situational awareness.
