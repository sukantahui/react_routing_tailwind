5. TROUBLESHOOTING & COMMON ERRORS
• Loading 1 Million Rows to Worksheet Tab (Memory Crash):
  Root Cause: Selecting 'Table' in Load To dialog crashes Excel sheet row limits.
  Diagnostic Fix: Select 'Only Create Connection' and check 'Add to Data Model'.
• Hardcoding File Paths in Power Query:
  Root Cause: Hardcoded local C:\ paths breaking on colleague laptops.
  Diagnostic Fix: Use dynamic folder parameters or relative workbook paths.
• Type Mismatch on Primary Key Columns:
  Root Cause: Customer ID as Integer in Fact table and Text in Dimension table.
  Diagnostic Fix: Explicitly set both join keys to identical data types (e.g. Text).

6. PRO TIPS & SHORTCUTS
• Only Create Connection (Close & Load To > Only Create Connection): Stores data in high-speed compressed memory.
• Folder Combine (Get Data > From File > From Folder): Automatically combines all files in a directory.
• Standardize Types (Explicitly cast every column type): Guarantees flawless relational joins in Power Pivot.
