1. EXECUTIVE OVERVIEW
Formatting measures, organizing display folders, and hiding technical keys from end-users is an essential discipline in enterprise data architecture, business intelligence, and large-scale analytical modeling.
It provides the core protocols required to shatter Excel's 1-million row limit, establish clean relational schemas, and build high-performance data models.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Power Pivot Property Grid: Formatting: Currency (₹) | Display Folder: Financials\Margins | Hidden: True (Hide Foreign Keys)

3. CORE TECHNICAL MECHANICS
1. Display Folder Grouping:
   Organizes dozens of measures into nested subfolders in the PivotTable field list (e.g. `Sales\YoY Metrics`, `Margins\Percentages`), eliminating field list clutter.

2. Hiding Technical Keys from End-Users:
   Hiding foreign keys (`Customer_ID_FK`, `Product_ID_FK`) and sorting helper columns prevents non-technical users from dragging useless technical codes into pivots.

3. Model-Level Number Formatting:
   Formats numbers at the Data Model level once; formatting persists automatically across all PivotTables and PivotCharts throughout the entire workbook.

5. TROUBLESHOOTING & COMMON ERRORS
• The 'Infinite Scroll' Field List Nightmare:
  Root Cause: Leaving 80 unorganized measures scattered alphabetically in a flat table makes it impossible for users to locate specific KPIs.
  Diagnostic Fix: Organize measures into logical Display Folders.
• Formatting Measures Locally in Each PivotTable:
  Root Cause: Spending 20 minutes re-formatting currency symbols in every single PivotTable manually.
  Diagnostic Fix: Format the measure ONCE in the Power Pivot window; it will format automatically everywhere.
• Hiding Dimension Description Columns by Mistake:
  Root Cause: Accidentally hiding Customer Name instead of Customer ID Key.
  Diagnostic Fix: Audit hidden column statuses in Diagram View (hidden items appear grayed out).

6. PRO TIPS & SHORTCUTS
• Create Display Folder (Select measure > Property Grid > Display Folder: FolderName): Organizes measures into neat collapsible folders in the field list.
• Nested Folders (Use backslash: Finance\Revenue\YoY): Creates multi-level nested folder hierarchies.
• Hide from Client Tools (Right-click column > Hide from Client Tools): Hides technical database keys from end-user view.
