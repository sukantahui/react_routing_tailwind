3. CORE TECHNICAL MECHANICS
1. Columnar Storage Architecture:
   Unlike traditional row-based Excel grids, VertiPaq stores each column as an independent contiguous vector in RAM, enabling 10x-20x data compression.

2. Dictionary & Run-Length Encoding:
   Replaces repetitive strings with compact integer IDs and compresses consecutive identical values, allowing millions of rows to fit in megabytes of RAM.

3. High-Speed Parallel Vector Processing:
   Scans billions of rows per second across multi-core CPU architectures without consuming disk I/O.

5. TROUBLESHOOTING & COMMON ERRORS
• Loading Unnecessary High-Cardinality Columns (GUIDs):
  Root Cause: Loading unique primary keys or transaction timestamps with milliseconds destroys VertiPaq compression ratios.
  Diagnostic Fix: Remove high-cardinality IDs and split timestamps into Date and Hour columns.
• Power Pivot Tab Missing in Excel Ribbon:
  Root Cause: Power Pivot is an advanced COM Add-in that is disabled by default in standard Excel installations.
  Diagnostic Fix: File > Options > Add-ins > COM Add-ins > Check 'Microsoft Power Pivot for Excel'.
• Confusing Workbook Grid Limits with Data Model Capacity:
  Root Cause: Thinking Excel cannot handle more than 1,048,576 rows.
  Diagnostic Fix: Load data directly into the Data Model (VertiPaq) rather than pasting onto standard worksheet grids.

6. PRO TIPS & SHORTCUTS
• Enable Power Pivot (File > Options > Add-ins > COM Add-ins > Power Pivot): Activates the dedicated Power Pivot modeling ribbon.
• Launch Data Model Window (Alt + B + M (or Power Pivot > Manage)): Opens the standalone Power Pivot tabular modeling environment.
• Optimize Cardinality (Remove unnecessary high-unique columns): Dramatically slashes file size and supercharges DAX query speeds.
