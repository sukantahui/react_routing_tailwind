1. EXECUTIVE OVERVIEW
Working day calculations: WORKDAY, WORKDAY.INTL, NETWORKDAYS, and NETWORKDAYS.INTL is an essential discipline in corporate spreadsheet development and ETL workflows.
It provides the core formulas required to sanitize, manipulate, and calculate text, dates, and times.

2. SYNTAX & TOKEN STRUCTURE
Formula Code: =WORKDAY(start_date, days, [holidays]) | =WORKDAY.INTL(start_date, days, [weekend], [holidays]) | =NETWORKDAYS(start_date, end_date, [holidays]) | =NETWORKDAYS.INTL(start_date, end_date, [weekend], [holidays])

3. CORE TECHNICAL MECHANICS
1. Standard vs Custom Weekend Filtering (.INTL):
   WORKDAY/NETWORKDAYS assume Saturday/Sunday weekends. The .INTL variants allow custom weekend string masks (e.g. "0000011" for Fri/Sat or 11 for Sunday-only).

2. Statutory Holiday Array Exclusion:
   Accepts an optional range of holiday dates, automatically subtracting holidays that fall on active working business days.

3. Forward & Backward Project Milestone Shifting:
   Positive day offsets calculate future delivery deadlines; negative day offsets calculate prerequisite procurement cutoffs.

5. TROUBLESHOOTING & COMMON ERRORS
• Default Weekend Misalignment in India/Middle East:
  Root Cause: Standard NETWORKDAYS assumes Sat/Sun off, miscalculating factories operating on 6-day (Sunday-only) workweeks.
  Diagnostic Fix: Use NETWORKDAYS.INTL with weekend code 11 (Sunday only) or custom 7-character string mask.
• Holiday Falls on Weekend Double-Counting:
  Root Cause: Worrying that a holiday falling on a Sunday subtracts 2 days (Excel handles this correctly).
  Diagnostic Fix: Provide complete holiday lists; Excel automatically avoids double-deducting weekend holidays.
• Start Date Exceeds End Date Negative Result:
  Root Cause: Passing a start_date later than end_date to NETWORKDAYS returns negative day counts.
  Diagnostic Fix: Ensure chronological order or wrap in ABS() if unsigned duration is needed.

6. PRO TIPS & SHORTCUTS
• Sunday Only Weekend (Weekend Code: 11): Sets Sunday as the sole weekend day in .INTL functions.
• Custom Shift Mask ("0000001" (7 digits)): 1 represents non-working day, 0 represents working day (Mon-Sun).
• Dynamic Month Net Days (=NETWORKDAYS(A2, EOMONTH(A2,0), Holidays)): Calculates exact working days in any given month.
