5. TROUBLESHOOTING & COMMON ERRORS
• Pipeline Formula Bottleneck:
  Root Cause: Chaining 10 complex text formulas across 500,000 rows causes workbook freezing.
  Diagnostic Fix: Use Power Query ETL for large datasets, or convert intermediate cleaned columns to static values.
• Uncaptured Edge-Case Formats:
  Root Cause: Assuming all names follow 'First Last' fails for single names or four-part compound names.
  Diagnostic Fix: Implement exception validation columns using IFERROR() to highlight unparsed rows.
• Overwriting Raw Source Data:
  Root Cause: Modifying original import sheets directly eliminates the audit trail.
  Diagnostic Fix: Always keep Raw_Import sheets immutable and build transformations on Cleaned_Data sheets.

6. PRO TIPS & SHORTCUTS
• Modular Helper Columns (Break formulas into steps): Build modular helper columns for intermediate parsing before combining formulas.
• Validation Status Column (=IF(ISNUMBER(B2), "OK", "CHECK")): Adds an instant visual audit flag for quality assurance.
• Save Template Structure (Save as .xltx): Preserve clean ETL structures for recurring monthly data imports.
