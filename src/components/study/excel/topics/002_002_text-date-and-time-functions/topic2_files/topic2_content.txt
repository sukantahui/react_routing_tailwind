1. EXECUTIVE OVERVIEW
Concatenation strategies: CONCAT, TEXTJOIN with custom delimiters, and the & operator is an essential discipline in corporate spreadsheet development and ETL workflows.
It provides the core formulas required to sanitize, manipulate, and calculate text, dates, and times.

2. SYNTAX & TOKEN STRUCTURE
Formula Code: =TEXTJOIN(delimiter, ignore_empty, text1, [text2], ...) | =CONCAT(text1, [text2], ...) | =text1 & text2

3. CORE TECHNICAL MECHANICS
1. The Modern TEXTJOIN Engine:
   TEXTJOIN() takes a delimiter, boolean ignore_empty flag, and full cell ranges, automatically aggregating lists without manual comma concatenation.

2. The Ampersand (&) Operator:
   The & operator provides lightweight, high-performance binary string merging for small formulas (e.g. `=A2 & " - " & B2`).

3. CONCAT() Range Support:
   CONCAT() replaces legacy CONCATENATE(), allowing full range arguments like `=CONCAT(A2:D2)` (without built-in delimiters).

5. TROUBLESHOOTING & COMMON ERRORS
• Missing Line Break Wrap Text:
  Root Cause: Using CHAR(10) to create multi-line text displays as square boxes or spaces unless Wrap Text is enabled.
  Diagnostic Fix: Enable Home > Wrap Text (Alt + H + W) on formatted cells.
• Legacy CONCATENATE Range Limitation:
  Root Cause: Using old CONCATENATE(A2:D2) fails to span arrays and returns #VALUE! in older Excel.
  Diagnostic Fix: Use modern TEXTJOIN() or CONCAT() functions.
• Forgetting ignore_empty Flag:
  Root Cause: Setting ignore_empty to FALSE produces duplicate delimiters (e.g. 'Item 1,,Item 3') when blank cells exist.
  Diagnostic Fix: Set the second argument of TEXTJOIN to TRUE.

6. PRO TIPS & SHORTCUTS
• Multi-Line Concatenation (=TEXTJOIN(CHAR(10), TRUE, A2:D2)): Inserts carriage returns between elements (requires Wrap Text enabled).
• Dynamic Comma List (=TEXTJOIN(", ", TRUE, A2:A50)): Quickly creates SQL IN-clause strings or reporting summaries.
• Direct Ampersand (=A2 & " " & B2): Fastest way to concatenate two individual cells without function call overhead.
