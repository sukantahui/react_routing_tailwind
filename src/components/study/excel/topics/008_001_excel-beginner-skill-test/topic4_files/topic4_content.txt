5. TROUBLESHOOTING & COMMON ERRORS
• Missing Absolute Referencing ($):
  Root Cause: Formulas breaking when copied.
  Diagnostic Fix: Lock parameter cells with F4.
• Formatting Errors:
  Root Cause: Leaving numbers unformatted.
  Diagnostic Fix: Apply Indian Rupee and comma separators.
• Unlinked Chart Titles:
  Root Cause: Leaving generic titles.
  Diagnostic Fix: Set descriptive dynamic titles.

6. PRO TIPS & SHORTCUTS
• Check Formula Bar (Ctrl + ` (Show Formulas)): Audits all formulas across the sheet simultaneously.
• Professional Polish (Alt + W + V + G (Hide Gridlines)): Gives dashboards a clean white canvas appearance.
• Save Your Work (Ctrl + S): Frequent saving prevents data loss.
