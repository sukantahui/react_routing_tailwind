5. TROUBLESHOOTING & COMMON ERRORS
• Touching the Mouse for Basic Navigation:
  Root Cause: Scrolling 10,000 rows with the mouse scroll wheel.
  Diagnostic Fix: Use `Ctrl + Down Arrow` to jump to table bottom instantly.
• Freezing Wrong Rows with Freeze Panes:
  Root Cause: Placing cursor in cell A1 before clicking Freeze Panes.
  Diagnostic Fix: Place active cursor in cell B2 to freeze Row 1 and Column A simultaneously.
• Accidentally Hiding Formula Bar / Ribbon:
  Root Cause: Pressing Ctrl + F1 hiding ribbon tabs.
  Diagnostic Fix: Press `Ctrl + F1` to restore full ribbon.

6. PRO TIPS & SHORTCUTS
• Jump to Bottom (Ctrl + Down Arrow): Instantly navigates to last data cell.
• Freeze Panes (Alt + W + F + F): Locks headers on screen while scrolling.
• Select to End (Ctrl + Shift + Down Arrow): Highlights entire column data block.
