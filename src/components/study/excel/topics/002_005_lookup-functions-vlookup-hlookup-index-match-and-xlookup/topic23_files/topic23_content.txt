5. TROUBLESHOOTING & COMMON ERRORS
• Spill Clashes in Dynamic Array Combinations:
  Root Cause: Placing text directly below spilled dynamic range formulas.
  Diagnostic Fix: Leave sufficient empty cells for array expansion.
• Blank Cells Distorting COUNTA in Dynamic Heights:
  Root Cause: Empty cells in middle of column causing `COUNTA` to underestimate true table height.
  Diagnostic Fix: Ensure continuous data or use structured table referencing.
• Circular References in Dynamic Name Definitions:
  Root Cause: Named range formula referencing cell that consumes the named range.
  Diagnostic Fix: Verify strict separation between input data and calculation cells.
