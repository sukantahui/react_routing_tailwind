COMMON TRAPS TO AVOID:
- Spill Clashes in Dynamic Array Combinations: Placing text directly below spilled dynamic range formulas. -> Fix: Leave sufficient empty cells for array expansion.
- Blank Cells Distorting COUNTA in Dynamic Heights: Empty cells in middle of column causing `COUNTA` to underestimate true table height. -> Fix: Ensure continuous data or use structured table referencing.
- Circular References in Dynamic Name Definitions: Named range formula referencing cell that consumes the named range. -> Fix: Verify strict separation between input data and calculation cells.
