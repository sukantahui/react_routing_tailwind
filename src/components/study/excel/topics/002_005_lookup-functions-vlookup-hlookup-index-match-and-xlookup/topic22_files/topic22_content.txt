Topic 22: Grid Coordinate & Dimension Functions: Generating dynamic numbering, matrix dimensions, and zebra-striping using ROW(), ROWS(), COLUMN(), and COLUMNS()
================================================================================

1. EXECUTIVE OVERVIEW
Grid Coordinate & Dimension Functions: Generating dynamic numbering, matrix dimensions, and zebra-striping using ROW(), ROWS(), COLUMN(), and COLUMNS() is a foundational formula engineering discipline in advanced spreadsheet modeling.
It equips financial analysts and data professionals with precision dynamic range referencing and next-gen array workflows.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Coordinate Functions: =ROW([cell]) | =ROWS(array) | =COLUMN([cell]) | =COLUMNS(array) | Dynamic Numbering: =ROW()-ROW($A$1) | Zebra: =ISODD(ROW())

3. CORE TECHNICAL MECHANICS
1. Relative Coordinate Generation (ROW / COLUMN):
   `ROW()` returns the current row number; `=ROW()-ROW($A$1)` creates a self-healing sequential serial number list that never breaks when rows are deleted.

2. Matrix Dimension Measurement (ROWS / COLUMNS):
   `=ROWS(Range)` and `=COLUMNS(Range)` return the exact integer count of rows and columns in a target table or array.

3. Dynamic Conditional Formatting Striping:
   Applying `=ISODD(ROW())` or `=MOD(ROW(), 2) = 0` in conditional formatting rules to create custom multi-color alternating row striping.

5. TROUBLESHOOTING & COMMON ERRORS
• Hardcoded Serial Numbers Breaking on Row Deletion:
  Root Cause: Typing 1, 2, 3 manually and having gaps when row 2 is deleted.
  Diagnostic Fix: Use `=ROW()-ROW($A$1)` for self-healing serial numbers.
• Confusing ROW() vs ROWS():
  Root Cause: `ROW()` returns position of a cell (e.g. 5); `ROWS()` returns total count of rows in range (e.g. 10).
  Diagnostic Fix: Use `ROW()` for position; `ROWS()` for count.
• Forgetting Absolute Lock on Header Cell in =ROW()-ROW($A$1):
  Root Cause: Omitting dollar signs causes anchor reference to shift when dragged down.
  Diagnostic Fix: Always lock anchor: `=ROW()-ROW($A$1)`.

6. PRO TIPS & SHORTCUTS
• Self-Healing Serial Numbers (=ROW()-ROW($A$1)): Never breaks when rows are inserted or deleted.
• Zebra Striping Formula (=ISODD(ROW())): Instant alternating row shading in Conditional Formatting.
• Count Table Rows (=ROWS(tblSales)): Returns total number of rows in structured table.
