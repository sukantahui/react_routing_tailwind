5. TROUBLESHOOTING & COMMON ERRORS
• Leaving Default Control Names (TextBox1, CommandButton1):
  Root Cause: Writing code with `TextBox1.Text` and `CommandButton1_Click` makes maintenance a nightmare across 20 fields.
  Diagnostic Fix: Rename every control immediately in the Properties window (`txtName`, `btnSave`).
• Chaotic Tab Order Frustrating Operators:
  Root Cause: Pressing Tab jumping randomly between field 1 and field 8 because TabIndex was not configured.
  Diagnostic Fix: Right-click UserForm > Tab Order > arrange fields in logical top-to-bottom sequence.
• Overcrowding UserForm with Clashing Colors:
  Root Cause: Using bright neon backgrounds and mismatched font sizes.
  Diagnostic Fix: Follow clean corporate UI standards (Segoe UI / Inter, subtle gray borders, standard 8pt grid padding).

6. PRO TIPS & SHORTCUTS
• Naming Convention (txt, cbo, lst, chk, btn prefixes): Self-documenting, professional code architecture.
• Tab Order Dialog (Right-click form > Tab Order): Ensures seamless keyboard navigation for operators.
• Show UserForm (UserForm1.Show (or frmMain.Show)): Launches the modal dialog on screen.
