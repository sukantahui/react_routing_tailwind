Topic 5: File System Automation using `Scripting.FileSystemObject` (FSO): Creating, moving, reading, and deleting files/folders
================================================================================

1. EXECUTIVE OVERVIEW
File System Automation using `Scripting.FileSystemObject` (FSO): Creating, moving, reading, and deleting files/folders is an essential discipline in enterprise desktop software engineering, event-driven architecture, and multi-application Office automation.
It provides the core protocols required to construct custom GUI forms, automate cross-application reporting decks, and deploy enterprise add-ins.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: FileSystemObject: Set fso = CreateObject("Scripting.FileSystemObject") | fso.FileExists(path) | fso.FolderExists | fso.CopyFile | fso.OpenTextFile

3. CORE TECHNICAL MECHANICS
1. The Microsoft Scripting Runtime Engine:
   Instantiated via Late Binding (`CreateObject("Scripting.FileSystemObject")`) or Early Binding (`Tools > References > Microsoft Scripting Runtime`).

2. High-Speed File & Folder Manipulation:
   Methods: `.FileExists()`, `.FolderExists()`, `.CreateFolder()`, `.CopyFile()`, `.MoveFile()`, `.DeleteFile()`.

3. Reading & Writing Text/CSV Streams:
   Methods: `.OpenTextFile(path, IOMode, Create)` to stream text line-by-line (`ReadLine`, `WriteLine`) directly from disk without opening in Excel.

5. TROUBLESHOOTING & COMMON ERRORS
• Failing to Check if Directory Exists Before Creating:
  Root Cause: Calling `fso.CreateFolder("C:\A\B\C")` when parent folder `C:\A\B` does not exist throws runtime error.
  Diagnostic Fix: Create nested parent folders iteratively or verify with `If Not fso.FolderExists(path) Then`.
• Leaving OpenTextFile Streams Unclosed in RAM:
  Root Cause: Forgetting `ts.Close` locks the external file on disk, preventing other applications from accessing it.
  Diagnostic Fix: Always include `ts.Close: Set ts = Nothing` in clean-up blocks.
• Overwriting Existing Files Without Overwrite Parameter:
  Root Cause: Calling `fso.CopyFile` over an existing file without setting `Overwrite:=True` throws 'File already exists'.
  Diagnostic Fix: Explicitly pass `fso.CopyFile src, dest, True`.

6. PRO TIPS & SHORTCUTS
• Late Binding FSO (Set fso = CreateObject("Scripting.FileSystemObject")): Runs on all client machines without reference errors.
• Check File Exists (If fso.FileExists(filePath) Then ...): Eliminates file-not-found runtime crashes.
• Fast Text File Write (Set ts = fso.CreateTextFile(path, True): ts.WriteLine text: ts.Close): Fastest way to write text/CSV logs from VBA.
