5. TROUBLESHOOTING & COMMON ERRORS
• Allowing Invoicing of Out-of-Stock Items (Negative Inventory):
  Root Cause: UserForm accepting orders exceeding warehouse stock.
  Diagnostic Fix: Add stock validation check: `If reqQty > stockQty Then MsgBox "Insufficient Stock!", vbCritical: Exit Sub`.
• Single-Point Transaction Failure Corrupting Balance:
  Root Cause: Writing the invoice but crashing before decrementing warehouse stock.
  Diagnostic Fix: Wrap transactions in structured rollback error handling.
• Unsanitized User Inputs Causing SQL / Array Errors:
  Root Cause: Failing to validate special characters or apostrophes in client names.
  Diagnostic Fix: Sanitize all input strings using `Replace(str, "'", "''")`.

6. PRO TIPS & SHORTCUTS
• Stock Check Before Write (Verify Available >= Requested): Prevents negative inventory anomalies.
• Atomic Transaction Pattern (Write Invoice + Decrement Stock + Generate PDF): Guarantees complete end-to-end data integrity.
• 1-Click Launch Button (frmBillingMaster.Show): Delivers an intuitive custom software experience for operators.
