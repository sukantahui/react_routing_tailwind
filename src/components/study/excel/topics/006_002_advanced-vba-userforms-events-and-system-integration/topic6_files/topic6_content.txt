Topic 6: Batch processing all workbooks inside a directory automatically
================================================================================

1. EXECUTIVE OVERVIEW
Batch processing all workbooks inside a directory automatically is an essential discipline in enterprise desktop software engineering, event-driven architecture, and multi-application Office automation.
It provides the core protocols required to construct custom GUI forms, automate cross-application reporting decks, and deploy enterprise add-ins.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Batch Processor: strFile = Dir(folderPath & "*.xlsx") | Do While strFile <> "" ... Workbooks.Open ... Process ... Close ... strFile = Dir() ... Loop

3. CORE TECHNICAL MECHANICS
1. The Classic `Dir()` Loop Pattern:
   1. `strFile = Dir(folderPath & "*.xlsx")`; 2. `Do While strFile <> ""`; 3. `Workbooks.Open(folderPath & strFile)`; 4. Extract data; 5. `wb.Close SaveChanges:=False`; 6. `strFile = Dir()`; 7. `Loop`.

2. Headless Silent Processing:
   Sets `Application.ScreenUpdating = False` and `Application.DisplayAlerts = False` so 100 workbooks open, process, and close invisibly in seconds without screen flashing.

3. Defensive Corrupted File Isolation:
   Wraps individual workbook processing in localized error traps so a single password-protected or corrupted file does not halt the entire batch run.

5. TROUBLESHOOTING & COMMON ERRORS
• The 'Infinite Same File' Loop Trap:
  Root Cause: Forgetting to write `strFile = Dir()` before the `Loop` statement causes the loop to re-open the first file forever.
  Diagnostic Fix: Always call `strFile = Dir()` at the bottom of the loop to advance to the next file.
• Saving Changes to Source Files Accidentally:
  Root Cause: Calling `wbSource.Close SaveChanges:=True` modifies client source files.
  Diagnostic Fix: Always close extraction sources safely with `wbSource.Close SaveChanges:=False`.
• Opening Temporary Lock Files (~$filename.xlsx):
  Root Cause: `Dir("*.xlsx")` picking up hidden Excel lock files (~$) created when a file is open.
  Diagnostic Fix: Filter out temporary files: `If Left(strFile, 2) <> "~$" Then ...`.

6. PRO TIPS & SHORTCUTS
• The Dir() Pattern (strFile = Dir(path) ... Do While strFile <> "" ... strFile = Dir() ... Loop): Universal directory looping engine in VBA.
• Skip Lock Files (If Left(strFile, 2) <> "~$" Then): Prevents crashes on open temporary files.
• Silent Headless Mode (ScreenUpdating & DisplayAlerts = False): Processes 100 workbooks completely invisibly.
