1. EXECUTIVE OVERVIEW
Worksheet events: `Worksheet_Change`, `Worksheet_SelectionChange`, `Worksheet_Calculate` is an essential discipline in enterprise desktop software engineering, event-driven architecture, and multi-application Office automation.
It provides the core protocols required to construct custom GUI forms, automate cross-application reporting decks, and deploy enterprise add-ins.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Worksheet Events (Sheet Modules): Private Sub Worksheet_Change(ByVal Target As Range) | Worksheet_SelectionChange | Worksheet_Calculate

3. CORE TECHNICAL MECHANICS
1. The `Target` Range Parameter:
   `Target` represents the exact cell or multi-cell range that was modified by the user or formula.

2. The Mandatory `Intersect` Guard Rail:
   `If Not Intersect(Target, Range("B2:B100")) Is Nothing Then` ensures the macro runs ONLY when the user edits designated monitoring columns.

3. Event Loop Suppression (`EnableEvents = False`):
   If `Worksheet_Change` modifies another cell on the sheet, it will trigger ITSELF recursively unless wrapped in `Application.EnableEvents = False`.

5. TROUBLESHOOTING & COMMON ERRORS
• The Fatal Infinite Event Recurse Crash:
  Root Cause: Modifying a cell inside `Worksheet_Change` without `Application.EnableEvents = False` causes the macro to trigger itself endlessly until Excel crashes.
  Diagnostic Fix: Always wrap cell writes in `Application.EnableEvents = False ... Target.Offset(0,1).Value = Now ... Application.EnableEvents = True`.
• Crashing on Multi-Cell Paste or Delete:
  Root Cause: Assuming `Target` is a single cell (`Target.Value`) crashes with 'Type Mismatch' when user pastes 50 cells at once.
  Diagnostic Fix: Check `If Target.CountLarge > 1 Then Exit Sub` or loop `For Each c In Target`.
• Placing Code in Standard Module:
  Root Cause: Sheet events written in Module1 are completely ignored by Excel.
  Diagnostic Fix: Place code in the specific `Sheet1 (Code)` object.

6. PRO TIPS & SHORTCUTS
• Intersect Guard Rail (If Not Intersect(Target, Range("A:A")) Is Nothing Then): Restricts execution strictly to target columns.
• Mandatory Event Toggle (Application.EnableEvents = False (before writing)): Prevents catastrophic recursive event loops.
• Multi-Cell Guard (If Target.CountLarge > 1 Then Exit Sub): Prevents runtime errors on large paste operations.
