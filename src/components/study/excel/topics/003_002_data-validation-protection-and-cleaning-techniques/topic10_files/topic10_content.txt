Topic 10: Document Inspector: Removing hidden properties, personal information, and metadata
================================================================================

1. EXECUTIVE OVERVIEW
Document Inspector: Removing hidden properties, personal information, and metadata is an essential discipline in corporate spreadsheet governance, data integrity, and template security.
It provides the core protocols required to prevent data corruption, audit complex formulas, and encrypt sensitive corporate assets.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: File > Info > Check for Issues > Inspect Document (Remove Personal Info, Document Properties, Hidden Worksheets, Comments)

3. CORE TECHNICAL MECHANICS
1. Deep Metadata Inspection:
   Scans the workbook XML architecture for hidden metadata: Author Name, Company, Revision History, File Paths, Printer Properties, and Email Addresses.

2. Hidden Content Scrubbing:
   Identifies and purges hidden worksheets, hidden rows/columns, invisible objects, custom XML data, and embedded cell comments/notes.

3. Regulatory Privacy & M&A Compliance:
   Essential step before releasing financial models to external buyers, regulatory bodies (SEBI/SEC), or public investor relations portals.

5. TROUBLESHOOTING & COMMON ERRORS
• Irreversible Deletion of Necessary Hidden Sheets:
  Root Cause: Clicking 'Remove All' on Hidden Worksheets in Document Inspector permanently DELETES those sheets from the workbook.
  Diagnostic Fix: Always save a backup copy (`Model_Master_Internal.xlsx`) before running Document Inspector.
• Accidental Removal of Live Pivot Cache XML:
  Root Cause: Removing Custom XML data can occasionally corrupt complex Power Query or third-party add-in connections.
  Diagnostic Fix: Review itemized inspection results before clicking 'Remove All'.
• Publishing Internal Notes to Public Competitors:
  Root Cause: Forgetting to inspect documents leaves confidential internal margin discussions visible in cell comments.
  Diagnostic Fix: Make Document Inspection a mandatory step in corporate sign-off checklists.

6. PRO TIPS & SHORTCUTS
• Launch Document Inspector (File > Info > Check for Issues > Inspect Document): Comprehensive audit of all hidden properties and comments.
• Save Backup First (Save as Model_Cleaned_External.xlsx): Mandatory safeguard before purging metadata.
• Inspect for Hidden Rows (Highlights hidden rows/cols): Prevents leaking sensitive filtered data in shared spreadsheets.
