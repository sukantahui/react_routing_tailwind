Topic 7: Handling multiple relationships with USERELATIONSHIP (Active vs Inactive relationships)
================================================================================

1. EXECUTIVE OVERVIEW
Handling multiple relationships with USERELATIONSHIP (Active vs Inactive relationships) is an essential discipline in enterprise business intelligence, quantitative finance, and advanced data modeling.
It provides the core protocols required to construct complex multi-dimensional financial measures, calculate period-over-period growth, and evaluate dynamic rankings.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: USERELATIONSHIP(Fact_Table[Date_FK], Dim_Calendar[Date_PK]) | ShipSales := CALCULATE([TotalSales], USERELATIONSHIP(Fact_Sales[ShipDate], Dim_Calendar[Date]))

3. CORE TECHNICAL MECHANICS
1. The Single Active Relationship Constraint:
   Power Pivot permits only ONE active relationship between two tables (solid line). Additional relationships remain Inactive (dotted lines).

2. Dynamic Relationship Activation with USERELATIONSHIP:
   `USERELATIONSHIP()` temporarily deactivates the default active relationship and activates the specified inactive dotted-line relationship during formula execution.

3. Eliminating Multiple Redundant Calendar Tables:
   Allows a single master Calendar table to analyze sales by Order Date, Ship Date, Due Date, and Return Date simultaneously.

5. TROUBLESHOOTING & COMMON ERRORS
• Using USERELATIONSHIP Outside of CALCULATE:
  Root Cause: Writing `USERELATIONSHIP()` as a standalone measure throws a DAX syntax error.
  Diagnostic Fix: USERELATIONSHIP can ONLY be passed as a filter argument inside `CALCULATE()`.
• Duplicating 5 Calendar Tables (Anti-Pattern):
  Root Cause: Creating `Calendar_Order`, `Calendar_Ship`, `Calendar_Pay` tables bloats the model and fragments slicers.
  Diagnostic Fix: Use 1 Master Calendar table with inactive relationships and `USERELATIONSHIP()`.
• Data Type Mismatch on Inactive Relationship Keys:
  Root Cause: Key data types differing between foreign and primary keys breaks activation.
  Diagnostic Fix: Ensure both key columns share identical data types in Power Query.

6. PRO TIPS & SHORTCUTS
• USERELATIONSHIP Syntax (CALCULATE([Measure], USERELATIONSHIP(FK, PK))): Temporarily activates an inactive dotted-line relationship.
• 1 Master Calendar (Single Date Dimension for all date fields): The enterprise standard for clean role-playing date modeling.
• Solid vs Dotted Lines (Solid = Active by default; Dotted = Inactive): Visual indicator in Power Pivot Diagram View.
