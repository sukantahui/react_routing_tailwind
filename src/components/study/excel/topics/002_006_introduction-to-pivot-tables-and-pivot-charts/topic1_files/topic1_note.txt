TOPIC 1 QUICK SUMMARY & INSTRUCTOR REFERENCE
================================================================================
Topic: Preparing source data for Pivot Tables: Flat tables vs Matrix layouts
Module: 002_006_introduction-to-pivot-tables-and-pivot-charts
Course: EXCEL-PRO-901: Microsoft Excel From Zero to Ultra Expert
Instructor: Sukanta Hui (Coder & AccoTax)

KEY FORMULA / SYNTAX:
Data Hygiene Standard: 1 Row = 1 Fact | 1 Col = 1 Attribute | No Blank Headers | No Merged Cells

PRIMARY CONCEPT:
Structuring and sanitizing source data into normalized flat tables (tabular format) versus unpivotable cross-tabulated 2D matrices

TEACHER'S ADVICE:
Garbage in, garbage out! 90% of PivotTable errors are caused by poor source data structure. Always enforce normalized flat tables with zero blank headers and zero merged cells.

COMMON TRAPS TO AVOID:
- Blank Header Field Error: Creating a PivotTable on a range with an empty column header triggers the fatal 'The PivotTable field name is not valid' error. -> Fix: Ensure every single column in the source table has a clear, unique header name.
- Merged Cells Ingestion Failure: Merged cells in source data corrupt row-by-row aggregation and cause fields to drop data. -> Fix: Unmerge all cells and fill down header/category labels.
- Including Total Rows in Source Range: Selecting summary totals (e.g. Grand Total row) in the source range doubles all pivot aggregations. -> Fix: Exclude total and subtotal rows from the PivotTable source data range.
