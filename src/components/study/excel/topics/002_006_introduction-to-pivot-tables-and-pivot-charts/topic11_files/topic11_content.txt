1. EXECUTIVE OVERVIEW
Formatting and Layout options: Compact, Outline, Tabular forms, and blank rows is an essential discipline in corporate business intelligence and reporting.
It provides the foundation for dynamic in-memory summarization, multi-dimensional slicing, and interactive dashboards.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Report Layouts: Compact Form (Default) | Outline Form | Tabular Form (Flat Grid) | Repeat All Item Labels

3. CORE TECHNICAL MECHANICS
1. Compact Form (Indented Tree):
   Default mode; places all row hierarchy fields in a single column with progressive indentation, saving horizontal space.

2. Outline Form (Stepped Columns):
   Separates each row hierarchy field into its own distinct column while keeping subtotals at the top of each group.

3. Tabular Form (Relational Flat Grid):
   Places each field in its own column with standard table headers. Pairing with 'Repeat All Item Labels' makes pivot output ready for downstream VLOOKUP and formulas.

5. TROUBLESHOOTING & COMMON ERRORS
• Missing Item Labels in Downstream Lookups:
  Root Cause: Tabular form leaves blank cells below category headers by default, breaking VLOOKUP / XLOOKUP on downstream formulas.
  Diagnostic Fix: Design tab > Report Layout > Select 'Repeat All Item Labels'.
• Subtotal Visual Clutter:
  Root Cause: Having subtotals on every single row level creates a messy, repetitive report.
  Diagnostic Fix: Design tab > Subtotals > Select 'Do Not Show Subtotals' or toggle specific fields.
• Column Width Auto-Reset on Refresh:
  Root Cause: Refreshing a PivotTable resets manually adjusted column widths back to default.
  Diagnostic Fix: PivotTable Options > Format > Uncheck 'Autofit column widths on update'.

6. PRO TIPS & SHORTCUTS
• Repeat Item Labels (Design > Report Layout > Repeat All Item Labels): Fills down all category labels, making pivot data 100% formula-ready.
• Lock Column Widths (Pivot Options > Uncheck Autofit column widths on update): Prevents column widths from jumping and changing on every refresh.
• Insert Blank Line (Design > Blank Rows > Insert Blank Line After Each Item): Creates visual breathing room between major division groups.
