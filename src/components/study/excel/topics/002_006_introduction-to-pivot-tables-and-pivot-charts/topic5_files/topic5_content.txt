1. EXECUTIVE OVERVIEW
Grouping data in Pivot Tables: Grouping dates (Years, Quarters, Months), Numbers, and Text is an essential discipline in corporate business intelligence and reporting.
It provides the foundation for dynamic in-memory summarization, multi-dimensional slicing, and interactive dashboards.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Group By: Years, Quarters, Months (Dates) | Starting At, Ending At, By (Numeric Bins) | Custom Text Selection

3. CORE TECHNICAL MECHANICS
1. Automated Date Hierarchy Grouping:
   Right-clicking any date cell and choosing 'Group' allows selecting multiple temporal intervals simultaneously (Years, Quarters, Months, Days).

2. Numeric Binning (Histograms):
   Groups continuous numeric ranges (e.g. Invoices $0 to $100,000) into discrete equal-width brackets (Starting at 0, Ending at 100000, By 10000).

3. Manual Text Selection Grouping:
   Select multiple arbitrary text categories (e.g. 'Barrackpore', 'Shyamnagar', 'Ichapur') and group them into custom sales territories ('North 24 Parganas Cluster').

5. TROUBLESHOOTING & COMMON ERRORS
• 'Cannot Group That Selection' Error:
  Root Cause: If the date column contains even a single blank cell, text date string ('27-Aug'), or invalid format, date grouping fails completely.
  Diagnostic Fix: Filter source column for blank cells and text strings; ensure 100% pure serial dates.
• Group Hierarchy Propagating Across All Pivot Tables:
  Root Cause: Grouping dates in one PivotTable automatically groups the same date field across all other PivotTables sharing that Pivot Cache.
  Diagnostic Fix: Uncheck sharing or create independent Data Model pivots if isolated grouping is required.
• Uneven Numeric Bracket Bounds:
  Root Cause: Choosing poor bin intervals creates misleading histogram distributions.
  Diagnostic Fix: Align numeric bin widths with corporate credit or operational bracket standards.

6. PRO TIPS & SHORTCUTS
• Multi-Select Date Tiers (Ctrl + Click Years, Quarters, Months): Select multiple date tiers simultaneously in the Grouping modal dialog.
• Ungroup Shortcut (Right-click > Ungroup (Alt + H + G + U)): Quickly restores raw daily date serials.
• Automatic Date Grouping Toggle (File > Options > Data > Disable automatic grouping): Prevents Excel from automatically splitting dates into Years/Quarters on insertion.
