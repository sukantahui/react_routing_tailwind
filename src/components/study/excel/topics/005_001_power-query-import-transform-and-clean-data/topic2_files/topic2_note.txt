1. THE 5 CORE UI ZONES:
--------------------------------------------------------------------------------
1. Ribbon: Home, Transform (in-place), Add Column (new column), View.
2. Queries Pane (Left): Query grouping, Duplicate vs Reference queries.
3. Data Preview Grid (Center): Live 1,000-row cache, column type icons, context menus.
4. Formula Bar (Top): Real-time M code step expressions.
5. Query Settings Pane (Right): Query Properties & chronological Applied Steps list.

2. CRITICAL BEST PRACTICES:
--------------------------------------------------------------------------------
• Press F2 to rename Applied Steps for audit compliance.
• Use "Remove Other Columns" to guarantee schema resilience.
• Use "Reference" instead of "Duplicate" for modular multi-stage staging pipelines.
• Toggle "Formula Bar" under the View tab to inspect and edit M code directly.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Never ignore column type icon badges—ensure Numbers are numeric and Dates are dates.
• Click the gear icon next to steps to modify visual parameters without re-creating.
• Use Query Dependencies (View tab) to visualize complex 30-query workbooks!
