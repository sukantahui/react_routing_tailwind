1. THE 4 DESTINATION LOAD TARGETS:
--------------------------------------------------------------------------------
• Table: Loads rows into a physical Excel worksheet ListObject table.
• PivotTable Report: Streams data directly into PivotTable cache without worksheet grid tables.
• PivotChart: Generates an interactive visual directly.
• Only Create Connection: Keeps query in memory as lightweight staging pipe (Zero sheet clutter!).

2. THE VERTIPAQ DATA MODEL (POWER PIVOT):
--------------------------------------------------------------------------------
• Checkbox: [X] "Add this data to the Data Model"
• Bypasses the 1,048,576 Excel worksheet row limit (supports 100+ million rows!).
• Achieves 5x to 10x columnar dictionary compression.
• Unlocks Power Pivot star schemas and high-speed DAX measures.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Always choose "Close & Load To..." instead of the default Close & Load button.
• Set all staging and cleaning queries to "Only Create Connection".
• Load final master fact/dimension tables to the Data Model with zero worksheet clutter!
