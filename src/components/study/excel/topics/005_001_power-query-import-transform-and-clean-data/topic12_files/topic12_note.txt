1. THE FUZZY MATCHING SUITE:
--------------------------------------------------------------------------------
• Core Function: Table.FuzzyNestedJoin(T1, Key1, T2, Key2, "Col", JoinKind, FuzzyOptions)
• Similarity Threshold: 0.00 (Match all) to 1.00 (Exact match); Default = 0.80 (Optimal: 0.80-0.85).
• Transformation Table: A 2-column table [From, To] mapping domain acronyms (e.g. BKP → Barrackpore).
• NumberOfMatches = 1: Prevents 1-to-many row explosion by picking top-scoring candidate.
• IgnoreSpaces = true: Handles token spacing variations ("Micro Soft" → "Microsoft").

2. THE 3-PHASE ENTERPRISE FUZZY ARCHITECTURE:
--------------------------------------------------------------------------------
Phase 1: Pre-clean text with Text.Clean, Text.Trim, and Text.Upper.
Phase 2: Deduplicate raw dirty keys and fuzzy-match the distinct list against the master table.
Phase 3: Exact-merge the cleansed master keys back onto the transaction fact table!

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Never fuzzy-match 500,000 raw fact rows directly—it burns CPU! Match distinct keys.
• Use Transformation Tables for Indian corporate abbreviations (Pvt Ltd, WB, BKP).
• Audit fuzzy matches by checking [Raw_Name] <> [Matched_Master_Name] side-by-side.
