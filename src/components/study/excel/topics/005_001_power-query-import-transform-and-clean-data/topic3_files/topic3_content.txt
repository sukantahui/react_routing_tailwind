2. DATA HYGIENE M FUNCTIONS:
- Clean: Table.TransformColumns(Source, {{"Customer", Text.Clean, type text}})
- Trim: Table.TransformColumns(#"Cleaned", {{"Customer", Text.Trim, type text}})
- Proper: Table.TransformColumns(#"Trimmed", {{"Customer", Text.Proper, type text}})
- Fill Down: Table.FillDown(#"Proper", {"Category"})
- Replace Errors: Table.ReplaceErrorValues(#"Prior", {{"Amount", 0}})
- Keep Errors: Table.SelectRowsWithErrors(Source, {"Amount"})
