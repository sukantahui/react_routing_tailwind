5. TROUBLESHOOTING & COMMON ERRORS
• Failing to Convert Dates to pd.to_datetime() First:
  Root Cause: Calling `.resample()` or date slicing on string date columns throws TypeError.
  Diagnostic Fix: Always convert date column: `df['Date'] = pd.to_datetime(df['Date']); df.set_index('Date', inplace=True)`.
• Unsorted Datetime Index Breaking Rolling Windows:
  Root Cause: Calculating rolling averages on chronologically unsorted data produces invalid trend metrics.
  Diagnostic Fix: Always sort index before time series operations: `df.sort_index(inplace=True)`.
• Resample Frequency Deprecation Warnings ('M' vs 'ME'):
  Root Cause: Using deprecated frequency string `'M'` in newer pandas versions.
  Diagnostic Fix: Use modern frequency aliases: `'ME'` (Month End), `'QE'` (Quarter End), `'YE'` (Year End).

6. PRO TIPS & SHORTCUTS
• Rolling 7-Day Average (df['Sales'].rolling(7).mean()): Smooths out day-of-week volatility.
• Monthly Resample (df.resample('ME').sum()): Aggregates daily data into clean monthly buckets.
• Date Range Slicing (df['2026-01':'2026-03']): Intuitive date range filtering on DatetimeIndex.
