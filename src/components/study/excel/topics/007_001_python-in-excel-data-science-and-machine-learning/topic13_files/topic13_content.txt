5. TROUBLESHOOTING & COMMON ERRORS
• Breaking Top-to-Bottom Execution Order:
  Root Cause: Placing variable definitions below consuming formula cells.
  Diagnostic Fix: Maintain strict upper-left to bottom-right cell hierarchy.
• Missing headers=True in xl() Calls:
  Root Cause: Corrupting column names into data rows.
  Diagnostic Fix: Always pass `headers=True` on tabular datasets.
• Calling plt.show() in Cloud Cells:
  Root Cause: Triggering container exceptions.
  Diagnostic Fix: Return `fig` on the last line of visualization formulas.
