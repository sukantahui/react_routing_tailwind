COMMON TRAPS TO AVOID:
- Breaking Top-to-Bottom Execution Order: Placing variable definitions below consuming formula cells. → Fix: Maintain strict upper-left to bottom-right cell hierarchy.
- Missing headers=True in xl() Calls: Corrupting column names into data rows. → Fix: Always pass `headers=True` on tabular datasets.
- Calling plt.show() in Cloud Cells: Triggering container exceptions. → Fix: Return `fig` on the last line of visualization formulas.
