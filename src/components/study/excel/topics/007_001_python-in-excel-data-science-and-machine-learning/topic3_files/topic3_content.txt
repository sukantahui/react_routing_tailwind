5. TROUBLESHOOTING & COMMON ERRORS
• Forgetting .reset_index() After GroupBy (Missing Column Names):
  Root Cause: Grouping without `.reset_index()` leaves grouping keys in the DataFrame index, causing missing headers when spilled.
  Diagnostic Fix: Always append `.reset_index()` to GroupBy operations: `df.groupby(...).sum().reset_index()`.
• Merge Key Type Mismatch (String vs Integer):
  Root Cause: Joining tables where ID in Table A is integer `101` and in Table B is string `"101"` returns empty DataFrame.
  Diagnostic Fix: Cast join keys: `df1['ID'] = df1['ID'].astype(str)`.
• Chained Indexing Assignment Warning:
  Root Cause: Modifying DataFrame slices with `df[df['A']>5]['B'] = 10`.
  Diagnostic Fix: Use `.loc`: `df.loc[df['A'] > 5, 'B'] = 10`.

6. PRO TIPS & SHORTCUTS
• Always Reset Index (df.groupby('Col').sum().reset_index()): Guarantees clean column headers on output.
• High-Speed Join (pd.merge(df1, df2, on='Key', how='left')): Replaces 20 complex VLOOKUP formulas in 1 line.
• Sort Values (df.sort_values(by='Revenue', ascending=False)): Sorts DataFrame by column.
