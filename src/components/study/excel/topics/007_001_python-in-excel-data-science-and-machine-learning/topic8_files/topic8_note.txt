KEY FORMULA / SYNTAX:
Linear Regression: import statsmodels.api as sm; X = sm.add_constant(df[['AdSpend', 'Discount']]); y = df['Revenue']; model = sm.OLS(y, X).fit(); model.summary()

PRIMARY CONCEPT:
Building econometric regression models and predictive coefficients in Excel using statsmodels.OLS: Ordinary Least Squares regression, R-squared, coefficient p-values, and multicollinearity diagnostics

TEACHER'S ADVICE:
Linear regression is the ultimate tool for corporate forecasting. Always write `X = sm.add_constant(X)` before fitting your model! In 4 lines of Python, you can find out exactly how much every ₹1 spent on marketing increases your bottom-line revenue.

COMMON TRAPS TO AVOID:
- Omitting sm.add_constant(X) (Zero Intercept Disaster): Forgetting `sm.add_constant()` forces the regression line through the origin (0,0), generating completely invalid R-squared and biased coefficients. → Fix: Always wrap feature matrices: `X = sm.add_constant(X)`.
- Multicollinearity Between Features (VIF > 10): Including two highly correlated independent variables (e.g. Total Revenue and Gross Sales) distorting coefficient p-values. → Fix: Check correlation matrix and remove redundant collinear features.
- Passing Strings or Missing Values into OLS: statsmodels requires clean numeric floats with zero NaN values. → Fix: Drop NaNs: `df.dropna(subset=['y', 'x1', 'x2'])` and encode categorical variables.
