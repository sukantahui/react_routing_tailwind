1. EXECUTIVE OVERVIEW
Statistical modeling and hypothesis testing with scipy.stats (t-tests, ANOVA, Chi-square) is an essential discipline in modern spreadsheet data science, applied machine learning, and advanced business analytics.
It provides the core protocols required to run Python analytics natively inside Excel, manipulate pandas DataFrames, and deploy predictive AI models.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Statistical Testing: from scipy import stats; t_stat, p_val = stats.ttest_ind(groupA, groupB); f_stat, p_val = stats.f_oneway(g1, g2, g3); chi2, p_val, ... = stats.chi2_contingency(table)

3. CORE TECHNICAL MECHANICS
1. Two-Sample Independent T-Tests (`ttest_ind`):
   Tests whether the difference in mean revenue or conversion rates between two marketing campaigns (A/B testing) is statistically significant.

2. One-Way ANOVA (`f_oneway`):
   Evaluates whether mean output differs significantly across 3 or more regional factory production lines.

3. Chi-Square Test of Independence (`chi2_contingency`):
   Tests for significant categorical association between customer demographics and product return rates.

5. TROUBLESHOOTING & COMMON ERRORS
• Misinterpreting p-value (p < 0.05 vs p >= 0.05):
  Root Cause: Rejecting null hypothesis when p-value is 0.12 (insufficient statistical evidence).
  Diagnostic Fix: Enforce standard alpha threshold: Reject H0 only if `p_val < 0.05`.
• Ignoring Normality & Variance Assumptions:
  Root Cause: Running standard t-tests on highly skewed non-normal data without variance checks.
  Diagnostic Fix: Check variance equality (`stats.levene`) or use non-parametric Mann-Whitney U test (`stats.mannwhitneyu`).
• Passing Unequal Sample Sizes into Paired T-Test:
  Root Cause: Calling `stats.ttest_rel()` on arrays with different lengths throws ValueError.
  Diagnostic Fix: Ensure paired observations have identical row lengths.

6. PRO TIPS & SHORTCUTS
• Two-Sample T-Test (stats.ttest_ind(groupA, groupB)): The gold standard for commercial A/B testing.
• p-Value Evaluation (is_significant = p_val < 0.05): Statistically significant at 95% confidence level.
• One-Way ANOVA (stats.f_oneway(group1, group2, group3)): Compares means across 3+ categories simultaneously.
