KEY FORMULA / SYNTAX:
Summary Statistics: df.describe() | Correlation Matrix: df.corr(numeric_only=True) | Value Counts: df['Category'].value_counts() | Skew/Kurt: df.skew(), df.kurt()

PRIMARY CONCEPT:
Generating comprehensive exploratory data analysis (EDA) summary matrices with pandas: descriptive statistics (mean, std, quartiles), correlation matrices, covariance, and frequency distributions

TEACHER'S ADVICE:
Want an instant summary of your entire dataset? Just type `df.describe()`! In half a second, Python gives you the average, median, min, max, standard deviation, and quartiles for every single numeric column.

COMMON TRAPS TO AVOID:
- Correlation Crashing on Non-Numeric Text Columns: Calling `df.corr()` in newer pandas versions on DataFrames with text columns throws ValueError. -> Fix: Always pass `numeric_only=True`: `df.corr(numeric_only=True)`.
- Confusing Correlation with Causation: Assuming high correlation (0.85) automatically means Variable A causes Variable B. -> Fix: Validate statistical correlations with domain expertise and regression hypothesis testing.
- Missing NaN Treatment in Correlation: Datasets with extreme missing values distorting correlation matrices. -> Fix: Inspect missing value counts with `df.isnull().sum()` prior to correlation.
