5. TROUBLESHOOTING & COMMON ERRORS
• Recipient Opening File in Legacy Desktop Excel 2016 / 2019:
  Root Cause: Legacy perpetual Office versions lack cloud Python runtime, displaying `#NAME?` error on `=PY()` cells.
  Diagnostic Fix: Advise recipients to open file in Excel for Web or upgrade to Microsoft 365.
• Leaving 50 Unneeded Visualizations Rendering on Every Calc:
  Root Cause: Recalculating 50 complex seaborn plots simultaneously on every cell edit causes cloud latency.
  Diagnostic Fix: Convert static finalized plots to Excel Values or image snapshots.
• Confusing Co-Authoring Lockups:
  Root Cause: Multiple users editing Python code cells simultaneously in live co-authoring sessions.
  Diagnostic Fix: Designate specific input assumption cells for collaborators while locking Python formula cells.

6. PRO TIPS & SHORTCUTS
• Standard .xlsx Format (No .xlsm required): Saves as standard clean Excel workbook.
• Excel for Web Fallback (Opens in any web browser): Guarantees cross-platform viewing on Mac, Linux, and tablets.
• Lock Python Formula Cells (Review > Protect Sheet): Prevents non-technical users from accidentally breaking Python formulas.
