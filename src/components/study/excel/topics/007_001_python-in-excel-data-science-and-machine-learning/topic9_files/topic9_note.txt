TEACHER'S ADVICE:
You are running real Machine Learning directly inside Microsoft Excel! Train a Random Forest model in cell A1, predict customer churn in cell B1, and your spreadsheet becomes an enterprise AI prediction machine.

COMMON TRAPS TO AVOID:
- Data Leakage During Feature Preprocessing: Fitting encoders or scalers on the entire dataset before splitting into train/test sets. → Fix: Always split data first: `X_train, X_test, y_train, y_test = train_test_split(X, y)`.
- Passing Categorical Text Directly to scikit-learn: scikit-learn algorithms require pure numeric matrices; passing text strings throws ValueError. → Fix: Encode text columns using `pd.get_dummies()` or `LabelEncoder()`.
- Overfitting on Small Sample Datasets: Training complex deep trees on 50 rows of data. → Fix: Use cross-validation and regularize tree depth (`max_depth=5`).
