5. TROUBLESHOOTING & COMMON ERRORS
• Data Leakage During Feature Preprocessing:
  Root Cause: Fitting encoders or scalers on the entire dataset before splitting into train/test sets.
  Diagnostic Fix: Always split data first: `X_train, X_test, y_train, y_test = train_test_split(X, y)`.
• Passing Categorical Text Directly to scikit-learn:
  Root Cause: scikit-learn algorithms require pure numeric matrices; passing text strings throws ValueError.
  Diagnostic Fix: Encode text columns using `pd.get_dummies()` or `LabelEncoder()`.
• Overfitting on Small Sample Datasets:
  Root Cause: Training complex deep trees on 50 rows of data.
  Diagnostic Fix: Use cross-validation and regularize tree depth (`max_depth=5`).

6. PRO TIPS & SHORTCUTS
• Train/Test Split (from sklearn.model_selection import train_test_split): Evaluates true generalization accuracy.
• One-Hot Encoding (pd.get_dummies(df, drop_first=True)): Converts text categories into numeric features.
• Confusion Matrix (from sklearn.metrics import confusion_matrix): Evaluates false positives and false negatives.
