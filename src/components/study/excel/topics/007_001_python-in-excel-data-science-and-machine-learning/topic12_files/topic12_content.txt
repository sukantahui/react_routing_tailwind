5. TROUBLESHOOTING & COMMON ERRORS
• Class Imbalance in Churn Datasets (95% Non-Churn vs 5% Churn):
  Root Cause: A naive model predicting 'No Churn' achieves 95% accuracy while failing to identify ANY actual churners.
  Diagnostic Fix: Set `class_weight='balanced'` in Random Forest or evaluate ROC-AUC rather than raw accuracy.
• Including Post-Event Leakage Variables (Data Leakage):
  Root Cause: Including 'Cancellation Date' as an input feature to predict cancellation.
  Diagnostic Fix: Use strictly historical pre-churn behavior metrics (usage drops, support tickets).
• Unchecked Outlier Distortions in Usage Metrics:
  Root Cause: Extreme customer usage spikes skewing linear logistic regression boundaries.
  Diagnostic Fix: Apply log transformation: `np.log1p(df['Usage'])`.

6. PRO TIPS & SHORTCUTS
• Balanced Class Weights (RandomForestClassifier(class_weight='balanced')): Critical for high accuracy on rare churn events.
• Cohort Pivot Matrix (df.pivot_table(index='Cohort', columns='Period', values='Retention')): Generates standard retention cohort grid.
• 1-Click Recalculation (F9 or Ctrl + Alt + F9): Recalculates entire machine learning pipeline across Azure cloud containers.
