COMMON TRAPS TO AVOID:
- Class Imbalance in Churn Datasets (95% Non-Churn vs 5% Churn): A naive model predicting 'No Churn' achieves 95% accuracy while failing to identify ANY actual churners. -> Fix: Set `class_weight='balanced'` in Random Forest or evaluate ROC-AUC rather than raw accuracy.
- Including Post-Event Leakage Variables (Data Leakage): Including 'Cancellation Date' as an input feature to predict cancellation. -> Fix: Use strictly historical pre-churn behavior metrics (usage drops, support tickets).
- Unchecked Outlier Distortions in Usage Metrics: Extreme customer usage spikes skewing linear logistic regression boundaries. -> Fix: Apply log transformation: `np.log1p(df['Usage'])`.
