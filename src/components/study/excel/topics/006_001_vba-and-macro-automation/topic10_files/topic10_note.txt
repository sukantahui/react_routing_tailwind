KEY FORMULA / SYNTAX:
VBA High-Speed Optimization Engine: Application.ScreenUpdating = False | Application.Calculation = xlCalculationManual | Application.EnableEvents = False | Application.DisplayAlerts = False

PRIMARY CONCEPT:
Supercharging VBA execution speed by 50x to 100x using the Big 4 optimization switches: disabling ScreenUpdating, pausing automatic calculation, disabling event triggers, and processing data in RAM arrays

TEACHER'S ADVICE:
Every serious macro you write MUST start with `Application.ScreenUpdating = False` and end with `Application.ScreenUpdating = True`. It stops the screen from flickering and makes your code run 50x faster instantly.

COMMON TRAPS TO AVOID:
- Leaving ScreenUpdating / Events Disabled on Macro Error: Macro crashes mid-way before restoring `ScreenUpdating = True`, leaving Excel frozen and unresponsive to user clicks. -> Fix: Always wrap in structured error handling (`On Error GoTo CleanUp`) to guarantee switches are restored.
- Leaving Calculation in Manual Mode After Execution: User edits numbers later and wonders why formulas are not updating. -> Fix: Restore `Application.Calculation = xlCalculationAutomatic` before exiting sub.
- Writing Cell-by-Cell in a 100,000 Row Loop: Crossing the COM bridge 100,000 times to write individual cells wastes 99% of CPU time. -> Fix: Use a Variant array to write all 100,000 rows in a single 1-line assignment: `Range("A1:E100000").Value2 = arr`.
