5. TROUBLESHOOTING & COMMON ERRORS
• Monolithic 500-Line Single Macro (Anti-Pattern):
  Root Cause: Writing a single giant unmaintainable 500-line Sub procedure.
  Diagnostic Fix: Decompose into clean, modular single-responsibility Sub procedures called from a Master Controller macro.
• Hardcoding File Paths or Sheet Indices:
  Root Cause: Hardcoded paths like `C:\Users\swadeep\` breaking on other team members' laptops.
  Diagnostic Fix: Use relative paths: `ThisWorkbook.Path & "\Reports\"`.
• Unprotected Master Template Overwrites:
  Root Cause: Macro overwriting the master template file instead of saving a timestamped copy.
  Diagnostic Fix: Save generated output as a new timestamped workbook: `"Report_" & Format(Now, "yyyymmdd_hhnn") & ".xlsx"`.

6. PRO TIPS & SHORTCUTS
• Modular Architecture (Master Controller calling Sub procedures): The standard software engineering pattern for enterprise VBA.
• Timestamped Output (Format(Now, "yyyymmdd_hhnnss")): Prevents accidental file overwriting on shared network drives.
• Attach to Ribbon Button (Assign Macro to custom button shape): Delivers an intuitive 1-click software experience for end-users.
