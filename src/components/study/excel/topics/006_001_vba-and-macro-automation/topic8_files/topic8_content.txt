1. EXECUTIVE OVERVIEW
Looping constructs: For...Next, For Each...Next (Looping over sheets, cells, shapes), and Do While/Until is an essential discipline in corporate workflow automation, spreadsheet engineering, and high-speed data processing.
It provides the core protocols required to eliminate manual repetitive tasks, manipulate Excel objects programmatically, and build enterprise-grade automation tools.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Looping Constructs: For i = 1 To lastRow ... Next i | For Each ws In ThisWorkbook.Worksheets ... Next ws | Do While Condition ... Loop

3. CORE TECHNICAL MECHANICS
1. For...Next (Indexed Counter Loops):
   Loops from a start index to an end index with optional `Step` (`For i = 2 To lastRow Step 1`). Perfect for processing rows in a table.

2. For Each...Next (Collection Iteration):
   Iterates through every object in an Excel collection (e.g. `For Each ws In ThisWorkbook.Worksheets`, `For Each c In Range("A1:A100")`). Cleanest and fastest way to loop through sheets.

3. Do While / Do Until (Condition-Driven):
   Continues looping until a specific business condition is met (e.g. reading lines from an external file until End-of-File `EOF`).

4. Looping Backwards for Row Deletion:
   When deleting rows based on a condition, you MUST loop backwards: `For i = lastRow To 2 Step -1` to prevent row index skipping.

5. TROUBLESHOOTING & COMMON ERRORS
• Looping Forward When Deleting Rows (The Row Skipping Bug):
  Root Cause: Looping `For i = 2 To lastRow` and deleting row 5 shifts row 6 into row 5 position; the next loop evaluates row 6 (skipping the new row 5!).
  Diagnostic Fix: Always loop BACKWARDS when deleting rows: `For i = lastRow To 2 Step -1`.
• Unbounded Do While Loop Freezing Excel:
  Root Cause: Writing `Do While x < 10` and forgetting to increment `x = x + 1` creates an infinite calculation loop.
  Diagnostic Fix: Include increment counters and test loops with F8 stepping.
• Looping Individual Cells on 1-Million Row Grids (Slow):
  Root Cause: Iterating cell-by-cell `For Each c In Range("A1:A1000000")` is slow because it crosses the COM boundary 1 million times.
  Diagnostic Fix: Read the entire range into a Variant Array in 1 shot, process in RAM, and write back in 1 shot.

6. PRO TIPS & SHORTCUTS
• Loop Backwards for Deletion (For i = lastRow To 2 Step -1): The only safe way to delete rows conditionally without skipping.
• Loop All Sheets (For Each ws In ThisWorkbook.Worksheets): Fastest way to perform operations across all workbook tabs.
• Exit For Early (If found Then Exit For): Terminates loop immediately once search target is found.
