Topic 12: Working with MsgBox and InputBox for user interaction
================================================================================

1. EXECUTIVE OVERVIEW
Working with MsgBox and InputBox for user interaction is an essential discipline in corporate workflow automation, spreadsheet engineering, and high-speed data processing.
It provides the core protocols required to eliminate manual repetitive tasks, manipulate Excel objects programmatically, and build enterprise-grade automation tools.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: User Interaction: MsgBox(Prompt, [Buttons], [Title]) | InputBox(Prompt, [Title], [Default]) | Application.InputBox(..., Type:=8 for Range)

3. CORE TECHNICAL MECHANICS
1. MsgBox Button Configurations & Return Codes:
   Combines button types and icons (`vbYesNo + vbQuestion`, `vbOKOnly + vbInformation`, `vbRetryCancel + vbCritical`) and evaluates response (`If res = vbYes Then ...`).

2. VBA InputBox vs Application.InputBox:
   VBA `InputBox` returns plain text. `Application.InputBox` supports strict data type enforcement using the `Type` parameter (e.g. `Type:=1` for Numbers, `Type:=8` for clickable Range selection).

3. Handling User Cancellation Gracefully:
   Always check if user clicked 'Cancel' or closed dialog without entering data (`If strInput = "" Then Exit Sub`).

5. TROUBLESHOOTING & COMMON ERRORS
• Crashing on Application.InputBox Type:=8 Cancel:
  Root Cause: User clicking 'Cancel' on a Range InputBox throws runtime error 424 'Object required'.
  Diagnostic Fix: Wrap in `On Error Resume Next: Set rng = Application.InputBox(..., Type:=8): On Error GoTo 0: If rng Is Nothing Then Exit Sub`.
• Setting vbDefaultButton to 'Yes' on Dangerous Actions:
  Root Cause: Defaulting to 'Yes' on a destructive delete action means an accidental press of Enter deletes all data.
  Diagnostic Fix: Set default button to No: `vbYesNo + vbDefaultButton2`.
• Missing Parentheses When Capturing Return Value:
  Root Cause: Writing `res = MsgBox "Text"` without parentheses throws a compile error.
  Diagnostic Fix: When assigning to a variable, use parentheses: `res = MsgBox("Text", vbYesNo)`.

6. PRO TIPS & SHORTCUTS
• Range InputBox (Type:=8) (Application.InputBox("Select:", Type:=8)): Allows user to click and drag a range directly on the worksheet.
• Safe Confirmation (vbYesNo + vbQuestion + vbDefaultButton2): Forces user to actively think before confirming dangerous actions.
• MsgBox Syntax Rule (Use parentheses ONLY when capturing result): `MsgBox "Hi"` vs `res = MsgBox("Hi", vbYesNo)`.
