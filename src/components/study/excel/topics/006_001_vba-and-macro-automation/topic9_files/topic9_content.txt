Topic 9: Writing Sub procedures and custom User-Defined Functions (UDFs) callable in worksheet cells

1. EXECUTIVE OVERVIEW
Writing Sub procedures and custom User-Defined Functions (UDFs) callable in worksheet cells is an essential discipline in corporate workflow automation, spreadsheet engineering, and high-speed data processing.
It provides the core protocols required to eliminate manual repetitive tasks, manipulate Excel objects programmatically, and build enterprise-grade automation tools.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: User-Defined Function: Function CalculateTax(Income As Double, Slab As String) As Double ... CalculateTax = Result ... End Function

3. CORE TECHNICAL MECHANICS
1. Sub Procedures (Perform Actions):
   Executes procedural actions (formatting cells, creating sheets, exporting PDFs). Cannot be called inside worksheet formula cells (`=MySub()`).

2. User-Defined Functions (Return Values):
   Calculates and returns a single value or dynamic array. Can be typed directly into worksheet cells like native formulas (`=CalculateGST(A2, "Tier1")`).

3. UDF Purity Sandbox Rules:
   Worksheet UDFs CANNOT modify worksheet structure, change formatting, or insert new sheets; they can ONLY compute and return values.

5. TROUBLESHOOTING & COMMON ERRORS
• Attempting to Format Cells Inside a UDF:
  Root Cause: Writing `Range("A1").Interior.Color = vbGreen` inside a worksheet UDF causes the function to fail and return `#VALUE!`.
  Diagnostic Fix: UDFs called from cells can ONLY calculate and return values; use Sub procedures for formatting.
• Forgetting to Assign the Return Value to the Function Name:
  Root Cause: In VBA, functions return values by assigning to the function name (`CalculateTax = dblTax`); forgetting this causes function to return 0.
  Diagnostic Fix: Assign the final result to the Function Name: `FunctionName = Result`.
• Missing Application.Volatile on Timestamp UDFs:
  Root Cause: Custom UDF not recalculating when other cells change.
  Diagnostic Fix: Add `Application.Volatile True` at the top of the function if it must recalculate on every worksheet change.

6. PRO TIPS & SHORTCUTS
• Assign to Function Name (MyFunction = CalculatedValue): Mandatory VBA syntax to return the result of a UDF.
• Write UDF in Standard Module (Insert > Module): UDFs must be in Standard Modules to be recognized in worksheet cells.
• Document Arguments (Function MyFunc(Val As Double) As Double): Enforces strict type safety on inputs and return values.
