1. FORMULA SYNTAX & COLUMN PROJECTION
--------------------------------------------------------------------------------
Syntax: =CHOOSECOLS(array, col_num1, [col_num2], ...)

Argument 1: array (Required)
  The source 2D table, range, or in-memory dynamic array.

Argument 2+: col_num1, col_num2... (Required / Optional)
  Positive integers (1, 2, 3...) count from the left (Column A onwards).
  Negative integers (-1, -2, -3...) count backwards from the rightmost column.
  Array constants (e.g. {1, 4, 2}) can be passed to reorder fields dynamically.

2. CORE ENTERPRISE USE CASES
--------------------------------------------------------------------------------
• Data Masking: Project only non-sensitive columns (Emp_ID, Name, Net_Pay),
  omitting confidential base salary and tax deduction columns.
• Dynamic Column Reordering: Reorganize backend database fields into desired
  presentation schemas without altering the raw database structure.
• Negative Indexing (-1): Dynamically reference the last column regardless of
  intervening columns added or deleted over time.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Never hardcode intermediate helper columns — use CHOOSECOLS directly in memory.
• Combine with FILTER: =CHOOSECOLS(FILTER(Table, Criteria), 1, 2, 5).
• Check destination footprint to prevent #SPILL! errors across columns.
