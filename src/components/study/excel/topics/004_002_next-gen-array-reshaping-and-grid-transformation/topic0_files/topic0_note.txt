1. ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------
Excel 365 introduced a dedicated suite of in-memory matrix manipulation and array
reshaping functions. These functions eliminate the historic need for volatile helper
columns, complex INDEX/MATCH/OFFSET formulas, and VBA macro loops.

The 11 Core Transformation Functions:
1. TOCOL       : Flattens 2D matrices into vertical 1D columns.
2. TOROW       : Flattens 2D matrices into horizontal 1D rows.
3. CHOOSEROWS  : Extracts specific rows across all columns by index (supports -ve indexing).
4. CHOOSECOLS  : Extracts and reorders specific columns across all rows by index.
5. TAKE        : Extracts Top N or Bottom N rows and columns.
6. DROP        : Excludes / strips outer boundary rows or columns.
7. EXPAND      : Resizes and pads arrays to standardized target dimensions.
8. WRAPROWS    : Wraps a 1D continuous stream into a structured 2D matrix (row-wise).
9. WRAPCOLS    : Wraps a 1D continuous stream into a structured 2D matrix (column-wise).
10. VSTACK     : Appends multiple arrays or ranges vertically into one unified matrix.
11. HSTACK     : Joins multiple arrays or vectors horizontally side-by-side.

2. KEY ADVANTAGES OVER LEGACY EXCEL
--------------------------------------------------------------------------------
• Zero Volatility: Unlike OFFSET and INDIRECT, reshaping functions are non-volatile
  and calculate with native C++ speed.
• Dynamic Spill Synergy: Seamlessly accept and process spilled ranges using `#`.
• Composability: Nestable inside SUM, AVERAGE, FILTER, SORT, and XLOOKUP in RAM.
• Clean Architecture: Raw data stays untouched; output is completely dynamic.

3. PEDAGOGICAL WARNINGS FOR STUDENTS (SUKANTA HUI'S CLASSROOM RULES)
--------------------------------------------------------------------------------
• Avoid whole column references (e.g. A:E) — always use structured tables or bounded ranges.
• Beware of negative indexing: -1 is the LAST row/col; -2 is the second last.
• When stacking tables with VSTACK, remember to DROP the headers of tables 2, 3, etc.
• Check for blocking cells to prevent #SPILL! errors.
