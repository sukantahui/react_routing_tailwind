1. EXECUTIVE OVERVIEW
Digit placeholders deep-dive: forced zero (0), optional digits (#), and decimal alignment (?) is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: 0 (Forced Zero) | # (Optional Digit) | ? (Fraction/Space Align)

3. CORE TECHNICAL MECHANICS
1. Forced Zero (0):
   Always displays a digit; if the input has fewer digits than zeroes in the format, Excel pads leading or trailing zeroes.

2. Optional Hash (#):
   Displays significant digits only; suppresses non-significant leading and trailing zeroes to keep display minimal.

3. Question Mark Alignment (?):
   Leaves an invisible non-breaking space for missing digits, guaranteeing perfect vertical decimal point alignment.

5. TROUBLESHOOTING & COMMON ERRORS
• Lost Leading Zeros in CSV:
  Root Cause: Using 00000 formatting visually shows leading zeros, but CSV export may drop them.
  Diagnostic Fix: Be aware of export formats; for CSV data transfer, prepend text codes or export as text.
• Misaligned Decimal Columns:
  Root Cause: Mixing # and 0 tokens causes jagged column decimal points when values have varying lengths.
  Diagnostic Fix: Use ? placeholders to reserve invisible spaces for missing digits.
• Unintended Trailing Zeros:
  Root Cause: Using 0.00 on whole numbers forces '15.00' when '15' is desired.
  Diagnostic Fix: Use 0.## when trailing zeros are optional.
