1. EXECUTIVE OVERVIEW
Currency and international formats: $, ₹, €, £, and Indian numbering (##,##,##0) is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: [$₹-402] ##,##,##0.00 /* Indian Lakhs & Crores */ | [$$-409] #,##0.00 /* USD */

3. CORE TECHNICAL MECHANICS
1. Indian Numbering System (Lakhs & Crores):
   Indian statutory standards group the first 3 digits from the right, followed by 2-digit groups: `[$-402] ##,##,##0.00`.

2. LCID Locale Enforcement:
   The `[$Symbol-LocaleID]` syntax locks currency rendering so sheets opened on foreign OS language packs maintain correct currency symbols.

3. Zero & Negative Handling with Currency:
   Combines currency symbols with accounting parentheses: `[$₹-402] ##,##,##0.00;([$₹-402] ##,##,##0.00);"-"`.

5. TROUBLESHOOTING & COMMON ERRORS
• Western vs Indian Grouping:
  Root Cause: Default #,##0.00 groups in thousands (1,250,000) instead of Indian lakhs (12,50,000).
  Diagnostic Fix: Use explicit Indian locale code [$-402] ##,##,##0.00 or custom group format.
• Currency Symbol Math Lock:
  Root Cause: Typing 'Rs. 5000' converts cell to text, breaking arithmetic formulas.
  Diagnostic Fix: Always apply currency format masks to raw numbers.
• Locale Code Syntax Drift:
  Root Cause: Using outdated country codes can cause unexpected currency symbols across Office versions.
  Diagnostic Fix: Use explicit LCID format codes like [$₹-hi-IN] or [$₹-402].

6. PRO TIPS & SHORTCUTS
• Indian Rupee Symbol (Ctrl + Alt + 4): Quickly insert the official ₹ rupee currency symbol.
• Indian Lakhs Grouping ([$-402] ##,##,##0): Enforce 2-digit grouping after hundreds place (Lakhs and Crores).
• Global Locale Tags ([$$-409], [$€-407]): Lock currency symbols regardless of client OS regional settings.
