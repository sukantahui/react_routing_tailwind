Topic 5: Scaling large numbers into Thousands (K), Millions (M), and Billions (B)
================================================================================

1. EXECUTIVE OVERVIEW
Scaling large numbers into Thousands (K), Millions (M), and Billions (B) is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: #,##0.0, "K" /* Thousands */ | #,##0.0,, "M" /* Millions */ | #,##0.0,,, "B" /* Billions */

3. CORE TECHNICAL MECHANICS
1. Trailing Comma Divisor Rule:
   Each comma placed after digit placeholders divides the displayed value by 1,000 without altering the cell's underlying numerical value.

2. Unit Suffix Labeling:
   Appends literal string suffixes like 'K', 'M', or 'B' after the scaling commas to produce clean executive metrics.

3. Formula Math Preservation:
   Downstream calculations continue computing against full raw values (e.g. 45,890,000) rather than scaled display floats (45.9).

5. TROUBLESHOOTING & COMMON ERRORS
• Accidental Formula Division:
  Root Cause: Dividing by 1,000,000 in formulas (/10^6) modifies underlying values and breaks dependent totals.
  Diagnostic Fix: Use trailing commas in custom number format instead of formula division.
• Comma Placement Errors:
  Root Cause: Placing spaces between commas cancels the 1,000 divisor effect.
  Diagnostic Fix: Keep trailing commas adjacent to digits before literal unit strings (e.g. #,##0.0,, "M").
• Over-Rounding Visuals:
  Root Cause: Scaling small values (e.g. ₹45,000) with M scaling shows '₹0.0M'.
  Diagnostic Fix: Choose appropriate scale (K vs M) based on magnitude of data range.

6. PRO TIPS & SHORTCUTS
• Thousands Scale (K) (#,##0, "K"): One trailing comma divides displayed value by 1,000.
• Millions Scale (M) (#,##0.0,, "M"): Two trailing commas divide displayed value by 1,000,000.
• Billions Scale (B) (#,##0.0,,, "B"): Three trailing commas divide displayed value by 1,000,000,000.
