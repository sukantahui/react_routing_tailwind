Topic 1: The 4-Section Syntax architecture: Positive ; Negative ; Zero ; Text
================================================================================

1. EXECUTIVE OVERVIEW
The 4-Section Syntax architecture: Positive ; Negative ; Zero ; Text is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: <POSITIVE> ; <NEGATIVE> ; <ZERO> ; <TEXT>

3. CORE TECHNICAL MECHANICS
1. Semicolon Partitioning Rules:
   Format strings contain up to 4 sections separated by semicolons: `Pos;Neg;Zero;Text`. If fewer sections are provided, Excel applies cascading fallback rules.

2. Section Fallback Cascade:
   1 section applies to all numbers. 2 sections apply to Positive/Zero ; Negative. 3 sections apply to Positive ; Negative ; Zero. 4 sections handle all 4 data types.

3. The @ Text Catch-All Operator:
   The fourth section specifies text handling. The `@` character is the placeholder for whatever text string is entered into the cell.

5. TROUBLESHOOTING & COMMON ERRORS
• Missing Semicolon Fallback:
  Root Cause: Omitting the 3rd semicolon causes zero values to adopt positive formatting rules.
  Diagnostic Fix: Include all 3 semicolons (Pos;Neg;Zero;Text) to establish clean four-way branching.
• Unquoted Text Strings:
  Root Cause: Typing raw literal words without double quotes triggers parsing syntax errors.
  Diagnostic Fix: Enclose arbitrary words in double quotes (e.g. "Nil", "Paid").
• Missing Text Placeholder:
  Root Cause: Omitting @ in section 4 suppresses entered text strings entirely.
  Diagnostic Fix: Always include @ or literal text in the 4th section.

6. PRO TIPS & SHORTCUTS
• Dash for Zero (Section 3: "-"): Use a clean hyphen "-" in Section 3 to replace distracting 0.00s in financial statements.
• Parentheses for Negatives (Section 2: (0.00)): Use parentheses in Section 2 to adhere to Wall Street accounting standards.
• Built-In Color Tags ([Red], [Green], [Blue]): Apply color tags inside section headers without heavy conditional formatting.
