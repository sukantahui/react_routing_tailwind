5. TROUBLESHOOTING & COMMON ERRORS
• Inconsistent Decimal Precision:
  Root Cause: Showing 2 decimals on some rows and 0 decimals on others makes statements look amateurish.
  Diagnostic Fix: Enforce consistent 0-decimal or 2-decimal standards across all financial statement lines.
• Unaligned Totals Underlines:
  Root Cause: Using cell bottom borders that do not match accounting single/double underline conventions.
  Diagnostic Fix: Use standard Accounting Underline settings (Single for subtotals, Double for Net Income).
• Missing Zero-Dashes:
  Root Cause: Leaving raw 0 values creates visual clutter across sparse matrix financial models.
  Diagnostic Fix: Enforce "-" for zero balances across all statement schedules.

6. PRO TIPS & SHORTCUTS
• Top/Bottom Border Convention (Single Top, Double Bottom): Universal institutional accounting standard for Net Income line items.
• Statement Header Block (Company / Statement / Period): 3-line header: Organization Name, Statement Title, Period Ending Date.
• Percentage Precision (0.0%): Format margins (Gross Margin, Operating Margin) with exactly 1 decimal place.
