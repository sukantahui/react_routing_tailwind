1. EXECUTIVE OVERVIEW
Introduction to Excel's format engine: Display values vs underlying stored values is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: #,##0.00 /* Visual Masking Layer */

3. CORE TECHNICAL MECHANICS
1. Visual Presentation Layer Decoupling:
   Excel separates raw underlying data (IEEE 754 float/serial int) from rendered visual glyphs. Formatting only changes cell rasterization, never truncating mathematical values.

2. Precision Preservation in Math:
   When 12.3456 is formatted as '12.35', formulas referencing that cell continue calculating with 12.3456, preventing cumulative rounding drift in financial ledgers.

3. Formula Bar vs Cell Grid Truth:
   The Formula Bar always reveals the unformatted ground truth value, whereas the grid displays the customized visual mask specified in Number Format settings.

5. TROUBLESHOOTING & COMMON ERRORS
• Visual Rounding Discrepancy:
  Root Cause: Cells display rounded numbers (e.g. 10.4 + 10.4 displayed as 10 + 10 = 21).
  Diagnostic Fix: Use ROUND() explicitly if regulatory compliance mandates calculating rounded decimals.
• Accidental Text Typing:
  Root Cause: Typing unit names ('1500 KG') directly into cells converts data to static text.
  Diagnostic Fix: Apply custom number format 0" KG" to keep pure numerical data type.
• Column Overflow (###):
  Root Cause: Formatted string exceeds column pixel width.
  Diagnostic Fix: Double-click column header boundary (Alt + H + O + I) to AutoFit.
