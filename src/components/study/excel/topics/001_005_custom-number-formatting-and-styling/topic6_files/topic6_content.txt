1. EXECUTIVE OVERVIEW
Embedded conditional criteria ([>1000]) and color formatting ([Red], [Green], [ColorN]) is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: [>1000][Green]#,##0;[<0][Red](#,##0);[Color10]#,##0

3. CORE TECHNICAL MECHANICS
1. Bracketed Relational Operators:
   Prefixing a format section with `[>1000]` overrides default Pos/Neg routing with custom mathematical threshold criteria.

2. Hardware-Accelerated Color Tags:
   Color tokens `[Red]`, `[Green]`, `[ColorN]` instruct Excel's rendering engine to apply colors directly without creating conditional formatting rules.

3. Two-Condition Boundary & Fallback:
   Format strings support up to 2 custom condition brackets, followed by a final fallback rule for all remaining values.

5. TROUBLESHOOTING & COMMON ERRORS
• Two-Condition Maximum Limit:
  Root Cause: Excel custom format supports at most 2 explicit bracket conditions plus 1 default fallback.
  Diagnostic Fix: If 4 or more conditions are required, use Excel's Conditional Formatting rule manager.
• Unsupported Color Names:
  Root Cause: Using custom names like [Orange] or [Purple] triggers syntax errors.
  Diagnostic Fix: Use standard color names ([Black],[White],[Red],[Green],[Blue],[Yellow],[Magenta],[Cyan]) or [Color1] to [Color56].
• Condition Order Misconfiguration:
  Root Cause: Placing [>100] before [>500] catches values >500 in the first condition.
  Diagnostic Fix: Always arrange conditional thresholds in descending (or mutually exclusive) order.

6. PRO TIPS & SHORTCUTS
• Standard 8 Colors ([Red], [Green], [Blue]...): Use core color names inside square brackets at the start of any section.
• Indexed Colors (1-56) ([Color10], [Color25]): Access Excel's full 56-color palette via [ColorN] tokens.
• Comparison Operators ([>0], [<=100], [<>0]): Replace standard Pos/Neg rules with custom mathematical comparison thresholds.
