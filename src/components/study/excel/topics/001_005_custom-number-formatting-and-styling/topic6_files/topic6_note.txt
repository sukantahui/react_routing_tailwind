Topic: Embedded conditional criteria ([>1000]) and color formatting ([Red], [Green], [ColorN])
Module: 001_005_custom-number-formatting-and-styling
Course: EXCEL-PRO-901: Microsoft Excel From Zero to Ultra Expert
Instructor: Sukanta Hui (Coder & AccoTax)

KEY FORMULA / SYNTAX:
[>1000][Green]#,##0;[<0][Red](#,##0);[Color10]#,##0

PRIMARY CONCEPT:
Square-bracket condition criteria ([>1000], [<=500]) and color tokens ([Red], [Green], [ColorN])

TEACHER'S ADVICE:
Embedded conditional format strings execute at native C++ GPU speed with zero recalculation lag. Use them for high-volume operational dashboards.

COMMON TRAPS TO AVOID:
- Two-Condition Maximum Limit: Excel custom format supports at most 2 explicit bracket conditions plus 1 default fallback. → Fix: If 4 or more conditions are required, use Excel's Conditional Formatting rule manager.
- Unsupported Color Names: Using custom names like [Orange] or [Purple] triggers syntax errors. → Fix: Use standard color names ([Black],[White],[Red],[Green],[Blue],[Yellow],[Magenta],[Cyan]) or [Color1] to [Color56].
- Condition Order Misconfiguration: Placing [>100] before [>500] catches values >500 in the first condition. → Fix: Always arrange conditional thresholds in descending (or mutually exclusive) order.
