5. TROUBLESHOOTING & COMMON ERRORS
• Mixing Up Semicolon Positions:
  Root Cause: Placing color tags or conditions in the wrong section causes syntax errors.
  Diagnostic Fix: Memorize: [Condition][Color]Format;[Condition][Color]Format;ZeroFormat;TextFormat.
• Over-Complicated Format Strings:
  Root Cause: Creating overly complex format strings when conditional formatting or helper columns are cleaner.
  Diagnostic Fix: Use custom format for layout and light conditions; use Power Query or DAX for multi-table ETL.
• Forgetting to Test Edge Cases:
  Root Cause: Testing only positive numbers and failing to test zero, negative, and text input behavior.
  Diagnostic Fix: Always test format strings with +100, -100, 0, and 'N/A' text.

6. PRO TIPS & SHORTCUTS
• Formula-Preserving Rule (Format != Data): Always confirm formulas like =SUM() and =AVERAGE() work on your formatted cells.
• Copy Format Easily (Format Painter (Ctrl+Shift+C / Ctrl+Shift+V)): Quickly replicate complex custom number formats across columns.
• Template Persistence (Save as .xltx): Save custom format palettes in Excel templates for company-wide reusability.
