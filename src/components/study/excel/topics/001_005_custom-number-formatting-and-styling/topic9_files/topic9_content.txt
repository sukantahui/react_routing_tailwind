1. EXECUTIVE OVERVIEW
Phone numbers, Tax IDs (PAN/GSTIN/SSN), and credit card masking patterns is an essential discipline in modern spreadsheet data engineering. 
It establishes the separation between raw data storage and visual UI representation.

2. SYNTAX & TOKEN STRUCTURE
Format Code: +91 ##### ##### | @@@@@0000@ (PAN) | 0000-0000-0000 (Aadhaar) | 0000-****-****-0000

3. CORE TECHNICAL MECHANICS
1. Fixed Digit Block Partitioning:
   Formats raw 10-digit mobile numbers into clean structured blocks (e.g. `+91 ##### #####`) without modifying numeric inputs.

2. Alphanumeric Text Token Masking (@):
   Uses the `@` placeholder to format structured alphanumeric codes like Indian Income Tax PANs and GSTIN tax identifiers.

3. Visual Privacy Masking:
   Renders credit card digits with asterisk masks (`0000-****-****-0000`) for secure client displays.

5. TROUBLESHOOTING & COMMON ERRORS
• Dropping Leading Country Zeros:
  Root Cause: Entering phone numbers as raw numbers drops leading zeros or country codes.
  Diagnostic Fix: Use custom format '+91 ##### #####' or enter as text.
• Alphanumeric Text Token Errors:
  Root Cause: Using numeric 0 placeholders on alphanumeric PAN cards fails because PAN contains letters.
  Diagnostic Fix: Use @ text placeholders or UPPER() functions for mixed alphanumeric codes.
• Formatting vs True Security:
  Root Cause: Formatting hides digits on screen, but the raw number remains in cell memory and formula bar.
  Diagnostic Fix: For true security, hash or truncate values using formulas (=RIGHT(A1,4)).

6. PRO TIPS & SHORTCUTS
• Indian Mobile Format (+91 ##### #####): Clean 10-digit mobile layout with +91 country prefix.
• Standard 4-Digit Groups (0000 0000 0000): Formats 12-digit Aadhaar / identity keys into 3 readable blocks.
• US Phone Format ((###) ###-####): Standard 10-digit North American telephone layout.
