1. EXECUTIVE OVERVIEW
Prompt Engineering for Spreadsheets: Crafting precise instructions for formula generation and data manipulation is an essential discipline in AI-assisted spreadsheet engineering, generative business intelligence, and modern workplace productivity.
It provides the core protocols required to leverage Microsoft Copilot, construct precision prompt workflows, integrate external LLM APIs, and build custom AI formulas.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Prompt Engineering Framework: [Role] + [Context / Table Schema] + [Action / Formula Goal] + [Constraints & Edge Cases] + [Output Format]

3. CORE TECHNICAL MECHANICS
1. The 5-Part Prompt Architecture:
   1. Role (Senior Financial Analyst); 2. Context (Table 'SalesTable'); 3. Goal (Calculate net commission); 4. Constraints (Tiers: 5% if >10L, 8% if >25L, else 2%); 5. Output (Single formula column).

2. Schema Anchoring:
   Always specify exact column header names in brackets (`[Revenue]`, `[Discount]`, `[Tax_Rate]`) to eliminate ambiguity.

3. Constraint Specification:
   Explicitly declare edge-case behaviors: 'If [Margin] is blank, return 0; wrap in IFERROR'.

5. TROUBLESHOOTING & COMMON ERRORS
• Using Generic Prompts ('Calculate profit'):
  Root Cause: Produces generic formulas that fail to account for gross vs net, taxes, discounts, or column names.
  Diagnostic Fix: Specify exact column names and mathematical formulas in prompt.
• Forgetting to Specify Zero/Blank Handling:
  Root Cause: Generated formula dividing by zero and returning `#DIV/0!` across blank rows.
  Diagnostic Fix: Add prompt constraint: 'Handle zero denominators using IF or IFERROR'.
• Mixing Up Multiple Unrelated Tasks in One Prompt:
  Root Cause: Asking AI to clean text, sort table, format colors, and calculate metrics all in one massive prompt.
  Diagnostic Fix: Decompose into sequential single-purpose prompts.

6. PRO TIPS & SHORTCUTS
• Use Bracketed Column Names (Reference [Column_Name] explicitly): Anchors AI directly to exact table fields.
• Specify Error Handling (Add 'wrap in IFERROR returning 0'): Guarantees clean calculated columns with no error flags.
• Iterative Refinement (Reply to AI: 'Adjust tier 2 to 6%'): Fine-tunes calculations conversationally.
