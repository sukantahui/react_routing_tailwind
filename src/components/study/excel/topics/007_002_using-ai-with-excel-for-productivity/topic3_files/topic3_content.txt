5. TROUBLESHOOTING & COMMON ERRORS
• Generated Formula Uses Functions Not Available in User's Excel Build:
  Root Cause: AI writing `=REGEXEXTRACT()` or `=GROUPBY()` for users running older Excel builds that lack those functions.
  Diagnostic Fix: Specify your Excel version or request backward-compatible legacy formulas (`INDEX/MATCH`).
• Regex Pattern Too Restrictive / Permissive:
  Root Cause: Regex failing on valid inputs with slight formatting variations (e.g. spaces or hyphens).
  Diagnostic Fix: Test regex against positive and negative test cases in sample cells.
• Excessive Formula Complexity (Unmaintainable):
  Root Cause: AI generating 500-character unreadable nested IF formulas instead of clean LET blocks.
  Diagnostic Fix: Prompt AI: 'Rewrite this using the LET function with clean variable names'.

6. PRO TIPS & SHORTCUTS
• Ask for LET Function (Prompt: 'Write as a LET formula'): Generates readable, self-documenting, high-performance formulas.
• Regex Generation (Prompt: 'Extract 10-digit PAN using REGEXEXTRACT'): Zero manual regex regex syntax memorization.
• Array Spill Output (Prompt: 'Return as dynamic spilled array'): Builds FILTER/SORT/UNIQUE pipelines instantly.
