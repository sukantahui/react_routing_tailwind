KEY FORMULA / SYNTAX:
Complex Formula Generation: Prompt -> Copilot outputs: =LET(rev, [Revenue], cost, [COGS], margin, (rev-cost)/rev, IF(margin>0.2, rev*0.08, rev*0.03))

PRIMARY CONCEPT:
Leveraging Copilot to synthesize advanced modern Excel formulas: multi-condition LET expressions, dynamic array pipelines (FILTER, SORT, UNIQUE), and modern Regular Expressions (REGEXTEST, REGEXEXTRACT)

TEACHER'S ADVICE:
Never spend an hour writing a giant nested formula again! Just tell Copilot: 'Write a LET formula that calculates discount based on volume, with clean variable names'. It will write a gorgeous, readable formula in 3 seconds.

COMMON TRAPS TO AVOID:
- Generated Formula Uses Functions Not Available in User's Excel Build: AI writing `=REGEXEXTRACT()` or `=GROUPBY()` for users running older Excel builds that lack those functions. -> Fix: Specify your Excel version or request backward-compatible legacy formulas (`INDEX/MATCH`).
- Regex Pattern Too Restrictive / Permissive: Regex failing on valid inputs with slight formatting variations (e.g. spaces or hyphens). -> Fix: Test regex against positive and negative test cases in sample cells.
- Excessive Formula Complexity (Unmaintainable): AI generating 500-character unreadable nested IF formulas instead of clean LET blocks. -> Fix: Prompt AI: 'Rewrite this using the LET function with clean variable names'.
