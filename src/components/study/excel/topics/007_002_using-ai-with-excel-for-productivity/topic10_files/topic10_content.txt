1. EXECUTIVE OVERVIEW
Best practices for debugging and auditing AI-generated formulas and VBA code is an essential discipline in AI-assisted spreadsheet engineering, generative business intelligence, and modern workplace productivity.
It provides the core protocols required to leverage Microsoft Copilot, construct precision prompt workflows, integrate external LLM APIs, and build custom AI formulas.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Auditing Checklist: Formula Bar Inspection (Ctrl+Shift+U) -> Evaluate Formula Tool (Alt+M+V) -> Trace Precedents (Ctrl+[) -> Error Bounds Testing

3. CORE TECHNICAL MECHANICS
1. Formula Decomposition (Evaluate Formula `Alt + M + V`):
   Steps through AI-generated nested formulas step-by-step to verify intermediate evaluation states and catch mathematical errors.

2. Boundary & Edge-Case Stress Testing:
   Injects extreme test values (0, negative numbers, blank cells, text strings, maximum dates) to verify formula resilience.

3. Trace Precedents & Dependents (`Ctrl + [` / `Ctrl + ]`):
   Audits cell relationships visually to ensure AI referenced the correct underlying input cells.

5. TROUBLESHOOTING & COMMON ERRORS
• Assuming Syntactically Valid Code is Mathematically Correct:
  Root Cause: A formula can calculate without errors (`#VALUE!`) while producing completely incorrect business numbers due to flawed operator precedence.
  Diagnostic Fix: Verify calculated results manually against known test cases.
• Failing to Check Formula Absolute/Relative Locks ($A$1 vs A1):
  Root Cause: AI omitting dollar signs on lookup tables, causing formulas to break when copied down the column.
  Diagnostic Fix: Verify range locking: `$A$1:$D$100` on reference tables.
• Accepting Hallucinated VBA Methods:
  Root Cause: AI generating non-existent VBA methods like `Range("A1").SortAlphabetical()`.
  Diagnostic Fix: Compile code in VBE (Debug > Compile VBAProject) to verify syntax.

6. PRO TIPS & SHORTCUTS
• Evaluate Formula Tool (Alt + M + V): Steps through formula evaluation step-by-step.
• Trace Precedents (Ctrl + [): Jumps directly to underlying precedent input cells.
• Compile VBA Project (Debug > Compile VBAProject (in VBE)): Catches hallucinated methods before running macros.
