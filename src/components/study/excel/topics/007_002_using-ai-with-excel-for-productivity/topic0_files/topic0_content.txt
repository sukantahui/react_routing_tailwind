5. TROUBLESHOOTING & COMMON ERRORS
• Using Copilot on Flat Unformatted Cell Ranges (Fails):
  Root Cause: Microsoft Copilot in Excel requires data to be formatted as an official structured Excel Table (`Ctrl + T`).
  Diagnostic Fix: Always convert flat data to an official Excel Table before launching Copilot.
• Blindly Trusting AI Calculations Without Verification (Hallucination):
  Root Cause: LLMs can hallucinate non-existent formulas or misinterpret edge-case business logic.
  Diagnostic Fix: Always inspect and audit the underlying formula generated by AI before signing off.
• Vague / Ambiguous Prompts:
  Root Cause: Prompting 'Fix my data' produces generic or incorrect transformations.
  Diagnostic Fix: Use precise prompt engineering: declare inputs, operations, constraints, and expected output formats.

6. PRO TIPS & SHORTCUTS
• Convert to Table First (Ctrl + T (Mandatory for Copilot)): Enables Copilot to understand schema and column names.
• Launch Copilot Pane (Home > Copilot (or ribbon button)): Opens the interactive AI chat sidebar.
• Audit Generated Formulas (Click 'Insert Column' & check formula bar): Inspects underlying logic before adopting.
