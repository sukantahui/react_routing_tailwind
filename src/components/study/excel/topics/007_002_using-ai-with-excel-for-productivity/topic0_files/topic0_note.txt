PRIMARY CONCEPT:
Understanding Generative AI and Large Language Model (LLM) integration in Microsoft Excel: Microsoft 365 Copilot architecture, GPT-4 reasoning, cognitive formula generation, and spreadsheet productivity multipliers

TEACHER'S ADVICE:
AI in Excel is like having a junior data analyst sitting next to you 24/7. Always format your data as a Table first (`Ctrl + T`), ask clear questions, and ALWAYS check the formula it writes!

COMMON TRAPS TO AVOID:
- Using Copilot on Flat Unformatted Cell Ranges (Fails): Microsoft Copilot in Excel requires data to be formatted as an official structured Excel Table (`Ctrl + T`). → Fix: Always convert flat data to an official Excel Table before launching Copilot.
- Blindly Trusting AI Calculations Without Verification (Hallucination): LLMs can hallucinate non-existent formulas or misinterpret edge-case business logic. → Fix: Always inspect and audit the underlying formula generated by AI before signing off.
- Vague / Ambiguous Prompts: Prompting 'Fix my data' produces generic or incorrect transformations. → Fix: Use precise prompt engineering: declare inputs, operations, constraints, and expected output formats.
