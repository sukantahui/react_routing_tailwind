5. TROUBLESHOOTING & COMMON ERRORS
• Inconsistent Sentiment Labeling Across Rows:
  Root Cause: AI returning 'Positive', 'Pos', 'Great', 'Good' instead of standardized category names.
  Diagnostic Fix: Constrain AI prompt: 'Return ONLY one of: [Positive, Neutral, Negative]'.
• High Latency on Massive Review Ingestion:
  Root Cause: Calling cloud LLMs on 50,000 rows without caching or batching.
  Diagnostic Fix: Use Power Query batch processing or local in-memory Dictionary caching.
• Biased Sentiment Interpretation on Sarcasm:
  Root Cause: AI misinterpreting sarcastic customer reviews as positive.
  Diagnostic Fix: Include few-shot examples in system prompt to teach sarcasm detection.

6. PRO TIPS & SHORTCUTS
• Standardized Labels (Positive | Neutral | Negative): Enables seamless Pivot Table aggregation.
• Net Sentiment Score (NSS) (% Positive - % Negative): The gold-standard executive sentiment metric.
• 1-Click Summary Prompt (Prompt: 'Summarize top 3 pain points'): Generates instant executive briefing notes.
