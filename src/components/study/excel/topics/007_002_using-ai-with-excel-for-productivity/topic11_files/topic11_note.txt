COMMON TRAPS TO AVOID:
- Inconsistent Sentiment Labeling Across Rows: AI returning 'Positive', 'Pos', 'Great', 'Good' instead of standardized category names. -> Fix: Constrain AI prompt: 'Return ONLY one of: [Positive, Neutral, Negative]'.
- High Latency on Massive Review Ingestion: Calling cloud LLMs on 50,000 rows without caching or batching. -> Fix: Use Power Query batch processing or local in-memory Dictionary caching.
- Biased Sentiment Interpretation on Sarcasm: AI misinterpreting sarcastic customer reviews as positive. -> Fix: Include few-shot examples in system prompt to teach sarcasm detection.
