1. EXECUTIVE OVERVIEW
AI-assisted data cleaning: Extracting entities, standardizing messy text, and pattern recognition is an essential discipline in AI-assisted spreadsheet engineering, generative business intelligence, and modern workplace productivity.
It provides the core protocols required to leverage Microsoft Copilot, construct precision prompt workflows, integrate external LLM APIs, and build custom AI formulas.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Data Cleaning Prompts: 'Extract the 6-digit PIN code from column Address' | 'Standardize customer names to Proper Case and remove extra spaces' | 'Split column Full_Name into First and Last'

3. CORE TECHNICAL MECHANICS

   Extracts addresses, dates, tracking numbers, and invoice IDs from messy, unstructured freehand text strings.

2. Text Standardization & Normalization:

3. Pattern Learning & Flash Fill Acceleration:

5. TROUBLESHOOTING & COMMON ERRORS
• Edge-Case Pattern Inconsistencies (Missing PIN Codes):
  Root Cause: AI entity extraction failing on rows where addresses lack PIN codes.
  Diagnostic Fix: Include prompt condition: 'If PIN code is missing, return blank; wrap in IFERROR'.
• Over-Aggressive Text Replacement:
  Root Cause: Standardizing 'St.' to 'Street' accidentally converting 'St. Xavier's' to 'Street Xavier's'.
  Diagnostic Fix: Inspect cleaned results across positive and negative sample cases.
• Slow Execution When Calling Cloud AI on 1 Million Rows:
  Root Cause: Calling cloud LLMs row-by-row on massive datasets.
  Diagnostic Fix: Have AI generate a single vectorized Excel formula (`REGEXEXTRACT` / `TEXTSPLIT`) that runs instantly on client.

6. PRO TIPS & SHORTCUTS
• Extract Formula Standard (Prompt: 'Write an Excel formula to extract...'): Generates reusable formulas that run instantly.
• Pattern Examples (Provide 2 before/after examples in prompt): Dramatically improves extraction accuracy.
• Proper Case Standard (Prompt: 'Format as Proper Case with single spaces'): Instantly cleans messy human data entry.
