5. TROUBLESHOOTING & COMMON ERRORS
• Exposing Production API Keys in Plaintext M-Code / VBA:
  Root Cause: Hardcoding `Bearer sk-proj-12345` inside Power Query formulas or VBA code.
  Diagnostic Fix: Store API keys in environment variables, secure SharePoint parameter tables, or Azure Key Vault.
• API Rate Limit Exhaustion (HTTP 429 Too Many Requests):
  Root Cause: Sending 10,000 individual row requests simultaneously in Power Query without throttling.
  Diagnostic Fix: Batch requests into chunks of 50 or use asynchronous queue endpoints.
• High API Token Costs on Massive Datasets:
  Root Cause: Using expensive frontier models (GPT-4o) with giant system prompts on 100,000 rows.
  Diagnostic Fix: Use lightweight cost-effective models (e.g. `gpt-4o-mini` or `claude-3-haiku`) with concise prompts.

6. PRO TIPS & SHORTCUTS
• Use Lightweight Models (gpt-4o-mini or claude-3-haiku): 98% cheaper with sub-second response times.
• Enforce JSON Mode (response_format: { type: "json_object" }): Guarantees reliable structured JSON output for easy Excel parsing.
• Low Temperature for Determinism (temperature: 0.0): Ensures consistent, repeatable categorical classifications.
