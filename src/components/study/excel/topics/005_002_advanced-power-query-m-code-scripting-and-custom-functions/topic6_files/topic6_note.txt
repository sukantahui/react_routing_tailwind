1. REST API ARCHITECTURE IN M:
--------------------------------------------------------------------------------
• Static Base URL with Dynamic RelativePath & Query:
  = Web.Contents(
      "https://api.exchangerate.host",
      [
        RelativePath = "v1/latest",
        Query = [base = "USD", symbols = "INR,EUR,GBP"],
        Headers = [#"Accept" = "application/json"],
        ManualStatusHandling = {400, 404, 500}
      ]
    )

• JSON Deserialization:
  - Object `{...}` → M Record `[...]`
  - Array `[...]` → M List `{...}`
  - Parse: `Json.Document(BinaryResponse)`

2. BEST PRACTICES & PRODUCTION PATTERNS:
--------------------------------------------------------------------------------
• Never concatenate query params into the main URL string (breaks Power BI Service refresh!).
• Use `Binary.Buffer(Web.Contents(...))` to cache API payloads and avoid duplicate HTTP calls.
• For JavaScript heavy SPAs, inspect DevTools Network tab to query the raw JSON API directly.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Always separate `RelativePath` and `Query` to satisfy Power BI Service credential validation!
• Use `ManualStatusHandling` to catch 404s and 500s without crashing entire scheduled refreshes.
• Relate dynamic FX API rate tables directly in Power Pivot for multi-currency automated models.
