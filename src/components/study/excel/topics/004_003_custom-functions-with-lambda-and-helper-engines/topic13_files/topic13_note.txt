1. WHAT IS A CORPORATE LAMBDA LIBRARY?
--------------------------------------------------------------------------------
• A standardized repository of audited, reusable custom functions.
• Replaces thousands of fragile ad-hoc formulas across corporate workbooks.
• Structured with domain prefixes: FX_FIN_, FX_TAX_, FX_HR_, FX_STR_.

2. KEY ARCHITECTURAL PILLARS:
• Advanced Formula Environment (AFE): Microsoft Garage tool for plain-text editing.
• Git Version Control: Track changes to corporate function modules in text files.
• IntelliSense Documentation: Embed parameter comments in Name Manager.
• Pure Function Principle: Zero hard-coded cell references (operate only on inputs).

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Always register corporate functions with Workbook Scope (never Worksheet Scope).
• Use semantic versioning (v1.0.0 → v1.1.0) and deprecate legacy signatures gracefully.
• Distribute via Master Template workbooks (.xltx) or corporate Excel Add-ins (.xlam).
