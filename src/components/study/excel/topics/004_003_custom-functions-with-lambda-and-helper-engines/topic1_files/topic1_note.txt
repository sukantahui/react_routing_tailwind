1. FORMULA SYNTAX & IMMEDIATE EXECUTION
--------------------------------------------------------------------------------
Syntax: =LAMBDA([param1, param2, ...], calculation)

Immediate Execution Syntax in a Worksheet Cell:
  =(LAMBDA(price, qty, price * qty * 1.18))(1500, 4) &rarr; Returns 7080

2. WHY IMMEDIATE EXECUTION IS ESSENTIAL
--------------------------------------------------------------------------------
• Bare LAMBDAs without arguments return #CALC! in worksheet cells.
• Trailing parentheses `(arg1, arg2, ...)` pass test inputs positionally in-place.
• Enables sandbox testing of complex logic on real data before Name Manager registration.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Parameters cannot contain spaces, match cell references (A1, C2), or match
  native Excel function names (SUM, MAX).
• Combine with LET inside the calculation block to optimize heavy formulas.
• Highlight formula in the formula bar and press F9 to evaluate in memory.
