1. WHAT IS THE MAP HELPER FUNCTION?
--------------------------------------------------------------------------------
Syntax: =MAP(array1, [array2, ...], lambda)

Core Mechanics:
• Iterates element-by-element across one or more parallel arrays.
• LAMBDA parameter count MUST match the number of input arrays.
• Output matrix has the exact same dimensions (rows x columns) as input arrays.

2. WHY MAP IS CRITICAL IN EXCEL 365
--------------------------------------------------------------------------------
• Vectorizes functions that otherwise collapse ranges (e.g. AND, OR, TEXTJOIN).
• Eliminates manual formula dragging down thousands of rows.
• Pairs parallel data columns (e.g. Days + Performance Score &rarr; Bonus Tier).

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• All arrays passed to MAP must have IDENTICAL dimensions (same rows and cols).
• Each MAP iteration must return a SINGLE scalar value (not nested arrays).
• Combine with LET inside the LAMBDA for complex multi-stage row calculations!
