1. WHAT IS THE SCAN HELPER FUNCTION?
--------------------------------------------------------------------------------
Syntax: =SCAN([initial_value], array, lambda)

Core Mechanics:
• Slices an array element-by-element, maintaining a running accumulator state.
• LAMBDA must declare strictly 2 parameters: LAMBDA(accumulator, value).
• Returns an array with identical dimensions containing all progressive step states.

2. WHY SCAN IS REVOLUTIONARY FOR SPREADSHEET PERFORMANCE
--------------------------------------------------------------------------------
• Replaces legacy dragged =SUM($D$5:D5) formulas.
• Linear O(N) execution complexity vs. legacy Quadratic O(N^2) complexity.
• In 100,000 rows: SCAN runs in ~15ms; legacy formulas take ~45 seconds!

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Always pass an explicit initial value (e.g. 0 or opening ledger balance).
• Use IFERROR inside the LAMBDA to prevent downstream error cascading.
• Combine with HSTACK to join the running balance directly to transaction ledgers!
