1. THE ROLE OF DOCUMENTATION IN PRODUCTION LAMBDAS
--------------------------------------------------------------------------------
Excel allows model authors to write descriptive guidance in the 'Comment' box
of Name Manager (Ctrl+F3). This text is displayed in Excel's autocomplete tooltip.

2. DOCUMENTATION BEST PRACTICES
--------------------------------------------------------------------------------
• Descriptive Parameter Identifiers: Use `taxable_value` and `gst_rate_pct`
  instead of ambiguous single letters `x` or `y`.
• Structured Comment Format:
  [Function Summary] - Params: [param: desc] - Returns: [return structure].
• Clarify Spilled Footprints: If returning HSTACK or VSTACK, specify:
  "Spills 4 columns: [Taxable, CGST, SGST, Total]".
• Document Default Fallbacks: Indicate default values for optional parameters.

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Never deploy an undocumented function in enterprise workbooks.
• Test your documentation by typing `=FX_` in an empty cell to ensure tooltips
  are clean and readable for junior staff members.
