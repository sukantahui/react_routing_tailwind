1. EXECUTIVE OVERVIEW
Generating automated Teams/Slack notifications and PDF reports from Excel via Power Automate is an essential discipline in cloud spreadsheet automation, serverless enterprise workflows, and TypeScript-driven business intelligence.
It provides the core protocols required to author cross-platform scripts, connect Excel to Microsoft Power Automate, and construct 24/7 autonomous cloud pipelines.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Notifications & PDF: Run Script (Calculate KPI & Generate Summary) → Create File (SharePoint .pdf) → Post message in a chat or channel (Teams / Slack) → Send Email (Outlook)

5. TROUBLESHOOTING & COMMON ERRORS
• Spamming Teams Channels with Every Single Row Entry:
  Root Cause: Posting a Teams message for every individual transaction in a 5,000-row batch.
  Diagnostic Fix: Aggregate metrics into a single summary payload and post ONE consolidated notification.
• Invalid Adaptive Card JSON Syntax:
  Root Cause: Malformed JSON structure in Adaptive Card payload breaking Teams message delivery.
  Diagnostic Fix: Use the Microsoft Adaptive Card Designer (`adaptivecards.io`) to validate payload JSON.
• Converting Unformatted Excel Sheets to PDF:
  Root Cause: Converting sheets without print area setup resulting in truncated PDF pages.
  Diagnostic Fix: Configure print titles and page scaling via Office Scripts prior to cloud PDF conversion.
