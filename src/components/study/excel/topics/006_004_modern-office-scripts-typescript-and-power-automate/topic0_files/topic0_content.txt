5. TROUBLESHOOTING & COMMON ERRORS
• Expecting VBA Methods (e.g. MsgBox, Application.ScreenUpdating):
  Root Cause: Office Scripts runs in a sandboxed cloud browser environment where desktop VBA UI popups do not exist.
  Diagnostic Fix: Use `console.log()` for debugging and return status values to Power Automate.
• Missing Microsoft 365 Commercial / Enterprise License:
  Root Cause: Office Scripts requires Microsoft 365 Business Standard, E3, or E5 license; not available on personal/family accounts.
  Diagnostic Fix: Ensure your corporate M365 account has Office Scripts enabled by IT tenant admin.
• Attempting File System Access (C:\ Drive):
  Root Cause: Cloud scripts cannot access local C:\ drives directly.
  Diagnostic Fix: Store files in OneDrive or SharePoint and access via Power Automate.
