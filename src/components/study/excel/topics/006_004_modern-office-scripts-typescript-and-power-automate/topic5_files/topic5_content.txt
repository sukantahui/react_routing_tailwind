1. EXECUTIVE OVERVIEW
Reading, writing, and formatting ranges with Office Scripts is an essential discipline in cloud spreadsheet automation, serverless enterprise workflows, and TypeScript-driven business intelligence.
It provides the core protocols required to author cross-platform scripts, connect Excel to Microsoft Power Automate, and construct 24/7 autonomous cloud pipelines.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Range Operations: const values = range.getValues(); range.setValues(newValues); range.getFormat().getFill().setColor("#0284c7"); range.getFormat().autofitColumns();

3. CORE TECHNICAL MECHANICS
1. Atomic 2D Batch Reading & Writing:
   Reads thousands of cells in 1 shot (`range.getValues()`), transforms in memory, and writes back in 1 shot (`range.setValues()`), delivering maximum cloud speed.

2. Dynamic Table Boundary Detection:
   `range.getUsedRange()` or `range.getSurroundingRegion()` automatically detects the active data boundaries without hardcoding row counts.

3. Professional Styling & Number Formats:
   Applies currency formats (`range.setNumberFormat("₹#,##0.00")`), hex background fills (`#0284c7`), and white bold fonts in clean chained calls.

5. TROUBLESHOOTING & COMMON ERRORS
• Dimensions Mismatch Between Array and Range (Fatal Error):
  Root Cause: Trying to write a 5x2 array into a 10x2 range throws runtime error.
  Diagnostic Fix: Size the target range dynamically using array dimensions: `ws.getRangeByIndexes(0, 0, arr.length, arr[0].length).setValues(arr)`.
• Writing Cell-by-Cell in a Loop (Cloud Latency):
  Root Cause: Calling `range.setValue()` 1,000 times across network round-trips makes cloud scripts crawl.
  Diagnostic Fix: Always read all data into a 2D array, modify in RAM, and call `setValues()` once.
• Invalid Hex Color String Format:
  Root Cause: Passing invalid color like `"blue-dark"` instead of `#0284c7` throws format error.
  Diagnostic Fix: Use standard 6-digit hex color strings (`#0284c7`).

6. PRO TIPS & SHORTCUTS
• Dynamic Target Range (ws.getRangeByIndexes(row, col, numRows, numCols)): Creates exact-sized target range for 2D array dumps.
• AutoFit Columns (range.getFormat().autofitColumns()): Eliminates ### column width truncation.
• Single Batch Write (range.setValues(dataArray)): 50x faster than cell-by-cell writing.
