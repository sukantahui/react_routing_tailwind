5. TROUBLESHOOTING & COMMON ERRORS
• Posting Expenses Before Manager Approval:
  Root Cause: Appending unapproved expenses directly to the finalized general ledger table.
  Diagnostic Fix: Post to a `Staging_Pending` table first; move to `Approved_Ledger` only after approval.
• Handling Duplicate Submissions on Refresh:
  Root Cause: User refreshing browser submitting duplicate expense entries.
  Diagnostic Fix: Check for duplicate submission IDs in the script before appending.
• Unchecked Currency Conversion on Multi-Currency Expenses:
  Root Cause: Mixing USD and INR amounts in the same numerical column without conversion.
  Diagnostic Fix: Include currency normalization in the TypeScript calculation logic.

6. PRO TIPS & SHORTCUTS
• Full-Stack Serverless (Forms + Power Automate + Office Scripts + Teams): The ultimate modern enterprise software architecture.
• Unique Transaction ID (`EXP-${Date.now()}`): Guarantees unique audit identification for every transaction.
• Interactive Approval Buttons (Power Automate Approvals Connector): Allows managers to approve directly from Outlook or Teams.
