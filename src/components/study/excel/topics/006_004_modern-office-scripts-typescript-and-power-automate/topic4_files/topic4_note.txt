TEACHER'S ADVICE:
Watch out for coordinate indexing! In VBA, `Cells(1,1)` is cell A1. But in Office Scripts (TypeScript), `ws.getCell(0,0)` is cell A1 because TypeScript uses 0-based indexing!

COMMON TRAPS TO AVOID:
- Calling getWorksheet with Non-Existent Tab Name: Calling `workbook.getWorksheet("Missing")` returns `undefined`, throwing error on next method call. → Fix: Verify worksheet exists: `const ws = workbook.getWorksheet("Data"); if (!ws) throw new Error("Sheet not found");`.
- Confusing getValues() with getText(): `getValues()` returns typed numbers/strings; `getTexts()` returns formatted display text (e.g. "$ 10.00"). → Fix: Use `getValues()` for calculations; use `getTexts()` for display string parsing.
- Attempting to Call Non-Existent VBA Methods: Calling `ws.Cells(1,1)` instead of `ws.getCell(0,0)` (Office Scripts uses 0-based coordinate indexing). → Fix: Use `ws.getCell(rowIndex, colIndex)` where (0,0) is cell A1.
