1. EXECUTIVE OVERVIEW
Creating, modifying, and auto-sorting Excel Tables and Pivot Tables via script is an essential discipline in cloud spreadsheet automation, serverless enterprise workflows, and TypeScript-driven business intelligence.
It provides the core protocols required to author cross-platform scripts, connect Excel to Microsoft Power Automate, and construct 24/7 autonomous cloud pipelines.

2. SYNTAX & TOKEN STRUCTURE
Operational Architecture: Table Automation: const table = ws.addTable("A1:E100", true); table.setName("SalesTable"); table.getSort().apply([{key: 2, ascending: false}]);

3. CORE TECHNICAL MECHANICS
1. Programmatic Table Conversion (`addTable`):
   Converts flat cell ranges into structured Excel Tables with built-in banding, filtering, and total row aggregations in 1 line.

2. Multi-Column Sorting Engine:
   `table.getSort().apply([{key: 0, ascending: true}, {key: 2, ascending: false}])`. Sorts large cloud datasets across multiple columns with zero UI lag.

3. Dynamic Pivot Table Construction:
   `workbook.addPivotTable(name, source, destination)` builds interactive summary pivot tables on dedicated reporting tabs.

5. TROUBLESHOOTING & COMMON ERRORS
• Adding Table Over Existing Table (Name Collision):
  Root Cause: Calling `addTable()` on a range that already contains an Excel Table throws runtime error.
  Diagnostic Fix: Check if table exists first, or clear existing tables before adding.
• 0-Based Column Key Confusion in Sorting:
  Root Cause: Passing `{key: 1}` when intending to sort by Column A (Column A is `key: 0`).
  Diagnostic Fix: Remember table column keys are 0-based (`key: 0` = first column).
• Adding Pivot Table on Occupied Cell Range:
  Root Cause: Creating a pivot table over existing cells causes collision errors.
  Diagnostic Fix: Create pivot tables on dedicated clean summary worksheets.

6. PRO TIPS & SHORTCUTS
• Add Table in 1 Line (const table = ws.addTable("A1:D50", true);): Converts range to official Excel Table.
• Enable Total Row (table.setShowTotals(true);): Calculates column totals automatically.
• Multi-Key Sort (table.getSort().apply([{key: 0, ascending: true}]);): Applies sorting across table columns.
