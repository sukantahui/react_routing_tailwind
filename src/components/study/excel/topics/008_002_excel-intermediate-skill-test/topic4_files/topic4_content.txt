5. TROUBLESHOOTING & COMMON ERRORS
• Pivot Table Slicers Not Filtering All Dashboard Tables:
  Root Cause: Forgetting to configure Report Connections on the Slicer.
  Diagnostic Fix: Right-click Slicer > Report Connections > check all Pivot Tables on dashboard.
• Blank Rows in Source Data Causing '(blank)' Grouping:
  Root Cause: Selecting empty rows below table when creating Pivot Table.
  Diagnostic Fix: Create Pivot Table from an official structured Excel Table (`tblSales`).
• Forgetting That Pivot Tables Do Not Auto-Refresh:
  Root Cause: Editing source numbers and wondering why Pivot Table numbers did not update.
  Diagnostic Fix: Right-click Pivot Table > Refresh (or press `Alt + F5`).

6. PRO TIPS & SHORTCUTS
• Report Connections (Right-click Slicer > Report Connections): Connects 1 Slicer to all Pivot Tables on sheet.
• Date Grouping (Right-click date > Group > Years/Quarters/Months): Instantly aggregates raw dates into calendar hierarchies.
• Show Values As % (Value Field Settings > Show Values As > % of Total): Generates instant percentage share metrics.
