1. WHAT IS SEMI-STRUCTURED DATA PARSING?
--------------------------------------------------------------------------------
Decomposing non-tabular strings (server logs, invoice narratives, ERP pipe-dumps) 
into structured relational columns using modern Excel 365 string intelligence.

2. CORE FORMULA ENGINES:
--------------------------------------------------------------------------------
• 5-Token Log Decomposition (Mode 2 Capturing Groups):
  =REGEXEXTRACT(A2, "^\[([^\]]+)\]\s+\[([^\]]+)\]\s+\[User:\s*([^\]]+)\]\s+\[IP:\s*([^\]]+)\]\s+(.+)$", 2)

• 2D Key-Value Parsing:
  =TEXTSPLIT(A2, ": ", " | ")

• Multi-Field Entity Extraction:
  =HSTACK(REGEXEXTRACT(A2, "[A-Z]{5}\d{4}[A-Z]"), REGEXEXTRACT(A2, "\b[6-9]\d{9}\b"))

• Lookbehind Key-Value Isolator:
  =REGEXEXTRACT(A2, "(?<=INV_NO=)[A-Z0-9-]+")

3. CLASSROOM RULES & ADVICE FROM SUKANTA HUI
--------------------------------------------------------------------------------
• Discard legacy Text-to-Columns wizard—it destroys dynamic formula linkage!
• Use REGEXEXTRACT mode 2 to spill multi-token log rows in 1 single formula.
• Combine REDUCE + VSTACK for high-speed multi-row parsing across 10,000 log lines.
