Topic: Modern multi-condition evaluation with the IFS function
Module: 002_003_conditional-logic-with-if-and-related-functions
Course: EXCEL-PRO-901: Microsoft Excel From Zero to Ultra Expert
Instructor: Sukanta Hui (Coder & AccoTax)

KEY FORMULA / SYNTAX:
=IFS(logical_test1, value_if_true1, [logical_test2, value_if_true2], ..., [TRUE, default_value])

PRIMARY CONCEPT:
Eliminating cumbersome nested IF parentheses using the modern IFS function with sequential condition-value pairing and default TRUE fallbacks

TEACHER'S ADVICE:
The IFS function was introduced in Excel 2019/365 to kill ugly nested IF parentheses. Always remember to put TRUE as your final condition to serve as the default fallback.

COMMON TRAPS TO AVOID:
- Missing Final TRUE Fallback (#N/A Error): If none of the condition pairs evaluate to TRUE and no default pair exists, IFS returns #N/A. -> Fix: Always end your IFS formula with the catch-all pair: `TRUE, "Default_Value"`.
- Odd Number of Arguments Error: Supplying an unpaired condition or result triggers an invalid formula parameter error. -> Fix: Ensure the total number of arguments passed to IFS is always an even number.
- Performance on 50+ Pairs: Using IFS for massive 50-item lists slows calculation and creates unwieldy formulas. -> Fix: Use XLOOKUP against a dedicated two-column configuration table for large mapping lists.
