================================================================================
Topic: Combining logical functions with SUM, AVERAGE, and LOOKUP functions
Module: 002_003_conditional-logic-with-if-and-related-functions
Course: EXCEL-PRO-901: Microsoft Excel From Zero to Ultra Expert
Instructor: Sukanta Hui (Coder & AccoTax)

KEY FORMULA / SYNTAX:
=SUMIFS(sum_range, crit_range1, crit1, ...) | =AVERAGEIFS(...) | =XLOOKUP(1, (CritRange1=Crit1)*(CritRange2=Crit2), ReturnRange)

PRIMARY CONCEPT:
Combining logical criteria with mathematical aggregations (SUMIFS, AVERAGEIFS, COUNTIFS) and complex multi-condition lookup functions

TEACHER'S ADVICE:
Standardize on SUMIFS, COUNTIFS, and AVERAGEIFS across all corporate models. Never use the obsolete single-condition SUMIF function.

COMMON TRAPS TO AVOID:
- SUMIF vs SUMIFS Argument Order Inversion: Legacy SUMIF puts sum_range LAST: SUMIF(crit_range, crit, sum_range). Modern SUMIFS puts sum_range FIRST: SUMIFS(sum_range, crit_range1, crit1). -> Fix: Always use modern SUMIFS and place sum_range as the very first argument.
- Quoting Comparison Operators in IFS: Writing =SUMIFS(A2:A100, B2:B100, >100) triggers syntax errors because >100 must be a string. -> Fix: Enclose operators in quotes: =SUMIFS(A2:A100, B2:B100, ">100").
- Concatenating Cell References with Operators: Writing ">B1" treats 'B1' as literal text rather than evaluating the value inside cell B1. -> Fix: Concatenate cell references: `">" & B1`.
