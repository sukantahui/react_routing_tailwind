1. EXECUTIVE OVERVIEW
Mastering Nested IF formulas and avoiding deeply nested formula pitfalls is an essential discipline in modern financial modeling and automated decision support.
It provides the core formulas required to evaluate complex business rules and multi-tier criteria.

2. SYNTAX & TOKEN STRUCTURE
Formula Code: =IF(cond1, val1, IF(cond2, val2, IF(cond3, val3, default_val)))

3. CORE TECHNICAL MECHANICS
1. Sequential Waterfall Evaluation:
   Excel evaluates nested IF statements from left to right. The first condition that evaluates to TRUE terminates execution, ignoring subsequent branches.

2. Strict-to-General Ordering Principle:
   Thresholds must be arranged in descending order (e.g. >=90, >=80, >=70) or ascending order (<=50, <=70, <=90) to prevent premature branch termination.

3. Parenthesis Stacking & 64-Level Limit:
   Excel allows up to 64 nested IF levels, though best practices discourage exceeding 3-4 levels in favor of IFS, SWITCH, or XLOOKUP.

5. TROUBLESHOOTING & COMMON ERRORS
• Incorrect Condition Sequence:
  Root Cause: Testing >=70 before >=90 causes an exam score of 95 to trigger the 'Grade C' branch and terminate early.
  Diagnostic Fix: Always arrange descending thresholds from highest to lowest: >=90, >=80, >=70, >=60.
• Unmatched Closing Parentheses:
  Root Cause: Failing to supply all required closing parentheses at the end of the formula causes syntax errors.
  Diagnostic Fix: Match the number of closing parentheses to the count of open IF statements.
• Deeply Nested Maintenance Nightmare:
  Root Cause: Nesting 10+ IF statements creates fragile, unreadable formulas that break during audit reviews.
  Diagnostic Fix: Replace deep nested IFs with XLOOKUP approximate match (search_mode 1) or IFS.

6. PRO TIPS & SHORTCUTS
• Alt + Enter Line Breaks (Alt + Enter in Formula Bar): Break nested IF branches into formatted multi-line code for crystal-clear readability.
• Descending Threshold Rule (>=90, >=80, >=70...): The universal rule for foolproof multi-tier numeric classifications.
• Color-Coded Parentheses (Excel UI Indicator): Excel highlights matching parentheses in distinct colors; ensure the final parenthesis is black.
