TOPIC 3 QUICK SUMMARY & INSTRUCTOR REFERENCE
================================================================================
Topic: Mastering Nested IF formulas and avoiding deeply nested formula pitfalls
Module: 002_003_conditional-logic-with-if-and-related-functions
Course: EXCEL-PRO-901: Microsoft Excel From Zero to Ultra Expert
Instructor: Sukanta Hui (Coder & AccoTax)

KEY FORMULA / SYNTAX:
=IF(cond1, val1, IF(cond2, val2, IF(cond3, val3, default_val)))

PRIMARY CONCEPT:
Building hierarchical multi-tier decision trees with nested IF formulas, optimizing evaluation order from strictest to most general

TEACHER'S ADVICE:
Whenever you write a nested IF, format it with Alt + Enter in the formula bar like real programming code! It makes your logic readable and impresses technical audit teams.

COMMON TRAPS TO AVOID:
- Incorrect Condition Sequence: Testing >=70 before >=90 causes an exam score of 95 to trigger the 'Grade C' branch and terminate early. → Fix: Always arrange descending thresholds from highest to lowest: >=90, >=80, >=70, >=60.
- Unmatched Closing Parentheses: Failing to supply all required closing parentheses at the end of the formula causes syntax errors. → Fix: Match the number of closing parentheses to the count of open IF statements.
- Deeply Nested Maintenance Nightmare: Nesting 10+ IF statements creates fragile, unreadable formulas that break during audit reviews. → Fix: Replace deep nested IFs with XLOOKUP approximate match (search_mode 1) or IFS.
