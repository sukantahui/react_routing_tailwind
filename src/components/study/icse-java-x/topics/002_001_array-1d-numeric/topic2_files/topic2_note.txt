1. CONCEPT OVERVIEW
----------------------------------------------------------------------
In Java, arrays are true objects created dynamically on the JVM heap using the 'new' keyword. The expression 'new int[n]' asks the memory allocator to reserve contiguous space for n integers and returns the starting memory reference.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Keyword 'new': Allocates heap memory for the array object and zeros all elements.
[2] Dynamic Size: The size passed inside brackets can be an expression, variable, or literal evaluated at runtime.
[3] Non-negative Size: Passing a negative integer size throws NegativeArraySizeException at runtime.
[4] Zero-Length Arrays: An array of size 0 ('new int[0]') is valid in Java and has length 0.
[5] Garbage Collection: When no references point to an array object, it becomes eligible for automatic garbage collection.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Supplying negative size variables resulting in NegativeArraySizeException.
[!] Pitfall 2: Re-instantiating an array with 'new' believing it resizes the original; it creates a brand new object losing previous contents.
[!] Pitfall 3: Running out of heap memory when creating excessively large arrays (OutOfMemoryError).
