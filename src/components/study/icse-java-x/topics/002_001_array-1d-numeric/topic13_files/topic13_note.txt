1. CONCEPT OVERVIEW & ALGORITHM OBJECTIVE
----------------------------------------------------------------------
Descending selection sort identifies the index of the maximum element in the unsorted subarray and places it at index i. With each pass, the next largest number is locked into its correct position at the front.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Maximum Index Tracking: Assume max_idx = i; search j = i + 1 to n - 1 for arr[j] > arr[max_idx].
[2] Pass Progression: First pass places largest at index 0; second pass places 2nd largest at index 1.
[3] Swap Efficiency: Swaps at most n - 1 times throughout the entire sorting process.
[4] Independent of Initial Order: Selection sort always makes the same number of comparisons regardless of initial order.
[5] Clean ICSE Implementation: Preferred in ICSE board exams for its clean, deterministic structure.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Using '<' instead of '>' in comparison condition, producing ascending rather than descending order.
[!] Pitfall 2: Starting inner loop from j = i instead of j = i + 1, doing a redundant self-comparison.
[!] Pitfall 3: Swapping arr[max_idx] with arr[j] instead of arr[i].
