1. CONCEPT OVERVIEW & ALGORITHM OBJECTIVE
----------------------------------------------------------------------
Bubble sort repeatedly steps through the array, compares adjacent elements, and swaps them if they are in the wrong order (arr[j] > arr[j+1]). After each complete outer pass, the largest remaining element bubbles to its final rightmost position.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Adjacent Swapping: Compare arr[j] with arr[j+1]; swap if arr[j] > arr[j+1] for ascending order.
[2] Outer Loop Bounds: Runs (n - 1) passes from i = 0 to i < n - 1.
[3] Inner Loop Optimization: Runs from j = 0 to j < n - 1 - i to skip already sorted end elements.
[4] Temporary Variable Swap: Swap requires a temporary variable: int temp = arr[j]; arr[j] = arr[j+1]; arr[j+1] = temp;.
[5] Quadratic Complexity: Performs O(n^2) comparisons in average and worst cases.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Inner loop bound error (j < n instead of j < n - 1 - i) causing ArrayIndexOutOfBoundsException when checking arr[j+1].
[!] Pitfall 2: Overwriting values during swap without using a temporary variable.
[!] Pitfall 3: Confusing ascending condition (>) with descending condition (<).
