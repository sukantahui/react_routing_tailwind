1. CONCEPT OVERVIEW
----------------------------------------------------------------------
Array traversal is the systematic process of visiting each element of an array exactly once to inspect, process, or accumulate values. The standard for-loop with an index counter variable (i) provides complete control over iteration direction and step size.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Forward Traversal: Initialize i = 0; loop while i < arr.length; increment i++.
[2] Reverse Traversal: Initialize i = arr.length - 1; loop while i >= 0; decrement i--.
[3] Step Sizing: Modify increment expression (e.g. i += 2) to visit alternate or even/odd indexed elements.
[4] Accumulator Pattern: Initialize running sum or count variable before loop; update inside loop body.
[5] In-Place Transformation: Modify array elements directly inside loop using arr[i] = transformedValue.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Off-by-one error: Starting loop at i = 1 skips the first element at index 0.
[!] Pitfall 2: Ending reverse loop at i > 0 skips the first element at index 0.
[!] Pitfall 3: Modifying the loop counter variable arbitrarily inside the loop body causing skipped elements or infinite loops.
