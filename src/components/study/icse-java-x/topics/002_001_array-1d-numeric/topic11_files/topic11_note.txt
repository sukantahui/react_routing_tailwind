1. CONCEPT OVERVIEW & ALGORITHM OBJECTIVE
----------------------------------------------------------------------
Descending bubble sort arranges elements from largest to smallest by swapping adjacent pairs whenever arr[j] < arr[j+1]. After each pass, the smallest unsorted element settles at the end of the array.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Descending Condition: Swap elements if arr[j] < arr[j+1].
[2] Pass Structure: Outer loop runs n - 1 passes, ensuring every element is systematically settled.
[3] Stable Sorting: Preserves relative order of duplicate elements because equal items are not swapped.
[4] Early Exit Optimization: Use a boolean 'swapped' flag to terminate early if no swaps occur in a pass.
[5] ICSE Syllabus Favorite: Frequently asked in Section B to sort marks, temperatures, or scores high-to-low.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Swapping when arr[j] <= arr[j+1], which breaks sort stability on duplicate values.
[!] Pitfall 2: Mixing up inner loop bound resulting in ArrayIndexOutOfBoundsException.
[!] Pitfall 3: Failing to reset the swap tracking flag at the start of each outer pass.
