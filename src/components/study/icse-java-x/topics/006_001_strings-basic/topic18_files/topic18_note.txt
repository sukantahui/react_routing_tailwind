1. THE STANDARD ICSE BACKWARD LOOP PATTERN
--------------------------------------------------------------------------------
String str = "COMPUTER";
String rev = "";
for (int i = str.length() - 1; i >= 0; i--) {
    rev = rev + str.charAt(i);
}
- Start index: str.length() - 1
- Terminating condition: i >= 0
- Decrement step: i--

2. THE PREPENDING FORWARD LOOP PATTERN
--------------------------------------------------------------------------------
String rev = "";
for (int i = 0; i < str.length(); i++) {
    char ch = str.charAt(i);
    rev = ch + rev; // Notice: 'ch' comes FIRST, then 'rev'!
}
