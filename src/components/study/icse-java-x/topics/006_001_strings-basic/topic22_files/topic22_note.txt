1. THE STANDARD ICSE DEDUPLICATION PATTERN
--------------------------------------------------------------------------------
String str = "BANANA";
String res = "";
for (int i = 0; i < str.length(); i++) {
    char ch = str.charAt(i);
    if (res.indexOf(ch) == -1) {
        res = res + ch;
    }
}
// Output: "BAN"

2. HOW IT WORKS
--------------------------------------------------------------------------------
- Start with empty result string: res = ""
- For each character 'ch', test: res.indexOf(ch) == -1
  * If -1: 'ch' has never been added to 'res'; add it!
  * If != -1: 'ch' already exists; skip it!
