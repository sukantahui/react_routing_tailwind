1. STRING TO CHAR ARRAY: toCharArray()
--------------------------------------------------------------------------------
- Prototype: public char[] toCharArray()
- Allocates a newly created char array whose length equals string length() and
  whose contents are copied from the string.
- Example: "Java".toCharArray() -> {'J', 'a', 'v', 'a'}

2. CHAR ARRAY TO STRING
--------------------------------------------------------------------------------
- Method 1: new String(charArr)
- Method 2: String.valueOf(charArr)
- Both methods create a new immutable String initialized with the array's characters.
