2. FINAL EXAM PREPARATION CHECKLIST
--------------------------------------------------------------------------------
[✓] String is a class in java.lang (auto-imported).
[✓] length() has parentheses; charAt() takes 0 to length() - 1.
[✓] substring(begin, end) excludes endIndex!
[✓] Always use .equals() for string contents.
[✓] Strings are immutable: any change returns a NEW object.
