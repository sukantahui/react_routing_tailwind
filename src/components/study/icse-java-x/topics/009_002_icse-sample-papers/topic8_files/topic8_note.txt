1. SYLLABUS OVERVIEW & BLUEPRINT:
--------------------------------------------------------------------------------
Model Examination Paper 9 strictly follows the CISCE Class 10 Computer Applications
curriculum and examination blueprint:
- Total Time: 2 Hours (plus 15 minutes reading time)
- Total Marks: 100 Marks
- Section A (40 Marks - Compulsory):
  * Question 1: 20 Multiple Choice Questions (1 mark each = 20 Marks)
  * Question 2: 10 Short Output / Evaluation Questions (2 marks each = 20 Marks)
- Section B (60 Marks - Attempt ANY 4 of 6 Questions):
  * 6 Programming Questions carrying 15 marks each (4 x 15 = 60 Marks)

2. CORE EXAM PRINCIPLES & ICSE BOARD TIPS:
--------------------------------------------------------------------------------
1. Read carefully during the 15-minute reading period. Select the 4 Section B
   questions you can code with 100% confidence.
2. Section A covers every corner of the syllabus: OOP principles, primitive data
   types, type casting, Wrapper class methods, Math class methods, Character class
   methods, String class methods, operators, loops, and constructors.
3. Every Section B answer MUST contain:
   a) Clean class definition with instance variables.
   b) Constructors and member methods matching exact signatures.
   c) Proper Scanner-based or parameter-based user inputs.
   d) Mandatory Variable Description Table (VDT) detailing Name, Data Type, and Purpose.

3. COMMON BOARD TRAPS & MISTAKES:
--------------------------------------------------------------------------------
- Off-by-one errors in String substring(start, end): The character at index 'end'
  is EXCLUDED!
- Math.round(double) returns long, while Math.round(float) returns int.
- Confusing String reference equality (==) with content equality (.equals()).
- Writing Java library shortcut methods like Arrays.sort() which score ZERO marks.
  Pure algorithmic loops (Bubble / Selection) are strictly required.
- Omitting Variable Description Table in Section B programs (-2 marks penalty).
