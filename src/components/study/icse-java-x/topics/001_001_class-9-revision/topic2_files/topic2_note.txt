1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Loops automate repeated execution of a block of statements while a condition remains true. Java classifies loops into entry-controlled ('for' and 'while', where the condition is tested before executing the body) and exit-controlled ('do-while', which executes the body at least once before checking the condition).

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] For Loop: Compact syntax combining initialization, condition test, and step increment in one line.
[2] While Loop: Entry-controlled iteration ideal when the number of iterations is unknown beforehand.
[3] Do-While Loop: Exit-controlled iteration guaranteeing at least one execution of the loop body.
[4] Break Statement: Immediately terminates the innermost loop and transfers control outside.
[5] Continue Statement: Skips the remainder of the current iteration and advances to the next loop cycle.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Semicolon after loop header: 'for (int i=0; i<5; i++);' creates an empty loop body with unintended logic.
[!] Pitfall 2: Infinite loop caused by forgetting to update the control variable inside a while or do-while loop.
[!] Pitfall 3: Off-by-one errors executing loops one time too many or one time too few.
