1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Conditional branching directs program execution along alternative paths based on boolean evaluation. Java provides 'if', 'if-else', 'nested if', 'if-else-if' ladders, the multi-way 'switch-case' selection structure, and the concise ternary operator (? :).

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Boolean Condition: In Java, 'if' requires a strictly boolean expression (e.g. if (x > 0)); non-zero integers are NOT boolean.
[2] Equality vs Assignment: Never confuse == (comparison) with = (assignment).
[3] Switch Supported Types: switch supports byte, short, char, int, String, and enums (floating point float/double are NOT allowed).
[4] Break in Switch: The 'break' statement prevents intentional or accidental 'fall-through' to subsequent case statements.
[5] Ternary Operator: 'condition ? expr1 : expr2' evaluates and returns one of two expressions conditionally.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Using '=' instead of '==' in conditions like: if (flag = true) which reassigns instead of checking.
[!] Pitfall 2: Omitting 'break' statements in switch cases leading to fall-through execution.
[!] Pitfall 3: Using double or float values in switch expressions resulting in compile-time errors.
