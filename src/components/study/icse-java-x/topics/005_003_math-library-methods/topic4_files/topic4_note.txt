1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Math.max(a, b) returns the greater of two values; Math.min(a, b) returns the smaller of two values. Both methods are overloaded for int, long, float, and double types, returning a result matching the type of the arguments.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Overloaded Types: Overloaded for int, long, float, and double.
[2] Two Arguments: Accepts exactly two arguments; to find max of three, nest calls: Math.max(a, Math.max(b, c)).
[3] Type Promotion: If comparing int and double, int is widened to double and the result is double: Math.max(5, 7.5) returns 7.5.
[4] Negative Comparison: Math.max(-10, -5) returns -5 (since -5 is greater than -10).
[5] Clamping Pattern: Restricting values within range: int clamped = Math.max(minVal, Math.min(val, maxVal));.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Attempting to pass three arguments: Math.max(a, b, c) causes compile error; must nest calls.
[!] Pitfall 2: Mixing up negative values: Math.min(-10, -5) is -10.
[!] Pitfall 3: Assuming result is always integer when one parameter is double.
