1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Math.cbrt(double x) returns the cube root of a double value, correctly preserving sign (cube root of negative is negative). Math.abs(x) returns the absolute (positive) magnitude of an argument and is overloaded for int, long, float, and double.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Cube Root of Negative: Unlike Math.sqrt, Math.cbrt(-27) is valid and returns -3.0.
[2] Math.cbrt Return Type: Always returns double.
[3] Math.abs Overloading: Returns the SAME data type as passed: Math.abs(-5) returns int 5, Math.abs(-5.5) returns double 5.5.
[4] Absolute Value: Distance from zero on the number line; never returns negative (except for Integer.MIN_VALUE overflow edge case).
[5] Common ICSE Application: Calculating absolute differences in geometric distance and currency change.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Believing Math.cbrt(-8) returns NaN; it returns -2.0.
[!] Pitfall 2: Assuming Math.abs() always returns an int; it preserves parameter type (abs(-3.5) is double 3.5).
[!] Pitfall 3: Confusing Math.cbrt with square root.
