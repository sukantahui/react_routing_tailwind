1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Math.pow(double a, double b) computes a raised to the power b (a^b). Math.sqrt(double x) computes the positive square root of x. Both methods belong to java.lang.Math, are static, and ALWAYS return a double value.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Return Type: Both Math.pow() and Math.sqrt() ALWAYS return a double, even if arguments are integers.
[2] Syntax: double res = Math.pow(2, 3); // returns 8.0, not integer 8.
[3] Negative Square Root: Math.sqrt(negativeNumber) returns Double.NaN (Not a Number), not an exception.
[4] Zero Power: Math.pow(x, 0) always returns 1.0 for any x.
[5] Explicit Casting: To store in an integer, explicit cast is mandatory: int p = (int) Math.pow(2, 3);

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Assuming Math.pow(2, 3) returns int 8; it returns double 8.0, causing type mismatch compile errors.
[!] Pitfall 2: Expecting Math.sqrt(-25) to throw an arithmetic exception; it returns NaN.
[!] Pitfall 3: Writing 'pow(a, b)' without the class prefix 'Math.'.
