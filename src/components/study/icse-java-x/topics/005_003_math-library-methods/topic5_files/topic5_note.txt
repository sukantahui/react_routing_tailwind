1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Math.random() generates a pseudorandom double value greater than or equal to 0.0 and strictly less than 1.0 [0.0, 1.0). To generate integers in an arbitrary range [min, max], developers scale and shift the formula: (int)(Math.random() * (max - min + 1)) + min.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Range: Returns a double value in the half-open range: 0.0 <= Math.random() < 1.0.
[2] Never Returns 1.0: The upper bound 1.0 is exclusive; it will never return exactly 1.0.
[3] Integer Scaling Formula: (int)(Math.random() * (max - min + 1)) + min generates integers between min and max inclusive.
[4] Dice Roll Example: (int)(Math.random() * 6) + 1 yields random integers from 1 to 6.
[5] Parentheses Precedence: Casting '(int) Math.random() * 6' ALWAYS evaluates to 0 because (int) casts the [0, 1) decimal to 0 first! Must write: (int)(Math.random() * 6).

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: The classic cast precedence bug: (int) Math.random() * 10 evaluates to 0 * 10 = 0 every time!
[!] Pitfall 2: Assuming Math.random() can return 1.0.
[!] Pitfall 3: Missing the '+ 1' in range size causing upper bound exclusion.
