1. SYLLABUS OVERVIEW & BLUEPRINT:
--------------------------------------------------------------------------------
Full syllabus trial examination following exact CISCE board format: Section A (40 Marks compulsory) and Section B (60 Marks - attempt 4 out of 6).

2. CORE EXAM PRINCIPLES & ICSE BOARD TIPS:
--------------------------------------------------------------------------------
1. Section A Q1: 20 MCQs covering primitives, operators, wrapper classes, Math methods, and String methods.
2. Section A Q2: Short answer questions covering outputs, conversions, syntax errors, and difference tables.
3. Section B Q3 to Q8: 15 marks each with Encapsulation class design, Array search/sort, String manipulation, Overloading, and Number logic.
4. Strict 2-hour time management: 45 minutes for Section A, 70 minutes for Section B, 5 minutes final review.

3. COMMON BOARD TRAPS & MISTAKES:
--------------------------------------------------------------------------------
- Off-by-one errors in loop boundaries (using <= length instead of < length).
- Omitting Variable Description Table in Section B programs (-2 marks penalty).
- Confusing String reference equality (==) with content equality (.equals()).
- Writing Java library shortcut methods like Arrays.sort() which score ZERO marks.
  Pure algorithmic loops (Bubble / Selection) are strictly required.
