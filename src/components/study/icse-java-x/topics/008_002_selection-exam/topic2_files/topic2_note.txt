1. THE CISCE OFFICIAL VDT STANDARD FORMAT
--------------------------------------------------------------------------------
Every Section B program (15 marks) mandates a Variable Description Table.
Standard 3-Column Table Format:

+-------------------+----------------+-----------------------------------------+
| Variable Name     | Data Type      | Purpose / Description                   |
+-------------------+----------------+-----------------------------------------+
| sc                | Scanner        | Object reference to read console input  |
| n                 | int            | Stores consumer units / user input      |
| arr               | int[]          | 1D array storing 15 sorted integers     |
| i, j              | int            | Loop counters for row and column passes |
| sum               | double         | Accumulator for running total of values |
| found             | boolean        | Flag set to true if search key matches  |
| temp              | int            | Temporary variable for swapping values  |
+-------------------+----------------+-----------------------------------------+

2. CRITICAL RULES FOR VDT DESCRIPTIONS
--------------------------------------------------------------------------------
- RULE 1: Never write vague descriptions like "stores i", "for loop", or "temp".
- RULE 2: State WHAT data is held and WHY the algorithm needs it.
- RULE 3: Include ALL variables: instance fields, local variables, loop counters,
          parameters, and Scanner references.
- RULE 4: Mention data dimensions: for arrays, specify 1D or 2D and capacity.
- RULE 5: Place the VDT immediately after the closing brace of the class.
