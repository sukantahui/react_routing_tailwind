1. CONCEPT OVERVIEW & OBJECTIVES
----------------------------------------------------------------------
Character.isWhitespace(char ch) is a static method of the java.lang.Character class that determines if the specified character is white space according to Java. It identifies standard spaces (' '), tab characters ('\t'), newline ('\n'), carriage return ('\r'), and form feed ('\f').

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Static Invocation: Called as Character.isWhitespace(ch); cannot be called on primitive char directly.
[2] Recognized Whitespace: Returns true for space (' '), horizontal tab ('\t'), line feed ('\n'), form feed ('\f'), and carriage return ('\r').
[3] Return Type: boolean (true if ch is whitespace, false otherwise).
[4] ASCII Space vs Whitespace: Space has ASCII code 32, tab is 9, newline is 10, carriage return is 13; all evaluate to true.
[5] ICSE Word Counting: The standard robust approach to count words in a sentence by detecting transitions between whitespace and non-whitespace characters.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Invoking as ch.isWhitespace() which is illegal on primitive char variables.
[!] Pitfall 2: Assuming isWhitespace() only checks for the standard space (' ') character; it checks all Unicode whitespace characters.
[!] Pitfall 3: Multiple consecutive spaces causing multiple word counts if not skipping redundant whitespace.
