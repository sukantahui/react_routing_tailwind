1. SUMMARY OF COMMON ICSE MATRIX BOARD PATTERNS
--------------------------------------------------------------------------------
Pattern Name             Index Condition / Formula
--------------------------------------------------------------------------------
Primary Diagonal         i == j
Secondary Diagonal       i + j == N - 1
Upper Triangle (Strict)  i < j
Lower Triangle (Strict)  i > j
Boundary Elements        i == 0 || i == N - 1 || j == 0 || j == N - 1
Non-Boundary Elements    i > 0 && i < N - 1 && j > 0 && j < N - 1
Corners (4 vertices)     (0,0), (0, N-1), (N-1, 0), (N-1, N-1)
Middle Row & Column      i == N / 2 || j == N / 2  (for odd N)
Transpose of Matrix      Transpose[j][i] = Original[i][j]
Symmetric Matrix         Original[i][j] == Original[j][i] for all i, j

2. BOUNDARY VS NON-BOUNDARY VISUAL GRID (4x4 Example)
--------------------------------------------------------------------------------
          Col 0      Col 1      Col 2      Col 3
       +----------+----------+----------+----------+
Row 0  | BOUNDARY | BOUNDARY | BOUNDARY | BOUNDARY |  (i == 0)
       +----------+----------+----------+----------+
Row 1  | BOUNDARY |  INNER   |  INNER   | BOUNDARY |
       | (j == 0) | (1, 1)   | (1, 2)   | (j == 3) |
       +----------+----------+----------+----------+
Row 2  | BOUNDARY |  INNER   |  INNER   | BOUNDARY |
       | (j == 0) | (2, 1)   | (2, 2)   | (j == 3) |
       +----------+----------+----------+----------+
Row 3  | BOUNDARY | BOUNDARY | BOUNDARY | BOUNDARY |  (i == 3)
       +----------+----------+----------+----------+

- Total Boundary Elements:     4 * N - 4 = 4(4) - 4 = 12 elements
- Total Non-Boundary Elements: (N - 2) * (N - 2) = (2 * 2) = 4 elements

3. MATRIX TRANSPOSE ALGORITHM
--------------------------------------------------------------------------------
Given an M x N Matrix A:
1. Declare Transpose matrix T of size N x M.
2. Traverse nested loops i (0 to M-1) and j (0 to N-1).
3. Set T[j][i] = A[i][j].

4. SYMMETRIC MATRIX CHECK ALGORITHM
--------------------------------------------------------------------------------
boolean isSymmetric = true;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (mat[i][j] != mat[j][i]) {
            isSymmetric = false;
            break;
        }
    }
    if (!isSymmetric) break;
}
if (isSymmetric) System.out.println("Matrix is SYMMETRIC");
else System.out.println("Matrix is NOT Symmetric");

5. 90-DEGREE CLOCKWISE ROTATION ALGORITHM
--------------------------------------------------------------------------------
Step 1: Transpose matrix in-place:
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++) {
                int temp = a[i][j]; a[i][j] = a[j][i]; a[j][i] = temp;
            }
Step 2: Reverse each row horizontally:
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n / 2; j++) {
                int temp = a[i][j]; a[i][j] = a[i][n - 1 - j]; a[i][n - 1 - j] = temp;
            }

6. SADDLE POINT OF A MATRIX
--------------------------------------------------------------------------------
- An element that is the MINIMUM in its row AND MAXIMUM in its column.
- ICSE Algorithm:
  For each row i:
    1. Find min element in row i and note its column index c.
    2. Check if this min element is >= all elements in column c.
    3. If yes, print "Saddle point found at [" + i + "][" + c + "] = " + val.
