1. MATHEMATICAL PRE-CONDITION FOR MATRIX ADDITION / SUBTRACTION
--------------------------------------------------------------------------------
- Two matrices A and B can be added or subtracted IF AND ONLY IF they have the
  exact same dimensions (same number of rows M and same number of columns N).
- Order of Matrix A: M x N
- Order of Matrix B: M x N
- Order of Resultant Matrix: M x N

2. ELEMENT-WISE FORMULAS
--------------------------------------------------------------------------------
- Addition:     Sum[i][j]  = A[i][j] + B[i][j]
- Subtraction:  Diff[i][j] = A[i][j] - B[i][j]

3. PROPERTIES OF MATRIX ADDITION
--------------------------------------------------------------------------------
a) Commutative Law:      A + B = B + A
b) Associative Law:      (A + B) + C = A + (B + C)
c) Additive Identity:    A + O = A  (where O is the Zero/Null Matrix)
d) Additive Inverse:     A + (-A) = O
e) Subtraction:          Non-commutative (A - B != B - A)

4. STEP-BY-STEP ALGORITHM (ICSE BLUEJ STANDARD)
--------------------------------------------------------------------------------
Step 1: Input dimensions M (rows) and N (columns).
Step 2: Declare matrices:
        int[][] a = new int[m][n];
        int[][] b = new int[m][n];
        int[][] sum = new int[m][n];
        int[][] diff = new int[m][n];
Step 3: Read (M * N) elements for Matrix A using nested loops (i, j).
Step 4: Read (M * N) elements for Matrix B using nested loops (i, j).
Step 5: Compute addition and subtraction using nested loops:
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                sum[i][j] = a[i][j] + b[i][j];
                diff[i][j] = a[i][j] - b[i][j];
            }
        }
Step 6: Display Matrix A, Matrix B, Sum, and Difference in clean grid layouts.

5. 2x2 CALCULATION EXAMPLE
--------------------------------------------------------------------------------
      Matrix A           Matrix B             Resultant (A + B)
   +-----+-----+      +-----+-----+        +-------------+-------------+
   |  2  |  4  |  +   |  1  |  3  |   =    |  2+1 = 3    |  4+3 = 7    |
   +-----+-----+      +-----+-----+        +-------------+-------------+
   |  6  |  8  |      |  5  |  7  |        |  6+5 = 11   |  8+7 = 15   |
   +-----+-----+      +-----+-----+        +-------------+-------------+

6. COMMON BOARD EXAM PITFALLS
--------------------------------------------------------------------------------
[!] Error: Trying to add matrices of different dimensions (e.g., 2x3 and 3x2).
    Causes: ArrayIndexOutOfBoundsException at runtime.

[!] Error: Reusing the same matrix reference for both operands.
    Always instantiate distinct arrays for A, B, and the Result matrix!
