1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- 2D arrays are declared as type[][] arrayName = new type[rows][cols];
- Outer loop (i) iterates over rows: 0 to rows - 1.
- Inner loop (j) iterates over columns: 0 to cols - 1.
- Primary Diagonal: i == j (for square matrix).
- Secondary Diagonal: i + j == N - 1 (for square matrix).

2. ESSENTIAL CHECKLIST
--------------------------------------------------------------------------------
