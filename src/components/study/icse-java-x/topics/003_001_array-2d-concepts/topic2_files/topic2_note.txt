1. CORE MATHEMATICAL & ALGORITHMIC RULES
--------------------------------------------------------------------------------
Given an M x N Matrix 'A':
- Row Sum for Row i (R_i)     = Sum of A[i][j] for j from 0 to N - 1
- Column Sum for Column j (C_j)= Sum of A[i][j] for i from 0 to M - 1
- Grand Total (Total Sum)     = Sum of all R_i = Sum of all C_j

2. ALGORITHM FOR ROW SUMS
--------------------------------------------------------------------------------
Step 1: Loop i from 0 to M - 1 (Outer Loop for Rows)
Step 2:   Set rowSum = 0 (CRITICAL: Reset accumulator for each new row)
Step 3:   Loop j from 0 to N - 1 (Inner Loop for Columns)
Step 4:     rowSum = rowSum + A[i][j]
Step 5:   End inner loop
Step 6:   Display "Sum of Row " + i + " = " + rowSum
Step 7: End outer loop

3. ALGORITHM FOR COLUMN SUMS (LOOP INVERSION)
--------------------------------------------------------------------------------
Step 1: Loop j from 0 to N - 1 (Outer Loop for Columns)
Step 2:   Set colSum = 0 (CRITICAL: Reset accumulator for each new column)
Step 3:   Loop i from 0 to M - 1 (Inner Loop for Rows)
Step 4:     colSum = colSum + A[i][j]
Step 5:   End inner loop
Step 6:   Display "Sum of Column " + j + " = " + colSum
Step 7: End outer loop

4. VISUAL CALCULATION MATRIX (3x3 Example)
--------------------------------------------------------------------------------
              Col 0   Col 1   Col 2  |  Row Sum (R_i)
            +-------+-------+-------+|
     Row 0  |  10   |  15   |  20   ||  --> 10 + 15 + 20 = 45
            +-------+-------+-------+|
     Row 1  |  25   |  30   |  35   ||  --> 25 + 30 + 35 = 90
            +-------+-------+-------+|
     Row 2  |  40   |  45   |  50   ||  --> 40 + 45 + 50 = 135
            +-------+-------+-------+|
    ---------------------------------+
    Col Sum |  75   |  90   | 105   ||  GRAND TOTAL = 270
    (C_j)   | (10+25| (15+30| (20+35||
            |  +40) |  +45) |  +50) ||

5. COMMON BOARD EXAM PITFALLS
--------------------------------------------------------------------------------
[!] Error: Declaring 'int rowSum = 0;' outside the outer row loop.
    Effect: Produces cumulative totals across rows instead of separate sums.

[!] Error: Using 'i' on outer loop and 'j' on inner loop for Column Sums.
    Remember: Column sums REQUIRE outer loop 'j' (0 to N-1) and inner loop 'i' (0 to M-1).

[!] Error: Forgetting to cast to double when calculating row averages.
    Fix: double avg = (double) rowSum / cols;
