1. WHAT IS A 2D ARRAY IN JAVA?
--------------------------------------------------------------------------------
- A 2D array is a tabular collection of homogeneous elements arranged in rows
  and columns.
- Unlike languages like C/C++ where 2D arrays occupy a single contiguous block,
  Java implements 2D arrays as an "Array of Arrays".
- The master reference variable (in Stack memory) points to a primary 1D array
  of row references on the Heap.
- Each row reference points to its own independent 1D array of primitive values
  or object references on the Heap.

2. SYNTAX & DECLARATION VARIATIONS
--------------------------------------------------------------------------------
a) Dynamic Allocation (using 'new'):
   int[][] matrix = new int[3][4];
   - Allocates 3 rows and 4 columns (Total 12 elements).
   - Default value for all integer cells is 0.

b) Direct Literal Initializer:
   int[][] matrix = {
       {10, 20, 30},
       {40, 50, 60},
       {70, 80, 90}
   };

c) Other Valid Java Declaration Syntaxes:
   int[][] arr1 = new int[3][3]; // Standard & Preferred
   int arr2[][] = new int[3][3]; // Valid C-style
   int[] arr3[] = new int[3][3]; // Valid Java-style

3. HEAP MEMORY ARCHITECTURE ("ARRAY OF ARRAYS")
--------------------------------------------------------------------------------
Stack Memory:
  [ matrix ] ---> Pointer @0x7A1B

Heap Memory:
  @0x7A1B (Master Array of Row Pointers, length = 3)
   +----------+----------+----------+
   |  Row 0   |  Row 1   |  Row 2   |
   | @0x8B01  | @0x8B02  | @0x8B03  |
   +----------+----------+----------+
        |          |          |
        v          v          v
   +---------+ +---------+ +---------+
   | 10 | 20 | | 30 | 40 | | 50 | 60 |  (Sub-arrays of data)
   +---------+ +---------+ +---------+

4. DIMENSION FORMULAS & PROPERTIES
--------------------------------------------------------------------------------
- Number of Rows:                matrix.length
- Number of Columns in Row i:    matrix[i].length
- Total Element Count:           matrix.length * matrix[0].length (for rectangular)
- First Cell Index:              matrix[0][0]
- Last Cell Index (M x N):       matrix[M - 1][N - 1]

5. JAGGED / RAGGED ARRAYS
--------------------------------------------------------------------------------
- When row sub-arrays have different lengths:
    int[][] jagged = new int[3][];
    jagged[0] = new int[2]; // Row 0 has 2 columns
    jagged[1] = new int[4]; // Row 1 has 4 columns
    jagged[2] = new int[1]; // Row 2 has 1 column

6. NESTED LOOP TRAVERSAL TEMPLATE (ROW-MAJOR)
--------------------------------------------------------------------------------
for (int i = 0; i < matrix.length; i++) {           // Outer loop for rows
    for (int j = 0; j < matrix[i].length; j++) {    // Inner loop for columns
        System.out.print(matrix[i][j] + "\t");
    }
    System.out.println();                           // Advance to next line
}

7. COMMON ICSE BOARD PITFALLS & MISTAKES
--------------------------------------------------------------------------------
[!] Error: for(int i = 0; i <= matrix.length; i++)
    Reason: Using '<=' leads to ArrayIndexOutOfBoundsException at i = length.
    Fix: Always use strict '<' (i < matrix.length).

[!] Error: Confusing matrix.length and matrix[0].length
    Remember: matrix.length = Total Rows, matrix[0].length = Total Columns.

[!] Error: int[][] a = new int[][3];
    Reason: Row dimension is mandatory when allocating 2D arrays in Java.
