1. TEST PAPER OVERVIEW:
--------------------------------------------------------------------------------
ICSE Board pattern test paper on extracting individual words using trailing spaces, finding longest word, and word-level filtering.

2. CORE ALGORITHMIC PRINCIPLES TESTED:
--------------------------------------------------------------------------------
1. Zero-indexing boundary rule: 0 to s.length() - 1. Loop must use '< s.length()'.
2. Trailing space convention: 's = s + " "' ensures final word extraction in loops.
3. Content equality: Always use .equals() or .equalsIgnoreCase() rather than '=='.
4. Lexicographical comparisons: compareTo() returns ASCII differences at first mismatch.
5. Case conversion: toUpperCase() / toLowerCase() returns a brand new String object.
