1. METHOD SPECIFICATION
--------------------------------------------------------------------------------
Prototype   : public char charAt(int index)
Package     : java.lang.String
Return Type : char
Parameters  : int index (0-based)
Throws      : java.lang.StringIndexOutOfBoundsException if index < 0 or index >= length()

2. GOLDEN BOARD RULES
--------------------------------------------------------------------------------
- First character is ALWAYS at charAt(0).
- Last character is ALWAYS at charAt(s.length() - 1).
- Never use s[i] to read characters from a String in Java!
