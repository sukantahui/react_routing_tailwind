1. METHOD SPECIFICATION & OBJECTIVE
----------------------------------------------------------------------
The equals(Object obj) method compares the actual character contents of two strings for exact equality in a case-sensitive manner. It overrides Object.equals() to provide logical value comparison rather than reference identity (memory address comparison).

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Value Comparison: Compares character-by-character sequence; returns true only if lengths and all characters match exactly.
[2] Case-Sensitivity: Strictly case-sensitive: 'Java'.equals('java') evaluates to false.
[3] Contrast with ==: '==' compares object memory addresses (references), while '.equals()' compares text content.
[4] Null Safety: str.equals(null) safely returns false without throwing an exception.
[5] Equivalence Relation: Satisfies reflexive (x.equals(x)), symmetric, and transitive mathematical properties.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Using '==' instead of '.equals()' to compare user input strings in ICSE Section B programs.
[!] Pitfall 2: Calling null.equals(str) which causes NullPointerException (use 'Constant'.equals(variable) for Yoda condition safety).
[!] Pitfall 3: Confusing boolean return value (true/false) with compareTo() integer return value (0).
