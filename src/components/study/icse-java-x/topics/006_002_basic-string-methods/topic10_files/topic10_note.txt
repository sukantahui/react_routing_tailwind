1. METHOD SPECIFICATION & OBJECTIVE
----------------------------------------------------------------------
The compareTo(String str) method compares two strings lexicographically (based on the Unicode/ASCII values of characters). It returns 0 if strings are equal, a negative integer if the calling string precedes the argument, and a positive integer if it follows.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Return Values: Returns 0 if equal, < 0 if this < str, > 0 if this > str.
[2] ASCII Calculation: At the first differing character at index k, returns: this.charAt(k) - str.charAt(k).
[3] Prefix Length Rule: If one string is a prefix of another, returns: this.length() - str.length().
[4] Case Sensitivity: Uppercase letters have smaller ASCII values than lowercase ('A' is 65, 'a' is 97).
[5] Sorting Foundation: The mandatory comparison operator used in Bubble sort and Selection sort on String arrays.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Assuming compareTo() returns only -1, 0, or 1; it returns the actual ASCII difference (e.g. 'A'.compareTo('D') is -3).
[!] Pitfall 2: Passing null to compareTo() resulting in runtime NullPointerException.
[!] Pitfall 3: Misinterpreting the return sign when sorting arrays in ascending vs descending order.
