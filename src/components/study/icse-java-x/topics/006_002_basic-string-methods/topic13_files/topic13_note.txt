1. METHOD SPECIFICATION & OBJECTIVE
----------------------------------------------------------------------
The substring() method extracts a sub-sequence of characters from a string. In its single-argument form, it extracts from beginIndex to the end. In its dual-argument form, it extracts from beginIndex inclusive up to endIndex EXCLUSIVE.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Single Parameter: str.substring(beginIndex) extracts from beginIndex to length().
[2] Dual Parameter: str.substring(beginIndex, endIndex) extracts from beginIndex up to endIndex - 1.
[3] Length Formula: The number of extracted characters is exactly: (endIndex - beginIndex).
[4] Bound Rules: 0 <= beginIndex <= endIndex <= str.length().
[5] ICSE Syllabus Pillar: The primary method used in Pig Latin, palindrome extraction, word extraction, and string slicing.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Off-by-one error: Forgetting that endIndex is EXCLUSIVE, missing the final desired character.
[!] Pitfall 2: StringIndexOutOfBoundsException when beginIndex < 0 or endIndex > length().
[!] Pitfall 3: IllegalArgumentException / Index error when beginIndex > endIndex.
