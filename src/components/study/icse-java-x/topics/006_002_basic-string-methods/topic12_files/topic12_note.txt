1. METHOD SPECIFICATION & OBJECTIVE
----------------------------------------------------------------------
The replace(char oldChar, char newChar) method returns a new string resulting from replacing all occurrences of oldChar in the string with newChar. Because strings are immutable, the original string remains untouched.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] All Occurrences: Replaces EVERY occurrence of oldChar with newChar throughout the string.
[2] Immutability: Returns a newly constructed String object; original string is never mutated.
[3] No Match Behavior: If oldChar does not occur in the string, returns a reference to the original string.
[4] CharSequence Overload: Also supports replacing substring sequences: str.replace('bad', 'good').
[5] Case Sensitive: 'Java'.replace('j', 'k') leaves 'Java' unchanged because 'j' != 'J'.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Believing replace() mutates the original string in place without reassigning.
[!] Pitfall 2: Case mismatch: expecting replace('a', 'x') to replace uppercase 'A'.
[!] Pitfall 3: Using double quotes for characters: replace('a', 'b') takes char literals, not strings.

"Never forget that Strings are immutable in Java!

Always assign the result back: str = str.replace(...) or your code will have no effect!"
