1. METHOD SPECIFICATION & OBJECTIVE
----------------------------------------------------------------------
The startsWith(String prefix) method tests whether a string begins with the specified prefix sequence. It returns true if the character sequence represented by the argument is a prefix of the character sequence represented by this string, taking case into account.

2. KEY RULES & BOARD SYLLABUS SPECIFICATIONS
----------------------------------------------------------------------
[1] Prefix Match: Returns true if the string begins with the specified prefix.
[2] Case Sensitivity: Strictly case-sensitive: 'ICSE'.startsWith('icse') returns false.
[3] Empty String Rule: Every string starts with empty string '': str.startsWith('') is always true.
[4] Offset Overload: str.startsWith(prefix, toffset) tests if the prefix begins at index toffset.
[5] Safe Length Handling: If prefix length exceeds string length, returns false safely without throwing errors.

3. COMMON BOARD EXAM PITFALLS TO AVOID
----------------------------------------------------------------------
[!] Pitfall 1: Assuming startsWith() is case-insensitive; use str.toLowerCase().startsWith() for case-insensitive checks.
[!] Pitfall 2: Passing null resulting in NullPointerException.
[!] Pitfall 3: Confusing startsWith() with contains(); startsWith() matches only at index 0.
