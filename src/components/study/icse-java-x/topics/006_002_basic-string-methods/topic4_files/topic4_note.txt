1. METHOD SPECIFICATION
--------------------------------------------------------------------------------
Prototype   : public String trim()
Package     : java.lang.String
Return Type : String
Parameters  : None
Function    : Removes leading and trailing whitespace (ASCII <= 32).
Note        : Internal spaces are NEVER removed!
