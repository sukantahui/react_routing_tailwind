1. METHOD SPECIFICATION
--------------------------------------------------------------------------------
Prototype   : public String toLowerCase()
Package     : java.lang.String
Return Type : String
Parameters  : None
Function    : Converts all uppercase characters ('A'-'Z') to lowercase ('a'-'z').
ASCII Shift : Adds 32 to ASCII value of uppercase letters (e.g. 'A' 65 + 32 = 97 'a').
