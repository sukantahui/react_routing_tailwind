1. METHOD PROTOTYPES
--------------------------------------------------------------------------------
1. public int lastIndexOf(int ch)
2. public int lastIndexOf(int ch, int fromIndex)
3. public int lastIndexOf(String str)
4. public int lastIndexOf(String str, int fromIndex)

2. CORE USAGE IN ICSE EXAMS
--------------------------------------------------------------------------------
- Scans backwards from right to left.
- Returns the index of the LAST occurrence.
- Returns -1 if character/substring is absent.
- Essential for extracting surnames: s.substring(s.lastIndexOf(' ') + 1)
