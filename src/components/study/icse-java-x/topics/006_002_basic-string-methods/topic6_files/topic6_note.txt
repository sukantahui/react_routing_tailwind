1. METHOD SPECIFICATION
--------------------------------------------------------------------------------
Prototype   : public String toUpperCase()
Package     : java.lang.String
Return Type : String
Parameters  : None
Function    : Converts all lowercase characters ('a'-'z') to uppercase ('A'-'Z').
ASCII Shift : Subtracts 32 from ASCII value of lowercase letters (e.g. 'a' 97 - 32 = 65 'A').
