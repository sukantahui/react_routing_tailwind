4. BOOLEAN POSTULATES & THEOREMS CATALOGUE
--------------------------------------------------------------------------------
1. Identity Laws:       A + 0 = A            | A · 1 = A
2. Null / Boundedness:  A + 1 = 1            | A · 0 = 0
3. Idempotent Laws:     A + A = A            | A · A = A
4. Complement Laws:     A + A' = 1           | A · A' = 0
5. Involution Law:      (A')' = A
6. Commutative Laws:    A + B = B + A        | A · B = B · A
7. Associative Laws:    (A+B)+C = A+(B+C)    | (A·B)·C = A·(B·C)
8. Distributive Laws:   A(B+C) = AB + AC     | A + BC = (A+B)(A+C)
9. Absorption Laws:     A + AB = A           | A(A+B) = A
                        A + A'B = A + B      | A(A'+B) = AB
10. De Morgan's 1st Law:(A + B)' = A' · B'   (NOR == Bubbled AND)
11. De Morgan's 2nd Law:(A · B)' = A' + B'   (NAND == Bubbled OR)

5. DUALITY PRINCIPLE RULES
--------------------------------------------------------------------------------
Rule 1: Interchange '+' (OR) and '·' (AND).
Rule 2: Interchange constants '0' and '1'.
Rule 3: Keep variable letters and their complements UNCHANGED!

6. ARITHMETIC DIGITAL CIRCUITS
--------------------------------------------------------------------------------
(A) Half Adder (2 inputs: A, B):
    - Sum   = A ⊕ B
    - Carry = A · B

(B) Full Adder (3 inputs: A, B, Cin):
    - Sum  = A ⊕ B ⊕ Cin
    - Cout = AB + Cin · (A ⊕ B)
