1. FORMAL DEFINITIONS OF l-value AND r-value
--------------------------------------------------------------------------------
In programming language theory and Python semantics:

A) l-value ("Locator Value" or "Left-Hand-Side Target"):
   - Represents a memory location or target reference that can HOLD or BIND to an object reference.
   - It appears on the LEFT side of an assignment operator (`=`).
   - An l-value MUST be a valid storage target (e.g. variable name, list element, dictionary item, object attribute).

B) r-value ("Read Value" or "Right-Hand-Side Expression"):
   - Represents a DATA VALUE or EVALUATED EXPRESSION that can be read.
   - It appears on the RIGHT side of an assignment operator (`=`).
   - Any valid Python expression that produces a value can be an r-value (constants, literals, calculations, function return values, variable contents).

2. THE FUNDAMENTAL ASSIGNMENT SEMANTICS RULE
--------------------------------------------------------------------------------
                     l-value  =  r-value
               (Memory Target)    (Evaluated Data)

- Execution Sequence:
  Step 1: The entire r-value expression on the RIGHT is evaluated FIRST to produce a single heap object.
  Step 2: The l-value reference on the LEFT is bound to point to that resulting heap object.

3. WHAT QUALIFIES AS A LEGAL l-value IN PYTHON?
--------------------------------------------------------------------------------
1. Standard Variable Identifiers:
   `score = 95`
2. Subscripted Sequence Elements (Lists, Dictionaries):
   `marks[0] = 100`
   `student['age'] = 17`
3. Object Attributes / Properties:
   `point.x = 25`
4. Tuple / List Destructuring Unpacking Targets:
   `x, y = 10, 20`
   `[a, b] = [5, 10]`
5. Slicing on Mutable Sequences:
   `my_list[1:3] = [88, 99]`

4. WHAT CANNOT BE AN l-value? (ILLEGAL TARGETS)
--------------------------------------------------------------------------------
1. Literals / Constants:
   `10 = a`  --> SyntaxError: cannot assign to literal
   `"Hello" = x` --> SyntaxError: cannot assign to literal
   Why: A constant value like 10 has no mutable variable binding location.

2. Arithmetic Expressions:
   `x + 2 = y` --> SyntaxError: cannot assign to expression
   `a * b = c` --> SyntaxError: cannot assign to expression
   Why: `x + 2` is an evaluated computation producing an r-value, not an assignable name target.

3. Function Calls:
   `len(text) = 5` --> SyntaxError: cannot assign to function call
   `math.sqrt(x) = 4` --> SyntaxError: cannot assign to function call
   Why: A function call returns an evaluated r-value.

4. Reserved Keywords:
   `def = 10` --> SyntaxError: invalid syntax

5. CAN AN l-value ALSO SERVE AS AN r-value?
--------------------------------------------------------------------------------
- YES! An l-value (like variable `x`) can be read on the right-hand side as an r-value:
  `y = x`  (Here, `y` is l-value, `x` is evaluated as r-value)
  `x = x + 1` (Here, `x` on RHS is read as r-value, evaluated, and bound to LHS `x` l-value).
- However, an r-value (like `10` or `a + b`) CANNOT serve as an l-value!
