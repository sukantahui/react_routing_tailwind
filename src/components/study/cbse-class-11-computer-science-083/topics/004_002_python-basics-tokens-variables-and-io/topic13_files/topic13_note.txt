SECTION A: COMMON PRACTICAL LAB ASSIGNMENTS
--------------------------------------------------------------------------------
1. Interactive Biodata Formatter:
   - Accept student's name, grade, age, marks in 5 subjects using input().
   - Cast numeric inputs with float() and int().
   - Compute total, average, and percentage.
   - Display a formatted grade sheet using print() with custom sep and end.

2. Identifier and Keyword Analyzer:
   - Given a list of arbitrary user-entered strings, classify each into:
     (a) Valid Python Identifier
     (b) Reserved Python Keyword
     (c) Invalid Identifier (stating reason: starts with digit, special char, etc.)

3. l-value and r-value Assignment Diagnostic:
   - Identify syntax errors in code snippets without executing them:
     * `a = 10` -> Valid
     * `10 = a` -> Invalid (Literal cannot be l-value)
     * `x + 5 = y` -> Invalid (Expression cannot be l-value)
     * `p, q = 10, 20` -> Valid (Tuple unpacking)

4. Console Separator Matrix:
   - Predict the exact terminal output for nested print statements with custom
     `sep` and `end` parameters.
