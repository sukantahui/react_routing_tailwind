1. BINARY ADDITION RULES:
- 0 + 0 = 0 (Carry: 0)
- 0 + 1 = 1 (Carry: 0)
- 1 + 0 = 1 (Carry: 0)
- 1 + 1 = 0 (Carry: 1)  -> (10 in binary = 2 in decimal)
- 1 + 1 + 1 (with incoming carry) = 1 (Carry: 1) -> (11 in binary = 3 in decimal)

Example:
   1 1 1  (Carries)
   1 0 1 1  (11)₁₀
 + 0 1 1 0  ( 6)₁₀
 ---------
   1 0 0 0 1  (17)₁₀

2. BINARY SUBTRACTION RULES:
- 0 - 0 = 0 (Borrow: 0)
- 1 - 0 = 1 (Borrow: 0)
- 1 - 1 = 0 (Borrow: 0)
- 0 - 1 = 1 (Borrow: 1 from next higher column) -> (Since 1 borrowed from next column equals 2 in the current column: 2 - 1 = 1)

Example:
   1 1 0 1  (13)₁₀
 - 0 1 1 0  ( 6)₁₀
 ---------
   0 1 1 1  ( 7)₁₀

3. BINARY MULTIPLICATION:
Follows decimal long multiplication using standard partial products (since 1 × 1 = 1 and 1 × 0 = 0):
      1 0 1  (5)₁₀
    × 0 1 1  (3)₁₀
    -------
      1 0 1  (101 × 1)
    1 0 1 0  (101 × 1, shifted by 1)
  + 0 0 0 0  (101 × 0, shifted by 2)
  ---------
    1 1 1 1  (15)₁₀

4. CBSE EXAMINATION PITFALLS:
- Forgetting incoming carry bits when adding multiple columns.
- Not verifying binary arithmetic by converting operands and results to decimal.
