1. FUNCTIONAL BLOCK DIAGRAM & COMPUTER COMPONENTS:
--------------------------------------------------------------------------------
A computer is an electronic, programmable data processing machine.
Primary functional units based on the von Neumann architecture:
  a) Input Unit: Accepts data and instructions from external users, translates them 
     into binary signals (0s and 1s). Examples: Keyboard, Mouse, OMR, OCR, MICR, Barcode.
  b) Central Processing Unit (CPU - "The Brain of the Computer"):
     - Arithmetic Logic Unit (ALU): Executes arithmetic (+, -, *, /, //, %) and 
       logical comparisons (<, >, ==, !=, AND, OR, NOT).
     - Control Unit (CU): The supervisor/manager. Fetches instructions from memory, 
       decodes binary opcodes, and generates electrical control/timing signals.
     - Internal Registers: Ultra high-speed memory cells inside the processor.
  c) Memory Unit:
     - Primary Memory: Directly addressable by CPU (RAM and ROM).
     - Secondary Memory: Permanent mass storage (SSD, HDD, Optical Disks, Flash).
  d) Output Unit: Converts processed binary output into human-comprehensible forms 
     (Monitors, Impact/Non-Impact Printers, Plotters, Speakers).

2. KEY PROCESSOR REGISTERS:
--------------------------------------------------------------------------------
  * Program Counter (PC): Holds the memory address of the NEXT instruction to be executed.
  * Memory Address Register (MAR): Holds the memory address currently being read/written.
  * Memory Buffer Register (MBR / MDR): Holds the actual data or instruction word being 
    transferred to or from RAM.
  * Instruction Register (IR): Holds the instruction code currently being decoded by CU.
  * Accumulator (AC): Holds intermediate arithmetic and logical computation outcomes of ALU.

3. THE SYSTEM BUS ARCHITECTURE:
--------------------------------------------------------------------------------
A collection of parallel electronic communication wires connecting CPU, RAM, and I/O:
  1) Address Bus (Unidirectional): Carries memory addresses generated by the CPU to locate data.
     A 32-bit address bus can access 2^32 bytes = 4 GB of RAM.
     A 64-bit address bus can address 2^64 bytes = 16 Exabytes (EB) of RAM.
  2) Data Bus (Bidirectional): Carries actual data words between CPU, memory, and devices.
     Width determines word size (e.g. 32-bit or 64-bit data bus).
  3) Control Bus (Bidirectional / Unidirectional lines): Transmits read/write, clock, 
     reset, and interrupt control signals.

4. THE INSTRUCTION EXECUTION CYCLE (F-D-E-S):
--------------------------------------------------------------------------------
  Step 1: FETCH   -> CU fetches the instruction at address in PC from RAM into IR; increments PC.
  Step 2: DECODE  -> CU decodes the binary opcode in IR to identify operation & operands.
  Step 3: EXECUTE -> ALU executes mathematical/logical computation or data transfer occurs.
  Step 4: STORE   -> Result stored in Accumulator or written back to RAM.

5. MEMORY HIERARCHY (SPEED, COST & CAPACITY):
--------------------------------------------------------------------------------
  [FASTEST / HIGHEST COST PER BYTE / SMALLEST CAPACITY]
    ▲  1. CPU Registers (sub-nanosecond, a few bytes/kilobytes)
    │  2. L1 Cache (1-2 ns, 32KB-128KB per core, static RAM)
    │  3. L2 Cache (3-5 ns, 256KB-1MB per core)
    │  4. L3 Cache (10-20 ns, 8MB-64MB shared across cores)
    │  5. Main Memory / RAM (DRAM, 50-80 ns, 8GB-64GB)
    │  6. Solid-State Drives / NVMe SSD (NAND flash, 50-100 microseconds, 512GB-4TB)
    ▼  7. Mechanical Hard Disk / HDD (magnetic, 5-15 milliseconds, 1TB-18TB)
  [SLOWEST / LOWEST COST PER BYTE / LARGEST CAPACITY]

6. PRIMARY MEMORY: RAM VS ROM:
--------------------------------------------------------------------------------
  * RAM (Random Access Memory - Volatile):
    - SRAM (Static RAM): Made of flip-flops. Does not need refreshing. Very fast, expensive. 
      Used in CPU Cache.
    - DRAM (Dynamic RAM): Made of capacitors & transistors. Charge leaks, requiring 
      refresh cycles thousands of times per second. Slower, dense, cheaper. Used as Main RAM.
  * ROM (Read Only Memory - Non-Volatile):
    - Stores BIOS/UEFI firmware and bootloader programs (POST - Power-On Self-Test).
    - PROM: Programmable once using high voltage.
    - EPROM: Erasable using Ultraviolet (UV) light exposure for 20 mins.
    - EEPROM: Electrically Erasable Programmable ROM (Flash memory). Can be updated in-place.

7. UNITS OF DIGITAL STORAGE MEASUREMENT:
--------------------------------------------------------------------------------
  * 1 Bit (b)             = 0 or 1 (Smallest unit)
  * 1 Nibble              = 4 Bits (Half a byte)
  * 1 Byte (B)            = 8 Bits (1 ASCII Character)
  * 1 Kilobyte (KB)       = 1024 Bytes      = 2^10 Bytes
  * 1 Megabyte (MB)       = 1024 KB         = 2^20 Bytes
  * 1 Gigabyte (GB)       = 1024 MB         = 2^30 Bytes
  * 1 Terabyte (TB)       = 1024 GB         = 2^40 Bytes
  * 1 Petabyte (PB)       = 1024 TB         = 2^50 Bytes
  * 1 Exabyte (EB)        = 1024 PB         = 2^60 Bytes
  * 1 Zettabyte (ZB)      = 1024 EB         = 2^70 Bytes
  * 1 Yottabyte (YB)      = 1024 ZB         = 2^80 Bytes

8. COMMON INPUT & OUTPUT PERIPHERALS:
--------------------------------------------------------------------------------
  * OCR (Optical Character Recognition): Scans printed/handwritten text into digital editable text.
  * OMR (Optical Mark Recognition): Detects shaded pencil/pen bubbles on multiple-choice sheets.
  * MICR (Magnetic Ink Character Recognition): Reads 9-digit magnetic iron-oxide codes on bank cheques.
  * Impact Printers (Dot Matrix): Striking pins against inked ribbon; noisy; creates carbon copies.
  * Non-Impact Printers (Laser, Inkjet): Electrostatic toner / micro ink spray; quiet, high resolution.
