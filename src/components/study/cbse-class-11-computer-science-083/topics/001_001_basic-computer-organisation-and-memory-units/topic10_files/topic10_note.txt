2. HIGH-YIELD SUBJECTIVE DRILL SOLUTIONS
-------------------------------------------------------------------------------
Q1. A processor has a 36-bit address bus. Calculate the maximum addressable RAM.
Ans: Max RAM = 2^36 Bytes = 2^6 * 2^30 Bytes = 64 Gigabytes (GB).

Q2. Calculate the average access time of an HDD with 7200 RPM, 9ms seek time, and 0.5ms transfer time.
Ans: Rotational Latency = (30,000 / 7200) = 4.17 ms.
     Total Access Time = 9.0 + 4.17 + 0.5 = 13.67 milliseconds.

Q3. Differentiate between OMR and OCR with one practical use case each.
Ans: OMR detects optical pencil marks on structured forms (e.g. CBSE answer sheets).
     OCR recognizes character shapes from scanned pages to produce editable text (e.g. passport scanning).

Q4. Why does an SSD achieve access times under 0.05ms while an HDD requires 10-15ms?
Ans: SSDs use solid-state semiconductor NAND flash cells with zero moving parts, eliminating
     the mechanical arm seek delay and platter rotational delay inherent in HDDs.
