1. FUNDAMENTAL UNITS OF DIGITAL INFORMATION
-------------------------------------------------------------------------------
Digital computers operate using binary electrical voltages (High = 1, Low = 0).
The basic units of digital storage are:

1. Bit (Binary Digit):
   - The smallest fundamental unit of digital data. Can only be 0 or 1.
2. Nibble:
   - A group of exactly 4 bits (e.g., 1010). Represents one hexadecimal digit (0-F).
3. Byte:
   - A group of exactly 8 bits (e.g., 01000001 = ASCII 'A').
   - The fundamental addressable unit of memory in modern computer architecture.
   - 1 Byte = 2 Nibbles = 8 Bits.

3. MEMORY CONVERSION RULES FOR CBSE EXAMINATIONS
-------------------------------------------------------------------------------
Rule 1: To convert from a LARGER unit to a SMALLER unit, MULTIPLY by 1024 (or 2^10).
  * Example: Convert 3 GB to KB:
    3 GB = 3 * 1024 MB = 3 * 1024 * 1024 KB = 3 * 2^20 KB = 3,145,728 KB.

Rule 2: To convert from a SMALLER unit to a LARGER unit, DIVIDE by 1024 (or 2^10).
  * Example: Convert 2,097,152 Bytes into Megabytes:
    2,097,152 / (1024 * 1024) = 2,097,152 / 1,048,576 = 2.0 MB.

Rule 3: Bits to Bytes Conversion:
  * Total Bits = Total Bytes * 8
  * Total Bytes = Total Bits / 8


4. BINARY PREFIXES (IEC) VS DECIMAL PREFIXES (SI)
-------------------------------------------------------------------------------
In commercial hard drive marketing, manufacturers use Decimal SI units:
  * 1 KB = 10^3 = 1,000 Bytes
  * 1 MB = 10^6 = 1,000,000 Bytes
  * 1 GB = 10^9 = 1,000,000,000 Bytes
  * 1 TB = 10^12 = 1,000,000,000,000 Bytes

In Computer Science & CBSE Curriculum, we strictly use Binary units:
  * 1 KB = 2^10 = 1,024 Bytes
  * 1 MB = 2^20 = 1,048,576 Bytes
  * 1 GB = 2^30 = 1,073,741,824 Bytes
  * 1 TB = 2^40 = 1,099,511,627,776 Bytes
