1. FUNCTIONAL UNITS OF A COMPUTER SYSTEM
-------------------------------------------------------------------------------
1. Input Unit: Transduces user commands into binary data (Keyboard, Mouse, OMR, OCR, MICR).
2. CPU: Executes instructions (ALU for math/logic, CU for sequencing, Registers for storage).
3. Primary Memory: Volatile RAM (SRAM/DRAM) & Non-Volatile ROM (PROM/EPROM/EEPROM).
4. Secondary Storage: Auxiliary persistent storage (HDD, SSD, Optical Discs, Flash).
5. Output Unit: Converts processed binary into human-readable form (Monitor, Printer, Plotter).


2. SYSTEM BUS ARCHITECTURE SUMMARY
-------------------------------------------------------------------------------
* Address Bus: STRICTLY UNIDIRECTIONAL (CPU -> Memory/IO). Width N determines max RAM: 2^N bytes.
* Data Bus: BIDIRECTIONAL (CPU <-> Memory/IO). Width M determines word transfer size: M/8 bytes.
* Control Bus: Carries timing strobes (MEMR, MEMW, IOR, IOW, INTR, RESET).


3. INSTRUCTION (MACHINE) CYCLE PHASES
-------------------------------------------------------------------------------
1. FETCH   : PC -> MAR -> RAM -> MDR -> IR; PC is incremented automatically.
2. DECODE  : Control Unit examines opcode in IR and generates micro-control signals.
3. EXECUTE : ALU computes operation or evaluates branch jumps; Flags updated.
4. STORE   : Result written to Accumulator or RAM via MDR.


4. MEMORY HIERARCHY SUMMARY
-------------------------------------------------------------------------------
Level             | Type     | Speed / Latency | Typical Capacity
------------------+----------+-----------------+-----------------
Registers         | Silicon  | 0.25 – 0.5 ns   | Bytes / KBs
L1/L2/L3 Cache    | SRAM     | 0.5 – 15 ns     | 32 KB – 96 MB
Main Memory (RAM) | DRAM     | 10 – 60 ns      | 8 GB – 64 GB
Secondary (SSD)   | 3D NAND  | 10 – 50 µs      | 500 GB – 4 TB
Secondary (HDD)   | Magnetic | 10 – 15 ms      | 1 TB – 22 TB


5. HIGH-YIELD FORMULA CHEAT SHEET
-------------------------------------------------------------------------------
* Max Addressable Memory = 2^N Bytes (N = address bus lines)
* Clock Period (T) = 1 / Frequency (f)
* Average Rotational Latency (ms) = (30,000 / RPM)
* Total HDD Access Time = Seek Time + Rotational Latency + Transfer Time
* Cache Hit Ratio (H) = Hits / Total Requests
* Average Memory Access Time (AMAT) = Hit_Time + (Miss_Rate * Miss_Penalty)
* 1 KB = 2^10 B | 1 MB = 2^20 B | 1 GB = 2^30 B | 1 TB = 2^40 B | 1 PB = 2^50 B
