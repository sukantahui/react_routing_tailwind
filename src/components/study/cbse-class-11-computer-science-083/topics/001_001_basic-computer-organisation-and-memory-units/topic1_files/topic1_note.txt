1. CENTRAL PROCESSING UNIT (CPU) OVERVIEW
-------------------------------------------------------------------------------
The Central Processing Unit (CPU), commonly known as the "Brain of the Computer",
is the electronic circuit responsible for executing program instructions and
coordinating all hardware subsystems.

A modern CPU consists of three primary internal components:
1. Arithmetic Logic Unit (ALU)
2. Control Unit (CU)
3. High-Speed Internal Processor Registers


2. ARITHMETIC LOGIC UNIT (ALU)
-------------------------------------------------------------------------------
* Function: Performs all fundamental arithmetic calculations and logical decision-making.
* Arithmetic Operations: Addition (+), Subtraction (-), Multiplication (*), Division (/).
* Logical Comparisons: Relational operations (==, !=, <, >, <=, >=) and Boolean logic
  (AND, OR, NOT, XOR).
* Operands are received from internal registers (e.g., Accumulator, General Purpose
  Registers) or memory buffers, and output flags (Zero, Sign, Carry, Overflow) are
  updated after each operation.


3. CONTROL UNIT (CU)
-------------------------------------------------------------------------------
* Function: Acts as the "Supervisory Controller" or "Conductor of the Orchestra".
* Responsibilities:
  1. Directs the sequential flow of instructions and data through the CPU.
  2. Generates micro-timed electrical control signals across the Control Bus.
  3. Decodes binary operation codes (opcodes) fetched into the Instruction Register.
  4. Manages the system clock and synchronizes instruction fetch-decode-execute phases.
* Note for CBSE Exams: The Control Unit does NOT execute arithmetic operations or store
  bulk program data; it strictly sequences and directs other hardware components.


4. KEY INTERNAL REGISTERS & THEIR ROLES
-------------------------------------------------------------------------------
Registers are high-speed temporary storage locations located inside the CPU core.
They operate at processor clock speed (nanosecond / picosecond latency), far faster
than primary memory (RAM) or cache.

Key Dedicated Registers for CBSE Class XI:
1. Program Counter (PC):
   - Holds the memory address of the NEXT instruction to be fetched and executed.
   - Automatically incremented by 1 (or instruction word length) during the fetch phase.
   - During jump/branch instructions (e.g. loops or if-else jumps), PC is overwritten
     with the branch destination address.

2. Instruction Register (IR):
   - Holds the current binary instruction word while it is being decoded and executed by the CU.

3. Memory Address Register (MAR):
   - Holds the physical memory address (in RAM or Cache) currently being read from or written to.
   - Connected directly to the Address Bus.

4. Memory Data Register (MDR) / Memory Buffer Register (MBR):
   - Holds the actual data or instruction word fetched from, or to be stored into, memory.
   - Connected directly to the Data Bus.

5. Accumulator (ACC):
   - A dedicated working register that stores intermediate arithmetic and logical results
     generated by the ALU.

6. Status / Flags Register (FLAGS):
   - Contains individual binary status bits (Flags) indicating operation outcomes:
     * Zero Flag (Z): Set to 1 if result equals 0.
     * Sign / Negative Flag (S/N): Set to 1 if result is negative.
     * Carry Flag (C): Set to 1 if an arithmetic carry out occurred.
     * Overflow Flag (O): Set to 1 if arithmetic overflow occurred.


5. HIGH-YIELD FORMULAS & NUMERICAL RULES
-------------------------------------------------------------------------------
* CPU Clock Cycle Time (T) = 1 / Clock Frequency (f)
  Example: A 4.0 GHz CPU has cycle time T = 1 / (4.0 * 10^9 s^-1) = 0.25 nanoseconds.
* CPI (Cycles Per Instruction): Average clock cycles needed per machine instruction.
* Memory Bandwidth = Bus Width (bytes) * Bus Clock Frequency (Hz).
