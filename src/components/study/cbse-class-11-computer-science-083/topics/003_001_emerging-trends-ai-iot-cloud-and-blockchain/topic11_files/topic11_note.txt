2. MASTER KEY CONCEPTS & DEFINITIONS CHEAT SHEET:

   A. ARTIFICIAL INTELLIGENCE (AI):
      - Definition: Simulating human cognitive intelligence, reasoning, and problem-solving in machines.
      - Turing Test (1950): Operational test of machine intelligence (Imitation Game).
      - Weak / Narrow AI (Siri, AlphaGo) vs Strong AI / AGI (General human-level cognition).

   B. MACHINE LEARNING & DEEP LEARNING:
      - Supervised Learning: Trained on paired input features (X) and ground-truth labels (Y).
        * Classification: Discrete labels (Spam vs Ham).
        * Regression: Continuous numbers (Price, Temperature).
      - Unsupervised Learning: Discovers hidden patterns/clusters in unlabelled data (K-Means).
      - Reinforcement Learning: Agent learns via environment interaction, rewards, and penalties.
      - Deep Learning: Multi-layered Artificial Neural Networks (ANN, CNN for vision, RNN for text).

   C. NATURAL LANGUAGE PROCESSING (NLP):
      - Subfields: NLU (Understanding & intent parsing) + NLG (Generating coherent text).
      - Pipeline: Sentence Segmentation -> Tokenization -> Stop-word Removal -> Stemming/Lemmatizing -> POS/NER.
      - Applications: Speech recognition (ASR), sentiment analysis, Project Bhashini, contextual chatbots.

   D. IMMERSIVE EXPERIENCES (AR / VR / MR):
      - AR: Digital overlays super-imposed on the real physical world (Pokémon GO, IKEA Place).
      - VR: 100% synthetic artificial world with total visual isolation (Meta Quest, Flight Simulators).
      - MR: Physical and digital objects co-exist and interact with physics (HoloLens, Vision Pro).
      - Tracking: 3-DoF (Rotational only) vs 6-DoF (Rotational + Positional room-scale walking).

   E. ROBOTICS:
      - Feedback Loop: Sense (Sensors) -> Plan (Microcontroller/CPU) -> Act (Actuators).
      - Actuators: DC/Servo motors, hydraulic pistons (heavy fluid), pneumatic air valves.
      - End Effectors: Claws, grippers, welding torches, surgical tools (da Vinci system).

   F. BIG DATA (THE 5 Vs):
      - Volume: Gigantic scale (Petabytes, Exabytes, Zettabytes, Yottabytes).
      - Velocity: Speed of streaming real-time data generation & ingestion.
      - Variety: Structured (SQL tables), Semi-Structured (JSON/XML), Unstructured (Video/Audio ~80%).
      - Veracity: Trustworthiness, cleanliness, and accuracy of data.
      - Value: Actionable strategic business and scientific intelligence extracted from data.

   G. INTERNET OF THINGS (IoT):
      - Network of physical devices embedded with sensors, software, and actuators communicating autonomously.
      - Architecture: Perception Layer (Sensors/Actuators) -> Network Layer (MQTT/BLE) -> Middleware -> Application.
      - RFID: Radio Frequency Identification (Passive = reader powered / FASTag; Active = battery powered).

   H. CLOUD COMPUTING (NIST):
      - 5 Characteristics: On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, Measured service.
      - Delivery Models:
        * IaaS: Hardware/Virtualization by vendor; OS, Runtimes, Apps by client (AWS EC2, Azure VMs).
        * PaaS: Hardware, OS, Runtimes by vendor; Code & Data by client (Google App Engine, Heroku).
        * SaaS: 100% managed by vendor; client uses browser interface (Gmail, Office 365).
      - Deployment Models: Public (Multi-tenant), Private (Single-tenant), Community (Consortium), Hybrid (Cloud Bursting).

   I. GRID COMPUTING & BLOCKCHAIN:
      - Grid Computing: Heterogeneous collaborative distributed resource sharing for massive scientific computing.
      - Blockchain: Decentralized, immutable cryptographic ledger using SHA-256 and Proof-of-Work consensus.
      - Smart Contracts: Self-executing conditional programs stored directly on blockchain ledgers.
