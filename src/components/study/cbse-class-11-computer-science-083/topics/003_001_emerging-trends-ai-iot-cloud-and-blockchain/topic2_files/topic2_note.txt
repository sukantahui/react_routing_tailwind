1. WHAT IS MACHINE LEARNING (ML)?
--------------------------------------------------------------------------------
* Definition (Arthur Samuel, 1959): "Machine Learning is the subfield of Computer Science that gives computers the ability to learn without being explicitly programmed."
* Traditional Programming vs Machine Learning:
  - Traditional: Data + Explicit Rules (Program) ----> Computer ----> Output Answers
  - Machine Learning: Data + Expected Output Answers ----> Computer ----> Learned Model (Rules)

2. THE THREE MAIN PARADIGMS OF MACHINE LEARNING
--------------------------------------------------------------------------------
(A) SUPERVISED LEARNING (Learning with a Teacher / Labeled Data):
    - The algorithm is provided with a training dataset consisting of input-output pairs $(X, Y)$ where each data point has a verified ground-truth label.
    - Goal: Learn a mapping function $f(X) = Y$ that accurately predicts the output for unseen new inputs.
    - Two Main Sub-Tasks:
      1. Classification: Predicts discrete categorical labels (e.g. Email is "Spam" vs "Ham", Tumor is "Malignant" vs "Benign").
         * Common Algorithms: Decision Trees, K-Nearest Neighbors (KNN), Support Vector Machines (SVM), Logistic Regression.
      2. Regression: Predicts continuous numerical values (e.g. Predicting House Prices based on square footage, stock price forecasting).
         * Common Algorithms: Linear Regression, Polynomial Regression.

(B) UNSUPERVISED LEARNING (Learning without a Teacher / Unlabeled Data):
    - The algorithm is fed raw input data $X$ with NO predefined labels or correct answers.
    - Goal: Discover hidden patterns, similarities, clusters, or latent structures inherent in the data.
    - Two Main Sub-Tasks:
      1. Clustering: Grouping similar data points together.
         * Example: E-Commerce Customer Segmentation based on purchase behaviors (K-Means Clustering).
      2. Association Rule Learning: Discovering frequent co-occurrence relationships.
         * Example: Market Basket Analysis (e.g. "Customers who buy bread also buy butter" - Apriori Algorithm).

(C) REINFORCEMENT LEARNING (Learning through Trial and Error with Rewards):
    - An autonomous Agent interacts with a dynamic Environment by taking Actions, transitioning between States, and receiving numerical Rewards (positive reinforcement) or Penalties (negative reinforcement).
    - Goal: Learn an optimal decision Policy ($\pi$) that maximizes cumulative rewards over time.
    - Key Components: Agent, Environment, State ($S$), Action ($A$), Reward ($R$), Policy ($\pi$).
    - Examples: Self-driving car obstacle avoidance, Game playing agents (AlphaGo, Chess, video games), Robotic arm control.

3. DEEP LEARNING & ARTIFICIAL NEURAL NETWORKS (ANN)
--------------------------------------------------------------------------------
* Deep Learning (DL) is a specialized subset of Machine Learning inspired by the biological neural structure of the human brain.
* Structure of an Artificial Neural Network:
  1. Input Layer: Receives raw feature signals (e.g. pixels of an image).
  2. Hidden Layers: Multiple interconnected layers of artificial neurons (nodes) that automatically extract hierarchical feature representations (e.g. edges -> shapes -> facial features).
  3. Output Layer: Produces final probability distributions or classifications.
* Why "Deep"? Because the network contains many (dozens to hundreds of) hidden layers.
* Specialized Architectures:
  - Convolutional Neural Networks (CNN): Specialized for 2D spatial image and video processing.
  - Recurrent Neural Networks (RNN) / Transformers: Specialized for sequential and time-series data (NLP, language translation).
