2. TIPS FOR ANSWERING 1-MARK, 2-MARK, AND 3-MARK QUESTIONS:
- For 1-mark classification questions, write both the category and a one-line justification (e.g. "Antivirus -> System Utility because it performs disk/file security maintenance").
- For 2-mark comparison questions, always construct a neat 2-column table comparing parameters side-by-side (Methodology, Error reporting, Object file, Speed).
- For 3-mark architecture questions, explicitly list the 4 OS management modules with real-world examples (Spooling for devices, Base/Limit registers for memory).
