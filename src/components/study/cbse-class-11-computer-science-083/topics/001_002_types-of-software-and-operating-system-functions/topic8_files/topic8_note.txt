1. DESKTOP & SERVER OPERATING SYSTEMS:

A. MICROSOFT WINDOWS:
The most widely adopted desktop operating system globally.
- Kernel Architecture: Windows NT Hybrid Kernel.
- Licensing: Proprietary commercial software (Requires paid license key).
- Default File System: NTFS (New Technology File System).
- Primary Strength: Unmatched third-party software catalog, legacy enterprise compatibility, and PC gaming support (DirectX).

B. GNU/LINUX (UBUNTU, DEBIAN, RED HAT, FEDORA):
A Unix-like operating system built around the open-source Linux kernel created by Linus Torvalds.
- Kernel Architecture: Monolithic Kernel.
- Licensing: Free and Open Source Software (FOSS) under GNU General Public License (GPL).
- Default File System: ext4, Btrfs.
- Primary Strength: Powers over 90% of the world's top 500 supercomputers, cloud servers (AWS, Azure, Google Cloud), and developer infrastructure due to stability, zero licensing cost, and security.

C. APPLE macOS:
The proprietary operating system engineered specifically for Apple Mac desktop and laptop computers.
- Kernel Architecture: XNU / Darwin Hybrid Kernel based on BSD Unix.
- Licensing: Proprietary (bundled with Apple Mac hardware).
- Default File System: APFS (Apple File System).
- Primary Strength: Seamless hardware-software integration, Unix-compliant terminal environment for developers, and creative production workflows.

2. MOBILE & EMBEDDED OPERATING SYSTEMS:

A. GOOGLE ANDROID:
The dominant global mobile operating system developed by Google and the Open Handset Alliance.
- Kernel Foundation: Customized Linux Kernel with the Android Runtime (ART) executing compiled bytecode.
- Licensing: Open-source foundation (Android Open Source Project - AOSP) with proprietary Google Mobile Services (GMS).
- File System: ext4 / F2FS (Flash-Friendly File System).

B. APPLE iOS:
The proprietary mobile operating system designed exclusively for Apple iPhone hardware.
- Kernel Foundation: Darwin / XNU Hybrid Kernel.
- Architecture: Heavily sandboxed security architecture; applications can only be installed from the official Apple App Store.
- File System: APFS with hardware-encrypted storage.
