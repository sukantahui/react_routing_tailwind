1. CONCEPT OVERVIEW
-------------------------------------------------------------------------------
Every runtime environment and programming language generates transient build
artifacts, dependency trees, and cache files that must never be checked into
version control.

Standardizing `.gitignore` templates per tech stack prevents repository bloating
(e.g., committing 300MB of `node_modules/` or compiled `.class` binaries).

3. GITHUB/GITIGNORE REPOSITORY STANDARD
-------------------------------------------------------------------------------
The official repository `github/gitignore` contains curated, battle-tested
templates maintained by the open-source community for over 100 languages.
You can generate merged templates instantly using tools like `gitignore.io`
or `npx gitignore <language>`.
