1. TERMINAL LAB OBJECTIVES
-------------------------------------------------------------------------------
This hands-on terminal lab is designed for student self-directed practice.
Students execute a 6-phase sequence directly in their terminal to solidify:
  Phase 1: Project Initialization & Identity Setup (`git init -b main`)
  Phase 2: Three-Tier Exclusion Configuration (`.gitignore` + `exclude`)
  Phase 3: Intent-to-Add & Surgical Patch Staging (`git add -N` + `git add -p`)
  Phase 4: Conventional Commits with 50/72 Formatting (`git commit`)
  Phase 5: Status & Diff Auditing (`git status -sb`, `git diff --staged`)
  Phase 6: Independent Revert Verification (`git revert`)

2. STEP-BY-STEP TERMINAL COMMAND RUNBOOK
-------------------------------------------------------------------------------
Step 1: `git init -b main pos_engine && cd pos_engine`
Step 2: `git config user.name "Your Name" && git config user.email "you@example.com"`
Step 3: Create `.gitignore` ignoring `node_modules/`, `dist/`, `.env`, `*.log`
Step 4: `git add .gitignore && git commit -m "chore: initialize repository with .gitignore"`
Step 5: Create `pos.js` with base checkout logic; stage and commit with `feat(pos): ...`
Step 6: Edit `pos.js` with both a bug fix and a debug `console.log`
Step 7: Run `git add -p pos.js`; press `y` for fix and `n` for debug log
Step 8: `git commit -m "fix(pos): correct tax computation error"`
Step 9: Run `git restore pos.js` to discard the debug log cleanly from working tree
Step 10: Run `git log --oneline --graph` to verify history cleanliness

3. LAB PASS CRITERIA
-------------------------------------------------------------------------------
  - All commits follow Conventional Commits specification.
  - Zero debug logs or temporary files committed to history.
  - Test suites pass cleanly on every commit.
  - Complete mastery of Three-Tree state transitions.
