2. KEY EXAMINATION PRINCIPLES
-------------------------------------------------------------------------------
- Git stores compressed object snapshots (blobs & trees), not delta diffs.
- `git status -s` Left Column = Index vs HEAD; Right Column = Working Tree vs Index.
- `git add -p` cannot auto-split (`s`) contiguous adjacent lines without context lines.
- `.gitignore` only applies to UNTRACKED files. Already-tracked files require `git rm --cached`.
- `.git/info/exclude` is private to that single local clone and never pushed to remotes.
