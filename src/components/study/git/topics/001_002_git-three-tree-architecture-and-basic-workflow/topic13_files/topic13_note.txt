1. PROJECT MISSION OVERVIEW
-------------------------------------------------------------------------------
The student cohort at Coder & AccoTax (Barrackpore) builds an Invoice Management
Engine from scratch while rigorously applying every concept from Module 001_002:
  1. Three-Tree lifecycle tracking (Working Tree -> Index -> HEAD).
  2. Granular staging with `git add -p` and `git add <file>`.
  3. Strict Conventional Commits (`feat`, `fix`, `test`, `refactor`, `docs`).
  4. Complete exclusion hygiene (`.gitignore`, `.git/info/exclude`, global ignore).
  5. Auditability verification via `git status -sb` and `git diff --staged`.
