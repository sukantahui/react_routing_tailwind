2. MASTER REFERENCE FORMULA CHEAT SHEET
--------------------------------------------------------------------------------
1. Topology Visualizer:
   git log --graph --oneline --decorate --all
2. Fast Author Output Breakdown:
   git shortlog -sn --no-merges
3. Deleted Function Search:
   git log -S "<identifier>" --stat -p --oneline
4. Line Range Provenance without Formatting Noise:
   git blame -w -C -C -L <start>,<end> <path>
5. Outgoing Local Commits:
   git log origin/main..HEAD --oneline
6. Incoming Remote Commits:
   git log HEAD..origin/main --oneline
7. Branch Divergence Since Fork:
   git log --left-right --graph --oneline main...feature
8. Inspect File Blob at Revision:
   git show <commit-sha>:<path/to/file>
