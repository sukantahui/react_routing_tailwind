• TOPIC 0: 2xn GAMES
  - Parameterization p = (p1, 1-p1)^T on 1D simplex.

  - Lower envelope floor and Maximin peak.

• TOPIC 1: mx2 GAMES
  - Parameterization q = (q1, 1-q1)^T on 1D simplex.
  - Strategy lines E(Ai, q) = (ai1 - ai2)*q1 + ai2.
  - Upper envelope ceiling and Minimax trough.

• TOPIC 2: GRAPHICAL METHOD

• TOPIC 3: PLOTTING STRATEGY LINES
  - Calibrating dual vertical axes (p1=0 / p1=1).

  - Slope calculation m = a1j - a2j and intersection formula p1 = (a2k - a2j)/(m_j - m_k).

• TOPIC 4: FINDING OPTIMAL STRATEGIES GRAPHICALLY
  - 5-step graphical optimization pipeline.

  - Global Optimality Audit: E(p*, Bj) >= v* for all columns.

• TOPIC 5: ALGEBRAIC METHOD

  - Two-stage filtration: Probability Admissibility in [0, 1] + Global Minimax Bounds.

• TOPIC 6: SOLVING EQUATIONS FOR OPTIMAL PROBABILITIES
  - Expected Payoff Indifference Principle.
  - Game determinant Δ = (a11 + a22) - (a12 + a21).
  - Cramer's Rule formulations: p1* = (a22 - a21)/Δ and q1* = (a22 - a12)/Δ.

• TOPIC 7: DETERMINING THE VALUE OF THE GAME
  - Determinant formula: v* = (a11*a22 - a12*a21)/Δ (in ₹).

  - Shift-invariance theorem: v_new* = v_old* + C.
