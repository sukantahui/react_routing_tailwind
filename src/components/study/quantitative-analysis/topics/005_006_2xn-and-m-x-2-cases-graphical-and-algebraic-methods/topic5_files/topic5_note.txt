1. METHOD OF 2x2 SUBMATRICES (COMBINATORIAL ENUMERATION)
--------------------------------------------------------------------------------
When graphical plotting is not preferred, we solve 2xn and mx2 games via the
EXHAUSTIVE SUBMATRIX ALGEBRAIC METHOD:

1. COMBINATORIAL PAIR SELECTION:
   • For 2xn Games: Select all C(n, 2) = n(n-1)/2 pairs of columns {B_j, B_k}.
   • For mx2 Games: Select all C(m, 2) = m(m-1)/2 pairs of rows {A_i, A_r}.

2. SOLVE EACH CANDIDATE 2x2 SUBMATRIX:
   • For each submatrix A_sub = [ [a_11, a_12], [a_21, a_22] ]:
         Δ = (a_11 + a_22) - (a_12 + a_21)
         p_1* = (a_22 - a_21) / Δ,   p_2* = 1 - p_1*
         q_1* = (a_22 - a_12) / Δ,   q_2* = 1 - q_1*
         v* = (a_11 * a_22 - a_12 * a_21) / Δ  (in ₹)

--------------------------------------------------------------------------------
2. THE TWO MANDATORY VALIDATION CRITERIA
--------------------------------------------------------------------------------

CRITERION 1: PROBABILITY ADMISSIBILITY
• Check: 0 <= p_1* <= 1  AND  0 <= q_1* <= 1.
• If any probability is negative (< 0) or exceeds 1 (> 1), DISCARD the submatrix!

CRITERION 2: GLOBAL MINIMAX / MAXIMIN OPTIMALITY
• For 2xn Games:
      Check: E(p*, B_c) >= v* for ALL columns c in {1, ..., n}.
• For mx2 Games:
      Check: E(A_r, q*) <= v* for ALL rows r in {1, ..., m}.
• If the condition fails for even one original strategy, DISCARD the candidate!

• The unique submatrix passing BOTH criteria is the true Nash Equilibrium solution!

4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never accept a submatrix solution without testing all unselected rows/columns.
- Discard candidate pairs where determinant denominator Δ = 0 (parallel lines).
- Automated algebraic scripts should implement the 2 criteria sequentially to maximize speed.
- State all game values and payoffs in Indian Rupees (₹).
