1. THE INDIFFERENCE PRINCIPLE (EQUAL PAYOFF THEOREM)
--------------------------------------------------------------------------------
In any active 2x2 sub-game A_sub = [ [a_11, a_12], [a_21, a_22] ]:

1. PLAYER A's PROBABILITY EQUATION (MAKING PLAYER B INDIFFERENT):
   • Player B's expected loss when playing B_1 equals expected loss when playing B_2:
         p_1 * a_11 + (1 - p_1) * a_21 = p_1 * a_12 + (1 - p_1) * a_22
   • Rearranging terms:
         p_1 * [ (a_11 - a_21) - (a_12 - a_22) ] = a_22 - a_21
         p_1 * [ (a_11 + a_22) - (a_12 + a_21) ] = a_22 - a_21
   • Solving for p_1*:
         p_1* = (a_22 - a_21) / Δ
         p_2* = 1 - p_1* = (a_11 - a_12) / Δ
     where Δ = (a_11 + a_22) - (a_12 + a_21).

2. PLAYER B's PROBABILITY EQUATION (MAKING PLAYER A INDIFFERENT):
   • Player A's expected return when playing A_1 equals expected return when playing A_2:
         q_1 * a_11 + (1 - q_1) * a_12 = q_1 * a_21 + (1 - q_1) * a_22
   • Rearranging terms:
         q_1 * [ (a_11 - a_12) - (a_21 - a_22) ] = a_22 - a_12
         q_1 * [ (a_11 + a_22) - (a_12 + a_21) ] = a_22 - a_12
   • Solving for q_1*:
         q_1* = (a_22 - a_12) / Δ
         q_2* = 1 - q_1* = (a_11 - a_21) / Δ.

--------------------------------------------------------------------------------
2. LINEAR ALGEBRAIC & CRAMER'S RULE MATRIX REPRESENTATION
--------------------------------------------------------------------------------
Matrix System for Player A:
      [ (a_11 - a_12)   (a_21 - a_22) ] [ p_1 ]   [ 0 ]
      [       1               1       ] [ p_2 ] = [ 1 ]

Determinant:
      det = (a_11 - a_12) - (a_21 - a_22) = (a_11 + a_22) - (a_12 + a_21) = Δ.

3. FOUR REAL-WORLD BENGAL CASE STUDIES
--------------------------------------------------------------------------------

CASE STUDY 1: Precision Foundry 2x2 Sub-Game Balancing (Debangshu)
Debangshu in Barrackpore solved A_sub = [[20, 50], [40, 10]] via indifference equations.
Δ = -60, yielding p1* = -30/-60 = 0.50 and q1* = -40/-60 = 2/3, locking in ₹30,000 per shift.

4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never switch the numerator terms (p1* uses a22 - a21; q1* uses a22 - a12).
- When Δ is negative, verify that the numerator is also negative to yield a positive probability!
- The sum p1* + p2* must ALWAYS equal 1.0.
- State all game values and payoffs in Indian Rupees (₹).
