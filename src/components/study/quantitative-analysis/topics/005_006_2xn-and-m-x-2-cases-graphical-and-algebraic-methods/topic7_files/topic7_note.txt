1. THREE EQUIVALENT MATHEMATICAL FORMULATIONS OF GAME VALUE v*
--------------------------------------------------------------------------------
In any active 2x2 sub-game A_sub = [ [a_11, a_12], [a_21, a_22] ]:

1. CLOSED-FORM DETERMINANT FORMULA:
         v* = (a_11 * a_22 - a_12 * a_21) / Δ  (in ₹)
     where Δ = (a_11 + a_22) - (a_12 + a_21).

2. EXPECTED PAYOFF ON ACTIVE SUPPORT (EQUAL PAYOFF PRINCIPLE):
         v* = E(p*, B_1) = p_1* * a_11 + (1 - p_1*) * a_21
         v* = E(p*, B_2) = p_1* * a_12 + (1 - p_1*) * a_22
         v* = E(A_1, q*) = q_1* * a_11 + (1 - q_1*) * a_12
         v* = E(A_2, q*) = q_1* * a_21 + (1 - q_1*) * a_22

3. BILINEAR MATRIX INNER PRODUCT:
         v* = p*^T * A * q* = sum_{i} sum_{j} [ p_i* * a_ij * q_j* ]

--------------------------------------------------------------------------------
2. SHIFT & SCALE INVARIANCE THEOREMS
--------------------------------------------------------------------------------
• CONSTANT ADDITION (+C):
  If every cell a_ij is replaced by a_ij + C:
      v_new* = v_old* + C  (in ₹)
      Optimal strategy vectors p* and q* remain 100% UNCHANGED!

• POSITIVE SCALAR MULTIPLICATION (*k with k > 0):
  If every cell a_ij is replaced by k * a_ij:
      v_new* = k * v_old*  (in ₹)
      Optimal strategy vectors p* and q* remain 100% UNCHANGED!

4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never forget the minus sign in the numerator: a11*a22 - a12*a21 (determinant).
- When Δ is negative, the numerator is usually also negative, yielding a positive v*.
- Verify v* by checking both row and column expected payoffs.
- State all game values and financial balances in Indian Rupees (₹).
