1. THE 4-STEP STRATEGY LINE PLOTTING PROTOCOL
--------------------------------------------------------------------------------

STEP 1: DUAL VERTICAL AXIS SETUP:
• Draw two vertical parallel axes separated by a horizontal distance representing [0, 1].
• Left Axis:  p_1 = 0 (or q_1 = 0) ➔ Represents Pure Strategy A_2 (or Pure Strategy B_2).
• Right Axis: p_1 = 1 (or q_1 = 1) ➔ Represents Pure Strategy A_1 (or Pure Strategy B_1).
• Calibrate both vertical axes with uniform increments in Indian Rupees (₹).

STEP 2: MARKING ENDPOINTS:
• For 2xn Game (Column B_j):
      Left Point (p_1 = 0):  (0, a_2j)
      Right Point (p_1 = 1): (1, a_1j)
• For mx2 Game (Row A_i):
      Left Point (q_1 = 0):  (0, a_i2)
      Right Point (q_1 = 1): (1, a_i1)

STEP 3: DRAWING & LABELING LINES:
• Connect the left and right points with a straight line.
• Line Equation: E_j(p_1) = (a_1j - a_2j) * p_1 + a_2j.
• Slope Classification:
      m_j > 0: Ascending Line  (a_1j > a_2j)
      m_j < 0: Descending Line (a_1j < a_2j)
      m_j = 0: Horizontal Line (a_1j = a_2j)

STEP 4: COMPUTING INTERSECTION COORDINATES:
• Equate E_j(p_1) = E_k(p_1):
      p_1 = (a_2k - a_2j) / ((a_1j - a_2j) - (a_1k - a_2k))
• Substitute p_1 back into E_j(p_1) to obtain the intersection payoff in ₹.

--------------------------------------------------------------------------------
3. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never reverse the left and right endpoints! (Left is Row 2 / Col 2; Right is Row 1 / Col 1).
- Parallel lines never intersect; the lower/higher line dominates completely.
- Use uniform scale intervals on both vertical axes to avoid distorted intersection angles.
- State all game values and intersection payoffs in Indian Rupees (₹).
