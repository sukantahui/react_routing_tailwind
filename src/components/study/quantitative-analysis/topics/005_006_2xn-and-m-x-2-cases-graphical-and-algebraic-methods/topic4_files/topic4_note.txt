1. THE COMPLETE GRAPHICAL OPTIMIZATION PIPELINE
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
A. FOR 2xn GAMES (PLAYER A MAXIMIZES ON LOWER ENVELOPE):
--------------------------------------------------------------------------------
1. Parameterize Player A's strategy: p = (p_1, 1 - p_1)^T.
2. Plot all n expected payoff lines: E_j(p_1) = (a_1j - a_2j) * p_1 + a_2j.
3. Trace the LOWER ENVELOPE: f_lower(p_1) = min_{j} [ E_j(p_1) ].
4. Locate the MAXIMIN PEAK (p_1*, v*) at the highest point of the lower envelope.
5. Identify the two intersecting columns B_j and B_k forming this apex.
6. Extract the active 2x2 submatrix:
         A_sub = [ [a_1j, a_1k],
                   [a_2j, a_2k] ]
7. Solve A_sub for exact closed-form probabilities q_j*, q_k* and Game Value v* (in ₹).
8. Reconstruct the full n-dimensional vector q* by assigning 0.0 to all inactive columns.

--------------------------------------------------------------------------------
B. FOR mx2 GAMES (PLAYER B MINIMIZES ON UPPER ENVELOPE):
--------------------------------------------------------------------------------
1. Parameterize Player B's strategy: q = (q_1, 1 - q_1)^T.
2. Plot all m expected payout lines: E_i(q_1) = (a_i1 - a_i2) * q_1 + a_i2.
3. Trace the UPPER ENVELOPE: f_upper(q_1) = max_{i} [ E_i(q_1) ].
4. Locate the MINIMAX TROUGH (q_1*, v*) at the lowest point of the upper envelope.
5. Identify the two intersecting rows A_i and A_r forming this apex.
6. Extract the active 2x2 submatrix:
         A_sub = [ [a_i1, a_i2],
                   [a_r1, a_r2] ]
7. Solve A_sub for exact closed-form probabilities p_i*, p_r* and Game Value v* (in ₹).
8. Reconstruct the full m-dimensional vector p* by assigning 0.0 to all inactive rows.

--------------------------------------------------------------------------------
2. GLOBAL OPTIMALITY AUDIT
--------------------------------------------------------------------------------
• For 2xn Games: Verify E(p*, B_c) >= v* for all columns c in {1, ..., n}.
• For mx2 Games: Verify E(A_r, q*) <= v* for all rows r in {1, ..., m}.
• Expected payoff equals v* on all active support strategies.

4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never assign non-zero probability to inactive strategies outside the envelope apex.
- Always check that the two intersecting lines have opposite slope signs.
- Complete the full vector reconstruction (do not stop at 2D sub-game probabilities).
- State all game values and payoffs in Indian Rupees (₹).
