================================================================================
TOPIC 23: WORKED EXAMPLE 17 – PROBLEM INVOLVING MULTIPLE RESOURCE CONSTRAINTS
================================================================================

1. PROBLEM STATEMENT
--------------------
A manufacturing company produces three products: Product A, Product B, and Product C.
The company has four resources that constrain production:
- Labor: 240 hours
- Machine A: 180 hours
- Machine B: 150 hours
- Raw Material: 200 units

Resource requirements per unit:
              Product A   Product B   Product C   Available
Labor (hrs)       2           3           4         240
Machine A (hrs)   3           2           1         180
Machine B (hrs)   1           3           2         150
Material (units)  2           2           3         200

Profit per unit: Product A = ₹60, Product B = ₹50, Product C = ₹70

The company wants to maximize total profit.

2. STEP-BY-STEP FORMULATION
---------------------------

STEP 1: Read and Understand
- Goal: Maximize total profit
- Products: A, B, C (3 products)
- Resources: Labor, Machine A, Machine B, Material (4 resources)
- All constraints are ≤ (maximum limits)

STEP 2: Identify Decision Variables
- x₁ = units of Product A produced
- x₂ = units of Product B produced
- x₃ = units of Product C produced

STEP 3: Identify the Objective
- Profit: A = ₹60, B = ₹50, C = ₹70
- Maximize Z = 60x₁ + 50x₂ + 70x₃

STEP 4: Identify Constraints
- Labor: 2x₁ + 3x₂ + 4x₃ ≤ 240
- Machine A: 3x₁ + 2x₂ + x₃ ≤ 180
- Machine B: x₁ + 3x₂ + 2x₃ ≤ 150
- Material: 2x₁ + 2x₂ + 3x₃ ≤ 200

STEP 5: Add Non-negativity
- x₁ ≥ 0, x₂ ≥ 0, x₃ ≥ 0

STEP 6: Review and Validate
- Test a feasible solution:
  x₁ = 20, x₂ = 30, x₃ = 20
  Labor = 40+90+80 = 210 ≤ 240 ✓
  Machine A = 60+60+20 = 140 ≤ 180 ✓
  Machine B = 20+90+40 = 150 ≤ 150 ✓
  Material = 40+60+60 = 160 ≤ 200 ✓
  Profit = 60(20)+50(30)+70(20) = 1,200+1,500+1,400 = ₹4,100

STEP 7: Document
- Final Model:
  Maximize Z = 60x₁ + 50x₂ + 70x₃
  Subject to:
    Labor: 2x₁ + 3x₂ + 4x₃ ≤ 240
    Machine A: 3x₁ + 2x₂ + x₃ ≤ 180
    Machine B: x₁ + 3x₂ + 2x₃ ≤ 150
    Material: 2x₁ + 2x₂ + 3x₃ ≤ 200
    x₁ ≥ 0, x₂ ≥ 0, x₃ ≥ 0

3. SOLUTION APPROACH
---------------------
This is a 3-variable LP with 4 constraints. Using simplex method or LP solver:

Optimal Solution (found by solving the LP):
- x₁ = 30 (Product A)
- x₂ = 20 (Product B)
- x₃ = 30 (Product C)

Check constraints:
- Labor: 2(30)+3(20)+4(30) = 60+60+120 = 240 ≤ 240 ✓ (binding)
- Machine A: 3(30)+2(20)+1(30) = 90+40+30 = 160 ≤ 180 ✓ (slack: 20)
- Machine B: 1(30)+3(20)+2(30) = 30+60+60 = 150 ≤ 150 ✓ (binding)
- Material: 2(30)+2(20)+3(30) = 60+40+90 = 190 ≤ 200 ✓ (slack: 10)

Profit = 60(30) + 50(20) + 70(30) = 1,800 + 1,000 + 2,100 = ₹4,900

4. INTERPRETATION
-----------------
- Produce 30 units of Product A, 20 units of Product B, and 30 units of Product C.
- Total profit = ₹4,900.
- Labor and Machine B are binding (fully used).
- Machine A has slack (20 hours unused).
- Material has slack (10 units unused).

5. KEY INSIGHTS
---------------
- Multiple resource constraints can be binding.
- Some resources may have slack (unused capacity).
- The optimal product mix balances resource usage across all constraints.
- Resource efficiency (profit per unit of resource) guides the solution.

6. REAL-WORLD APPLICATIONS
---------------------------
- Manufacturing resource allocation.
- Production planning with multiple constraints.
- Capacity utilization optimization.
- Supply chain resource management.

7. WHAT WE LEARN
----------------
- How to handle multiple resource constraints.
- How to identify binding vs non-binding resources.
- How to balance resource usage across products.
- The importance of resource efficiency.

8. KEY TAKEAWAYS
-----------------
- Multiple resources may be binding simultaneously.
- Slack resources indicate excess capacity.
- Resource efficiency is key to understanding the optimal solution.
- The optimal solution balances all constraints.
