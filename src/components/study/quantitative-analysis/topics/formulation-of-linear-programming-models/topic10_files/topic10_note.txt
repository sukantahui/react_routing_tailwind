================================================================================
TOPIC 10: WORKED EXAMPLE 4 – RESOURCE ALLOCATION PROBLEM
================================================================================

1. PROBLEM STATEMENT
--------------------
A company has three types of resources to allocate across two projects:
- Labor (total: 200 hours)
- Equipment (total: 150 hours)
- Capital (total: ₹100,000)

Each project requires different amounts of resources per unit and generates different returns:

Project 1 requires: 3 labor, 2 equipment, ₹2,000 capital per unit
Project 2 requires: 2 labor, 3 equipment, ₹1,500 capital per unit

Return per unit: Project 1 = ₹12,000, Project 2 = ₹10,000

The company wants to maximize total return.

2. STEP-BY-STEP FORMULATION
---------------------------

STEP 1: Read and Understand
- Goal: Maximize total return
- Activities: Project 1 and Project 2 (2 activities)
- Resources: Labor, Equipment, Capital (3 resources)
- No demand constraints

STEP 2: Identify Decision Variables
- x₁ = number of units of Project 1 undertaken
- x₂ = number of units of Project 2 undertaken

STEP 3: Identify the Objective
- Return per unit: Project 1 = ₹12,000, Project 2 = ₹10,000
- Maximize Z = 12,000x₁ + 10,000x₂

STEP 4: Identify Constraints
- Labor: 3x₁ + 2x₂ ≤ 200
- Equipment: 2x₁ + 3x₂ ≤ 150
- Capital: 2,000x₁ + 1,500x₂ ≤ 100,000

STEP 5: Add Non-negativity
- x₁ ≥ 0, x₂ ≥ 0

STEP 6: Review and Validate
- Test x₁ = 0, x₂ = 50:
  Labor = 100 ≤ 200 ✓
  Equipment = 150 ≤ 150 ✓
  Capital = 75,000 ≤ 100,000 ✓

- Test x₁ = 40, x₂ = 20:
  Labor = 120 + 40 = 160 ≤ 200 ✓
  Equipment = 80 + 60 = 140 ≤ 150 ✓
  Capital = 80,000 + 30,000 = 110,000 ≤ 100,000 ✗

STEP 7: Document
- Final Model:
  Maximize Z = 12,000x₁ + 10,000x₂
  Subject to:
    Labor: 3x₁ + 2x₂ ≤ 200
    Equipment: 2x₁ + 3x₂ ≤ 150
    Capital: 2,000x₁ + 1,500x₂ ≤ 100,000
    x₁ ≥ 0, x₂ ≥ 0

3. GRAPHICAL SOLUTION
---------------------
Step 1: Plot constraints on x₁-x₂ plane
Step 2: Identify feasible region
Step 3: Find corner points:
  - (0, 0)
  - (0, 50)
  - (30, 30)  [Intersection of Labor and Equipment]
  - (50, 0)   [Labor limit]
  - (40, 13.33) [Intersection of Labor and Capital]
  - (33.33, 22.22) [Intersection of Equipment and Capital]

Step 4: Evaluate objective at each corner:
  - (0, 0): Z = 0
  - (0, 50): Z = 500,000
  - (30, 30): Z = 360,000 + 300,000 = 660,000
  - (50, 0): Z = 600,000
  - (40, 13.33): Z = 480,000 + 133,333 = 613,333
  - (33.33, 22.22): Z = 400,000 + 222,222 = 622,222

Step 5: Optimal solution: (30, 30) with return = ₹660,000

4. INTERPRETATION
-----------------
- Undertake 30 units of Project 1 and 30 units of Project 2.
- Total return = ₹660,000.
- Resource usage at optimum:
  - Labor: 3(30) + 2(30) = 90 + 60 = 150 hrs (not fully used)
  - Equipment: 2(30) + 3(30) = 60 + 90 = 150 hrs (fully used)
  - Capital: 2,000(30) + 1,500(30) = 60,000 + 45,000 = 105,000 > 100,000 ✗

Wait! The capital constraint is violated at (30,30). Let me recalculate.

At (30,30):
- Labor: 3(30) + 2(30) = 90 + 60 = 150 ≤ 200 ✓
- Equipment: 2(30) + 3(30) = 60 + 90 = 150 ≤ 150 ✓
- Capital: 2,000(30) + 1,500(30) = 60,000 + 45,000 = 105,000 ≤ 100,000 ✗ (exceeds by 5,000)

So (30,30) is infeasible. The actual optimal is at the intersection of Equipment and Capital constraints.

Let me solve properly:

Equipment: 2x₁ + 3x₂ = 150
Capital: 2,000x₁ + 1,500x₂ = 100,000 → divide by 500: 4x₁ + 3x₂ = 200

Solve:
2x₁ + 3x₂ = 150
4x₁ + 3x₂ = 200
Subtract: 2x₁ = 50 → x₁ = 25
Substitute: 2(25) + 3x₂ = 150 → 50 + 3x₂ = 150 → 3x₂ = 100 → x₂ = 33.33

So the optimal corner is (25, 33.33) where Equipment and Capital intersect.

But let me check if Labor allows this:
Labor: 3(25) + 2(33.33) = 75 + 66.67 = 141.67 ≤ 200 ✓

So the optimal solution is x₁ = 25, x₂ = 33.33.

Total return = 12,000(25) + 10,000(33.33) = 300,000 + 333,333 = ₹633,333

5. REVISED CORNER POINT ANALYSIS
--------------------------------
Corner points of feasible region:
- (0, 0): Z = 0
- (0, 50): Z = 500,000
- (25, 33.33): Z = 633,333 ★ Optimal
- (50, 0): Z = 600,000
- (0, 0) is also a corner

Resource usage at optimal (25, 33.33):
- Labor: 3(25) + 2(33.33) = 75 + 66.67 = 141.67 hrs (slack: 58.33)
- Equipment: 2(25) + 3(33.33) = 50 + 100 = 150 hrs (fully used)
- Capital: 2,000(25) + 1,500(33.33) = 50,000 + 50,000 = 100,000 hrs (fully used)

6. KEY INSIGHTS
---------------
- Resource allocation problems involve distributing limited resources across competing activities.
- The optimal solution balances resource usage across multiple constraints.
- Some resources may have slack (unused capacity) at the optimum.
- The most valuable resources are those that are binding at the optimum.

7. REAL-WORLD APPLICATION
-------------------------
This type of problem applies to:
- Project selection and portfolio management
- Budget allocation across departments
- Staff scheduling and assignment
- Manufacturing resource planning

8. KEY TAKEAWAYS
-----------------
- Resource allocation is a fundamental LP application.
- Multiple resources compete for allocation.
- The optimal solution maximizes total return or minimizes cost.
- Binding resources have shadow prices indicating their value.
