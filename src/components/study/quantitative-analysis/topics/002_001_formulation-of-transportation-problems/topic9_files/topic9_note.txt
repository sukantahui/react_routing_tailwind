2. KEY CONCEPTS
================================================================================

Transportation Problem Fundamentals:
---------------------------------------------------------
- Optimal distribution of goods from sources to destinations
- Minimize total transportation cost
- Subject to supply and demand constraints
- Special structure of linear programming

Key Components:
---------------------------------------------------------
Sources: Supply points where goods originate
Destinations: Demand points where goods are needed
Cost Matrix: Per-unit transportation costs
Decision Variables: Quantities shipped
Supply Values: Capacity at sources
Demand Values: Requirements at destinations

Balance Condition:
---------------------------------------------------------
Balanced: ΣSᵢ = ΣDⱼ (ideal)
Unbalanced: ΣSᵢ ≠ ΣDⱼ (requires dummies)

3. SOLUTION METHODS
================================================================================

Initial Solution Methods:
---------------------------------------------------------
1. Northwest Corner Method:
   - Start at top-left corner
   - Simple but gives poor solution
   - Fast and easy to implement

2. Least Cost Method:
   - Start with cheapest cell
   - Better than northwest corner
   - Reasonably good initial solution

3. Vogel's Approximation Method (VAM):
   - Consider penalty costs
   - Best initial solution
   - Often close to optimal

Optimization Methods:
---------------------------------------------------------
1. Transportation Simplex Method:
   - Specialized simplex method
   - Efficient for transportation problems
   - Finds optimal solution

2. Modified Distribution (MODI) Method:
   - Checks optimality
   - Uses dual variables uᵢ and vⱼ
   - Calculates reduced costs

3. Stepping Stone Method:
   - Traces loops in transportation table
   - Finds improvement paths
   - Alternative to MODI

4. HANDLING UNBALANCED PROBLEMS
================================================================================

Surplus Supply (ΣSᵢ > ΣDⱼ):
---------------------------------------------------------
- Add dummy destination
- Dummy demand = surplus
- Zero costs from all sources
- Represents unused supply

Excess Demand (ΣDⱼ > ΣSᵢ):
---------------------------------------------------------
- Add dummy source
- Dummy supply = deficit
- Zero costs to all destinations
- Represents unmet demand

5. KEY PROPERTIES
================================================================================

Integrality Property:
---------------------------------------------------------
- Integer supplies and demands → integer optimal solution
- Due to totally unimodular constraint matrix
- Practical for real-world applications

Degeneracy:
---------------------------------------------------------
- Occurs when basic variables < m + n - 1
- Requires special handling (add epsilon)
- Can cause cycling in simplex method

6. ECONOMIC INTERPRETATIONS
================================================================================

Shadow Prices (Dual Variables):
---------------------------------------------------------
- uᵢ: Value of additional supply at source i
- vⱼ: Value of additional demand at destination j
- Used for sensitivity analysis
- Guide investment decisions

Dummy Allocations:
---------------------------------------------------------
- Dummy source: Unmet demand
- Dummy destination: Unused supply
- Reveal inefficiencies
- Guide capacity planning

7. COMMON MISTAKES
================================================================================

❌ Forgetting to Check Balance:
   Not verifying ΣSᵢ = ΣDⱼ before solving.

❌ Wrong Dummy Addition:
   Adding dummy source when dummy destination is needed.

❌ Incorrect Cost Matrix:
   Using wrong costs or placing them incorrectly.

❌ Ignoring Degeneracy:
   Not handling when basic variables < m + n - 1.

❌ Assuming Balance:
   Not checking and assuming balance exists.

❌ Misinterpreting Dummies:
   Thinking dummies represent real locations.
