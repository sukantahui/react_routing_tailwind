1. THE GLOBAL OPTIMALITY THEOREM
--------------------------------------------------------------------------------
In the Modified Distribution (MODI / u-v) Method, an Initial Basic Feasible
Solution (IBFS) is mathematically certified to be GLOBALLY OPTIMAL if and only if:

    d_ij = c_ij - (u_i + v_j) >= 0   (for ALL non-basic cells (i, j))

EQUIVALENCE TO DUAL LINEAR PROGRAMMING FEASIBILITY:
Because basic cells satisfy:
    u_i + v_j = c_ij
The condition d_ij >= 0 is mathematically identical to:
    u_i + v_j <= c_ij   (for all i = 1..m, j = 1..n)

By the Fundamental Duality Theorem & Complementary Slackness:
1. Primal Feasibility: Sum_j x_ij = S_i, Sum_i x_ij = D_j, x_ij >= 0 (Satisfied by IBFS).
2. Dual Feasibility: u_i + v_j <= c_ij (Satisfied when all d_ij >= 0).
3. Complementary Slackness: x_ij * [c_ij - (u_i + v_j)] = 0 (Satisfied because basic
   cells have c_ij - u_i - v_j = 0, and non-basic cells have x_ij = 0).

CONCLUSION:
When all d_ij >= 0, the primal-dual pair achieves ZERO DUALITY GAP:
    Minimum Total Cost Z = Maximum Dual Objective W
The solution is unconditionally certified as the absolute Global Minimum!

2. STRICT OPTIMALITY VS. ALTERNATIVE (MULTIPLE) OPTIMA
--------------------------------------------------------------------------------
CASE 1: STRICT OPTIMALITY (UNIQUE GLOBAL MINIMUM)
- Condition: ALL d_ij > 0 (strictly positive for every non-basic cell).
- Property: Every unoccupied route is strictly more expensive than the current
  basic path.
- Result: The optimal basic solution is UNIQUE. No other allocation matrix can
  match this minimal total cost Z.

CASE 2: ALTERNATIVE (MULTIPLE) OPTIMAL SOLUTIONS
- Condition: ALL d_ij >= 0, AND at least ONE non-basic cell has d_kl = 0.
- Property: Route (k, l) has direct cost that exactly equals the network shadow cost.
- Result: Shifting flow into cell (k, l) around a closed loop creates an
  ALTERNATIVE optimal allocation matrix with the EXACT SAME minimal total cost Z.
- Managerial Advantage: Gives operations managers flexibility to choose routes
  based on road quality, tolls, or weather without spending a single extra rupee!

--------------------------------------------------------------------------------
