1. THE FORMAL OPTIMALITY CERTIFICATE & COST FORMULA
--------------------------------------------------------------------------------
Once the Modified Distribution (MODI) algorithm reaches an iteration where ALL
opportunity costs satisfy:
    d_ij = c_ij - (u_i + v_j) >= 0   (for all non-basic cells (i, j))

The current basic feasible solution is mathematically certified to be GLOBALLY OPTIMAL.
The FINAL MINIMUM TRANSPORTATION COST Z* is calculated as:

    Z* = Sum_{i=1}^m Sum_{j=1}^n (c_ij * x_ij*)

Where:
• c_ij = Unit transportation cost along route (i, j) in Indian Rupees (₹).
• x_ij* = Optimal physical tonnage allocated to route (i, j).

STRONG DUALITY VERIFICATION (INDEPENDENT CHECK):
By the Strong Duality Theorem of Linear Programming, the optimal primal cost
must exactly equal the optimal dual objective value:
    Z* = W* = Sum_{i=1}^m (S_i * u_i*) + Sum_{j=1}^n (D_j * v_j*)
If Z* == W*, the arithmetic and basis structure are 100% verified!
