--------------------------------------------------------------------------------
1. THE 3 EQUIVALENT METHODS FOR COMPUTING THE VALUE OF THE GAME (v*)
--------------------------------------------------------------------------------
For any 2x2 Two-Person Zero-Sum Game A = [[a_11, a_12], [a_21, a_22]] without a saddle point:

METHOD 1: DETERMINANT OVER DELTA FORMULA
      v* = det(A) / Delta = (a_11 * a_22 - a_12 * a_21) / [ (a_11 + a_22) - (a_12 + a_21) ]

METHOD 2: EXPECTED PAYOFF SUBSTITUTION
      v* = E(p*, B_1) = p_1* * a_11 + p_2* * a_21
      v* = E(p*, B_2) = p_1* * a_12 + p_2* * a_22

METHOD 3: ODDMENTS INNER PRODUCT
      v* = (a_11 * O_A1 + a_21 * O_A2) / O_A
      v* = (a_12 * O_A1 + a_22 * O_A2) / O_A

All 3 methods yield 100% IDENTICAL numerical results in Indian Rupees (₹)!

--------------------------------------------------------------------------------
2. INTERPRETATION & ECONOMIC MEANING OF v*
--------------------------------------------------------------------------------
• IF v* > 0: Game is favorable to Player A (Row Maximizer secures positive expected profit in ₹).
• IF v* < 0: Game is favorable to Player B (Column Minimizer inflicts net expected loss on Player A in ₹).
• IF v* == 0: STRICTLY FAIR GAME (Neither player has an inherent advantage).

--------------------------------------------------------------------------------
3. FUNDAMENTAL BOUNDS ON THE VALUE OF THE GAME
--------------------------------------------------------------------------------
For any zero-sum matrix game:
      Maximin (alpha) <= v* <= Minimax (beta)
      min(a_ij) <= v* <= max(a_ij)

4. FOUR REAL-WORLD BENGAL CASE STUDIES

Debangshu in Barrackpore solved A = [[₹40k, ₹10k], [₹10k, ₹50k]].
det(A) = 2000 - 100 = 1900. Delta = 70.
Value of Game v* = 1900/70 = ₹27,142.86 (positive expected profit per shift).

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never forget to subtract the off-diagonal product (a12 * a21) in det(A).
- Check bounds: v* must always satisfy Maximin <= v* <= Minimax.
- In symmetric zero-sum games where A = -A^T, the game value v* is ALWAYS 0 (Fair Game).
- State all game values in Indian Rupees (₹).
