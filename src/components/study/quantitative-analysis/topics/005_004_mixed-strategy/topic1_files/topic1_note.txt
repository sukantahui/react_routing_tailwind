1. MATHEMATICAL FORMULATION OF PROBABILITY VECTORS
--------------------------------------------------------------------------------
In an m x n Two-Person Zero-Sum Game:

• PLAYER A PROBABILITY VECTOR (m Strategies):
      p = (p_1, p_2, ..., p_m)^T
  Subject to the 2 Fundamental Probability Axioms:
      1. Normalization:    sum_{i=1}^m p_i = p_1 + p_2 + ... + p_m = 1.0
      2. Non-Negativity:   p_i >= 0    for all i = 1, 2, ..., m

• PLAYER B PROBABILITY VECTOR (n Strategies):
      q = (q_1, q_2, ..., q_n)^T
  Subject to:
      1. Normalization:    sum_{j=1}^n q_j = q_1 + q_2 + ... + q_n = 1.0
      2. Non-Negativity:   q_j >= 0    for all j = 1, 2, ..., n

--------------------------------------------------------------------------------
2. GEOMETRY OF THE PROBABILITY SIMPLEX
--------------------------------------------------------------------------------

1. THE 2-STRATEGY SIMPLEX (Delta_1):
   • A 1-dimensional line segment joining corner vertex (1, 0) to vertex (0, 1).
   • Fully parameterized by a single variable p_1 in [0, 1], where p_2 = 1 - p_1.

2. THE 3-STRATEGY SIMPLEX (Delta_2):
   • A 2-dimensional equilateral triangle in 3D Euclidean space.
   • Vertices represent pure strategies: e_1 = (1,0,0), e_2 = (0,1,0), e_3 = (0,0,1).
   • Interior points represent completely mixed strategies (p_i > 0 for all i).

--------------------------------------------------------------------------------
3. VECTOR NORMALIZATION ALGORITHM
--------------------------------------------------------------------------------
If an analyst provides arbitrary non-negative relative weights w = (w_1, w_2, ..., w_m):
1. Compute the total weight sum:  W = sum_{i=1}^m w_i
2. Compute each probability:      p_i = w_i / W
3. Verify: sum p_i = 1.0 and p_i >= 0.

5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never use negative probabilities; all p_i must be >= 0.
- Ensure the sum of probabilities equals exactly 1.0 (watch for floating point rounding!).
- Pure strategies are simply basis vectors (e.g. p = (1, 0) or (0, 1)).
