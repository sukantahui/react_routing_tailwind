1. THE ODDMENTS METHOD (RULE OF DIFFERENCES)
--------------------------------------------------------------------------------
The ODDMENTS METHOD is a classical arithmetic short-cut for calculating the optimal
mixed strategies p* and q* for 2x2 games without writing simultaneous equations.

STEP-BY-STEP ODDMENTS PROCEDURE:

1. FOR PLAYER A (ROW ODDMENTS):
   - Subtract the elements of Row 2: |a_21 - a_22|. Place this value opposite Row 1.
   - Subtract the elements of Row 1: |a_11 - a_12|. Place this value opposite Row 2.
   - Sum of Row Oddments: O_A = |a_21 - a_22| + |a_11 - a_12|
   - Optimal Probabilities:
         p_1* = |a_21 - a_22| / O_A
         p_2* = |a_11 - a_12| / O_A

2. FOR PLAYER B (COLUMN ODDMENTS):
   - Subtract the elements of Column 2: |a_12 - a_22|. Place this value opposite Column 1.
   - Subtract the elements of Column 1: |a_11 - a_21|. Place this value opposite Column 2.
   - Sum of Column Oddments: O_B = |a_12 - a_22| + |a_11 - a_21|
   - Optimal Probabilities:
         q_1* = |a_12 - a_22| / O_B
         q_2* = |a_11 - a_21| / O_B

NOTE: The sum of row oddments O_A ALWAYS equals the sum of column oddments O_B = |Delta|!

--------------------------------------------------------------------------------
2. INVARIANCE PROPERTIES OF OPTIMAL PROBABILITIES
--------------------------------------------------------------------------------
1. SCALE INVARIANCE:
   • Multiplying all entries by k > 0 scales both oddments and denominator by k,
     leaving p* and q* 100% UNCHANGED.
2. SHIFT INVARIANCE:
   • Adding a constant c to all entries does not change the differences |a_ij - a_kl|,
     leaving p* and q* 100% UNCHANGED.

Row oddments: Row 1 = 60, Row 2 = 30. Total = 90.
Optimal ratio p* = [60/90, 30/90] = [2/3, 1/3], optimizing furnace allocation.

Optimal fleet split q* = [20/35, 15/35] = [4/7, 3/7], minimizing breakdown variance.

--------------------------------------------------------------------------------
4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never place Row 1's difference opposite Row 1! Remember to SWAP (cross-assign) differences!
- Never place Col 1's difference opposite Col 1! Cross-assign to Col 2!
- Always take ABSOLUTE differences (magnitudes must be positive).
- Verify that O_A == O_B == |Delta|.
