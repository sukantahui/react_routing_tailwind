--------------------------------------------------------------------------------
1. THE MASTER 2x2 CLOSED-FORM SOLUTION SYSTEM
--------------------------------------------------------------------------------
For any 2x2 Two-Person Zero-Sum Game without a saddle point:
      A = [ [a_11, a_12],
            [a_21, a_22] ]

1. THE COMMON DENOMINATOR (DELTA):
      Delta = (a_11 + a_22) - (a_12 + a_21)
      Delta = (Sum of Main Diagonal Elements) - (Sum of Off-Diagonal Elements)

2. OPTIMAL PROBABILITIES FOR PLAYER A (ROW MAXIMIZER):
      p_1* = (a_22 - a_21) / Delta
      p_2* = 1 - p_1* = (a_11 - a_12) / Delta

3. OPTIMAL PROBABILITIES FOR PLAYER B (COLUMN MINIMIZER):
      q_1* = (a_22 - a_12) / Delta
      q_2* = 1 - q_1* = (a_11 - a_21) / Delta

4. OPTIMAL VALUE OF THE GAME (v* in ₹):
      v* = (a_11 * a_22 - a_12 * a_21) / Delta = det(A) / Delta

--------------------------------------------------------------------------------
2. STEP-BY-STEP FIRST-PRINCIPLES DERIVATION
--------------------------------------------------------------------------------

DERIVING PLAYER A'S FORMULA (p_1*):
• Player A plays p = (p_1, 1 - p_1)^T.
• Expected Payoff vs Column B_1:  E(p, B_1) = p_1 * a_11 + (1 - p_1) * a_21
• Expected Payoff vs Column B_2:  E(p, B_2) = p_1 * a_12 + (1 - p_1) * a_22
• Equating expected payoffs (Indifference Principle):
      p_1 * a_11 + a_21 - p_1 * a_21 = p_1 * a_12 + a_22 - p_1 * a_22
      p_1 * (a_11 - a_21 - a_12 + a_22) = a_22 - a_21
      p_1 * [ (a_11 + a_22) - (a_12 + a_21) ] = a_22 - a_21
      p_1* = (a_22 - a_21) / Delta.  (Q.E.D.)

3. FOUR REAL-WORLD BENGAL CASE STUDIES
--------------------------------------------------------------------------------

CASE STUDY 1: Precision Foundry 2x2 Tender Solution (Debangshu)
Debangshu in Barrackpore solved A = [[₹40k, ₹10k], [₹10k, ₹50k]].
Delta = (40 + 50) - (10 + 10) = 70.
p_1* = (50 - 10)/70 = 4/7, p_2* = 3/7.
v* = (40*50 - 10*10)/70 = 1900/70 = ₹27,142.86.

q_1* = (40 - 15)/45 = 25/45 = 5/9, q_2* = 4/9.
v* = (30*40 - 15*10)/45 = 1050/45 = ₹23,333.33.

--------------------------------------------------------------------------------
4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never use these mixed strategy formulas if the game HAS a saddle point! (Always check Maximin == Minimax first!).
- Remember Delta = (Main Diag Sum) MINUS (Off Diag Sum); do not swap signs!
- Check that p_1 + p_2 = 1.0 and q_1 + q_2 = 1.0.
- State all game values and payoffs in Indian Rupees (₹).
