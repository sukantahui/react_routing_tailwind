INFINITE OPTIMAL SOLUTIONS
===============================================================================

TOPIC 51 – MAXIMUM FLEXIBILITY IN DECISION-MAKING

-------------------------------------------------------------------------------
1. WHAT ARE INFINITE OPTIMAL SOLUTIONS?
-------------------------------------------------------------------------------
Infinite optimal solutions occur when every point on an edge of the
feasible region gives the same optimal objective value.

- The objective function is parallel to a constraint edge
- The entire edge is optimal
- There are uncountably infinite optimal points

Key idea: Infinite optima = maximum flexibility!

-------------------------------------------------------------------------------
2. WHY INFINITE OPTIMA OCCUR
-------------------------------------------------------------------------------
1. The objective function has the same slope as a constraint
2. The objective line overlaps the constraint edge at the optimum
3. Every point on the edge gives the same objective value
4. There are infinitely many optimal points

-------------------------------------------------------------------------------
3. EXAMPLES
-------------------------------------------------------------------------------
Example 1: Maximization
  Z = x + y (slope = -1)
  Constraint: x + y = 10 (slope = -1)
  → Infinite optima on the entire edge
  Sample points: (10,0), (8,2), (6,4), (5,5), (4,6), (2,8), (0,10)

Example 2: With 3 Constraints
  Z = 2x + y (slope = -2)
  Constraint: 2x + y = 10 (slope = -2)
  → Infinite optima on the entire edge
  Sample points: (5,0), (4,2), (3,4), (2,6)

Example 3: Minimization
  C = x + y (slope = -1)
  Constraint: x + y = 5 (slope = -1)
  → Infinite optima on the entire edge
  Sample points: (0,5), (2.5,2.5), (5,0)

-------------------------------------------------------------------------------
4. KEY POINTS
-------------------------------------------------------------------------------
✓ Infinite optima occur when the objective is parallel to a constraint
✓ The entire edge is optimal
✓ There are infinitely many optimal points
✓ This provides maximum flexibility to decision-makers
✓ Any point on the optimal edge is equally good

-------------------------------------------------------------------------------
5. COMMON MISTAKES
-------------------------------------------------------------------------------
✗ Not recognizing that the entire edge is optimal
✗ Assuming infinite optima means the problem is unbounded
✗ Forgetting to mention the entire edge is optimal
✗ Only stating the corner points, missing the continuum
✗ Confusing infinite optima with unbounded solutions

-------------------------------------------------------------------------------
6. BEST PRACTICES
-------------------------------------------------------------------------------
✓ Identify if the objective is parallel to a constraint
✓ State that all points on the optimal edge are optimal
✓ Provide sample points to illustrate the continuum
✓ Explain the flexibility infinite optima provide
✓ Distinguish between infinite optima and unbounded solutions
