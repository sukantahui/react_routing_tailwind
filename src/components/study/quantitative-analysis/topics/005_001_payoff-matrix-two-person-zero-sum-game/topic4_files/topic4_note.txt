--------------------------------------------------------------------------------
1. DEFINITION & MATHEMATICAL AXIOMS OF A TPZSG
--------------------------------------------------------------------------------
A TWO-PERSON ZERO-SUM GAME (TPZSG) is a strategic game involving exactly two rational
opponents (Player A and Player B) where total wealth, score, or utility is strictly conserved:

        u_A(s_A, s_B) + u_B(s_A, s_B) = 0   for all strategy pairs (s_A, s_B)
   ==>  u_B(s_A, s_B) = -u_A(s_A, s_B)

CORE PROPERTY:
• Pure competitive conflict: Every rupee won by Player A is an exact loss conceded by Player B.

--------------------------------------------------------------------------------
2. VON NEUMANN'S MINIMAX THEOREM (1928 / 1944)
--------------------------------------------------------------------------------
For every finite two-person zero-sum game represented by matrix A = [a_ij]_{m x n},
there exists a UNIQUE real number v* (the Value of the Game in ₹) and optimal mixed
strategy vectors p* = (p_1*, ..., p_m*) and q* = (q_1*, ..., q_n*) such that:

        max_p min_q (p^T * A * q) = min_q max_p (p^T * A * q) = v*

SIGNIFICANCE:
• Guarantees that every zero-sum matrix game has an optimal, unexploitable solution!

--------------------------------------------------------------------------------
3. STRICTLY VS. NON-STRICTLY DETERMINED GAMES
--------------------------------------------------------------------------------

1. STRICTLY DETERMINED GAME:
   • Maximin == Minimax == v* (Pure Strategy Saddle Point exists).
   • Optimal strategies: Pure strategy row i* for Player A, pure strategy column j* for Player B.
   • Neither player has any incentive to randomize or deviate.

2. NON-STRICTLY DETERMINED GAME:
   • Maximin < Minimax (No Pure Saddle Point).
   • Players MUST randomize over actions using mixed strategies (p*, q*) to achieve equilibrium v*.

--------------------------------------------------------------------------------
4. VALUE OF THE GAME (v*) CLASSIFICATION
--------------------------------------------------------------------------------
• v* > 0 (Biased toward Player A): Player A expects to win ₹v* per round under optimal play.
• v* < 0 (Biased toward Player B): Player B expects to win ₹|v*| per round (Player A loses ₹|v*|).
• v* = 0 (FAIR GAME): Neither player has a structural advantage.

--------------------------------------------------------------------------------
6. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never assume a zero-sum game is unfair simply because payoffs are large; check if v* = 0.
- If Maximin == Minimax, do NOT use mixed strategy formulas; the saddle point gives the exact solution.
- Constant-sum games (u_A + u_B = C) can be converted to zero-sum by subtracting C/2 from all cells.
- State all game values and security floors in Indian Rupees (₹).
