1. COMPLETE 8-TOPIC MODULE ARCHITECTURE RECAPITULATION
--------------------------------------------------------------------------------
This module has formulated the complete foundational mechanics of Payoff Matrices
and Two-Person Zero-Sum Games:

• TOPIC 0: INTRODUCTION TO GAME THEORY
  - Strategic interaction among rational players vs single-agent optimization.
  - 5 structural elements: Players, Strategies, Information, Payoffs (₹), Rationality.
  - Game taxonomy: Zero-Sum vs Non-Zero-Sum, Simultaneous vs Sequential, Cooperative vs Non-Cooperative.

• TOPIC 1: PLAYERS AND STRATEGIES
  - Player A (Row Maximizer) vs Player B (Column Minimizer).
  - Pure Strategy (deterministic, p = 1.0) vs Mixed Strategy (probabilistic, sum p_i = 1.0).
  - Strictly Dominant vs Dominated strategies.

• TOPIC 2: PAYOFF CONCEPT
  - Numerical utility and monetary returns in Indian Rupees (₹).
  - VNM Expected Utility Theory and Expected Payoff formula: E(p, q) = p^T A q.
  - Zero-Sum Conservation: u_A + u_B = 0 and E_A + E_B = 0.

• TOPIC 3: PAYOFF MATRIX
  - Rectangular array A = [a_ij]_{m x n}.
  - Row Minima vector (min_j a_ij) and Column Maxima vector (max_i a_ij).
  - Maximin Value (alpha = v_lower) and Minimax Value (beta = v_upper).
  - Universal Invariant: Maximin <= Minimax (v_lower <= v_upper).

• TOPIC 4: TWO-PERSON ZERO-SUM GAME
  - John von Neumann's Minimax Theorem (1928): max min = min max = v*.
  - Strictly Determined Games (Saddle Points) vs Non-Strictly Determined Games.
  - Fair Games (v* = 0).

• TOPIC 5: INTERPRETATION OF PAYOFF ENTRIES
  - Universal sign convention (+ = gain to A, - = loss to A).
  - Capital flows between players.
  - Linear Transformation Invariance: a' = k*a + c preserves strategies and saddle points.

• TOPIC 6: FORMULATING SIMPLE GAME MATRICES
  - 4-step formulation pipeline: Players → Strategies → Net Payoffs (₹) → Assemble Matrix.
  - Real-world paradigms: Tenders, Advertising, Retail Price Matching, Legal Disputes.

• TOPIC 7: SHORT QUESTIONS & VIVA VOCE SYNTHESIS
  - Comprehensive flashcards, high-yield examination review, and theoretical mastery.

2. MASTER FORMULA & THEOREM QUICK REFERENCE TABLE
--------------------------------------------------------------------------------
Concept / Parameter          | Mathematical Formula / Governing Rule
--------------------------------------------------------------------------------
Zero-Sum Property            | u_A(s_A, s_B) + u_B(s_A, s_B) = 0   ==>  u_B = -u_A
Expected Payoff (Mixed)      | E(p, q) = sum_{i=1}^m sum_{j=1}^n p_i * q_j * a_ij = p^T * A * q
Probability Vector (Player A)| p = (p_1, ..., p_m),   p_i >= 0,   sum_{i=1}^m p_i = 1.0
Probability Vector (Player B)| q = (q_1, ..., q_n),   q_j >= 0,   sum_{j=1}^n q_j = 1.0
Row Minimum (Security Level) | Row Min_i = min_{j} a_ij
Column Maximum (Liability)   | Col Max_j = max_{i} a_ij
Maximin Value (v_lower)      | alpha = max_{i} [ min_{j} a_ij ]
Minimax Value (v_upper)      | beta = min_{j} [ max_{i} a_ij ]
Universal Inequality        | Maximin <= Minimax   <==>   v_lower <= v_upper
Saddle Point Condition       | Maximin == Minimax == v*   (at cell (i*, j*))
Minimax Theorem (von Neumann)| max_p min_q (p^T A q) = min_q max_p (p^T A q) = v*
Linear Transformation        | a'_ij = k * a_ij + c (k > 0)  ==>  v'* = k * v* + c
Fair Game Condition          | Value of the Game v* = ₹0
