TOPIC 4: TRANSLATING VERBAL CONDITIONS INTO MATHEMATICAL CONSTRAINTS
====================================================================

INTRODUCTION
------------
Translation is the process of converting word problems into mathematical 
LP formulations. This is the most critical skill in applying LP to 
real-world problems.

WHY TRANSLATION MATTERS
-----------------------
1. Bridges theory and practice
2. Enables solving real-world problems
3. Requires understanding of both language and math
4. Develops analytical thinking

KEY TRANSLATION ELEMENTS
------------------------
1. Decision Variables:
   - What are you deciding?
   - Example: x = chairs, y = tables

2. Objective Function:
   - What are you optimizing?
   - "Maximize" or "Minimize"
   - Example: Max Z = 40x + 50y

3. Constraints:
   - What limits the solution?
   - Resource constraints (≤)
   - Requirement constraints (≥)
   - Equality constraints (=)

VERBAL TO MATHEMATICAL GUIDE
----------------------------
| Verbal Phrase | Math | Example |
|--------------|------|---------|
| At most, No more than | ≤ | x + y ≤ 10 |
| At least, Minimum | ≥ | x + y ≥ 8 |
| Exactly, Equal to | = | x + y = 12 |
| Available, Limited | ≤ | 2x + 3y ≤ 120 |
| Requirement, Must have | ≥ | 4x + 2y ≥ 24 |
| Profit per unit | Coefficient | 40x |
| Cost per unit | Coefficient | 20x |
| Percentage | Linear form | x ≥ 0.4(x+y) |

STEPS TO TRANSLATE
------------------
Step 1: Read Carefully
- Identify what you're trying to decide
- Identify what you're optimizing
- Identify all limitations

Step 2: Define Variables
- Choose clear variable names
- Include units
- Example: Let x = number of chairs

Step 3: Identify Objective
- Look for "maximize" or "minimize"
- Determine coefficients (profit/cost per unit)

Step 4: Identify Constraints
- Resource constraints (≤)
- Requirement constraints (≥)
- Special constraints (ratios, percentages)

Step 5: Add Non-Negativity
- x ≥ 0, y ≥ 0

Step 6: Verify
- Check each constraint matches the verbal condition
- Verify units are consistent

COMMON MISTAKES
---------------
1. Mixing up ≤ and ≥
2. Forgetting non-negativity
3. Misidentifying the objective
4. Incorrectly translating percentages
5. Missing constraints

PERCENTAGE CONSTRAINTS
----------------------
To translate percentage constraints:
1. Write the percentage condition
2. Convert to linear form
3. Simplify

Example: A must be at least 40% of total
x ≥ 0.4(x + y)
x ≥ 0.4x + 0.4y
0.6x ≥ 0.4y
3x ≥ 2y

RATIO CONSTRAINTS
-----------------
To translate ratio constraints:
1. Write the ratio condition
2. Convert to linear form
3. Simplify

Example: x to y must be at least 2:1
x/y ≥ 2
x ≥ 2y

BEST PRACTICES
--------------
1. Read problem multiple times
2. Underline key phrases
3. Write variables with units
4. Check constraint directions
5. Verify formulation
6. Practice regularly

TEACHER'S NOTE
--------------
Translation is the most critical skill in LP. I emphasize that 
students should practice regularly, as this skill improves with 
experience. The key is to look for "clue words" that indicate 
what type of constraint or objective is being described."
