--------------------------------------------------------------------------------
1. DEFINITION & PHILOSOPHY OF THE MINIMAX PRINCIPLE
--------------------------------------------------------------------------------
The MINIMAX PRINCIPLE is a loss-capping, liability-minimizing decision criterion
adopted by PLAYER B (Column Player / Minimizer).

PHILOSOPHICAL PREMISE:
• Player B assumes that for whichever column strategy B_j they choose, the intelligent,
  rational opponent (Player A) will select the row that maximizes Player A's payoff.
• Therefore, Player B seeks to MINIMIZE their MAXIMUM payout liability (Mini-Max).

--------------------------------------------------------------------------------
2. THE 2-STAGE COMPUTATIONAL ALGORITHM
--------------------------------------------------------------------------------
Given an m x n Payoff Matrix A = [a_ij]:

• STAGE 1: COMPUTE COLUMN MAXIMA (VERTICAL MAXIMIZATION):
  - For each column j = 1, 2, ..., n, determine:
        Col Max_j = max_{i=1}^m a_ij
  - Represents Player B's worst-case payout liability if strategy B_j is chosen.

• STAGE 2: COMPUTE MINIMAX VALUE (HORIZONTAL MINIMIZATION):
  - Identify the minimum among all column maxima:
        Minimax (beta) = min_{j=1}^n [ Col Max_j ]
                       = min_{j=1}^n [ max_{i=1}^m a_ij ]
                       = v_upper (Upper Value of the Game in ₹)

• STAGE 3: SELECT MINIMAX STRATEGY:
  - The column j* corresponding to beta is Player B's optimal Minimax Strategy.

--------------------------------------------------------------------------------
3. THE UPPER VALUE OF THE GAME (v_upper) GUARANTEE
--------------------------------------------------------------------------------
By selecting the Minimax column j*:
• Player B is MATHEMATICALLY GUARANTEED to concede AT MOST v_upper in Indian Rupees (₹),
  regardless of what Player A chooses:
        Actual Payout u_A(A_i, B_j*) <= v_upper    for all i = 1, ..., m
• If Player A plays sub-optimally, Player B's actual payout will be strictly LESS than v_upper.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Always find the MAXIMUM down columns first, then find the MINIMUM of those maxima.
- Do not confuse Minimax (Player B) with Maximin (Player A).
- The Minimax value v_upper can be positive, negative, or zero.
- State all liability ceilings and payouts with the Indian Rupee (₹) symbol.
