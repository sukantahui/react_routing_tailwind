--------------------------------------------------------------------------------
1. DEFINITION & PHILOSOPHY OF THE MAXIMIN PRINCIPLE
--------------------------------------------------------------------------------
The MAXIMIN PRINCIPLE is a conservative, security-first decision criterion adopted
by PLAYER A (Row Player / Maximizer).

PHILOSOPHICAL PREMISE:
• Player A assumes that for whichever row strategy A_i they choose, the intelligent,
  rational opponent (Player B) will select the column that minimizes Player A's payoff.
• Therefore, Player A seeks to MAXIMIZE their MINIMUM guaranteed payoff (Max-Min).

--------------------------------------------------------------------------------
2. THE 2-STAGE COMPUTATIONAL ALGORITHM
--------------------------------------------------------------------------------
Given an m x n Payoff Matrix A = [a_ij]:

• STAGE 1: COMPUTE ROW MINIMA (HORIZONTAL MINIMIZATION):
  - For each row i = 1, 2, ..., m, determine:
        Row Min_i = min_{j=1}^n a_ij
  - Represents Player A's guaranteed security floor for strategy A_i.

• STAGE 2: COMPUTE MAXIMIN VALUE (VERTICAL MAXIMIZATION):
  - Identify the maximum among all row minima:
        Maximin (alpha) = max_{i=1}^m [ Row Min_i ]
                        = max_{i=1}^m [ min_{j=1}^n a_ij ]
                        = v_lower (Lower Value of the Game in ₹)

• STAGE 3: SELECT MAXIMIN STRATEGY:
  - The row i* corresponding to alpha is Player A's optimal Maximin Strategy.

--------------------------------------------------------------------------------
3. THE LOWER VALUE OF THE GAME (v_lower) GUARANTEE
--------------------------------------------------------------------------------
By selecting the Maximin row i*:
• Player A is MATHEMATICALLY GUARANTEED to receive AT LEAST v_lower in Indian Rupees (₹),
  regardless of what Player B chooses:
        Actual Payoff u_A(A_i*, B_j) >= v_lower    for all j = 1, ..., n
• If Player B plays sub-optimally, Player A's actual payoff will be strictly GREATER than v_lower.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Always find the MINIMUM across rows first, then find the MAXIMUM of those minima.
- Do not confuse Maximin (Player A) with Minimax (Player B).
- The Maximin value v_lower can be positive, negative, or zero.
- State all security levels and payoffs with the Indian Rupee (₹) symbol.
