--------------------------------------------------------------------------------
1. DEFINITION & SIGNIFICANCE OF THE VALUE OF THE GAME (v*)
--------------------------------------------------------------------------------
The VALUE OF THE GAME (denoted by v*) is the mathematical expected monetary return
received by PLAYER A (and conceded by PLAYER B) when BOTH players execute their
respective optimal strategies in Indian Rupees (₹).

IN STRICTLY DETERMINED GAMES:
• When a Saddle Point (i*, j*) exists:
      v* = a_i*j* = Maximin (alpha) = Minimax (beta)

IN NON-STRICTLY DETERMINED GAMES:
• Determined via mixed strategy equilibrium:
      v* = p*^T * A * q*

--------------------------------------------------------------------------------
2. THE FUNDAMENTAL BOUNDING THEOREM
--------------------------------------------------------------------------------
For every two-person zero-sum game, the true Value of the Game is strictly bounded:

      v_lower <= v* <= v_upper
  i.e.,  max_{i} min_{j} a_ij <= v* <= min_{j} max_{i} a_ij

SIGNIFICANCE:
• Player A can never be held below v_lower.
• Player B can never be forced above v_upper.
• If v_lower == v_upper, then v* = v_lower = v_upper (Saddle Point!).

--------------------------------------------------------------------------------
3. CLASSIFICATION BY GAME VALUE (FAIRNESS SPECTRUM)
--------------------------------------------------------------------------------

1. FAIR GAME (v* == ₹0):
   • Neither player holds an inherent mathematical advantage.
   • Under optimal play, expected net wealth transfer is zero.

2. BIASED IN FAVOR OF PLAYER A (v* > ₹0):
   • Player A expects to win ₹v* per round under optimal play.
   • Player B must concede ₹v* per round.

3. BIASED IN FAVOR OF PLAYER B (v* < ₹0):
   • Player B expects to win ₹|v*| per round (Player A loses ₹|v*|).

--------------------------------------------------------------------------------
4. LINEAR TRANSFORMATION OF GAME VALUE
--------------------------------------------------------------------------------
If matrix A is transformed by a'_ij = k * a_ij + c (where k > 0):
      v'* = k * v* + c

6. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never confuse the Value of the Game with individual cell payoffs; v* is the EQUILIBRIUM outcome.
- A game with negative payoffs can still be positive in value (v* > 0).
- When a constant c is added during calculation, subtract c to get the true economic game value!
- State all game values and fairness metrics with the Indian Rupee (₹) symbol.
