1. INTRODUCTION TO DUALITY PROPERTIES
================================================================================

Definition:
Basic duality properties are the fundamental mathematical characteristics that 
define the relationship between primal and dual problems. They form the 
theoretical foundation of linear programming and are essential for 
understanding, solving, and interpreting optimization problems.

The Four Basic Properties:
---------------------------------------------------------
1. Weak Duality: Bounding property
2. Strong Duality: Equality at optimality
3. Complementary Slackness: Link between solutions
4. Symmetry Property: Dual of dual is primal

2. WEAK DUALITY
================================================================================

Statement:
For any feasible primal solution x and any feasible dual solution y:
- If Primal is Maximization: Z(x) ≤ W(y)
- If Primal is Minimization: W(y) ≤ Z(x)

Mathematical Proof:
---------------------------------------------------------
For Standard Form (Max Primal, Min Dual):
Z = cᵀx ≤ yᵀAx ≤ yᵀb = W

This shows:
- cᵀx ≤ yᵀAx (from dual constraint Aᵀy ≥ c)
- yᵀAx ≤ yᵀb (from primal constraint Ax ≤ b)

Implications:
---------------------------------------------------------
1. Bounding: Dual provides an upper/lower bound on primal
2. Feasibility Check: Z > W (for max) indicates non-optimality
3. Optimality Certificate: Any feasible dual solution works
4. Algorithm Stopping: Used in optimization algorithms

3. STRONG DUALITY
================================================================================

Statement:
If both primal and dual have optimal solutions:
Z* = W*

Conditions:
---------------------------------------------------------
1. Feasibility: Both problems have feasible solutions
2. Boundedness: Objective values are finite
3. For Non-linear: Convexity and constraint qualification

Implications:
---------------------------------------------------------
1. Zero Duality Gap: Difference is zero at optimality
2. Optimality Guarantee: Both problems give same value
3. Solution Verification: Used to check optimality
4. Algorithm Foundation: Basis for many algorithms

4. COMPLEMENTARY SLACKNESS
================================================================================

Statement:
At optimality, for all i and j:
- yᵢ × (bᵢ - Aᵢx) = 0
- xⱼ × (Aⱼᵀy - cⱼ) = 0

Interpretation:
---------------------------------------------------------
Primal Perspective:
- If slack > 0 (constraint loose) → yᵢ = 0
- If yᵢ > 0 → constraint is tight (slack = 0)

Dual Perspective:
- If dual constraint slack > 0 → xⱼ = 0
- If xⱼ > 0 → dual constraint is tight

Economic Meaning:
---------------------------------------------------------
1. Scarce resources (fully used) have positive shadow prices
2. Surplus resources have zero shadow prices
3. Products produced have zero reduced cost
4. Products not produced have positive reduced cost

5. SYMMETRY PROPERTY
================================================================================

Statement:
The dual of the dual problem is the original primal problem.

Mathematical Proof:
---------------------------------------------------------
Start with primal (standard form):
Max Z = cᵀx, s.t. Ax ≤ b, x ≥ 0

The dual is:
Min W = bᵀy, s.t. Aᵀy ≥ c, y ≥ 0

The dual of this dual:
Max Z = cᵀx, s.t. Ax ≤ b, x ≥ 0

Which is the original primal.

Implications:
---------------------------------------------------------
1. Perfect Symmetry: Relationship is completely symmetric
2. Choice of Formulation: Can solve either problem
3. Economic Equivalence: Consistent interpretation
4. Theoretical Foundation: Confirms mathematical validity

6. INTERRELATIONSHIP OF THE PROPERTIES
================================================================================

How They Work Together:
---------------------------------------------------------
1. Weak Duality → Gives bounds on the problem
2. Strong Duality → Shows where optimum lies
3. Complementary Slackness → Connects optimal solutions
4. Symmetry → Provides flexibility in solving

Practical Use in Problem Solving:
---------------------------------------------------------
1. Start with weak duality for bounds
2. Use strong duality to confirm optimality
3. Apply complementary slackness for verification
4. Leverage symmetry for solving efficiency

8. COMMON MISTAKES
================================================================================

1. Misapplying Weak Duality:
   - Only applies to feasible solutions
   - Don't use with infeasible solutions

2. Assuming Strong Duality Always Holds:
   - Requires feasibility and boundedness
   - Check conditions before applying

3. Misapplying Complementary Slackness:
   - Only holds at optimality
   - Don't apply to non-optimal solutions

4. Forgetting Symmetry Conditions:
   - Requires standard form
   - Mixed constraints break symmetry

5. Confusing Weak and Strong Duality:
   - Weak: bounds for all feasible solutions
   - Strong: equality at optimality

9. BEST PRACTICES
================================================================================

   - Verify weak duality for any feasible solutions
