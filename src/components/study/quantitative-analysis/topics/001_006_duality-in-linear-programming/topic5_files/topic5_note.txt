2. KEY CONCEPTS
================================================================================

Basic Definitions:
---------------------------------------------------------
Primal Problem:
- The original optimization problem
- Focuses on decision variables and constraints
- Answers "what to do"

Dual Problem:
- The companion problem derived from the primal
- Focuses on resource valuation (shadow prices)
- Answers "what resources are worth"

Shadow Price:
- Marginal value of a resource
- How much objective improves with one additional unit
- Economic value of the resource

Duality Gap:
- Difference between primal and dual values
- Z - W (for maximization)
- Zero at optimality

3. DUAL FORMATION RULES
================================================================================

Optimization Direction:
---------------------------------------------------------
- Max Primal → Min Dual
- Min Primal → Max Dual

Variable-Constraint Swap:
---------------------------------------------------------
- Primal constraints → Dual variables
- Primal variables → Dual constraints

Coefficient Swap:
---------------------------------------------------------
- Primal RHS (b) → Dual objective coefficients
- Primal objective (c) → Dual RHS

Sign Restrictions:
---------------------------------------------------------
- ≤ constraints → y ≥ 0
- ≥ constraints → y ≤ 0  
- = constraints → y free (unrestricted)

4. FOUR BASIC PROPERTIES
================================================================================

1. Weak Duality:
---------------------------------------------------------
- For any feasible x and y
- Max: Z(x) ≤ W(y)
- Min: W(y) ≤ Z(x)
- Dual provides bounds on primal

2. Strong Duality:
---------------------------------------------------------
- At optimality: Z* = W*
- Requires feasibility and boundedness
- Zero duality gap
- Confirms optimality

3. Complementary Slackness:
---------------------------------------------------------
- At optimality: yᵢ × slackᵢ = 0
- Tight constraints have positive shadow prices
- Loose constraints have zero shadow prices
- Links primal and dual solutions

4. Symmetry Property:
---------------------------------------------------------
- Dual(Dual(Primal)) = Primal
- Perfect symmetry in standard form
- Can solve either formulation
- Consistent economic interpretation

5. ECONOMIC INTERPRETATIONS
================================================================================

Shadow Prices:
---------------------------------------------------------
- Positive: Resource is scarce and valuable
- Zero: Resource is abundant and surplus
- Represents marginal value of resources
- Guides investment decisions

Dual Objective:
---------------------------------------------------------
- Total value of all resources
- Sum of (Resource quantity × Shadow price)
- Equals primal objective at optimality
- Shows total resource value

Dual Constraints:
---------------------------------------------------------
- Fair pricing conditions
- Resource cost ≥ Product price
- Prevents unprofitable production
- Guides product decisions

7. COMMON MISTAKES
================================================================================

1. Wrong Optimization Direction:
   - Forgetting that dual takes opposite direction
   - Max → Min, Min → Max

2. Incorrect Sign Restrictions:
   - Misplacing y ≥ 0 vs y ≤ 0
   - ≤ constraints → y ≥ 0, ≥ constraints → y ≤ 0

3. Variable Count Mismatch:
   - Creating wrong number of variables/constraints
   - Dual variables = Primal constraints
   - Dual constraints = Primal variables

4. Confusing Shadow Prices with Market Prices:
   - Shadow prices are internal values
   - Market prices are external
   - Don't mix them up

5. Misapplying Complementary Slackness:
   - Only applies at optimality
   - Don't use for non-optimal solutions

9. QUICK REFERENCE
================================================================================

Key Relationships:
---------------------------------------------------------
- Weak Duality: Z ≤ W (for max)
- Strong Duality: Z* = W*
- Complementary Slackness: yᵢ × slackᵢ = 0
- Symmetry: Dual(Dual) = Primal

Key Conversions:
---------------------------------------------------------
- Max → Min (and vice versa)
- Constraints → Variables
- Variables → Constraints
- RHS → Objective (and vice versa)
- A → Aᵀ

Key Economic Terms:
---------------------------------------------------------
- Shadow Price = Marginal value of resource
- Duality Gap = Z - W (for max)
- Opportunity Cost = Shadow price
- Economic Rent = Shadow price
