1. FORMAL OBJECTIVE FUNCTION FORMULATION
================================================================================

Definition:
The total initial transportation cost Z is the linear sum of all individual 
route expenditures incurred by the Initial Basic Feasible Solution (IBFS):

   Z = ∑_{i=1}^m ∑_{j=1}^n (c_ij · x_ij)

Where:
- c_ij is the unit freight rate from Origin i to Destination j (in ₹/unit).
- x_ij is the quantity of goods allocated to cell (i, j).
- m is the number of supply origins.
- n is the number of demand destinations.

Key Observations:
1. Non-Basic Cells (Unoccupied):
   For all unallocated cells, x_ij = 0. Therefore, c_ij · 0 = ₹0.
2. Basic Cells (Occupied):
   Only the exactly m + n - 1 basic variables contribute non-zero values to Z.
3. Dummy Allocations:
   Allocations to virtual dummy destinations with c_i,dummy = ₹0 contribute 
   x_i,dummy · ₹0 = ₹0 to total freight cost.


2. STEP-BY-STEP ARITHMETIC CALCULATION PROCEDURE
================================================================================

Step 1: Identify All Basic Allocated Cells
- List every cell (i, j) where x_ij > 0.
- Verify that total count of allocated cells equals m + n - 1.

Step 2: Compute Individual Route Costs (Subtotals)
- Multiply the allocated quantity by the corresponding unit freight rate:
    Cost_(i, j) = x_ij × c_ij (in ₹)

Step 3: Sum All Subtotals
- Add all individual product terms together to obtain the grand initial cost Z:
    Z = Cost_1 + Cost_2 + ... + Cost_(m+n-1)

Step 4: Compute Average Unit Shipping Cost
- Average Freight Rate = Z / Total Flow (in ₹/unit).


3. FOUR REAL-WORLD CASE STUDIES (WITH ₹ CURRENCY)
================================================================================

Case Study 1: Heavy Fasteners Logistics (Debangshu)
--------------------------------------------------------------------------------
Origins: Barrackpore (50 tons), Ichapur (70 tons)
Destinations: Kolkata (40), Jadavpur (50), Salt Lake (30) | Total Flow = 120 tons

Itemized Cost Breakdown:
  1. Route (Ichapur → Jadavpur):     50 tons × ₹3/ton  = ₹150
  2. Route (Barrackpore → Kolkata):  40 tons × ₹4/ton  = ₹160
  3. Route (Ichapur → Salt Lake):    20 tons × ₹5/ton  = ₹100
  4. Route (Barrackpore → Salt Lake):10 tons × ₹6/ton  = ₹60
--------------------------------------------------------------------------------
  Total Initial Transportation Cost Z = ₹150 + ₹160 + ₹100 + ₹60 = ₹470.
  Average Freight Rate = ₹470 / 120 tons = ₹3.92 per ton.
  (NWCR Baseline = ₹670; Matrix Minima saves ₹200 or 29.8%).

5. COMMON PITFALLS & BEST PRACTICES
================================================================================

Common Mistakes:
1. Omitting an Allocated Cell: Forgetting one of the m + n - 1 product terms.
2. Multiplying Remaining Balances Instead of Assigned Volume: Using remaining S_k 
   instead of actual allocated x_kl.
3. Adding Unit Rates Directly: Adding c_ij values without multiplying by volume.

Best Practices:
1. Itemize each route subtotal on its own line before summing.
2. Label all monetary totals with the Rupee symbol (₹).
3. Count the number of summed terms; it must equal exactly m + n - 1.
