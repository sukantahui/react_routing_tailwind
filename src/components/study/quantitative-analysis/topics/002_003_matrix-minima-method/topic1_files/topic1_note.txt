1. ALGORITHM OVERVIEW & FORMAL DEFINITION
================================================================================

Definition:
The Matrix Minima Method (also known as the Least-Cost Method or Inspection Method)
is an iterative algorithm designed to construct an Initial Basic Feasible Solution 
(IBFS) for transportation linear programming models.

Core Mechanism:
At each iteration, the algorithm scans the entire active 2D cost matrix C = [c_ij]
to identify the cell with the globally lowest unit transportation cost, assigns 
the maximum feasible quantity min(S_k, D_l), updates remaining capacities, and 
eliminates the exhausted origin row or satisfied destination column.

Mathematical Objective:
   Minimize Z = ∑_{i=1}^m ∑_{j=1}^n c_ij · x_ij

Subject to:
   ∑_{j=1}^n x_ij = S_i  (Supply conservation for all origins i = 1, ..., m)
   ∑_{i=1}^m x_ij = D_j  (Demand conservation for all destinations j = 1, ..., n)
   x_ij ≥ 0              (Non-negative shipment quantities)
   ∑_{i=1}^m S_i = ∑_{j=1}^n D_j (Balanced Transportation Condition)


2. FORMAL ALGORITHM PSEUDOCODE & EXECUTION PIPELINE
================================================================================

Algorithm: MatrixMinima(CostMatrix C[m][n], Supply S[m], Demand D[n])
--------------------------------------------------------------------------------
1. Verify Balance:
   If ∑ S_i != ∑ D_j, introduce a dummy row/column with unit cost ₹0.

2. Initialize:
   Set X[m][n] = 0 for all i, j.
   Set RowActive[1..m] = true, ColActive[1..n] = true.
   Set AllocationsCount = 0.

3. While (Any RowActive[i] == true AND Any ColActive[j] == true):
   a. Find Cell (k, l) such that:
      c_kl = min { c_ij | RowActive[i] == true and ColActive[j] == true }
      (Apply tie-breaking rules if multiple cells share min cost).

   b. Determine Allocation Quantity:
      AllocQuantity = min(S[k], D[l])
      X[k][l] = AllocQuantity
      AllocationsCount = AllocationsCount + 1

   c. Update Balances:
      S[k] = S[k] - AllocQuantity
      D[l] = D[l] - AllocQuantity

   d. Line Elimination & Degeneracy Guard:
      - Case 1 (S[k] == 0 and D[l] > 0):
        RowActive[k] = false (Row k is exhausted).
      - Case 2 (D[l] == 0 and S[k] > 0):
        ColActive[l] = false (Column l is satisfied).
      - Case 3 (S[k] == 0 and D[l] == 0 and not all lines finished):
        RowActive[k] = false
        Assign X[r][l] = ε (infinitesimal zero) to an unassigned active cell r
        ColActive[l] = false

4. Compute Objective Function Value:
   Total Freight Bill Z = ∑_{i=1}^m ∑_{j=1}^n (c_ij · X[i][j])

5. Return Allocation Matrix X and Total Cost Z.

Case Study 1: Kolkata-Barrackpore Heavy Fasteners Logistics
--------------------------------------------------------------------------------
Lead Engineer: Debangshu
Origins:
  - S1: Barrackpore Plant (Supply = 50 tons)
  - S2: Ichapur Foundry (Supply = 70 tons)
Destinations:
  - D1: Kolkata Metro Depot (Demand = 40 tons)
  - D2: Jadavpur Distribution Hub (Demand = 50 tons)
  - D3: Salt Lake Electronics Park (Demand = 30 tons)
Total Supply = 120 tons | Total Demand = 120 tons (Balanced)

Cost Matrix (₹ per ton):
                 D1 (Kolkata)   D2 (Jadavpur)   D3 (Salt Lake)   Supply
  S1 (Barrack.)       ₹4             ₹8              ₹6            50
  S2 (Ichapur)        ₹7             ₹3              ₹5            70
  Demand              40             50              30           120

Execution Steps:
  - Step 1: Global min cost is ₹3 at cell (S2, D2) [Ichapur → Jadavpur].
    Allocate x_22 = min(70, 50) = 50 tons.
    Update: S2 = 70 - 50 = 20 tons; D2 = 50 - 50 = 0 (Column D2 Satisfied & Eliminated).
  - Step 2: In remaining matrix, min cost is ₹4 at cell (S1, D1) [Barrackpore → Kolkata].
    Allocate x_11 = min(50, 40) = 40 tons.
    Update: S1 = 50 - 40 = 10 tons; D1 = 40 - 40 = 0 (Column D1 Satisfied & Eliminated).
  - Step 3: In remaining column D3, min cost is ₹5 at cell (S2, D3) [Ichapur → Salt Lake].
    Allocate x_23 = min(20, 30) = 20 tons.
    Update: S2 = 20 - 20 = 0 (Row S2 Exhausted & Eliminated); D3 = 30 - 20 = 10 tons.
  - Step 4: Final remaining cell is (S1, D3) at ₹6.
    Allocate x_13 = min(10, 10) = 10 tons.
    Update: S1 = 0, D3 = 0. Both eliminated.

Solution Matrix:
  - x_11 = 40 (@ ₹4), x_13 = 10 (@ ₹6)
  - x_22 = 50 (@ ₹3), x_23 = 20 (@ ₹5)
Number of Basic Cells = 4 (matches m + n - 1 = 2 + 3 - 1 = 4).
Total Cost Z = (40 × ₹4) + (10 × ₹6) + (50 × ₹3) + (20 × ₹5)
             = ₹160 + ₹60 + ₹150 + ₹100 = ₹470.
(NWCR Cost = ₹670; Matrix Minima saves ₹200 or ~30%).

4. ADVANCED TIE-BREAKING & DEGENERACY RESOLUTION
================================================================================

Tie-Breaking Protocol:
- Tier 1: Maximum Allocation Volume -> max { min(S_i, D_j) }
  Allocating 60 units at ₹2 saves far more than allocating 10 units at ₹2.
- Tier 2: Greatest Line Capacity -> choose row/col with larger remaining capacity.
- Tier 3: Arbitrary Selection -> mathematically valid and preserves basis.

Degeneracy (S_k == D_l):
- Occurs when an assignment zeroes out both a supply and a demand line simultaneously.
- If uncorrected, this yields only (m + n - 2) basic cells, causing division by zero 
  or failure during MODI multiplier (u_i + v_j) evaluation.
- Remedy: Add ε (where ε → 0) in an unallocated independent cell to preserve 
  m + n - 1 basic variables.

6. PROFESSIONAL TIPS & COMMON MISTAKES
================================================================================

Top Tips:
1. Always circle allocated quantities to avoid confusing them with unit costs.
2. Cross out dead rows/columns with light horizontal/vertical lines.
3. Verify that total basic allocated cells equal m + n - 1 before computing cost.

Pitfalls to Avoid:
1. Never allocate more than min(S_i, D_j).
2. Do not select costs in eliminated rows or columns.
3. Do not assume the Matrix Minima solution is optimal without running the MODI check.
