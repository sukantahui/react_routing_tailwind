1. COMPREHENSIVE MULTI-DIMENSIONAL COMPARISON
================================================================================

Parameter               North-West Corner Rule (NWCR)   Matrix Minima Method (Least-Cost)
--------------------------------------------------------------------------------
1. Core Philosophy      Positional Traversal (Top-Left) Economic Cost Minimization (argmin)
2. Cost Matrix View     Completely Cost-Blind           Globally Cost-Aware (2D Scan)
3. Selection Sequence   Strict (1,1) → (m,n) Diagonal   Dynamic (Lowest ₹/unit first)
4. Initial Cost (Z)     Very High (Far from Optimal)    Low to Near-Optimal
5. MODI Iterations      High (6 to 12 pivot loops)      Low (1 to 3 pivot loops)
6. Computational Time   O(m + n) Linear                 O(mn log(mn)) with Min-Heap
7. Big-M Routing        Vulnerable to high penalties    Naturally filters Big-M routes
8. Permutation Impact   Sensitive to row/col ordering   Permutation Invariant
9. Degeneracy Handling  Same rule (m + n - 1 with ε)    Same rule (m + n - 1 with ε)
10. Industrial Use      Classroom conceptual baseline   Practical enterprise starting heuristic

3. THE PEDAGOGICAL LADDER OF TRANSPORTATION HEURISTICS
================================================================================

Level 1: North-West Corner Rule (NWCR)
- Role: Teaches basic table balancing and line elimination mechanics.
- Limitation: Ignores costs completely; produces expensive shipping schedules.

Level 2: Matrix Minima Method (Least-Cost)
- Role: Introduces economic greedy optimization; suppresses starting costs by 30-45%.
- Strength: Simple to compute by hand while delivering near-optimal results.

Level 3: Vogel's Approximation Method (VAM)
- Role: Advanced penalty/regret heuristic; avoids severe downstream bottlenecks.
- Strength: Closest to true global optimum at the cost of higher manual math.

Level 4: MODI (Modified Distribution) Method
- Role: Exact optimization algorithm; guarantees and proves mathematical optimality.


4. COMMON PITFALLS & BEST PRACTICES
================================================================================

Common Mistakes:
1. Assuming NWCR is faster overall: While NWCR saves 1 minute during the starting 
   draft, it wastes 15 minutes solving 8 extra MODI stepping-stone loops!
2. Confusing greedy selection with global optimality: Matrix Minima is an excellent 
   starting point, but it still requires MODI verification.
3. Blindly using NWCR in business presentations: Always use Matrix Minima or VAM 
   when presenting logistics budgets to executive stakeholders.

Best Practices:
1. Use NWCR only for initial classroom mechanical practice.
2. Adopt Matrix Minima as your default manual problem-solving method.
3. Compare starting costs against NWCR to demonstrate financial ROI.
