--------------------------------------------------------------------------------
1. THE COMPUTATIONAL BOTTLENECK OF LARGE m x n MATRICES
--------------------------------------------------------------------------------
In real-world competitive scenarios, organizations frequently identify large sets
of tactical options, generating 3x3, 4x4, 5x5, or even 10x10 payoff matrices.

THE PROBLEM WITH UNREDUCED m x n MATRICES:
• High Computational Complexity: Direct solution requires setting up Dual Linear
  Programming models with m constraints and n variables, requiring lengthy Simplex tableaus.
• Strategic Redundancy: Most large matrix entries represent inferior, dominated, or
  duplicative actions that will receive exactly 0.0 probability in equilibrium.

--------------------------------------------------------------------------------
2. THE PHILOSOPHY OF MATRIX DIMENSIONALITY REDUCTION
--------------------------------------------------------------------------------
Dimensionality Reduction systematically prunes redundant decision branches:
1. Target 1x1: Reduces directly to a pure Saddle Point (if dominance-solvable).
2. Target 2x2: Reduces to a 2-strategy game solvable via closed-form algebraic formulas (Delta, p*, q*, v*).
3. Target 2xn or mx2: Reduces to 2-dimensional games solvable via the Graphical Method (lower/upper envelopes).

THE VALUE INVARIANCE THEOREM:
• The optimal Value of the Game v* in Indian Rupees (₹) remains 100% UNCHANGED throughout
  all reduction passes!

--------------------------------------------------------------------------------
3. ISOLATING THE EQUILIBRIUM STRATEGY SUPPORT
--------------------------------------------------------------------------------
• By eliminating dominated rows and columns, analysts immediately identify the SUPPORT
  of the mixed strategy:
      supp(p*) = { Surviving Rows }
      supp(q*) = { Surviving Columns }
• All eliminated strategies receive probability 0.0 in the full strategy vector.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never set up a large Linear Programming tableau before attempting dominance reduction!
- Pruning rows/columns does NOT change the true optimal Game Value v*.
- Verify that eliminated strategies are given probability 0.0 in the full-sized vectors.
- State all payoffs and valuations in Indian Rupees (₹).
