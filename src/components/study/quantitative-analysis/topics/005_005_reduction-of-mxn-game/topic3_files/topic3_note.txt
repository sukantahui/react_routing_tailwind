1. THE 5-STEP END-TO-END REDUCTION TO 2x2 PIPELINE
--------------------------------------------------------------------------------
Given an initial m x n Payoff Matrix A:

STEP 1: ITERATIVE DOMINANCE REDUCTION
• Apply pure row sweeps, column sweeps, and convex combination blends until exactly
  two rows I = {r_1, r_2} and two columns J = {c_1, c_2} survive.

STEP 2: EXTRACT 2x2 SUBMATRIX
      A_sub = [ [a_(r1, c1), a_(r1, c2)],
                [a_(r2, c1), a_(r2, c2)] ]

STEP 3: CLOSED-FORM 2x2 SUB-GAME SOLUTION
• Denominator: Delta_sub = (a_11 + a_22) - (a_12 + a_21)
• Player A sub-probabilities:
      p_1_sub* = (a_22 - a_21) / Delta_sub,  p_2_sub* = (a_11 - a_12) / Delta_sub
• Player B sub-probabilities:
      q_1_sub* = (a_22 - a_12) / Delta_sub,  q_2_sub* = (a_11 - a_21) / Delta_sub
• Value of the Game:
      v* = det(A_sub) / Delta_sub  (in ₹)

STEP 4: FULL-VECTOR PROBABILITY RECONSTRUCTION
• Reconstruct m-dimensional p* and n-dimensional q* with 0.0 for all pruned strategies.

STEP 5: GLOBAL OPTIMALITY VERIFICATION ON ORIGINAL m x n MATRIX
• Against every original Column j:  E(p*, B_j) >= v*  (equality for active j in J).
• Against every original Row i:     E(A_i, q*) <= v*  (equality for active i in I).

3. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never forget to check global optimality: E(p*, Bj) >= v* for all original columns.
- Ensure the active row and column indices are mapped correctly to p* and q*.
- If an eliminated column yields an expected payoff strictly LESS than v*, re-check your reduction steps!
- State all game values and payoffs in Indian Rupees (₹).
