--------------------------------------------------------------------------------
1. THE 5-PHASE ITERATIVE REDUCTION ALGORITHM
--------------------------------------------------------------------------------
For any general m x n Payoff Matrix A:

PHASE 1: SADDLE POINT CHECK
- Compute row minima (alpha_i) and column maxima (beta_j).
- If Maximin (alpha) == Minimax (beta), stop: pure saddle point exists.
- If Maximin < Minimax, proceed to reduction.

PHASE 2: ROW DOMINANCE SWEEPS (PLAYER A MAXIMIZATION)
- For every pair of rows (R_i, R_j):
  If a_ik >= a_jk for ALL columns k, then Row R_i dominates Row R_j.
  Action: Delete Row R_j (assign p_j* = 0.0). Matrix size becomes (m - 1) x n.

PHASE 3: COLUMN DOMINANCE SWEEPS (PLAYER B MINIMIZATION)
- For every pair of columns (C_r, C_s):
  If a_kr <= a_ks for ALL rows k, then Column C_r dominates Column C_s.
  Action: Delete Column C_s (assign q_s* = 0.0). Matrix size becomes (m - 1) x (n - 1).

PHASE 4: CASCADING FEEDBACK LOOP
- Repeat Phases 2 and 3 on the newly reduced submatrix!
- Column deletions often reveal newly dominant rows.
- Stop when a full pass produces zero further deletions.

PHASE 5: CONVEX COMBINATION SWEEP (IF DEADLOCKED)
- If pure dominance fails and matrix size >= 3x3, test if a convex combination of two
  rows/columns dominates a third: lambda * R_a + (1 - lambda) * R_b >= R_c.

--------------------------------------------------------------------------------
2. FULL-VECTOR PROBABILITY RECONSTRUCTION
--------------------------------------------------------------------------------
Once the matrix is reduced to a 2x2 submatrix involving active indices I = {r_1, r_2}
and J = {c_1, c_2}:
1. Solve 2x2 sub-game to find sub-probabilities [p_1_sub, p_2_sub] and [q_1_sub, q_2_sub].
2. Construct full m-dimensional vector p*:
      p_i* = p_1_sub if i == r_1
      p_i* = p_2_sub if i == r_2
      p_i* = 0.0 otherwise
3. Construct full n-dimensional vector q*:
      q_j* = q_1_sub if j == c_1
      q_j* = q_2_sub if j == c_2
      q_j* = 0.0 otherwise
4. The Game Value v* in Indian Rupees (₹) is identical to the 2x2 submatrix value!

4. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never stop after only 1 pass! Always loop until a full sweep yields ZERO deletions.
- Remember: Player A deletes SMALLER rows; Player B deletes LARGER columns.
- Ensure the full reconstructed vectors sum to exactly 1.0 (100%).
