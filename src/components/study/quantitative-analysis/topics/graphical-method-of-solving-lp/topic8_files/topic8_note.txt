KEY DEFINITIONS
---------------
LP: Optimization with linear relationships
Feasible Region: All points satisfying constraints
Binding Constraint: Slack = 0
Corner Point: Vertex of feasible region
Slack: Unused resources (RHS - LHS)
Shadow Price: Value of additional resources

KEY FORMULAS
------------
Objective: Z = c₁x + c₂y
Constraint: a₁x + a₂y ≤ b
Slack: Slack = b - (a₁x* + a₂y*)
Shadow Price: SP = ΔZ/Δb
Utilization: (Used/Available) × 100%
Objective Slope: m = -c₁/c₂

KEY CONCEPTS
------------
• Optimal Solution: At a corner point
• Multiple Optima: Objective parallel to constraint
• Infeasible: No overlapping constraints
• Unbounded: Region extends to infinity
• Degenerate: 3+ binding constraints
• Redundant: Constraint doesn't affect region

PROBLEM-SOLVING STEPS
---------------------
1. Define variables
2. Formulate objective
3. Formulate constraints
4. Graph constraints
5. Find feasible region
6. Identify corner points
7. Evaluate objective
8. Select optimal solution
9. Interpret results

COMMON MISTAKES
---------------
• Forgetting non-negativity constraints
• Incorrect shading of feasible region
• Missing corner points
• Not verifying the solution
• Confusing maximization with minimization
• Misinterpreting shadow prices
