--------------------------------------------------------------------------------
1. DEFINITION OF PROJECT DURATION
--------------------------------------------------------------------------------
The PROJECT DURATION (T) is the total elapsed calendar time from project commencement
(Node 1 at time t = 0) to final project handover (Node n).

MATHEMATICAL RELATIONSHIP:
    Project Duration T = Earliest Finish of Terminal Node E_n = Length of Critical Path

--------------------------------------------------------------------------------
2. NORMAL DURATION VS. CRASH DURATION
--------------------------------------------------------------------------------

1. NORMAL PROJECT DURATION (T_normal):
   • Standard project duration executed with normal crew sizes, regular shift hours,
     and standard supply deliveries at minimum direct expenditure (Normal Direct Cost C_n).

2. CRASH PROJECT DURATION (T_crash):
   • The absolute theoretical minimum time required to complete the project by
     deploying maximum overtime, multi-shift labor, expedited air freight, and premium
     equipment rentals regardless of direct expense (Crash Direct Cost C_c).

--------------------------------------------------------------------------------
3. THE TIME-COST TRADE-OFF & THE U-SHAPED TOTAL COST CURVE
--------------------------------------------------------------------------------
Every project is governed by two opposing financial cost drivers:

1. DIRECT COSTS (C_direct):
   • Costs directly tied to activity execution (labor wages, equipment fuel, raw materials).
   • As project duration T is compressed, Direct Costs INCREASE due to overtime premiums
     and expedited logistics.

2. INDIRECT OVERHEAD COSTS (C_indirect):
   • Ongoing daily expenses incurred per unit time (site security, scaffolding rental,
     field office administration, project manager salaries, utilities).
   • As project duration T is compressed, Indirect Costs DECREASE linearly:
         C_indirect(T) = T * Daily Indirect Overhead Rate

3. TOTAL PROJECT COST FUNCTION:
       Total Cost(T) = Direct Cost(T) + Indirect Cost(T)

4. OPTIMAL PROJECT DURATION (T*):
   • The specific duration where the combined Total Cost is MINIMIZED (the bottom
     of the U-shaped Total Cost curve).
   • Economic Crashing Rule: Continue crashing critical activities as long as:
         Marginal Cost Slope (Delta C / Delta T) < Daily Indirect Overhead Rate

--------------------------------------------------------------------------------
4. COST SLOPE EQUATION & CRASHING PROTOCOL
--------------------------------------------------------------------------------
For any activity (i, j):
    Cost Slope = (Crash Cost C_c - Normal Cost C_n) / (Normal Time T_n - Crash Time T_c)
               = Delta C / Delta T   in Indian Rupees (₹) per Day

STEP-BY-STEP CRASHING ALGORITHM:
1. Determine Critical Path(s) and current project duration T = E_n.
2. Compute Cost Slope for all critical activities.
3. Identify the critical activity with the LOWEST Cost Slope.
4. Crash that activity by 1 day (or up to its crash limit / until a subcritical path becomes critical).
5. If Cost Slope < Daily Overhead Rate, the crash is profitable ➔ update total cost.
6. Re-evaluate network, update all path durations, and repeat until no further profitable crashes exist.

--------------------------------------------------------------------------------
6. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never crash an activity beyond its Crash Limit (T_crash).
- Never crash a non-critical activity (it increases direct cost without shortening project duration).
- If multiple critical paths exist, crash an activity on EACH critical path simultaneously.
- Always state budgets, overhead rates, and cost slopes in Indian Rupees (₹).
