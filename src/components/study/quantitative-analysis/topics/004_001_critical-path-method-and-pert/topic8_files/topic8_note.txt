--------------------------------------------------------------------------------
1. DEFINITION OF A CRITICAL ACTIVITY
--------------------------------------------------------------------------------
A CRITICAL ACTIVITY is an activity within a project network that possesses
EXACTLY ZERO TOTAL FLOAT (TF = 0).

OPERATIONAL CONSEQUENCE:
• Zero Float (TF = 0, FF = 0, IF = 0): There is ZERO time buffer available.
• 1-to-1 Project Delay: Any delay in starting or executing a critical activity
  causes an identical delay in the final project completion date.
• Managerial Focus: Critical activities receive top-priority resource allocation,
  daily tracking, and are the ONLY candidates for time-cost crashing.

--------------------------------------------------------------------------------
2. THE 3 INVARIANT MATHEMATICAL CONDITIONS FOR CRITICALITY
--------------------------------------------------------------------------------
For an activity (i, j) with duration d_ij, it is CRITICAL if and only if ALL THREE
conditions are simultaneously satisfied:

CONDITION 1: TAIL EVENT IS CRITICAL
    E_i = L_i   (Tail event slack S_i = 0)

CONDITION 2: HEAD EVENT IS CRITICAL
    E_j = L_j   (Head event slack S_j = 0)

CONDITION 3: DURATION EXACTLY BRIDGES THE EVENT TIME INTERVAL
    E_j - E_i = L_j - L_i = d_ij
    (Equivalently: Total Float TF = LF - EF = LS - ES = 0)

--------------------------------------------------------------------------------
3. THE "FALSE-CRITICALITY TRAP" (COUNTEREXAMPLE)
--------------------------------------------------------------------------------
COMMON STUDENT MISTAKE:
"If Node i is critical (E_i = L_i) and Node j is critical (E_j = L_j), then activity (i, j)
must be a critical activity." ➔ FALSE!

COUNTEREXAMPLE:
Suppose:
• Node 2 is critical: E_2 = 5, L_2 = 5
• Node 6 is critical: E_6 = 19, L_6 = 19
• Activity (2, 6) has duration d_26 = 8 days.

TESTING THE 3 CONDITIONS:
1. E_2 = L_2 = 5 ✅ (Condition 1 holds)
2. E_6 = L_6 = 19 ✅ (Condition 2 holds)
3. Duration Check: E_6 - E_2 = 19 - 5 = 14 days != 8 days ❌ (Condition 3 FAILS!)

TOTAL FLOAT CALCULATION:
    TF = L_6 - E_2 - d_26 = 19 - 5 - 8 = 6 Days > 0.
➔ Activity (2, 6) is NON-CRITICAL with 6 days of allowable buffer!

6. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never assume an activity is critical without verifying Condition 3: E_j - E_i = d_ij.
- Critical activities have TF = 0, FF = 0, and IF = 0 simultaneously.
- Never spend crashing budgets on non-critical activities.
- State all critical task costs, crash rates, and direct budgets in Indian Rupees (₹).
