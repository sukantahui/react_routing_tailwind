TOPIC 8: ITERATION PROCEDURE
============================

INTRODUCTION
------------
The iteration procedure is the step-by-step process of the Simplex 
Method. Each iteration transforms the tableau and improves the 
objective value until optimality is reached.

THE 8-STEP ITERATION PROCEDURE
------------------------------
Step 1: Find Entering Variable
- Look at Z row
- Most negative coefficient (maximization)

Step 2: Find Leaving Variable
- Use ratio test
- Minimum positive RHS/coefficient

Step 3: Identify Pivot Element
- Intersection of entering column and leaving row
- Must be positive

Step 4: Normalize Pivot Row
- Divide entire pivot row by pivot element
- Pivot becomes 1

Step 5: Eliminate Pivot Column
- Make all other entries in pivot column zero
- Row = Row - coefficient × Pivot Row

Step 6: Update Z Row
- Apply same elimination to Z row

Step 7: Update Basic Variables
- Replace leaving with entering in B column

Step 8: Check Optimality
- All Z coefficients ≥ 0 → optimal
- If negative coefficients remain → continue

EXAMPLE
-------
Maximize Z = 3x + 2y
2x + y ≤ 10
x + 2y ≤ 8

Initial Tableau:
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  B  │  x  │  y  │ s₁  │ s₂  │ RHS │
├─────┼─────┼─────┼─────┼─────┼─────┤
│ s₁  │  2  │  1  │  1  │  0  │ 10  │
│ s₂  │  1  │  2  │  0  │  1  │  8  │
├─────┼─────┼─────┼─────┼─────┼─────┤
│  Z  │ -3  │ -2  │  0  │  0  │  0  │
└─────┴─────┴─────┴─────┴─────┴─────┘

Iteration 1:
Step 1: x enters (-3)
Step 2: s₁ leaves (min ratio 5)
Step 3: Pivot = 2
Step 4-7: Row operations
Step 8: Not optimal (Z has -0.5)

After Iteration 1:
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  B  │  x  │  y  │ s₁  │ s₂  │ RHS │
├─────┼─────┼─────┼─────┼─────┼─────┤
│  x  │  1  │ 0.5 │ 0.5 │  0  │  5  │
│ s₂  │  0  │ 1.5 │-0.5 │  1  │  3  │
├─────┼─────┼─────┼─────┼─────┼─────┤
│  Z  │  0  │-0.5 │ 1.5 │  0  │ 15  │
└─────┴─────┴─────┴─────┴─────┴─────┘

Iteration 2:
Step 1: y enters (-0.5)
Step 2: s₂ leaves (min ratio 2)
Step 3: Pivot = 1.5
Step 4-7: Row operations
Step 8: Optimal! (all Z ≥ 0)

Final Tableau:
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  B  │  x  │  y  │ s₁  │ s₂  │ RHS │
├─────┼─────┼─────┼─────┼─────┼─────┤
│  x  │  1  │  0  │0.667│-0.333│  4  │
│  y  │  0  │  1  │-0.333│0.667│  2  │
├─────┼─────┼─────┼─────┼─────┼─────┤
│  Z  │  0  │  0  │1.333│0.333│ 16  │
└─────┴─────┴─────┴─────┴─────┴─────┘

Optimal Solution: x = 4, y = 2, Z = 16

KEY RULES
---------
1. Follow steps in order
2. Pivot must be positive
3. Check optimality after each iteration
4. Stop when all Z ≥ 0

COMMON MISTAKES
---------------
1. Skipping steps
2. Incorrect row operations
3. Forgetting to check optimality
4. Not updating basic variables correctly

BEST PRACTICES
--------------
1. Be systematic
2. Use exact fractions
3. Verify pivot column is identity
4. Check Z improves each iteration

TEACHER'S NOTE
--------------
Each iteration is like a step in a journey - you know you're 
making progress because Z keeps increasing. Be methodical and 
check your work at each step."
