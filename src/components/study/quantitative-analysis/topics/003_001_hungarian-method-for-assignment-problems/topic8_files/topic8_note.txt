--------------------------------------------------------------------------------
1. THE ROW REDUCTION ALGORITHM & MATHEMATICAL DEFINITION
--------------------------------------------------------------------------------
Row Reduction is the SECOND STEP of the Hungarian Method. It operates on an
n x n square cost matrix C = [c_ij]:

ALGORITHM:
1. For every row i (from i = 1 to n):
   • Find the minimum entry in row i:
         u_i = min_{1 <= j <= n} (c_ij)
   • Subtract u_i from every entry in row i:
         c_ij' = c_ij - u_i     (for all j = 1, 2, ..., n)

MATHEMATICAL PROPERTIES:
• Non-Negativity: Since c_ij >= u_i for all j, c_ij' >= 0 (no negative numbers).
• Guaranteed Zero: The cell that held the minimum value (c_ik = u_i) becomes:
      c_ik' = u_i - u_i = 0
  Therefore, EVERY single row is guaranteed to contain at least one zero!

--------------------------------------------------------------------------------
2. DUAL LP SIGNIFICANCE OF ROW REDUCTION
--------------------------------------------------------------------------------
In the Dual LP of the Assignment Problem:
    Maximize   W = Sum_{i=1}^n u_i + Sum_{j=1}^n v_j
    Subject to: u_i + v_j <= c_ij

• The subtracted row minimums u_i represent the initial values of the dual row
  potential variables u_i (with v_j = 0 initially).
• Because u_i = min_j(c_ij) <= c_ij, the dual feasibility condition:
      u_i + 0 <= c_ij   ➔   u_i <= c_ij
  is SATISFIED for all matrix cells!
• Total dual objective lower bound established by Row Reduction:
      W_{row} = Sum_{i=1}^n u_i

--------------------------------------------------------------------------------
3. SPECIAL ROW REDUCTION CONDITIONS
--------------------------------------------------------------------------------
1. TIED ROW MINIMUMS:
   If a row contains multiple identical minimum values (e.g. [14, 10, 18, 10]),
   subtracting 10 produces multiple zeros in that row: [4, 0, 8, 0].

2. PROHIBITED CELLS (Big-M Technique):
   If cell c_ik = M, ignore M when finding the row minimum:
       u_i = min_{j != k} (c_ij)
   Upon subtraction: M - u_i = M (Infinity barrier remains intact).

3. DUMMY COLUMN (ALL 0s):
   If a dummy column exists with ₹0 rates, every row minimum is u_i = 0.
   Row reduction is automatically a NO-OP (matrix remains unchanged).

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never subtract a number larger than the row minimum; all reduced entries must be >= 0.
- When Big-M is present, never select M as the row minimum!
- Always record your row minimums u_i clearly on exam margins for partial credit.
- Remember: Row reduction is applied across ROWS (horizontally), not columns!
