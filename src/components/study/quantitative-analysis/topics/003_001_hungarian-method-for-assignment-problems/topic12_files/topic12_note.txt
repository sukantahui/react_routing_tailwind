--------------------------------------------------------------------------------
1. THE INDEPENDENT ZERO ALLOCATION DEFINITION
--------------------------------------------------------------------------------
In Step 5 of the Hungarian Method (after L == n has been certified), we extract
exactly n INDEPENDENT ZEROS from the reduced matrix:

DEFINITION:
A set of zeros is INDEPENDENT if NO two zeros share the same row and NO two zeros
share the same column.
• Number of Independent Zeros: Exactly n (for an n x n matrix).
• Represents a pure permutation matrix X* where Sum_i x_ij = 1 and Sum_j x_ij = 1.

--------------------------------------------------------------------------------
2. THE EXACT SEQUENTIAL ASSIGNMENT PROTOCOL
--------------------------------------------------------------------------------

PHASE 1: ROW SCANNING
1. Scan rows sequentially starting from Row 1 to Row n.
2. Find any row containing EXACTLY ONE ZERO.
3. Enclose that zero in a square box: [0] (make assignment x_ij = 1).
4. Immediately CROSS OUT WITH AN 'X' (X) all other zeros in the SAME COLUMN j.
5. Repeat for all remaining rows having exactly one unboxed/uncrossed zero.

PHASE 2: COLUMN SCANNING
1. Scan columns sequentially starting from Column 1 to Column n.
2. Find any column containing EXACTLY ONE ZERO.
3. Enclose that zero in a square box: [0] (make assignment x_ij = 1).
4. Immediately CROSS OUT WITH AN 'X' (X) all other zeros in the SAME ROW i.
5. Repeat for all remaining columns having exactly one unboxed/uncrossed zero.

PHASE 3: SUCCESSIVE PASSES & ARBITRARY BRANCHING
• Repeat Phase 1 and Phase 2 until all zeros in the matrix are either boxed [0] or crossed out (X).
• If a state is reached where all remaining rows and columns have TWO OR MORE zeros:
  ➔ Make an ARBITRARY selection on any zero, box it [0], cross out its row/col zeros, and continue.
  ➔ This confirms the presence of ALTERNATIVE OPTIMAL SOLUTIONS (multiple optima).

3. STEP-BY-STEP WORKED EXAMPLE (4x4 MATRIX ALLOCATION)
--------------------------------------------------------------------------------
REDUCED MATRIX C* (L = 4 = n):
       J1    J2    J3    J4
  W1    0     5     0     9
  W2    1     0     0     5
  W3    2     1     2     0
  W4    0     1     1     2

STEP-BY-STEP EXECUTION:
1. Row 3 has only ONE zero at Cell (3, 4):
   ➔ Box Cell (3, 4) [0].
   ➔ Cross out other zeros in Col 4 (None).

2. Row 4 has only ONE zero at Cell (4, 1):
   ➔ Box Cell (4, 1) [0].
   ➔ Cross out other zeros in Col 1: Cell (1, 1) is CROSSED OUT (X)!

3. Now Row 1 has only ONE remaining zero at Cell (1, 3):
   ➔ Box Cell (1, 3) [0].
   ➔ Cross out other zeros in Col 3: Cell (2, 3) is CROSSED OUT (X)!

4. Now Row 2 has only ONE remaining zero at Cell (2, 2):
   ➔ Box Cell (2, 2) [0].
   ➔ Cross out other zeros in Col 2 (None).

FINAL ASSIGNMENT SET (4 Independent Zeros):
• Debangshu (W1) ➔ Job 3  (Cell 1, 3)
• Susmita (W2)   ➔ Job 2  (Cell 2, 2)
• Mamata (W3)    ➔ Job 4  (Cell 3, 4)
• Mahima (W4)    ➔ Job 1  (Cell 4, 1)

5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never forget to cross out (X) conflicting zeros in the same column/row immediately!
- Never box a zero that has already been crossed out.
- Always pull unit rates from the ORIGINAL cost matrix in Indian Rupees (₹).
- If fewer than n zeros can be boxed, return to Step 4 and re-check line covering!
