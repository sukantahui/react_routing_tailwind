1. CORE CONCEPTUAL VIVA-VOCE CHEAT SHEET
--------------------------------------------------------------------------------

Q1: What is an Assignment Problem?
A1: A specialized 1-to-1 linear programming problem allocating n resources to n
tasks at minimum total cost (or maximum profit), ensuring no double-booking.

Q2: Why is it a degenerate transportation problem?
A2: Requires m + n - 1 = 2n - 1 basic variables, but has only n positive allocations
of x_ij = 1, leaving n - 1 basic cells at value zero.

Q3: Complexity comparison?
A3: Hungarian Method runs in O(n^3) polynomial time vs Brute Force O(n!) factorial.

Q4: What is Kőnig's Theorem (1931)?
A4: Min lines (L) to cover all zeros EQUALS Max independent zeros (M).

Q5: When is the matrix optimal?
A5: When minimum covering lines L equals matrix order n (L == n).

Q6: What is the 3-part Step 4b rule (Additional Reductions)?
A6: 1. Uncovered subtract e; 2. Intersections add e; 3. Single-covered unchanged.

Q7: How to convert Maximization to Minimization?
A7: Identify M_max = max(P); Relative Regret Matrix c_ij = M_max - p_ij.

Q8: How to balance an unbalanced problem (m != n)?
A8: Add |m - n| dummy rows (if m < n) or dummy columns (if m > n) with ₹0 unit costs.

Q9: What does a dummy allocation mean?
A9: Worker paired with Dummy Col = Worker is IDLE; Dummy Row paired with Task = Task is OUTSOURCED.

Q10: What is the Box [0] and Cross-Out (X) rule?
A10: Scan rows/cols with 1 zero ➔ Box [0] ➔ Cross out (X) conflicting zeros in same col/row.
