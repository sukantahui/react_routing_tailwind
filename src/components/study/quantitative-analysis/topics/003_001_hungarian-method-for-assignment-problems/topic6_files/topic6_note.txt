1. THE PRECISE DUMMY AUGMENTATION ALGORITHM
--------------------------------------------------------------------------------
Given an asymmetric cost matrix C of size m x n:

CONDITION 1: TASK DEFICIT (m < n)
• Number of Workers (m) is less than Number of Tasks (n).
• Action: Augment k = n - m DUMMY ROWS.
• Cost Assignment: c_{dummy_r, j} = ₹0   (for all j = 1, 2, ..., n).
• Resulting Matrix Shape: n x n.

CONDITION 2: LABOR SURPLUS (m > n)
• Number of Workers (m) is greater than Number of Tasks (n).
• Action: Augment k = m - n DUMMY COLUMNS.
• Cost Assignment: c_{i, dummy_c} = ₹0   (for all i = 1, 2, ..., m).
• Resulting Matrix Shape: m x m.

--------------------------------------------------------------------------------
2. EFFECT OF DUMMY LINES ON HUNGARIAN REDUCTION STEPS
--------------------------------------------------------------------------------
1. EFFECT OF A DUMMY ROW (ALL 0s):
   • Row reduction on real rows proceeds normally.
   • Column reduction is a NO-OP (bypassed) because every column contains a ₹0 in
     the dummy row (Col Min = 0).

2. EFFECT OF A DUMMY COLUMN (ALL 0s):
   • Row reduction is a NO-OP (bypassed) because every row contains a ₹0 in the
     dummy column (Row Min = 0).
   • Column reduction on real columns proceeds normally.

3. PROHIBITING DUMMY OUTSOURCING (Big-M Technique):
   • If Task j is critical and CANNOT be outsourced, set c_{dummy, j} = M (₹99,999).
   • This forces the algorithm to pair an internal worker with Task j.

3. FULL WORKED EXAMPLE (4x5 PROBLEM WITH 1 DUMMY ROW)
--------------------------------------------------------------------------------
PROBLEM STATEMENT:
4 Technicians (W1..W4) available for 5 Foundry Repair Jobs (J1..J5):
       J1    J2    J3    J4    J5
  W1  ₹10   ₹15   ₹12   ₹18   ₹14
  W2  ₹13   ₹12   ₹14   ₹16   ₹11
  W3  ₹15   ₹14   ₹17   ₹12   ₹16
  W4  ₹11   ₹13   ₹15   ₹14   ₹12

STEP 1: AUGMENT DUMMY ROW W5 (₹0 RATES)
Matrix becomes 5x5:
       J1    J2    J3    J4    J5
  W1  ₹10   ₹15   ₹12   ₹18   ₹14
  W2  ₹13   ₹12   ₹14   ₹16   ₹11
  W3  ₹15   ₹14   ₹17   ₹12   ₹16
  W4  ₹11   ₹13   ₹15   ₹14   ₹12
  W5   ₹0    ₹0    ₹0    ₹0    ₹0   (Dummy Row)

STEP 2: ROW REDUCTION
• Row 1 min = 10 ➔ [0, 5, 2, 8, 4]
• Row 2 min = 11 ➔ [2, 1, 3, 5, 0]
• Row 3 min = 12 ➔ [3, 2, 5, 0, 4]
• Row 4 min = 11 ➔ [0, 2, 4, 3, 1]
• Row 5 min = 0  ➔ [0, 0, 0, 0, 0]

STEP 3: COLUMN REDUCTION
Since Row 5 contains 0s in all columns, all column minimums are 0!

STEP 4: ZERO ASSIGNMENT (L = 5 lines)
• W1 ➔ J3: c_13 = ₹12
• W2 ➔ J5: c_25 = ₹11
• W3 ➔ J4: c_34 = ₹12
• W4 ➔ J1: c_41 = ₹11
• W5 (Dummy) ➔ J2: c_52 = ₹0  (Job 2 is outsourced to vendor!)

STEP 5: CERTIFIED MINIMUM COST
    Z* = 12 + 11 + 12 + 11 + 0 = ₹46.

5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never assign non-zero costs to standard dummy cells.
- If a specific job cannot be outsourced, use Big-M (c_{dummy, j} = M).
- Pull all final monetary rates from the ORIGINAL cost matrix in Indian Rupees (₹).
- Explicitly state which job is outsourced or which worker is idle in your conclusion.
