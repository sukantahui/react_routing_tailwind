--------------------------------------------------------------------------------
1. THE ONE-TO-ONE BIJECTION PRINCIPLE
--------------------------------------------------------------------------------
The hallmark of the Assignment Problem is the ONE-TO-ONE ALLOCATION RULE:
• Each resource i (Worker/Machine) must be assigned to EXACTLY ONE task j.
• Each task j (Job/Case) must be performed by EXACTLY ONE resource i.

MATHEMATICAL EQUATIONS:
1. Row Constraints (No idle workers, no double-booking):
       Sum_{j=1}^n x_ij = 1     (for all i = 1, 2, ..., n)

2. Column Constraints (No neglected tasks, no multi-worker clashes):
       Sum_{i=1}^n x_ij = 1     (for all j = 1, 2, ..., n)

3. Binary Decision Flags:
       x_ij in {0, 1}           (for all i, j)

--------------------------------------------------------------------------------
2. PERMUTATION MATRICES & FACTORIAL COMBINATORIAL SPACE
--------------------------------------------------------------------------------
A valid 1-to-1 allocation schedule corresponds to an n x n PERMUTATION MATRIX:
• Total Non-Zero Entries: Exactly n ones (all x_ij = 1).
• Total Inactive Cells:   Exactly n^2 - n zeros (all x_ij = 0).
• Matrix Sparsity:        ((n - 1) / n) * 100% of the matrix consists of zeros!

FACTORIAL GROWTH:
For an n x n problem, there are n! distinct valid permutation matrices:
• 3 x 3 ➔ 3! = 6 permutations
• 4 x 4 ➔ 4! = 24 permutations
• 5 x 5 ➔ 5! = 120 permutations
• 10 x 10 ➔ 10! = 3,628,800 permutations

--------------------------------------------------------------------------------
3. ALLOCATION CONFLICT TAXONOMY
--------------------------------------------------------------------------------
1. ROW CONFLICT (Double-Booking / Over-Allocation):
   Occurs when Sum_{j=1}^n x_ij > 1.
   Example: Worker 1 assigned to Task 1 AND Task 2.
   Consequence: Human worker physically cannot execute two tasks simultaneously!

2. COLUMN CONFLICT (Task Contestation / Multi-Assignment):
   Occurs when Sum_{i=1}^n x_ij > 1.
   Example: Worker 1 and Worker 2 both assigned to Task 3.
   Consequence: Two people fighting over one machine, causing labor waste!

3. ROW DEFICIT (Idle Resource):
   Occurs when Sum_{j=1}^n x_ij = 0. Worker sits idle on payroll.

4. COLUMN DEFICIT (Unassigned Task):
   Occurs when Sum_{i=1}^n x_ij = 0. Customer order or surgery neglected.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Always verify both row sums == 1 AND column sums == 1.
- Total number of allocated cells (ones) MUST equal n.
- Never allow fractional splits (x_ij = 0.5) in standard 1-to-1 models.
- Always report total cost Z in Indian Rupees (₹).
