--------------------------------------------------------------------------------
1. MATHEMATICAL FORMULATION OF COLUMN DOMINANCE
--------------------------------------------------------------------------------
In a Two-Person Zero-Sum Game, PLAYER B is the COLUMN MINIMIZER.

FORMAL DEFINITION:
• Column r DOMINATES Column s if:
      a_kr <= a_ks    for ALL rows k = 1, 2, ..., m
  with at least one strict inequality (a_kr < a_ks for some row k).

ELIMINATION DIRECTIVE:
• Delete COLUMN s (the Dominated / LARGER Column).
• Retain COLUMN r (the Dominating / SMALLER Column).

--------------------------------------------------------------------------------
2. WHY COLUMN DELETION IS STRATEGICALLY SOUND
--------------------------------------------------------------------------------
• For every possible move by Player A (Row k):
      Payout in Column r <= Payout in Column s
• Therefore, Player B has NO economic or strategic incentive to ever select Column s.
• In the optimal mixed strategy probability vector q*:
      q_s* = 0.0 (Probability of eliminated column is strictly zero).

--------------------------------------------------------------------------------
3. STEP-BY-STEP PAIRWISE COLUMN COMPARISON ALGORITHM
--------------------------------------------------------------------------------
Given an m x n Payoff Matrix:
1. For every pair of columns (r, s) where r != s:
2. Compare each element down all m rows:
   - Check if a_1r <= a_1s, a_2r <= a_2s, ..., a_mr <= a_ms.
3. If all inequalities hold (with at least one strict <):
   - Strike out Column s (the larger column).
   - Reduce column dimension from n to n - 1.
4. Repeat for all remaining columns.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never eliminate the smaller column! Player B wants lower liabilities, so eliminate the LARGER column.
- Check ALL rows without exception; if even one row has a_kr > a_ks, dominance FAILS!
- If two columns are identical, eliminate either one (redundant strategy).
- State all column liability ceilings in Indian Rupees (₹).
