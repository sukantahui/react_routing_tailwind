--------------------------------------------------------------------------------
1. MATHEMATICAL FORMULATION OF ROW DOMINANCE
--------------------------------------------------------------------------------
In a Two-Person Zero-Sum Game, PLAYER A is the ROW MAXIMIZER.

FORMAL DEFINITION:
• Row i DOMINATES Row j if:
      a_ik >= a_jk    for ALL columns k = 1, 2, ..., n
  with at least one strict inequality (a_ik > a_jk for some column k).

ELIMINATION DIRECTIVE:
• Delete ROW j (the Dominated / Smaller Row).
• Retain ROW i (the Dominating / Larger Row).

--------------------------------------------------------------------------------
2. WHY ROW DELETION IS STRATEGICALLY SOUND
--------------------------------------------------------------------------------
• For every possible move by Player B (Column k):
      Payoff in Row i >= Payoff in Row j
• Therefore, Player A has NO economic or strategic incentive to ever select Row j.
• In the optimal mixed strategy probability vector p*:
      p_j* = 0.0 (Probability of eliminated row is strictly zero).

--------------------------------------------------------------------------------
3. STEP-BY-STEP PAIRWISE ROW COMPARISON ALGORITHM
--------------------------------------------------------------------------------
Given an m x n Payoff Matrix:
1. For every pair of rows (i, j) where i != j:
2. Compare each element across all n columns:
   - Check if a_i1 >= a_j1, a_i2 >= a_j2, ..., a_in >= a_jn.
3. If all inequalities hold (with at least one strict >):
   - Strike out Row j.
   - Reduce row dimension from m to m - 1.
4. Repeat for all remaining rows.

--------------------------------------------------------------------------------
5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never eliminate the larger row! Player A wants higher numbers, so eliminate the SMALLER row.
- Check ALL columns without exception; if even one column has a_ik < a_jk, dominance FAILS!
- If two rows are identical, eliminate either one (redundant strategy).
- State all row payoffs in Indian Rupees (₹).
