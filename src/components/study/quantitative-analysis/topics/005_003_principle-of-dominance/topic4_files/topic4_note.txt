--------------------------------------------------------------------------------
1. THE COMPLETE MULTI-PASS REDUCTION METHODOLOGY
--------------------------------------------------------------------------------
Large m x n payoff matrices can be systematically shrunk to compact 2x2 games
using the 4-Pass Iterative Elimination Pipeline:

• PASS 1 (INITIAL ROW SCAN):
  - Compare all row pairs. Delete any row j dominated by row i (a_ik >= a_jk for all k).

• PASS 2 (SUB-MATRIX COLUMN SCAN):
  - In the surviving trimmed matrix, compare all column pairs.
  - Delete any column s dominated by column r (a_kr <= a_ks for all k).

• PASS 3 (RE-EVALUATION CASCADES):
  - Deleting columns removes opponent moves, often creating BRAND NEW row dominances!
  - Re-compare remaining rows and delete newly dominated rows.

• PASS 4 (MODIFIED DOMINANCE & TERMINATION):
  - If pure dominance stalls, test convex combinations (50-50 averages).
  - Terminate when an irreducible 2x2 matrix, a 2xn / mx2 matrix (for Graphical Method),
    or a 1x1 saddle point is reached!

--------------------------------------------------------------------------------
2. FULL-SIZED STRATEGY VECTOR RECONSTRUCTION
--------------------------------------------------------------------------------
When the reduced 2x2 matrix is solved:
• Let (p_1*, p_2*) and (q_1*, q_2*) be the optimal probabilities for surviving rows and cols.
• Map them back to the original full m-dimensional and n-dimensional vectors:
  - Assign p_i* to surviving row i.
  - Assign 0.0 to all previously eliminated rows.
  - Example: If rows A2 and A4 survive in a 4-row game, p* = (0, p_1*, 0, p_2*)^T.

--------------------------------------------------------------------------------
3. VALUE INVARIANCE THEOREM
--------------------------------------------------------------------------------
The Value of the Game v* remains STRICTLY CONSTANT throughout every reduction step:
      v*(Original m x n) == v*(Intermediate Sub-matrix) == v*(Final 2 x 2)

--------------------------------------------------------------------------------
