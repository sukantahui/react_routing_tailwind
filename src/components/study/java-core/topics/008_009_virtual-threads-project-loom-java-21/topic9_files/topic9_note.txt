1. THREAD.STARTVIRTUALTHREAD(RUNNABLE):
   - One-line quick launcher for virtual threads.
   - Starts immediately; anonymous by default.
   - Replaces legacy 'new Thread(r).start()'.
   - Returns a 'Thread' handle you can 'join()' on.
