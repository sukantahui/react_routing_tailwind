1. REACTIVE vs VIRTUAL THREADS:
   - Reactive (WebFlux): High throughput, but complex async pipelines & broken stack traces.
   - Virtual Threads (Java 21): High throughput WITH simple synchronous Java code!
   - Write sequential code: 'User user = fetchUser();'
   - Full compatibility with existing JDBC, JPA, and debugging tools.
