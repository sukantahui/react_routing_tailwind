1. SCOPED VALUES:
   - Replaces heavy, mutable 'ThreadLocal'.
   - Immutable: Values cannot be modified downstream.
   - Bounded Lifetime: Automatically cleared when scope exits.
   - Zero memory leaks (No manual 'remove()' required).
   - Designed specifically to scale across millions of Virtual Threads.
