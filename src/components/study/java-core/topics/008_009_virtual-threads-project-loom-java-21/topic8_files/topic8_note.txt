1. THREAD.OFVIRTUAL() BUILDER:
   - '.name("prefix-", startNumber)': Auto-incrementing thread names.
   - '.start(runnable)': Creates and immediately starts.
   - '.unstarted(runnable)': Creates thread in NEW unstarted state.
   - '.factory()': Produces a reusable 'ThreadFactory' for virtual threads.
