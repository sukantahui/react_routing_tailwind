1. VIRTUAL THREADS (JAVA 21 LTS):
   - Managed entirely by the JVM in user space.
   - M:N multiplexing onto OS carrier threads.
   - Tiny dynamic stacks (~few hundred bytes on JVM heap).
   - Creation cost is nearly zero (as cheap as creating a standard object).
   - Check with: 'Thread.currentThread().isVirtual()'.
