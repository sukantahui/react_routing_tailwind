Topic 11: Never Pool Virtual Threads

1. NEVER POOL VIRTUAL THREADS:
   - Platform threads were pooled because they cost 1 MB RAM.
   - Virtual threads are ephemeral (~few hundred bytes).
   - Create a new virtual thread per task & let it die upon completion.
   - Need to limit database/API access? Use 'Semaphore', NOT thread pools!
