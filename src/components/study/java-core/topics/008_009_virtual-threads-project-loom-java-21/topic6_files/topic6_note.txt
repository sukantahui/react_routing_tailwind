1. AUTOMATIC UNMOUNTING ON I/O:
   - JDK rewritten to integrate with OS epoll/kqueue/IOCP.
   - Calling 'socket.read()' or 'Thread.sleep()' triggers 'Continuation.yield()'.
   - Virtual Thread unmounts & carrier thread is instantly freed.
   - When I/O data arrives, Virtual Thread re-mounts on any available carrier.
   - Zero OS thread blocking!
