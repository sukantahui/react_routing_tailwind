1. THREAD PINNING:
   - What: Virtual Thread cannot unmount during blocking I/O.
   - Causes: 'synchronized' blocks or JNI Native C methods.
   - Consequence: Freezes physical OS carrier threads.
   - Diagnostic Flag: '-Djdk.tracePinnedThreads=full'.
   - Fix: Replace 'synchronized' with 'ReentrantLock'!
