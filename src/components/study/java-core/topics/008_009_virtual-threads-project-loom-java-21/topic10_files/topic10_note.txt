1. NEWVIRTUALTHREADPERTASKEXECUTOR():
   - Spawns a new Virtual Thread for EVERY task.
   - Implements 'AutoCloseable': use with 'try-with-resources'.
   - Exiting 'try' block automatically waits for all tasks to complete!
   - The default executor used in modern Spring Boot 3.2+ and Quarkus.
