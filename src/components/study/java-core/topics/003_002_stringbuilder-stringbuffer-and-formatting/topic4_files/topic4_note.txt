1. BUFFER CAPACITY ESSENTIALS:
   - Default capacity = 16.
   - Growth formula: 'newCapacity = (oldCapacity * 2) + 2'.
   - If initial string provided ('new StringBuilder("hello")'): capacity = 16 + length.
   - Best Practice: Pre-allocate capacity if estimated size is known.
