1. TEXT BLOCKS RULES (Java 15+):
   - Opens with '"""' followed immediately by a newline.
   - Closes with '"""'.
   - Double quotes ('"') do NOT need backslash escapes inside Text Blocks.
   - Automatically computes and removes incidental indentation.
