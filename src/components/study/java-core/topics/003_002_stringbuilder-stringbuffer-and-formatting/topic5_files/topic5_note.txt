1. CORE METHOD TOOLSET:
   - 'append(data)'              : Appends primitives/objects to end.
   - 'insert(offset, data)'      : Inserts at index.
   - 'delete(start, end)'        : Deletes range (end exclusive).
   - 'deleteCharAt(idx)'         : Deletes single character.
   - 'replace(start, end, str)'  : Replaces slice with string.
   - 'reverse()'                 : Reverses buffer in-place.
   - 'setCharAt(idx, ch)'        : Mutates single char at index.
