1. COUNTDOWNLATCH:
   - Initialized with count N.
   - 'await()': Blocks until count == 0.
   - 'countDown()': Atomically decrements count by 1.
   - One-Time Use ONLY (Cannot be reset or reused).
   - Use Case: Server startup (wait for DB, Cache, and Messaging to initialize).
