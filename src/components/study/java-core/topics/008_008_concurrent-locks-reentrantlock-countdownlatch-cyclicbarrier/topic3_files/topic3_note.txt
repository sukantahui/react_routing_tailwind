1. THE CONDITION INTERFACE:
   - Replaces 'wait/notify' with 'await()' and 'signal()'.
   - Created via 'lock.newCondition()'.
   - Enables multiple independent wait-sets per lock (e.g. 'notFull', 'notEmpty').
   - Eliminates CPU wake-up thrashing of 'notifyAll()'.
   - Powers Java's built-in 'ArrayBlockingQueue'.
