1. REENTRANTLOCK FEATURES:
   - 'tryLock()': Non-blocking instant attempt.
   - 'tryLock(timeout, unit)': Bounded timed acquisition.
   - 'lockInterruptibly()': Can be cancelled while queued.
   - 'new ReentrantLock(true)': Fair FIFO lock (eliminates starvation).
   - 'new ReentrantLock(false)': Non-fair (faster throughput via barging).
