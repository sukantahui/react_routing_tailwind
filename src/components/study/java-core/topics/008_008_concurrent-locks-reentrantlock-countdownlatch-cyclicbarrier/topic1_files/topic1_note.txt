1. THE REENTRANTLOCK IDIOM:
   - Interface: 'java.util.concurrent.locks.Lock'.
   - Standard Implementation: 'ReentrantLock'.
   - Rule 1: Call 'lock.lock()' immediately BEFORE 'try {'.
   - Rule 2: ALWAYS call 'lock.unlock()' in the 'finally {' block.
   - Reentrant: Same thread can acquire the lock multiple times without self-deadlock.
