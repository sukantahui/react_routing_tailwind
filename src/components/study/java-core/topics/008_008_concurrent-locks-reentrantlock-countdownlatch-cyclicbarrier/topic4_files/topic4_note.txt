1. REENTRANTREADWRITELOCK:
   - 'readLock()': Shared lock (N readers can read at the same time).
   - 'writeLock()': Exclusive lock (1 writer at a time, blocks all).
   - Read & Read → Concurrent.
   - Read & Write → Blocked.
   - Write & Write → Blocked.
