1. CYCLICBARRIER:
   - Synchronizes N parallel threads at a common rendezvous point.
   - Every thread calls 'barrier.await()'.
   - When the last thread arrives, optional 'barrierAction' runs.
   - REUSABLE: Automatically resets for subsequent computation rounds.
   - Ideal for multi-step parallel algorithms (e.g. scientific simulations).
