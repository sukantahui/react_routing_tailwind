1. LATCH vs BARRIER:
   - CountDownLatch: One-time gate, 1 master waits for N tasks to finish.
   - CyclicBarrier: Reusable barrier, N peer threads wait for each other.
   - Latch cannot reset; Barrier resets automatically after each round.
   - Barrier executes optional 'barrierAction' when all threads reach gate.
