1. READWRITELOCK CACHE ARCHITECTURE:
   - Wraps standard 'HashMap' with 'ReadWriteLock'.
   - 'get()' acquires 'readLock()'.
   - 'put()' acquires 'writeLock()'.
   - Best for: Read-heavy shared caches (>90% reads).
   - High multi-core speedup over synchronized HashMap.
