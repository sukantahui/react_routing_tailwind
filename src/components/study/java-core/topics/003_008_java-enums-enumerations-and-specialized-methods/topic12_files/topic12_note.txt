1. MODULE 003_008 SUMMARY:
   - Enums eliminate brittle int constants.
   - Enums implicitly extend java.lang.Enum and are final.
   - Safe to compare with '=='.
   - Built-in methods: name(), ordinal(), values(), valueOf().
   - Enums support fields, constructors, and constant-specific abstract methods.
   - EnumSet (bit-vector) and EnumMap (array-indexed) offer maximum performance.
   - Single-element Enum is the ultimate thread-safe, serialization-proof Singleton.
