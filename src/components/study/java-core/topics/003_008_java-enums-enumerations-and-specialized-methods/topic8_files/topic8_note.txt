1. POLYMORPHIC ENUM METHODS:
   - Declare 'public abstract double apply(double x, double y);' in enum.
   - Each constant overrides the method in its own anonymous subclass body.
   - Eliminates fragile switch statements.
   - Enforced at compile time for every new constant.
