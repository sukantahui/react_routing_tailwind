1. INT ENUM ANTI-PATTERN FLAWS:
   - Zero compile-time type safety.
   - Allows invalid integers like 999999.
   - Prints raw digits instead of descriptive names.

2. MODERN ENUM ADVANTAGES:
   - 100% Type-Safe.
   - Dedicated namespace.
   - Built-in toString(), equals(), hashCode().
