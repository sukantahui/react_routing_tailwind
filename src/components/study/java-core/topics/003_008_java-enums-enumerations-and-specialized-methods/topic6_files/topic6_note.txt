1. CUSTOM FIELDS & CONSTRUCTORS:
   - Constants listed first with constructor arguments: 'OK(200, "Success");'.
   - Fields should be 'private final' for immutability.
   - Semicolon ';' is mandatory after the last constant if members follow.
   - Constructor is implicitly private.
