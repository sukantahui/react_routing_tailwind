1. COMPILER SYNTHESIS:
   - 'public final class MyEnum extends java.lang.Enum<MyEnum>'
   - Constants are 'public static final' fields initialized with super(name, ordinal).
   - Cannot extend any class (already extends java.lang.Enum).
   - CAN implement interfaces.
