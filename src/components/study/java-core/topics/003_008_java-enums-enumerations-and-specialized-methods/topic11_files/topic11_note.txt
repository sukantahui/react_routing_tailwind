1. ENUMSET & ENUMMAP:
   - 'EnumSet.of(...)', 'EnumSet.allOf(...)', 'EnumSet.range(...)'.
   - EnumSet: Bit-vector representation (fastest possible Set).
   - EnumMap: Array-indexed Map without hashing or hash collisions.
   - Always prefer EnumSet/EnumMap whenever enum keys are used.
