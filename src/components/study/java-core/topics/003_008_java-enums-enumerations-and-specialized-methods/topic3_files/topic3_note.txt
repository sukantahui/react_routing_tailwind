1. CORE ENUM METHODS:
   - 'name()'            : Returns exact name String ('IN_TRAINING').
   - 'ordinal()'         : Returns 0-based declaration index (avoid for DB storage).
   - 'values()'          : Returns array of all constants in order.
   - 'valueOf("NAME")'   : Parses string to enum (throws IllegalArgumentException).
