1. LEGACY FLAWS (Pre-Java 8):
   - 'Date' and 'Calendar' are mutable.
   - Month 0 = January, Month 11 = December.
   - 'SimpleDateFormat' is not thread-safe.
   - Deprecated in modern code; replaced by 'java.time' (JSR-310).
