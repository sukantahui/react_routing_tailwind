1. TAXONOMY MAP:
   - 'LocalDate'     : Date only (2026-08-26).
   - 'LocalTime'     : Time only (14:30:00).
   - 'LocalDateTime' : Date + Time (2026-08-26T14:30:00).
   - 'ZonedDateTime' : Date + Time + Zone ('Asia/Kolkata').
   - 'Instant'       : UTC Epoch timestamp.
