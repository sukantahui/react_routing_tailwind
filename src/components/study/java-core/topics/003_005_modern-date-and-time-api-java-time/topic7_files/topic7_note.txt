1. ZONE RULES:
   - 'ZoneOffset': Fixed difference ('+05:30', '-05:00').
   - 'ZoneId': Region identifier ('Asia/Kolkata', 'America/New_York').
   - 'ZoneRules': Automatically shifts clocks by 1 hour during DST changes.
