1. MAX-HEAP IN JAVA:
   - Default PriorityQueue = Min-Heap.
   - Max-Heap syntax: 'new PriorityQueue<>(Collections.reverseOrder())'.
   - Root index 0 holds the maximum element.
   - Essential for Top-K largest problems and priority dispatching.
