1. QUEUE METHOD FAMILIES:
   - Insert  : 'add(e)' (Exception) vs 'offer(e)' (false).
   - Remove  : 'remove()' (Exception) vs 'poll()' (null).
   - Examine : 'element()' (Exception) vs 'peek()' (null).
   - Best practice: Prefer 'offer()', 'poll()', and 'peek()'.
