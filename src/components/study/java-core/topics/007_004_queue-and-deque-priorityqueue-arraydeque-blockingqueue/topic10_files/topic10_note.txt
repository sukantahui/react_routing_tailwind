1. ARRAYDEQUE CIRCULAR BUFFER:
   - Resizable circular array buffer ('elements[]').
   - 'head' and 'tail' indices wrap around circularly.
   - Bitwise wrap: '(head - 1) & (length - 1)'.
   - O(1) head and tail operations with zero array copying/shifting.
