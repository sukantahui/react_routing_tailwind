1. HEAP SIFTING OPERATIONS:
   - 'peek()' &rarr; O(1) instant root lookup ('queue[0]').
   - 'offer()' &rarr; O(log n) sift-up from tail.
   - 'poll()' &rarr; O(log n) sift-down from root.
   - 'remove(o)' &rarr; O(n) linear search + O(log n) sift.
