1. SPECIAL-VALUE METHODS:
   - 'offer(e)' → returns 'false' if bounded queue is full.
   - 'poll()' → returns 'null' if queue is empty.
   - 'peek()' → returns 'null' without removing head.
   - Zero exception allocation overhead; high throughput standard.
