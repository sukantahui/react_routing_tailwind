1. PRIORITY QUEUE CONTRACT:
   - Ordered by priority (Min-Heap by default).
   - Natural order: implements 'Comparable<T>'.
   - Custom order: pass 'Comparator<T>'.
   - 'poll()' extracts minimum element in O(log n).
   - For-each iteration does NOT guarantee sorted order (use poll()).
