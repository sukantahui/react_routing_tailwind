1. MIN-HEAP ARRAY MATHEMATICS:
   - Root (minimum): always at index 0 ('queue[0]').
   - Parent of 'i'     &rarr; '(i - 1) / 2'.
   - Left child of 'i'  &rarr; '2 * i + 1'.
   - Right child of 'i' &rarr; '2 * i + 2'.
   - Zero pointer overhead; stores complete binary tree in a flat array.
