1. EXCEPTION-THROWING METHODS:
   - 'remove()' &rarr; throws 'NoSuchElementException' if empty.
   - 'element()' &rarr; throws 'NoSuchElementException' if empty.
   - 'add(e)' &rarr; throws 'IllegalStateException' if bounded queue is full.
   - Use when failure indicates a critical defect in application logic.
