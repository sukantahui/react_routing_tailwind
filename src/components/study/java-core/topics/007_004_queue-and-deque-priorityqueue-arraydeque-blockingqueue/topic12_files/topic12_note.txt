1. LIFO STACK PATTERN:
   - Declare: 'Deque<T> stack = new ArrayDeque<>();'.
   - 'push(e)' → addFirst(e).
   - 'pop()' → removeFirst().
   - 'peek()' → peekFirst().
   - Ideal for expression parsing, depth-first search (DFS), and undo-redo stacks.
