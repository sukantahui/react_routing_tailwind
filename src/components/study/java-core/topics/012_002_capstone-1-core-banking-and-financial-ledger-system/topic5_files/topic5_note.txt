1. BIGDECIMAL RULES FOR BANKING:
   - Always instantiate via 'new BigDecimal("100.50")' or 'BigDecimal.valueOf(100.50)'.
   - NEVER use 'new BigDecimal(0.1)' (passes double representation error into BigDecimal!).
   - Always specify scale and 'RoundingMode.HALF_EVEN' during division.
