1. REENTRANTREADWRITELOCK IN BANKING:
   - Read lock  : Shared by multiple balance checking threads.
   - Write lock : Exclusive lock during money withdrawal or deposit.

2. FAIR LOCKING ('new ReentrantReadWriteLock(true)'):
   - Grants lock to longest waiting thread, preventing thread starvation.
