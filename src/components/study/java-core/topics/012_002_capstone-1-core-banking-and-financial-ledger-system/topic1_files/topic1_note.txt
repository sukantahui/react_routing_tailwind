1. DOMAIN MODELING RULES:
   - Monetary values : 'BigDecimal' (scaled to 2 or 4 decimals).
   - Identifiers     : 'UUID' or structured alphanumeric strings ('SB-BKP-101').
   - Timestamps      : 'Instant' (UTC ISO-8601).
   - Ledger Entries  : Pure immutable Java Records.
