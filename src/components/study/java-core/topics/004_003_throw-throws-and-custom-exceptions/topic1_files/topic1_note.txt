1. CORE STANDARD EXCEPTIONS:
   - 'IllegalArgumentException'     : Bad argument passed by caller.
   - 'IllegalStateException'        : Object not in valid state for call.
   - 'NoSuchElementException'       : Requested element does not exist.
   - 'UnsupportedOperationException': Method not supported by implementation.
