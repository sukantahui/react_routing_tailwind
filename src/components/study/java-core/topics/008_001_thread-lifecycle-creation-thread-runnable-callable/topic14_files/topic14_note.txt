1. LIVE STATE TRANSITIONS:
   - NEW → start() → RUNNABLE.
   - RUNNABLE → sleep(t) → TIMED_WAITING.
   - TIMED_WAITING → wait() → WAITING.
   - WAITING → notify() → BLOCKED / RUNNABLE.
   - RUNNABLE → exit run() → TERMINATED.
