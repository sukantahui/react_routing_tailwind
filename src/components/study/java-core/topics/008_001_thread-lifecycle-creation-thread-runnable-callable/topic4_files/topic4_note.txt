1. NEW & RUNNABLE STATES:
   - NEW: Thread instance created ('new Thread()'), OS thread not allocated yet.
   - RUNNABLE: 'start()' invoked; allocated native OS thread.
   - RUNNABLE encompasses both 'Ready' (in OS queue) and 'Running' (on CPU core).
   - Calling 'start()' on a thread twice throws 'IllegalThreadStateException'.
