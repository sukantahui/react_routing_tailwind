1. CREATION METHOD 1 (Extending Thread):
   - 'class MyThread extends Thread { public void run() { ... } }'.
   - Call 'myThread.start()' to begin execution.
   - Drawbacks: Burns single class inheritance slot.
   - Violates Single Responsibility (couples code with thread execution).
   - Prefer 'Runnable' or 'Callable' for enterprise code!
