1. THREAD PRIORITIES:
   - Range: 1 (MIN_PRIORITY) to 10 (MAX_PRIORITY); default is 5 (NORM_PRIORITY).
   - Merely hints to the underlying OS thread scheduler.
   - OS-dependent: Linux CFS often ignores Java thread priorities.
   - Never use priorities to enforce execution order!
   - Use CountDownLatch, Semaphore, or Locks instead.
