1. CREATION METHOD 2 (Implementing Runnable):
   - '@FunctionalInterface Runnable' defines 'void run()'.
   - Instantiate task: 'Runnable task = new MyTask()'.
   - Pass to thread: 'new Thread(task, "Name").start()'.
   - Allows class inheritance ('extends BaseClass').
   - Directly compatible with 'ExecutorService' thread pools.
