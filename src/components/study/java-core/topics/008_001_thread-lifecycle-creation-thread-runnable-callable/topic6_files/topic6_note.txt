1. TIMED_WAITING & TERMINATED:
   - TIMED_WAITING: entered via 'sleep(t)', 'wait(t)', 'join(t)'.
   - Wakes up when timeout expires OR if interrupted.
   - TERMINATED: run() finished normally or threw uncaught exception.
   - Dead threads CANNOT be restarted (throws 'IllegalThreadStateException').
