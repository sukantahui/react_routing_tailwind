1. START vs RUN:
   - 'thread.run()': plain synchronous method call on CURRENT stack (zero concurrency).
   - 'thread.start()': invokes native 'start0()', creates new OS thread & Call Stack.
   - Calling 'start()' twice throws 'IllegalThreadStateException'.
   - Always call 'start()' to achieve true multithreading!
