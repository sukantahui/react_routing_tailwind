1. JVM MEMORY FOR THREADS:
   - Shared Areas: Heap Memory (objects, static fields) & Metaspace.
   - Private Areas: Call Stack (local variables) & PC Register.
   - Local variables inside methods are inherently thread-safe (on private stack).
   - Shared heap objects require synchronization to prevent race conditions.
