1. THE 6 THREAD STATES:
   - NEW: instantiated, not started.
   - RUNNABLE: running or ready to run on CPU.
   - BLOCKED: waiting for 'synchronized' monitor lock.
   - WAITING: waiting indefinitely ('wait()', 'join()').
   - TIMED_WAITING: waiting for duration ('sleep()', 'wait(t)').
   - TERMINATED: dead/finished.
   - Query state: 'thread.getState()'.
