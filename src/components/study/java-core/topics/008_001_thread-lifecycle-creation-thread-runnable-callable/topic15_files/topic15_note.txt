1. CREATION APPROACH MATRIX:
   - Extends Thread: Burns inheritance, tightly coupled (avoid).
   - Runnable Class: Decoupled, preserves inheritance, void return.
   - Runnable Lambda: Zero boilerplate, inline fire-and-forget.
   - Callable<V>: Returns value, throws checked exceptions, ideal for ExecutorService.
