1. CREATION METHOD 4 (Callable & FutureTask):
   - 'Callable<V>' defines 'V call() throws Exception'.
   - Returns a typed value upon task completion.
   - Can throw checked exceptions.
   - Wrap in 'FutureTask<V>' to run via 'new Thread(futureTask).start()'.
   - Call 'futureTask.get()' to block and retrieve calculated result.
