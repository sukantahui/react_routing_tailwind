1. THREAD IDENTIFICATION:
   - 'Thread.currentThread()': returns reference to currently executing thread.
   - 'getName()' / 'setName("Descriptive-Name")': assigns human-readable name.
   - 'getId()' / 'threadId()': unique long integer identifier.
   - Always name threads explicitly to aid production thread dump analysis!
