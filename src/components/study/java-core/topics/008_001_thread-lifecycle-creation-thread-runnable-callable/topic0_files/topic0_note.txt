1. CONCURRENCY vs PARALLELISM:
   - Concurrency: Dealing with many tasks (interleaved time-slicing on 1 core).
   - Parallelism: Doing many tasks simultaneously (across multiple CPU cores).
   - Java threads can be concurrent (1 core) or parallel (multi-core).
   - Query cores: 'Runtime.getRuntime().availableProcessors()'.
