1. BLOCKED vs WAITING:
   - BLOCKED: Thread is waiting to acquire a 'synchronized' monitor lock.
   - WAITING: Thread is waiting indefinitely due to:
     * 'Object.wait()'
     * 'Thread.join()' (without timeout)
     * 'LockSupport.park()'
   - WAITING thread yields CPU and does NOT consume processor cycles.
