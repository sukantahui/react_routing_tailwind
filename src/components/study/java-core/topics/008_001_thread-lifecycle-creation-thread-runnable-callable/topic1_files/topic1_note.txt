1. PROCESS vs THREAD:
   - Process: Heavyweight, isolated memory space, high creation/switch cost.
   - Thread: Lightweight, shares heap memory within 1 process, fast switch.
   - 1 Java Process (JVM) contains many concurrent Threads.
   - Threads communicate directly via shared heap references.
