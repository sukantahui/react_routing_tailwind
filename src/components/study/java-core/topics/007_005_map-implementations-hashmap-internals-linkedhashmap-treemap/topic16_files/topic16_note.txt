1. LINKEDHASHMAP MODES:
   - Default: insertion-order (reflects put sequence).
   - Access-order: 'new LinkedHashMap<>(16, 0.75f, true)'.
   - 'get()' moves entry to TAIL (Most Recently Used).
   - HEAD always holds Least Recently Used (LRU) entry.
   - Singly hash buckets + global doubly linked list ('before', 'after').
