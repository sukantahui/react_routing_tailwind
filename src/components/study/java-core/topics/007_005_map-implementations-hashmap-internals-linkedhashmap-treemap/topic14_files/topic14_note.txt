1. IDEAL KEY PROPERTIES:
   - Immutability: State never mutates after creation.
   - Cached Hash: String caches 'hash' field to avoid re-computation.
   - Guaranteed consistency between 'equals()' and 'hashCode()'.
   - Prevents lost key / memory leak hazards.
