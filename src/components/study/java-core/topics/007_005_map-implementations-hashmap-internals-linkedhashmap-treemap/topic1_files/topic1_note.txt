1. CORE MAP METHODS:
   - 'getOrDefault(k, default)': avoids null checks.
   - 'containsKey(k)': O(1) hash bucket jump.
   - 'containsValue(v)': O(n) linear scan across all buckets.
   - 'entrySet()': iterate over key-value pairs efficiently in 1 pass.
