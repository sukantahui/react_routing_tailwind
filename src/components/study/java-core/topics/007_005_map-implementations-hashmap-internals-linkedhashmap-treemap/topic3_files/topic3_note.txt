1. HASHMAP PILLARS:
   - 'Node<K, V>[] table' bucket array.
   - Hash function: '(h = key.hashCode()) ^ (h >>> 16)'.
   - Index formula: '(n - 1) & hash'.
   - Initial Capacity: 16 (power of 2).
   - Load Factor: 0.75 (Threshold = 12).
   - Treeify at 8 nodes (>= 64 capacity); Untreeify at 6 nodes.
