1. MAP CONTRACT:
   - Key-Value pairs ('Map<K, V>').
   - Keys must be strictly unique.
   - Values may contain duplicates.
   - 'put(k, v)' overwrites existing value and returns the old value.
   - Independent hierarchy from 'java.util.Collection'.
