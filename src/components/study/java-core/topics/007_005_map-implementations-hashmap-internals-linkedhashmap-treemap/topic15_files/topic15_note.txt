1. LOST KEY HAZARD:
   - Never use mutable objects as Map keys.
   - Mutating key fields changes 'hashCode()'.
   - 'get()' and 'containsKey()' look in the wrong bucket and return null/false.
   - Trapped entry causes silent heap memory leak.
   - Best practice: Use immutable objects (String, Integer, Records) as keys.
