1. LRU CACHE RECIPE:
   - Extends 'LinkedHashMap<K, V>'.
   - Constructor: 'super(capacity, 0.75f, true)'.
   - Override: 'protected boolean removeEldestEntry(Map.Entry eldest)'.
   - Return 'size() > maxCapacity'.
   - O(1) reads, O(1) writes, automatic O(1) eviction!
