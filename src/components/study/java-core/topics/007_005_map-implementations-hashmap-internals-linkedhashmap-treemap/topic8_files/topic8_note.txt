1. BUCKET INDEX FORMULA:
   - 'index = (n - 1) & hash'.
   - 'n' is table length (always power of 2).
   - Bitmask '(n - 1)' filters lower bits.
   - Mathematically identical to 'hash % n'.
   - 1 CPU clock cycle vs 20-40 cycles for division.
