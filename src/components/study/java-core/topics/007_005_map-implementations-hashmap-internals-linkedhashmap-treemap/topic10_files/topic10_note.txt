1. TREEIFICATION RULES:
   - Trigger: 8 collisions in a single bucket.
   - Pre-condition: Table capacity >= 64 ('MIN_TREEIFY_CAPACITY').
   - Replaces 'Node<K, V>' with 'TreeNode<K, V>' (Red-Black Tree).
   - Improves worst-case search from O(n) to O(log n).
   - Defends against HashDoS security vulnerabilities.
