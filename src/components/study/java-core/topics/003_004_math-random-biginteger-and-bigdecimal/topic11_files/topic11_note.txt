1. EQUALITY COMPARISON:
   - 'a.equals(b)'      : Compares VALUE + SCALE ('2.0' != '2.00').
   - 'a.compareTo(b)==0': Compares MATHEMATICAL VALUE ONLY ('2.0' == '2.00').
   - HashSet uses 'equals()'; TreeSet uses 'compareTo()'.
