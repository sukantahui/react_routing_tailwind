1. INSTANTIATION RULES:
   - FORBIDDEN : 'new BigDecimal(0.1)' → Imprecise double input.
   - PREFERRED : 'new BigDecimal("0.1")' → Pristine string input.
   - ACCEPTABLE: 'BigDecimal.valueOf(0.1)' → Uses Double.toString().
