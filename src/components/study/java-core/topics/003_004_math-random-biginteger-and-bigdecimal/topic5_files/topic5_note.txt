1. IEEE 754 ESSENTIALS:
   - 0.1 and 0.2 are repeating fractions in base-2 binary.
   - '0.1 + 0.2 == 0.3' evaluates to 'false'.
   - Produces '0.30000000000000004'.
   - Solution: Use 'BigDecimal' for exact decimal arithmetic!
