1. MATH METHODS CHEATSHEET:
   - 'Math.abs(n)'   : Absolute value.
   - 'Math.ceil(d)'  : Rounds up → double.
   - 'Math.floor(d)' : Rounds down → double.
   - 'Math.round(d)' : Nearest integer → long.
   - 'Math.pow(a, b)': $a^b$ → double.
   - 'Math.sqrt(d)'  : Square root → double.
