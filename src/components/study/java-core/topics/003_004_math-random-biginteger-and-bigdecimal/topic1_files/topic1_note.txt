1. MATH METHODS CHEATSHEET:
   - 'Math.abs(n)'   : Absolute value.
   - 'Math.ceil(d)'  : Rounds up &rarr; double.
   - 'Math.floor(d)' : Rounds down &rarr; double.
   - 'Math.round(d)' : Nearest integer &rarr; long.
   - 'Math.pow(a, b)': $a^b$ &rarr; double.
   - 'Math.sqrt(d)'  : Square root &rarr; double.
