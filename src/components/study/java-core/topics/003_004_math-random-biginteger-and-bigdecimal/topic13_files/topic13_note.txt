1. MODULE 003_004 SUMMARY:
   - 'java.lang.Math' provides static constants and exact overflow math.
   - 'SecureRandom' is mandatory for tokens and OTPs.
   - IEEE 754 float/double fails for money; NEVER use for finance.
   - 'BigDecimal' provides exact monetary precision (use String constructor).
   - Use 'compareTo() == 0' instead of 'equals()' for BigDecimal values.
   - 'BigInteger' powers RSA cryptography with 'modPow()', 'gcd()', and 'probablePrime()'.
