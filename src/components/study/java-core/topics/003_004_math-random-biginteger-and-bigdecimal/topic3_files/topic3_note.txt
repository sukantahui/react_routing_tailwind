1. RANDOM GENERATION FORMULAS:
   - 'Math.random()' returns '[0.0, 1.0)'.
   - Range [min, max]: '(int)(Math.random() * (max - min + 1)) + min'.
   - 'Random.nextInt(bound)' returns '[0, bound - 1]'.
