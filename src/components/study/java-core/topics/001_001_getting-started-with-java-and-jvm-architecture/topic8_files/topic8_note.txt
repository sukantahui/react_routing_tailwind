1. CHOOSING AN OPENJDK DISTRIBUTION
--------------------------------------------------------------------------------
- Eclipse Temurin (Adoptium): Industry standard, 100% open-source, vendor-neutral.
- Amazon Corretto: Production-grade, long-term enterprise OpenJDK distribution.
- Oracle OpenJDK / Oracle JDK: Official Oracle builds (free under NFTC for development).
- Microsoft OpenJDK: Optimized for Azure and Windows cloud deployments.

2. STEP-BY-STEP INSTALLATION & ENVIRONMENT CONFIGURATION

A. WINDOWS CONFIGURATION
1. Download JDK 21 LTS (or modern LTS) installer/zip and install to `C:\Program Files\Java\jdk-21`.
2. Open System Environment Variables (Start → search "env").
3. Under System Variables, click "New":
   - Variable name: `JAVA_HOME`
   - Variable value: `C:\Program Files\Java\jdk-21`  (Notice: NO \bin at the end!)
4. Under System Variables, select `Path` → click "Edit":
   - Add new entry: `%JAVA_HOME%\bin`
   - Move to top to take precedence.
5. Verification in new PowerShell / CMD:
   `javac -version`
   `java -version`

B. LINUX / MACOS CONFIGURATION
1. Linux (Ubuntu/Debian):
   `sudo apt update && sudo apt install openjdk-21-jdk`
2. Add to `~/.bashrc` or `~/.zshrc`:
   `export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64`
   `export PATH=$JAVA_HOME/bin:$PATH`
3. Reload shell: `source ~/.bashrc`

3. QUICK CHECKLIST
--------------------------------------------------------------------------------
[✓] `JAVA_HOME` must point to the ROOT directory (e.g. `C:\Program Files\Java\jdk-21`).
[✓] `PATH` must contain `%JAVA_HOME%\bin` (Windows) or `$JAVA_HOME/bin` (Linux/Mac).
[✓] Always open a FRESH terminal after saving environment variables.
