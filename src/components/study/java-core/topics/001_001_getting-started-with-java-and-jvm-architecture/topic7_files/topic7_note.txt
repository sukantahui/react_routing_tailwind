1. THE FIVE INTERNAL PHASES OF JAVAC
--------------------------------------------------------------------------------
1. Lexical Analysis (Scanning / Tokenization):
   - Reads raw source characters and groups them into meaningful tokens (keywords, identifiers, literals, operators).

2. Syntax Analysis (Parsing):
   - Validates tokens against Java grammar rules and builds an Abstract Syntax Tree (AST).

3. Semantic Analysis (Enter, Attr, Flow):
   - Symbol resolution: Registers symbols in the Symbol Table.
   - Type Checking (Attribution): Verifies variable assignment types, method parameter compatibility, and return types.
   - Flow Analysis: Checks variable reachability, definite assignment, and checked exception handling.

4. Desugaring (TransTypes, Lower):
   - Replaces high-level syntactic sugar with lower-level Java primitives:
     * Generics -> Raw types with Type Erasure & cast insertions.
     * Enhanced for-each loop -> Iterators / index loops.
     * Autoboxing -> `Integer.valueOf()` / `intValue()`.
     * String concatenation -> `StringBuilder` / `invokedynamic`.

5. Code Generation (Gen):
   - Emits standardized binary .class bytecode with `0xCAFEBABE` header, Constant Pool, and method bytecode arrays.

2. QUICK CHECKLIST
--------------------------------------------------------------------------------
[✓] `javac` does NOT create native machine code; it creates Bytecode.
[✓] Type erasure occurs during desugaring inside `javac`.
[✓] `javap -c` allows inspecting generated bytecode opcodes.
[✓] Syntactic sugar is completely unwrapped during compilation.
