1. INTRODUCTION
Java is a versatile programming language conceived in June 1991 by James Gosling, Mike Sheridan, and Patrick Naughton. Originally named "Oak" after an oak tree outside Gosling's office, it was later renamed Java (inspired by Java coffee from Indonesia) and officially launched in 1995.

2. PHILOSOPHY OF PLATFORM INDEPENDENCE
In traditional languages like C and C++, the compiler directly translates human-readable source code into machine code specific to the host CPU architecture (e.g. x86_64, ARM) and operating system (Windows PE, Linux ELF). Hence, a C binary compiled on Windows cannot execute on a Linux server without recompilation.

Java revolutionized this model by introducing an intermediate abstraction layer called "Bytecode":
1. Programmer writes: `HelloWorld.java`
2. Java Compiler (`javac`) produces: `HelloWorld.class` (Bytecode)
3. Java Virtual Machine (`java` / JVM) executes the bytecode on the host OS.

The JVM is platform-dependent (there is a JVM for Windows, a JVM for Linux, a JVM for macOS), but the bytecode it consumes is 100% platform-independent.

3. ENTERPRISE RELEVANCE
Why does Java dominate enterprise IT?
- Backwards Compatibility: Code written in Java 1.4 in 2002 still compiles and runs on Java 21 LTS in 2026.
- Robust Memory Safety: Automatic Garbage Collection reclaims unreferenced heap memory, eliminating memory leaks and segmentation faults caused by manual malloc/free calls.
- Massive Ecosystem: Millions of open-source libraries, frameworks (Spring Boot, Hibernate, Apache Commons), and developer tooling.
- Concurrency and Scalability: First-class multithreading primitives and modern Project Loom Virtual Threads supporting millions of simultaneous connections.

4. REAL-WORLD DOMAINS
- Banking & Financial Services: Account ledgers, transaction processing, fraud detection.
- E-Commerce: Order processing, inventory synchronization, payment gateways.
- Big Data Infrastructure: Distributed stream processing with Apache Kafka, batch processing with Spark.
- Android Ecosystem: Over 3 billion active Android smartphones running Java-based apps and services.
