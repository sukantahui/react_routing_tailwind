1. HISTORICAL GENESIS
--------------------------------------------------------------------------------
- 1991: Green Project initiated by James Gosling, Mike Sheridan, and Patrick Naughton at Sun Microsystems. Designed for interactive cable TV and embedded home appliances.
- Originally named "Oak" after the oak tree standing outside Gosling's office window.
- 1995: Renamed to "Java" (inspired by aromatic Java coffee from Indonesia) and officially unveiled at SunWorld conference.
- Netscape Navigator incorporated Java support, triggering explosive web adoption.

2. MAJOR MILESTONES IN THE JAVA EVOLUTION
--------------------------------------------------------------------------------
- JDK 1.0 (1996): Initial release. Basic AWT, WORA, primitive types, Applets.
- J2SE 1.2 (1998): Renamed to Java 2. Introduced Collections Framework and Swing.
- J2SE 5.0 / Java 5 (2004): Major quantum leap. Generics, Enums, Autoboxing/Unboxing, Varargs, Annotations, Enhanced for-each loop, java.util.concurrent.
- Java SE 6 (2006): Scripting API, JDBC 4.0, compiler performance upgrades.
- 2010: Oracle Corporation acquires Sun Microsystems.
- Java SE 7 (2011): Try-with-resources (ARM), Diamond operator (<>), Strings in switch, ForkJoinPool, NIO.2 (Files, Path).
- Java SE 8 LTS (2014): The biggest paradigm shift. Lambda Expressions, Functional Interfaces, Stream API, Modern java.time API, Optional, Default/Static interface methods.
- Java SE 9 (2017): Java Platform Module System (JPMS / Project Jigsaw), jlink, jshell REPL.
- Java SE 11 LTS (2018): New 6-month release cadence established. HTTP Client (java.net.http), String utility methods (isBlank, strip), local-variable syntax for lambdas (var).
- Java SE 17 LTS (2021): Sealed Classes, Records, Pattern Matching for instanceof, Text Blocks.
- Java SE 21 LTS (2023): Virtual Threads (Project Loom), Pattern Matching for switch, Record Patterns, Sequenced Collections.

3. MODERN RELEASE CADENCE (LTS vs NON-LTS)
--------------------------------------------------------------------------------
- Feature Releases: Every 6 months (March & September).
- Long-Term Support (LTS) Releases: Designated every 2 years for multi-year enterprise support.
- Industry Standard LTS Production Versions: Java 8, Java 11, Java 17, and Java 21.
