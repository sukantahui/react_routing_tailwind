1. FORMAL PROBLEM DEFINITION & CAPSTONE ALGORITHMIC SPECIFICATIONS
--------------------------------------------------------------------------------
PROBLEM 12: Segment 1 Timed Coding Assessment (Comprehensive Capstone)
- Objective: Integrate algorithms across all Segment 1 foundational pillars
  into a unified evaluation and academic billing engine without external libraries.
- Specification 12A (Matrix Diagonals & Binary Search):
  * Matrix Diagonal Sum: Given an N x N square matrix, accumulate primary diagonal
    matrix[i][i] and secondary diagonal matrix[i][n-1-i] in O(N) time.
    If N is odd, deduct the intersecting center matrix[n/2][n/2] once.
  * Recursive Binary Search: Perform divide-and-conquer target lookup in a sorted
    array with overflow-safe midpoint calculation: mid = low + (high - low) / 2.
    Return 0-based target index or -1 if absent. Time complexity: O(log N).
- Specification 12B (Sieve Roll Primality & 18% GST Ledger):
  * In-Memory Sieve: Precompute boolean[] prime table up to max roll in O(N log log N).
  * Academic Tier Dispatch: Switch expression on AcademicTier enum:
    - DISTINCTION  (score >= 90) : 25% waiver
    - FIRST_CLASS  (score >= 75) : 15% waiver
    - SECOND_CLASS (score >= 60) : 5% waiver
    - PASS / FAIL  (score < 60)  : 0% waiver
  * Statutory GST Invoicing:
    - netBeforeTax = baseFeeInr - scholarshipInr
    - finalPayableFeeInr = netBeforeTax * 1.18 (18% GST in India)
    - Output: CapstoneCandidateResult record.
- Constraints: Pure primitive arrays and records. Zero collections.
