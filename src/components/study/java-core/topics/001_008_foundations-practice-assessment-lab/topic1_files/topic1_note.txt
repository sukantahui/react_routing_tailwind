1. FORMAL PROBLEM DEFINITION & SPECIFICATIONS
--------------------------------------------------------------------------------
PROBLEM 1A: Classical Sieve of Eratosthenes
- Objective: Find and mark all prime numbers in the range [2..limit].
- Input: int limit (N >= 2).
- Output: boolean[] isPrime (size N + 1, where isPrime[i] is true iff i is prime).
- Constraints: O(N log(log N)) time, O(N) auxiliary space.
- Invariants: Outer loop stops at p * p <= N; inner loop begins at p * p.

PROBLEM 1B: Bit-Packed Primitive Sieve
- Objective: Pack 32 primality flags per 32-bit int using bitwise shifts.
- Formula: compositeBits[p >> 5] |= (1 << (p & 31)) to mark composite.
- Memory: 32x reduction compared to boolean arrays (~12.5 MB for 100M limit).

2. CORE ALGORITHM MECHANICS
--------------------------------------------------------------------------------
- What is Sieve of Eratosthenes?
  * An optimal algorithm to find all primes up to limit N in O(N log(log N)) time.
  * Initialize boolean[] isPrime of size N + 1 with true; set 0 and 1 to false.

- The 2 Invariant Optimizations:
  1. Outer Loop Bound  : Runs only up to sqrt(N) → 'for (int p = 2; p * p <= limit; p++)'.
  2. Inner Loop Start  : Starts marking composites at p * p → 'for (int m = p * p; m <= limit; m += p)'.
     (Smaller multiples 2p, 3p, ... (p-1)p were already marked by earlier primes!).

- Memory Efficiency:
  * Standard boolean[] uses 1 byte (8 bits) per entry (~100 MB for 100M numbers).
  * Primitive int[] bit array uses exactly 1 bit per entry via bitwise operators (~12.5 MB for 100M numbers, 8x less!).
