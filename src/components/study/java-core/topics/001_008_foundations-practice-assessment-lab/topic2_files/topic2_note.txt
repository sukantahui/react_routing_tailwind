1. FORMAL PROBLEM DEFINITION & SPECIFICATIONS
--------------------------------------------------------------------------------
PROBLEM 2A: Integer Palindrome via Half-Reversal
- Objective: Determine if 32-bit signed integer x is a palindrome without
  converting it to String and without risking 32-bit integer overflow.
- Input: int x (-2^31 <= x <= 2^31 - 1).
- Output: boolean (true if x is a palindrome, false otherwise).
- Invariant: Loop while (x > reversedHalf); stop at midpoint.

PROBLEM 2B: Two-Pointer Alphanumeric Phrase Palindrome
- Objective: Determine if string s is a palindrome considering only alphanumeric
  characters and ignoring case differences.
- Input: String s (raw text with punctuation and whitespace).
- Output: boolean (true if alphanumeric subsequence is a palindrome).
- Constraints: O(N) time, O(1) auxiliary space using inward pointers.

2. CORE ALGORITHM MECHANICS
--------------------------------------------------------------------------------
- Integer Palindrome (Half-Reversal Optimization):
  * Negative numbers are NEVER palindromes (if (x < 0) return false;).
  * Numbers ending in 0 (except 0) are NEVER palindromes (if (x % 10 == 0 && x != 0) return false;).
  * Reversing only half: while (x > rev) { rev = rev * 10 + x % 10; x /= 10; }
  * Check: (x == rev) || (x == rev / 10) → Completely eliminates integer overflow!

- String Palindrome (Two-Pointer In-Place O(1) Space):
  * Pointers left = 0, right = s.length() - 1.
  * Skip non-alphanumerics with Character.isLetterOrDigit().
  * Compare case-insensitively with Character.toLowerCase().
  * Increment left, decrement right until pointers meet.

3. ESSENTIAL CHECKLIST
--------------------------------------------------------------------------------
[✓] Integer half-reversal: O(log10 N) Time | O(1) Space | Zero Overflow Risk.
[✓] Two-pointer string scan: O(N) Time | O(1) Space | In-Place Memory.
[✓] Single character ('A', 7) and empty string ("") are valid palindromes.
