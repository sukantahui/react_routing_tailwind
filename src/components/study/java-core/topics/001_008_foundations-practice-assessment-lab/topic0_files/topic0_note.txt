1. FORMAL PROBLEM DEFINITION & ARCHITECTURAL SPECIFICATIONS
--------------------------------------------------------------------------------
PROBLEM 0: Integrated Academic Ledger & Student Grading Synthesis Engine
- Objective: Engineer a robust, modular terminal billing and grading engine
  unifying all 7 Segment 1 foundational pillars without using collections.
- Input: StudentRecord[] (name, campus, int[] testScores, baseTuition, waiverPct).
- Output: Terminal ledger display with average scores, switch-evaluated letter
  grades, net tuition fees in Indian Rupees (₹), and 18% GST computations.
- Constraints:
  * Zero Collections (ArrayList, List, Map forbidden).
  * Pure primitive arrays, static methods, loops, switch expressions, records.
  * Fail-safe handling for null or empty test score arrays.
