1. FORMAL PROBLEM DEFINITION & ASSESSMENT ENGINE SPECIFICATIONS
--------------------------------------------------------------------------------
PROBLEM 11: Automated MCQ Exam & Scholarship Engine
- Objective: Implement an automated Multiple Choice Question (MCQ) assessment
  engine evaluating student submissions across the 7 core Java Foundations
  modules (001_001..007) using pure primitive arrays, without Java Collections.
- Specification 11A (Exam Bank & Submission Evaluator):
  * Input: `ExamQuestion[] questions`, `int[] studentAnswers`.
    `ExamQuestion` record: (questionId, moduleTopic, questionText, options[], correctIndex, explanation).
  * Output: `StudentExamResult` record:
    (studentName, totalQuestions, correctAnswers, scorePercentage, letterGrade, scholarshipAwardInr).
  * Algorithm: Iterate through `questions`; match `studentAnswers[i] == questions[i].correctOptionIndex()`.
  * Guard: Bounds check `i < studentAnswers.length` against partial submissions.
- Specification 11B (Automated Grading & Scholarship Dispatch):
  * Percentage Formula: `((double) correctAnswers / totalQuestions) * 100.0`.
  * Tier Breakdown:
    - Grade 'A' (>= 90.0%): Merit Award ₹5,000.00
    - Grade 'B' (>= 80.0% & < 90.0%): Merit Award ₹2,500.00
    - Grade 'C' (>= 70.0% & < 80.0%): Merit Award ₹0.00
    - Grade 'F' (< 70.0%): Fail / ₹0.00
- Constraints: Pure primitive arrays (`ExamQuestion[]`, `int[]`). Zero collections.
