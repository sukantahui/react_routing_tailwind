1. JVM TERMINATION RULE:
   - JVM exits when active User thread count reaches ZERO.
   - All Daemon threads are instantly killed mid-flight.
   - 'finally' blocks in Daemon threads do NOT run during JVM exit.
   - Never write database commits or file streams inside daemon threads.
