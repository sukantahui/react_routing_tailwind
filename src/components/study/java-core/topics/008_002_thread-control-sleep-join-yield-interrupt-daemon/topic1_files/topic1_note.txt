1. RESTORING INTERRUPT STATUS:
   - JVM clears interrupt flag when throwing 'InterruptedException'.
   - NEVER swallow 'InterruptedException' with an empty catch block!
   - Option A: Rethrow 'InterruptedException' to caller.
   - Option B: Restore status via 'Thread.currentThread().interrupt()'.
   - Allows framework and upstream loops to gracefully terminate.
