1. BOUNDED JOIN TIMEOUTS:
   - 't.join(millis)' puts calling thread in 'TIMED_WAITING'.
   - Returns when target thread terminates OR timeout expires (whichever comes first).
   - Check 't.isAlive()' after timeout to see if thread finished.
   - Prevents cascading production deadlocks and infinite thread hangs.
