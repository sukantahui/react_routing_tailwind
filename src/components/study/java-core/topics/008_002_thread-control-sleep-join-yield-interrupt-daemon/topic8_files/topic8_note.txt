1. USER vs DAEMON THREADS:
   - User Threads: Core business logic; JVM stays alive until all User threads finish.
   - Daemon Threads: Background helpers (GC, health monitor); JVM kills them when User threads die.
   - Method: 'thread.setDaemon(true)'.
   - 'isDaemon()' queries daemon status.
