1. SETDAEMON() RULES:
   - Must be called while thread is in 'NEW' state (before 'start()').
   - Calling after 'start()' &rarr; throws 'IllegalThreadStateException'.
   - A thread created by a daemon thread automatically inherits daemon status.
   - A thread created by a user thread defaults to user thread.
