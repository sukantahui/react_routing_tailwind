1. THE 3 INTERRUPT METHODS:
   - 't.interrupt()': sets interrupt flag = true on target thread.
   - 't.isInterrupted()': returns true/false without changing flag.
   - 'Thread.interrupted()': static check for current thread + CLEARS flag to false!
   - Calling 'Thread.interrupted()' twice in a row returns false second time.
