1. THREAD.JOIN():
   - 't.join()' blocks the CALLING thread until 't' finishes.
   - Puts calling thread in 'WAITING' state.
   - Throws checked 'InterruptedException'.
   - If 't' is already terminated, 't.join()' returns immediately.
   - Essential for fork-join aggregation patterns.
