1. THREAD.SLEEP(MILLIS):
   - Static method pausing currently executing thread.
   - Transitions thread to 'TIMED_WAITING' state.
   - Throws checked 'InterruptedException'.
   - NEVER releases locks (holds onto synchronized monitors!).
   - In contrast: 'Object.wait()' releases monitor locks.
