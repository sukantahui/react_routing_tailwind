1. DEPRECATED THREAD METHODS:
   - 'Thread.stop()': Releases all locks immediately mid-operation &rarr; Data corruption!
   - 'Thread.suspend()': Freezes thread while keeping locks &rarr; Deadlocks!
   - 'Thread.resume()': Unreliable pair of suspend().
   - Modern Rule: Use Cooperative Cancellation via 'Thread.interrupt()'.
