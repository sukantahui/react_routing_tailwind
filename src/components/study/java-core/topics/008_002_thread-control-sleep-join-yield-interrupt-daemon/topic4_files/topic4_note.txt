1. THREAD.YIELD():
   - Voluntary hint to OS scheduler to give up remaining CPU time-slice.
   - Thread remains in 'RUNNABLE' state.
   - Does NOT release locks.
   - Non-deterministic and platform dependent.
   - Rarely used in application logic (useful in busy-wait spinlocks).
