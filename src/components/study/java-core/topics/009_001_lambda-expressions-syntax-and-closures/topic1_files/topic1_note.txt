1. LAMBDA ANATOMY:
   - Syntax: '(parameters) → { body }'
   - 1. Parameter List: Arguments received by the SAM interface method.
   - 2. Arrow Token ('->'): Connects parameters to the implementation.
   - 3. Body: Single expression or block of statements.
