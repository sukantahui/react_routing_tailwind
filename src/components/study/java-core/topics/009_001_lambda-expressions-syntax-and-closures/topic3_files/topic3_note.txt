1. TARGET TYPING:
   - A lambda has NO standalone type.
   - Type is inferred from context (variable, parameter, return, cast).
   - Target must be a Functional Interface matching method signature.
   - The same lambda can bind to different interfaces (e.g. Callable vs Supplier).
