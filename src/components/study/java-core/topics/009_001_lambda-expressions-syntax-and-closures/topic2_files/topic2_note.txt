1. LAMBDA SYNTAX RULES:
   - Type inference: '(a, b) → a + b' (Types omitted).
   - Single parameter: 'x → x * x' (Parentheses omitted).
   - Zero parameters: '() → "Hello"' (Empty parentheses mandatory).
   - Single expression: Omit curly braces AND 'return' keyword together.
   - Multi-statement: Curly braces and explicit 'return;' are mandatory.
