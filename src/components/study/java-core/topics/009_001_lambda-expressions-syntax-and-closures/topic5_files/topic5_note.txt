1. @FUNCTIONALINTERFACE ANNOTATION:
   - Optional, but strongly recommended (Best Practice).
   - Instructs compiler to verify exactly ONE abstract method.
   - Throws compile error if 0 or 2+ abstract methods are added.
   - Documents design intent clearly for other developers and Javadoc.
