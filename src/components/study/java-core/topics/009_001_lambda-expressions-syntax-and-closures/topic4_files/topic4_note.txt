1. FUNCTIONAL INTERFACE (SAM):
   - Exactly ONE abstract method (SAM: Single Abstract Method).
   - Can have unlimited 'default' methods.
   - Can have unlimited 'static' methods.
   - Public 'java.lang.Object' methods (equals, hashCode) do not count as SAM.
   - Acts as the target type for all lambda expressions.
