1. MODULE 009_001 GRAND SUMMARY:
   - Functional Programming: Unifies OOP with declarative, immutable data pipelines.
   - Lambda Anatomy: '(parameters) -> { body }'.
   - Syntax Shortcuts: Inferred types, single-param no-parentheses, single-expression no-return.
   - Target Typing: Compiler infers lambda type from assignment/argument context.
   - SAM Rule: Functional Interfaces declare exactly ONE abstract method.
   - @FunctionalInterface: Compiler guard protecting SAM contracts.
   - invokedynamic: Lambdas use INDY bytecode (0 synthetic .class disk files).
   - Lexical Scoping: 'this' inside lambda refers to enclosing outer class instance.
   - Effectively Final: Captured local variables must be assigned once and never mutated.
   - Why Mutation Prohibited: Stack variables die after return; prevents multi-thread race conditions.
