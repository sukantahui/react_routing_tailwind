1. EFFECTIVELY FINAL RULE:
   - Capturing: Lambda copies local variables into its closure.
   - Captured local variables MUST be 'final' or 'Effectively Final'.
   - 'Effectively Final' = Assigned once, never modified.
   - Instance and static fields CAN be read and mutated (they live on heap).
