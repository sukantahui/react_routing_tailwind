1. LEXICAL SCOPING IN LAMBDAS:
   - Lambdas do NOT create their own 'this' scope.
   - 'this' inside a lambda = 'this' of the enclosing outer class.
   - 'super' inside a lambda = 'super' of the enclosing outer class.
   - Variable names cannot shadow outer variables (e.g. 'int x' cannot be re-declared in lambda parameter).
