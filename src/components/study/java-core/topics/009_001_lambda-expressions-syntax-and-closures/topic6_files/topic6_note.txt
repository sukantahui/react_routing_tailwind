1. ANONYMOUS CLASSES vs LAMBDAS:
   - Anonymous class creates 'Outer$1.class' file on disk.
   - Lambda generates 'invokedynamic' bytecode (no extra .class files).
   - Non-capturing lambdas are cached as singletons (0 allocation).
   - Anonymous 'this' = anonymous object; Lambda 'this' = enclosing outer object.
