1. METADATA INSPECTION METHODS:
   - 'getSuperclass()': Returns Class representing the superclass (returns null for Object & interfaces).
   - 'getInterfaces()': Returns 'Class<?>[]' of directly implemented interfaces.
   - 'getModifiers()': Returns an integer bitmask of modifiers.
   - 'isInterface()', 'isArray()', 'isPrimitive()', 'isEnum()', 'isRecord()', 'isAnnotation()'.

2. MODIFIER UTILITY CLASS ('java.lang.reflect.Modifier'):
   - Helper methods: 'Modifier.isPublic(mod)', 'Modifier.isStatic(mod)', 'Modifier.isFinal(mod)'.
   - 'Modifier.toString(mod)': Formats bitmask into a clean modifier string.
