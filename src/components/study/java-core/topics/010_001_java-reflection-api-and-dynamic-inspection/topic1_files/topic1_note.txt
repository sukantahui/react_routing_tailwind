1. FRAMEWORK ARCHITECTURE POWERED BY REFLECTION:
   - Spring Framework:
     * Scans for '@Component', '@Service', '@Repository'.
     * Instantiates beans via 'constructor.newInstance()'.
     * Injects dependencies into fields annotated with '@Autowired'.
   - Hibernate / JPA:
     * Scans for '@Entity', '@Table', '@Column'.
     * Maps database table rows into private entity fields via 'field.set()'.
   - Jackson / Gson:
     * Scans getters/fields to serialize objects to JSON strings and deserialize back.
   - JUnit 5:
     * Discovers and invokes all methods annotated with '@Test'.
