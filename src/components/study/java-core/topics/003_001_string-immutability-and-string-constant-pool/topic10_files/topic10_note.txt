1. SUBSTRING & REPLACEMENT RULES:
   - 'substring(begin, end)' : 'begin' is INCLUSIVE, 'end' is EXCLUSIVE.
   - 'replace(target, repl)' : Literal string replacement (no regex).
   - 'replaceAll(regex, repl)': Regular expression replacement.
   - 'replaceFirst(regex, r)': Replaces only the first regex match.
