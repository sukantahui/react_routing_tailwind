1. STRING EQUALITY RULES:
   - '=='       : Reference identity (Do they point to the exact same RAM address?).
   - '.equals()': Semantic content equality (Are the characters identical?).
   - Compile-time constants ('"a" + "b"') are folded by javac into SCP.
