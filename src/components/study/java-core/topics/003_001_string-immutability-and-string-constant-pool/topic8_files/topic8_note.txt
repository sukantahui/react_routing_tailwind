1. INSPECTION METHODS:
   - 'length()'             : Total number of 16-bit char code units.
   - 'isEmpty()'            : 'length() == 0'.
   - 'isBlank()' (Java 11+) : True if empty or all whitespaces.
   - 'charAt(idx)'          : Char at index (0-indexed).
   - 'indexOf(sub)'         : First occurrence index (-1 if missing).
   - 'contains(seq)'        : True if substring is present.
