1. SCP REUSE MECHANISM:
   - When a literal is encountered, JVM checks if it exists in SCP.
   - If present &rarr; Returns existing pooled reference.
   - If absent  &rarr; Creates new string in SCP and returns reference.
   - Flyweight design pattern implemented at JVM bytecode level.
