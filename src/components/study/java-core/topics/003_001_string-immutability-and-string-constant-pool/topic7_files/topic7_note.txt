1. COMPARISON METHODS:
   - 'equalsIgnoreCase(str)'     : Returns true/false ignoring uppercase/lowercase.
   - 'compareTo(str)'            : Returns negative, 0, or positive (Unicode diff).
   - 'compareToIgnoreCase(str)'  : Alphabetical sort comparison ignoring case.
