1. THE 4 IMMUTABILITY PILLARS:
   - SCP Sharing  : Shared references remain isolated and uncorrupted.
   - Security     : Network/DB connection strings cannot be hijacked.
   - Concurrency  : Thread-safe without 'synchronized' locks.
   - Hash Caching : 'hash' integer cached on first calculation for fast HashMap lookups.
