1. TRANSFORMATION METHODS:
   - 'toLowerCase()' / 'toUpperCase()' : Generates new case string.
   - 'trim()'                          : Legacy ASCII whitespace strip.
   - 'strip()' (Java 11+)              : Unicode-aware whitespace strip.
   - 'stripLeading()' / 'stripTrailing()': Strips start or end whitespace.
   - 'repeat(n)' (Java 11+)            : Concatenates string n times.
