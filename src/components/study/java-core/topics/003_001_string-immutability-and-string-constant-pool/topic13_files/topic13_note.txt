1. BINARY CONVERSION RULES:
   - 'str.toCharArray()'                     → Generates fresh copy of 'char[]'.
   - 'str.getBytes(StandardCharsets.UTF_8)'  → Encodes into UTF-8 byte stream.
   - 'new String(bytes, UTF_8)'              → Decodes UTF-8 bytes back to String.
