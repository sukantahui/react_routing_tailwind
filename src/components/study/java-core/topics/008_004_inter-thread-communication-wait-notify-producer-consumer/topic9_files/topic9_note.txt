1. THE GOLDEN RULE OF WAIT():
   - ALWAYS: 'while (!condition) { lock.wait(); }'.
   - NEVER: 'if (!condition) { lock.wait(); }'.
   - Defends against:
     * Spurious wakeups.
     * State changes made by another thread before this thread acquires the lock.
   - Mandated by Effective Java & Java Concurrency in Practice.
