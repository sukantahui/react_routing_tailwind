1. HOW WAIT() WORKS:
   - Atomically releases the monitor lock.
   - Enrolls thread in object's Wait Set (WAITING state).
   - Consumes 0% CPU cycles.
   - On 'notify()', moves to Entry Set (BLOCKED).
   - MUST re-acquire monitor lock before exiting 'wait()'.
