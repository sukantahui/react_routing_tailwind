1. ILLEGALMONITORSTATEEXCEPTION:
   - RuntimeException thrown by JVM.
   - Triggered when calling 'wait()/notify()' without monitor ownership.
   - Hazard: Synchronizing on Lock A but calling wait on Lock B.
   - Solution: 'synchronized(lock) { lock.wait(); }' (same object!).
