1. SPURIOUS WAKEUPS:
   - Thread wakes from 'wait()' without notify() or interrupt.
   - Caused by low-level OS kernel signal handling (POSIX pthreads).
   - Explicitly allowed by Java Language Specification.
   - Defense: ALWAYS wrap 'wait()' in a 'while' loop.
