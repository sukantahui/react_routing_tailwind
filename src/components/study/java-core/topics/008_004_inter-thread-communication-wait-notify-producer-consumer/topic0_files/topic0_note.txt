1. BUSY WAITING vs SIGNALING:
   - Busy Waiting: 'while (!flag) {}' spins at 100% CPU utilization.
   - Causes CPU starvation, thermal throttling, and battery drain.
   - Inter-Thread Communication: 'wait()' suspends thread with 0% CPU cost.
   - 'notify()' wakes up waiting thread only when data is ready.
