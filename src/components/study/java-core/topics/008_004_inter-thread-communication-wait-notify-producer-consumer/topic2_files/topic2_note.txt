1. WHY WAIT/NOTIFY ARE IN OBJECT:
   - Intrinsic locks live on Objects, not Threads.
   - Threads can hold locks on multiple objects at once.
   - 'obj.wait()' specifies WHICH object lock is released.
   - Each object has its own private Wait Set.
   - Calling 'objA.notify()' targets only threads waiting on objA.
