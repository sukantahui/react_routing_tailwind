1. HOW NOTIFYALL() WORKS:
   - Wakes up ALL threads in the Wait Set.
   - Moves all threads to Entry Set (BLOCKED state).
   - Threads acquire lock sequentially and re-test condition.
   - Eliminates 'lost signal' and 'wrong thread awakened' bugs.
   - Standard best practice in 99% of custom synchronization code.
