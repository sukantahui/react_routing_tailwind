1. HOW NOTIFY() WORKS:
   - Wakes up exactly ONE arbitrary thread from Wait Set.
   - Non-deterministic: NO FIFO or priority order guaranteed.
   - Moves thread from WAITING to BLOCKED (Entry Set).
   - Risk: Other waiting threads remain trapped (Thread Starvation).
   - Prefer 'notifyAll()' to eliminate missed signal hazards.
