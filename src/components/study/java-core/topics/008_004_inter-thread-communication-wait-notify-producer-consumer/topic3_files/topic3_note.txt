1. MANDATORY LOCK PREREQUISITE:
   - 'wait()' and 'notify()' MUST be called inside 'synchronized(lockObject)'.
   - The thread must OWN the monitor lock of that exact target object.
   - Prevents the 'Lost Wakeup' race condition.
   - Calling outside synchronized throws 'IllegalMonitorStateException'.
