1. OBJECT SIGNALING API:
   - 'wait()': Releases lock, enters WAITING state.
   - 'wait(millis)': Releases lock with timeout (TIMED_WAITING).
   - 'notify()': Wakes 1 arbitrary waiting thread.
   - 'notifyAll()': Wakes ALL waiting threads (safest choice).
   - All require holding the object's synchronized lock!
