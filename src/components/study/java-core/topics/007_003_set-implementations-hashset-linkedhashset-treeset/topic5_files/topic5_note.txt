1. MUTABILITY HAZARD:
   - Never mutate fields used in 'hashCode()' or 'equals()'.
   - Mutating hash causes 'contains()' to look in the wrong bucket.
   - Object becomes trapped and unremovable (Memory Leak).
   - Solution: Declare all hash fields as 'final' (Immutable).
