1. TREESET ORDERING RULES:
   - Natural Ordering: Elements must implement 'Comparable<T>'.
   - Custom Ordering: Pass 'Comparator<T>' into 'new TreeSet<>(comparator)'.
   - Missing Comparable & Comparator → runtime 'ClassCastException'.
   - Lambda Comparators: 'Comparator.comparingDouble(...).reversed()'.
