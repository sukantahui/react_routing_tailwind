1. LINKEDHASHSET ARCHITECTURE:
   - Backed by 'LinkedHashMap'.
   - Nodes contain 'before' and 'after' pointers.
   - Threads a doubly-linked list through hash buckets.
   - O(1) lookup speed + 100% guaranteed insertion ordering.
