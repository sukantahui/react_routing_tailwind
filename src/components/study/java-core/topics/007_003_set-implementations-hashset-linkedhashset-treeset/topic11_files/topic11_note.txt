1. TREESET UNIQUENESS RULE:
   - Ignores 'equals()' and 'hashCode()'.
   - Uniqueness determined SOLELY by: 'compareTo(other) == 0'.
   - If compareTo is inconsistent with equals, silent data loss occurs.
   - Golden Rule: Ensure '(x.compareTo(y) == 0) == (x.equals(y))'.
