1. THE PRESENT CONSTANT:
   - 'private static final Object PRESENT = new Object();'.
   - Shared across all HashSet instances.
   - Serves as dummy value in 'map.put(element, PRESENT)'.
   - Zero memory overhead since only 1 instance exists.
