1. HASHSET INTERNALS:
   - Backed by 'private transient HashMap<E, Object> map;'.
   - 'set.add(e)' &rarr; calls 'map.put(e, PRESENT)'.
   - Set elements are stored as KEYS in the internal HashMap.
   - Reuses HashMap's hash bucket and red-black tree architecture.
