1. MODULE 007_003 GRAND SUMMARY:
   - HashSet: O(1) hash bucket lookup; backed by HashMap + PRESENT.
   - Element Mutability Hazard: Never mutate hash fields after insertion.
   - LinkedHashSet: O(1) + guaranteed insertion ordering via before/after pointers.
   - TreeSet: O(log n) sorted Red-Black tree; backed by TreeMap.
   - compareTo() == 0 dictates TreeSet uniqueness (ignores equals).
   - Nulls: HashSet & LinkedHashSet permit 1 null; TreeSet prohibits null (NPE).
