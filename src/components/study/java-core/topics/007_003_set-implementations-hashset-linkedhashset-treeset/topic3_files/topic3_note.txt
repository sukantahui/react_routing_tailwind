1. UNIQUENESS ALGORITHM:
   - Step 1: 'hashCode()' calculates target bucket.
   - Step 2: If bucket empty → insert.
   - Step 3: If bucket occupied → invoke 'equals()'.
   - If 'equals() == true' → rejected (duplicate).
   - If 'equals() == false' → inserted (collision handled).
