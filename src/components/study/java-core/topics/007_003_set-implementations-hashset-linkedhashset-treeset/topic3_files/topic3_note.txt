1. UNIQUENESS ALGORITHM:
   - Step 1: 'hashCode()' calculates target bucket.
   - Step 2: If bucket empty &rarr; insert.
   - Step 3: If bucket occupied &rarr; invoke 'equals()'.
   - If 'equals() == true' &rarr; rejected (duplicate).
   - If 'equals() == false' &rarr; inserted (collision handled).
