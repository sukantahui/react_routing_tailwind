1. WHAT IS BATCHUPDATEEXCEPTION:
   - Subclass of 'SQLException' thrown when an error occurs during batch execution.

2. 'getUpdateCounts()' CODES:
   - int value &gt;= 0 : Row update count for successful statement.
   - 'Statement.SUCCESS_NO_INFO' (-2) : Success without row count.
   - 'Statement.EXECUTE_FAILED' (-3) : Specific statement failed.
