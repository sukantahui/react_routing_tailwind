1. LAYER ROLES:
   - Controller : User Interaction / HTTP endpoints.
   - Service    : Business Rules / Calculations.
   - DAO        : Database CRUD operations.
   - Model      : Immutable Data representations.

2. GOLDEN RULE:
   - Never skip layers (e.g. Controller calling DAO directly without Service).
