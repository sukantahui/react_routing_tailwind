1. THE LATENCY OVERHEAD:
   - Every individual 'executeUpdate()' requires:
     * Serialization of SQL packet
     * Network socket transit
     * Database parse and execute
     * Disk write and return packet
   - In a loop of N iterations, latency multiplies N times!

2. THE SOLUTION:
   - Group statements in client buffer using JDBC Batching!
