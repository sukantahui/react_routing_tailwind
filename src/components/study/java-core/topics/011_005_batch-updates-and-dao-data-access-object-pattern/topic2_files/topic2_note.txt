1. BATCH API METHODS:
   - 'pstmt.addBatch()'    : Appends current parameter values to the internal batch buffer.
   - 'pstmt.executeBatch()': Submits the batch to the database engine. Returns 'int[]'.

2. RETURN VALUE OF 'executeBatch()':
   - An array of integers ('int[]') containing the update count for each command in the batch:
     * &gt;= 0 : Successfully executed; value is number of affected rows.
     * 'Statement.SUCCESS_NO_INFO' (-2) : Successfully executed, but affected row count is unknown.
     * 'Statement.EXECUTE_FAILED' (-3)  : Command failed.
