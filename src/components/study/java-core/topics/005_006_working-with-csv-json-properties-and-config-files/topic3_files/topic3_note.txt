1. FALLBACK DEFAULTS:
   - 'props.getProperty("key", "defaultVal")': Returns default if key is absent.
   - Prevents 'null' returns and NPEs.
   - Hierarchical chaining: 'new Properties(defaultParentProps)'.
   - Clean, resilient application startup architecture.
