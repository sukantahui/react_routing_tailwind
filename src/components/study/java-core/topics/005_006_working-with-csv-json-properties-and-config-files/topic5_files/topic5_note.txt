1. CLASSPATH RESOURCE LOADING:
   - 'InputStream is = ClassLoader.getResourceAsStream("path")'.
   - Mandatory for files bundled inside JAR/WAR archives.
   - Always check 'if (is == null)' for missing resources.
   - Wrap in InputStreamReader with StandardCharsets.UTF_8.
