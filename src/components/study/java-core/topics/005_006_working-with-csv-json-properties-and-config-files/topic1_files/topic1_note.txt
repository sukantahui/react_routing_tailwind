1. .PROPERTIES SYNTAX SPEC:
   - Delimiters : '=', ':', or whitespace ' '.
   - Comments   : Lines starting with '#' or '!'.
   - Multi-line : Trailing backslash '\' escapes newline.
   - Escaping   : Escaping colons or equals in keys (e.g. 'tax\:rate').
