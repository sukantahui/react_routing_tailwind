1. CSV WRITING RULES (RFC 4180):
   - Check if field contains ',', '"', or '\n'.
   - Double internal quotes: 'val.replace("\"", "\"\"")'.
   - Enclose in outer quotes: '"' + escaped + '"'.
   - Join with commas and write platform newline.
