1. JSON DATA MODEL (RFC 8259):
   - Objects: '{ "key": value }'.
   - Arrays: '[ item1, item2 ]'.
   - Primitives: Strings (double-quoted), Numbers, Booleans, Null.
   - Strictly requires double quotes for keys and string values.
