1. LOADING PROPERTIES:
   - 'props.load(new FileReader(file, StandardCharsets.UTF_8))'.
   - Avoid legacy 'load(InputStream)' for non-English UTF-8 files.
   - Seamlessly populates all key-value entries into memory.
   - Closes automatically via Try-with-Resources.
