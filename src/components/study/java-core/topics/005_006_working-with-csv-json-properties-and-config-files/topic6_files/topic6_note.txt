1. RFC 4180 CSV RULES:
   - Fields containing commas must be enclosed in double quotes '"..."'.
   - Quotes inside quoted fields are escaped by doubling them '""'.
   - Avoid naive 'line.split(",")' on complex data.
   - Use character-by-character state parsing for robust token extraction.
