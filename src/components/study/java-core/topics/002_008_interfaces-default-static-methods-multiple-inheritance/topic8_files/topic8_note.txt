1. DEFAULT CONFLICT RESOLUTION RULES:
   - Rule 1 (Classes Win): A method declared in a class/superclass always wins over interface defaults.
   - Rule 2 (Sub-interfaces Win): More specific sub-interface defaults win over parent interface defaults.
   - Rule 3 (Explicit Resolution): Sibling interface collision &rarr; Child MUST override and use 'Interface.super.method()'.
