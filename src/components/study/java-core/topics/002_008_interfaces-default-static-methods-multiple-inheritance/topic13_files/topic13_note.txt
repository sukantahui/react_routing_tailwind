FEATURE MATRIX:
+-------------------+----------------------------+-----------------------------+
| Feature           | Abstract Class             | Interface                   |
+-------------------+----------------------------+-----------------------------+
| Inheritance       | Single ('extends')         | Multiple ('implements')     |
| Instance Fields   | Yes (private, protected)   | No (public static final)    |
| Constructors      | Yes (invoked via super())  | No (Never instantiated)     |
| Methods           | Abstract + Concrete        | Abstract, default, static   |
| Speed             | Slightly faster vtable     | Interface table lookup      |
+-------------------+----------------------------+-----------------------------+
