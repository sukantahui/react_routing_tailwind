1. LOOSE COUPLING PRINCIPLE:
   - Always declare variable references as the Interface type (e.g. 'List<T>' not 'ArrayList<T>').
   - High-level classes depend on abstractions (interfaces), not concrete details.
   - Foundation for Dependency Injection and Unit Testing (Mocking).
