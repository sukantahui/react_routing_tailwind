1. MARKER INTERFACE CHARACTERISTICS:
   - 0 methods, 0 fields.
   - Used as a type tag checked via 'if (obj instanceof Marker)'.
   - Built-in examples: Cloneable, Serializable, Remote, RandomAccess.
   - In modern Java, Annotations (@Tag) are often preferred for custom metadata.
