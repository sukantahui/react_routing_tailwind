1. OUT PARAMETER REGISTRATION RULES:
   - Must be registered BEFORE calling 'execute()'.
   - Uses SQL type constants from 'java.sql.Types' (e.g. 'Types.INTEGER', 'Types.VARCHAR', 'Types.DECIMAL').

2. INOUT PARAMETERS:
   - Must call BOTH 'setXxx(index, value)' AND 'registerOutParameter(index, sqlType)' before execution!
