1. AUTO-GENERATED KEY CONTRACT:
   - Pass 'Statement.RETURN_GENERATED_KEYS' to 'conn.prepareStatement()'.
   - Call 'pstmt.getGeneratedKeys()' immediately after 'pstmt.executeUpdate()'.

2. KEY RETRIEVAL FORMAT:
   - 'getGeneratedKeys()' returns a standard 'ResultSet'.
   - The generated key is at column index 1 ('rs.getLong(1)').
