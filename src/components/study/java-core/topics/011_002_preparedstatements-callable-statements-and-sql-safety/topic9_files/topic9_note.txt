1. WHAT IS CALLABLESTATEMENT:
   - Interface extending 'java.sql.PreparedStatement'.
   - Used to execute SQL Stored Procedures and Functions.

2. JDBC ESCAPE SYNTAX:
   - Standard: '{call procedure_name(?, ?)}'
   - Function: '{? = call function_name(?)}' (First '?' is the return value).
