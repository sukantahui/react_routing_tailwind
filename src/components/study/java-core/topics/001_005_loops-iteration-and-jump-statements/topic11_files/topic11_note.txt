1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- What is an Iteration Trace Table?
  A discrete, row-by-row table mapping variable values, boolean conditions,
  state mutations, and printed output at every clock step of loop execution.

- Standard Trace Table Column Blueprint:
  +------+-----------+--------------+-----------+--------------+------------------+----------------+
  | Step | Outer Var | Outer Cond   | Inner Var | Inner Cond   | Action/Mutation  | Printed Output |
  +------+-----------+--------------+-----------+--------------+------------------+----------------+
  |    1 | i = 1     | 1 <= 3 (T)   | j = 1     | 1 <= 1 (T)   | sum: 0 -> 1      | 1*1=1          |
  |    2 | i = 2     | 2 <= 3 (T)   | j = 1     | 1 <= 2 (T)   | sum: 1 -> 3      | 2*1=2          |
  |    3 | i = 2     | 2 <= 3 (T)   | j = 2     | 2 <= 2 (T)   | sum: 3 -> 7      | 2*2=4          |
  |    4 | i = 3     | 3 <= 3 (T)   | j = 1     | 1 <= 3 (T)   | sum: 7 -> 10     | 3*1=3          |
  |    5 | i = 3     | 3 <= 3 (T)   | j = 2     | 2 <= 3 (T)   | sum: 10 -> 16    | 3*2=6          |
  |    6 | i = 3     | 3 <= 3 (T)   | j = 3     | 3 <= 3 (T)   | sum: 16 -> 25    | 3*3=9          |
  +------+-----------+--------------+-----------+--------------+------------------+----------------+

- Key Observations from Trace Tables:
  1. The Inner Loop resets back to its starting value (j = 1) whenever outer i advances.
  2. Total steps for triangular loop = 1 + 2 + ... + N = N(N+1)/2.
  3. Catches boundary errors (< vs <=) and uninitialized accumulators.

2. ESSENTIAL CHECKLIST
--------------------------------------------------------------------------------
[✓] Always pick small inputs (N=3) for manual dry runs to avoid arithmetic fatigue.
[✓] Write down EVERY variable value explicitly on paper; never rely on mental memory!
[✓] Explicitly record the 'FALSE' boundary step that terminates the inner loop.
[✓] Use trace tables during technical whiteboard interviews to prove correctness.
