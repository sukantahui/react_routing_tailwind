1. SUPPLIER<T>:
   - SAM: 'T get()'.
   - Input: None (), Output: T.
   - Purpose: Factory generation, lazy evaluation, default fallbacks.
   - Powers: 'Optional.orElseGet()', 'Stream.generate()', 'CompletableFuture.supplyAsync()'.
   - Eager vs Lazy: Code inside Supplier runs ONLY when 'get()' is called.
