1. CONSUMER ANDTHEN():
   - Executes left consumer FIRST, then right consumer on same input.
   - Ideal for multi-step processing: 'c1.andThen(c2).andThen(c3)'.
   - Stops execution if any consumer throws an exception.
   - Returns 'Consumer<T>' allowing fluent builder patterns.
