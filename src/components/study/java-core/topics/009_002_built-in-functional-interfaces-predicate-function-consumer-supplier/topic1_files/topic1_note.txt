1. THE BIG 4 INTERFACES:
   - 'Predicate<T>': 'boolean test(T)' (Filter/Check).
   - 'Function<T, R>': 'R apply(T)' (Map/Transform).
   - 'Consumer<T>': 'void accept(T)' (Print/Process).
   - 'Supplier<T>': 'T get()' (Generate/Supply).
