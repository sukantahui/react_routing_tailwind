1. JAVA.UTIL.FUNCTION PACKAGE (43 INTERFACES):
   - The Big 4:
     1. Predicate<T>: 'T → boolean' (Filtering).
     2. Function<T, R>: 'T → R' (Mapping).
     3. Consumer<T>: 'T → void' (Side-effects).
     4. Supplier<T>: '() → T' (Lazy factory).
   - Bi-Variants: BiPredicate, BiFunction, BiConsumer.
   - Operators: UnaryOperator, BinaryOperator.
   - Primitive Variants: IntPredicate, DoubleFunction, etc.
