1. FUNCTIONAL COMPOSITION:
   - Built via 'default' methods on interfaces (retains SAM contract).
   - Predicate: '.and()', '.or()', '.negate()', 'Predicate.isEqual()'.
   - Function: '.andThen()' (Forward pipe), '.compose()' (Reverse pipe).
   - Consumer: '.andThen()' (Sequential side-effects).
   - Builds complex logic out of tiny, testable micro-functions.
