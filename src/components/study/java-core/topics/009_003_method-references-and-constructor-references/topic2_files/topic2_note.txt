1. THE 4 KINDS OF METHOD REFERENCES:
   - 1. Static: 'ClassName::staticMethod' ('Math::max').
   - 2. Bound Instance: 'objRef::instanceMethod' ('System.out::println').
   - 3. Unbound Instance: 'ClassName::instanceMethod' ('String::length').
   - 4. Constructor: 'ClassName::new' ('ArrayList::new').
