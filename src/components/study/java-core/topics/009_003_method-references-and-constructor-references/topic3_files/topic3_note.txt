1. STATIC METHOD REFERENCES:
   - Syntax: 'ClassName::staticMethodName'.
   - Equivalence: '(args) -> ClassName.staticMethodName(args)'.
   - Examples: 'Math::max', 'Integer::parseInt', 'Double::valueOf'.
   - Arguments match 1:1 with SAM parameters.
