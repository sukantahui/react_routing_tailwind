1. DOUBLE COLON (::) SYNTAX:
   - Format: 'TargetRef::MethodName'.
   - NEVER add parentheses '()' after the method name!
   - Arguments are routed implicitly by the compiler.
   - Use 'Target::new' for constructor references.
