1. WHAT IS A METHOD REFERENCE:
   - Compact syntax for lambdas calling existing methods.
   - Eliminates boilerplate parameter names.
   - Example: 'x → System.out.println(x)' → 'System.out::println'.
   - Evaluated at runtime with the same performance as lambda expressions.
