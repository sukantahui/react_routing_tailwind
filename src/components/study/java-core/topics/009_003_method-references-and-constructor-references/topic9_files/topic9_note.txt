1. REFACTORING PATTERNS:
   - 'x -> Objects.nonNull(x)'     &rarr; 'Objects::nonNull'
   - 's -> s.getName()'            &rarr; 'Student::getName'
   - 's -> s.toUpperCase()'        &rarr; 'String::toUpperCase'
   - 'x -> System.out.println(x)'  &rarr; 'System.out::println'
   - '() -> new ArrayList<>()'     &rarr; 'ArrayList::new'
