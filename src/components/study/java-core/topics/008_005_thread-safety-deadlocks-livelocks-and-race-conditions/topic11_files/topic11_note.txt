1. DEADLOCK DIAGNOSIS TOOLS:
   - Modern CLI: 'jcmd <PID> Thread.print'.
   - Classic CLI: 'jstack -l <PID>'.
   - GUI: VisualVM, JConsole.
   - Programmatic: 'ThreadMXBean.findDeadlockedThreads()'.
   - HotSpot JVM prints 'Found one Java-level deadlock' with full cycle stack traces.
