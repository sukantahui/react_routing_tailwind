1. THREAD SAFETY DEFINITION:
   - Behaves correctly under any thread interleaving.
   - Caller needs NO extra synchronization.
   - Preserves state invariants at all times.
   - 3 Pathways:
     1. Immutability (final fields, read-only).
     2. Thread Confinement (ThreadLocal, stack variables).
     3. Synchronized Mutation (Locks, AtomicInteger).
