1. COFFMAN 2: HOLD AND WAIT:
   - Nested locks: 'synchronized(A) { synchronized(B) { ... } }'.
   - Thread holds Lock A while waiting for Lock B.
   - Broken by:
     * All-or-Nothing resource acquisition.
     * Releasing held locks before requesting additional locks.
     * Non-blocking 'tryLock()' with timeout.
