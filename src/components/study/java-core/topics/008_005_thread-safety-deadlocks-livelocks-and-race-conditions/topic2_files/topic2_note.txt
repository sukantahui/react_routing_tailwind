1. WHAT IS DEADLOCK:
   - Circular dependency where 2+ threads wait forever on locks held by each other.
   - Deadlocked threads enter 'BLOCKED' state.
   - CPU usage drops to 0%, but application freezes completely.
   - JVM cannot resolve deadlocks automatically; process must be diagnosed or restarted.
