1. RACE CONDITION CATEGORIES:
   - 1. Read-Modify-Write:
     * Next state depends on current state ('count++').
     * Causes lost updates.
     * Fix: AtomicInteger, synchronized.
   - 2. Check-Then-Act:
     * Action depends on observed condition.
     * Stale check creates duplicate singletons or overdrawn balances.
     * Fix: Synchronized blocks, Double-Checked Locking with volatile.
