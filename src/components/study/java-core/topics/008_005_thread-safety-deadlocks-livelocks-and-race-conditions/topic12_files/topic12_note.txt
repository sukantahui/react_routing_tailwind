1. DECODING THREAD DUMPS:
   - Search for 'BLOCKED (on object monitor)'.
   - Cross-reference hex addresses:
     * Thread 1: locked <0xA>, waiting to lock <0xB>.
     * Thread 2: locked <0xB>, waiting to lock <0xA>.
   - Check line numbers at top of stack trace.
   - HotSpot JVM prints 'Found 1 deadlock' at the very bottom.
