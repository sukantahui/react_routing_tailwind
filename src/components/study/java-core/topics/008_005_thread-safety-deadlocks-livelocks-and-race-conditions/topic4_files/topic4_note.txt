1. COFFMAN 1: MUTUAL EXCLUSION:
   - Resource held exclusively by 1 thread (non-shareable).
   - Java 'synchronized' enforces 100% exclusive mutex.
   - For write operations, mutual exclusion is essential.
   - For read operations, 'ReadWriteLock' allows shared concurrent access.
