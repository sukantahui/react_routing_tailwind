1. BREAKING DEADLOCKS WITH TIMEOUTS:
   - 'lock.tryLock(timeout, TimeUnit)': Bounded lock acquisition attempt.
   - Returns boolean success/failure.
   - On timeout: Release all held locks in 'finally' block.
   - Add randomized sleep back-off to prevent Livelock.
   - Superior to unbounded 'synchronized' blocks for high-contention systems.
