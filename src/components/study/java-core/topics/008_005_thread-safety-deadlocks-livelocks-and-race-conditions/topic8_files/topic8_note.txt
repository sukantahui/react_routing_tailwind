1. GLOBAL LOCK ORDERING:
   - Problem: Inverted lock acquisition (A &rarr; B vs B &rarr; A) deadlocks.
   - Solution: Sort lock targets deterministically before acquiring.
   - Compare 'accountId' or 'System.identityHashCode()'.
   - Both threads acquire smaller ID first, then larger ID.
   - 100% immune to deadlocks in bidirectional transfers!
