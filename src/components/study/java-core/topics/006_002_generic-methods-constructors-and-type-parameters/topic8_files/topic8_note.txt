1. GENERIC VARARGS:
   - 'public static <T> List<T> createList(T... elements)'.
   - Syntactic sugar for 'T[]' array.
   - Accepts 0, 1, or many comma-separated arguments.
   - Foundation for 'List.of()' and 'Arrays.asList()'.
