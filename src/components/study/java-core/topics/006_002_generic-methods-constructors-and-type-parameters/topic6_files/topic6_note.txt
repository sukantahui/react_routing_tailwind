1. GENERIC ARRAYS METHOD RULES:
   - 'public static <T> void printArray(T[] array)'.
   - Works seamlessly with any reference array (String[], Integer[]).
   - Incompatible with primitive arrays (int[], double[]).
   - Boxed wrapper arrays must be used.
