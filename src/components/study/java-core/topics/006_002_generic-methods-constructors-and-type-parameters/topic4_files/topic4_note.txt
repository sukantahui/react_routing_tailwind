1. STATIC GENERICS SCOPING RULE:
   - Class-level '<T>' belongs to heap instances.
   - Static methods belong to the class definition.
   - Static methods CANNOT use class '<T>'.
   - Static methods MUST declare independent '<E>' before return type.
