1. METHOD INVOCATION STYLES:
   - Inferred: 'coalesce(a, b)' (compiler deduces T automatically).
   - Explicit Type Witness: 'MyClass.<String>coalesce(a, b)'.
   - Used for common supertypes (e.g. <Number>) or empty collections.
   - Syntactically placed before the method name.
