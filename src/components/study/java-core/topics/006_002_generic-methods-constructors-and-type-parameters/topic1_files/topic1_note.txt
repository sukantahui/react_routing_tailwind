1. GENERIC METHOD SYNTAX:
   - '[modifiers] <T, R> ReturnType methodName(T param1, R param2)'.
   - '<T>' placed right before return type.
   - Multiple type parameters: '<K, V>'.
   - Return type can be 'T', a concrete class, or 'void'.
