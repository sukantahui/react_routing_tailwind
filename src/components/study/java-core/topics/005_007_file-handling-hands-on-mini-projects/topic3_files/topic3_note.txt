1. FLAT-FILE DB ARCHITECTURE:
   - Fixed-width records (e.g. 64 bytes per row).
   - In-memory index: 'Map<ID, ByteOffset>'.
   - 'RandomAccessFile.seek(offset)' for instantaneous O(1) seeks.
   - Padded byte buffers for uniform binary layout.
