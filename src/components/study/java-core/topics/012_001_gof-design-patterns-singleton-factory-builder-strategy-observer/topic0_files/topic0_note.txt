1. WHAT DESIGN PATTERNS ARE:
   - Established architectural solutions to recurring software engineering problems.
   - They provide a shared technical vocabulary among senior engineers.

2. WHAT THEY ARE NOT:
   - They are NOT concrete code libraries or frameworks.
   - They should not be forced into simple code (avoid Premature Patternization!).
