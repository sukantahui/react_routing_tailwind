1. INTENT:
   - Provide a surrogate or placeholder for another object to control access to it.

2. COMMON PROXY TYPES:
   - Virtual Proxy   : Lazy initialization of expensive resources.
   - Protection Proxy: Role-based authorization & permission validation.
   - Remote Proxy    : RMI / gRPC network stub representation.
   - Dynamic Proxy   : Spring AOP transactions ('@Transactional') and caching.
