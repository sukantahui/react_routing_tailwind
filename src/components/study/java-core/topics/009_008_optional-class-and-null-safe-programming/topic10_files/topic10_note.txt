1. IFPRESENT(CONSUMER):
   - Signature: 'public void ifPresent(Consumer<? super T> action)'.
   - If a value is present, performs the given action with the value.
   - Otherwise, does nothing.

2. IFPRESENTORELSE(CONSUMER, RUNNABLE) [JAVA 9+]:
   - Signature: 'public void ifPresentOrElse(Consumer<? super T> action, Runnable emptyAction)'.
   - If a value is present, invokes 'action.accept(value)'.
   - If absent, invokes 'emptyAction.run()'.
   - Provides a clean functional replacement for traditional 'if (opt.isPresent()) ... else ...'.
