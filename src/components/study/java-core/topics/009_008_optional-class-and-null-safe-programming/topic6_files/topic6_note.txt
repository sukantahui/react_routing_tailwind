1. METHOD CONTRACT (Java 10+):
   - Signature: 'public T orElseThrow()'.
   - If a value is present, returns the value.
   - Otherwise, throws 'NoSuchElementException("No value present")'.

2. WHY OR ELSE THROW WAS ADDED TO REPLACE GET():
   - Method name '.get()' sounds innocent and disguises the risk of throwing an exception.
   - '.orElseThrow()' clearly communicates that absence will trigger an exception.
   - Java architects recommend '.orElseThrow()' over '.get()' in all modern codebases.
