1. METHOD SIGNATURE:
   - '<X extends Throwable> T orElseThrow(Supplier<? extends X> exceptionSupplier) throws X'

2. ENTERPRISE DESIGN PATTERN:
   - Common in Spring Boot / Jakarta EE service layers.
   - Maps database repository misses directly into HTTP 404 / 400 custom domain exceptions.
   - Example:
     'userRepo.findById(id).orElseThrow(() → new UserNotFoundException(id));'
