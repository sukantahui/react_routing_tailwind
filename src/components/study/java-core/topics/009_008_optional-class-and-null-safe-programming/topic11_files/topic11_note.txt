1. METHOD CONTRACT:
   - Signature: 'public Optional<T> filter(Predicate<? super T> predicate)'.
   - If a value is present and matches the predicate, returns this Optional.
   - If a value is present but fails the predicate, returns 'Optional.empty()'.
   - If the Optional was already empty, returns 'Optional.empty()'.

2. COMMON USE CASES:
   - Security permissions & role checks.
   - Numerical threshold validation.
   - Non-empty string validation ('opt.filter(s -> !s.isBlank())').
