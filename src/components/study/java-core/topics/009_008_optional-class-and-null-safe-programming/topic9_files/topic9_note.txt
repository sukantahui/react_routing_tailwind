1. OPTIONAL AS A MONADIC CONTAINER:
   - Optional mirrors the Stream API functional operations:
     * 'filter(Predicate)' : Conditionally retains value or converts to empty.
     * 'map(Function)'     : Transforms contained value (1-to-1).
     * 'flatMap(Function)' : Transforms and un-nests Optional-returning functions.
     * 'stream()' [Java 9] : Converts Optional to Stream (0 or 1 element).

2. MONADIC SHORT-CIRCUITING:
   - If an Optional becomes empty at ANY point in the chain, subsequent 'map' and 'filter'
     operations are immediately skipped without errors!
