1. METHOD CONTRACT (Java 9+):
   - Signature: 'public Stream<T> stream()'.
   - If a value is present, returns a sequential Stream containing ONLY that single value.
   - If empty, returns an EMPTY Stream of size 0.

2. THE CANONICAL STREAM-OPTIONAL IDIOM:
   - 'Stream<Optional<T>>' &rarr; 'Stream<T>':
     'stream.flatMap(Optional::stream)'
   - Replaces clunky Java 8 pattern:
     'stream.filter(Optional::isPresent).map(Optional::get)'
