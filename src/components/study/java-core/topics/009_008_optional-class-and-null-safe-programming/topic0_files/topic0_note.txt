1. THE NULL REFERENCE PROBLEM:
   - Invented in 1965 by Sir Tony Hoare (ALGOL W) to represent absence of reference.
   - Problems with 'null' in Java:
     1. Unchecked runtime 'NullPointerException' (NPE).
     2. Pollutes domain logic with nested defensive 'if (x != null)' statements.
     3. Type system does not declare whether a method can return null.

2. THE FUNCTIONAL SOLUTION:
   - Monadic wrapper 'java.util.Optional<T>' (inspired by Haskell's Maybe and Scala's Option).
   - Encapsulates value presence or absence cleanly in the type system.
