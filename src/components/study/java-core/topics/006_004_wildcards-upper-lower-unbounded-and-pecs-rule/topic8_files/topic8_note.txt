1. CONSUMER SUPER RULES:
   - 'List<? super T>' acts as a DATA CONSUMER.
   - Write-enabled: safe to insert 'T' and subtypes.
   - Accepts collections of 'T', superclasses, and 'Object'.
   - Elements can only be read as 'Object'.
