1. LOWER BOUNDED WILDCARD (CONTRAVARIANCE):
   - 'List<? super Integer>': accepts Integer and all supertypes.
   - Accepts 'List<Integer>', 'List<Number>', 'List<Object>'.
   - WRITE-ENABLED: safe to add 'Integer'.
   - Acts as a DATA CONSUMER.
   - Elements read only as 'Object'.
