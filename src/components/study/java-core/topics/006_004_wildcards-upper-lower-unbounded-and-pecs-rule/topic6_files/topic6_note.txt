1. READ/WRITE DECISION MATRIX:
   - '<? extends T>': PRODUCER → read 'T', cannot write.
   - '<? super T>': CONSUMER → write 'T', read 'Object'.
   - '<?>': UNBOUNDED → read 'Object', cannot write.
   - Only 'null' can be written to '<? extends T>' or '<?>'.
