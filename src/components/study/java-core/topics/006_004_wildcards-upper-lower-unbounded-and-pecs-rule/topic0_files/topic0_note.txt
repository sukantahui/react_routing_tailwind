1. GENERICS INVARIANCE:
   - 'List<String>' is NOT a subtype of 'List<Object>'.
   - Prevents inserting wrong types into specialized collections.
   - Eliminates runtime ClassCastException risks.
   - Solution for polymorphism: Wildcards ('List<?>', 'List<? extends T>').
