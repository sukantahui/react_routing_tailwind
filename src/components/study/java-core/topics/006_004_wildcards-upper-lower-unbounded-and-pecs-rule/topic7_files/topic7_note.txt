1. PRODUCER EXTENDS RULES:
   - 'List<? extends T>' serves as a DATA PRODUCER.
   - Elements are safely read as 'T'.
   - 'add(element)' is completely blocked at compile time.
   - Preserves collection integrity regardless of actual subtype.
