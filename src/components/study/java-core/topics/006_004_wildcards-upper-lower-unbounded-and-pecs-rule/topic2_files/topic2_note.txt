1. THE 3 WILDCARD TYPES:
   - 'List<?>': Unbounded.
   - 'List<? extends T>': Upper bounded (T and subtypes).
   - 'List<? super T>': Lower bounded (T and supertypes).
   - Enables covariance and contravariance in Java collections.
