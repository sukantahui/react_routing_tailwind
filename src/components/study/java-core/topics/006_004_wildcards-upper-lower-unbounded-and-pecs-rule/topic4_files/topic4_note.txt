1. UPPER BOUNDED WILDCARD (COVARIANCE):
   - 'List<? extends Number>': accepts Number and any subtype.
   - Elements can be read safely as 'Number'.
   - Acts as a DATA PRODUCER.
   - Cannot add elements (except null) to preserve type invariants.
