1. Collections.copy DECONSTRUCTION:
   - 'public static <T> void copy(List<? super T> dest, List<? extends T> src)'.
   - 'src' produces data of type 'T' (extends).
   - 'dest' consumes data of type 'T' (super).
   - Enables copying 'List<Integer>' into 'List<Number>' or 'List<Object>'.
