1. UNBOUNDED WILDCARD RULES:
   - 'List<?>': universal read-only supertype.
   - Elements can be read safely as 'Object'.
   - CANNOT add any objects (compile error).
   - 'list.add(null)' is the ONLY allowed insertion.
