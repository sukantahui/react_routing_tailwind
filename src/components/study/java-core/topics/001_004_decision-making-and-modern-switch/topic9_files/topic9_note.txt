1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- Architectural Comparison:
  Feature               | 'switch' Statement          | 'else-if' Ladder
  ----------------------|-----------------------------|----------------------------
  Matching Style        | Discrete Constants          | General Boolean Expressions
  Time Complexity       | O(1) [tableswitch]          | O(N) Linear Cascade
  Data Types Supported  | byte, short, int, char,     | ALL types (including long,
                        | String, enum                | float, double, boolean)
  Inequality / Ranges   | Not directly supported      | Fully Supported (x >= 80)
  Readability (4+ cases)| High (Table layout)         | Verbose (Repeated vars)

- Bytecode Optimization in Switch:
  * Dense Integer Keys  → 'tableswitch'  (O(1) Direct Indexed Address Jump)
  * Sparse Integer Keys → 'lookupswitch' (O(log N) Binary Search Table)

- Decision Matrix:
  * Choose 'switch'  : When matching ONE variable against 4+ discrete constants.
  * Choose 'else-if' : When checking ranges, floating-point numbers, or multi-var logic.

--------------------------------------------------------------------------------
