1. COMPARABLE vs COMPARATOR:
   - Comparable: 'java.lang', 'compareTo(o)', 1 natural sort, requires source edits.
   - Comparator: 'java.util', 'compare(o1, o2)', multiple custom sorts, lambda-friendly.
   - Rule of Thumb: Implement Comparable for default natural sort; use Comparator for ad-hoc sorts.
