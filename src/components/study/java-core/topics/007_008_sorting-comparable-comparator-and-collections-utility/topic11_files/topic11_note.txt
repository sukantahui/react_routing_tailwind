1. CORE ALGORITHMS:
   - 'Collections.sort(list)' → sorts list in-place (TimSort).
   - 'Collections.reverse(list)' → reverses list in-place.
   - 'Collections.binarySearch(list, key)' → O(log n) lookup (must be sorted!).
   - 'Collections.swap(list, i, j)' → swaps elements at indices i and j.
   - 'Collections.shuffle(list)' → pseudo-random permutation.
