1. MULTI-LEVEL CHAINING:
   - Equivalent to SQL 'ORDER BY col1, col2 DESC, col3'.
   - 'Comparator.comparing(...).thenComparing(...)'.
   - Cascades down the chain only when previous level returns 0 (tie).
   - Highly readable and declarative.
