1. EMPTY & SINGLETON COLLECTIONS:
   - 'Collections.emptyList() / emptySet() / emptyMap()'.
   - Returns shared static singleton instance (zero GC memory bloat).
   - 'Collections.singletonList(e)': highly optimized 1-element list.
   - Best practice: Always return empty collections instead of 'null'!
