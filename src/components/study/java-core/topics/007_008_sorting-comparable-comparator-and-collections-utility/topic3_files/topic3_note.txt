1. CONSISTENCY RULE:
   - '(x.compareTo(y) == 0) == (x.equals(y))'.
   - Inconsistent: 'BigDecimal("1.0")' vs 'BigDecimal("1.00")'.
   - HashSet treats them as distinct (size 2).
   - TreeSet treats them as duplicates (size 1).
   - Always ensure compareTo reflects equals fields!
