1. COMPARATOR FACTORIES:
   - 'Comparator.comparing(Getter)': for object keys (e.g. String).
   - 'Comparator.comparingInt(Getter)': for primitive int.
   - 'Comparator.comparingDouble(Getter)': for primitive double.
   - 'reversed()': inverts sort direction.
   - Primitive specializations prevent auto-boxing GC churn.
