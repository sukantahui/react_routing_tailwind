1. JAVA 8 COMPARATOR TOOLKIT:
   - 'Comparator.comparing(extractor)': creates comparator from getter.
   - 'thenComparing(secondary)': adds secondary tie-breaker sort.
   - 'reversed()': inverts sort order.
   - 'nullsFirst() / nullsLast()': null-safe handling.
   - Primitive specializations: 'comparingInt()', 'comparingDouble()'.
