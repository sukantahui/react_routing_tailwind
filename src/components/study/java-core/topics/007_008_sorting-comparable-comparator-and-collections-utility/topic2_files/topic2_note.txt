1. COMPARETO CONTRACT:
   - Return < 0 : 'this' precedes 'other'.
   - Return == 0: 'this' equals 'other'.
   - Return > 0 : 'this' follows 'other'.
   - Subtraction Trap: Never use 'a - b' due to 32-bit integer overflow.
   - Safe idiom: 'Integer.compare(a, b)', 'Double.compare(a, b)'.
