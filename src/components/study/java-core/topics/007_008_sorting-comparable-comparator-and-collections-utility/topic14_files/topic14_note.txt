1. UNMODIFIABLE WRAPPERS:
   - 'Collections.unmodifiableList(orig)'.
   - 'Collections.unmodifiableSet(orig)'.
   - 'Collections.unmodifiableMap(orig)'.
   - Throws 'UnsupportedOperationException' on mutation attempts.
   - Backing view trap: mutations to 'orig' list leak into the view.
   - For true immutability: use 'List.copyOf(orig)' (Java 10+).
