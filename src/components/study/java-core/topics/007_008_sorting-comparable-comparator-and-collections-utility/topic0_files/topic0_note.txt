1. SORTING PARADIGMS:
   - Natural Order: 'Comparable<T>' ('compareTo(o)').
   - Custom Strategy: 'Comparator<T>' ('compare(o1, o2)').
   - Collections.sort(list) &rarr; uses Comparable.
   - list.sort(comparator) &rarr; uses custom strategy.
