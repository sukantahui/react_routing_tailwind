1. WHAT IS CONNECTION:
   - Extends 'java.lang.AutoCloseable' and 'java.sql.Wrapper'.
   - Encapsulates stateful database session context (current user, transaction state, temporary tables).

2. AUTO-COMMIT DEFAULT:
   - Default is 'autoCommit = true' (every single SQL statement commits immediately).
   - In enterprise apps, disable auto-commit to execute multi-step atomic transactions!
