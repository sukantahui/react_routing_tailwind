1. GENERAL SYNTAX FORMAT:
   - 'jdbc:<subprotocol>://<host>:<port>/<database>?<param1>=<val1>&<param2>=<val2>'

2. ESSENTIAL PRODUCTION PARAMETERS:
   - 'serverTimezone=UTC' (prevents date/time offset discrepancies).
   - 'useSSL=true / sslmode=require' (enforces encrypted transport).
   - 'connectTimeout=5000' (caps TCP connect wait time).
