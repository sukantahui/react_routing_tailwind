1. DRIVER REGISTRATION:
   - Modern JDBC (Java 6+) uses 'java.util.ServiceLoader' to discover driver classes automatically.
   - Calling 'Class.forName()' is obsolete and no longer necessary.

2. 'DriverManager.getConnection()' SIGNATURES:
   - 'getConnection(String url)'
   - 'getConnection(String url, String user, String password)'
   - 'getConnection(String url, Properties info)'
