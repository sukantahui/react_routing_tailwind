1. LAYER ROLES:
   - Application Code : Interacts exclusively with standard interfaces.
   - 'DriverManager'  : Manages a list of database drivers and matches the connection URL.
   - Driver JAR       : Translates method calls (e.g. 'executeQuery()') into binary database network packets.
   - Database Engine  : Processes query plans and returns row buffers.
