1. WHAT IS DATASOURCE:
   - Factory interface defined in 'javax.sql.DataSource'.
   - Represents a source of physical or pooled database connections.

2. CORE METHOD:
   - 'Connection getConnection()'
   - 'Connection getConnection(String username, String password)'

3. THREE TYPES OF DATASOURCE IMPLEMENTATIONS:
   - Basic DataSource            : Produces unpooled connections.
   - ConnectionPoolDataSource    : Produces pooled connections (HikariCP, Commons DBCP2).
   - XADataSource                : Produces distributed 2-phase commit transactions.
