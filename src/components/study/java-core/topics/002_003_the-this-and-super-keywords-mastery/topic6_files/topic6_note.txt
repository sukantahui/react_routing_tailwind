1. FLUENT CHAINING MECHANICS:
   - Method return type matches the class type (e.g. 'public MyClass setX(int x)').
   - Last statement in method: 'return this;'
   - Enables dot chaining: 'new MyClass().setA(1).setB(2).setC(3);'
   - Used extensively in Builder patterns and StringBuilder.
