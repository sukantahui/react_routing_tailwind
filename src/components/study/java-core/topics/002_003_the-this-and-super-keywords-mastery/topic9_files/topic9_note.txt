1. FIELD SHADOWING IN INHERITANCE:
   - Fields are NOT polymorphic and are NEVER overridden.
   - If Child declares 'int fee = 200;', it shadows Parent 'int fee = 100;'.
   - 'this.fee' → Child's field (200).
   - 'super.fee' → Parent's field (100).
