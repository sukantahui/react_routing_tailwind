1. STATIC VS 'this':
   -----------------------------------------------------------------------------
   - Static methods/blocks execute at the CLASS level (Metaspace).
   - 'this' requires a living OBJECT on the Heap (Eden space).
   - Calling 'this' inside static context triggers:
     "compile-time error: non-static variable this cannot be referenced from a static context"
