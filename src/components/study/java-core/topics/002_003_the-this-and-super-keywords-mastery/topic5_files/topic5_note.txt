1. PASSING 'this' IN CONSTRUCTOR CALLS:
   - Syntax: 'this.child = new ChildComponent(this);'
   - Binds child component to parent instance for bi-directional navigation.
   - CAUTION: Ensure fields are initialized before passing 'this' to avoid
     exposing partially constructed state.
