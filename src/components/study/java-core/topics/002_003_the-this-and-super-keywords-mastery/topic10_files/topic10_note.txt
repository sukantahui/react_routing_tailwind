1. METHOD EXTENSION VIA 'super':
   - Calling 'super.methodName()' invokes the parent's version of an overridden method.
   - Bypasses dynamic virtual dispatch to execute the base implementation directly.
   - Essential for decorating / augmenting base behavior (e.g. adding 2FA after standard login).
