1. IMPLICIT super() RULES:
   - If you write neither 'this()' nor 'super()' on Line 1, javac automatically
     injects 'super();' at compile time.
   - TRAP: If the parent class does NOT have an accessible no-arg constructor,
     this implicit 'super()' fails with a compile error!
