1. VARIABLE SHADOWING DEFINITION:
   -----------------------------------------------------------------------------
   - Occurs when parameter names match instance variable names.
   - Inside the method/constructor, unqualified variable names resolve to the
     LOCAL parameter!

2. THE 'this.' SOLUTION:
   - 'this.fieldName' → Targets instance variable on Heap.
   - 'fieldName' → Targets local parameter in stack frame.
   - Syntax: 'this.fieldName = fieldName;'

3. THE 'name = name' BUG:
   - Writing 'name = name;' assigns parameter to parameter (no-op).
   - Leaves Heap field uninitialized (null or 0)!
