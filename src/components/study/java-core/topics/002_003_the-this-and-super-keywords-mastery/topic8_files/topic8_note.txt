1. WHAT IS 'super':
   - A reference variable targeting the IMMEDIATE SUPERCLASS of the current object.
   - Used to:
     1. Access shadowed parent instance variables ('super.field').
     2. Invoke overridden parent methods ('super.method()').
     3. Invoke parent constructors ('super()').
