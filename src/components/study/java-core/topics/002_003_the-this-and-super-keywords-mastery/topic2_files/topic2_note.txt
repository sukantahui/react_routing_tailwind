1. METHOD INVOCATION VIA 'this':
   -----------------------------------------------------------------------------
   - Calling 'this.methodName()' explicitly invokes an instance method on the
     current Heap object.
   - If 'this.' is omitted, the compiler automatically inserts it during bytecode
     generation ('invokevirtual').
