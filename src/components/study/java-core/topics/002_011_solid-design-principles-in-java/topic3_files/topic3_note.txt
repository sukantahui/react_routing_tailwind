1. OCP RULE (Bertrand Meyer & Uncle Bob):
   - 'Open for extension, closed for modification.'
   - Replace brittle 'if-else' / 'switch' chains with polymorphic interface strategies.
   - New features = New classes added to classpath without editing existing code.
