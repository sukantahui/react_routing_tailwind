1. THE SOLID MASTER MATRIX:
   - S (Single Responsibility) : 1 reason to change.
   - O (Open/Closed)          : Open for extension, closed for modification.
   - L (Liskov Substitution)   : Subtypes must preserve parent contracts.
   - I (Interface Segregation) : Fine-grained, role-specific interfaces.
   - D (Dependency Inversion)  : Depend on abstractions via constructor DI.
