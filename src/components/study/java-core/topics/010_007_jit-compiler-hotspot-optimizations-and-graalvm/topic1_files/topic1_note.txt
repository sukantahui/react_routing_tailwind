1. WHAT IS TIERED COMPILATION:
   - Default since Java 8 ('-XX:+TieredCompilation').
   - Bridges the gap between C1 (fast compilation, moderate optimization) and C2 (slow compilation, peak optimization).

2. STANDARD PROMOTION PATH:
   - 'Level 0 (Interpreted) &rarr; Level 3 (C1 Full Profiling) &rarr; Level 4 (C2 Server JIT)'.
