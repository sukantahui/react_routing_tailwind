1. BOUNDS-CHECK ELIMINATION (BCE):
   - Java guarantees memory safety by checking array indices against bounds at runtime.
   - HotSpot JIT analyzes loop induction variables ('for (int i=0; i<arr.length; i++)').
   - Replaces N individual runtime bounds checks with a single upfront check before the loop!

2. LOOP UNROLLING:
   - Expands loop bodies to reduce branch instructions and enable CPU instruction-level parallelism.
