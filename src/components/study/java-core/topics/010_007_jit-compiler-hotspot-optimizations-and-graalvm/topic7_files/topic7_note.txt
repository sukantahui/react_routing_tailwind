1. WHAT IS SCALAR REPLACEMENT:
   - An optimization where an Aggregate Object is decomposed into its individual primitive fields (scalars).
   - The scalars are stored directly in CPU Registers or on the Thread Stack Frame instead of on the Heap.

2. PREREQUISITES:
   - The object must be proven 'NoEscape' via Escape Analysis.
   - Enabled by default: '-XX:+EliminateAllocations'.
