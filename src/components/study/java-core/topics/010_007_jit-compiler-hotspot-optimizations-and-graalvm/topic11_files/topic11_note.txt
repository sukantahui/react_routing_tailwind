1. LOG FLAGS CHEATSHEET:
   - '-XX:+PrintCompilation'               : Real-time notification of method compilation and tier.
   - '-XX:+UnlockDiagnosticVMOptions -XX:+PrintInlining' : Explains why methods were or were not inlined.

2. PRINTCOMPILATION ATTRIBUTE FLAGS:
   - '%' : On-Stack Replacement (OSR) compilation.
   - 's' : Synchronized method.
   - '!' : Method has exception handlers.
   - 'b' : Blocking compilation.
   - 'make_not_entrant' : Method de-optimized and marked stale.
