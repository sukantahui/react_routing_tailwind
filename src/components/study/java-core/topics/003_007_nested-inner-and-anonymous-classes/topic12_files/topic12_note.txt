1. BYTECODE FILE NAMING:
   - 'Outer$Inner.class'         : Member inner / Static nested.
   - 'Outer$1Local.class'        : Method-local inner class.
   - 'Outer$1.class'             : First anonymous inner class.
   - 'Outer$2.class'             : Second anonymous inner class.
   - JVM sees all classes as separate top-level classes.
