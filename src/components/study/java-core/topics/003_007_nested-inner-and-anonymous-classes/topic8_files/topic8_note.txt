1. ANONYMOUS INNER CLASS:
   - No explicit class name.
   - Declared and instantiated simultaneously in one expression.
   - Implements an interface or extends a class on the fly.
   - Compiled to synthetic 'Outer$1.class', 'Outer$2.class'.
