1. SHADOWING DISAMBIGUATION:
   - 'name'                 &rarr; Local variable / parameter.
   - 'this.name'            &rarr; Inner class instance variable.
   - 'OuterClass.this.name' &rarr; Enclosing Outer class instance variable.
