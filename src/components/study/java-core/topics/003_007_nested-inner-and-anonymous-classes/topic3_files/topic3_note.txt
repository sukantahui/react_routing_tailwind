1. INSTANTIATION SYNTAX:
   - Style 1: 'Outer outer = new Outer(); Outer.Inner in = outer.new Inner();'
   - Style 2: 'Outer.Inner in = new Outer().new Inner();'
   - 'new Outer.Inner()' only works for STATIC nested classes.
