1. MEMORY LEAK MECHANISM:
   - Inner class holds hidden reference ('this$0') to Outer instance.
   - If Inner is registered in a static/global list, Outer CANNOT be GC'd.
   - Causes OutOfMemoryError in Android Activities & Swing UI.
   - Solution: Use 'static class' or 'WeakReference'.
