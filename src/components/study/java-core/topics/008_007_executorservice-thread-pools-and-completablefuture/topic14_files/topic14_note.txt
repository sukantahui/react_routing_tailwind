1. THENCOMPOSE (ASYNC FLATMAP):
   - Used when Stage 2 returns another CompletableFuture.
   - 'thenApply()' yields: 'CompletableFuture<CompletableFuture<T>>' (Nested).
   - 'thenCompose()' yields: 'CompletableFuture<T>' (Flattened).
   - Perfect for dependent asynchronous sequential workflows (e.g. Auth &rarr; Fetch Profile).
