1. COMPLETABLEFUTURE OVERVIEW:
   - Implements 'Future<T>' + 'CompletionStage<T>' (Java 8+).
   - 100% Non-Blocking: Zero thread waiting with reactive callbacks.
   - Declarative async chaining: 'supplyAsync() &rarr; thenApply() &rarr; thenAccept()'.
   - By default executes on 'ForkJoinPool.commonPool()'.
   - Can accept custom 'ExecutorService' thread pools.
