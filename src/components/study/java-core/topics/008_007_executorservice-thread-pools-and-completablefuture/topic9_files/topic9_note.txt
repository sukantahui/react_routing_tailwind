1. GRACEFUL SHUTDOWN PROTOCOL:
   - 'shutdown()': Stops accepting new tasks; drains existing queue.
   - 'shutdownNow()': Sends 'interrupt()' to running threads; returns unstarted tasks.
   - 'awaitTermination(t, unit)': Blocks calling thread waiting for termination.
   - Standard 2-Phase: 'shutdown()' → 'await(5s)' → if timeout: 'shutdownNow()' → 'await(5s)'.
