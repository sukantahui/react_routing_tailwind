1. NEWCACHEDTHREADPOOL():
   - 'corePoolSize = 0', 'maxPoolSize = Integer.MAX_VALUE' (uncapped!).
   - 'workQueue': 'SynchronousQueue' (zero capacity handoff).
   - Idle threads terminate after 60 seconds.
   - Great for: Many short-lived, lightweight asynchronous tasks.
   - Fatal hazard: Traffic spikes create thousands of threads → Native Stack OOM crash.
