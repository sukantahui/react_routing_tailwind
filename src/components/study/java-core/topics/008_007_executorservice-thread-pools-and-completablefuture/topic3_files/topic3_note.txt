1. EXECUTORS FACTORY TRAPS:
   - 'newFixedThreadPool(n)': Unbounded queue &rarr; Heap OutOfMemoryError.
   - 'newCachedThreadPool()': Unbounded thread count &rarr; Native thread OOM crash.
   - 'newSingleThreadExecutor()': Unbounded queue.
   - Production Best Practice: Instantiate 'ThreadPoolExecutor' with explicit bounded queues!
