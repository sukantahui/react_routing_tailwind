1. EXECUTOR INTERFACE HIERARCHY:
   - 'Executor': 'execute(Runnable)' (bare-bones).
   - 'ExecutorService': 'submit()', 'shutdown()', 'invokeAll()', 'Future<T>'.
   - 'ScheduledExecutorService': 'scheduleAtFixedRate()', 'scheduleWithFixedDelay()'.
   - Implemented by 'ThreadPoolExecutor' and 'ScheduledThreadPoolExecutor'.
