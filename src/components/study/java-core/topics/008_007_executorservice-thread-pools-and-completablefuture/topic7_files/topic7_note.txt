1. SCHEDULED THREAD POOL:
   - 'schedule(task, delay, unit)': One-shot delayed task.
   - 'scheduleAtFixedRate()': Start-to-Start cadence (constant frequency).
   - 'scheduleWithFixedDelay()': End-to-Start cadence (guaranteed rest gap).
   - If a scheduled task throws an unhandled exception, subsequent executions STOP!
