1. EXECUTOR FRAMEWORK:
   - Cleanly separates Task Definition (Runnable/Callable) from Execution (Thread Pool).
   - Reuses worker threads continuously from an internal queue.
   - Throttles concurrency to protect server hardware.
   - Standard: 'ExecutorService executor = Executors.newFixedThreadPool(n)'.
   - Mandatory: Always call 'executor.shutdown()' when finished!
