1. NEWSINGLETHREADEXECUTOR():
   - Exactly 1 worker thread at all times.
   - Strict FIFO execution order.
   - Self-Healing: Spawns a replacement thread if worker crashes.
   - Ideal for: Sequential audit logging, single-writer state machines.
   - Caution: Uses unbounded queue; keep memory bounded in production.
