1. SUPPLYASYNC vs RUNASYNC:
   - 'runAsync(Runnable)': Returns 'CompletableFuture<Void>' (no result).
   - 'supplyAsync(Supplier<T>)': Returns 'CompletableFuture<T>' (with result).
   - Default Pool: 'ForkJoinPool.commonPool()'.
   - Best Practice: Always pass a custom 'ExecutorService' for blocking I/O tasks!
