1. FUTURE<V> INTERFACE:
   - Asynchronous handle representing the pending result of a task.
   - 'get()': Blocks indefinitely (throws ExecutionException if task failed).
   - 'get(timeout, unit)': Enforces SLA timeout (throws TimeoutException).
   - 'cancel(true)': Cancels task and sends thread interrupt.
   - 'isDone()': Checks if finished, failed, or cancelled.
