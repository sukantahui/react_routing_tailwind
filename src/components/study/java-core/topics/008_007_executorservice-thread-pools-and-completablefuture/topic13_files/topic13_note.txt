1. CALLBACK OPERATORS:
   - 'thenApply(Function)': Transforms input → output (map equivalent).
   - 'thenAccept(Consumer)': Consumes value; returns Void.
   - 'thenRun(Runnable)': Ignores value; runs side-effect action.
   - Async variants: 'thenApplyAsync()' dispatches callback to a separate thread pool.
