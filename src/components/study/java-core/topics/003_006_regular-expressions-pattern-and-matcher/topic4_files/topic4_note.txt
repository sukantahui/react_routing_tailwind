1. META-CHARACTERS:
   - '.'  : Any character.
   - '\d' : Digit [0-9].
   - '\D' : Non-digit.
   - '\s' : Whitespace.
   - '\S' : Non-whitespace.
   - '\w' : Word char [a-zA-Z0-9_].
   - '\W' : Non-word char.
