1. MATCHER ITERATION:
   - 'Pattern.compile(regex)'     → Pre-compiles pattern.
   - 'pattern.matcher(text)'      → Returns stateful Matcher.
   - 'matcher.find()'             → Finds next matching occurrence.
   - 'matcher.group()'            → Returns matched string.
   - 'matcher.start()' / 'end()'  → Index boundaries.
