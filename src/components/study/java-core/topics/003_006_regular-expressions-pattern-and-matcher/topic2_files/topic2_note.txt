1. MATCHER ITERATION:
   - 'Pattern.compile(regex)'     &rarr; Pre-compiles pattern.
   - 'pattern.matcher(text)'      &rarr; Returns stateful Matcher.
   - 'matcher.find()'             &rarr; Finds next matching occurrence.
   - 'matcher.group()'            &rarr; Returns matched string.
   - 'matcher.start()' / 'end()'  &rarr; Index boundaries.
