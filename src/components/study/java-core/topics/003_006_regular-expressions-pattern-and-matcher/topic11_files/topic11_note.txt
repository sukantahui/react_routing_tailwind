1. MATCHER METHODS:
   - 'matches()'     : Asserts entire string matches pattern.
   - 'find()'        : Searches for next matching substring.
   - 'reset()'       : Resets search cursor to beginning.
   - 'replaceAll()'  : Replaces all matching substrings.
   - 'replaceFirst()': Replaces only first match.
