1. REGEX FLAGS CHEATSHEET:
   - 'Pattern.CASE_INSENSITIVE' ('(?i)') : Ignores uppercase/lowercase.
   - 'Pattern.MULTILINE'        ('(?m)') : '^' and '$' match start/end of each line.
   - 'Pattern.DOTALL'           ('(?s)') : Dot '.' matches newlines ('\n').
   - Combining flags: 'FLAG1 | FLAG2' (Bitwise OR).
