1. CHARACTER CLASSES:
   - '[abc]'      : Match a, b, or c.
   - '[^abc]'     : Match NOT a, b, or c.
   - '[a-zA-Z]'   : Match any English letter.
   - '[0-9]'      : Match any digit.
   - '[a-z&&[aeiou]]' : Intersection (vowels only).
