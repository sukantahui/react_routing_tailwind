1. QUANTIFIER MODES:
   - Greedy     : '*', '+', '?', '{n,m}' &rarr; Matches maximum length.
   - Reluctant  : '*?', '+?', '??' &rarr; Matches minimum length (lazy).
   - Possessive : '*+', '++', '?+' &rarr; Never backtracks (fastest & ReDoS safe).
