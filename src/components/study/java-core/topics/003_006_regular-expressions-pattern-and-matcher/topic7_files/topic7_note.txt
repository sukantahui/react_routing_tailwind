1. QUANTIFIER MODES:
   - Greedy     : '*', '+', '?', '{n,m}' → Matches maximum length.
   - Reluctant  : '*?', '+?', '??' → Matches minimum length (lazy).
   - Possessive : '*+', '++', '?+' → Never backtracks (fastest & ReDoS safe).
