1. INSTRUCTION REORDERING:
   - Reordered by: javac compiler, JIT compiler (HotSpot C2), CPU hardware pipeline.
   - 'as-if-serial' semantics: Single-threaded execution looks unaltered.
   - Multithreaded hazard: Another thread sees 'ready=true' before data is written!
   - Solution: Use 'volatile' (inserts hardware Memory Barriers preventing reordering).
