1. JAVA MEMORY MODEL (JMM):
   - Formal specification (JSR-133, Java 5+).
   - Governs two critical dimensions:
     1. Visibility: When writes become visible to other threads.
     2. Ordering: When instruction execution order is preserved.
   - Provides unified memory semantics across x86, ARM, and RISC-V.
