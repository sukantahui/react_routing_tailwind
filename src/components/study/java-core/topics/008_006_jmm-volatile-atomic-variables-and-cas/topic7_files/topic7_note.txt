1. VOLATILE MEMORY BARRIERS:
   - StoreStore: Flushes prior writes before volatile write.
   - StoreLoad: Heaviest barrier; separates writes from subsequent reads.
   - LoadLoad & LoadStore: Ensures volatile read happens before subsequent ops.
   - Guarantees Safe Publication: Normal variables written before volatile are visible!
