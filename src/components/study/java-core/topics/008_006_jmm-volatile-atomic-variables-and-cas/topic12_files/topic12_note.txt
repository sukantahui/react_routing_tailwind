1. CORE ATOMIC TYPES:
   - AtomicInteger / AtomicLong: 32-bit & 64-bit lock-free numeric counters.
   - AtomicBoolean: Atomic flags and one-time triggers.
   - AtomicReference<V>: Lock-free atomic reference swaps on custom domain objects.
   - All backed by hardware CAS (Compare-And-Swap).
