1. HAPPENS-BEFORE RULES:
   - Program Order: In-thread statement order.
   - Monitor Lock: Unlock(M) happens-before Lock(M).
   - Volatile Variable: Write(V) happens-before Read(V).
   - Thread Start: start() happens-before thread's run().
   - Thread Join: All thread actions happen-before join() returns.
   - Transitivity: A → B and B → C implies A → C.
