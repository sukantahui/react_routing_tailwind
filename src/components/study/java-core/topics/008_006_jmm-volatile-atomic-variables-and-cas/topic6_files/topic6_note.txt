1. VOLATILE MEMORY VISIBILITY:
   - Writes flush immediately from Store Buffer to RAM.
   - Reads bypass L1/L2 caches and load directly from RAM.
   - Hardware: MESI protocol invalidates other cores' cache lines.
   - Eliminates stale data reads across multi-core CPUs.
