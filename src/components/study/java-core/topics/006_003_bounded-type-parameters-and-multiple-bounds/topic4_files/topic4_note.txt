1. MULTIPLE BOUNDS SYNTAX:
   - '<T extends ClassA & InterfaceB & InterfaceC>'.
   - Ampersand '&' connects bounds.
   - Enforces simultaneous inheritance of class and interfaces.
   - Allows invocation of methods from all listed bounds.
