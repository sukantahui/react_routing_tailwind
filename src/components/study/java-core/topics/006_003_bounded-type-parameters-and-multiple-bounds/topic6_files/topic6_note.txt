1. RECURSIVE TYPE BOUNDS:
   - '<T extends Comparable<T>>'.
   - Self-referential type constraint.
   - Guarantees mutual comparability between instances of 'T'.
   - Powers 'Collections.max()' and 'Collections.sort()'.
