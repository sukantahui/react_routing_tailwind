1. BOUNDED TYPE PARAMETERS:
   - Syntax: '<T extends SuperType>'.
   - Restricts type arguments to subtypes of 'SuperType'.
   - Unlocks supertype methods inside generic class body.
   - Prevents incompatible type instantiation at compile time.
