1. UPPER BOUND SYNTAX:
   - '<T extends SuperType>' establishes upper limit.
   - Accepts 'SuperType' and all descendant subclasses.
   - Rejects unrelated classes at compile time.
   - Enforces domain-specific polymorphism.
