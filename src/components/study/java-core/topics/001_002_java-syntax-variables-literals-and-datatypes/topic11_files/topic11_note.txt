1. CORE CONCEPTS & RULES
--------------------------------------------------------------------------------
- Character Data Type Specifications:
  * Size & Bit Width : 16 bits (2 bytes)
  * Classification   : Unsigned Integral Type
  * Numeric Range    : 0 to 65,535 ('\u0000' to '\uffff')
  * Encoding Standard: UTF-16 Code Units (Basic Multilingual Plane - BMP)

- ASCII Anchor Points:
  * '0' to '9' : ASCII 48 to 57
  * 'A' to 'Z' : ASCII 65 to 90
  * 'a' to 'z' : ASCII 97 to 122
  * Case Offset: 'a' - 'A' == 32 (Add 32 to lowercase, subtract 32 to uppercase)

- Arithmetic & Type Promotion:
  * Math on char ('A' + 1) promotes to 'int' (result: 66).
  * Explicit cast needed: (char)('A' + 1) --> 'B'.
  * Increment (c++) performs implicit narrowing cast.
  * Digit to integer conversion: int digit = ch - '0'; ('7' - '0' = 7).

- Unicode Escape Sequences (\uXXXX):
  * Exactly 4 hexadecimal digits: '\uXXXX'
  * Indian Rupee (₹)     : '\u20B9'
  * Copyright (©)        : '\u00A9'
  * Bengali Ka (ক)       : '\u0995'
  * Bengali Ba (ব)       : '\u09AC'
  * Bengali Ra (র)       : '\u09B0'

- Supplementary Characters (Emojis & Rare Glyphs > U+FFFF):
  * Stored as Surrogate Pairs (High Surrogate + Low Surrogate = 2 chars).
  * Use str.codePointCount(0, str.length()) for real glyph count.

- Password Security Best Practice:
  * Store passwords in char[] instead of String so memory can be zeroed out
    immediately via Arrays.fill(pwd, '\u0000').
