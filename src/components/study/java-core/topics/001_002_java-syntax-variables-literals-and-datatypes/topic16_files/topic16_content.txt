1. COMPREHENSIVE SCANNER PARSING METHODOLOGY
The `java.util.Scanner` class is one of the most feature-rich parsing utilities in the Java standard library. It provides distinct method families tailored for:
1. Token-level String consumption (`next()`).
2. Line-level String consumption (`nextLine()`).
3. Primitive numeric decoding (`nextByte`, `nextShort`, `nextInt`, `nextLong`, `nextFloat`, `nextDouble`).
4. Truth value parsing (`nextBoolean`).
5. Arbitrary precision financial accounting (`nextBigInteger`, `nextBigDecimal`).

2. TOKEN-BASED (next()) VS LINE-BASED (nextLine()) MECHANICS
A. `scanner.next()`:
   - Skips all leading whitespace delimiters.
   - Accumulates characters until encountering the first delimiter (space, tab, newline).
   - Returns the single token.
   - Example: Input "Barrackpore West Bengal" → `next()` returns "Barrackpore".

B. `scanner.nextLine()`:
   - Scans from the current cursor position to the next newline character (`\n` or `\r\n`).
   - Consumes the newline character from the stream.
   - Returns all preceding text on that line (including spaces).
   - Example: Input "25 Shibtala Road, Barrackpore" → `nextLine()` returns "25 Shibtala Road, Barrackpore".

3. PRIMITIVE & HIGH-PRECISION NUMERIC PARSING
- `nextInt()` / `nextInt(radix)`: Parses 32-bit signed two's complement integers. Supports radix parsing for hexadecimal (`radix 16`) and binary (`radix 2`).
- `nextDouble()` / `nextFloat()`: Parses standard and scientific exponential notation (e.g. `1.5e4`). Respects locale decimal delimiters (`.` vs `,`).
- `nextBigDecimal()`: Highly recommended for commercial invoicing and student tuition fees in Indian Rupees (₹) to prevent IEEE 754 precision artifacts.

4. THE ROLE OF NEXTBOOLEAN()
- Matches case-insensitive regex `(?i:true|false)`.
- Valid inputs: "true", "TRUE", "True", "false", "FALSE", "False".
- Any other string throws `InputMismatchException`.

5. MODERN JAVA 9+ STREAM ENHANCEMENTS
In Java 9, `Scanner` was upgraded with functional streaming:
- `scanner.tokens()`: Returns `Stream<String>` of remaining tokens.
- `scanner.findAll(Pattern)`: Streams regex match results across inputs.
