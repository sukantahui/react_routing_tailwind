1. PHILOSOPHICAL FOUNDATIONS OF BOOLEAN IN JAVA
In computer programming languages, conditional branching is the mechanism by which algorithms make decisions. In older languages (such as C, C++, and early scripting languages), truth values were conflated with numeric integers (where `0` represented false and any non-zero integer represented true).

This architectural ambiguity led to countless catastrophic bugs, most notably the infamous accidental assignment in conditional statements (`if (x = 1)`).

In Java, James Gosling established a strict, unbreachable boundary between numbers and truth values by introducing the `boolean` primitive data type.

2. SPECIFICATIONS & MEMORY REPRESENTATION
- Legal Literals: `true` and `false` (lowercase reserved keywords).
- Storage Size:
  * In JVM HotSpot, individual boolean variables on the stack occupy 32-bit int slots for CPU alignment.
  * In heap arrays (`boolean[]`), each element consumes exactly 1 byte (8 bits).
  * For extreme memory efficiency (e.g. millions of bit flags), `java.util.BitSet` compresses booleans to exactly 1 bit per flag.
- Default Value: `false` for uninitialized instance and static fields.
- Non-Convertibility: Java forbids implicit and explicit casting between boolean and numeric types.

3. PREVENTING THE ACCIDENTAL ASSIGNMENT BUG
In C/C++:
  int authenticated = 0;
  if (authenticated = 1) { // BUG: assigns 1, evaluates to true!
    grantAdminAccess();    // Security breach!
  }

In Java:
  int authenticated = 0;
  if (authenticated = 1) { // COMPILE-TIME ERROR: Type mismatch int cannot convert to boolean!
    grantAdminAccess();
  }
The Java compiler catches this mistake instantly during compilation.

4. SHORT-CIRCUIT VS EAGER LOGICAL OPERATORS
A. Short-Circuit AND (`&&`):
   Evaluates left operand first. If `false`, the entire expression is immediately `false`, and the right operand is NEVER evaluated.
   Critical Guard Pattern:
   if (student != null && student.getFee() > 0) { ... } // Safe against NullPointerException

B. Short-Circuit OR (`||`):
   Evaluates left operand first. If `true`, the entire expression is immediately `true`, and the right operand is skipped.

C. Eager Logical Operators (`&` and `|`):
   Evaluate both left and right expressions unconditionally.

D. Logical XOR (`^`):
   Returns `true` if and only if exactly one operand is `true`.

5. WRAPPER CLASS: JAVA.LANG.BOOLEAN
- Primitive `boolean` has object wrapper `Boolean`.
- Beware of `null` references during auto-unboxing:
  Boolean flag = null;
  boolean b = flag; // THROWS NullPointerException at runtime!
- Use static constants `Boolean.TRUE` and `Boolean.FALSE` instead of allocating new objects.
