1. PROCEDURAL VS OBJECT-ORIENTED PARADIGM
--------------------------------------------------------------------------------
- Procedural Paradigm (C / Pascal style):
  * Code is organized into step-by-step procedures/functions.
  * Data (global variables/arrays) is DECOUPLED from functions.
  * Major Flaw: State is globally exposed and prone to corruption (no data hiding!).

- Object-Oriented Paradigm (Java OOP):
  * Code is organized around OBJECTS that bundle State (fields) and Behavior (methods).
  * Encapsulation: Fields are private; access is strictly controlled via public methods.
  * Invariant Protection: Business rules (e.g. balance >= 0) are validated inside methods.

- The 4 Pillars of OOP:
  1. Encapsulation : Bundling data & methods; Data Hiding (private fields).
  2. Inheritance   : Code reuse and hierarchical specialization (extends).
  3. Polymorphism   : Dynamic method dispatch and flexible interfaces.
  4. Abstraction   : Hiding internal complexity via abstract classes & interfaces.
