1. MAJOR CHARSETS:
   - 'US-ASCII'   : 7-bit (0-127). English only.
   - 'ISO-8859-1' : 8-bit (0-255). Latin-1.
   - 'UTF-8'      : 1-4 bytes variable. Global standard.
   - 'UTF-16'     : 2 or 4 bytes. JVM internal String memory.
