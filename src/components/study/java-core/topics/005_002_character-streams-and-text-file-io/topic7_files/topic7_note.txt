1. BRIDGE ARCHITECTURE:
   - 'InputStreamReader' : InputStream (Bytes) → Reader (Chars).
   - 'OutputStreamWriter': Writer (Chars) → OutputStream (Bytes).
   - Always supply 'StandardCharsets.UTF_8' as the 2nd constructor parameter.
   - Core mechanism used by 'new Scanner(System.in)' and 'new BufferedReader(new InputStreamReader(System.in))'.
