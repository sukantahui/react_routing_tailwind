1. CHARACTER STREAM BASE CLASSES:
   - 'java.io.Reader': Abstract superclass for character input.
   - 'java.io.Writer': Abstract superclass for character output.
   - 'Writer' implements 'Flushable' to force buffered characters to destination.
   - Both implement 'AutoCloseable' for ARM compatibility.
