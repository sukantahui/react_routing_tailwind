1. CORE READER METHODS:
   - 'int read()'                    : Reads 1 char (returns 0-65535 or -1 for EOF).
   - 'int read(char[] cbuf)'         : Reads block into buffer array.
   - 'boolean ready()'               : Returns true if read won't block.
   - 'void close()'                  : Closes stream and frees OS descriptor.
