1. StandardCharsets ADVANTAGES:
   - 'StandardCharsets.UTF_8' from 'java.nio.charset'.
   - Avoids string typos like "UTF8" or "utf-8".
   - No 'UnsupportedEncodingException' declared.
   - Pre-allocated static Charset instance for maximum speed.
