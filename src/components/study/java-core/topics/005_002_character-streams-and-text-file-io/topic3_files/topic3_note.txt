1. CORE WRITER METHODS:
   - 'write(int c)'                  : Writes 1 char.
   - 'write(char[] cbuf, off, len)'  : Writes char array slice.
   - 'write(String str)'             : Writes String directly.
   - 'flush()'                       : Flushes internal memory buffers.
   - 'close()'                       : Flushes buffers and closes stream.
