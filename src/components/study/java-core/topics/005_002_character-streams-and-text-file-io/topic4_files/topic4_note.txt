1. FILEREADER & FILEWRITER (Java 11+):
   - Always pass 'StandardCharsets.UTF_8'.
   - 'new FileWriter(file, StandardCharsets.UTF_8, appendMode)'.
   - Avoid legacy constructors that rely on OS default encoding.
   - Clean, lightweight for small text files.
