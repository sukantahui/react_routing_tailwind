1. BYTE VS CHARACTER STREAMS:
   - Byte Streams (8-bit): InputStream, OutputStream (Images, audio, PDFs, binary).
   - Character Streams (16-bit): Reader, Writer (Text, JSON, CSV, logs).
   - Character streams decode multi-byte UTF-8 sequences (Bengali, Hindi, Emojis) cleanly.
