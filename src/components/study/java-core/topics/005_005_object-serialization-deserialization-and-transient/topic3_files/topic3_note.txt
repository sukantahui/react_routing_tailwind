1. OBJECT STREAM LIFECYCLE:
   - 'ObjectOutputStream.writeObject(obj)' flattens object graph.
   - 'ObjectInputStream.readObject()' rehydrates live object (requires cast).
   - Supports mixed primitives: 'writeInt()', 'writeUTF()', 'writeDouble()'.
   - Mandatory: read in the EXACT same sequence written.
