1. MARKER INTERFACE RULES:
   - 'java.io.Serializable' has 0 methods and 0 fields.
   - Opt-in signal: tells JVM 'this class is safe for serialization'.
   - Checked at runtime: 'if (!(obj instanceof Serializable)) throw new NotSerializableException()'.
   - Subclasses automatically inherit Serializable status.
