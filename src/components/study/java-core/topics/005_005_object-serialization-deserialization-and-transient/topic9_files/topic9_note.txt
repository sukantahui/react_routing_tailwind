1. InvalidClassException DIAGNOSTICS:
   - Thrown when stream UID != class UID.
   - Message displays: 'local class incompatible: stream classdesc serialVersionUID = X, local class serialVersionUID = Y'.
   - Compatible evolution: Keep UID identical when adding new fields.
   - Incompatible evolution: Increment UID when removing fields or altering types.
