1. THE TRANSIENT MODIFIER:
   - 'private transient String password;'.
   - Instructs ObjectOutputStream to skip this field entirely.
   - Upon deserialization, field becomes default (null / 0 / false).
   - Used for passwords, temporary caches, and non-serializable OS handles.
