1. STATIC FIELD BEHAVIOR:
   - 'static' variables are NEVER written to the serialized byte stream.
   - Deserialized objects read whatever static value the receiving JVM currently holds.
   - 'transient' is for instance fields; 'static' is automatically non-serialized.
