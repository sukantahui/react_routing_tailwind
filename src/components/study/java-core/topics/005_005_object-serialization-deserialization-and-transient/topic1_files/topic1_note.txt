1. DESERIALIZATION RECONSTRUCTION:
   - 'ObjectInputStream.readObject()' rehydrates live object.
   - Constructor of Serializable class is NEVER called.
   - JVM directly populates fields from stream byte offsets.
   - Restored instance is a new, independent heap clone (== returns false).
