1. NotSerializableException DIAGNOSTICS:
   - Thrown when an object in the graph lacks 'Serializable' marker.
   - 'ex.getMessage()' returns the exact offending class name.
   - Solutions:
     1. Add 'implements Serializable'.
     2. Mark field 'transient'.
     3. Implement custom 'writeObject()' and 'readObject()'.
