1. BUFFERED BYTE STREAMS:
   - 'BufferedOutputStream': Wraps OutputStream; caches writes before OS flush.
   - 'BufferedInputStream' : Wraps InputStream; supports 'mark()' and 'reset()'.
   - Classic GoF Decorator Design Pattern implementation.
   - Always close the outermost decorator stream.
