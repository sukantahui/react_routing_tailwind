1. PERFORMANCE COMPARISON:
   - 'BufferedReader': 8KB buffer, pure char search, ~10x faster, thread-safe.
   - 'Scanner': 1KB buffer, regex pattern engine, parses primitives, slower.
   - Rule of Thumb: Use Scanner for small user console inputs; use BufferedReader for files and big data.
