1. BUFFER INTERNALS:
   - Default size: 8192 (8 KB).
   - Internal state variables: 'pos' (cursor), 'count' (valid bytes cached).
   - Matches standard OS 4KB/8KB filesystem block allocations.
   - Custom tuning: 'new BufferedInputStream(in, 65536)' for 64KB high-speed processing.
