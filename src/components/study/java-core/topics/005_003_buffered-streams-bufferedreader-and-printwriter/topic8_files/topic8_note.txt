1. SCANNER ADVANTAGES:
   - Built-in type conversion: 'nextInt()', 'nextDouble()', 'nextBoolean()'.
   - Automatic whitespace tokenization.
   - Custom delimiters: 'scanner.useDelimiter(",")'.
   - Slower than BufferedReader due to regex overhead, but convenient for primitives.
