1. BufferedReader.readLine() RULES:
   - Canonical loop: 'while ((line = br.readLine()) != null)'.
   - Returns String content without trailing '\n' or '\r'.
   - Returns 'null' at EOF.
   - 10x to 50x faster than Scanner for raw line extraction.
