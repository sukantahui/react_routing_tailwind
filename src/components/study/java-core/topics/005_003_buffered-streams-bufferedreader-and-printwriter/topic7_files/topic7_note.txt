1. PRINTWRITER ERROR DESIGN:
   - 'print()', 'println()', 'printf()' DO NOT throw 'IOException'.
   - Eliminates try-catch boilerplate.
   - Internal boolean error flag is set upon failure.
   - Call 'pw.checkError()' to flush and verify stream health.
