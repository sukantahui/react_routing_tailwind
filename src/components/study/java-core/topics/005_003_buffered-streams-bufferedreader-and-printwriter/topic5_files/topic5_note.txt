1. BUFFEREDWRITER BENEFITS:
   - Buffers character writes in 8KB memory chunks.
   - 'bw.newLine()' inserts OS-specific line separator ('System.lineSeparator()').
   - 'bw.flush()' pushes pending characters to destination.
   - Ideal for generating massive CSV and log exports.
