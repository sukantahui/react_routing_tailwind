1. PATH FACTORIES:
   - Modern (Java 11+): 'Path.of("folder", "sub", "file.txt")'.
   - Legacy (Java 7)  : 'Paths.get("folder", "sub", "file.txt")'.
   - URI Factory      : 'Path.of(URI.create("file:///C:/app/log.txt"))'.
   - Prefer 'Path.of()' for all modern Java development.
