1. readAllLines() USAGE:
   - 'List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8)'.
   - 'Files.write(path, List<String>, StandardCharsets.UTF_8)'.
   - Eager memory loading; ideal for small configs and CSVs.
   - For massive big data files, use lazy 'Files.lines(path)'.
