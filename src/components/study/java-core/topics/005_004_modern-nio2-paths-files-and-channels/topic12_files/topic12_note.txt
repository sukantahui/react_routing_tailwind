1. STREAM FILE UTILITIES:
   - 'Files.lines(path)': Lazy line streaming; ideal for gigabyte logs.
   - 'Files.list(dir)': Streams 1st-level directory entries lazily.
   - 'Files.walk(dir, maxDepth)': Recursive directory tree traversal.
   - 'Files.find(dir, depth, matcher)': Combines walking with file attribute predicates.
   - ALWAYS enclose returned streams in Try-with-Resources!
