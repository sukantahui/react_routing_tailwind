1. CHANNEL & BUFFER LIFECYCLE:
   - 'FileChannel.open(path, StandardOpenOption.READ/WRITE)'.
   - 'ByteBuffer.allocate(size)' or 'ByteBuffer.allocateDirect(size)'.
   - Writing data: advances 'position'.
   - 'flip()': switches buffer to reading mode (limit = pos, pos = 0).
   - 'clear()': resets buffer for fresh writes (pos = 0, limit = cap).
