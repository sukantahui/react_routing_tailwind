1. CORE PATH METHODS:
   - 'getFileName()'     : Target file or directory name.
   - 'getParent()'        : Parent directory path.
   - 'normalize()'        : Removes '.' and '..' redundant elements.
   - 'toAbsolutePath()'   : Converts to fully qualified filesystem path.
   - 'resolve(child)'     : Concatenates child path to base.
   - 'relativize(target)' : Computes relative path from this to target.
