1. LIFECYCLE OPERATIONS:
   - 'Files.createDirectories(path)': Creates entire folder chain.
   - 'Files.createFile(path)': Creates empty file (fails if exists).
   - 'Files.copy(src, dst, StandardCopyOption.REPLACE_EXISTING)'.
   - 'Files.move(src, dst, StandardCopyOption.ATOMIC_MOVE)'.
   - 'Files.delete(path)' vs 'Files.deleteIfExists(path)'.
