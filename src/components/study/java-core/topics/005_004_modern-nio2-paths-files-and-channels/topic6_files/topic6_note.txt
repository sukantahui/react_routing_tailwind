1. METADATA METHODS:
   - 'Files.exists(path)'        : Checks existence.
   - 'Files.isRegularFile(path)' : Confirms normal physical file (not directory).
   - 'Files.isDirectory(path)'   : Checks if folder.
   - 'Files.size(path)'          : File size in bytes.
   - 'Files.getLastModifiedTime' : Queries OS modification timestamp.
