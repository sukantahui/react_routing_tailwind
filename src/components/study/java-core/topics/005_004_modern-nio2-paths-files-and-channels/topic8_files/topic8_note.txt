1. COPY & MOVE OPTIONS:
   - 'StandardCopyOption.REPLACE_EXISTING': Overwrites destination if present.
   - 'StandardCopyOption.COPY_ATTRIBUTES': Preserves timestamps and permissions.
   - 'StandardCopyOption.ATOMIC_MOVE': Kernel-level instantaneous atomic rename.
   - 'LinkOption.NOFOLLOW_LINKS': Does not dereference symbolic links.
