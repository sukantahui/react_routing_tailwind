1. PATH INTERFACE CONTRACT:
   - 'Path': Immutable and thread-safe locator.
   - Converting to legacy File: 'path.toFile()'.
   - Converting from legacy File: 'file.toPath()'.
   - Zero disk I/O on creation; purely represents a locator.
