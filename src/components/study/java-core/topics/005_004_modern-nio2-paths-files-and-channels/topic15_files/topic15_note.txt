1. WATCHSERVICE WORKFLOW:
   - 'WatchService watcher = FileSystems.getDefault().newWatchService()'.
   - 'path.register(watcher, ENTRY_CREATE, ENTRY_MODIFY, ENTRY_DELETE)'.
   - 'WatchKey key = watcher.take()' (blocking) or 'watcher.poll(timeout)'.
   - Iterate 'key.pollEvents()'.
   - Mandatory: call 'key.reset()' to stay in ready state.
