1. LEGACY FILE FLAWS:
   - Silent failures: returns 'false' instead of throwing informative exceptions.
   - 'listFiles()' causes OOM on directories with millions of files.
   - Lacks atomic move and replace options.
   - Cannot read POSIX permissions or handle symbolic links.
   - Superseded by 'java.nio.file.Path' and 'java.nio.file.Files'.
