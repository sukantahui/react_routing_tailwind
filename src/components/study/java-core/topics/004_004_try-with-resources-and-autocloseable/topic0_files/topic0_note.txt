1. LEGACY CLEANUP ANTI-PATTERNS:
   - Nested try-catch blocks inside 'finally'.
   - Null-checks required before closing.
   - If first 'close()' fails, subsequent streams are never closed (leak).
   - Clutters code and masks original business exceptions.
