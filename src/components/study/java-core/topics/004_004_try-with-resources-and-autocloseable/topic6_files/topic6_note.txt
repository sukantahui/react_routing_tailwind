1. MULTIPLE RESOURCES SYNTAX:
   - Separate declarations with semicolons: 'try (Res1 r1 = ...; Res2 r2 = ...)'.
   - Both resources are scoped to the try block.
   - Automatically closed in reverse order upon completion.
