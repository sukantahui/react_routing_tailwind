1. AUTOCLOSEABLE SPECIFICATION:
   - Root interface for ARM: 'java.lang.AutoCloseable'.
   - Method: 'void close() throws Exception;'.
   - Implementers should narrow the throws clause if possible.
   - Must be idempotent (safe against double-closing).
