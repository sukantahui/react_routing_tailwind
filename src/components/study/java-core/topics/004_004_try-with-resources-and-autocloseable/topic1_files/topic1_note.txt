1. ARM / TRY-WITH-RESOURCES:
   - Syntax: 'try (Resource r = new Resource()) { ... }'
   - Automatically calls 'r.close()' upon exit.
   - Eliminates tedious manual finally blocks.
   - Guaranteed closing even during exceptions.
