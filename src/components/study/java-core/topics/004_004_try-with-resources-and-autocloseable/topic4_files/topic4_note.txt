1. CLOSEABLE DIFFERENCES:
   - 'java.io.Closeable' extends 'java.lang.AutoCloseable'.
   - Narrows exception from 'Exception' to 'IOException'.
   - Dedicated specifically to I/O streams (FileInputStream, etc.).
   - Both work seamlessly with Try-with-Resources.
