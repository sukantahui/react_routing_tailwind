1. WHAT IS SERIAL GC:
   - Enabled via '-XX:+UseSerialGC'.
   - Performs all garbage collection work in a single thread.
   - Full STW pauses for both Young and Old generation collections.

2. ADVANTAGES:
   - Lowest memory footprint and CPU overhead of any Java collector.
   - Zero multi-threaded synchronization or inter-thread communication penalty.
