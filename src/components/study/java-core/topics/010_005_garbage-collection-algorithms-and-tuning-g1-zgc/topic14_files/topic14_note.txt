1. THE 3 CORE HEAP SIZING FLAGS:
   - '-Xms<size>' : Initial heap size at JVM startup.
   - '-Xmx<size>' : Maximum allowable heap size.
   - '-Xmn<size>' : Sets the size of the Young Generation directly (Eden + Survivors).

2. CONTAINER SIZING RULE OF THUMB:
   - In Docker/Kubernetes, set Max Heap to 70-80% of the container memory limit.
   - Example for 4GB Pod Limit: '-XX:MaxRAMPercentage=75.0' or '-Xmx3g'.
