1. WHY REFERENCE COUNTING WAS REJECTED BY JAVA:
   - In Reference Counting, each object holds an integer count of inbound pointers.
   - Flaw: Circular References ('A &rarr; B &rarr; A') maintain a count &ge; 1 even when totally disconnected
     from the running application ('Island of Isolation').

2. JAVA'S SOLUTION: GC ROOTS REACHABILITY ANALYSIS (Tracing):
   - A graph traversal algorithm starting from a set of known live pointers ('GC Roots').
   - Traverses all object references.
   - Any object in the heap that is not reachable via any path from a GC Root is marked dead.
