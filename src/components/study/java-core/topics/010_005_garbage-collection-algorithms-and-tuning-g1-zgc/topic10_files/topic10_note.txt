1. WHAT IS G1 GC (Garbage-First):
   - Default collector starting with Java 9 LTS through modern Java 21+.
   - Designed for multi-gigabyte heaps (4GB to 64GB+).
   - Divides heap into ~2,048 equal regions.

2. KEY ADVANTAGES:
   - Predictable pause times: G1 adjusts Young Gen size dynamically to meet '-XX:MaxGCPauseMillis'.
   - Eliminates Full GCs through incremental concurrent mixed collections.
   - Handles Humongous Objects (objects &gt; 50% region size) in dedicated H-regions.
