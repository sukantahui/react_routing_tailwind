1. WHAT IS GARBAGE COLLECTION:
   - Automated dynamic memory management built into the Java Virtual Machine.
   - Eliminates manual pointer management ('malloc', 'free', 'delete' from C/C++).
   - Eliminates common memory bugs: dangling pointers, double-free, and most memory leaks.

2. WHEN AN OBJECT BECOMES ELIGIBLE FOR GC:
   - When it cannot be reached by any chain of live references starting from a GC Root.
   - Explicitly nullifying references ('obj = null') or exiting a variable's scope makes objects unreachable.
