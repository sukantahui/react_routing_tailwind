1. THE DANGER OF RETURN IN FINALLY:
   - Overrides return values from try and catch.
   - Silently swallows propagating exceptions.
   - Converts severe crashes into fake successful executions.
   - RULE: 'finally' must ONLY perform resource cleanup, never control flow.
