1. THE 'catch' BLOCK:
   - Parameter specifies target exception type ('catch (IOException ex)').
   - Polymorphic: catches the declared type and all its subclasses.
   - Core methods: 'getMessage()', 'getCause()', 'printStackTrace()'.
