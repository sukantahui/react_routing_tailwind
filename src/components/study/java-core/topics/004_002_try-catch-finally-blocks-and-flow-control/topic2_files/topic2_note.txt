1. FLOW CONTROL RULES:
   - Success Case: try block runs to completion → catch skipped → post-code runs.
   - Failure Case: try block aborts at failure → catch runs → post-code runs.
   - Uncaught Error: try aborts → method terminates abruptly → exception propagates.
