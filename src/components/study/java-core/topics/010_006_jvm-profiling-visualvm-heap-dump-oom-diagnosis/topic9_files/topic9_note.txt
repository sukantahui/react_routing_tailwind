1. WHAT IS JPS:
   - Java Process Status tool.
   - Lists instrumented HotSpot JVM processes running under the current user account on the target machine.

2. ESSENTIAL FLAGS:
   - '-l' : Prints full package name of the main class or JAR file path.
   - '-v' : Prints JVM options/arguments ('-Xms', '-Xmx', '-XX' options).
   - '-m' : Prints application arguments passed to 'main()'.
