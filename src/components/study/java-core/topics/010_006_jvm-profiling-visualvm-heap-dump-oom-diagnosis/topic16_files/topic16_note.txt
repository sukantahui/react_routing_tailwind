1. DOMINATOR TREE DEFINITION:
   - Transforms the complex, cyclical object reference graph into a strict, tree-shaped
     dominator hierarchy.
   - The top nodes in the Dominator Tree are the single largest memory retainers in the JVM.

2. IMMEDIATE DOMINATOR (idom):
   - The unique closest node that dominates a target node.
