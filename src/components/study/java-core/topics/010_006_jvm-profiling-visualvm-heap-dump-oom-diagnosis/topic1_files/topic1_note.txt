1. TAXONOMY OF JAVA LEAKS:
   - Heap Leaks       : Managed Java objects held by unintended GC Root chains.
   - Native/Off-Heap  : 'ByteBuffer.allocateDirect()', JNI malloc allocations, unclosed file descriptors.
   - Metaspace Leaks  : ClassLoader leakage from hot code reloading and dynamic proxy generation.
