1. WHAT IS VISUALVM:
   - Visual all-in-one profiling tool for Java applications.
   - Included historically with JDK (now standalone at 'visualvm.github.io').
   - Integrates JConsole MBeans, JFR snapshots, and HPROF heap dump viewing.

2. SAMPLING VS PROFILING:
   - Sampling (Recommended for Prod/Staging) : Periodically polls thread stacks (low overhead ~2-5%).
   - Instrumentation Profiling (Dev only)    : Modifies bytecode to measure exact execution times (high overhead).
