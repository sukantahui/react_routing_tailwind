1. WHY EXCLUDE WEAK/SOFT REFERENCES:
   - Weak and Soft references do not prevent Garbage Collection when memory is tight.
   - Excluding them isolates the STRONG references that are actively keeping the object pinned in memory.

2. FORENSIC VALUE:
   - Tells you the EXACT field name, object instance, and class holding the reference.
