1. WHAT IS ECLIPSE MAT:
   - Industry-standard open-source memory analyzer for Java heap dumps.
   - Capable of analyzing massive production heap dumps (multi-gigabyte to terabyte).

2. KEY WORKFLOW:
   - Step 1: Open '.hprof' file in MAT.
   - Step 2: Review automated 'Leak Suspects' pie chart report.
   - Step 3: Drill down into 'Dominator Tree' or 'Histogram'.
   - Step 4: Inspect 'Path to GC Roots' to locate the offending reference.
