1. WHAT IS JCMD:
   - Recommended command-line utility for sending diagnostic command requests to the JVM.
   - Introduced in Java 7 to unify all diagnostic interfaces into a single tool.

2. COMMAND SYNTAX:
   - 'jcmd <pid | main_class> <command> [arguments]'
