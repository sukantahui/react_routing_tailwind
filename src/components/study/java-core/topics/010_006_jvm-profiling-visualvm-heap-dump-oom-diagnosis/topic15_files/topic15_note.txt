1. WHAT THE REPORT REVEALS:
   - Uses heuristic algorithms to identify single objects or collections that dominate &gt;10% of the heap.
   - Shows the exact class name, ClassLoader, and retained byte size.
   - Lists relevant keywords and stack traces active during allocation.

2. SPEED OF TRIAGE:
