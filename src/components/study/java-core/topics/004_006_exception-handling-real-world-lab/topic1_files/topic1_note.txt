1. RFC 7807 ERROR MODEL FIELDS:
   - 'timestamp'  : Instant.now() in UTC.
   - 'status'     : HTTP status code (400, 404, 500).
   - 'errorCode'  : Machine-parseable identifier ('PAY_4001').
   - 'message'    : Descriptive string.
   - 'path'       : Endpoint URI ('/api/v1/enroll').
   - 'fieldErrors': Map of specific validation failures.
