1. CORE EXAM HIGHLIGHTS:
   - System.exit(0) bypasses finally.
   - Catch order: Subclass before Superclass.
   - Multi-catch parameter is implicitly final.
   - ARM calls close() in reverse order of declaration.
   - Never return inside finally (swallows exceptions).
