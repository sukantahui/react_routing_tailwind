1. MODULE 002_009 SUMMARY:
   - Packages organize code and prevent namespace collisions.
   - Reverse domain name (com.coderaccotax.app) ensures global uniqueness.
   - 4 Access Modifiers: private, default, protected, public.
   - Packaged CLI: 'javac -d bin' and 'java -cp bin com.pkg.Main'.
   - JAR packaging bundles bytecode + MANIFEST.MF metadata.
   - Java 9 JPMS enforces module boundaries: 'requires', 'exports', 'opens'.
