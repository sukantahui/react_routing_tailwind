1. WILDCARD IMPORT FACTS:
   - 'import java.util.*' imports types in that package on-demand.
   - It does NOT import sub-packages (e.g. 'java.util.concurrent' is NOT imported).
   - Bytecode contains exact fully qualified class names (Zero runtime difference).
