1. METHOD SIGNATURE:
   - 'Optional<T> reduce(BinaryOperator<T> accumulator)'

2. EXECUTION SEMANTICS:
   - If stream is empty → returns 'Optional.empty()'.
   - If stream has 1 element → returns 'Optional.of(element)' without invoking accumulator.
   - If stream has N elements → first element is used as initial accumulator, then combined
     with remaining N-1 elements.

3. COMMON USE CASES:
   - Finding custom min/max without requiring Comparator.
   - Finding the longest/shortest string.
   - Mathematical reductions when no neutral identity exists.
