1. NUMERIC PRIMITIVE TERMINAL REDUCTIONS:
   - 'sum()': Returns primitive int, long, or double sum (Identity is 0).
   - 'average()': Returns 'OptionalDouble' (handles 0 elements safely).
   - 'min()': Returns 'OptionalInt', 'OptionalLong', or 'OptionalDouble'.
   - 'max()': Returns 'OptionalInt', 'OptionalLong', or 'OptionalDouble'.

2. SUMMARYSTATISTICS CLASSES:
   - 'IntSummaryStatistics', 'LongSummaryStatistics', 'DoubleSummaryStatistics'.
   - Captures count, min, max, sum, and average in a single sequential or parallel pass.
   - Extremely memory-efficient and fast for business dashboards.
