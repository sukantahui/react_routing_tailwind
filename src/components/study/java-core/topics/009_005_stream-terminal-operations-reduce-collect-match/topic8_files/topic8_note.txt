1. METHOD CONTRACT:
   - Signature: 'boolean anyMatch(Predicate<? super T> predicate)'.
   - Returns 'true' if AT LEAST ONE element matches the given predicate.
   - Terminal & Short-Circuiting operation.
   - If stream is empty, returns 'false' immediately without evaluating predicate.

2. SHORT-CIRCUIT BEHAVIOR:
   - Halts processing as soon as predicate evaluates to 'true' for any single element.
   - If no element matches, traverses the entire stream before returning 'false'.
