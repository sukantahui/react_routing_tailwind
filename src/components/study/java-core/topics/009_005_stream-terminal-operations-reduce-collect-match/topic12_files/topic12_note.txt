1. METHOD CONTRACT:
   - Signature: 'Optional<T> findAny()'.
   - Returns an Optional describing some element of the stream, or an empty Optional if the stream is empty.
   - Terminal & Short-Circuiting operation.

2. FINDFIRST VS FINDANY IN PARALLEL STREAMS:
   -----------------------------------------------------------------------------
   METHOD        ORDER GUARANTEE            PARALLEL PERFORMANCE
   -----------------------------------------------------------------------------
   findFirst()   Strict Encounter Order     Requires thread synchronization barrier
   findAny()     Non-deterministic (Any)    Maximum performance (lock-free winner takes all)
   -----------------------------------------------------------------------------
