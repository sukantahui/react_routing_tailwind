1. DISTINCT METHOD CONTRACT:
   - Signature: 'Stream<T> distinct()'.
   - Returns a stream consisting of the distinct elements of this stream.
   - Intermediate & Stateful operation.
   - For ordered streams, preserves encounter order (the first occurrence is retained).

2. EQUALS & HASHCODE PREREQUISITE:
   - For custom classes, 'Object.equals(Object)' and 'Object.hashCode()' MUST be overridden correctly.
   - Using Java 'record' automatically provides correct value-based equals and hashCode implementations.
