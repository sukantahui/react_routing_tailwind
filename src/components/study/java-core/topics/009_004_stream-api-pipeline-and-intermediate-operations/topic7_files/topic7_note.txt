1. STREAM.ITERATE():
   - Generates an ordered infinite sequential stream produced by iterative application of a function to an initial element (seed).
   - Java 8: 'Stream.iterate(T seed, UnaryOperator<T> f)' (Unbounded; requires .limit()).
   - Java 9: 'Stream.iterate(T seed, Predicate<T> hasNext, UnaryOperator<T> next)' (Bounded iteration).

2. STREAM.GENERATE():
   - Generates an infinite sequential unordered stream where each element is generated by a 'Supplier<T>'.
   - Signature: 'public static <T> Stream<T> generate(Supplier<T> s)'.
   - Ideal for random numbers, timestamps, UUID generation, constant streams.

3. MANDATORY RULE:
   - Always bound infinite streams using '.limit(n)', '.takeWhile(predicate)', or a finite terminal operation like '.findFirst()'.
