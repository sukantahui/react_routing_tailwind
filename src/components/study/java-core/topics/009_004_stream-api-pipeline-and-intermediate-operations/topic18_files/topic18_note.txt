1. LIMIT(LONG MAXSIZE):
   - Returns a stream consisting of the elements of this stream, truncated to be no longer than 'maxSize' in length.
   - Short-circuiting stateful intermediate operation.
   - Extremely useful for bounding infinite streams ('Stream.iterate().limit(10)').

2. SKIP(LONG N):
   - Returns a stream consisting of the remaining elements of this stream after discarding the first 'n' elements.
   - Stateful intermediate operation.
   - If stream contains fewer than 'n' elements, returns an empty stream.

3. PAGINATION FORMULA:
   - 'stream.skip((pageNumber - 1) * pageSize).limit(pageSize)'
