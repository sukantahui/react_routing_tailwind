1. MAP METHOD CONTRACT:
   - Signature: '<R> Stream<R> map(Function<? super T, ? extends R> mapper)'.
   - Transforms each element of type T into an element of type R.
   - Intermediate & Stateless operation.
   - Preserves stream size: Input Stream of size N &rarr; Output Stream of size N.

2. PRIMITIVE SPECIALIZATIONS OF MAP:
   - 'mapToInt(ToIntFunction)' -> IntStream (unboxed primitive int).
   - 'mapToLong(ToLongFunction)' -> LongStream.
   - 'mapToDouble(ToDoubleFunction)' -> DoubleStream.
   - Use primitive specializations when transforming objects into numbers to avoid boxing!
