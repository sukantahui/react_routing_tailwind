1. RADIX PARSING RULES:
   - 'Integer.parseInt(str, 2)'  → Binary.
   - 'Integer.parseInt(str, 8)'  → Octal.
   - 'Integer.parseInt(str, 16)' → Hexadecimal.
   - 'Integer.parseInt(str, 36)' → Base-36 Alphanumeric.
   - Min Radix = 2, Max Radix = 36.
