1. CACHE SUMMARY ACROSS WRAPPERS:
   - Boolean   : TRUE & FALSE (100% cached).
   - Byte      : -128 to 127 (100% cached).
   - Character : 0 to 127 (ASCII).
   - Short/Int/Long : -128 to 127.
   - Float/Double   : NO CACHING.
