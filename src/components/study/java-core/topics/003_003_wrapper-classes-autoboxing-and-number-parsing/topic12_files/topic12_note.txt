1. NumberFormatException TRIGGERS:
   - Non-digits in string ('"100k"').
   - Decimals passed to parseInt ('"12.5"').
   - Number exceeds 32-bit Integer range (-2^31 to 2^31-1).
   - Unhandled whitespace (fix with '.strip()').
