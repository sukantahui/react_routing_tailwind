1. THE 8 WRAPPERS:
   - byte    &rarr; Byte
   - short   &rarr; Short
   - int     &rarr; Integer
   - long    &rarr; Long
   - float   &rarr; Float
   - double  &rarr; Double
   - char    &rarr; Character
   - boolean &rarr; Boolean
   - All are 'public final class' and immutable.
