1. THE 8 WRAPPERS:
   - byte    → Byte
   - short   → Short
   - int     → Integer
   - long    → Long
   - float   → Float
   - double  → Double
   - char    → Character
   - boolean → Boolean
   - All are 'public final class' and immutable.
