1. INTEGER CACHE RULES:
   - Cache range: '-128' to '127' (inclusive).
   - 'Integer.valueOf(n)' queries the cache first.
   - Within cache: 'a == b' is true.
   - Outside cache: 'a == b' is false (two distinct objects).
   - ALWAYS compare wrapper objects using '.equals()'!
