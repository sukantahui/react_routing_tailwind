1. PARSING METHODS:
   - 'Integer.parseInt(str)'    &rarr; Returns primitive 'int'.
   - 'Double.parseDouble(str)'  &rarr; Returns primitive 'double'.
   - 'Boolean.parseBoolean(str)'&rarr; Returns 'true' (case-insensitive) or 'false'.
   - 'Integer.valueOf(str)'     &rarr; Returns cached 'Integer' object.
