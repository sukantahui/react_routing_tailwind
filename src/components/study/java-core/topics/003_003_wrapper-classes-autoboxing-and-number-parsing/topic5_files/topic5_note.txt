1. BYTECODE TRANSLATION RULES:
   - Boxing   : Translated to 'Integer.valueOf(primitive)'.
   - Unboxing : Translated to 'wrapper.intValue()'.
   - 'obj++'  : 'obj = Integer.valueOf(obj.intValue() + 1)'.
