1. FORBIDDEN ABSTRACT METHOD COMBINATIONS:
   - 'private abstract': Child cannot see private methods.
   - 'static abstract': Static methods cannot be dynamically overridden.
   - 'final abstract': Final forbids overriding.
   - 'synchronized abstract' / 'native abstract': Forbidden modifiers on abstract declarations.
