1. INSTANTIATION RULES:
   - 'new AbstractClass()' → COMPILE ERROR ("cannot be instantiated").
   - Can declare reference variables: 'AbstractClass ref;' (100% legal).
   - Only concrete child subclasses that implement all abstract methods can be instantiated.
