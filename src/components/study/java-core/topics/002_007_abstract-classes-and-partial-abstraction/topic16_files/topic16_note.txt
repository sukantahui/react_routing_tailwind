1. MODULE 002_007 SUMMARY:
   - Abstraction hides complexity and establishes blueprints.
   - Abstract classes cannot use 'new'; must be extended.
   - Abstract methods have no bodies; must be overridden.
   - Partial abstraction combines shared concrete logic with abstract contracts.
   - Cannot combine: 'abstract' with 'final', 'private', or 'static'.
   - Template Method pattern locks algorithm workflow in base class.
