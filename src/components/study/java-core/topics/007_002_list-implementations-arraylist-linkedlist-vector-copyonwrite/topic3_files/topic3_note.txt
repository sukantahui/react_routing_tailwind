1. EXPANSION MECHANICS:
   - Triggered when 'size == data.length'.
   - Allocates new array with 'newCapacity'.
   - 'Arrays.copyOf()' delegates to 'System.arraycopy()'.
   - Native intrinsic uses SIMD/memmove for parallel memory copy.
