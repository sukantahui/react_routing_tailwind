1. LIST ITERATOR ESSENTIALS:
   - Bidirectional navigation: 'next()' / 'previous()'.
   - Index introspection: 'nextIndex()' / 'previousIndex()'.
   - In-place mutation: 'set(E)' replaces element, 'add(E)' inserts.
   - Initialized at any index: 'list.listIterator(size)'.
