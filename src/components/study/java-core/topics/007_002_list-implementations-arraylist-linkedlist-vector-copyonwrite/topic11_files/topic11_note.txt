1. LEGACY CLASSES:
   - 'Vector': Java 1.0 synchronized array list (slow lock overhead).
   - 'Stack': flawed inheritance extending Vector; exposes 'add(index)'.
   - Modern replacement for Vector: 'ArrayList' or 'CopyOnWriteArrayList'.
   - Modern replacement for Stack: 'ArrayDeque'.
