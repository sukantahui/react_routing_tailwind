1. ARRAYLIST TUNING:
   - Constructor: 'new ArrayList<>(expectedSize)'.
   - 'ensureCapacity(n)': pre-allocates capacity in 1 shot, eliminates resizes.
   - 'trimToSize()': shrinks backing array to match exact 'size'.
   - Essential for large datasets and long-lived memory caches.
