1. WHY ARRAYLIST WINS:
   - Zero per-element Node object allocations.
   - Low GC pressure and memory footprint.
   - CPU Cache Line spatial locality prefetching.
   - For Queue/Deque workloads: Prefer 'ArrayDeque' over LinkedList.
