1. BIG-O TIME COMPLEXITY:
   - get(i) / set(i, val) → O(1) instant pointer arithmetic.
   - add(tail) → O(1) amortized.
   - add(0, val) / remove(0) → O(n) due to arraycopy shifts.
   - contains(obj) → O(n) linear scan.
