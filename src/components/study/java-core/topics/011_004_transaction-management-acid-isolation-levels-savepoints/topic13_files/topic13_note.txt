1. WHAT IS A DIRTY READ:
   - Occurs when Transaction A reads data modified by concurrent Transaction B that has NOT yet committed.
   - If Transaction B performs a ROLLBACK, the data read by Transaction A becomes invalid 'dirty' data.

2. PREVENTION:
   - Enforced by 'Connection.TRANSACTION_READ_COMMITTED' and above.
