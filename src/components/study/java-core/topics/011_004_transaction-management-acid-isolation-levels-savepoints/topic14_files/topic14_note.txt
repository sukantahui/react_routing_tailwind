1. WHAT IS A NON-REPEATABLE READ (Fuzzy Read):
   - Occurs when Transaction A reads a row, and a concurrent Transaction B modifies that row and commits.
   - When Transaction A reads the row a second time, it observes the newly committed changes,
     producing inconsistent data within a single transaction.

2. PREVENTION:
   - Enforced by 'Connection.TRANSACTION_REPEATABLE_READ' and 'Connection.TRANSACTION_SERIALIZABLE'.
