1. CORE GUARANTEE:
   - A query only reads data that was committed before the query began.
   - Prevents Dirty Reads completely.

2. STATEMENT SNAPSHOT VS TRANSACTION SNAPSHOT:
   - In READ COMMITTED, each SELECT statement within the transaction takes a fresh snapshot of data!
