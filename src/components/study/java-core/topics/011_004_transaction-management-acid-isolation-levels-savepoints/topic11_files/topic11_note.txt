1. WHAT IS A SAVEPOINT:
   - A bookmark/checkpoint within an active transaction.
   - Allows rolling back a portion of the transaction without aborting the entire unit of work.

2. LIFECYCLE:
   - 'conn.setSavepoint()' / 'conn.setSavepoint(String name)'
   - 'conn.rollback(Savepoint sp)'
   - 'conn.releaseSavepoint(Savepoint sp)'
   - All savepoints are automatically released when the transaction commits or completely rolls back.
