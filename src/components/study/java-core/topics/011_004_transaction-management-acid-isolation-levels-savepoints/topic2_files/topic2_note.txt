1. WHAT IS ATOMICITY:
   - Guarantees that all statements within a transaction are treated as a single composite operation.
   - If any statement fails, the entire transaction is aborted and rolled back.

2. JDBC ATOMIC WORKFLOW:
   - 'conn.setAutoCommit(false)'
   - Execute all DML statements.
   - 'conn.commit()' in try block.
   - 'conn.rollback()' in catch block.
