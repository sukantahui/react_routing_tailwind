1. CHARACTERISTICS:
   - Lowest level of isolation.
   - Transactions can see uncommitted data changes made by other concurrent transactions.
   - Zero shared lock contention.

2. VULNERABILITIES:
   - Suffers Dirty Reads, Non-Repeatable Reads, and Phantom Reads.
