1. WHAT SERIALIZABLE GUARANTEES:
   - Eliminates all Dirty Reads, Non-Repeatable Reads, and Phantom Reads.
   - Highest consistency, lowest concurrent throughput.

2. RETRY OBLIGATION:
   - Applications running on SERIALIZABLE must catch SQLState '40001' serialization errors
     and automatically retry the transaction.
