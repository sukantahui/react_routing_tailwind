1. THE TRANSACTION LIFECYCLE:
   - 'conn.setAutoCommit(false)' marks the start of a manual transaction.
   - 'conn.commit()' flushes all updates executed since the transaction started to disk.
   - 'conn.rollback()' discards all updates and releases row locks.

2. CONNECTION POOL HYGIENE:
   - Always restore 'conn.setAutoCommit(true)' or allow the connection pool to reset state.
