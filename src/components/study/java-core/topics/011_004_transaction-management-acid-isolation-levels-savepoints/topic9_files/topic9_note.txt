1. WHAT 'rollback()' DOES:
   - Undoes all changes made in the current transaction.
   - Releases any database locks currently held by the Connection.

2. CATCH BLOCK BEST PRACTICE:
   - Catch BOTH 'SQLException' AND 'RuntimeException' (or 'Exception') to ensure rollback executes
     even on unexpected runtime logic errors (e.g. 'NullPointerException')!
