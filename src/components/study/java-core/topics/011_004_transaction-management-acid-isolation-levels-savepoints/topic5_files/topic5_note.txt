1. WHAT IS DURABILITY:
   - Guarantees that once a transaction has committed, it will remain committed even in the event
     of a system crash, power outage, or OS failure.

2. KEY MECHANISMS:
   - Write-Ahead Logging (WAL in PostgreSQL / Redo Log in MySQL InnoDB / Oracle).
   - Checkpointing (flushing dirty RAM pages to disk periodically).
   - RAID non-volatile disk storage & replication.
