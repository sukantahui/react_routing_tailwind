1. WHAT IS ISOLATION:
   - Controls how changes made by one transaction are visible to other concurrent transactions.
   - Configured in JDBC via 'conn.setTransactionIsolation(level)'.

2. MVCC (Multi-Version Concurrency Control):
   - The modern standard in PostgreSQL, MySQL InnoDB, and Oracle.
   - Provides snapshot isolation without heavy table or row read-locking.
