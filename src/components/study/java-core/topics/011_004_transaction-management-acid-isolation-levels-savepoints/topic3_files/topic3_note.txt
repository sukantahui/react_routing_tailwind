1. WHAT IS CONSISTENCY:
   - Ensures that only valid data following all rules and constraints is written to the database.
   - If an operation would leave the database in an illegal state, the entire transaction is rejected.

2. SHARED RESPONSIBILITY:
   - Database enforces structural constraints (PK, FK, Unique, Check).
   - Java application enforces complex business invariants.
