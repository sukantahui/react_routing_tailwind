1. TRANSACTION-LEVEL SNAPSHOT:
   - Re-reading the same row multiple times within the transaction is guaranteed to return identical data.
   - Prevents Dirty Reads and Non-Repeatable Reads.

2. DEFAULT IN MYSQL INNODB:
   - MySQL uses 'REPEATABLE READ' as its default isolation level.
