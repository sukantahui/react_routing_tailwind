1. ACID BREAKDOWN:
   - A (Atomicity)   : No partial transactions.
   - C (Consistency) : Data transitions from one valid state to another valid state.
   - I (Isolation)   : Transactions do not leak intermediate dirty state to others.
   - D (Durability)  : Once committed, data is written to non-volatile storage.
