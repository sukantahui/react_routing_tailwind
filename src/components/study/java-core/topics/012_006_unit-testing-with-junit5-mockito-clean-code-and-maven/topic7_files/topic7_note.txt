1. MOCKITO ANNOTATIONS:
   - '@ExtendWith(MockitoExtension.class)' : Enables JUnit 5 Mockito lifecycle integration.
   - '@Mock'         : Creates a mock instance.
   - '@InjectMocks'  : Creates instance of class under test and injects '@Mock' / '@Spy' fields.
   - 'MockitoAnnotations.openMocks(this)' : Programmatic alternative to extension.
