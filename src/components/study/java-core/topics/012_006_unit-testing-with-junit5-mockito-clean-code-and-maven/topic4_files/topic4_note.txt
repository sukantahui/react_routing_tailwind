1. DATA SOURCE ANNOTATIONS:
   - '@ValueSource(ints = {...}, strings = {...})' : Simple primitive/String array.
   - '@CsvSource({"1, 2, 3", "10, 20, 30"})'  : Comma-separated values mapped to params.
   - '@MethodSource("provideData")'             : Stream/Collection provider method.
   - '@EnumSource(ChronoUnit.class)'             : Runs test for all enum constants.
