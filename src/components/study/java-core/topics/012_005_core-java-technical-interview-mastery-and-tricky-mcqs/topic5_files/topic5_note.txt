1. FINALLY EXECUTION GUARANTEES:
   - 'finally' block executes regardless of normal completion or exception throwing.
   - If 'finally' contains a 'return', it overwrites previous 'return' statements.
   - If an exception was thrown in 'try', a 'finally' return discards the exception!
   - Anti-Pattern: Never place 'return' or 'throw' inside a finally block.
