1. IEEE 754 FLOATING POINT SPECIFICATION:
   - 'NaN == NaN' is ALWAYS false by IEEE 754 definition.
   - Use 'Double.isNaN(val)' to verify NaN.
   - Floating point division by zero does NOT throw 'ArithmeticException'; it returns 'Infinity' or 'NaN'.
   - 'Double.equals()' distinguishes between '-0.0' and '+0.0' for HashMap consistency.
