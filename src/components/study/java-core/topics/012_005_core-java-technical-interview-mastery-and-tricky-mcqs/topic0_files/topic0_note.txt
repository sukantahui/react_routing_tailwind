1. EVALUATION RULES:
   - Evaluates strictly left-to-right.
   - If both operands are numbers: '+' performs arithmetic addition.
   - If either operand is a String: '+' performs string concatenation.
   - 'char + char' performs numeric integer addition of ASCII/Unicode values!
