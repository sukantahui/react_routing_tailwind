1. INTEGER CACHE (Flyweight Pattern):
   - 'IntegerCache' caches instances from -128 to 127 (high bound configurable via '-XX:AutoBoxCacheMax=<size>').
   - Autoboxing ('Integer i = 100') invokes 'Integer.valueOf(100)'.
   - Outside [-128, 127], 'valueOf()' calls 'new Integer()', returning distinct references.
   - ALWAYS use '.equals()' for wrapper class equality!
