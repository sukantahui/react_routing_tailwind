1. HASHCODE & EQUALS CONTRACT:
   - If 'a.equals(b)' is true, 'a.hashCode() == b.hashCode()' MUST be true.
   - If two objects have the same hashCode (collision), they do NOT have to be equal.
   - Keys must ideally be immutable (e.g. String, Integer, Records).
