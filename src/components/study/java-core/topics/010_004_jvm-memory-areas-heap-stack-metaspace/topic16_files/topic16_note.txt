1. JVM MEMORY ERROR TRIAGE GUIDE:
   1. 'java.lang.OutOfMemoryError: Java heap space'
      - Objects cannot be allocated on Heap despite Full GC.
      - Diagnostic Tool: Capture dump with '-XX:+HeapDumpOnOutOfMemoryError'.
   2. 'java.lang.OutOfMemoryError: Metaspace'
      - Native metadata limit reached due to classloader leakage.
      - Diagnostic Tool: 'jcmd <pid> GC.class_stats' / VisualVM.
   3. 'java.lang.StackOverflowError'
      - Thread stack frame capacity exceeded by recursive calls.
