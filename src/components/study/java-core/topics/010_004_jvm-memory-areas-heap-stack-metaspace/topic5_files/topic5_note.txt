1. WHAT IS THE NATIVE METHOD STACK:
   - Dedicated thread-private memory stack supporting execution of native methods
     (methods declared with the 'native' keyword and implemented in C/C++).

2. ERROR CONDITIONS:
   - 'StackOverflowError' : If native method recursion exceeds native stack bounds.
   - 'OutOfMemoryError'   : If native memory cannot be allocated for new native threads.
