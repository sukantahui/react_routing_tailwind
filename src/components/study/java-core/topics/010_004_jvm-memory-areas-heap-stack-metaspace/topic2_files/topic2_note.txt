1. CHARACTERISTICS OF THE HEAP:
   - Created when the JVM starts up and shared among all active threads.
   - Stores all class instances, records, strings, and arrays.
   - Objects are NEVER explicitly freed by code; the Garbage Collector reclaims unreferenced objects.

2. PRODUCTION TUNING FLAGS:
   - '-Xms<size>' : Sets initial heap size.
   - '-Xmx<size>' : Sets maximum heap size.
   - Production Tip: Setting '-Xms == -Xmx' eliminates runtime heap resizing pauses.
