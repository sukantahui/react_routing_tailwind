1. JMH FUNDAMENTALS:
   - Built by OpenJDK engineers for scientific Java benchmarking.
   - Warmup iterations: allows JIT C1/C2 compiler stabilization.
   - Blackhole: prevents JIT dead-code elimination optimizations.
   - Modes: Throughput (ops/sec) vs AverageTime (time/op).
   - Never benchmark Java code with simple System.currentTimeMillis() loops!
