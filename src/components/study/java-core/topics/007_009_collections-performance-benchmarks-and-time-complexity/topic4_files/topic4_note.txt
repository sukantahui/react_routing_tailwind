1. PRIMITIVE vs BOXED PERFORMANCE:
   - int[] stores raw bits; ArrayList<Integer> stores references.
   - 64-byte CPU cache line holds 16 consecutive primitive ints.
   - ArrayList requires pointer dereference + auto-unboxing.
   - Primitive arrays are 5x-10x faster for intensive math/data processing.
