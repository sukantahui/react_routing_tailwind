1. THE 11 CORE COLLECTIONS:
   - Lists: ArrayList (dynamic array), LinkedList (doubly linked).
   - Queues: ArrayDeque (circular buffer), PriorityQueue (binary heap).
   - Sets: HashSet (hash table), LinkedHashSet (linked hash), TreeSet (Red-Black tree).
   - Maps: HashMap (hash table), LinkedHashMap (LRU/insertion), TreeMap (sorted tree).
   - Concurrent: ConcurrentHashMap (CAS + bucket locks).
