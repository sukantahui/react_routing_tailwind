1. ENTERPRISE MODELING SUMMARY:
   - Use IS-A when true subtyping polymorphism is required (Manager IS-A Employee).
   - Use HAS-A for data parts and modular services (Employee HAS-A Address).
   - Keep inheritance hierarchies shallow and favor composition.
