1. FRAGILE BASE CLASS VULNERABILITY:
   - Subclasses are tightly coupled to superclass internal implementations.
   - Changes in superclass logic cause silent runtime bugs in child classes.
   - Solution: Use Composition with Forwarding (Decorator / Wrapper pattern).
