1. INHERITANCE VISIBILITY MATRIX:
   - public & protected: ALWAYS inherited and directly accessible.
   - default (package-private): Inherited ONLY if subclass is in same package.
   - private: NOT directly accessible by name (must use public getters).
   - constructors: NEVER inherited (must be invoked via super()).
