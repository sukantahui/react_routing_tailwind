1. WHY FAVOR COMPOSITION:
   - Dynamic Runtime Polymorphism: Can swap internal strategies on the fly.
   - Encapsulation Protection: Superclass changes do not break child code.
   - Loose Coupling: Classes depend on interfaces, not rigid concrete hierarchies.
