1. RELATIONSHIP MODELING:
   - IS-A: Modeled using 'extends' / 'implements' (Inheritance).
   - HAS-A: Modeled using instance variable references (Association).
   - Rule of Thumb: If X is a type of Y, use IS-A. If X contains Y, use HAS-A.
