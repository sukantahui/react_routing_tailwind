1. SUPPORTED CLASS INHERITANCE FORMS:
   - Single Inheritance: 1 Parent -> 1 Child
   - Multilevel Inheritance: Grandparent -> Parent -> Child
   - Hierarchical Inheritance: 1 Parent -> Multiple Child classes

2. UNSUPPORTED FORMS (WITH CLASSES):
   - Multiple Inheritance (Multiple parents -> 1 Child)
   - Hybrid Inheritance involving multiple parents
