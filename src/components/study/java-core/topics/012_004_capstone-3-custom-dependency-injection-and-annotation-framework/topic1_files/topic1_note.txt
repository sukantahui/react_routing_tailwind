1. ANNOTATION TARGETS:
   - 'ElementType.TYPE'        : For class definitions (@Component, @Service).
   - 'ElementType.FIELD'       : For field injection (@Autowired, @Value).
   - 'ElementType.METHOD'      : For method interception (@Transactional).

2. RETENTION POLICY:
   - Must strictly be 'RetentionPolicy.RUNTIME' for reflection inspection.
