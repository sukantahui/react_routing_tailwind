1. MINIMIZING LOCK SCOPE:
   - Rule: Hold locks for the absolute shortest duration possible.
   - Do expensive tasks (JSON parsing, DB I/O, crypto) OUTSIDE the lock.
   - Enter 'synchronized' only to update shared memory.
   - Low lock contention = maximum multi-core CPU utilization.
