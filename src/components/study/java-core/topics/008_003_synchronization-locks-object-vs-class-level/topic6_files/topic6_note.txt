1. SYNCHRONIZED BLOCKS:
   - Syntax: 'synchronized(lockTarget) { /* critical section */ }'.
   - Lock target can be 'this', 'ClassName.class', or a private Object.
   - Fine-grained lock scope &rarr; higher concurrency throughput.
   - Use multiple lock objects for independent state variables.
