1. LOCK REENTRANCY:
   - Java intrinsic locks ('synchronized') and 'ReentrantLock' are REENTRANT.
   - Locks are per-THREAD, not per-method.
   - JVM maintains an internal recursion counter ('hold count').
   - Same thread can re-enter nested synchronized blocks without blocking.
   - Prevents self-deadlocks in OOP inheritance hierarchies.
