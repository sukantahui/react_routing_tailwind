1. RACE CONDITIONS:
   - Occur when 2+ threads access shared mutable state without synchronization.
   - 'counter++' is NOT atomic (Read → Modify → Write).
   - Lost Update Anomaly: Multiple increments overwrite each other.
   - Solution: Synchronization (locks) or Atomic variables (AtomicInteger).
