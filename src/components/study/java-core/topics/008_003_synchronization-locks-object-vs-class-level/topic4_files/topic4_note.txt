1. SYNCHRONIZED INSTANCE METHODS:
   - Declared with 'public synchronized void method()'.
   - Acquires intrinsic lock of 'this' object instance.
   - Other threads calling synchronized methods on SAME object are BLOCKED.
   - Threads calling synchronized methods on DIFFERENT instances run concurrently.
