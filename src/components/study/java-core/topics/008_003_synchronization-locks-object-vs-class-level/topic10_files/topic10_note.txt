1. PRIVATE FINAL LOCK IDIOM:
   - 'private final Object lock = new Object();'.
   - 'private': Encapsulates lock; prevents external Denial-of-Service lock hijacking.
   - 'final': Guarantees lock reference never changes.
   - Replaces 'synchronized(this)' in robust library and enterprise code.
