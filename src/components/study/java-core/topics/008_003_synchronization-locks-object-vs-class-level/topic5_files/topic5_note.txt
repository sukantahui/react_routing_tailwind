1. SYNCHRONIZED STATIC METHODS:
   - Declared with 'public static synchronized void method()'.
   - Acquires the Class-level lock ('ClassName.class').
   - Locks globally across ALL instances of the class.
   - Protects shared static variables across all threads.
   - Independent from instance-level locks ('this').
