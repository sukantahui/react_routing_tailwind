1. INTRINSIC MONITOR LOCKS:
   - Attached to EVERY Java object in heap memory.
   - Encoded in the Object Header's 8-byte Mark Word.
   - Lock inflation: Biased &rarr; Lightweight (CAS) &rarr; Heavyweight (OS Mutex).
   - Bytecode instructions: 'monitorenter' and 'monitorexit'.
   - Exception safety guaranteed by JVM exception tables.
