1. OBJECT vs CLASS LOCK:
   - Object-Level Lock: 'synchronized void foo()' locks 'this' instance.
   - Class-Level Lock: 'static synchronized void bar()' locks 'ClassName.class'.
   - Two distinct locks in memory!
   - Thread A on 'this' and Thread B on 'Class.class' run SIMULTANEOUSLY.
   - A static synchronized method NEVER blocks an instance synchronized method.
