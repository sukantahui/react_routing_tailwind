1. CRITICAL SECTION:
   - Code block accessing shared mutable resources.
   - Must be executed with Mutual Exclusion (Mutex).
   - Dijkstra's 3 rules: Mutual Exclusion, Progress, Bounded Waiting.
   - Java enforces this via 'synchronized' blocks and explicit locks.
