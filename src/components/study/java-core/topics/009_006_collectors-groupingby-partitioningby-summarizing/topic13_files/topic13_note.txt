1. WHAT IS PARTITIONING:
   - A special case of 'groupingBy' where the classifier is a 'Predicate<T>'.
   - The resulting Map is ALWAYS typed as 'Map<Boolean, D>'.
   - Both 'true' and 'false' keys are ALWAYS guaranteed to be present in the resulting Map,
     even if one of the partitions has 0 elements.

2. OVERLOADS:
   - 'partitioningBy(Predicate<? super T> predicate)' → Map<Boolean, List<T>>
   - 'partitioningBy(Predicate<? super T> predicate, Collector downstream)' → Map<Boolean, D>
