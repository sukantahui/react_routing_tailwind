1. SUMMARIZATION COLLECTORS SUITE:
   - Counting: 'Collectors.counting()' → Collector<T, ?, Long>.
   - Summing:
     * 'Collectors.summingInt(ToIntFunction)'
     * 'Collectors.summingLong(ToLongFunction)'
     * 'Collectors.summingDouble(ToDoubleFunction)'
   - Averaging:
     * 'Collectors.averagingInt(ToIntFunction)'
     * 'Collectors.averagingLong(ToLongFunction)'
     * 'Collectors.averagingDouble(ToDoubleFunction)'
   - Complete Statistics:
     * 'Collectors.summarizingInt(ToIntFunction)' → IntSummaryStatistics
     * 'Collectors.summarizingLong(ToLongFunction)' → LongSummaryStatistics
     * 'Collectors.summarizingDouble(ToDoubleFunction)' → DoubleSummaryStatistics
