1. COLLECTOR.OF() CONVENIENCE FACTORY:
   - 'Collector.of(supplier, accumulator, combiner, finisher, characteristics...)'
   - Eliminates need to write anonymous inner classes implementing the 'Collector' interface.

2. WHEN TO IMPLEMENT CUSTOM COLLECTORS:
   - Collecting into custom proprietary domain data structures.
   - Performing specialized encryption/compression during reduction.
   - Post-sorting and returning immutable views in a single pass.
