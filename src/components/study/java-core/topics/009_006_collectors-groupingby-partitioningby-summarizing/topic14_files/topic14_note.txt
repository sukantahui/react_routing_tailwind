1. METHOD SIGNATURE:
   - '<T, A, R, RR> Collector<T, A, RR> collectingAndThen(Collector<T, A, R> downstream, Function<R, RR> finisher)'

2. HOW IT WORKS:
   - Executes the 'downstream' collector normally to produce intermediate result 'R'.
   - Passes 'R' to the 'finisher' function to transform it into final result 'RR'.

3. COMMON APPLICATIONS:
   - Creating unmodifiable collections ('Collections::unmodifiableList', 'Set::copyOf').
   - Unwrapping Optional from 'maxBy' / 'minBy' ('Optional::orElseThrow').
   - Converting domain aggregates to customized DTO wrappers.
