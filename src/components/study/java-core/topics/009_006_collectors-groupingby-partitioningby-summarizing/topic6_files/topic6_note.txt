1. CLASSIFIER FUNCTION FLEXIBILITY:
   - The classifier function 'Function<? super T, ? extends K>' maps an element to its grouping key.
   - Types of Classifiers:
     1. Property Extractor: 'Student::getCenter' -> Groups by center.
     2. Computed Classification: 's -> s.getScore() >= 85 ? "A" : "B"' -> Groups by conditional tier.
     3. Compound Key Object: 's -> new CenterCourseKey(s.getCenter(), s.getCourse())'.
