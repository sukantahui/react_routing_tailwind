1. MAXBY & MINBY COLLECTORS:
   - 'Collectors.maxBy(Comparator<? super T> comp)' → Collector<T, ?, Optional<T>>.
   - 'Collectors.minBy(Comparator<? super T> comp)' → Collector<T, ?, Optional<T>>.

2. UNWRAPPING OPTIONAL PATTERN:
   - By default, 'groupingBy(k, maxBy(comp))' returns 'Map<K, Optional<T>>'.
   - To unwrap the Optional into 'Map<K, T>', wrap with 'collectingAndThen()':
     * 'Collectors.collectingAndThen(Collectors.maxBy(comp), Optional::orElseThrow)'
