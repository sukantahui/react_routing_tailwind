1. CORE STANDARD COLLECTORS:
   - 'Collectors.toList()': Returns a List (implementation usually ArrayList; mutable).
   - 'Collectors.toSet()': Returns a Set (implementation usually HashSet; unordered, distinct).
   - 'Collectors.toCollection(Supplier<C> factory)': Collects into any custom Collection
     (e.g. 'TreeSet::new', 'LinkedList::new', 'ArrayDeque::new', 'CopyOnWriteArrayList::new').

2. UNMODIFIABLE COLLECTORS:
   - 'Collectors.toUnmodifiableList()' (Java 10+): Returns an immutable list (throws UnsupportedOperationException on add/remove).
   - 'Collectors.toUnmodifiableSet()' (Java 10+).
   - 'Stream.toList()' (Java 16+): Direct syntax shortcut returning an unmodifiable list.
