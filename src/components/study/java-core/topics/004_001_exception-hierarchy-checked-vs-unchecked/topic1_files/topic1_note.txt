1. HIERARCHY BREAKDOWN:
   - 'Object' → 'Throwable' (Root).
   - Branch A: 'Error' (JVM hardware/RAM failure - unrecoverable).
   - Branch B: 'Exception' (Application conditions - recoverable).
     - Checked: Subclasses of Exception (compile-time enforced).
     - Unchecked: Subclasses of RuntimeException.
