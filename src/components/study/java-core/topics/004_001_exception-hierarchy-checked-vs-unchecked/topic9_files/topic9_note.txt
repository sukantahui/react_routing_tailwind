1. STANDARD EXCEPTIONS SUMMARY:
   - 'NPE'              : Invocation on null pointer.
   - 'ClassCastException': Incompatible downcasting.
   - 'IllegalArgument'  : Method argument validation failure.
   - 'IllegalState'     : Object state lifecycle violation.
   - 'NumberFormat'     : Integer.parseInt("abc") failure.
