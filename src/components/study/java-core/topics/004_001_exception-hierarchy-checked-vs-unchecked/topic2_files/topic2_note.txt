1. ERROR CHARACTERISTICS:
   - Subclass of 'Throwable'.
   - Unchecked by compiler.
   - Indicates serious JVM/hardware issues (RAM, stack).
   - Examples: 'OutOfMemoryError', 'StackOverflowError', 'NoClassDefFoundError'.
   - NEVER catch Error in production code.
