1. DESIGN DECISION MATRIX:
   - Can caller recover? → Use CHECKED ('extends Exception').
   - Is it a bug / bad argument? → Use UNCHECKED ('extends RuntimeException').
   - Precondition checks → 'IllegalArgumentException', 'IllegalStateException'.
