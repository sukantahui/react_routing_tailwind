1. DESIGN DECISION MATRIX:
   - Can caller recover? &rarr; Use CHECKED ('extends Exception').
   - Is it a bug / bad argument? &rarr; Use UNCHECKED ('extends RuntimeException').
   - Precondition checks &rarr; 'IllegalArgumentException', 'IllegalStateException'.
