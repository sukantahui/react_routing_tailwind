1. RETURN CODE FLAWS:
   - Callers can forget to check return codes.
   - Return value conflation (is -1 an error or a valid answer?).
   - Clutters business logic with nested if-else checks.

2. STRUCTURED EXCEPTION ADVANTAGES:
   - Clean separation via try-catch.
   - Cannot be ignored.
   - Rich stack trace diagnostics.
