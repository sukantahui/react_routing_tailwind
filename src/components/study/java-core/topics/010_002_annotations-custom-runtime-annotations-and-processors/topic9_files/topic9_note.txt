1. THE 'VALUE()' SINGLE-ELEMENT SHORTCUT:
   - If an annotation has an element named 'value()', and it is the ONLY element being specified,
     the attribute name can be omitted:
     '@SecurityRole("ADMIN")' is identical to '@SecurityRole(value="ADMIN")'.

2. DEFAULT VALUES:
   - Specified via the 'default' keyword: 'String center() default "Barrackpore";'.
   - Elements with defaults are OPTIONAL when declaring the annotation.
   - Elements without defaults are MANDATORY.
