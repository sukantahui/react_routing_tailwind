1. THE 3 RETENTION POLICIES ('java.lang.annotation.RetentionPolicy'):
   -----------------------------------------------------------------------------
   POLICY             STORED IN .CLASS?   LOADED BY JVM?   VISIBLE VIA REFLECTION?
   -----------------------------------------------------------------------------
   SOURCE             NO (Erased by javac) NO              NO
   CLASS (Default)    YES                 NO (Dropped by VM) NO
   RUNTIME            YES                 YES              YES
   -----------------------------------------------------------------------------

2. DEFAULT POLICY:
   - If '@Retention' is not specified on a custom annotation, it defaults to 'RetentionPolicy.CLASS'.
   - Common Pitfall: Forgetting '@Retention(RetentionPolicy.RUNTIME)' causes 'clazz.getAnnotation()'
     to return 'null' at runtime!
