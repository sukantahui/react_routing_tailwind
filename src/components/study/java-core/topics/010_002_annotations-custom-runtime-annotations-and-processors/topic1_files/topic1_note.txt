1. CORE BUILT-IN ANNOTATIONS IN 'java.lang':
   - '@Override'
     * Informs compiler that method must override superclass or interface method.
     * Prevents subtle typo bugs (e.g. 'hashcode()' vs 'hashCode()').
   - '@Deprecated(since="17", forRemoval=true)'
     * Signals element is outdated. 'forRemoval=true' indicates imminent deletion.
   - '@SuppressWarnings({"unchecked", "deprecation", "rawtypes"})'
     * Instructs compiler to ignore specific named warnings.
   - '@FunctionalInterface'
     * Validates interface has exactly ONE abstract method.
   - '@SafeVarargs'
     * Suppresses heap pollution warnings on generic varargs methods/constructors.
