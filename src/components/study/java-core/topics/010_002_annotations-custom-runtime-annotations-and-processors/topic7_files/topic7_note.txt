1. WHAT @REPEATABLE DOES (Java 8+):
   - Allows an annotation type to be applied more than once to the same declaration.
   - Eliminates clunky container wrapping syntax (e.g. '@Filters({@Filter, @Filter})').

2. THE TWO REQUIRED STEPS:
   1. Define Container Annotation with a 'value()' method returning an array:
      'public @interface Schedules { Schedule[] value(); }'
   2. Annotate the repeated annotation with '@Repeatable(Schedules.class)'.

3. REFLECTION EXTRACTION METHOD:
   - Use 'element.getAnnotationsByType(Schedule.class)' to extract the array directly.
