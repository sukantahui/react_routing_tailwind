1. LOCK CONTENTION BOTTLENECK:
   - Coarse-grained global mutex locks the entire map.
   - Multiple threads accessing different buckets block each other.
   - Reads block reads; writes block writes.
   - Multi-core scalability collapses under high concurrency.
   - Obsolete in modern Java &rarr; use 'ConcurrentHashMap'.
