1. MODERN JAVA 8+ CONCURRENTHASHMAP:
   - Eliminates Segment objects.
   - Empty bucket → lock-free CAS ('casTabAt').
   - Occupied bucket → 'synchronized(headNode)'.
   - Maximum concurrency: number of concurrent writes = number of buckets!
   - Converts bucket to TreeBin at 8 nodes.
