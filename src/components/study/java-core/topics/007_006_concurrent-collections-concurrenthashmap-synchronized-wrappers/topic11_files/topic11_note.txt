1. COPYONWRITEARRAYSET:
   - Backed by 'CopyOnWriteArrayList'.
   - Uniqueness enforced via 'addIfAbsent()'.
   - Lock-free reads and snapshot iterators.
   - Writes clone the entire backing array.
   - Ideal for event listeners and read-heavy config sets.
