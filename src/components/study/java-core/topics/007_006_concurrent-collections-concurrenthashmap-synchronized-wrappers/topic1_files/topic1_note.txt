1. SYNCHRONIZED WRAPPERS:
   - 'Collections.synchronizedMap(map)'.
   - 'Collections.synchronizedList(list)'.
   - Uses Decorator pattern with coarse-grained 'mutex' lock.
   - Individual methods are thread-safe.
   - MANDATORY: Wrap iterations in 'synchronized(map) { ... }' blocks!
