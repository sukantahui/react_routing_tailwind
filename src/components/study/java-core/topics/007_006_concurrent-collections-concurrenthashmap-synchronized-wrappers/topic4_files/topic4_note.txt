1. JAVA 7 SEGMENT LOCKING:
   - 'Segment<K,V>[] segments' (Default 16).
   - Each Segment extends 'ReentrantLock'.
   - Allowed 16 concurrent write threads.
   - High memory bloat (16 tables allocated).
   - Replaced in Java 8 with fine-grained per-bucket CAS & synchronization.
