1. ATOMIC OPERATIONS:
   - 'putIfAbsent(k, v)': atomically puts only if absent.
   - 'replace(k, oldVal, newVal)': atomic CAS replace.
   - 'remove(k, val)': removes only if currently mapped to val.
   - 'computeIfAbsent(k, k -> compute())': atomic lazy creation.
   - Eliminates Check-Then-Act race conditions.
