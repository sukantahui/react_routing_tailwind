1. NULL PROHIBITION:
   - 'put(null, v)' → throws NullPointerException.
   - 'put(k, null)' → throws NullPointerException.
   - Eliminates 'get(k) == null' ambiguity in multithreading.
   - Prevents race conditions between 'get()' and 'containsKey()'.
   - Shared rule across all JSR-166 concurrent queues and maps.
