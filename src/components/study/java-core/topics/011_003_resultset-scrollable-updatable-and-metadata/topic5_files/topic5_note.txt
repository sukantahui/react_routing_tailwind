1. CHARACTERISTICS:
   - Cursor moves exclusively forward with 'rs.next()'.
   - 'rs.previous()', 'rs.first()', 'rs.last()', and 'rs.absolute()' are unsupported.

2. STREAMING MYSQL / POSTGRESQL TRICK:
   - In MySQL, set 'statement.setFetchSize(Integer.MIN_VALUE)' to enable true streaming mode without client buffering!
