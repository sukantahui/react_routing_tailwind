1. WHY USE THE ROWMAPPER PATTERN:
   - Eliminates boilerplate repetition of 'rs.getInt()' across DAO methods.
   - Decouples SQL database mechanics from business domain models.

2. COMBINING WITH JAVA RECORDS:
   - Java Records (introduced in Java 16) provide compact, immutable, thread-safe DTO carriers
     for tabular database data.
