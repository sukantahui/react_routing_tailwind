1. WHAT IS DATABASEMETADATA:
   - Comprehensive interface obtained via 'conn.getMetaData()'.
   - Encapsulates database server capabilities, SQL grammar limits, and catalog/schema objects.

2. CORE INTROSPECTION METHODS:
   - 'getTables(catalog, schema, tablePattern, types)'
   - 'getColumns(catalog, schema, tablePattern, colPattern)'
   - 'getPrimaryKeys(catalog, schema, table)'
   - 'getImportedKeys(catalog, schema, table)' (Foreign keys)
