1. WHAT IS RESULTSET:
   - Represents a database result table generated by executing a statement that queries the database.
   - Maintains a cursor pointing to its current row of data.

2. CURSOR POSITION AT START:
   - When newly created, the cursor is positioned BEFORE the first row.
   - The first call to 'rs.next()' moves the cursor to the first row (returns true if a row exists).
