1. WHAT IS 'wasNull()':
   - Method on 'java.sql.ResultSet'.
   - Returns true if the LAST column value read by a getter was SQL NULL, false otherwise.

2. GOLDEN PATTERN FOR NULLABLE PRIMITIVES:
   'int score = rs.getInt("score");
    Integer finalScore = rs.wasNull() ? null : score;'

3. ALTERNATIVE IN MODERN JDBC (getObject with Class):
   'Integer score = rs.getObject("score", Integer.class); // Returns null natively!'
