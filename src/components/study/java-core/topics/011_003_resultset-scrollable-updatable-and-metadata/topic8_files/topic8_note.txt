1. PREREQUISITES FOR CONCUR_UPDATABLE:
   - The SELECT query MUST include the table's Primary Key column (needed to locate the row for UPDATE).
   - The query must select from a single table (no joins or aggregates).

2. WORKFLOW:
   - 'rs.updateXxx(column, value)' &rarr; modifies the buffer.
   - 'rs.updateRow()' &rarr; commits the update to the physical database.
