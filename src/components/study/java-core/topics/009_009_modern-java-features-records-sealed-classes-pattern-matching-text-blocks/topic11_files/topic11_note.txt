1. HOW EXHAUSTIVENESS WORKS:
   - When switching on an enum or a 'sealed' type, the compiler knows the full closed
     set of permitted subclasses.
   - If the 'switch' expression covers every permitted subclass, NO 'default' branch is required.

2. ARCHITECTURAL SAFETY:
   - If a new permitted subclass is added in the future, the compiler generates errors
     at all switch sites across the codebase that fail to cover the new type.
   - Eliminates silent runtime bugs caused by forgotten switch branches.
