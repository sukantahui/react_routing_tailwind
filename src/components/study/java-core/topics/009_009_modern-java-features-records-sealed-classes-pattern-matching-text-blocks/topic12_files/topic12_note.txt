1. WHAT ARE RECORD PATTERNS (Java 21 Standard - JEP 440):
   - Allows deconstructing record instances into their individual constituent components
     directly inside 'instanceof' and 'switch' expressions.
   - Syntax:
     'if (obj instanceof Point(int x, int y)) { /* use x and y directly */ }'

2. NESTED RECORD PATTERNS:
   - Records containing other records can be destructured recursively in a single pattern:
     'if (obj instanceof Order(Customer(String name, Address(String city)), double total))'
