1. WHAT ARE SEALED CLASSES:
   - Introduced in Java 17 (JEP 409).
   - Allows a class or interface to declare which other classes or interfaces may extend
     or implement it.
   - Syntax:
     'public sealed class Shape permits Circle, Rectangle, Triangle {}'

2. CORE MOTIVATION:
   - Bridges the gap between fully open inheritance ('public') and closed ('final').
   - Models closed algebraic data types (ADTs) in object-oriented Java.
