1. PERMITS OMISSION RULE:
   - If all permitted subclasses or implementing records are declared in the SAME compilation
     unit (same .java file), the 'permits' clause can be omitted.
   - The compiler automatically discovers and populates the permitted list.

2. RECORDS AS SEALED IMPLEMENTATIONS:
   - Java Records are implicitly 'final'.
   - Therefore, a record implementing a sealed interface fulfills the modifier requirement
     without needing to declare 'final'.
