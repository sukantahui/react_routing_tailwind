1. SILICON-LEVEL BITWISE ARCHITECTURE
Bitwise operators perform direct binary Boolean logic on individual bits of integral data types (`byte`, `short`, `char`, `int`, `long`). In Java, numeric values are represented in two's complement binary format:
- `&` (Bitwise AND): Sets bit to 1 if both corresponding bits are 1.
- `|` (Bitwise OR): Sets bit to 1 if either corresponding bit is 1.
- `^` (Bitwise XOR): Sets bit to 1 if bits differ (exclusive disjunction).
- `~` (Bitwise Inversion): Flips all binary bits (`~x = -(x + 1)`).

2. BITMASK ENGINEERING PATTERNS
Bitmasking allows encoding up to 32 boolean states in a single 32-bit `int` or 64 states in a `long`:
A. Flag Definition:
   Define powers of two: `1 (1<<0), 2 (1<<1), 4 (1<<2), 8 (1<<3)...`
B. Setting Flags:
   `flags |= MASK;`
C. Checking Flags:
   `boolean hasPermission = (flags & MASK) != 0;`
   Parentheses are required because `!=` has higher precedence than `&`.
D. Toggling Flags:
   `flags ^= MASK;`
E. Clearing Flags:
   `flags &= ~MASK;`

3. ALGORITHMIC PROPERTIES OF XOR (EXCLUSIVE OR)
XOR obeys critical mathematical properties:
1. Commutativity: `A ^ B == B ^ A`
2. Associativity: `(A ^ B) ^ C == A ^ (B ^ C)`
3. Identity Element: `A ^ 0 == A`
4. Self-Inverse: `A ^ A == 0`

Applications:
- In-Place Variable Swap:
  `a ^= b; b ^= a; a ^= b;`
- Finding Unique Unpaired Number in an Array:
  XORing all elements eliminates pairs (`x ^ x = 0`), leaving only the singleton value.

4. BITWISE LOW-LEVEL OPTIMIZATIONS
- Parity Check (Odd/Even): `(n & 1) != 0` evaluates faster than `n % 2 != 0`.
- Power of Two Check: `(n > 0) && ((n & (n - 1)) == 0)`.
- Unsigned Byte Conversion: `b & 0xFF` converts signed `-128..127` to unsigned `0..255`.
