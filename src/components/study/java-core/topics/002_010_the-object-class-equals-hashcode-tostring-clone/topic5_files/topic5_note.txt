1. THE 4-STEP equals() RECIPE:
   - Step 1: 'if (this == obj) return true;'
   - Step 2: 'if (obj == null || getClass() != obj.getClass()) return false;'
   - Step 3: 'ClassType other = (ClassType) obj;'
   - Step 4: 'return field1 == other.field1 && Objects.equals(f2, other.f2);'
