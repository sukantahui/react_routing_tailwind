1. THE GOLDEN CONTRACT:
   - If 'a.equals(b) == true'  → 'a.hashCode() == b.hashCode()' is MANDATORY.
   - If 'a.hashCode() == b.hashCode()' → 'a.equals(b)' can be true OR false (Collision).
   - If 'a.equals(b) == false' → 'a.hashCode()' can still be same or different.
