1. MEMORY COMPARISON:
   - Shallow Copy: Primitive values copied; nested object pointers SHARED.
   - Deep Copy   : Primitive values copied; nested objects CLONED recursively.
   - Default 'super.clone()' is ALWAYS a shallow copy.
