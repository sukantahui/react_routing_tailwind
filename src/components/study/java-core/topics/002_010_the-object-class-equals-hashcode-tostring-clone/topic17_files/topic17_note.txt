1. MODULE 002_010 SUMMARY:
   - 'Object' is the cosmic root superclass of Java.
   - Always override 'toString()' for readable logs.
   - '==' compares references; 'equals()' compares semantic contents.
   - Always override 'equals()' and 'hashCode()' together using identical fields.
   - Prefer Copy Constructors over 'Object.clone()'.
   - 'finalize()' is deprecated; use 'AutoCloseable' and 'Cleaner'.
