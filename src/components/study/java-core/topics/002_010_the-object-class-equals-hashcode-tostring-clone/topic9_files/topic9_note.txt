1. HASH COLLISION FACTS:
   - 'a.hashCode() == b.hashCode()' does NOT mean 'a.equals(b)'.
   - Pigeonhole Principle: 2^32 int hashCodes cannot uniquely map infinite objects.
   - HashMap resolves collisions via LinkedList & Red-Black Trees (Java 8+).
