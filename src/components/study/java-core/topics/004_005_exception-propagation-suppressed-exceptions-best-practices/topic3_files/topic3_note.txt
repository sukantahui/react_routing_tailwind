1. STACK TRACE ANATOMY:
   - Line 1: 'ExceptionType: Error Message'.
   - 'at ClassName.methodName(FileName.java:LineNumber)'.
   - Read from the top down to find your own code's line number.
   - 'Caused by:' sections at the bottom indicate root causes.
