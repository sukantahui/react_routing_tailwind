1. STACK UNWINDING PROCESS:
   - Call stack allocates frames on invocation (Push).
   - Exception triggers rapid frame deallocation (Pop / Unwind).
   - Invariant: 'finally' block in every frame runs before frame destruction.
   - Preserves memory and lock safety.
