1. EXCEPTION CHAINING:
   - High-level layers should not leak 'SQLException'.
   - Wrap in domain exceptions: 'throw new DomainEx("msg", sqlEx);'.
   - Preserves root cause via 'getCause()'.
   - Renders 'Caused by: ...' in stack traces.
