1. THE GOLDEN RULE OF LOGGING:
   - Handle OR Throw &rarr; NEVER BOTH.
   - Logging + Rethrowing creates N identical stack traces in logs.
   - Let exceptions bubble to the top boundary (Controller) and log once.
