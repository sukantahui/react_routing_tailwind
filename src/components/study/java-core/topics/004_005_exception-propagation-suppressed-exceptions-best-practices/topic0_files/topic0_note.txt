1. EXCEPTION PROPAGATION:
   - Starts at the failing line in method N.
   - Searches local try-catch; if absent, method terminates immediately.
   - Bubbles up to caller method (N-1).
   - Repeats until caught or JVM Default Exception Handler terminates the thread.
