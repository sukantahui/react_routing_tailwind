1. UNCAUGHT EXCEPTION LIFECYCLE:
   - Unhandled in main() &rarr; Invokes 'Thread.UncaughtExceptionHandler'.
   - Default action: Prints stack trace to System.err & halts thread.
   - Enterprise hook: 'Thread.setDefaultUncaughtExceptionHandler(...)'.
