1. CAUSE LINKING MECHANISMS:
   - Modern: 'super(message, cause)' in constructor.
   - Legacy: 'ex.initCause(rootCause)'.
   - Calling initCause() twice throws 'IllegalStateException'.
   - Always preserve root causes to avoid losing diagnostic context.
