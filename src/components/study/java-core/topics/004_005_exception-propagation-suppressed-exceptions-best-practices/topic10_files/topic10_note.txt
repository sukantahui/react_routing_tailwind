1. MODULE 004_005 SUMMARY:
   - Propagation bubbles exceptions up the call stack.
   - Stack unwinding dismantles stack frames while guaranteeing finally execution.
   - Default exception handler halts thread and prints stack trace.
   - Read stack traces: Class & Message on top, first app line is the bug.
   - Exception chaining: Wrap low-level errors into domain exceptions with cause.
   - Avoid 'Log & Throw', 'Swallow & Ignore', and 'Catch Throwable' anti-patterns.
   - Document all exceptions with '@throws' in Javadoc.
   - Multi-tier architecture: Repo &rarr; Service (Wrap) &rarr; Controller (Log once).
