1. JAVADOC EXCEPTION RULES:
   - Use '@throws ExceptionType condition description'.
   - Document both Checked and Unchecked exceptions.
   - Do NOT clutter method header with unchecked exceptions.
   - Provides clear preconditions to API consumers.
