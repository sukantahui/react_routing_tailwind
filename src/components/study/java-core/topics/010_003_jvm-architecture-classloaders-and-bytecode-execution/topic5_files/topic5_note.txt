1. WHAT OCCURS IN PREPARATION:
   - JVM allocates memory in Metaspace/Heap for static variables (class variables).
   - Sets each variable to the default initial value of its datatype (0, false, null).
   - No user code or expressions are executed yet.

2. SPECIAL CASE - 'ConstantValue' ATTRIBUTE:
   - If a field is 'static final' with a compile-time constant expression, the compiler
     attaches a 'ConstantValue' attribute.
   - The JVM assigns the real value during Preparation rather than waiting for Initialization!
