1. WHAT IS RESOLUTION:
   - The process of replacing symbolic references in the Runtime Constant Pool
     with direct pointers to memory structures (classes, interfaces, fields, methods).

2. TIMING OF RESOLUTION:
   - Eager Resolution : Performed immediately when the class is linked.
   - Lazy Resolution  : Deferred until the instruction referencing the symbol is first executed (default in most HotSpot implementations).

3. COMMON RESOLUTION ERRORS:
   - 'NoSuchMethodError', 'NoSuchFieldError', 'NoClassDefFoundError', 'IllegalAccessError'.
