1. WHAT VERIFICATION GUARANTEES:
   - Variable values are never accessed without prior initialization.
   - Method calls adhere to access control modifiers (public/private/protected).
   - Parameters match expected method argument types.
   - Operand stack depth never overflows or underflows during execution.
   - Bytecode instructions have valid opcode branch targets.

2. VERIFICATION ERROR:
   - 'java.lang.VerifyError' (subclass of 'LinkageError').
