1. WHAT THE APPLICATION CLASSLOADER DOES:
   - Also known as the 'System ClassLoader'.
   - Loads classes from the application classpath ('-classpath', '-cp', or 'CLASSPATH' env variable).
   - Responsible for loading all user-written application code and third-party libraries (Maven/Gradle JARs).

2. RETRIEVAL METHOD:
   - 'ClassLoader.getSystemClassLoader()'
