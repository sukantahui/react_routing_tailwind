1. DEFENSE AGAINST MALICIOUS BYTECODE:
   - Parent delegation ensures trusted core libraries (java.base) are always loaded
     by the trusted Bootstrap ClassLoader before any untrusted classpath JARs are examined.

2. 'PROHIBITED PACKAGE' ENFORCEMENT:
   - Inside 'ClassLoader.defineClass()', the JVM checks if the class name starts with 'java.'.
   - If a custom classloader attempts to define a class in the 'java.*' package, the JVM
     immediately throws 'java.lang.SecurityException: Prohibited package name: java.lang'.
