1. LISTITERATOR EXCLUSIVE POWERS:
   - Bidirectional: 'hasNext()/next()' and 'hasPrevious()/previous()'.
   - Index queries: 'nextIndex()' and 'previousIndex()'.
   - 'set(e)': replaces last element returned.
   - 'add(e)': inserts element into list at cursor position.
   - Available ONLY on 'List' implementations (ArrayList, LinkedList).
