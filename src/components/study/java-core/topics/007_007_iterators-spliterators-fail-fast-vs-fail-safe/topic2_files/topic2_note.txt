1. SAFE REMOVAL:
   - 'it.remove()' is the ONLY safe way to remove during loops.
   - Synchronizes 'expectedModCount = modCount'.
   - Mandatory rule: 'next()' MUST be called before each 'remove()'.
   - Java 8 idiom: 'list.removeIf(predicate)' uses this under the hood.
