1. MODULE 007_007 GRAND SUMMARY:
   - Iterator pattern: Decouples traversal from internal collection structure.
   - Safe removal: 'it.remove()' is the ONLY safe way; 'list.remove()' throws CME.
   - modCount: Version counter tracking structural size changes.
   - Fail-Fast: 'modCount != expectedModCount' in 1 CPU cycle (ArrayList, HashMap).
   - Fail-Safe: CopyOnWriteArrayList (snapshot), ConcurrentHashMap (weakly consistent).
   - ListIterator: Bidirectional (previous), index queries, and inline set/add mutations.
   - Spliterator: Engine of parallel streams; recursive 'trySplit()' across ForkJoin cores.
