1. FAIL-FAST COLLECTIONS:
   - ArrayList, LinkedList, HashSet, HashMap, TreeSet, TreeMap.
   - Mechanism: 'modCount != expectedModCount'.
   - Action: Throws 'ConcurrentModificationException' immediately.
   - Purpose: Prevents non-deterministic bugs and memory corruption.
