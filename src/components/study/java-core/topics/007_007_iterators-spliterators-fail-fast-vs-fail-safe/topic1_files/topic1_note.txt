1. ITERATOR METHODS:
   - 'hasNext()': checks if more elements exist without moving cursor.
   - 'next()': returns current element and advances cursor forward.
   - 'forEachRemaining(Consumer)': consumes all remaining unvisited elements.
   - Throws 'NoSuchElementException' if 'next()' called when 'hasNext() == false'.
