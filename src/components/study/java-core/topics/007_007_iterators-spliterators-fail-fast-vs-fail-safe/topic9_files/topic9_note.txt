1. SPLITERATOR FUNDAMENTALS:
   - Portmanteau of 'Split' + 'Iterator'.
   - Engine behind Java 8 Streams and Parallel Streams.
   - Key methods: 'tryAdvance()', 'trySplit()', 'estimateSize()'.
   - Enables lock-free recursive partitioning for multi-core CPUs.
