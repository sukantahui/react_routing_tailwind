1. SPLITERATOR CHARACTERISTICS:
   - 'trySplit()': splits source in half for parallel threads.
   - 'ORDERED': elements have defined encounter order.
   - 'SIZED': exact size known before traversal.
   - 'DISTINCT': no duplicate element pairs.
   - 'SORTED': elements follow natural or custom sort.
   - 'CONCURRENT': safely mutated concurrently.
