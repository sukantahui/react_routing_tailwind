1. CME HAZARD:
   - For-each loop compiles to Iterator 'it = list.iterator()'.
   - 'list.add()' or 'list.remove()' increments 'modCount'.
   - Next call to 'it.next()' detects 'modCount != expectedModCount'.
   - Throws 'ConcurrentModificationException' immediately (Fail-Fast).
   - Solution: Use 'iterator.remove()' or 'list.removeIf()'.
