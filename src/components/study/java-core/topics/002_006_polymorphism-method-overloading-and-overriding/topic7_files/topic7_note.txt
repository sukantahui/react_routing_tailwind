1. CHECKED EXCEPTION OVERRIDING LAWS:
   - Child CAN declare: Same checked exception, narrower subclass exception, or NO exception.
   - Child CANNOT declare: Broader checked exception (e.g. Exception when parent declares IOException).
   - Unchecked exceptions (RuntimeException): Unrestricted.
