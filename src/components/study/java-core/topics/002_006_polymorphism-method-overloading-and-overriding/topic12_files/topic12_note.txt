1. 'instanceof' OPERATOR:
   - Syntax: 'if (ref instanceof Type) { ... }'
   - Returns boolean: true if 'ref' is an instance of Type or subtype; false otherwise.
   - Null-Safe: If 'ref == null', evaluates to false without throwing NPE.
