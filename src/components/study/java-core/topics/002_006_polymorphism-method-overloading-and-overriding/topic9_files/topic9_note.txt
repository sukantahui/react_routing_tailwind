1. DYNAMIC METHOD DISPATCH (DMD):
   - Mechanism by which a call to an overridden method is resolved at RUNTIME.
   - Powered by 'invokevirtual' opcode and the Virtual Method Table (vtable).
   - Enables writing flexible, pluggable software architectures.
