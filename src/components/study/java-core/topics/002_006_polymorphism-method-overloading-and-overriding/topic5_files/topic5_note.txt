1. VISIBILITY RULES IN OVERRIDING:
   - Parent 'public' &rarr; Child MUST be 'public'.
   - Parent 'protected' &rarr; Child can be 'protected' or 'public'.
   - Parent 'default' &rarr; Child can be 'default', 'protected', or 'public'.
   - Stricter access in child causes: "attempting to assign weaker access privileges".
