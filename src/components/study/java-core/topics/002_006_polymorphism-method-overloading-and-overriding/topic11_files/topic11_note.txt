1. DOWNCASTING RULES:
   - Syntax: 'Child c = (Child) parentRef;' (Explicit Cast Mandatory).
   - Dangerous: If 'parentRef' points to another subclass or pure parent,
     JVM throws: 'java.lang.ClassCastException'.
   - Solution: Always check with 'instanceof' before downcasting!
