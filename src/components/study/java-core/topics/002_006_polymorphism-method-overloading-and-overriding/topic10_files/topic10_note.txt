1. UPCASTING RULES:
   - Syntax: 'Parent p = new Child();'
   - Implicit & 100% Safe (no ClassCastException possible).
   - Visibility is constrained by the Parent reference type at compile time.
   - Behavior is dispatched to the Child object at runtime.
