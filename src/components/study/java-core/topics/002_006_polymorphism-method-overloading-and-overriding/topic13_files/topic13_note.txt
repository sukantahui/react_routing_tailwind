1. PATTERN MATCHING SYNTAX:
   - 'if (obj instanceof TargetType varName) { ... }'
   - The variable 'varName' is scoped strictly to the true branch of the 'if'.
   - Can combine with boolean guards: 'if (obj instanceof String s && s.length() > 5)'.
