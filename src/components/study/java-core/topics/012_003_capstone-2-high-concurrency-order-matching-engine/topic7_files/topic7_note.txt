1. WRITE-AHEAD LOG (WAL) MECHANICS:
   - Every state change is appended to sequential disk storage BEFORE being applied to in-memory state.
   - 'FileChannel.force(false)' commits dirty OS buffer cache blocks to disk.
   - Enables instantaneous recovery after system crashes.
