1. PRICE-TIME PRIORITY:
   - Price Priority : Best available price gets matched first.
   - Time Priority  : First order to arrive at that price gets filled first (FIFO).

2. ORDER SIDES:
   - Buy Book (Bids): Max-heap or descending sorted map.
   - Sell Book (Asks): Min-heap or ascending sorted map.
