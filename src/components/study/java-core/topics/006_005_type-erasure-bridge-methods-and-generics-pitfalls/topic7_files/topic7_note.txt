1. RESTRICTION 2: NO 'new T()':
   - 'new T()' is illegal (erased to new Object()).
   - Compiler cannot guarantee accessible constructor exists.
   - Workaround: Pass 'Class<T> clazz' token.
   - Instantiate via: 'clazz.getDeclaredConstructor().newInstance()'.
