1. TYPE REPLACEMENT RULES:
   - '<T>' &rarr; replaced with 'Object'.
   - '<T extends SuperType>' &rarr; replaced with 'SuperType'.
   - '<T extends Bound1 & Bound2>' &rarr; replaced with 'Bound1'.
   - Guarantees valid non-generic JVM bytecode.
