1. RESTRICTION 3: NO STATIC FIELDS OF TYPE T:
   - 'private static T field;' is ILLEGAL.
   - Static fields are shared across all instances.
   - Type arguments differ per instance.
   - Prohibits memory and type conflicts in Metaspace.
