1. RESTRICTION 1: NO PRIMITIVE GENERICS:
   - 'List<int>' is ILLEGAL.
   - Primitives do not extend 'java.lang.Object'.
   - Type erasure requires Object reference compatibility.
   - Solution: Use wrapper classes ('Integer', 'Double', 'Boolean').
