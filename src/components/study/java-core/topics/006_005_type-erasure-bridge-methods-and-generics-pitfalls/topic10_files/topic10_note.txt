1. RESTRICTION 5: NO GENERIC ARRAYS:
   - 'new List<String>[10]' is ILLEGAL.
   - Array reification conflicts with generic erasure.
   - Prevents fatal heap pollution bypassing ArrayStoreException.
   - Solution: Use 'List<List<T>>' (Effective Java Item 28).
