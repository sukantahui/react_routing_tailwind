1. JAVAP COMMAND TOOLS:
   - 'javap -c -v MyClass.class'.
   - Reveals erased field descriptors (Ljava/lang/Object;).
   - Identifies 'checkcast' instructions.
   - Shows 'ACC_BRIDGE' and 'ACC_SYNTHETIC' method flags.
