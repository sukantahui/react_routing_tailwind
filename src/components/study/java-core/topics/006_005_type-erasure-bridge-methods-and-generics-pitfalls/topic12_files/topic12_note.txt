1. RESTRICTION 7: NO OVERLOAD CLASHES:
   - Cannot overload methods where parameters erase to same raw type.
   - 'method(List<String>)' and 'method(List<Integer>)' → both erase to 'method(List)'.
   - Triggers compiler 'name clash' error.
   - Solution: Use distinct method names.
