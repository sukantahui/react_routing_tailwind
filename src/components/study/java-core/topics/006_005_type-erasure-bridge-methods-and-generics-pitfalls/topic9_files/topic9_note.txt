1. RESTRICTION 4: NO PARAMETERIZED INSTANCEOF:
   - 'instanceof List<String>' is ILLEGAL.
   - Generic types are non-reifiable.
   - JVM cannot inspect element types at runtime.
   - Valid checks: 'instanceof List<?>' or 'instanceof List'.
