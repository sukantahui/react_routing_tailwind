1. RESTRICTION 6: NO GENERIC EXCEPTIONS:
   - 'class MyEx<T> extends Exception' is ILLEGAL.
   - Cannot catch parameterized exceptions: 'catch (MyEx<T> e)'.
   - JVM exception table requires concrete runtime types.
   - 'throws T' in generic method signatures is permitted.
