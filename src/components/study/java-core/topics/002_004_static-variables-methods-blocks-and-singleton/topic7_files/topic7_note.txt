1. METHOD HIDING VS OVERRIDING:
   -----------------------------------------------------------------------------
   FEATURE              STATIC METHOD (Hiding)        INSTANCE METHOD (Overriding)
   -----------------------------------------------------------------------------
   Polymorphism         NO (Static Binding)           YES (Dynamic Virtual Dispatch)
   Resolved At          Compile Time                  Runtime
   Dispatched Via       Reference Variable Type       Heap Object Runtime Type
