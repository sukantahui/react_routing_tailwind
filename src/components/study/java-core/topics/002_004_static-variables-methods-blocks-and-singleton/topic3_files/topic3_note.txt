1. ACCESS CONVENTIONS:
   - Always access static members via: 'ClassName.variableName'
   - Avoid 'objectRef.variableName' (misleading; implies instance state).
   - Even if 'ref = null', 'ref.staticVar' works because javac binds it to ClassName.
