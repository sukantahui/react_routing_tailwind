1. MEMORY COMPARISON TABLE:
   -----------------------------------------------------------------------------
   FEATURE            STATIC VARIABLE                  INSTANCE VARIABLE
   -----------------------------------------------------------------------------
   Location           Metaspace / Class mirror         Heap (Eden / Tenured space)
   Copies             Exactly ONE per ClassLoader      One per object instance
   Created            During Class Loading             During 'new' instantiation
   Destroyed          When Class is unloaded           When Object is GC'd
   Access             ClassName.variable               objectRef.variable
