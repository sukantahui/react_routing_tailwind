1. WHY ENUM SINGLETON IS UNBEATABLE:
   - 100% Thread-safe (guaranteed by JVM).
   - Reflection Proof: 'Constructor.newInstance()' throws IllegalArgumentException for Enums.
   - Serialization Proof: Java guarantees only 1 enum constant exists during deserialization.
   - Recommended by Joshua Bloch (Effective Java).
