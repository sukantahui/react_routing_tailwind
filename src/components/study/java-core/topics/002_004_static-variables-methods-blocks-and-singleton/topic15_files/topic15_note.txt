1. DOUBLE-CHECKED LOCKING RULES:
   - Use 'volatile' on the static instance variable.
   - Check 1: 'if (instance == null)' outside synchronized block (high performance).
   - Lock: 'synchronized (Singleton.class)'
   - Check 2: 'if (instance == null)' inside synchronized block (thread safety).
