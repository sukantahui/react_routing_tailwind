1. STATIC VS INSTANCE PARADIGM:
   - static: Belongs to the CLASS (stored in Metaspace/Class data area).
   - non-static: Belongs to the INSTANCE (stored in Heap memory).
   - Single shared copy across all objects.
   - Accessed directly via ClassName.member.
