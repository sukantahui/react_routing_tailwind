1. SET INTERFACE CONTRACT:
   - Extends 'Collection<E>'.
   - Strictly unique elements (no duplicates).
   - 'add(e)' returns false if element already exists.
   - HashSet: O(1) unordered.
   - LinkedHashSet: preserves insertion order.
   - TreeSet: sorted Red-Black tree order.
