1. ARRAYS VS COLLECTIONS:
   - Arrays: Fixed size, manual arraycopy, lacks Set/Map semantics.
   - Collections: Dynamic auto-growth, O(1) searches, rich APIs.
   - Solves array covariance issues via generic type safety.
   - Standard backbone of modern Java applications.
