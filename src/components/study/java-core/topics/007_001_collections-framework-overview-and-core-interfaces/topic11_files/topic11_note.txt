1. CREATION MATRIX SUMMARY:
   - 'Arrays.asList()': Fixed-size, permits set(), backed by array, allows null.
   - 'Collections.unmodifiableList()': Read-only view, backing list mutations leak through.
   - 'List.of()': Truly immutable, standalone, forbids nulls, no set().
