1. THE 4 JCF BRANCHES:
   - List  : Index-based sequence, permits duplicates.
   - Set   : Mathematical uniqueness, no duplicates.
   - Queue : FIFO/LIFO processing buffer.
   - Map   : Key-Value dictionary (unique keys).
