1. MAP INTERFACE CONTRACT:
   - Key-Value pairs with strictly unique keys.
   - Independent hierarchy from 'java.util.Collection'.
   - 'put(K, V)', 'get(K)', 'getOrDefault(K, default)'.
   - 3 Collection Views: keySet(), values(), entrySet().
   - 'Map.Entry<K, V>' for fast key-value traversal.
