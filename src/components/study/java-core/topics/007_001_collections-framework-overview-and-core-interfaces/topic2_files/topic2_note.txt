1. ITERABLE ROOT CONTRACT:
   - Resides in 'java.lang' package.
   - Superinterface of 'java.util.Collection'.
   - Unlocks enhanced for-each loop: 'for (T x : collection)'.
   - 'default void forEach(Consumer<? super T> action)' since Java 8.
