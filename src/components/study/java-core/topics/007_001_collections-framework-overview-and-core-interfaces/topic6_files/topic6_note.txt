1. LIST INTERFACE CONTRACT:
   - Extends 'Collection<E>'.
   - Zero-indexed positional access: 'get(i)', 'set(i, e)', 'add(i, e)'.
   - Preserves strict insertion ordering.
   - Permits duplicate elements and multiple nulls.
   - Offers 'indexOf()', 'lastIndexOf()', 'subList()', 'listIterator()'.
