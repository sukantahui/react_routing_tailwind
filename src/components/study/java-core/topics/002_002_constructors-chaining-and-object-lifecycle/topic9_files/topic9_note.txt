1. COPY CONSTRUCTOR DEFINITION:
   -----------------------------------------------------------------------------
   - A constructor accepting an instance of its own class to duplicate state:
     'public Student(Student source) { ... }'

2. SHALLOW VS DEEP COPYING:
   - Shallow Copy: Copies reference pointers (nested objects are shared!).
   - Deep Copy: Creates brand-new copies of all nested mutable objects
     (CampusAddress, ArrayList, Date) ensuring complete memory isolation.

3. WHY JAVA PREFERS COPY CONSTRUCTORS OVER Object.clone():
   - Type-safe (no casting required).
   - No CloneNotSupportedException.
   - Assigns 'final' fields cleanly and safely.
   - Full control over shallow vs deep duplication.
