1. DEFAULT CONSTRUCTOR RULES:
   -----------------------------------------------------------------------------
   - Generated by compiler ONLY when ZERO constructors are written in the class.
   - Access modifier matches the class (public / package-private).
   - Injects 'super()' as its first instruction.
   - Populates fields with JVM default zero values (null, 0, 0.0, false).

2. COMPILER VS USER-DEFINED:
   - Compiler-generated: Free gift, empty body, basic zero defaults.
   - User-defined no-arg: Written by developer, assigns meaningful baseline state.

3. THE GOLDEN RULE OF REVOCATION:
   - As soon as you write ANY constructor (even 'Student(String name)'),
     the compiler's default constructor is PERMANENTLY REVOKED!
