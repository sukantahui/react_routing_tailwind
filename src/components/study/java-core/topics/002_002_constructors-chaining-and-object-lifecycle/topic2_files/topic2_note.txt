1. THE 10-POINT ARCHITECTURAL COMPARISON MATRIX:
   -----------------------------------------------------------------------------
   FEATURE              CONSTRUCTOR                       METHOD
   -----------------------------------------------------------------------------
   1. Purpose           Initialize Heap memory & state   Execute behavior & computation
   2. Invocation        Implicit via 'new', this(), super Explicit via dot operator (.)
   3. Return Type       NONE (not even void)             Mandatory (type or void)
   4. Name              EXACT match with class name      Any valid identifier (camelCase)
   5. Inheritance       NEVER inherited by child classes  Inherited by subclasses
   6. Overriding        CANNOT be overridden             CAN be overridden polymorphically
   7. Default Generated Synthesized if zero written      NEVER generated by compiler
   8. static Modifier   PROHIBITED (needs 'this')         PERMITTED for class-level logic
   9. Other Modifiers   Access modifiers ONLY            final, abstract, synchronized, etc.
   10. JVM Opcode       invokespecial <init>             invokevirtual, invokestatic, etc.
   -----------------------------------------------------------------------------

2. KEY PITFALLS:
   - Adding 'void' turns a constructor into a normal method!
   - Calling overridable methods inside a constructor risks subclass bugs.
   - Constructors cannot be static, final, abstract, or synchronized.
