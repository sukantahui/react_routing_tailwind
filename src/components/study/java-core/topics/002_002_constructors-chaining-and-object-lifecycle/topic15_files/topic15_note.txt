1. THE 4 PROHIBITED MODIFIERS:
   -----------------------------------------------------------------------------
   MODIFIER         WHY FORBIDDEN BY JLS COMPILER SPECIFICATION
   -----------------------------------------------------------------------------
   static           Requires 'this' instance; static has no instance context.
   final            Constructors cannot be inherited or overridden.
   abstract         Constructors must have an executable body to initialize fields.
   synchronized     Object is private to creating thread until publication.
   -----------------------------------------------------------------------------

2. PERMITTED MODIFIERS:
   - Access modifiers ONLY: public, protected, default, private.
