1. ARCHITECTURAL PATTERN SUMMARY:
   -----------------------------------------------------------------------------
   - Mandatory parameters are required by all constructors.
   - Optional parameters receive sensible domain defaults.
   - All constructors chain into 1 Master Constructor via 'this(...)'.
   - Immutable fields guarantee domain invariant safety.

2. MODULE 002_002 SUMMARY:
   - Object Genesis: new (memory allocation) + Constructor (state initialization).
   - Constructor Laws: Name matches class, NO return type (not even void).
   - Chaining: this(...) on Line 1 funnels to Master Constructor.
   - IIB Execution: Executes after super() and before constructor body.
   - Security: Private constructors for Singletons & Utility toolkits.
