1. RULES OF IMMUTABLE CLASS CONSTRUCTORS:
   -----------------------------------------------------------------------------
   - Class is marked 'final' (prevents subclass mutation).
   - All fields are 'private final'.
   - Constructor performs DEFENSIVE COPYING on all mutable arguments (List, Date).
   - Getters return unmodifiable views or defensive copies.
   - NEVER let 'this' reference escape during construction!
