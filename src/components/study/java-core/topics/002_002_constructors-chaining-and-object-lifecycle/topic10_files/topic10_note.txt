1. IIB SYNTAX & EXECUTION:
   -----------------------------------------------------------------------------
   - Syntax: An unnamed block '{ ... }' in the class body.
   - Executes ONCE per object creation immediately AFTER 'super()' returns
     and BEFORE the constructor body runs!
   - Multiple IIBs execute in top-to-bottom textual order.

2. COMPILER INLINING:
   - The compiler copies all IIBs directly into the start of every constructor
     right after the 'super()' invocation.

3. USE CASES:
   - Universal initialization shared across all constructors.
   - Anonymous inner classes (which cannot declare named constructors).
