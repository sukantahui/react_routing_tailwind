1. CORE CONCEPT SUMMARY:
The INSERT INTO statement appends new records to a table. SQL supports both positional insertion across all columns and named column insertion.

2. KEY EXAMINATION POINTS:
  (1) Positional Syntax: 'INSERT INTO table_name VALUES (val1, val2, ...);' requires values for every column in the exact schema order.
  (2) Selective Column Syntax: 'INSERT INTO table_name (col1, col3) VALUES (val1, val3);' assigns omitted columns their DEFAULT value or NULL (if allowed).
  (3) Character and Date literals MUST be enclosed within single quotes ('...') or double quotes ("..."), whereas numerical values are written bare.
  (4) Violation of PRIMARY KEY (duplicate), NOT NULL (missing mandatory field), or FOREIGN KEY causes the INSERT statement to abort.

3. SYNTAX & CODE SNIPPET:
-- Method 1: Inserting all columns in schema order
INSERT INTO Employee VALUES (101, 'Sunita Roy', 'Sales', 58000.00, '2022-04-15');

-- Method 2: Inserting specific columns (omitted columns take DEFAULT or NULL)
INSERT INTO Employee (EmpId, EName, Dept) VALUES (102, 'Rohan Verma', 'IT');

-- Method 3: Inserting explicit NULL
INSERT INTO Employee (EmpId, EName, Dept, Salary, DOJ) VALUES (103, 'Priya Sen', 'HR', NULL, '2023-01-10');

4. CBSE COMMON PITFALLS:
Omitting a column without listing explicit column names in the INSERT clause will throw 'Column count doesn't match value count at row 1'.
