MASTER TEACHER SUKANTA HUI'S GOLDEN RULES FOR 100% MARKS IN SQL:
1. Always enclose string literals and date values ('YYYY-MM-DD') in single or double quotes.
2. Remember that NULL cannot be checked with '=' or '!='; always use 'IS NULL' or 'IS NOT NULL'.
3. In BETWEEN low AND high, the lower boundary MUST come first, and BOTH bounds are inclusive.
4. ORDER BY is always the last clause in a SELECT query. Default sorting direction is ASC.
5. In UPDATE and DELETE, check the WHERE clause twice to prevent unintentional whole-table modifications!
