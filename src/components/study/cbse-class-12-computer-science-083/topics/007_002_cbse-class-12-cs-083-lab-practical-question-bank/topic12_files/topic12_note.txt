Python script connecting to MySQL Server, creating a new database 'SchoolDB', and creating table 'Student' with PRIMARY KEY and column integrity constraints.

2. KEY EXAMINATION POINTS:
  (1) Connects to MySQL server without database argument first to create database.
  (2) Executes 'CREATE DATABASE IF NOT EXISTS SchoolDB;'.
  (3) Switches to SchoolDB or connects with database='SchoolDB'.
  (4) Executes CREATE TABLE with RollNo INT PRIMARY KEY, SName VARCHAR(30), Marks DECIMAL(5,2).

3. PRACTICAL CODE SNIPPET:
import mysql.connector

def setup_database():
    con = mysql.connector.connect(host='localhost', user='root', password='password')
    cur = con.cursor()
    cur.execute("CREATE DATABASE IF NOT EXISTS SchoolDB;")
    cur.execute("USE SchoolDB;")
    cur.execute("""
        CREATE TABLE IF NOT EXISTS Student (
            RollNo INT PRIMARY KEY,
            SName VARCHAR(30) NOT NULL,
            Stream VARCHAR(15),
            Marks DECIMAL(5,2)
        );
    """)
    print("Database & Student table initialized successfully!")
    cur.close(); con.close()
