1. CORE CONCEPT SUMMARY:
Python practical program implementing a full Linear Stack Abstract Data Type (ADT) for numeric values with Push, Pop, Peek, and Display operations.

2. KEY EXAMINATION POINTS:
  (1) Uses a standard Python list as the underlying storage buffer.
  (2) Push: append(item) at top of stack.
  (3) Pop: underflow check (if len == 0), then pop() and return element.
  (4) Peek: returns topmost item without removal (stk[-1]); Display traverses stack from top to bottom.

3. PRACTICAL CODE SNIPPET:
def push(stk, val):
    stk.append(val)

def pop(stk):
    if len(stk) == 0:
        print("Stack Underflow!")
        return None
    return stk.pop()

def peek(stk):
    return stk[-1] if stk else None

def display(stk):
    if not stk:
        print("Stack is Empty")
    else:
        for i in range(len(stk) - 1, -1, -1):
            print(stk[i])
