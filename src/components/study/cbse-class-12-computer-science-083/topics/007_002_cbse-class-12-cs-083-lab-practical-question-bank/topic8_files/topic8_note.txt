1. CORE CONCEPT SUMMARY:
Python practical program to create an employee CSV file containing (EmpId, Name, Dept, Salary) with user-defined records and proper newline handling.

2. KEY EXAMINATION POINTS:
  (1) Opens CSV file with 'newline=""' to prevent blank line insertion on Windows.
  (2) Initializes writer object: writer = csv.writer(f).
  (3) Writes header row via writer.writerow(['EmpId', 'Name', 'Dept', 'Salary']).
  (4) Accepts multiple records and appends using writer.writerow() or writer.writerows().

3. PRACTICAL CODE SNIPPET:
import csv

def create_employee_csv():
    with open('employees.csv', 'w', newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['EmpId', 'Name', 'Dept', 'Salary'])
        while True:
            eid = int(input("EmpId: "))
            name = input("Name: ")
            dept = input("Dept: ")
            sal = float(input("Salary: "))
            writer.writerow([eid, name, dept, sal])
            if input("More? (y/n): ").lower() != 'y':
                break
    print("employees.csv generated successfully!")
