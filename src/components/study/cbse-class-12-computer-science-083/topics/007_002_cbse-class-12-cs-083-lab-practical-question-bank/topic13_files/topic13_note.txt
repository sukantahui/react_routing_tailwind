1. CORE CONCEPT SUMMARY:
Python program accepting dynamic student records from user and inserting them safely into table 'Student' using parameterized '%s' placeholders and connection.commit().

2. KEY EXAMINATION POINTS:
  (1) Uses parameterized query: 'INSERT INTO Student VALUES (%s, %s, %s, %s);'.
  (2) Passes values as a Python tuple to prevent SQL injection.
  (3) Calls con.commit() to persist modifications permanently.
  (4) Prints rowcount confirming successful tuple insertion.

3. PRACTICAL CODE SNIPPET:
import mysql.connector

def add_student():
    con = mysql.connector.connect(host='localhost', user='root', password='password', database='SchoolDB')
    cur = con.cursor()
    r = int(input("Roll No: "))
    n = input("Name: ")
    s = input("Stream: ")
    m = float(input("Marks: "))
    
    query = "INSERT INTO Student VALUES (%s, %s, %s, %s);"
    cur.execute(query, (r, n, s, m))
    con.commit()
    print(f"{cur.rowcount} student enrolled successfully!")
    cur.close(); con.close()
