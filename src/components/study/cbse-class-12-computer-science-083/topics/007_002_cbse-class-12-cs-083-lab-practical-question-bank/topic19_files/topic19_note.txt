1. CORE CONCEPT SUMMARY:
Practical queries linking Employee and Department tables via common DeptId attribute to produce unified tabular reports with filtering and sorting.

2. KEY EXAMINATION POINTS:
  (1) Equi-Join syntax: SELECT E.EName, D.DeptName, E.Salary FROM Employee E, Department D WHERE E.DeptId = D.DeptId;.
  (2) Equi-join combined with filtering: WHERE E.DeptId = D.DeptId AND D.Location = 'Kolkata'.
  (3) Equi-join with GROUP BY: DeptName and count of employees in each department.
  (4) The definitive multi-table query practical expected in Class 12 CS lab records.

3. PRACTICAL CODE SNIPPET:
-- SQL Practical Set 4: Multi-Table Equi-Join
SELECT E.EmpId, E.EName, D.DeptName, D.Location, E.Salary 
FROM Employee E, Department D 
WHERE E.DeptId = D.DeptId 
ORDER BY D.DeptName ASC, E.Salary DESC;

-- Combined Join and Grouping
SELECT D.DeptName, COUNT(E.EmpId) AS StaffCount, AVG(E.Salary) AS DeptAvgSalary 
FROM Employee E, Department D 
WHERE E.DeptId = D.DeptId 
GROUP BY D.DeptId, D.DeptName;
