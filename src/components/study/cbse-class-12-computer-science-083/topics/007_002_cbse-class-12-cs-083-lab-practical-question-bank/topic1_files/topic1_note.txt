1. CORE CONCEPT SUMMARY:
Complete production-ready Python practical program to read a text file and calculate total characters, total words, total lines, and frequencies of each individual vowel.

2. KEY EXAMINATION POINTS:
  (1) Reads text file using 'with open('data.txt', 'r') as f:'.
  (2) Calculates lines via f.readlines(), words via text.split(), and characters via len(text).
  (3) Dictionary or tuple counter to track vowels 'A', 'E', 'I', 'O', 'U' case-insensitively.
  (4) Standard lab test problem frequently assigned by CBSE external examiners.

3. PRACTICAL CODE SNIPPET:
def analyze_text_file(filename):
    with open(filename, 'r') as f:
        lines = f.readlines()
        num_lines = len(lines)
        num_words = sum(len(line.split()) for line in lines)
        text = "".join(lines)
        num_chars = len(text)
        vowels = {v: text.lower().count(v) for v in 'aeiou'}
        
    print(f"Lines: {num_lines}, Words: {num_words}, Characters: {num_chars}")
    print("Vowel Frequencies:", vowels)
