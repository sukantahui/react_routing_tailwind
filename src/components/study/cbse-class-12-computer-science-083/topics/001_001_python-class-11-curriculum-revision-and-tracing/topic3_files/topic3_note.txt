1. OPERATOR PRECEDENCE TABLE (Highest to Lowest):
   1. Parentheses: ( )
   2. Exponentiation: ** (Right-to-Left Associativity!)
   3. Unary Operators: +x, -x, ~x
   4. Multiplication, Division, Floor Division, Modulo: *, /, //, % (Left-to-Right)
   5. Addition, Subtraction: +, -
   6. Bitwise Shifts: <<, >>
   7. Bitwise AND: &
   8. Bitwise XOR, OR: ^, |
   9. Comparison / Relational & Membership / Identity: ==, !=, <, <=, >, >=, is, in
   10. Logical NOT: not
   11. Logical AND: and
   12. Logical OR: or
   13. Assignment Operators: =, +=, -=, etc.

2. VITAL BOARD EXAMINATION PITFALLS:
   a. Exponentiation Associativity:
      '2 ** 3 ** 2' evaluates from RIGHT to LEFT: 2 ** (3 ** 2) = 2 ** 9 = 512.
   b. Negative Floor Division (//):
      Floors towards negative infinity!
      '-7 // 2' yields '-4' (not -3!).
   c. Modulo Formula with Negatives:
      a % b = a - (b * (a // b))
      '-7 % 2' = -7 - (2 * (-4)) = -7 - (-8) = 1.
      '7 % -2' = 7 - (-2 * (-4)) = 7 - 8 = -1.

3. SHORT-CIRCUIT EVALUATION:
   - In 'A and B', if A is falsy, Python returns A immediately without evaluating B.
   - In 'A or B', if A is truthy, Python returns A immediately without evaluating B.
   - Used to prevent runtime crashes: '(n != 0) and (total / n > 50)'.
