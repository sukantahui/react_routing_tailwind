1. CORE CONCEPT SUMMARY:
The is_connected() boolean method checks whether the database connection is currently open, authenticated, and ready to transmit queries.

2. KEY EXAMINATION POINTS:
  (1) Syntax: 'if con.is_connected(): print("Connected!")'
  (2) Returns True if the connection is active and socket communication is responsive; returns False if disconnected.
  (3) Crucial for robust application programming: prevents attempting queries on failed or timed-out connections.
  (4) CBSE Exam Classic: Writing a complete connection verification snippet with try-except and is_connected().

3. SYNTAX & CODE SNIPPET:
import mysql.connector

try:
    con = mysql.connector.connect(
        host="localhost",
        user="root",
        password="tiger",
        database="SchoolDB"
    )
    if con.is_connected():
        print("Successfully connected to MySQL database!")
        print("Server Version:", con.get_server_info())
        con.close()
except mysql.connector.Error as err:
    print("Failed to connect:", err)

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
