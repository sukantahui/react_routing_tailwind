1. CORE CONCEPT SUMMARY:
By default, mysql.connector does NOT autocommit DML modifications. Without connection.commit(), changes are lost when the script ends!

2. KEY EXAMINATION POINTS:
  (1) The Most Common CBSE Trap: An INSERT or UPDATE statement executes without error, but the MySQL table remains completely unchanged!
  (2) Reason: mysql.connector begins an implicit transaction; changes remain in uncommitted buffer until 'con.commit()' is invoked.
  (3) Syntax: 'con.commit()' writes all pending INSERT, UPDATE, and DELETE operations permanently to the database disk.
  (4) Rollback: 'con.rollback()' cancels all pending uncommitted changes in case an error occurs.

3. SYNTAX & CODE SNIPPET:
import mysql.connector

con = mysql.connector.connect(host="localhost", user="root", password="tiger", database="SchoolDB")
cur = con.cursor()

# Performing an INSERT
query = "INSERT INTO Student VALUES (106, 'Kunal Sen', 'Commerce', 89.0);"
cur.execute(query)

# CRITICAL STEP: Commit transaction to disk
con.commit()
print(f"{cur.rowcount} record(s) inserted successfully!")

# Clean up
cur.close()
con.close()

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
