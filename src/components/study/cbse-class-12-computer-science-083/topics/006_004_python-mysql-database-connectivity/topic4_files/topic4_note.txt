1. CORE CONCEPT SUMMARY:
A cursor object acts as an operational handle or workhorse. It sends SQL statements to MySQL and holds the resulting record set in client memory.

2. KEY EXAMINATION POINTS:
  (1) Creation: 'cur = con.cursor()' creates a cursor bound to that specific connection.
  (2) Primary Responsibilities: Executing SQL queries via .execute(), retrieving result rows via fetch methods, and reporting row counts.
  (3) Buffered vs Unbuffered cursors: By default, MySQL connector cursors fetch all rows from the server into memory buffer.
  (4) Always close cursors when done using 'cur.close()' to free server memory.

3. SYNTAX & CODE SNIPPET:
import mysql.connector

con = mysql.connector.connect(host="localhost", user="root", password="tiger", database="SchoolDB")

# Create the cursor
cur = con.cursor()

# Use cursor to send SQL command
cur.execute("SHOW TABLES;")

# Clean up
cur.close()
con.close()

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
