1. CORE CONCEPT SUMMARY:
The connect() factory method initiates a TCP/IP network connection to the MySQL server and returns an active Connection object.

2. KEY EXAMINATION POINTS:
  (1) Syntax: 'con = mysql.connector.connect(host="localhost", user="root", password="your_pass", database="school")'
  (2) Essential Connection Parameters: host (server IP or 'localhost'), user (database username), password (credentials), database (target DB name).
  (3) Default MySQL port is 3306. If MySQL runs on a custom port, pass 'port=3307'.
  (4) Always close connections when tasks finish using 'con.close()' to prevent connection pool exhaustion.

3. SYNTAX & CODE SNIPPET:
import mysql.connector

# Establishing connection to local MySQL server
con = mysql.connector.connect(
    host="localhost",
    user="root",
    password="tiger",        # Replace with your MySQL password
    database="SchoolDB"      # Name of the database to connect to
)

print("Connection object:", con)

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
