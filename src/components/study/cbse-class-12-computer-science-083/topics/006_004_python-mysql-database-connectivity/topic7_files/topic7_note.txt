1. CORE CONCEPT SUMMARY:
Cursors in mysql.connector implement Python's iterator protocol, allowing direct iteration over result sets without calling fetchall() first.

2. KEY EXAMINATION POINTS:
  (1) Direct Cursor Loop: 'for row in cur:' automatically fetches rows one by one, saving memory on large tables.
  (2) Each row is a Python tuple: attributes are accessed by index: 'roll = row[0]', 'name = row[1]'.
  (3) Tuple unpacking in loop: 'for roll, name, marks in cur:' cleanly unpacks fields directly.
  (4) CBSE Exam Classic: Formatted display with column headers using string formatting: f"{row[0]:<10}{row[1]:<25}{row[2]:>8.2f}".

3. SYNTAX & CODE SNIPPET:
import mysql.connector

con = mysql.connector.connect(host="localhost", user="root", password="tiger", database="SchoolDB")
cur = con.cursor()

cur.execute("SELECT RollNo, SName, Stream, Marks FROM Student WHERE Stream = 'Science';")

print("-" * 55)
print(f"{'Roll No':<10}{'Name':<25}{'Stream':<12}{'Marks':>8}")
print("-" * 55)

# Direct iteration over cursor object
for roll, name, stream, marks in cur:
    print(f"{roll:<10}{name:<25}{stream:<12}{marks:>8.2f}")

print("-" * 55)

cur.close()
con.close()

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
