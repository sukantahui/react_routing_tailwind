MASTER TEACHER SUKANTA HUI'S GOLDEN RULES FOR 100% MARKS IN PYTHON-MYSQL CONNECTIVITY:
1. NEVER FORGET con.commit(): Without it, any INSERT, UPDATE, or DELETE will NOT be saved to the MySQL table!
2. UNIVERSAL PLACEHOLDER '%s': Regardless of whether the column is INT, FLOAT, DATE, or VARCHAR, always use '%s' in mysql.connector.
3. SINGLE-ELEMENT TUPLE: When passing one parameter, always remember the trailing comma: (param, ).
4. ALWAYS CLOSE RESOURCES: Use cur.close() and con.close() in a finally block to avoid leaking connection sockets.
5. EXCEPTION HANDLING: Wrap database operations in try-except catching mysql.connector.Error.
