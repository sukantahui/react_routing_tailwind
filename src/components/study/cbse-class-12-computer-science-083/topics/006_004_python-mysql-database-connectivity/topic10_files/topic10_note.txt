1. CORE CONCEPT SUMMARY:
Network outages, duplicate keys, invalid passwords, or syntax errors throw mysql.connector.Error exceptions. Try-except blocks ensure graceful handling.

2. KEY EXAMINATION POINTS:
  (1) Catching Database Errors: 'except mysql.connector.Error as err: print(f"Error: {err}")'
  (2) Key Error Attributes: 'err.errno' contains the numerical MySQL error code (e.g. 1062 for Duplicate entry), 'err.msg' contains description.
  (3) The finally block ensures database connections and cursors are safely closed even when unhandled exceptions occur.
  (4) Safe transaction pattern: try -> execute -> con.commit() -> except -> con.rollback() -> finally -> con.close().

3. SYNTAX & CODE SNIPPET:
import mysql.connector

con = None
try:
    con = mysql.connector.connect(host="localhost", user="root", password="tiger", database="SchoolDB")
    cur = con.cursor()
    
    # Attempting to insert duplicate primary key
    cur.execute("INSERT INTO Student VALUES (101, 'Duplicate', 'Arts', 75.0);")
    con.commit()
    print("Record saved!")
except mysql.connector.Error as err:
    print(f"Database Error [{err.errno}]: {err.msg}")
    if con:
        con.rollback()
finally:
    if con and con.is_connected():
        cur.close()
        con.close()
        print("Database connection safely closed.")

4. CBSE COMMON PITFALLS:
Always remember to commit transactions and close both cursor and connection.
