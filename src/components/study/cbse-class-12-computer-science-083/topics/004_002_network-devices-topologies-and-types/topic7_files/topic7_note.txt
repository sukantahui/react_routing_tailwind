1. FUNDAMENTAL DEFINITION:
   - A network node that serves as an entrance and translator between two completely dissimilar network architectures using fundamentally different communication protocol suites.
   - Operating OSI Layer: Operates at ALL layers of the OSI model, especially the Transport, Session, Presentation, and Application Layers (Layers 4 through 7).
   - "Protocol Converter": The defining characteristic of a Gateway is its ability to translate data formats, control codes, and addressing between incompatible protocol stacks.

3. COMMON REAL-WORLD GATEWAYS:
   - Voice over IP (VoIP) Gateway:
     * Converts digital IP voice packets (SIP/RTP) into traditional analog circuit-switched telephone voice signals (PSTN / PBX).
   - Email Gateway:
     * Translates messages between dissimilar mail messaging systems (e.g. SMTP to X.400 or proprietary messaging).
   - Payment Gateway:
     * Securely encrypts and translates payment authorization messages between merchant websites and banking transaction networks.
   - Cloud / API Gateway:
     * Acts as an entry point for external client HTTP/REST requests, translating them into internal microservice protocols (gRPC, message queues).

4. TERMINOLOGY CLARIFICATION (CBSE BOARD CONTEXT):
   - In basic home/office networking, the term "Default Gateway" often colloquially refers to the local router connecting the LAN to the ISP.
   - In theoretical Computer Science board examination definitions, a true "Gateway" is strictly a PROTOCOL CONVERTER connecting dissimilar network architectures!
