1. CORE NETWORK DEVICES COMPARISON SUMMARY
================================================================================
Device      OSI Layer  Intelligence  Collision Domains  Key Function
--------------------------------------------------------------------------------
Modem       Layer 1    Low           N/A                Modulates digital to analog; demodulates back
NIC         Layer 2    Hardware      1 (point-to-point) Contains 48-bit burned-in MAC address
RJ-45       Physical   Passive       N/A                8P8C modular connector for Cat5e/Cat6 UTP
Hub         Layer 1    Zero (Dumb)   1 (Shared by all)  Multiport repeater; broadcasts all incoming bits
Switch      Layer 2    Intelligent   1 per Port         Packet forwarding via dynamic MAC CAM table
Repeater    Layer 1    Zero          Shared             Regenerates attenuated digital electrical signals
Router      Layer 3    High          1 per Interface    Routes packets across subnets via IP addressing
Gateway     Layers 1-7 Highest       Protocol Bridge    Translates between completely dissimilar protocol suites
Access Point Layer 2   Intelligent   1 (Shared RF)      Bridges 802.11 wireless to 802.3 wired Ethernet

2. NETWORK TOPOLOGIES AT A GLANCE
================================================================================
Topology   Structure                   Fault Tolerance   Cabling Cost  CBSE Board Recommendation
--------------------------------------------------------------------------------
Bus        Single shared backbone      Low (Backbone break) Low         Legacy only; terminators mandatory
Star       Central Switch / Hub        High (Cable break) Medium       RECOMMENDED for modern buildings & labs
Tree       Hierarchical Star-Bus       High (Branch iso)   Medium-High  RECOMMENDED for multi-block campus
Mesh       Dedicated point-to-point    Extreme (High red) Very High    Critical infrastructure (WAN core)
Ring       Continuous unidirectional   Low (Single loop)   Medium       Deterministic token passing

Formula for Links in Full Mesh: Links = N * (N - 1) / 2
Ports required per device in Full Mesh: N - 1

4. EXAM GOLDEN RULES FOR CBSE CASE-STUDY (4 MARKS)
================================================================================
- Place the SERVER in the block with the MAXIMUM NUMBER OF COMPUTERS (80-20 rule).
- Install a SWITCH/HUB in EVERY BLOCK to connect local workstations.
- Install a REPEATER along links EXCEEDING 100 METERS if UTP is used.
- Install a ROUTER/MODEM/GATEWAY for connecting the campus LAN to the external ISP or disparate WAN.
- Choose STAR topology inside each building, and STAR or TREE topology across multiple buildings.
