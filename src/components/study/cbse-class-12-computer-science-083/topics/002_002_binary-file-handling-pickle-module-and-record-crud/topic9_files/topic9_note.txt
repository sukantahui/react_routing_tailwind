1. THE COMPLETE 5-OPERATION CRUD BLUEPRINT
   - [C] CREATE / ADD: Appends new dictionary record in 'ab' mode.
   - [R] READ / DISPLAY: Traverses all records in 'rb' mode using EOFError loop.
   - [U] UPDATE: Uses temp.dat to locate record by Roll No and update marks.
   - [D] DELETE: Uses temp.dat to filter out record by Roll No.
   - [S] SEARCH: Locates record by Roll No and displays details.
