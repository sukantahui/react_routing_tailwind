1. CORE CONCEPT SUMMARY:
MIN() and MAX() find the minimum and maximum values in a column. Unlike SUM/AVG, they work on numbers, dates, and text strings.

2. KEY EXAMINATION POINTS:
  (1) Numeric data: MIN returns lowest number, MAX returns highest number.
  (2) Date data: MIN returns earliest/oldest date (chronologically first), MAX returns latest/most recent date.
  (3) String/Text data: MIN returns alphabetically first string (ASCII order), MAX returns alphabetically last string.
  (4) NULL values are ignored by both MIN() and MAX().

3. SYNTAX & CODE SNIPPET:
-- Numbers: Min and Max Price
SELECT MIN(Price) AS CheapestItem, MAX(Price) AS MostExpensive FROM Item;

-- Dates: Oldest and Youngest Employee Joining Date
SELECT MIN(DOJ) AS SeniorMostJoinDate, MAX(DOJ) AS LatestJoinDate FROM Employee;

-- Strings: Alphabetical boundaries
SELECT MIN(EName) AS FirstAlphaName, MAX(EName) AS LastAlphaName FROM Employee;
