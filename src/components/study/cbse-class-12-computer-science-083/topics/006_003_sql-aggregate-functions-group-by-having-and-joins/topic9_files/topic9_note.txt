1. CORE CONCEPT SUMMARY:
Table aliases provide concise substitute names for relations in the FROM clause, simplifying references to common attribute names.

2. KEY EXAMINATION POINTS:
  (1) Syntax: 'FROM Employee E, Department D' assigns alias 'E' to Employee and 'D' to Department.
  (2) Disambiguation: When two tables have columns with identical names, use dot notation: 'E.DeptId = D.DeptId'.
  (3) Once a table alias is declared in the FROM clause, it MUST be used throughout the SELECT, WHERE, and JOIN clauses instead of the original table name.
  (4) Table aliases improve query readability and are essential for self-joins and complex equi-joins.

3. SYNTAX & CODE SNIPPET:
-- Concise Multi-Table Query with Table Aliases:
SELECT E.EmpId, E.EName, D.DeptName, D.Location 
FROM Employee E, Department D 
WHERE E.DeptId = D.DeptId;

4. CBSE COMMON PITFALLS:
Ensure correct placement of WHERE before GROUP BY and HAVING after GROUP BY.
