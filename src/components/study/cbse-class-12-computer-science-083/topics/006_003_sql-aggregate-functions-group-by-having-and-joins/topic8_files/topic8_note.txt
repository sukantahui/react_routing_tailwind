1. CORE CONCEPT SUMMARY:
The Cartesian Product combines every tuple of the first table with every tuple of the second table. In CBSE exams, calculating degree and cardinality is guaranteed.

2. KEY EXAMINATION POINTS:
  (1) Syntax: 'SELECT * FROM TableA, TableB;' or 'SELECT * FROM TableA CROSS JOIN TableB;'
  (2) Cardinality Rule: Total rows = Cardinality(TableA) × Cardinality(TableB).
  (3) Degree Rule: Total columns = Degree(TableA) + Degree(TableB).
  (4) CBSE Exam Classic: If TableA has 5 rows & 3 columns, and TableB has 4 rows & 2 columns: Degree = 3 + 2 = 5; Cardinality = 5 × 4 = 20.

3. SYNTAX & CODE SNIPPET:
-- Cartesian Product query:
SELECT * FROM Student, Stream;

-- If Student has 4 rows (RollNo, Name, StreamId)
-- and Stream has 3 rows (StreamId, StreamName)
-- Result will contain 4 * 3 = 12 rows, and 3 + 2 = 5 columns!

4. CBSE COMMON PITFALLS:
Ensure correct placement of WHERE before GROUP BY and HAVING after GROUP BY.

5. REVISION CHECKLIST:

  [ ] Remember WHERE cannot contain aggregate functions; use HAVING.
  [ ] Know Cartesian Product formulas: Cardinality = R1 * R2, Degree = C1 + C2.
  [ ] Always include (N - 1) join conditions when joining N tables.
