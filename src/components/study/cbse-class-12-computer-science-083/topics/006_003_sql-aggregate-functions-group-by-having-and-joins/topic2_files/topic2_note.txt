1. CORE CONCEPT SUMMARY:
SUM() computes the mathematical sum of numeric values, while AVG() calculates the arithmetic mean. Both ignore NULL values entirely.

2. KEY EXAMINATION POINTS:
  (1) Both SUM() and AVG() operate strictly on numeric attributes (INT, FLOAT, DECIMAL).
  (2) NULL values are completely omitted from both the numerator (sum) and denominator (count) in AVG().
  (3) CBSE Exam Classic: If Marks column has [80, 90, NULL], SUM(Marks) is 170. AVG(Marks) is 170 / 2 = 85.0 (NOT 170 / 3!).
  (4) SUM(DISTINCT col) sums only the unique values in the column.

3. SYNTAX & CODE SNIPPET:
-- Computing total and average sales commissions
SELECT 
  SUM(Commission) AS TotalCommissionPaid,
  AVG(Commission) AS AvgCommissionPerSalesperson
FROM Salesperson;

-- Notice: Salespeople with NULL Commission are excluded from both SUM and AVG.
