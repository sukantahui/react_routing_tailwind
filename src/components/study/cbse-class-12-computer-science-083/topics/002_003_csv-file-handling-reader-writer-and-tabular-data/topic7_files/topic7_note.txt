TOPIC 7: MATHEMATICAL AGGREGATIONS ON CSV DATA

1. WHAT ARE AGGREGATIONS?
- Mathematical summarization across multiple rows of a column:
  * Sum / Total (total_marks += float(row[3]))
  * Count of records (count += 1)
  * Average / Mean (average = total / count)
  * Maximum / Highest (if val > max_val: max_val = val)
  * Minimum / Lowest (if val < min_val: min_val = val)

2. CORE IMPLEMENTATION PATTERN:
  total = 0.0
  count = 0
  max_marks = -1.0
  topper_name = ""

  with open('students.csv', 'r', newline='') as f:
      reader = csv.reader(f)
      header = next(reader) # skip header
      for row in reader:
          if not row: continue
          marks = float(row[3])
          total += marks
          count += 1
          if marks > max_marks:
              max_marks = marks
              topper_name = row[1]

  avg_marks = total / count if count > 0 else 0

3. DIVISION BY ZERO PROTECTION:
- Always check 'if count > 0:' before dividing by count to compute average, protecting against empty datasets.
