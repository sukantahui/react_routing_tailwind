2. SEARCHING BY PRIMARY KEY / IDENTIFIER:
- Searching for a specific student by Roll Number or Admission Number:

  found = False
  for row in reader:
      if row[0] == target_roll:
          print("Record Found:", row)
          found = True
          break
  if not found:
      print("Record not found!")
