1. COMPLETE MODULE 1 CONCEPTS RECAPITULATION
   - Stream abstraction: Flow of characters between RAM and secondary storage.
   - Access Modes:
     * 'r'  : Read-only (requires file to exist).
     * 'w'  : Write-only (creates or truncates to 0 bytes).
     * 'a'  : Append-only (creates if missing, appends at EOF).
     * 'r+' : Read and Write (preserves data, overwrites in-place).
     * 'w+' : Write and Read (wipes to 0 bytes upon opening!).
     * 'a+' : Append and Read (creates if missing, reads via seek).
   - Reading:
     * read()      -> Full string.
     * read(n)     -> Up to n characters.
     * readline()  -> One line (preserves \n, '' at EOF).
     * readlines() -> List of lines.
     * for line in f -> Memory-efficient streaming.
   - Writing:
     * write(s)    -> Writes string, no automatic \n.
     * writelines(L) -> Writes list of strings, NO automatic newlines between items!
   - File Pointer:
     * tell()      -> Current byte position.
     * seek(offset, whence=0) -> Moves cursor. (0: start, 1: curr, 2: end).
   - Safe Management:
     * with open(...) as f -> Context manager ensuring automatic closure.
