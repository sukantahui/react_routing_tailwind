CRITICAL RULES FOR TEXT FILES:
1. 'r' is default mode; FileNotFoundError occurs if file is missing.
2. 'w' creates or truncates the file to 0 bytes.
3. 'a' appends data to the end without truncation.
4. seek(offset, 0) moves from beginning. In text mode, non-zero offsets from current/end are invalid.
5. tell() returns the integer byte position of the file pointer.
6. 'with open(...) as f:' ensures deterministic file closure.
