2. MALWARE TAXONOMY SUMMARY
================================================================================
- Virus: Requires host file (.exe, doc); requires user execution to replicate.
- Worm: Standalone; replicates autonomously across networks without human action.
- Trojan Horse: Disguised as legitimate software; does NOT self-replicate; drops backdoors.
- Ransomware: Encrypts files with strong cryptography; demands extortion payment.
- Spyware / Keylogger: Covertly monitors user activity and captures typed keystrokes.

================================================================================
3. CYBER ATTACKS & DEFENSE SUMMARY
================================================================================
- Phishing: Deceptive social engineering emails/sites stealing credentials.
- DoS vs DDoS: Single attacking source (DoS) vs thousands of zombie botnet nodes (DDoS).
- Spoofing: Forging IP address, Email sender, or DNS resolution mappings.
- Firewall: Filters network traffic based on ACL rules (Hardware vs Software).
- Ethical Hacker: Authorized penetration tester with legal, constructive intent.
- Cracker: Unauthorized cybercriminal breaking into systems with malicious intent.
