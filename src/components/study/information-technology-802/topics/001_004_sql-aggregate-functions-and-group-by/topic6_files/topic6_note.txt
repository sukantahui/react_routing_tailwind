1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] WHERE Clause: Filters individual row tuples before grouping. CANNOT contain aggregate functions (e.g. WHERE AVG(Salary) > 50000 is ILLEGAL).
[2] HAVING Clause: Filters aggregated group summaries after grouping. CAN contain aggregate functions (e.g. HAVING AVG(Salary) > 50000).
[3] Syntax Order: SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY ...
[4] If a condition does NOT involve aggregate functions, it is more efficient to place it in WHERE.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- HAVING vs WHERE Demonstration
USE SchoolDB;

-- Find Streams with an Average Score >= 90.00 and having more than 1 student
SELECT 
  Stream,
  COUNT(*) AS StudentCount,
  AVG(TotalMarks) AS AvgStreamScore
FROM Student
WHERE TotalMarks >= 50.00          -- Row-level filter: Exclude failures before grouping
GROUP BY Stream
HAVING AVG(TotalMarks) >= 90.00    -- Group-level filter: Only streams with average >= 90
   AND COUNT(*) > 1;

--------------------------------------------------------------------------------
"100% Guaranteed Board Question: 'Difference between WHERE and HAVING'. WHERE filters records BEFORE grouping. HAVING filters groups AFTER aggregation. Aggregate functions are NEVER allowed in WHERE! — Sukanta Hui"
