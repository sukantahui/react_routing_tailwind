1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] The GROUP BY clause collapses rows sharing identical categorical values into summary group tuples.
[2] Syntax: SELECT CategoryCol, AGG_FUNC(ValueCol) FROM Table GROUP BY CategoryCol;
[3] Standard SQL Rule: Any column in the SELECT list that is NOT inside an aggregate function MUST be present in the GROUP BY clause.
[4] Each group produces exactly ONE summary output row.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Categorical Summarization using GROUP BY
USE SchoolDB;

-- 1. Summary Statistics per Academic Stream
SELECT 
  Stream,
  COUNT(*) AS StudentCount,
  AVG(TotalMarks) AS AverageMarks,
  MAX(TotalMarks) AS TopScore,
  MIN(TotalMarks) AS LowestScore
FROM Student
GROUP BY Stream;

-- 2. Stock Value Totals per Asset Type
SELECT 
  Category,
  SUM(Units) AS TotalUnitsHeld,
  SUM(Value) AS TotalPortfolioValue
FROM STOCKDATA
GROUP BY Category;

3. TEACHER'S MENTOR ADVICE:
--------------------------------------------------------------------------------
"Rule of Thumb: Whatever column you put in GROUP BY (e.g. Stream), you can safely write in SELECT (SELECT Stream, AVG(Marks) ...). Never put un-grouped columns in SELECT! — Sukanta Hui"
