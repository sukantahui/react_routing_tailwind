1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] MAX(column): Returns the highest or latest scalar value in the column.
[2] MIN(column): Returns the lowest or earliest scalar value in the column.
[3] Numeric columns: Returns the largest / smallest mathematical number.
[4] Date columns: MIN returns the oldest (earliest) date; MAX returns the most recent (latest) date.
[5] String columns: MIN returns the alphabetically first string (A-Z); MAX returns the alphabetically last string.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Extreme Value Discovery on Numbers, Dates, and Text
USE SchoolDB;

-- CBSE Classic Question: SELECT MAX(Fee), MIN(Fee) FROM COACH;
SELECT 
  MAX(TotalMarks) AS HighestScore,
  MIN(TotalMarks) AS LowestScore,
  MIN(AdmissionDate) AS EarliestAdmission,
  MAX(AdmissionDate) AS LatestAdmission,
  MIN(FullName) AS AlphabeticallyFirstStudent,
  MAX(FullName) AS AlphabeticallyLastStudent
FROM Student;
