1. WHAT IS PRODUCTION DEPLOYMENT?
--------------------------------------------------------------------------------
Production Deployment is the process of releasing the fully tested and verified web application onto live cloud or web servers (such as Apache Tomcat, AWS, Nginx, or Google Cloud) so that end-users across the world can access it via standard web browsers.

Key Deployment Steps:
1. Staging Environment Rehearsal: Testing final database migration scripts and configurations on a sandbox clone of the production environment.
2. Domain & DNS Mapping: Pointing human-readable domain names (e.g. `www.codernaccotax.co.in`) to the web server's public IP address.
3. SSL/TLS Certificate Setup: Installing cryptographic SSL certificates to enable secure, encrypted HTTPS traffic with the green padlock icon.
4. Database Production Migration: Executing normalized SQL DDL schema scripts and populating essential seed data.
5. Environment Variables & Secret Configuration: Safely configuring database credentials, API keys, and JWT secrets outside source code.

2. THE FOUR TYPES OF SOFTWARE MAINTENANCE (CRUCIAL FOR CBSE)
--------------------------------------------------------------------------------
Software maintenance accounts for 60% to 80% of total lifecycle effort. CBSE Class 12 IT 802 categorizes maintenance into four distinct types:

A. Corrective Maintenance (Fixing Live Errors):
   - Purpose: Diagnosing and repairing bugs, runtime crashes, and calculation errors discovered by users after deployment.
   - Example: A consumer reports that an electricity bill invoice is deducting ₹10 extra during UPI checkout. Developers fix the billing calculation logic immediately.

B. Adaptive Maintenance (Adapting to Environmental Changes):
   - Purpose: Modifying the web application to adapt to changes in external hardware, operating systems, legal tax laws, or third-party APIs.
   - Example: Updating the billing application's tax calculation formulas to comply with a revised Indian GST tax slab (e.g. from 18% to 12%), or updating code for Chrome version 130 compatibility.

C. Perfective Maintenance (Enhancing Performance & Features):
   - Purpose: Improving software performance, query execution speed, UI responsiveness, or adding convenient new features requested by users.
   - Example: Adding a "Download Monthly Statement as Excel / PDF" button and Dark Mode UI theme to the electricity billing portal based on consumer feedback.

D. Preventive Maintenance (Preventing Future Failures):
   - Purpose: Proactively refactoring code, updating dependencies, creating automated backups, and optimizing database indexes to prevent potential future failures before they ever happen.
   - Example: Upgrading MySQL 5.7 to MySQL 8.0 and patching OpenSSL libraries to eliminate security vulnerabilities prior to any cyberattack.

3. CONTINUOUS USER FEEDBACK INTEGRATION & THE FEEDBACK LOOP
--------------------------------------------------------------------------------
Web application development is an ongoing iterative lifecycle. Once deployed, systems establish structured feedback channels:
- In-App Rating & Feedback Modals
- Customer Support Helpdesk Tickets
- Web Analytics (Traffic drop-off points, page load latencies)

The Feedback Loop:
  [LIVE DEPLOYMENT] 
        |
        v
  [USER FEEDBACK & METRICS] 
        |
        v
  [STAGE 1: REQUIREMENT DEFINITION for Version 2.0]
        |
        v
  [STAGE 2: DESIGN] -> [STAGE 3: CODING] -> [STAGE 4: TESTING] -> [NEW DEPLOYMENT]

4. DELIVERABLES OF POST-DEVELOPMENT PHASE
--------------------------------------------------------------------------------
1. Live Production Deployment URL with valid HTTPS certificate
2. Service Level Agreement (SLA) & Uptime Monitoring Dashboard
3. Maintenance Logs & Bug Patch History (Hotfix Release Notes)
4. User Feedback Analytics Reports & Feature Roadmap for Version 2.0

5. KEY CBSE BOARD EXAM TAKEAWAYS
--------------------------------------------------------------------------------
- "Which maintenance type fixes bugs found by live users?" -> Corrective Maintenance.
- "Which maintenance type updates software for new tax regulations or OS changes?" -> Adaptive Maintenance.
- "Which maintenance type adds new features or speeds up performance?" -> Perfective Maintenance.
- "Which maintenance type prevents future system breakdowns proactively?" -> Preventive Maintenance.
- "What does DNS do during deployment?" -> Maps domain URLs to server IP addresses.
