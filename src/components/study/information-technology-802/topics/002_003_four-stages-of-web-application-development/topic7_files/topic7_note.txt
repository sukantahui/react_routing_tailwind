2. 10-POINT MASTER REVISION CHECKLIST FOR CBSE PRE-BOARD EXAMS
--------------------------------------------------------------------------------
[ ] 1. I can enumerate and explain the 4 sequential stages of web development in exact order.
[ ] 2. I know that Stage 1 answers "WHAT" the system does, and Stage 2 answers "HOW" it will work and look.
[ ] 3. I know that the Software Requirements Specification (SRS) is the primary deliverable of Stage 1.
[ ] 4. I can explain the 3-Tier Architecture (Presentation Tier, Application Tier, Data Tier) and give examples.
[ ] 5. I understand database normalization (1NF, 2NF, 3NF) and the roles of Primary Key & Foreign Key.
[ ] 6. I know why PreparedStatement with parameter placeholders (?) is mandatory in JDBC to block SQL Injection.
[ ] 7. I know that executeUpdate() runs INSERT/UPDATE/DELETE, while executeQuery() runs SELECT and returns a ResultSet.
[ ] 8. I can distinguish Unit Testing, Integration Testing, System Testing, Regression Testing, and UAT (Beta Testing).
[ ] 9. I can define the 4 types of maintenance: Corrective (bugs), Adaptive (tax/OS changes), Perfective (new features/speed), and Preventive (proactive upgrades).
[ ] 10. I can analyze real-world case study prompts and accurately identify the exact development phase and deliverable.
