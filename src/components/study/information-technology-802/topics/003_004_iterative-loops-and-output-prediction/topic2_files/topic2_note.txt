1. WHAT IS A WHILE LOOP?
--------------------------------------------------------------------------------
The `while` loop is an entry-controlled loop in Java that evaluates a Boolean 
expression before every iteration. If the condition is true, the statements 
within the block execute; if false, the loop terminates immediately.

2. SYNTAX AND CONTROL FLOW
--------------------------------------------------------------------------------
Syntax:
    while (boolean_expression) {
        // Statements to execute repeatedly
        // Variable update expression
    }

Execution Steps:
1. Java evaluates `boolean_expression`.
2. If `true`, the body statements execute sequentially.
3. The control variable is modified (incremented/decremented).
4. Flow loops back to step 1 to re-evaluate `boolean_expression`.
5. If `false` at any evaluation, control exits to the statement following `}`.

3. DEFINITE VS INDEFINITE ITERATION
--------------------------------------------------------------------------------
* Definite Iteration: The exact number of iterations is known before entering 
  the loop (e.g., repeating 10 times from i = 1 to 10). `for` loop is most popular.
* Indefinite Iteration: The number of iterations cannot be predicted in advance 
  because it depends on real-time inputs or runtime conditions (e.g., reading until 
  sentinel value `-1` or extracting digits until `num == 0`). `while` loop is best.

4. CLASSIC ALGORITHMS USING WHILE LOOPS
--------------------------------------------------------------------------------
A. Sum of Digits Extraction:
   int n = 582, sum = 0;
   while (n > 0) {
       sum += (n % 10);  // Extracts last digit (2, then 8, then 5)
       n = n / 10;       // Removes last digit (58, then 5, then 0)
   }
   Result: sum = 15.

B. Number Reversal Algorithm:
   int num = 481, rev = 0;
   while (num != 0) {
       int rem = num % 10;
       rev = (rev * 10) + rem;
       num = num / 10;
   }
   Result: rev = 184.

5. COMMON TRAPS & BEST PRACTICES
--------------------------------------------------------------------------------
1. Accidental Semicolon: `while (x < 10); { x++; }` creates an infinite loop 
   on the empty statement because `x++` is never reached.
2. Missing Update: Forgetting `x++` or `x--` leaves the condition permanently 
   true, freezing the application.
