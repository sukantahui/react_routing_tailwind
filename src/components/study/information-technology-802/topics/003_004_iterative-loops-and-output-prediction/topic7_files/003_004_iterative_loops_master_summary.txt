1. CORE CONCEPTS SUMMARY
--------------------------------------------------------------------------------
* Loop Components: Initialization, Condition, Body, Update Expression.
* Entry-Controlled (while, for): Condition tested BEFORE body. Min runs: 0.
* Exit-Controlled (do-while): Condition tested AFTER body. Min runs: 1.
* Semicolon Alert: `do { ... } while(condition);` MUST have a semicolon.
  `while(condition);` creates an empty body loop!

2. DRY RUNNING OUTPUT PREDICTION (CBSE FAVORITE)
--------------------------------------------------------------------------------
Snippet:
    int num = 5;
    do {
        System.out.println(num + 2);
        --num;
    } while (num >= 2);

Output:
7
6
5
4

Final value of num: 1

3. JUMP STATEMENTS
--------------------------------------------------------------------------------
* `break;`: Terminates the entire enclosing loop immediately.
* `continue;`: Skips the remaining statements in the current iteration only.
