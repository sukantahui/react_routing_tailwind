1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] By default, SELECT returns all matching rows, including duplicate values (the default is ALL).
[2] The DISTINCT keyword filters out repeated duplicate tuples from the displayed result set.
[3] Syntax: SELECT DISTINCT col1, col2 FROM table_name;
[4] DISTINCT applies to the combination of all projected columns in the SELECT list.
[5] DISTINCT only affects the displayed output; it never deletes duplicate rows from the underlying physical table.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- DISTINCT Demonstration
USE SchoolDB;

-- 1. All rows (Shows repeated cities)
SELECT City FROM Student;

-- 2. Eliminating duplicate cities (Unique list)
SELECT DISTINCT City FROM Student;

-- 3. DISTINCT across multiple columns (Unique Stream + City combinations)
SELECT DISTINCT Stream, City FROM Student;
