1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] AND operator: Evaluates to TRUE only if BOTH surrounding conditions are TRUE.
[2] OR operator: Evaluates to TRUE if AT LEAST ONE surrounding condition is TRUE.
[3] NOT operator: Inverts the boolean truth value of a condition.
[4] Precedence Rule: NOT has highest precedence, followed by AND, and lastly OR (NOT > AND > OR).
[5] Use parentheses `(...)` to override default precedence and ensure explicit condition grouping.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Logical Operators & Precedence Benchmark
USE SchoolDB;

-- 1. AND: Both conditions must hold
SELECT * FROM Student 
WHERE Stream = 'Science' AND TotalMarks >= 85;

-- 2. OR: Either condition suffices
SELECT * FROM Student 
WHERE City = 'Barrackpore' OR City = 'Shyamnagar';

-- 3. Demonstrating Precedence: AND evaluates before OR
-- Fetches (Commerce with Marks > 90) OR anyone in Science regardless of marks
SELECT * FROM Student 
WHERE Stream = 'Science' OR Stream = 'Commerce' AND TotalMarks > 90;

-- 4. Overriding Precedence with Parentheses
-- Fetches anyone in (Science OR Commerce) who has Marks > 90
SELECT * FROM Student 
WHERE (Stream = 'Science' OR Stream = 'Commerce') AND TotalMarks > 90;

--------------------------------------------------------------------------------
