1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] The WHERE clause filters rows returned by SELECT, updated by UPDATE, or removed by DELETE.
[2] Relational Operators: = (equal), <> or != (not equal), < (less than), > (greater than), <= (less than or equal), >= (greater than or equal).
[3] String Comparisons: WHERE Stream = 'Science' (Case-insensitive by default in standard MySQL collations).
[4] Date Comparisons: WHERE AdmissionDate >= '2025-01-01'.
[5] Relational operators evaluate each row to TRUE, FALSE, or UNKNOWN.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Relational Operator Query Lab
USE SchoolDB;

-- 1. Exact Equality & Non-Equality
SELECT * FROM Student WHERE City = 'Barrackpore';
SELECT * FROM Student WHERE City <> 'Kolkata';

-- 2. Range & Numeric Comparisons
SELECT RollNo, FullName, TotalMarks 
FROM Student 
WHERE TotalMarks >= 90.00;

-- 3. Date Comparisons
SELECT * FROM Student 
WHERE AdmissionDate < '2025-04-01';
