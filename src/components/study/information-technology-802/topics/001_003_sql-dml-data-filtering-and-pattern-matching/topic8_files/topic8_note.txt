1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] Starting with a specific character/string: LIKE 'A%' or LIKE 'Dr.%'
[2] Ending with a specific character/string: LIKE '%a' or LIKE '%Roy'
[3] Containing a substring anywhere: LIKE '%Kumar%' (matches at start, middle, or end)
[4] Specific character position: LIKE '_a%' (2nd letter is 'a'), LIKE '__u%' (3rd letter is 'u')
[5] Starting and ending with specific letters: LIKE 'S%h' (Starts with S and ends with h)
[6] Fixed length strings: LIKE '___' (exactly 3 characters long)

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- CBSE Board Pattern Recipes
USE SchoolDB;

-- Recipe 1: Names containing 'Kumar' anywhere
SELECT RollNo, FullName FROM Student WHERE FullName LIKE '%Kumar%';

-- Recipe 2: Names starting with 'S' and ending with 'a'
SELECT RollNo, FullName FROM Student WHERE FullName LIKE 'S%a';

-- Recipe 3: Second letter is 'u' and total at least 4 letters
SELECT RollNo, FullName FROM Student WHERE FullName LIKE '_u__%';

-- Recipe 4: Cities of exactly 6 characters starting with 'K'
SELECT DISTINCT City FROM Student WHERE City LIKE 'K_____';
