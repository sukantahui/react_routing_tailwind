1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] The LIKE operator performs pattern matching on string and character columns.
[2] Percent Wildcard (%): Matches ANY string of zero, one, or multiple arbitrary characters.
[3] Underscore Wildcard (_): Matches EXACTLY ONE single character at that specific position.
[4] LIKE is case-insensitive by default in standard MySQL character sets (e.g. utf8mb4_general_ci).
[5] NOT LIKE inverts the pattern match, selecting strings that do NOT conform to the pattern.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Wildcard Demonstration
USE SchoolDB;

-- Percent (%) matches 0 or more chars:
SELECT * FROM Student WHERE FullName LIKE 'M%';        -- Starts with M
SELECT * FROM Student WHERE FullName LIKE '%a';        -- Ends with a
SELECT * FROM Student WHERE FullName LIKE '%sh%';      -- Contains 'sh' anywhere

-- Underscore (_) matches exactly 1 character:
SELECT * FROM Student WHERE FullName LIKE '_a%';       -- 2nd letter is 'a'
SELECT * FROM Student WHERE City LIKE '_____';         -- Exactly 5 characters long

3. TEACHER'S MENTOR ADVICE:
--------------------------------------------------------------------------------
"Remember: `%` = 0 or many characters, `_` = strictly 1 character. If a question asks for 'names with exactly 4 letters', write `LIKE '____'` (4 underscores)! — Sukanta Hui"
