1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] DELETE FROM removes specific row tuples from a table based on a WHERE criteria.
[2] Syntax: DELETE FROM table_name WHERE condition;
[3] Omitting the WHERE clause (DELETE FROM table_name;) deletes all records, leaving an empty table structure with cardinality 0.
[4] DELETE is a DML command (transactional and row-by-row); DROP and TRUNCATE are DDL commands.
[5] DROP TABLE destroys the table blueprint completely from the data dictionary.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Safe Record Deletion
USE SchoolDB;

-- 1. Conditional Deletion: Remove inactive or graduated students
DELETE FROM Student 
WHERE Stream = 'Science' AND TotalMarks < 40;

-- 2. Deleting specific record by Primary Key
DELETE FROM Student 
WHERE RollNo = 105;

-- 3. To empty the table completely while keeping columns:
-- DELETE FROM Student; -- Cardinality becomes 0, Degree remains unchanged.
