1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] The UPDATE statement modifies existing column values within table rows.
[2] Standard Syntax: UPDATE table_name SET col1 = expr1, col2 = expr2 WHERE condition;
[3] The SET clause specifies column assignments; multiple assignments are separated with commas.
[4] The WHERE clause acts as a safety gate. Omitting WHERE modifies EVERY row in the entire table!
[5] Unlike ALTER TABLE (which alters schema structure), UPDATE modifies table contents/instances.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Safe vs Mass UPDATE Demonstration
USE CompanyDB;

-- 1. Safe Conditional UPDATE (Affects only matching rows)
UPDATE Employee 
SET Department = 'Research & Development', BasicSalary = 65000.00
WHERE EmpNo = 104;

-- 2. Multi-column Update with Arithmetic Calculation
UPDATE Employee 
SET Commission = 5000.00, Grade = 'A'
WHERE BasicSalary > 60000;

-- WARNING: Omitting WHERE updates all rows in table
-- UPDATE Employee SET Status = 'Active'; -- Applies to every tuple!

3. TEACHER'S MENTOR ADVICE:
--------------------------------------------------------------------------------
