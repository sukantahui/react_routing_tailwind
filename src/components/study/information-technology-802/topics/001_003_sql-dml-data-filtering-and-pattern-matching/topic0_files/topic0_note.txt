1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] INSERT INTO is a core DML command that appends new row tuples to an existing table.
[2] Syntax 1 (All columns in schema order): INSERT INTO table_name VALUES (v1, v2, v3...);
[3] Syntax 2 (Explicit column projection): INSERT INTO table_name (col1, col3) VALUES (v1, v3);
[4] Literal Quoting Rule: Character strings ('Amit') and Dates ('2026-10-08') MUST be enclosed in single quotes.
[5] Numeric Literals (Integers, Decimals) and the keyword NULL must NOT be enclosed in quotes.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Master INSERT INTO Demonstration
USE SchoolDB;

-- 1. Inserting full row tuples in exact column order
INSERT INTO Student VALUES 
  (101, 'Mamata Sharma', '2008-04-12', 92.50, 'Barrackpore', 'Science'),
  (102, 'Susmita Roy', '2007-11-23', 88.00, 'Shyamnagar', 'Science'),
  (103, 'Debangshu Pal', '2008-01-19', 95.00, 'Kolkata', 'Commerce');

-- 2. Inserting with explicit column list (Omitted columns take DEFAULT or NULL)
INSERT INTO Student (RollNo, FullName, Stream) 
VALUES (104, 'Ajoy Sen', 'Humanities');

-- Verify inserted tuples
SELECT * FROM Student;
