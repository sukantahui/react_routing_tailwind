1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] NULL represents missing, unassigned, or unknown information in a relational database.
[2] Three-Valued Logic (3VL): SQL conditions evaluate to TRUE, FALSE, or UNKNOWN.
[3] Any equality or arithmetic comparison with NULL (e.g. Comm = NULL or Comm != NULL) yields UNKNOWN.
[4] Since WHERE clauses only accept rows that evaluate strictly to TRUE, `WHERE Comm = NULL` returns 0 rows!
[5] Always use the dedicated operators `IS NULL` and `IS NOT NULL` to test for missing values.

2. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- 3-Valued Logic and NULL Demonstration
USE CompanyDB;

-- WRONG (Will return 0 rows!):
-- SELECT * FROM Employee WHERE Commission = NULL;

-- CORRECT: Using IS NULL
SELECT EmpNo, EmpName, BasicSalary, Commission 
FROM Employee 
WHERE Commission IS NULL;

-- CORRECT: Using IS NOT NULL
SELECT EmpNo, EmpName, BasicSalary, Commission 
FROM Employee 
WHERE Commission IS NOT NULL;

-- Arithmetic with NULL yields NULL:
SELECT EmpName, BasicSalary + Commission AS TotalPay 
FROM Employee; -- If Commission is NULL, TotalPay becomes NULL!

3. TEACHER'S MENTOR ADVICE:
--------------------------------------------------------------------------------
"Master this rule: You can NEVER use `=` with NULL. Always write `WHERE Column IS NULL` or `WHERE Column IS NOT NULL`. Writing `= NULL` is an immediate point loss in board exams! — Sukanta Hui"
