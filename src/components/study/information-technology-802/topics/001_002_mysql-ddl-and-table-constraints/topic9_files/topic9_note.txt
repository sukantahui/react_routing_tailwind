1. CORE CONCEPT SUMMARY:
--------------------------------------------------------------------------------
[1] DESCRIBE table_name (or DESC table_name): Displays the structural specification of a table in a 6-column tabular layout (Field, Type, Null, Key, Default, Extra).
[2] Field: Column attribute name.
[3] Type: MySQL data type and length.
[4] Null: Indicates whether the column accepts NULL values (YES or NO).
[5] Key: Indicates indexing status (PRI for Primary Key, UNI for Unique, MUL for non-unique secondary index or Foreign Key).
[6] Default: Displays the default fallback value assigned to the column.
[7] Extra: Displays special attributes like `auto_increment`.
[8] SHOW CREATE TABLE table_name: Outputs the exact complete SQL statement required to reconstruct the table.

2. THEORETICAL BREAKDOWN:
--------------------------------------------------------------------------------
--- 1. Deconstructing the DESCRIBE Output Table ---
When you execute `DESCRIBE Student;`, MySQL outputs a diagnostic table:

```text
+-----------+-------------+------+-----+---------+----------------+
| Field     | Type        | Null | Key | Default | Extra          |
+-----------+-------------+------+-----+---------+----------------+
| RollNo    | int         | NO   | PRI | NULL    | auto_increment |
| Name      | varchar(50) | NO   |     | NULL    |                |
| Email     | varchar(80) | YES  | UNI | NULL    |                |
| City      | varchar(30) | YES  |     | Kolkata |                |
+-----------+-------------+------+-----+---------+----------------+
```

- **PRI in Key column:** Identifies the Primary Key.
- **UNI in Key column:** Identifies a Unique column constraint.
- **MUL in Key column:** Identifies a Foreign Key or non-unique indexed column.


3. PRACTICAL SQL BENCHMARK SCRIPT:
--------------------------------------------------------------------------------
-- Schema Inspection Commands Showcase
CREATE TABLE InventoryItem (
    ItemID INT PRIMARY KEY AUTO_INCREMENT,
    ItemName VARCHAR(60) NOT NULL,
    SKUCode CHAR(8) UNIQUE NOT NULL,
    UnitPrice DECIMAL(8,2) NOT NULL DEFAULT 0.00,
    StockQuantity INT NOT NULL DEFAULT 0,
    LastRestocked DATE
);

DESCRIBE InventoryItem;
-- or shorthand:
DESC InventoryItem;

SHOW CREATE TABLE InventoryItem;
