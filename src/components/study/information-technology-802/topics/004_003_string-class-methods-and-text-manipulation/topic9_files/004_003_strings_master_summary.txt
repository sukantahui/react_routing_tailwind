1. STRING IMMUTABILITY & REASSIGNMENT
--------------------------------------------------------------------------------
* Strings cannot be modified in-place.
* Methods return new String objects.
* Always reassign: `str = str.concat(" text");`

2. MASTER STRING METHODS SUMMARY
--------------------------------------------------------------------------------
Method                | Return Type | Description / Example
----------------------|-------------|-------------------------------------------
`str.length()`        | `int`       | Total character count (with spaces)
`str.indexOf(ch)`     | `int`       | 0-based first occurrence; -1 if not found
`str.replace(a, b)`   | `String`    | Replaces all occurrences of target
`str.concat(s)`       | `String`    | Appends string to end
`str.toUpperCase()`   | `String`    | Converts to uppercase letters
`str.toLowerCase()`   | `String`    | Converts to lowercase letters
`str.substring(s, e)` | `String`    | Slices from s (inclusive) to e (exclusive)
`str.equals(s2)`      | `boolean`   | Compares character content case-sensitively
`str.equalsIgnoreCase`| `boolean`   | Compares character content case-insensitively
`s1 == s2`            | `boolean`   | Compares memory addresses in heap/SCP

4. `str.substring(start, end)` excludes the character at `end`.
