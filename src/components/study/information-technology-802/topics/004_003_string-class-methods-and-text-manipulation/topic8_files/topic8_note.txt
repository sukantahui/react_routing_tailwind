1. THE STANDARD 4-MARK SECTION B QUESTION
--------------------------------------------------------------------------------
Question Prompt:
Given the string: `String str = "Information Technology";`
Write individual Java statements to do the following:
(i)   Find the position of character 's' in `str`
(ii)  Find the length of `str`
(iii) Replace the word "Technology" with "Science" in `str`
(iv)  Concatenate " for me" at the end of `str`

2. MASTER SOLUTIONS & TRACES
--------------------------------------------------------------------------------
Part (i): Position of 's'
Statement: `int pos = str.indexOf('s');`
Explanation: Searches for 's'. Since 's' is not present in "Information Technology", 
it returns `-1`.

Part (ii): Length of `str`
Statement: `int len = str.length();`
Explanation: Returns total characters (11 + 1 + 10 = `22`).

Part (iii): Replace word
Statement: `String res = str.replace("Technology", "Science");`
// or `str = str.replace("Technology", "Science");`
Explanation: Returns `"Information Science"`.

Part (iv): Concatenate text
Statement: `String res = str.concat(" for me");`
// or `str = str.concat(" for me");`
Explanation: Returns `"Information Technology for me"`.
