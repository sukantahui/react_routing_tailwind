1. CORE ARRAY FUNDAMENTALS
--------------------------------------------------------------------------------
* 1D Arrays: Homogeneous elements stored in contiguous heap memory.
* Length Property: `arr.length` (Property, no parentheses).
* Index Range: `0` to `arr.length - 1`.
* Literal Initialization: `double[] Marks = {93.0, 87.5, 97.5, 65.0, 70.0};`

2. JAVA.UTIL.ARRAYS UTILITIES
--------------------------------------------------------------------------------
* Package Import: `import java.util.Arrays;`
* Sorting: `Arrays.sort(arr);` (In-place ascending order).
* Binary Search: `Arrays.binarySearch(arr, key);` (Requires sorted array).
* Return values of Binary Search:
  - If found: Returns 0-based index.
  - If not found: `-(insertion_point) - 1`.
