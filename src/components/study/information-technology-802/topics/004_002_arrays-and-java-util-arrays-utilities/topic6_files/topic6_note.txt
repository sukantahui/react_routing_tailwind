1. WHAT IS ARRAYS.BINARYSEARCH()?
--------------------------------------------------------------------------------
`Arrays.binarySearch()` is a fast logarithmic search algorithm ($O(\log N)$) 
that searches a sorted array for a specified target key.

Import Requirement:
    import java.util.Arrays;

2. RETURN VALUE RULES
--------------------------------------------------------------------------------
Case 1: Key is Found in Array
Returns the positive or zero index where `arr[index] == key`.
Example: `int[] a = {10, 20, 30, 40, 50};`
`Arrays.binarySearch(a, 30)` -> Returns `2` (Index 2).

Case 2: Key is NOT Found in Array
Returns a negative value indicating where it would be inserted:
Formula:
    return_value = -(insertion_point) - 1

Example: Searching for 25 in `{10, 20, 30, 40, 50}`:
- 25 belongs between 20 (index 1) and 30 (index 2).
- Insertion point = index 2.
- Return value = -(2) - 1 = `-3`.

3. WHY -(INSERTION_POINT) - 1?
--------------------------------------------------------------------------------
If Java returned `-insertion_point`, an element belonging at index 0 would return 
`-0 = 0`, which would be confused with a successful match at index 0! 
The `- 1` guarantees that all unfound elements return negative values strictly `<= -1`.
