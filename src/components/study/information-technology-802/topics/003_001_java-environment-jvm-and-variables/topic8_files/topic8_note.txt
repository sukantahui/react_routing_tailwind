Q1: Differentiate between Java Source Code and Java Bytecode.
Model Answer:
- Java Source Code: High-level human-readable code written in `.java` files by developers. Cannot be executed directly by hardware CPU.
- Java Bytecode: Platform-independent intermediate machine code for the JVM, generated by the `javac` compiler and stored in `.class` files (Magic Number: `0xCAFEBABE`).

Q2: Explain the purpose of the 'final' keyword with respect to variables in Java with an example.
Model Answer:
- The `final` keyword is used to declare constants in Java. Once a final variable is assigned an initial value, its value becomes immutable and cannot be modified or reassigned.
- Example: `final double PI = 3.14159;`
- Attempting to reassign `PI = 3.14;` generates a compile-time error: "cannot assign a value to final variable PI".

Q3: Why is 'char' 2 bytes in Java unlike in C/C++ where it is 1 byte?
Model Answer:
- In C/C++, `char` uses 1 byte (8 bits) based on ASCII encoding (256 characters).
- In Java, `char` uses 2 bytes (16 bits) to conform to the international Unicode standard (0 to 65,535 / '\u0000' to '\uffff'), enabling Java to represent characters from all global languages (including Bengali, Hindi, Japanese, Arabic, etc.).

Q4: Explain the role and relationship between JDK, JRE, and JVM in Java architecture.
Model Answer:
1. JVM (Java Virtual Machine): The abstract runtime engine that loads, verifies, and executes compiled bytecode (.class) natively on the host processor.
2. JRE (Java Runtime Environment): Package containing JVM + Core Java Class Libraries (rt.jar / java.base). Needed by end-users to run Java applications.
   * Formula: JRE = JVM + Core Class Libraries
3. JDK (Java Development Kit): Full development environment containing JRE + Development Tools (javac compiler, debugger, javadoc). Needed by software developers to write and compile code.
   * Formula: JDK = JRE + Development Tools (javac)

Q5: Identify and explain all syntax errors in the following code snippet:
```java
public class Demo {
    public static void main(String[] args) {
        float price = 99.50;
        char grade = "A";
        double discount% = 10.0;
        system.out.println(price);
    }
}
```
Model Answer:
1. `float price = 99.50;` -> Error: 99.50 is double by default. Correction: `float price = 99.50f;`
2. `char grade = "A";` -> Error: Double quotes denote String. Correction: `char grade = 'A';`
3. `double discount% = 10.0;` -> Error: '%' is an illegal character in identifiers. Correction: `double discountPercent = 10.0;`
4. `system.out.println(...)` -> Error: 'system' must start with capital 'S'. Correction: `System.out.println(...)`

Q6: Describe the memory architecture of the Java Virtual Machine (JVM), explaining the purpose of Heap, Stack, Method Area, PC Register, and Execution Engine.
Model Answer:
1. Method Area (Metaspace): Shared across all threads. Stores class metadata, method bytecodes, static variables, and runtime constant pool.
2. Heap Memory: Shared memory pool where all instantiated objects and arrays created with `new` reside. Managed automatically by Garbage Collector.
3. Java Stack: Private to each thread. Stores Stack Frames for active method invocations containing local primitive variables and method call states. Pops frame on method exit.
4. Program Counter (PC) Register: Holds the memory address of the currently executing JVM bytecode instruction for that thread.
5. Execution Engine:
   - Interpreter: Executes bytecode opcodes line-by-line.
   - JIT Compiler: Compiles frequently executed hotspots into native machine code.
   - Garbage Collector (GC): Frees unreferenced memory from Heap.
