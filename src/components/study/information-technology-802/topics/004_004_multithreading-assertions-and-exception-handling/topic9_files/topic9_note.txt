1. SKILL PRACTICE HIGHLIGHTS:
-----------------------------
- Test your ability to trace multithreaded outputs, assertion conditions with `-ea`, and try-catch-finally control flows.
- Review error symptoms:
  * `IllegalThreadStateException`: Multiple calls to `start()`.
  * `AssertionError`: Failed invariant with `-ea`.
  * `NumberFormatException`: Decimal strings or words passed to `Integer.parseInt()`.
  * `NullPointerException`: Methods called on `null` object references.
  * `ArrayIndexOutOfBoundsException`: Index < 0 or index >= array length.
