1. MASTER TRANSFORMATION CATALOG (AFFIRMATIVE <===> NEGATIVE)
--------------------------------------------------------------------------------
+---+----------------------------+-----------------------------+-------------------------------+
| # | Affirmative Pattern        | Negative Equivalent         | Exemplar Transformation       |
+---+----------------------------+-----------------------------+-------------------------------+
| 1 | Adjective + Noun           | not + Antonym               | "He is honest" -> "not dis..."|
| 2 | Only / Alone (Person)      | None but                    | "Only Swadeep" -> "None but.."|
| 3 | Only (Inanimate Object)    | Nothing but                 | "Only books" -> "Nothing but" |
| 4 | Only (Age / Number)        | Not more than / Not less    | "Only ten" -> "Not more than" |
| 5 | As soon as ... , ...       | No sooner did/had ... than  | "As soon as he came, than..." |
| 6 | Too ... to + Verb          | so ... that + cannot/could  | "Too weak to walk" -> "so weak"|
| 7 | Every + Noun               | There is no ... but         | "Every mother" -> "There is no"|
| 8 | Must + Verb                | cannot but / cannot help    | "Must submit" -> "cannot but" |
| 9 | Always + Verb              | never + Antonym             | "Always remember" -> "Never f"|
|10 | Both ... and ...           | Not only ... but also       | "Both A and B" -> "Not only.."|
|11 | Where there is A, is B     | There is no A without B     | "Smoke/fire" -> "No smoke w/o"|
+---+----------------------------+-----------------------------+-------------------------------+

--------------------------------------------------------------------------------
2. THE 'NO SOONER' TEMPORAL INVARIANT
--------------------------------------------------------------------------------
Formula A: [ NO SOONER DID ] + [ SUBJECT ] + [ V1 (BASE) ] + ... + [ THAN ] + [ CLAUSE 2 ]
Formula B: [ NO SOONER HAD ] + [ SUBJECT ] + [ V3 (PAST PART) ] + ... + [ THAN ] + [ CLAUSE 2 ]

CRITICAL EXAM TRAP:
- NEVER use 'when' or 'then' with 'No sooner'! (Correlative is strictly THAN).
- 'Hardly / Scarcely' take WHEN: "Hardly HAD he arrived WHEN the bell rang."

--------------------------------------------------------------------------------
3. BENGALI LEARNER BRIDGES
--------------------------------------------------------------------------------
* বাংলায় 'শুধু' বা 'কেবলমাত্র' বোঝাতে 'Only' বসে:
  - ব্যক্তির ক্ষেত্রে: 'None but' (কেউ নয় কেবল...)
  - বস্তুর ক্ষেত্রে: 'Nothing but' (কিছু নয় কেবল...)
  - বয়সের ক্ষেত্রে: 'Not more than' (এর বেশি নয়...)
