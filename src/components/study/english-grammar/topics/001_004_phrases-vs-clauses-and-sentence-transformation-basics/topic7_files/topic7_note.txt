1. THE EXCLAMATORY <===> ASSERTIVE TRANSFORMATION MATRIX
--------------------------------------------------------------------------------
+---+----------------------------------+---------------------------------------+
| # | Exclamatory Pattern              | Assertive Equivalent                  |
+---+----------------------------------+---------------------------------------+
| 1 | How + Adjective / Adverb         | Subject + Verb + VERY + Adj / Adv     |
| 2 | What a / an + Adj + Noun         | Subject + Verb + a VERY + Adj + Noun  |
| 3 | What a + Noun (no adjective)     | Subject + Verb + a GREAT / WONDERFUL  |
| 4 | Alas! + Clause                   | It is a matter of GREAT SORROW that...|
| 5 | Hurrah! + Clause                 | It is a matter of IMMENSE JOY that... |
| 6 | Bravo! + Clause                  | It is a matter of GREAT PRAISE that...|
| 7 | Fie! + Clause                    | It is extremely SHAMEFUL that...      |
| 8 | O that / If only / Would that    | I EARNESTLY WISH that...              |
| 9 | O for + Noun                     | I INTENSELY LONG / WISH for...        |
|10 | Had I but known ...              | I wish I had known ...                |
+---+----------------------------------+---------------------------------------+

--------------------------------------------------------------------------------
2. WORD ORDER MIGRATION MECHANISM
--------------------------------------------------------------------------------
* EXCLAMATORY ORDER (Fronting for emotional intensity):
  [ INTENSIFIER (How/What a) + DESCRIPTOR ] + [ SUBJECT ] + [ VERB ] !
  - "How brilliant Swadeep is!"

* ASSERTIVE ORDER (Restoration of grammatical baseline):
  [ SUBJECT ] + [ VERB ] + [ INTENSIFIER (very/great) + DESCRIPTOR ] .
  - "Swadeep is VERY brilliant."

--------------------------------------------------------------------------------
3. BENGALI LEARNER BRIDGES & COMMON EXAM TRAPS
--------------------------------------------------------------------------------
1. 'VERY' VS 'GREAT' USAGE:
   * With Adjectives -> use 'VERY' / 'EXTREMELY' ("very cold", "very beautiful").
   * With Nouns      -> use 'GREAT' / 'WONDERFUL' ("a great fool", "a great pity").

2. PUNCTUATION INTEGRITY:
   * Exclamatory MUST end with (!)
   * Transformed Assertive MUST end with (.)
