1. THE COMPLEX-TRANSITIVE ARCHITECTURE (জটিল সকর্মক গঠন - SVOC)
--------------------------------------------------------------------------------
An Object Complement (OC) follows the Direct Object (DO) and completes the 
predication by renaming, classifying, or describing that direct object.

CORE EQUATION: [DIRECT OBJECT]  ==  [OBJECT COMPLEMENT]

A. NOUN PHRASE OBJECT COMPLEMENT (Renaming / Role / Title):
   • "The cohort elected [Swadeep: DO] [captain: OC]." (Swadeep = Captain).
   • "They named [the mascot: DO] [Byte: OC]." (Mascot = Byte).

B. ADJECTIVE PHRASE OBJECT COMPLEMENT (Resultant State / Attribute):
   • "Mentor Sukanta Sir painted [the door: DO] [green: OC]." (Door = Green).
   • "His performance made [the mentor: DO] [proud: OC]." (Mentor = Proud).
   • "The court declared [the contract: DO] [null and void: OC]."

2. THE SVOO vs SVOC EQUALITY DIAGNOSTIC TEST (সমতা পরীক্ষা)
--------------------------------------------------------------------------------
To distinguish Ditransitive (SVOO) from Complex-Transitive (SVOC):

TEST: Insert 'IS / WAS' between the two postverbal nominals:
  • "They made [Debangshu] [team leader]" -> "Debangshu IS team leader" 
    [LOGICAL EQUALITY -> SVOC!]
  • "Swadeep gave [Debangshu] [a laptop]"   -> *"Debangshu IS a laptop"* 
    [ILLOGICAL / SEPARATE ENTITIES -> SVOO!]

3. MASTER CATALOG OF COMPLEX-TRANSITIVE VERBS
--------------------------------------------------------------------------------
1. VERBS OF APPOINTING / ELECTING: elect, appoint, choose, nominate, select, crown.
2. VERBS OF NAMING / CALLING: name, call, christen, dub, title.
3. VERBS OF COGNITION / JUDGING: consider, judge, believe, think, find, prove, deem.
4. VERBS OF CAUSATION / MAKING: make, render, keep, paint, leave.

4. PASSIVE VOICE TRANSFORMATION INVARIANT
--------------------------------------------------------------------------------
When an SVOC sentence is converted to PASSIVE VOICE:
  • Direct Object becomes the PASSIVE SUBJECT.
  • Object Complement becomes a SUBJECT COMPLEMENT.
  
  Active:  "They elected [Swadeep: DO] [captain: OC]."
  Passive: "[Swadeep: Subject] was elected [captain: Subject Complement] by them."

5. ESSENTIAL REVISION CHECKLIST
--------------------------------------------------------------------------------

[✓] Apply the Equality Test (DO == OC) to instantly distinguish SVOC from SVOO.
[✓] Understand how the active Object Complement transforms into a passive Subject Complement.
[✓] Recognize causative verbs (make, keep, render) and bare infinitive complements.
