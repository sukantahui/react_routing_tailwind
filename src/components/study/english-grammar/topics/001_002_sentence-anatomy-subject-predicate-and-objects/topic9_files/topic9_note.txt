1. HIERARCHICAL SENTENCE TREE SYNTACTIC BLUEPRINT
--------------------------------------------------------------------------------
Every grammatical English clause deconstructs into a two-branch binary node:

                           [ S (SENTENCE CLAUSE) ]
                                  /        \
                  [ NP (SUBJECT) ]          [ VP (PREDICATE) ]
                     /        \                /            \
             [Det / Adj]   [Head Noun]    [Finite Verb]   [Object / Comp / Adjunct]
                  |             |               |                    |
                 The         scholar        developed          a brilliant app

* NP (Noun Phrase): Contains the simple subject plus determiners, adjectives, 
  and prepositional modifier phrases.
* VP (Verb Phrase): Contains the finite verb, auxiliary verbs, direct objects, 
  indirect objects, subject/object complements, and adverbials.

--------------------------------------------------------------------------------

3. THE THREE MASTER TESTS FOR ACCURATE SENTENCE PARSING
--------------------------------------------------------------------------------
TEST A: EQUALITY TEST (SVO vs SVC)
* If Subject == Element after Verb -> SVC (Subject Complement)
  Example: "Debangshu is a developer." (Debangshu == developer -> SVC)
* If Subject != Element after Verb -> SVO (Direct Object)
  Example: "Debangshu hired a developer." (Debangshu != developer -> SVO)

TEST B: EQUALITY TEST (SVOO vs SVOC)
* If Object 1 != Object 2 -> SVOO (Indirect Object + Direct Object)
  Example: "She sent her sister a gift." (sister != gift -> SVOO)
* If Object 1 == Object 2 -> SVOC (Direct Object + Object Complement)
  Example: "They appointed her sister manager." (sister == manager -> SVOC)

TEST C: THE DATIVE SHIFT TEST (DITRANSITIVE PREPOSITIONING)
* S + V + IO + DO  <===>  S + V + DO + TO/FOR + IO
  Example: "He gave me a book" <===> "He gave a book TO me"
  Example: "She bought him tea" <===> "She bought tea FOR him"
* LATINATE VERB EXCEPTION: Verbs like 'explain, describe, suggest, announce'
  FORBID the SVOO pattern!
  INCORRECT: *He explained me the logic.
  CORRECT:    He explained the logic TO me. (SVOA pattern)

4. BENGALI LEARNER BRIDGES & COMMON EXAM TRAPS
--------------------------------------------------------------------------------
1. SOV vs SVO WORD ORDER:
   * Bengali Word Order (SOV): "স্বাদ্বীপ [S] সফটওয়্যার [O] তৈরি করেছে [V]।"
   * English Word Order (SVO): "Swadeep [S] created [V] the software [O]."
   * Common Trap: Placing objects before verbs or splitting verb phrases inappropriately.

2. SENSORY LINKING VERB TRAP:
   * Bengali: "চা-টি সুন্দর গন্ধ ছাড়ছে" / "খাবারটি সুস্বাদু লাগছে।"
   * INCORRECT: *The soup tastes deliciously.
   * CORRECT:    The soup tastes delicious. (SVC: Sensory Copular Verb + Adjective).

3. CAUSATIVE/COMPLEX-TRANSITIVE NO-INFINITIVE TRAP:
   * Verbs of making/naming/appointing take direct noun/adjective complements:
   * INCORRECT: *They made him to be captain. / *They elected him as president.
   * CORRECT:    They made him captain. / They elected him President. (SVOC).
