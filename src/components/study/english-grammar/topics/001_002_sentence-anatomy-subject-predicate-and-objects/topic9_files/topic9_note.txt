1. HIERARCHICAL SENTENCE TREE PROTOCOL
--------------------------------------------------------------------------------
                  [ S (SENTENCE CLAUSE) ]
                         /        \
           [ NP (SUBJECT) ]      [ VP (PREDICATE) ]
              /        \            /        \
         [Det/Adj]    [Head Noun] [Verb]   [Obj / Comp / Adv]

2. PARSING DIAGNOSTIC SUMMARY
--------------------------------------------------------------------------------
1. Find Finite Verb.
2. Ask "Who/What + Verb?" -> Extract Complete Subject NP.
3. Check Transitivity:
   - Intransitive: SV or SVA.
   - Transitive: SVO (DO), SVOO (IO + DO), SVOA (DO + Adv).
   - Linking (Copula): SVC (Subject Complement).
   - Complex-Transitive: SVOC (Direct Object + Object Complement).

3. BENGALI LEARNER BRIDGES
--------------------------------------------------------------------------------
* বাংলা বাক্যরীতি (SOV): "স্বাদ্বীপ [S] প্রোগ্রামটি [O] বানিয়েছে [V]।"
* ইংরেজি বাক্যরীতি (SVO): "Swadeep [S] developed [V] the program [O]."
* ট্রি পার্সিং ইংরেজি ও বাংলার এই পদবিন্যাসের পার্থক্যকে স্পষ্ট করে।
