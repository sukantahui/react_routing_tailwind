1. EXECUTIVE OVERVIEW & THE RSA ATTACK SURFACE TAXONOMY
--------------------------------------------------------------------------------
The security of the RSA cryptosystem rests upon the computational difficulty of integer 
prime factorization and modular algebra. However, flawed implementations, low exponents, 
and physical side-channel leaks can compromise RSA keys without breaking the underlying math:

  * MATHEMATICAL HARDNESS  : General Number Field Sieve (GNFS) requires 2^112 operations for RSA-2048.
  * STRUCTURAL ATTACK VECTORS: Low exponents (Wiener/Boneh-Durfee), algebraic flaws (Fermat/Pollard), 
                             side channels (SPA/Cache), and quantum computing (Shor's algorithm).

3. PHYSICAL & SIDE-CHANNEL VULNERABILITIES
--------------------------------------------------------------------------------

  * SIMPLE POWER ANALYSIS (SPA) & TIMING ATTACKS:
    - Variable-time Square-and-Multiply leaks private key bits through power oscilloscope traces.
    - Defense: Constant-time Montgomery Ladder + Cryptographic Blinding (C' = C * r^e mod N).

  * CPU CACHE-TIMING ATTACKS (Flush+Reload):
    - Memory table indexing in windowed exponentiation leaks table access patterns.
    - Defense: Constant-time branchless table lookups (load every element into registers).

  * HARVEST NOW, DECRYPT LATER (HNDL):
    - Adversaries record encrypted RSA traffic today to decrypt with quantum computers in the 2030s.
    - Defense: Pilot Hybrid Post-Quantum Key Encapsulation (X25519Kyber768Draft00) today.

6. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL RSA HARDENING HABITS:
  1. Always Enforce Full-Entropy Private Exponent d: Never truncate d to speed up decryption (Defeats Wiener/Boneh-Durfee).
  2. Implement Cryptographic Blinding: Decouples physical execution time from secret message bits.
  3. Pre-Verify CRT Signatures: Prevent Bellcore single-glitch hardware factorization attacks.
  4. Prepare for Post-Quantum Migration: Track NIST FIPS 203 ML-KEM hybrid key exchanges.

* COMMON BEGINNER HARDENING PITFALLS:
  - Choosing a small private exponent d to optimize decryption speed (Cracked in seconds by Wiener's attack).
  - Choosing primes too close together (Trivially factored by Fermat's difference of squares).
  - Generating smooth primes with small (p - 1) factors (Vulnerable to Pollard's p - 1 attack).
  - Transmitting unverified CRT signatures (Vulnerable to Bellcore laser fault injection).
