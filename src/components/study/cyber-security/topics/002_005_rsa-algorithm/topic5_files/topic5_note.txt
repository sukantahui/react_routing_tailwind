2. CANONICAL WORKED EXAMPLE 1 (p = 61, q = 53)
--------------------------------------------------------------------------------

  STEP 1 : COMPUTE PUBLIC MODULUS (N)
    - Primes: p = 61, q = 53
    - N = p * q = 61 * 53 = 3,233

  STEP 2 : COMPUTE GROUP ORDERS (phi(N) & lambda(N))
    - Euler's Totient:      phi(N) = (61 - 1) * (53 - 1) = 60 * 52 = 3,120
    - Carmichael's Totient: lambda(N) = lcm(60, 52) = (60 * 52) / gcd(60, 52) = 3120 / 4 = 780

  STEP 3 : SELECT PUBLIC ENCRYPTION EXPONENT (e)
    - Choose e = 17.
    - Verification: gcd(17, 3120) = 1 (Coprime, valid!).

  STEP 4 : DERIVE PRIVATE DECRYPTION EXPONENT (d)
    - Extended Euclidean Equation: (17 * d) ≡ 1 (mod 3120)
    - Bezout Solution: (17 * 2753) + (3120 * -15) = 1
    - Private Key: d = 2753  (Or via lambda(N): d = 413)

  STEP 5 : ENCRYPT PLAINTEXT MESSAGE (M = 65)
    - Plaintext: M = 65 (ASCII character 'A')
    - Ciphertext: C ≡ M^e (mod N) = 65^17 mod 3233 = 2,790

  STEP 6 : DECRYPT CIPHERTEXT (C = 2790)
    - Plaintext: M ≡ C^d (mod N) = 2790^2753 mod 3233 = 65 (ASCII 'A' RESTORED!)

--------------------------------------------------------------------------------
3. STEP-BY-STEP RSA-CRT GARNER RECOMBINATION TRACE
--------------------------------------------------------------------------------

  * PRE-COMPUTED CRT CONSTANTS:
    - d_p = 2753 mod (61 - 1) = 2753 mod 60 = 17
    - d_q = 2753 mod (53 - 1) = 2753 mod 52 = 25
    - q_inv = 53^(-1) mod 61 = 38  (Check: 53 * 38 = 2014 = 33 * 61 + 1 ≡ 1 mod 61)

  * GARNER DECRYPTION EXECUTION (C = 2790):
    1. m1 = (2790 % 61)^17 mod 61 = 45^17 mod 61 = 4
    2. m2 = (2790 % 53)^25 mod 53 = 34^25 mod 53 = 12
    3. h  = (q_inv * (m1 - m2)) mod p = (38 * (4 - 12)) mod 61 = -304 mod 61 = 1
    4. M  = m2 + h * q = 12 + 1 * 53 = 65 (EXACT MATCH!)

5. UNIVERSITY EXAMINATION STRATEGY (BCAC703 / MAKAUT)
--------------------------------------------------------------------------------

When solving RSA numerical questions in university exams:
  1. Always state the formula: N = p * q and phi(N) = (p - 1)(q - 1).
  2. Clearly show gcd(e, phi(N)) = 1 before computing the inverse.
  3. Draw the Extended Euclidean division tableau to derive d.
  4. Write out binary square-and-multiply powers rather than typing huge exponents.
  5. Conclude with both the ciphertext integer C and the decrypted verification M.

7. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL CALCULATION HABITS:
  1. Double Check gcd(e, phi(N)) == 1: If not coprime, no unique inverse d exists.
  2. Handle Negative Remainders in EEA: Always add phi(N) to get the canonical positive key d.
  3. Use Square-and-Multiply for Exponentiation: Avoid computing massive unreduced powers.
  4. Remember Pedagogical Limitations: Small primes are for learning; never use them in production!

* COMMON BEGINNER CALCULATION MISTAKES:
  - Computing phi(N) as p * q instead of (p - 1) * (q - 1).
  - Forgetting to take the modulo operation after each squaring step.
  - Mistaking public exponent e for private key d.
  - Confusing Euler's totient phi(N) with Carmichael's totient lambda(N).
