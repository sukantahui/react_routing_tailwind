1. EXECUTIVE OVERVIEW & MATHEMATICAL OPERATIONS
--------------------------------------------------------------------------------
RSA encryption and decryption transform integers across finite modular fields through 
asymmetric modular exponentiation:

  * ENCRYPTION : Ciphertext C ≡ M^e (mod N)   [Uses Public Key (e, N)]
  * DECRYPTION : Plaintext  M ≡ C^d (mod N)   [Uses Private Key (d, N)]
  * CORRECTNESS: (M^e)^d ≡ M^(e*d) ≡ M^(1 + k*phi(N)) ≡ M (mod N) for ALL integers M < N.

--------------------------------------------------------------------------------
2. UNIVERSAL PROOF OF RSA DECRYPTION (HANDLING gcd(M, N) > 1)
--------------------------------------------------------------------------------

While Euler's theorem strictly requires gcd(M, N) = 1, RSA decryption holds for ALL plaintexts M < N:

  1. MODULO PRIME p:
     - If p divides M:       M^(e*d) ≡ 0 ≡ M (mod p).
     - If p does not divide: By Fermat's Little Theorem: M^(p-1) ≡ 1 (mod p).
                             M^(e*d) = M^(1 + k(p-1)(q-1)) = M * (M^(p-1))^(k(q-1)) ≡ M * (1) ≡ M (mod p).

  2. MODULO PRIME q:
     - By identical logic:   M^(e*d) ≡ M (mod q).

  3. CHINESE REMAINDER THEOREM SYNTHESIS:
     - Since gcd(p, q) = 1:  M^(e*d) ≡ M (mod p * q) = M (mod N) unconditionally!

4. RSA-OAEP (OPTIMAL ASYMMETRIC ENCRYPTION PADDING)
--------------------------------------------------------------------------------

Under PKCS#1 v2.2 (RFC 8017), plaintext M is padded via a 2-round Feistel network:
  - Step 1: Form Data Block: DB = Hash(Label) || 0x00...01 || M
  - Step 2: Generate random 256-bit seed r via CSPRNG.
  - Step 3: MaskedDB = DB ⊕ MGF1( r, DB_Len )
  - Step 4: MaskedSeed = r ⊕ MGF1( MaskedDB, Seed_Len )
  - Step 5: EncodedMsg = 0x00 || MaskedSeed || MaskedDB
  - Step 6: Ciphertext C = (EncodedMsg)^e mod N (IND-CCA2 Provably Secure!)

--------------------------------------------------------------------------------
5. HIGH-SPEED DECRYPTION VIA RSA-CRT & GARNER'S FORMULA
--------------------------------------------------------------------------------

The private key computes RSA-CRT in 1/4th the CPU time:
  1. Compute: m1 = C^(d_p) mod p   (1024-bit exponentiation)
  2. Compute: m2 = C^(d_q) mod q   (1024-bit exponentiation)
  3. Garner Recombination:
         h = ( q_inv * (m1 - m2) ) mod p
         M = m2 + h * q
  4. Cryptographic Blinding: Multiply C by r^e mod N to defeat timing side channels!

8. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL RSA OPERATION HABITS:
  1. Never Use Textbook RSA: Always enforce RSA-OAEP (RFC 8017) for encryption.
  2. Standardize on e = 65537: Provides ultra-fast encryption with 17 operations and immunity to cube root attacks.
  3. Deploy RSA-CRT with Blinding: Delivers a 4x decryption speedup with total side-channel immunity.
  4. Use Hybrid Cryptography: Encrypt symmetric AES-256 session keys with RSA rather than raw large files.

* COMMON BEGINNER OPERATIONAL MISTAKES:
  - Encrypting raw data directly with RSA without symmetric AES envelope encryption.
  - Using e = 3 with small unpadded messages (Vulnerable to standard cube root attacks).
  - Failing to randomize padding (Vulnerable to codebook dictionary search attacks).
  - Using unblinded RSA-CRT (Vulnerable to Bellcore fault injection and timing attacks).
