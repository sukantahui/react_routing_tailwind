1. EXECUTIVE OVERVIEW & NUMBER-THEORETIC FOUNDATIONS
--------------------------------------------------------------------------------
The RSA algorithm transforms abstract concepts of number theory into an impenetrable 
cryptographic vault. Its security is grounded in the Fundamental Theorem of Arithmetic 
and the algebraic properties of Euler's Totient function:

  * PRIME NUMBERS (p, q) : Random, massive 1024-bit integers with no divisors other than 1 and itself.
  * COMPOSITE MODULUS (N): Product of two primes: N = p * q (2048 bits / 617 decimal digits).
  * TRAPDOOR PROPERTY    : Forward multiplication takes microseconds; factoring N without p, q 
                           takes billions of classical CPU years using the General Number Field Sieve (GNFS).

--------------------------------------------------------------------------------
2. EULER'S TOTIENT FUNCTION & CARMICHAEL'S TOTIENT
--------------------------------------------------------------------------------

  1. EULER'S TOTIENT FUNCTION phi(N):
     - Definition: Counts the number of positive integers in [1, N-1] coprime to N (gcd(a, N) = 1).
     - For a Prime p: phi(p) = p - 1.
     - Multiplicative Property: For coprimes p and q:
             phi(N) = phi(p * q) = phi(p) * phi(q) = (p - 1) * (q - 1)

  2. CARMICHAEL'S TOTIENT lambda(N) [PKCS#1 v2.2 STANDARD]:
     - Definition: The smallest positive integer such that a^lambda(N) ≡ 1 (mod N).
     - Formula: lambda(N) = lcm(p - 1, q - 1) = [ (p - 1)(q - 1) ] / gcd(p - 1, q - 1).
     - Advantage: Produces a smaller valid private exponent d, speeding up RSA computations.

--------------------------------------------------------------------------------
3. EULER'S THEOREM & PROOF OF RSA DECRYPTION
--------------------------------------------------------------------------------

* EULER'S THEOREM:
  - If gcd(a, N) = 1, then:
                      a^phi(N) ≡ 1 (mod N)

* MATHEMATICAL PROOF OF RSA DECRYPTION:
  - By construction: e * d ≡ 1 (mod phi(N))  ==>  e * d = 1 + k * phi(N).
  - Encrypt: C ≡ M^e (mod N)
  - Decrypt: C^d ≡ (M^e)^d ≡ M^(e*d) ≡ M^(1 + k*phi(N)) ≡ M * (M^phi(N))^k ≡ M * (1)^k ≡ M (mod N).

5. INTEGER FACTORIZATION ATTACKS & HARDENING
--------------------------------------------------------------------------------

  * FERMAT'S FACTORIZATION (Close Primes):
    - If |p - q| is small, N = x^2 - y^2 factors N in seconds.
    - Rule: Enforce |p - q| > 2^(1024 - 100) bits during prime generation.

  * POLLARD'S p - 1 ATTACK (Smooth Primes):
    - If p - 1 has only small prime factors, gcd(2^M - 1, N) factors N in milliseconds.
    - Rule: Select "Strong Primes" where p - 1 = 2 * p' + 1 and p' is a huge prime.

  * GENERAL NUMBER FIELD SIEVE (GNFS):
    - Sub-exponential complexity L_N[1/3, c]. 2048-bit RSA requires 2^112 operations, 
      guaranteeing computational security against all classical supercomputers.

8. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL RSA MATHEMATICAL HABITS:
  1. Enforce 64-Round Miller-Rabin Testing: Guarantees error probability < 2^(-128).
  2. Use Carmichael's Totient lambda(N): Yields smaller private exponents d for faster operations.
  3. Ensure Large Prime Separation: Never generate primes where |p - q| is small (Defeats Fermat factoring).
  4. Securely Wipe p, q, and phi(N): Once key generation is complete, erase p, q, and phi(N) from RAM.

* COMMON BEGINNER NUMBER-THEORY MISTAKES:
  - Relying on Fermat's primality test (Fooled by Carmichael numbers like 561).
  - Choosing primes too close together (Trivially factored by Fermat's difference of squares).
  - Generating weak primes with smooth (p - 1) factors (Vulnerable to Pollard's p - 1 attack).
  - Storing Euler's totient phi(N) alongside the public key (Allows anyone to compute private key d).
