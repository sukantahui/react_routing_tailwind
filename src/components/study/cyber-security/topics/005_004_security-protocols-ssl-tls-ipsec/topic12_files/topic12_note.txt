1. THE NEED FOR FORMAL CRYPTOGRAPHIC PROTOCOL VERIFICATION
----------------------------------------------------------------------------------------------------
Human intuition and informal pen-and-paper security proofs frequently miss subtle race conditions, 
malleability flaws, and protocol state machine vulnerabilities. Formal Methods mathematically model 
protocols and systematically explore all possible execution states under an active adversary to prove 
whether security invariants hold.

The Dolev-Yao Adversary Model (1983):
The foundational standard for formal protocol verification assumes:
- The network is under total adversary control.
- The attacker can overhear, intercept, modify, delete, replay, and inject arbitrary messages.
- Cryptographic primitives (encryption, hashing, digital signatures) are treated as perfect black-box 
  mathematical abstractions (Attacker cannot break encryption without the key).


2. CORE SECURITY INVARIANTS & PROPERTIES TO PROVE
----------------------------------------------------------------------------------------------------
1. Secrecy (Confidentiality):
   - Proof that no sequence of adversary actions can allow the attacker to derive the secret session key $K$.
2. Injective Agreement (Authentication):
   - Proves that if Alice believes she has established a session with Bob, Bob indeed engaged in the session 
     with Alice, and both agree on all session parameters, with a strict 1-to-1 match (immune to replay).
3. Perfect Forward Secrecy (PFS):
   - Proves that compromising a party's long-term private identity key at time $T_2$ does NOT compromise 
     past session keys negotiated at time $T_1$.
4. Post-Compromise Security (PCS / Healing):
   - Proves that even if an ephemeral session key is compromised at time $T_1$, future session keys 
     automatically heal and regain confidentiality through cryptographic ratcheting.

4. HISTORIC CASE STUDY: FORMAL VERIFICATION OF TLS 1.3 (RFC 8446)
----------------------------------------------------------------------------------------------------
TLS 1.3 was the first major internet protocol developed in close collaboration with the academic 
formal verification community. Formal models in ProVerif and Tamarin proved:
- Full handshake 1-RTT and 0-RTT secrecy and non-injective agreement.
- Identified and fixed subtle 0-RTT replay vulnerabilities and key derivation separation bugs 
  BEFORE the RFC was published.
