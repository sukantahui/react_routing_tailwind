1. DEFINITION & THE ROLE OF AI / ML IN CYBERSECURITY
----------------------------------------------------------------------------------------------------
Machine Learning (ML) in Intrusion Detection Systems (IDS) applies statistical modeling, pattern recognition, 
and artificial neural networks to automatically discover malicious network behavior, detect zero-day attacks, 
and cluster anomalous data exfiltration streams across high-volume multi-gigabit network flows without 
relying on static manual signatures.


2. THE 3 MACHINE LEARNING PARADIGMS IN IDS
----------------------------------------------------------------------------------------------------
1. SUPERVISED LEARNING (Classification of Known Attack Types):
   - Algorithms: Random Forest, Support Vector Machines (SVM), XGBoost, Multi-Layer Perceptrons (MLP).
   - Training: Trained on labeled datasets (e.g., CIC-IDS2017, NSL-KDD) containing tagged "Normal" vs "DDoS", 
     "PortScan", "Botnet", "BruteForce".
   - Strength: Extremely high accuracy and low false-alarm rate on known attack families.
   - Limitation: Blind to novel zero-days whose patterns deviate from training labels.

2. UNSUPERVISED LEARNING (Zero-Day Outlier & Anomaly Detection):
   - Algorithms: Isolation Forest, DBSCAN Clustering, K-Means, Autoencoders (Deep Learning Reconstruction Error), 
     Local Outlier Factor (LOF).
   - Training: Requires NO labeled data. Models the intrinsic geometric density and clustering of unlabelled 
     network flows.
   - Strength: Ideal for discovering previously unseen zero-day exploits and covert lateral movement.
   - Limitation: Higher false-positive rates on noisy enterprise networks.

3. SEMI-SUPERVISED LEARNING (One-Class Classification):
   - Algorithms: One-Class SVM (OC-SVM), Deep Autoencoders.
   - Training: Trained exclusively on verified 100% clean baseline traffic. Anything that fails reconstruction 
     or falls outside the learned hyper-sphere is flagged as an intrusion.


3. AUTOENCODER DEEP LEARNING FOR ANOMALY DETECTION
----------------------------------------------------------------------------------------------------
An Autoencoder is a neural network trained to compress (Encoder) input flow feature vectors into a low-dimensional 
latent space ($Z$) and then reconstruct (Decoder) the original input ($X'$).

Mathematical Reconstruction Error Formulation:
  - Input Feature Vector: $X = [f_1, f_2, \dots, f_k]$ (e.g. packet count, byte size, IAT, entropy)
  - Reconstructed Output: $X' = \text{Decoder}(\text{Encoder}(X))$
  - Reconstruction Loss (Mean Squared Error - MSE):
    $$\text{MSE}(X, X') = \frac{1}{K} \sum_{j=1}^{K} (x_j - x'_j)^2$$
  - Decision Logic:
    - Normal Traffic: Low reconstruction loss ($\text{MSE} < \theta_{\text{threshold}}$).
    - Zero-Day Attack: Neural network cannot accurately reconstruct anomalous features ($\text{MSE} > \theta_{\text{threshold}}$), 
      triggering an Anomaly Intrusion Alert.


4. FEATURE EXTRACTION & ENGINEERING PIPELINE
----------------------------------------------------------------------------------------------------
Raw packet bytes cannot be fed directly into machine learning models. The IDS Feature Extractor converts 
bidirectional network flows into numerical feature vectors:
  - Temporal Features: Flow Duration, Packet Inter-Arrival Time (IAT Mean & Variance).
  - Volumetric Features: Forward/Backward Packet Count, Byte Volume, Bytes per Second.
  - Protocol Features: TCP Flag Ratios (SYN/ACK ratio, FIN ratio), TCP Window Size, Flow Shannon Entropy.


5. ADVERSARIAL MACHINE LEARNING ATTACKS
----------------------------------------------------------------------------------------------------
Adversaries employ specialized mathematical attacks to defeat AI-based IDS:
  1. Evasion Attacks (Adversarial Perturbation):
     - Injecting tiny, imperceptible delays or benign padding bytes into packet payloads to move the feature 
       vector across the classifier decision boundary without altering exploit functionality.
  2. Model Poisoning:
     - Injecting subtle malicious noise into training datasets over months, conditioning the baseline model 
       to accept malicious command-and-control beacons as normal traffic.
