1. DEFINITION & THE CORE DETECTION PHILOSOPHY
----------------------------------------------------------------------------------------------------
Intrusion Detection Systems employ two foundational detection methodologies to identify cyber threats:

1. SIGNATURE-BASED DETECTION (Misuse / Knowledge-Based Detection):
   - Compares incoming packet headers and payload byte sequences against an exact database of pre-compiled 
     exploit patterns, known malware hashes, and vulnerability signatures (e.g., Snort rules, Suricata rules, YARA).
   - Philosophy: "Block what is known to be evil."
   - Primary Strength: Near-zero false positives on well-crafted signatures; ultra-fast hardware execution 
     using multi-pattern string matching algorithms (Aho-Corasick DFA).
   - Primary Weakness: Completely blind to novel zero-day exploits, polymorphic code, and evasion variations.

2. ANOMALY-BASED DETECTION (Behavioral / Heuristic Detection):
   - Establishes a mathematical baseline model of "normal" network or host behavior during a learning period, 
     then flags any statistical deviation or abnormal activity that exceeds defined standard deviation thresholds.
   - Philosophy: "Block what is abnormal."
   - Primary Strength: Capable of detecting unknown zero-day attacks, stealthy insider data exfiltration, and 
     novel advanced persistent threats (APTs).
   - Primary Weakness: High false-positive rate triggered by legitimate shifts in user or business activity 
     (e.g., promotional campaigns, software deployments).


2. COMPREHENSIVE COMPARISON MATRIX: SIGNATURE VS ANOMALY DETECTION
----------------------------------------------------------------------------------------------------
+--------------------+------------------------------------+-----------------------------------------+
| CHARACTERISTIC     | SIGNATURE-BASED DETECTION          | ANOMALY-BASED / HEURISTIC DETECTION     |
+--------------------+------------------------------------+-----------------------------------------+
| Detection Principle| Pattern Matching against known CVEs| Statistical deviation from baseline norm|
| Zero-Day Attack    | ❌ Blind (0% detection capability) | ✔ Capable of detecting unknown exploits |
| False Positive Rate| Very Low (Near 0% on tuned rules)  | High (Legitimate spikes trigger alerts) |
| Initial Calibration| Minimal (Load rule set and run)    | Requires 14–30 day baseline learning    |
| Maintenance Need   | Constant daily signature updates   | Periodic baseline model recalibration   |
| Computation Method | Aho-Corasick Multi-Pattern DFA     | Gaussian Z-Score, PCA, Machine Learning |
| Resource Overhead  | Predictable, linear CPU usage      | High memory state tracking & math modeling|
+--------------------+------------------------------------+-----------------------------------------+


3. MULTI-PATTERN STRING MATCHING ALGORITHMS (AHO-CORASICK DFA)
----------------------------------------------------------------------------------------------------
In high-speed 10+ Gbps IDS sensors evaluating 30,000+ signatures simultaneously, naive linear string search 
is impossible.

The Aho-Corasick Algorithm:
  - Constructs a single trie (Deterministic Finite Automaton - DFA) from all 30,000 signature strings.
  - Ingests incoming packet payload bytes in a single pass ($O(N)$ where $N$ is packet length), transitioning 
    between states in constant time regardless of whether there are 10 or 50,000 signatures loaded.


4. STATISTICAL ANOMALY DETECTION MATHEMATICS (GAUSSIAN Z-SCORE)
----------------------------------------------------------------------------------------------------
Anomaly engines track time-series metrics (e.g., DNS queries per second, outbound bytes per host, Shannon entropy).

Mathematical Formulation:
  - Mean baseline ($\mu$) and standard deviation ($\sigma$) are calculated during the baseline period:
    $$\mu = \frac{1}{N} \sum_{i=1}^{N} x_i, \quad \sigma = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^2}$$
  - During live inspection, the engine calculates the Z-Score of the current observation ($x$):
    $$Z = \frac{x - \mu}{\sigma}$$
  - If $|Z| > 3.0$ (exceeding 3 standard deviations, representing 99.7% confidence in Gaussian distribution), 
    an Anomaly Intrusion Alert is generated.
