1. DEFINITION & THE UNIFIED SOC ARCHITECTURE
----------------------------------------------------------------------------------------------------
In modern enterprise cybersecurity, standalone intrusion sensors and deception traps operating in isolation 
create fragmented data silos. Security Operations Centers (SOCs) achieve holistic visibility by integrating 
Network IDS/IPS (Suricata, Snort), Host IDS (Wazuh, Sysmon), and Cyber Deception assets (Canarytokens, Honeynets) 
into a centralized Security Information and Event Management (SIEM) and Security Orchestration, Automation, 
and Response (SOAR) platform.


2. THE 4-STAGE TELEMETRY PIPELINE: INGESTION TO CONTAINMENT
----------------------------------------------------------------------------------------------------
1. DISTRIBUTED INGESTION & DATA STREAMING:
   - Sensors emit structured telemetry (Suricata `eve.json`, Wazuh alerts, Cowrie JSON) to high-throughput 
     message queues (Apache Kafka, Fluentbit, Vector).
2. NORMALIZATION & PARSING:
   - Translates diverse vendor formats into a standardized schema: Elastic Common Schema (ECS) or Open 
     Cybersecurity Schema Framework (OCSF).
3. SIEM MULTI-SOURCE CORRELATION:
   - Rule Correlation Engines link disparate events sharing common 5-tuples (SrcIP, DstIP, Timestamp) 
     or user accounts across a 5-minute sliding window.
   - Example: NIDS Alert (SQL Injection Probe) + Honeypot Decoy Hit (100% True Positive) + Endpoint EDR 
     (Process Injection) ➔ High-Severity Consolidated Incident!
4. SOAR AUTOMATED PLAYBOOK EXECUTION:
   - Executes zero-touch response actions within 500 milliseconds: dynamically pushes firewall block rules, 
     isolates compromised host in EDR, revokes Active Directory sessions, and opens ticketing records.


3. THE TRIAGE CONE: REDUCING 100,000 ALERTS TO ACTIONABLE INCIDENTS

4. STATUTORY INDIAN CERT-IN COMPLIANCE & LEGAL MANDATES
----------------------------------------------------------------------------------------------------
Under statutory directives issued by the Indian Computer Emergency Response Team (CERT-In) and the Digital 
Personal Data Protection (DPDP) Act 2023:
  1. Mandatory 180-Day Immutable Log Retention:
     - All SIEM logs, firewall events, IDS/IPS alerts, honeypot telemetry, and DNS queries must be preserved 
       within Indian jurisdiction for a minimum of 180 days.
  2. NPL India NTP Clock Synchronization:
     - All servers, routers, and sensors must synchronize system clocks with the National Physical Laboratory (NPL) 
       India or authorized national NTP stratum-1 servers to ensure legally undisputed forensic timestamps.
  3. Mandatory 6-Hour Incident Reporting:
     - Any confirmed cybersecurity breach or ransomware incident must be reported to CERT-In within 6 hours 
       of identification.
