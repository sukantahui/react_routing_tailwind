1. EXECUTIVE OVERVIEW & IDENTITY MASQUERADE THEORY
--------------------------------------------------------------------------------
A Masquerade (or Identity Spoofing) Attack occurs when an unauthorized entity pretentiously 
assumes the digital identity of a legitimate authorized user, device, or service to gain 
unauthorized privileges, trust, or access. This violates the AUTHENTICITY and INTEGRITY pillars:

  * THE ESSENCE OF MASQUERADE :
    - Unlike passive eavesdropping which silently listens, masquerade actively manufactures 
      false digital credentials:
        Forged Identity : I_fake ➔ Claims to be I_legitimate (Admin, Gateway, Bank Domain)
        Target Response : System grants root access, redirects money, or accepts malicious routes.

  * THE ROOT CAUSE :
    - Legacy protocols (IPv4, SMTP, DNS, ARP, HTTP, BGP) were designed without built-in 
      cryptographic source authentication, blindly trusting header values.

3. CRYPTOGRAPHIC & PROTOCOL AUTHENTICATION PILLARS
================================================================================

1. EMAIL AUTHENTICATION TRIO (SPF, DKIM, DMARC) :
   - SPF (Sender Policy Framework): Published in DNS TXT; lists authorized sending IPs.
   - DKIM (DomainKeys Identified Mail): Cryptographic digital signature over email body.
   - DMARC: Enforces strict alignment policy (`p=reject` drops unauthenticated emails).

2. DNSSEC (DOMAIN NAME SYSTEM SECURITY EXTENSIONS) :
   - Cryptographically signs DNS Resource Record Sets (RRsets) with Zone Signing Keys (ZSK).
   - Validates parent-child delegation through Delegation Signer (DS) hashes up to ICANN Root.

3. UNICAST REVERSE PATH FORWARDING (uRPF / BCP 38) :
   - Strict Mode: Drops packets if source IP is not reachable via the incoming interface FIB table.
   - Completely eliminates forged source IP packets at ISP and enterprise borders.

4. FIDO2 / WEBAUTHN PASSKEY AUTHENTICATION :
   - Origin-Bound Cryptography: Challenge signed with hardware private key bound to browser domain.
   - Phishing sites (`fake-bank.in`) cannot harvest or reuse WebAuthn credentials!

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 66C   : Identity theft & password spoofing (Up to 3 Years Prison + ₹1 Lakh Fine).
    - Section 66D   : Cheating by Personation using Computer Resource (Up to 3 Years Prison + ₹1 Lakh Fine).
    - Section 43    : Civil liability up to ₹1 CRORE for unauthorized access via spoofed identity.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5)  : Mandates reasonable technical security safeguards (MFA/Anti-Spoofing).
    - Section 33    : Penalties up to ₹250 CRORES for systemic data breaches caused by identity masquerade.
