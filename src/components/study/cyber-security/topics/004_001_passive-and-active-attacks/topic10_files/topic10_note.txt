1. EXECUTIVE OVERVIEW & ZERO TRUST ARCHITECTURE THEORY
--------------------------------------------------------------------------------
Unlike passive attacks that silently eavesdrop, active attacks (message modification, 
masquerade, replay, MitM, and DoS) deliberately alter system state, inject malicious data, 
forge identities, and exhaust resources.

  * THE ZERO TRUST PARADIGM (NIST SP 800-207) :
    - Core Rule: "NEVER TRUST, ALWAYS VERIFY."
    - Perimeter-based security is obsolete. Every user, device, network packet, and API 
      transaction must be authenticated, authorized, and cryptographically verified at every step.

  * THE ACTIVE MITIGATION FEEDBACK LOOP :
    1. Cryptographic Invariants (AEAD GHASH, HMAC-SHA256, mTLS).
    2. Real-Time Detection (SIEM correlation rules).
    3. Automated Containment (SOAR playbooks isolating rogue ports in <200ms).
