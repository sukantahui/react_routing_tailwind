1. EXECUTIVE OVERVIEW & MATHEMATICAL STATE-MACHINE AXIOMS
--------------------------------------------------------------------------------
In computer network security, cryptography, and threat modeling (RFC 4949 and ISO 7498-2), 
cyber attacks are classified based on their mathematical interaction with the target system state.

Let an information system state be defined as the tuple:
    S = (D, C, R)
where:
    * D = Stored data, database records, and in-transit packet streams.
    * C = System security configurations, firewall access lists, and auth tables.
    * R = Computational resources (CPU cycles, RAM buffers, network bandwidth, TCB tables).

--------------------------------------------------------------------------------
A. PASSIVE ATTACKS (STATE-INVARIANT THREATS) :
--------------------------------------------------------------------------------
An attack that attempts to learn or make use of information from the system WITHOUT 
affecting system resources, altering data, or degrading performance.

  * Mathematical Formulation :
      ΔS = ∅  (System state remains 100% unchanged)
      I_leak(D) > 0  (Information leaked to adversary)
      ΔR = 0  (Zero latency or resource depletion)

  * Primary Target           : CONFIDENTIALITY (Pillar "C" of the CIA Triad).
  * System Detectability     : VIRTUALLY IMPOSSIBLE on standard networks (0 audit logs generated).
  * Defense Philosophy       : 100% PREVENTION (End-to-End Encryption, Zero-Knowledge, Traffic Padding).

--------------------------------------------------------------------------------
B. ACTIVE ATTACKS (STATE-CORRUPTING THREATS) :
--------------------------------------------------------------------------------
An attack that attempts to alter system resources, corrupt data records, forge identities, 
replay valid transactions, or disrupt the operational availability of services.

  * Mathematical Formulation :
      ΔS ≠ ∅  (System state is corrupted or knocked offline)
      D' ≠ D ∨ C' ≠ C  (Data tampered or configurations corrupted)
      R → ∅  (In Denial of Service: memory/CPU exhausted)

  * Primary Targets          : INTEGRITY & AVAILABILITY (Pillars "I" & "A" of the CIA Triad).
  * System Detectability     : HIGHLY DETECTABLE (IDS/IPS, SIEM logs, hash mismatches, 504 timeouts).
  * Defense Philosophy       : PREVENTION + RAPID DETECTION + AUTOMATED INCIDENT RESPONSE.

4. DEEP-DIVE TAXONOMY OF ATTACK MECHANISMS & CODE DEFENSES
================================================================================

1. PACKET EAVESDROPPING / SNIFFING :
   - Attacker runs Promiscuous Mode on shared LAN (Wireshark/tcpdump).
   - Captures unencrypted passwords, HTTP session tokens, cleartext SQL data.
   - Mitigation: Enforce TLS 1.3 with AEAD (AES-256-GCM / ChaCha20-Poly1305).

2. TRAFFIC FLOW & FREQUENCY ANALYSIS :
   - Even when payload is encrypted, adversary observes transmission volume spikes, 
     burst timing, and node pairs (e.g. military base in Barrackpore to Kolkata HQ).
   - Mitigation: Constant-Bitrate Traffic Padding (injecting continuous dummy encrypted packets).

3. OPTICAL FIBER MACROBENDING WIRETAP :
   - Physical layer tap: bending glass fiber to leak 1-3% of light photons without breaking link.
   - Mitigation: Optical Time-Domain Reflectometry (OTDR) + MACsec (802.1AE) Layer 2 encryption.

4. IN-FLIGHT MESSAGE MODIFICATION (DATA TAMPERING) :
   - Active adversary alters transaction amounts from ₹500 to ₹50,000 in transit.
   - Mitigation: HMAC-SHA256, Authenticated Encryption (AEAD), Digital Signatures (ECDSA).

5. CRYPTOGRAPHIC REPLAY ATTACKS :
   - Adversary captures valid encrypted message E_k('Pay ₹10,000') and resends it 10 times.
   - CRITICAL RULE: Encryption alone does NOT stop replay attacks!
   - Mitigation: Cryptographic Nonces (UUID), Monotonic Sequence Counters, 500ms Timestamp TTL.

6. DENIAL OF SERVICE (SYN FLOOD / DoS) :
   - Botnet sends millions of half-open TCP SYN packets with spoofed source IPs.
   - Exhausts kernel Transmission Control Blocks (TCBs), dropping legitimate connections.
   - Mitigation: SYN Cookies (RFC 4987 - stateless sequence encoding), Anycast scrubbing, BCP 38.

5. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 (AMENDED 2008) :
    - Section 43(a) : Civil penalty up to ₹1 CRORE for unauthorized access/downloading.
    - Section 66    : Criminal penalties for active hacking (Up to 3 years prison + ₹5 Lakh fine).
    - Section 66F   : Cyber terrorism (attacks on critical infrastructure) -> LIFE IMPRISONMENT.

  * CERT-In MANDATORY CYBER DIRECTIVE (APRIL 2022) :
    - Mandatory 6-Hour reporting SLA for all active security breaches and ransomware intrusions.
    - Mandatory 180-day NTP-synchronized secure log retention on Indian territory.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5)  : Mandates reasonable technical security safeguards to prevent data breaches.
    - Section 33    : Penalties up to ₹250 CRORES for failure to protect personal data.
