1. EXECUTIVE OVERVIEW & MitM TOPOLOGY THEORY
--------------------------------------------------------------------------------
A Man-in-the-Middle (MitM) Attack is an active cyber threat where an adversary secretly 
intercepts, relays, and potentially modifies communications between two legitimate parties 
who believe they are directly communicating with each other:

  * THE DUAL-SESSION PARADOX :
    - An in-line attacker establishes TWO independent secure communication sessions:
        Session 1 : Client (Alice) <====[ Key_AE ]====> Attacker (Eve)
        Session 2 : Attacker (Eve) <====[ Key_EB ]====> Server (Bob)
    - Alice encrypts data for Eve believing she is Bob; Eve decrypts, inspects/modifies 
      the plaintext, re-encrypts with Key_EB, and forwards it to Bob.

  * VULNERABILITY ROOT CAUSE :
    - Unauthenticated key exchange (Raw Diffie-Hellman) and failure to validate digital 
      certificates or enforce transport layer encryption locks.

--------------------------------------------------------------------------------
2. UNAUTHENTICATED DIFFIE-HELLMAN MitM MATHEMATICAL PROOF
--------------------------------------------------------------------------------

  1. Alice sends public key: A = g^a mod p
  2. Attacker intercepts A and sends: E = g^e mod p to Bob
  3. Bob sends public key: B = g^b mod p
  4. Attacker intercepts B and sends: E = g^e mod p to Alice
  5. Alice computes shared key: K_1 = E^a = g^(ea) mod p
  6. Bob computes shared key  : K_2 = E^b = g^(eb) mod p
  7. Attacker computes BOTH   : K_1 = A^e = g^(ea)  AND  K_2 = B^e = g^(eb)
  ===> Attacker transparently decrypts and re-encrypts all data with ZERO key errors!

  * DEFENSE: SIGMA PROTOCOL (AUTHENTICATED ECDH) :
    - Bob digitally signs the key exchange transcript using his private key:
        S_B = Sign_PrivB( g^a || g^b ) + X.509 Certificate Chain
    - Alice verifies S_B using Bob's public certificate, making MitM mathematically impossible!

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 66    : Criminal hacking & unauthorized data interception (Up to 3 Years Prison + ₹5 Lakh Fine).
    - Section 66D   : Cheating by Personation / MitM Proxying (Up to 3 Years Prison + ₹1 Lakh Fine).
    - Section 69    : Sovereign Lawful Interception Procedure (Requires explicit written order by Home Secretary).
    - Section 43    : Civil damages up to ₹1 CRORE for unauthorized interception/tampering.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5)  : Mandates reasonable technical security safeguards (mTLS/HSTS) on citizen telemetry.
    - Section 33    : Penalties up to ₹250 CRORES for systemic data breaches caused by MitM vulnerabilities.

5. STUDENT MINI CHECKLIST (EXAM & CAREER ESSENTIALS)
================================================================================
  [✔] MitM attacks break both Confidentiality and Integrity by establishing dual encrypted sessions.
  [✔] Unauthenticated Diffie-Hellman is vulnerable to MitM; TLS 1.3 solves this with signed ECDH.
  [✔] HSTS Preloading forces browsers to use HTTPS exclusively, completely defeating SSLstrip.
  [✔] Dynamic ARP Inspection (DAI) on switches eliminates ARP cache poisoning on local LANs.
  [✔] Certificate Pinning protects mobile apps against compromised or rogue root CAs.
  [✔] Section 69 of the IT Act mandates that lawful wiretaps require Home Secretary written authorization.
