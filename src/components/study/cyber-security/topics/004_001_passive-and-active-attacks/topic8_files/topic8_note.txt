1. EXECUTIVE OVERVIEW & AVAILABILITY THREAT THEORY
--------------------------------------------------------------------------------
A Denial of Service (DoS) or Distributed Denial of Service (DDoS) Attack is an active cyber 
threat designed to overwhelm, exhaust, or crash target systems, rendering them unavailable 
to legitimate users. This directly violates the AVAILABILITY pillar of the CIA Triad:

  * THE ESSENCE OF DoS :
    - Confidentiality : Intact (No secret data stolen).
    - Integrity       : Intact (No data altered).
    - Availability    : DESTROYED (Legitimate users receive 504 Gateway Timeouts or connection drops).

  * BOTNETS & SCALING :
    - Attackers command thousands or millions of compromised IoT bots (Mirai botnets) 
      to unleash coordinated multi-terabit volumetric floods across global networks.

--------------------------------------------------------------------------------
2. THE THREE PILLARS OF DDoS THREAT VECTORS
--------------------------------------------------------------------------------

A. VOLUMETRIC AMPLIFICATION FLOODS (MEASURED IN Gbps / Tbps) :
   - Exploits stateless UDP protocols with spoofed victim source IPs:
       * DNS Amplification (EDNS0)  : ~50x to 70x Amplification Factor (AF)
       * NTP monlist Reflection     : ~556x Amplification Factor (AF)
       * Memcached UDP Reflection   : ~10,000x to 51,000x Amplification Factor (AF!)
   - Math: Inbound_Volume = Bots × Egress_Rate × Amplification_Factor

B. PROTOCOL & STATE EXHAUSTION ATTACKS (MEASURED IN Mpps) :
   - Saturates stateful connection tables, firewalls, and OS socket buffers:
       * TCP SYN Flood  : Fills `SYN_RECV` half-open backlog queue, dropping connections.
       * Smurf Attack   : ICMP echo broadcasts reflecting from entire subnets.
       * Teardrop       : Overlapping IP fragment offsets crashing legacy kernel reassembly.

C. APPLICATION LAYER (LAYER 7) RESOURCE EXHAUSTION (MEASURED IN RPS) :
   - Forces heavy backend CPU computation, database queries, or thread locks:
       * HTTP/2 Rapid Reset (CVE-2023-44487) : HEADERS + RST_STREAM floods (398M RPS record!).
       * Slowloris / RUDY                    : Incomplete headers/body holding worker threads.
       * ReDoS (Regex Denial of Service)     : Catastrophic backtracking O(2^n) locking CPU.
