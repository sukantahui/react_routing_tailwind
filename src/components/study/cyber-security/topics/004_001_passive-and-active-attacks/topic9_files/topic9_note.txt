1. EXECUTIVE OVERVIEW & THE ASYMMETRIC PASSIVE DEFENSE
--------------------------------------------------------------------------------
Because passive cyber attacks (packet sniffing, fiber macrobending taps, electromagnetic 
eavesdropping) generate ZERO logs, modify ZERO bits, and produce ZERO state transitions (ΔS = ∅), 
traditional detection-first models fail completely:

  * THE ASYMMETRIC DEFENSIVE MODEL :
    1. SPECIALIZED INSTRUMENTATION :
       - Deploy physical/side-channel detection tools (C-OTDR 1625nm, Canary Honeytokens, 
         Fake Unicast MAC testing).
    2. 100% PROACTIVE PREVENTION :
       - Mandate end-to-end cryptography, line-rate MACsec, and Constant-Bitrate (CBR) 
         traffic padding so intercepted ciphertext is mathematically unreadable.

2. SPECIALIZED DETECTION & DECEPTION TECHNIQUES
--------------------------------------------------------------------------------

A. CONTINUOUS OPTICAL TIME-DOMAIN REFLECTOMETRY (C-OTDR) :
   - Injects an out-of-band supervisory wavelength (1625 nm) alongside live 1310/1550 nm traffic.
   - Measures Rayleigh backscatter drops as small as 0.05 dB, locating physical macrobending 
     taps to within ±0.5 meters in real time!

B. REMOTE PROMISCUOUS MODE DETECTION TESTS :
   - Fake Unicast MAC Probe: Transmits frames with valid IP but bogus MAC (`00:00:00:00:00:01`).
   - Normal NICs drop in hardware; promiscuous NICs accept and reply, exposing their presence!
   - Latency Flood Test: Broadcast floods bog down promiscuous kernels, creating measurable RTT spikes.

C. CANARY HONEYTOKEN DECEPTION :
   - Deliberately plants fake credentials (`DB_PASS=canary_user_kolkata`) inside simulated feeds.
   - Using the stolen token on any login portal alerts the SOC and reveals the sniffer's IP.
