1. EXECUTIVE OVERVIEW & THE DETECTION ASYMMETRY
--------------------------------------------------------------------------------
Passive cyber attacks represent the most asymmetric threat paradigm in computer network 
security. Because passive threats alter zero bits, inject zero packets, and produce zero 
system state changes, standard intrusion detection systems (IDS) and security logs 
receive ZERO forensic event warnings:

  * THE DETECTION ASYMMETRY :
    - Active Attacks  : Loud digital anomalies (Failed login spikes, 504 timeouts, crash dumps).
    - Passive Attacks : Completely silent (Promiscuous NIC sniffing, optical macrobending taps).

  * THE PREVENTION PARADOX :
    - Because detection in real-time is virtually impossible on standard network infrastructure, 
      defensive architecture must focus 100% on PROACTIVE PREVENTION (End-to-End Encryption, 
      Zero-Trust Authentication, and Constant-Rate Traffic Padding).

3. ADVANCED DETECTION PARADIGMS & SPECIALIZED INSTRUMENTATION
================================================================================

1. CANARY HONEYTOKENS (DECOY CREDENTIALS) :
   - Planting unique fake credentials (e.g. `DB_PASS=canary_user_kolkata`) inside simulated 
     cleartext traffic. When an eavesdropper uses the token on a login portal, the canary backend 
     instantly alerts the SOC, proving that passive sniffing took place!

2. REMOTE PROMISCUOUS MODE DETECTION TESTS :
   - Fake Unicast MAC Addressing: Sending an ARP/ICMP packet with the target's IP but a bogus 
     destination MAC (`00:00:00:00:00:01`). Normal NICs drop it in hardware; promiscuous NICs 
     accept it and reply, exposing their silent sniffing presence!
   - Latency Flooding Test: Flooding non-matching broadcast ARP frames; promiscuous hosts 
     suffer millisecond processing delays while filtering frames in kernel software.

3. CONTINUOUS TIME-DOMAIN REFLECTOMETRY (C-OTDR & TDR) :
   - C-OTDR (Optical): Injects 1625nm supervisory light pulses during live traffic, detecting 
     Rayleigh backscatter drops as small as 0.05 dB at exact geographic markers (±0.5 meters).
   - TDR (Copper): Transmits fast electrical voltage pulses down copper twisted pairs to detect 
     impedance discontinuities (Z_0 = 100 Ohms) caused by inductive taps.

4. HARVEST NOW, DECRYPT LATER (HNDL) & POST-QUANTUM DEFENSES :
   - Adversaries archive encrypted diplomatic/financial streams today to decrypt later via quantum 
     computers running Shor's Algorithm.
   - Mitigation: Deploy NIST Post-Quantum Standards (FIPS 203 ML-KEM / CRYSTALS-Kyber).
