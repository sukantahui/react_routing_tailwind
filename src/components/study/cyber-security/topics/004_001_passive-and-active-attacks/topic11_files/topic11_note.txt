1. EXECUTIVE OVERVIEW & THE MASTER DICHOTOMY
--------------------------------------------------------------------------------
Cyber threats are classified into two foundational paradigms based on their interaction 
with system state (S) and the CIA Triad:

  * PASSIVE ATTACKS (SECRECY & RECONNAISSANCE) :
    - Goal: Eavesdrop, capture data, analyze traffic patterns.
    - System State: Invariant (ΔS = ∅). Zero bits modified, zero server memory altered.
    - CIA Impact: Directly compromises CONFIDENTIALITY (Integrity and Availability intact).
    - Detection: Near-impossible via standard IT logs (requires specialized C-OTDR / Honeytokens).
    - Strategy: 100% Proactive Prevention (Assume wire tapped ➔ End-to-End Encryption / MACsec).

  * ACTIVE ATTACKS (DISRUPTION, FRAUD & TAMPERING) :
    - Goal: Alter messages, impersonate users, replay requests, intercept sessions, crash systems.
    - System State: Altered (ΔS ≠ ∅). Bits flipped, permissions elevated, socket queues flooded.
    - CIA Impact: Directly compromises INTEGRITY and/or AVAILABILITY.
    - Detection: Highly detectable via SIEM event logs, hash mismatches, buffer overflows.
    - Strategy: Zero Trust Feedback Loop (Detect ➔ Cryptographic Verification ➔ Automated SOAR).
