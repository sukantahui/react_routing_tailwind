1. EXECUTIVE OVERVIEW & SAME-ORIGIN POLICY (SOP) BYPASS
--------------------------------------------------------------------------------
Cross-Site Scripting (XSS) occurs when an application includes untrusted user data in web pages 
without proper context-aware encoding or sanitization, causing the victim's browser to execute 
the attacker's client-side JavaScript within the trusted origin context:

  * THE 3 CORE XSS CLASSIFICATIONS :
    1. STORED XSS (Type II / Persistent) : Payload permanently stored in database (comments, forums).
    2. REFLECTED XSS (Type I / Non-Persist): Payload reflected immediately in HTTP response (search/error).
    3. DOM-BASED XSS (Type 0 / Client-Side): Executes entirely in client JS (`location.hash` ➔ `innerHTML`).
