1. EXECUTIVE OVERVIEW & THE DUAL-PERIMETER ARCHITECTURE
--------------------------------------------------------------------------------
Comprehensive defense-in-depth establishes two complementary security perimeters:

  * THE DUAL-PERIMETER PILLARS :
    1. INBOUND PERIMETER (WAF) : Inspects Layer 7 HTTP/HTTPS traffic at the cloud edge, blocking SQLi, 
       XSS, RCE, and bots via anomaly scoring and OpenAPI schema allowlists.
    2. BROWSER PERIMETER (CSP) : Restricts browser script execution via cryptographic nonces (`nonce-SECRET`), 
       neutralizing XSS in the client DOM even if an attacker injects markup.

5. STUDENT MINI CHECKLIST (EXAM & CAREER ESSENTIALS)
================================================================================
  [✔] WAF operates at Layer 7; inspects HTTP parameters, headers, and request bodies.
  [✔] WAFs are not a substitute for Parameterized Queries; they buy time via Virtual Patching.
  [✔] Strict Nonce-Based CSP (`script-src 'nonce-...'`) completely neutralizes XSS in the browser.
  [✔] `frame-ancestors 'none'` supersedes `X-Frame-Options: DENY` for Clickjacking defense.
  [✔] Use CSP Report-Only mode during staging to audit violations without breaking functionality.
  [✔] Section 66F of the IT Act penalizes perimeter attacks on critical infrastructure with Life Imprisonment.
