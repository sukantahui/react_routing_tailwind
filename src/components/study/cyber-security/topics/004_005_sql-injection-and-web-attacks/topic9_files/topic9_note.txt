1. EXECUTIVE OVERVIEW & TWO-PHASE QUERY COMPILATION PIPELINE
--------------------------------------------------------------------------------
Parameterized Queries (Prepared Statements) represent the indisputable Gold Standard defense 
against SQL Injection, enforcing strict mathematical separation between code instructions and literal data:

  * THE TWO-PHASE COMPILATION PIPELINE :
    1. PHASE 1 (`PREPARE`) : The database engine parses, optimizes, and compiles the SQL query string 
       into an Abstract Syntax Tree (AST) template, permanently freezing all grammar nodes and clauses.
    2. PHASE 2 (`EXECUTE`) : User parameters are transmitted separately over the database wire protocol 
       as pure literal data values, placed directly into pre-compiled execution slots ($\Delta \text{AST} = \emptyset$).
