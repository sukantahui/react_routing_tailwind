1. EXECUTIVE OVERVIEW & THE 5-PHASE SQLi KILL CHAIN
--------------------------------------------------------------------------------
SQL Injection is not merely an information disclosure bug; it represents a full kill-chain vector capable 
of escalating from authentication bypass to full host operating system and Active Directory takeover:

  * THE 5 KILL-CHAIN PHASES :
    1. AUTHENTICATION BYPASS  : Bypasses login gates via `' OR 1=1--` or elevates role to `SUPER_ADMIN`.
    2. MASS DATA THEFT        : Exfiltrates millions of customer credentials, PAN cards, and health records.
    3. DATA TAMPERING & DoS   : Overwrites financial balances (`UPDATE`) or drops database tables (`DROP TABLE`).
    4. HOST OS TAKEOVER (RCE) : Executes shell commands via `xp_cmdshell`, `INTO OUTFILE`, or `COPY PROGRAM`.
    5. LATERAL DOMAIN PIVOT   : Dumps LSASS NetNTLM hashes using Mimikatz to compromise the Domain Controller!

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 66F   : SQLi host takeover of Critical Infrastructure is CYBER TERRORISM (LIFE IMPRISONMENT).
    - Section 70    : Unauthorized access to PROTECTED SYSTEMS (Up to 10 YEARS IMPRISONMENT + Fine).
    - Section 43(a) : Civil compensation up to ₹1 CRORE for unauthorized database extraction/damage.
    - Section 66    : Criminal hacking & data tampering (Up to 3 Years Prison + Fine).

  * INDIAN PENAL CODE (IPC) :
    - Section 420   : Cheating & Fraudulent Balance Manipulation (Up to 7 Years Prison).
    - Section 427   : Mischief & Digital Property Destruction (Up to 2 Years Prison).

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - Database compromises and host takeovers must be reported within 6 HOURS.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5) & 33: Mandatory reasonable security safeguards; failure triggers fines up to ₹250 CRORES.
