1. EXECUTIVE OVERVIEW & THE FUNDAMENTAL INJECTION FLAW
--------------------------------------------------------------------------------
Injection vulnerabilities occur when untrusted user data is directly concatenated into an interpreter 
string without structured parameter binding, causing the interpreter to treat user data as executable code:

  * THE 8 CORE INJECTION VECTORS :
    1. SQL INJECTION (SQLi)        : Manipulates RDBMS database queries (`' OR '1'='1`).
    2. OS COMMAND INJECTION        : Executes host terminal shell commands (`system()`, `exec()`).
    3. NoSQL INJECTION             : Bypasses authentication using BSON operator objects (`$ne`, `$gt`).
    4. LDAP INJECTION              : Bypasses Active Directory queries using filter wildcards (`*`).
    5. XPATH / XML INJECTION       : Navigates XML document trees to extract confidential nodes.
    6. SERVER-SIDE TEMPLATE (SSTI) : Evaluates expressions in Jinja2/Twig, leading to backend RCE (`{{7*7}}`).
    7. CODE INJECTION (`eval()`)   : Evaluates user input as native JavaScript/Python/PHP code.
    8. CRLF / HEADER INJECTION     : Injects `\r\n` characters to force HTTP response splitting.

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 66F   : Injection attacks on Critical Infrastructure is CYBER TERRORISM (LIFE IMPRISONMENT).
    - Section 70    : Unauthorized access to PROTECTED SYSTEMS (Up to 10 YEARS IMPRISONMENT + Fine).
    - Section 43(a) : Civil compensation up to ₹1 CRORE for unauthorized data extraction.
    - Section 66    : Criminal hacking & data manipulation (Up to 3 Years Prison + Fine).

  * INDIAN PENAL CODE (IPC) :
    - Section 420   : Cheating & Fraudulent Balance Manipulation (Up to 7 Years Prison).
    - Section 427   : Mischief & Digital Property Deletion (Up to 2 Years Prison).

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - Database breaches resulting from injection attacks must be reported within 6 HOURS.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5) & 33: Mandatory reasonable security safeguards; failure triggers fines up to ₹250 CRORES.
