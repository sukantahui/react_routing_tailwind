1. EXECUTIVE OVERVIEW & THE DEFENSE TRIAD
--------------------------------------------------------------------------------
The Defense Triad provides end-to-end data lifecycle protection across application perimeters, 
database storage, and browser rendering contexts:

  * THE 3 CORE PILLARS :
    1. INPUT VALIDATION  : Syntactic & semantic gating (Accept/Reject) based on strict allowlists.
    2. SANITIZATION      : Data normalization and transformation (stripping illegal characters/tags).
    3. OUTPUT ENCODING   : Translating characters into context-safe entity representations (HTML, JS, URL).

--------------------------------------------------------------------------------

| VALIDATION PILLAR    | FOCUS METRIC       | IMPLEMENTATION PATTERN         | EXAMPLE SPECIFICATION      |

3. CONTEXT-AWARE OUTPUT ENCODING MATRIX
================================================================================

+-------------------+---------+-----------------------------+-----------------------------+
| PARSER DESTINATION| SINK    | ENCODING MECHANISM          | RESULTING SAFE OUTPUT       |
+-------------------+---------+-----------------------------+-----------------------------+
| HTML Body Text    | `<div>` | HTML Entity Encoding        | `<script>` ➔ `&lt;script&gt;`|
| HTML Attribute    | `value=`| Attribute Hex Entity        | `"` ➔ `&quot;` / `&#x22;`   |
| JavaScript Block  | `<scr>` | Unicode Hex Escape Sequence | `'` ➔ `\u0027`, `;` ➔ `\u003B`|
| Hyperlink Target  | `href=` | URL Scheme Whitelisting     | Enforce `https://` or `/`   |
+-------------------+---------+-----------------------------+-----------------------------+

5. STUDENT MINI CHECKLIST (EXAM & CAREER ESSENTIALS)
================================================================================
  [✔] Validation gates data at entry; Sanitization cleans data; Encoding protects data at exit.
  [✔] Allowlists (positive validation) are vastly superior to easily bypassed blocklists.
  [✔] Unicode normalization (`NFKC`) must always occur BEFORE applying validation regexes.
  [✔] Client-side validation is purely for user experience; server-side validation is mandatory for security.
  [✔] HTML Entity encoding protects HTML text, but JavaScript contexts require Unicode hex (`\u0027`).
  [✔] Section 66F of the IT Act penalizes input injection attacks on critical systems with Life Imprisonment.
