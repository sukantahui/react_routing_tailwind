1. EXECUTIVE OVERVIEW & WEB ARCHITECTURE ATTACK SURFACE
--------------------------------------------------------------------------------
Web applications process critical personal, financial, and governmental data across a 4-tier stack:
  * CLIENT TIER      : Browser DOM, Single Page Apps, Cookies, LocalStorage, Web Tokens.
  * TRANSPORT TIER   : TLS 1.3, HSTS (Strict-Transport-Security), Certificate Pinning.
  * APPLICATION TIER : Web APIs, Reverse Proxies, Microservices, Node.js/Java/Python runtimes.
  * DATA TIER        : Relational RDBMS (PostgreSQL/MySQL), NoSQL (MongoDB), In-memory Caches (Redis).

3. ENTERPRISE DEFENSIVE ARCHITECTURES & HARDENING HEADERS
================================================================================

  * CLIENT & BROWSER SECURITY HEADERS :
    - Content-Security-Policy    : default-src 'self'; script-src 'self' 'nonce-...'; (Stops XSS)
    - Strict-Transport-Security  : max-age=63072000; includeSubDomains; preload (Stops SSL Stripping)
    - X-Frame-Options            : DENY (Completely eliminates Clickjacking UI Redressing)
    - Set-Cookie Flags           : HttpOnly; Secure; SameSite=Strict (Protects Session Tokens)

  * APPLICATION & DEVSECOPS CONTROLS :
    - Parameterized Queries      : Prepared statements completely separate SQL code from user data!
    - Attribute-Based Access     : ABAC / RBAC checks on every single API endpoint (Prevents IDOR).
    - Supply Chain Auditing      : Automated `npm audit` and Snyk checks in CI/CD pipelines.

================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 43(a) : Civil compensation up to ₹1 CRORE for unauthorized data access/extraction.
    - Section 66    : Criminal hacking & data theft (Up to 3 Years Prison + ₹5 Lakh Fine).
    - Section 66C   : Identity theft & credential misuse (Up to 3 Years Prison + ₹1 Lakh Fine).
    - Section 66D   : Cheating by personation using computer resource (Up to 3 Years Prison).
    - Section 70    : Unauthorized access to PROTECTED SYSTEMS (Up to 10 Years Imprisonment).

  * INDIAN PENAL CODE (IPC) :
    - Section 420   : Cheating & Web Application Fraud (Up to 7 Years Prison).
    - Section 427   : Mischief & Digital Defacement (Up to 2 Years Prison).

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - Web application breaches and data leaks must be reported to CERT-In within 6 HOURS.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5) & 33: Mandatory reasonable security safeguards; failure triggers fines up to ₹250 CRORES.
