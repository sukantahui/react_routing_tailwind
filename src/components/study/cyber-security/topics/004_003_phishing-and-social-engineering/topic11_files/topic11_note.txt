1. EXECUTIVE OVERVIEW & UEBA MACHINE LEARNING ARCHITECTURE
--------------------------------------------------------------------------------
User and Entity Behavior Analytics (UEBA) moves beyond static SIEM rules by using machine 
learning to dynamically baseline normal behavior for users and devices, detecting statistical anomalies:

  * THE CORE UEBA ARCHITECTURE LAYERS :
    1. MULTI-SOURCE INGESTION : Streaming AD, VPN, Endpoint DLP, Proxy, and CloudTrail logs.
    2. PEER GROUP BASELINING  : Clustering users by department/role to eliminate false positives.
    3. MACHINE LEARNING ENGINE: Statistical Z-Scores, Isolation Forests, Markov sequence models.
    4. COMPOSITE RISK SCORING : Aggregating multi-vector indicators into a single 0-100 risk score.

--------------------------------------------------------------------------------
2. ADVANCED UEBA THREAT DETECTION USE CASES
--------------------------------------------------------------------------------

A. IMPOSSIBLE TRAVEL & VELOCITY ANOMALIES :
   - Flagging logins from geographically distant locations (Kolkata & Frankfurt) in impossible times.

B. PRE-RESIGNATION FLIGHT RISK & DATA HOARDING :
   - Correlating HR notice periods with surges in cross-departmental file share downloads.

C. VIP RECORD SNOOPING & FIRST-TIME-SEEN (FTS) :
   - Alerting when unauthorized staff view VIP medical records or connect to novel critical servers.

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 72A   : Breach of Confidentiality under lawful contract (Up to 3 Years Prison + Fine).
    - Section 43(b) : Civil damages up to ₹1 CRORE for unauthorized data copying detected by UEBA.
    - Section 66    : Criminal hacking & fraudulent access using compromised credentials.

  * INDIAN PENAL CODE (IPC) :
    - Section 408   : Criminal Breach of Trust by Clerk or Servant (Up to 7 Years Prison + Fine).

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - All account takeovers & insider data exfiltrations must be reported within 6 HOURS.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5) & 33: Mandatory UEBA monitoring with employee privacy; failure triggers ₹250 CRORE fines.
