1. EXECUTIVE OVERVIEW & THREAT TAXONOMY
--------------------------------------------------------------------------------
Watering Hole attacks and Business Email Compromise (BEC) represent two of the highest-impact 
threat vectors in modern enterprise cybersecurity:

  * WATERING HOLE (STRATEGIC WEB COMPROMISE) :
    - Compromises legitimate third-party websites frequently visited by target demographics.
    - Uses selective IP filtering to deliver zero-day browser exploits only to target enterprises.

  * BUSINESS EMAIL COMPROMISE (BEC) & EAC :
    - FBI IC3 5 Scenarios: 1. Supplier Swindle; 2. CEO Fraud; 3. Account Compromise (EAC);
      4. Attorney Impersonation; 5. Data Theft (Salary/PAN records).
    - Maintains persistence via hidden Exchange inbox rules and malicious OAuth Graph API grants.

--------------------------------------------------------------------------------
2. ADVANCED PERSISTENCE & TECHNICAL EVASIONS
--------------------------------------------------------------------------------

A. MALICIOUS OAUTH CONSENT GRANTS :
   - Tricks users into granting Graph API permissions (`Mail.ReadWrite`, `Mail.Send`).
   - Persists indefinitely through password resets and MFA changes.

B. REMOTE BROWSER ISOLATION (RBI) :
   - Neutralizes Watering Hole exploits by rendering untrusted sites in isolated cloud containers.
   - Streams only sanitized WebRTC visual pixels to the user's local browser.

C. VISHING-ASSISTED MULTI-CHANNEL BEC :
   - Combines spoofed CEO emails with real-time AI voice cloned phone calls to force transfers.

4. STATUTORY & REGULATORY COMPLIANCE IN INDIA
================================================================================

  * INFORMATION TECHNOLOGY ACT 2000 :
    - Section 66D   : Cheating by Personation using computer resources (Up to 3 Years Prison).
    - Section 43(a) : Civil damages up to ₹1 CRORE for unauthorized access via EAC.
    - Section 66    : Criminal hacking & fraudulent deception (Up to 3 Years Prison + ₹5 Lakh Fine).

  * INDIAN PENAL CODE (IPC) :
    - Section 420   : Cheating & Dishonestly Inducing Delivery of Property (Up to 7 Years Prison).

  * MHA CITIZEN FINANCIAL CYBER FRAUD REPORTING (CFCFRMS) :
    - Report wire fraud within 1-2 hours on Helpline 1930 for automated bank mule account freeze.

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - All BEC compromises & unauthorized financial redirections must be reported within 6 HOURS.

  * DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023 :
    - Section 8(5) & 33: Mandatory organizational security safeguards; failure triggers fines up to ₹250 CRORES.
