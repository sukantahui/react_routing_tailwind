2. DATA ENCRYPTION STANDARD (DES) DEEP-DIVE
--------------------------------------------------------------------------------

* SPECIFICATIONS:
  - Block Size: 64 bits (8 bytes).
  - Key Size: 64 bits nominal (8 parity bits discarded → 56 bits effective entropy = 2^56 keys).
  - Rounds: 16 Feistel rounds.
  - Round Function F:
    1. Expansion Permutation (E-Box): Expands 32-bit Right half to 48 bits.
    2. XOR with 48-bit Round SubKey.
    3. Eight S-Boxes (6 bits in → 4 bits out): Provides non-linear Confusion.
    4. P-Box (32-bit Permutation): Provides Diffusion.

* WHY DES DIED:
  - 1999: EFF "Deep Crack" brute-forced a DES key in 22 hours.
  - Today: Modern GPU clusters recover 56-bit DES keys in under 1 hour.

--------------------------------------------------------------------------------
3. TRIPLE-DES (3DES) & THE SWEET32 ATTACK
--------------------------------------------------------------------------------

* ENCRYPT-DECRYPT-ENCRYPT (EDE) SEQUENCE:
  - Encryption: C = E_K3( D_K2( E_K1( P ) ) )
  - Decryption: P = D_K1( E_K2( D_K3( C ) ) )
  - Backward Compatibility: If K1 == K2 == K3, then E_K(D_K(E_K(P))) = E_K(P) (Single DES).

* THE SWEET32 ATTACK (CVE-2016-2183):
  - Root Cause: 64-bit block size.
  - Birthday Paradox: After encrypting sqrt(2^64) = 2^32 blocks (~32 GB of data), there is a 50% 
    chance of a block collision (C_i == C_j).
  - Leakage: In CBC mode, colliding blocks leak plaintext XOR: P_i ^ P_j = C_{i-1} ^ C_{j-1}.
  - Regulatory Impact: NIST and the Reserve Bank of India (RBI) banned 3DES in December 2023.

--------------------------------------------------------------------------------
4. ADVANCED ENCRYPTION STANDARD (AES / RIJNDAEL)
--------------------------------------------------------------------------------

* SPECIFICATIONS:
  - Standardized as FIPS 197 in 2001 (Designed by Vincent Rijmen & Joan Daemen).
  - Block Size: 128 bits (16 bytes arranged in a 4x4 State matrix).
  - Key Variants:
    - AES-128 : 10 Rounds (128-bit key)
    - AES-192 : 12 Rounds (192-bit key)
    - AES-256 : 14 Rounds (256-bit key)

* 4 INTERNAL ROUND OPERATIONS:
  1. `SubBytes`   : Replaces each byte with its multiplicative inverse in Galois Field GF(2^8) 
                    modulo (x^8 + x^4 + x^3 + x + 1), followed by an affine transformation.
  2. `ShiftRows`  : Cyclically rotates rows to the left: Row 0 by 0, Row 1 by 1, Row 2 by 2, Row 3 by 3 bytes.
  3. `MixColumns` : Multiplies each column by a fixed MDS matrix over GF(2^8) (Omitted in final round).
  4. `AddRoundKey`: Bitwise XORs the 128-bit State matrix with the round subkey from Key Schedule.

* HARDWARE AES-NI INSTRUCTIONS:
  - Dedicated CPU silicon instructions (`_mm_aesenc_si128`) execute AES rounds in constant clock cycles, 
    achieving 5-10 GB/s throughput and eliminating software S-box cache-timing side-channel attacks.

5. INDIAN STATUTORY COMPLIANCE & BANKING DIRECTIVES
--------------------------------------------------------------------------------

* RBI CYBER SECURITY DIRECTIVES FOR BANKS:
  - All Indian Scheduled Commercial Banks, ATM networks (NFS), and POS payment gateways must 
    completely retire 3DES and migrate to AES-256-GCM backed by FIPS 140-3 Hardware Security Modules.

* DIGITAL PERSONAL DATA PROTECTION (DPDP) ACT 2023:
  - Section 33: Failure to deploy modern authenticated encryption (AES-GCM) leading to personal data 
    breaches incurs administrative penalties up to ₹250 Crores.

7. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL SYMMETRIC CIPHER HABITS:
  1. Default Exclusively to AES-256-GCM: Provides confidentiality and integrity in a single parallel pass.
  2. Retire 3DES and 64-bit Ciphers: Avoid Sweet32 collision risks on high-bandwidth connections.
  3. Leverage Hardware AES-NI: Ensures constant-time execution with zero cache-timing vulnerability.

* COMMON BEGINNER CIPHER PITFALLS:
  - Assuming 3DES is secure because it has "168-bit key" (Effective security is only 112 bits).
  - Confusing DES parity bits with key bits (DES key is 56 bits, not 64 bits).
  - Using software S-Box lookup tables in C without constant-time masking (Leaks cache timing).
  - Failing to recognize that 3DES is legally prohibited for Indian banking under RBI directives.
