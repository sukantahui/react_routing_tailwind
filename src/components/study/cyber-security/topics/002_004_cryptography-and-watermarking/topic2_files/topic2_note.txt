1. EXECUTIVE OVERVIEW & THE CLASSICAL TAXONOMY
--------------------------------------------------------------------------------
Classical cryptography is bifurcated into two foundational mathematical operations:

  1. SUBSTITUTION CIPHERS : Each character or symbol in the plaintext is REPLACED by another 
     character, digit, or symbol (alters character identity; provides Shannon Confusion).
  2. TRANSPOSITION CIPHERS: The characters of the plaintext remain unchanged, but their 
     linear POSITIONS are permuted/shuffled (alters character position; provides Shannon Diffusion).

--------------------------------------------------------------------------------
2. SUBSTITUTION CIPHER PARADIGMS
--------------------------------------------------------------------------------

[1. MONOALPHABETIC SUBSTITUTION]
  * Caesar Cipher: Rotational shift: C = (P + K) mod 26 (Trivial key space: 25 keys).
  * ROT13: Special case with K=13; self-inverting function: ROT13(ROT13(P)) = P.
  * Affine Cipher: C = (aP + b) mod 26; requires gcd(a, 26) = 1 (Key space = 12 * 26 = 312).
  * General Monoalphabetic: 26! ≈ 4.03 * 10^26 keys; instantly broken via Frequency Analysis.

[2. POLYALPHABETIC SUBSTITUTION]
  * Vigenère Cipher: C_i = (P_i + K_{i mod L}) mod 26; shifts letters based on repeating keyword.
  * Kasiski Examination: Finds distance between repeated ciphertext trigraphs to deduce key length L.
  * Index of Coincidence (IoC): William Friedman's formula; English Ic ≈ 0.0667 vs Random Ic ≈ 0.0385.

[3. POLYGRAPHIC SUBSTITUTION]
  * Playfair Cipher: Encrypts letter pairs (digrams) using a 5x5 matrix (Row, Column, Rectangle rules).
  * Hill Cipher: Linear algebra matrix multiplication: C = K * P mod 26; requires gcd(det(K), 26) = 1.

--------------------------------------------------------------------------------
3. TRANSPOSITION CIPHER PARADIGMS
--------------------------------------------------------------------------------

[1. RAIL FENCE CIPHER]
  * Plaintext is written in a zig-zag wave across N rails and read off horizontally row by row.

[2. COLUMNAR TRANSPOSITION]
  * Plaintext is written into a rectangular grid of width L; columns are read out vertically 
    in the alphabetical order of the keyword characters. Double Columnar repeats this twice.

[3. SCYTALE CIPHER]
  * Spartan military cipher; parchment wrapped around a wooden rod of fixed diameter (the key).

--------------------------------------------------------------------------------
4. THE BIRTH OF MODERN PRODUCT CIPHERS
--------------------------------------------------------------------------------

Claude Shannon proved that neither substitution alone nor transposition alone is secure. 
Modern symmetric ciphers are "Product Ciphers" that cascade both operations across multiple rounds:

+--------------------+-------------------------+--------------------+------------------------------------------------+
| ARCHITECTURE       | MECHANISM               | ROUND BEHAVIOR     | HISTORIC & MODERN EXAMPLES                     |
+--------------------+-------------------------+--------------------+------------------------------------------------+
| 1. Feistel Network | Splits block into L & R;| Round function F   | - Data Encryption Standard (DES - 16 Rounds)   |
|                    | L_{i+1}=R_i, R_{i+1}=...| operates on half   | - Blowfish, Twofish, Triple-DES (3DES)         |
+--------------------+-------------------------+--------------------+------------------------------------------------+
| 2. Substitution-   | Transforms entire block | SubBytes (S-Box) + | - Advanced Encryption Standard (AES Rijndael)  |
|    Permutation (SPN| in parallel every round | ShiftRows/MixCol   | - 10 rounds (128-bit) to 14 rounds (256-bit)   |
+--------------------+-------------------------+--------------------+------------------------------------------------+

6. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL CLASSICAL CRYPTOGRAPHY HABITS:
  1. Recognize Substitution = Confusion: S-Boxes obscure the key.
  2. Recognize Transposition = Diffusion: P-Boxes spread plaintext statistics.
  3. Never Deploy Classical Ciphers in Production: They fail all modern security standards.

* COMMON BEGINNER CLASSICAL MISTAKES:
  - Choosing an Affine multiplier 'a' that is even or 13 (gcd(a, 26) != 1 means no inverse exists!).
  - Confusing letter substitution (changes ASCII byte) with transposition (only moves positions).
  - Assuming a large key space like 26! equals strong security (Frequency analysis breaks it instantly).
  - Deploying ROT13 thinking it provides confidentiality (It is merely an obfuscation tool).
