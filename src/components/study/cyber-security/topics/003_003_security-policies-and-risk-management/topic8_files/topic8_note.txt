1. EXECUTIVE OVERVIEW & THE MATHEMATICS OF CYBER RISK
--------------------------------------------------------------------------------
Quantitative risk analysis translates technical cybersecurity threats into the universal language 
of business: Rupees (₹). Under ISO/IEC 27005:2022 and the FAIR standard, quantitative financial modeling 
enables security architects to calculate exact loss expectancies and justify security investments to CFOs:

  * SINGLE LOSS EXPECTANCY (SLE)  : Financial loss per breach incident (Asset Value x Exposure Factor).
  * ANNUAL LOSS EXPECTANCY (ALE)  : Total annualized financial risk exposure (SLE x ARO).
  * RETURN ON SECURITY INVESTMENT : Net percentage return from deploying security controls (ROSI %).

--------------------------------------------------------------------------------

3. COST-BENEFIT DECISION RULE (CFO APPROVAL CRITERIA)
--------------------------------------------------------------------------------

  * DECISION RULE : A proposed security countermeasure is financially justified ONLY IF:
    $$(ALE_{before} - ALE_{after}) > Annual Control Cost (CC)$$
  * Example: If a tool reduces ALE by ₹60 Lakhs and costs ₹15 Lakhs/year:
    - Net Annual Savings : ₹45 Lakhs / year.
    - Calculated ROSI    : (45L / 15L) * 100 = 300% ROSI ➔ APPROVED BY CFO IMMEDIATELY!

4. STATUTORY SAFE HARBOR UNDER INDIAN CYBER LAW
--------------------------------------------------------------------------------

  * DPDP ACT 2023 SECTION 33 STATUTORY FINE CAPS :
    - Up to ₹250 CRORES per violation must be factored into Asset Value and SLE calculations 
      when modeling breaches involving citizen personal data repositories.
  * RESERVE BANK OF INDIA (RBI) CYBER RESILIENCE GUIDELINES :
    - Commercial banks and FinTech switches must conduct quantitative ALE stress testing, 
      maintaining dedicated capital reserve funds in escrow matching modeled ALE.

6. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL QUANTITATIVE HABITS:
  1. Include DPDP Penalties in AV: Factor in ₹250 Cr statutory fines when calculating Asset Value.
  2. Size Cyber Insurance by Max SLE: Match policy limits to catastrophic single-loss events.
  3. Re-calibrate ARO Annually: Update attack frequencies using real-time CERT-In threat intelligence.
  4. Prove Positive ROSI: Always ensure that Annual Loss Reduction exceeds Annual Tooling Cost.

* COMMON BEGINNER QUANTITATIVE PITFALLS:
  - Confusing SLE with ALE (SLE is cost per single event; ALE is total annualized cost).
  - Negative ROSI Blindness (Deploying a ₹50 Lakh tool to prevent a ₹10 Lakh annual loss).
  - Hardware-Only Valuation (Ignoring daily revenue loss and regulatory penalties in Asset Value).
  - Static ARO Modeling (Failing to adjust incident frequency when new zero-days are disclosed).
