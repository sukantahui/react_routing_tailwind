1. EXECUTIVE OVERVIEW & THE OSINT FRAMEWORK
--------------------------------------------------------------------------------
Open-Source Intelligence (OSINT) is the disciplined process of collecting, processing, 
and analyzing publicly available information to produce actionable threat intelligence.

Unlike illegal hacking operations, OSINT operates 100% within the public domain—querying 
search engines, social media platforms, public Git repositories, Certificate Transparency 
ledgers, and domain registries without bypassing technical authentication barriers.

3. THE 5-STAGE OSINT INTELLIGENCE CYCLE
--------------------------------------------------------------------------------

  [ STAGE 1: PLANNING & DIRECTION ]
    * Define intelligence requirements, legal authorization, and assessment scope.

  [ STAGE 2: COLLECTION ]
    * Gather raw public data via automated scrapers, APIs, crt.sh, Shodan, and search engines.

  [ STAGE 3: PROCESSING & COLLATION ]
    * Filter out noise, normalize JSON/CSV structures, and de-duplicate entity records.

  [ STAGE 4: ANALYSIS & PRODUCTION ]
    * Correlate disparate data points using visual link analysis (Maltego) to identify vulnerabilities.

  [ STAGE 5: DISSEMINATION & REPORTING ]
    * Deliver actionable, executive threat intelligence reports with concrete remediation steps.

4. OPERATIONAL SECURITY (OPSEC) FOR INVESTIGATORS
--------------------------------------------------------------------------------

1. Dedicated Research Environments:
   - Conduct OSINT inside disposable virtual machines (Tails / Whonix) to isolate local filesystems.

2. Anonymous Routing:
   - Use multi-hop VPNs or Tor circuits to avoid leaking personal ISP IP addresses to target web servers.

3. Sanitized Sock Puppet Personas:
   - Never use personal social media or Google accounts; personal tracking cookies compromise anonymity.

5. INDIAN CYBER LAW & PRIVACY BOUNDARIES (DPDP ACT 2023)
--------------------------------------------------------------------------------

1. Digital Personal Data Protection (DPDP) Act, 2023:
   - Section 6 & 33: Gathering public data for legitimate defensive threat modeling is lawful.
   - Forbids compiling non-consensual personal profiling dossiers (penalties up to ₹250 Crores).

2. IT Act 2000 Section 43 & Section 66:
   - OSINT must remain strictly passive; actively probing target networks crosses into unauthorized access.

7. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL OSINT HABITS:
  1. Audit GitHub Commit Logs: Use Trufflehog to find secrets buried 50 commits in the past.
  2. Check Historical DNS: SecurityTrails reveals true origin server IPs hidden behind Cloudflare.
  3. Verify Geolocation with Google Lens: Reverse image search landmarks to pin exact GPS locations.

* COMMON BEGINNER OSINT MISTAKES:
  - Conducting OSINT while logged into personal social media accounts (Target receives notification).
  - Believing that deleting a public GitHub commit removes the secret (It persists in commit history).
  - Relying on a single search engine rather than aggregating Amass, Shodan, and crt.sh.
  - Compiling intrusive personal dossiers on individuals without legitimate cybersecurity justification.
