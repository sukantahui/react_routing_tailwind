1. EXECUTIVE OVERVIEW & POST-EXPLOITATION GOALS
--------------------------------------------------------------------------------
Initial access (Phase 3) almost always lands in a constrained, low-privilege security context 
(such as `www-data` on a web server or a standard employee account on a workstation).

In Phase 4 of ethical hacking, technical operators execute two essential disciplines:
  1. PRIVILEGE ESCALATION : Elevating local access to full Administrator / Root (`SYSTEM` / `UID 0`).
  2. LATERAL MOVEMENT     : Pivoting across internal network subnets to reach crown-jewel assets.

--------------------------------------------------------------------------------
2. VERTICAL VS HORIZONTAL PRIVILEGE ESCALATION
--------------------------------------------------------------------------------

  * VERTICAL ESCALATION   : Moving UPWARD in privilege hierarchy (e.g. `www-data` -> `root`).
  * HORIZONTAL ESCALATION : Moving SIDEWAYS to access data of another peer user at the same level.

4. LINUX PRIVILEGE ESCALATION VECTORS (GTFOBINS)
--------------------------------------------------------------------------------

[1. SUID / SGID BINARIES]
  * Flaw: Binary runs with file owner (root) privileges (`chmod u+s`).
  * Discovery: `find / -perm -4000 2>/dev/null`
  * Exploit (GTFOBins): `/usr/bin/find . -exec /bin/sh -p \; -quit` -> Instant Root Shell!

[2. SUDO MISCONFIGURATIONS (NOPASSWD)]
  * Flaw: `/etc/sudoers` permits running commands as root without a password.
  * Discovery: `sudo -l`
  * Exploit (Vim): `sudo vim -c ':!/bin/bash'` -> Escapes into root shell.

[3. KERNEL EXPLOITS (LAST RESORT)]
  * Dirty Pipe (CVE-2022-0847): Overwrites read-only `/etc/passwd` page cache in memory.
  * Baron Samedit (CVE-2021-3156): Heap overflow in sudo command-line unescaping.

5. LATERAL MOVEMENT & NETWORK PIVOTING TRADECRAFT
--------------------------------------------------------------------------------

1. Pass-the-Hash (PtH):
   - Authenticates over SMB (Port 445) using extracted NTLM hashes directly via `wmiexec.py` or `psexec.py`.

2. Overpass-the-Hash (Pass-the-Key):
   - Converts an NTLM hash into a valid Kerberos Ticket-Granting Ticket (TGT) using Rubeus to bypass NTLM blocks.

3. SOCKS5 Proxy Pivoting (Chisel / SSH Dynamic Tunneling):
   - Establishes an encrypted proxy (`ssh -D 1080 user@dmz_host`) to route scanner traffic into private subnets.

4. BloodHound Active Directory Graph Analysis:
   - Uses graph database queries (Neo4j) to uncover multi-hop shortest paths to Domain Admin.

--------------------------------------------------------------------------------
6. ENTERPRISE CONTAINMENT ARCHITECTURES
--------------------------------------------------------------------------------

1. Microsoft LAPS (Local Administrator Password Solution):
   - Automatically randomizes the local Administrator password on every endpoint, stopping Pass-the-Hash dead.

2. Tiered Administration Model:
   - Strict credential isolation: Tier 0 (Domain Controllers), Tier 1 (Servers), Tier 2 (Endpoints).
   - Tier 0 Domain Admins are strictly forbidden from logging into Tier 2 workstations.

3. Micro-segmentation & Host Firewalls:
   - Blocks workstation-to-workstation lateral SMB/WinRM traffic across local VLAN subnets.

8. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL PRIVILEGE ESCALATION HABITS:
  1. Check Misconfigurations First: Always run LinPEAS / WinPEAS before attempting risky kernel exploits.
  2. Deploy LAPS Everywhere: Randomizing local admin passwords eliminates 90%+ of lateral movement.
  3. Restrict Service Account Privileges: Strip `SeImpersonatePrivilege` from non-system daemons.

* COMMON BEGINNER PRIVILEGE ESCALATION MISTAKES:
  - Firing kernel exploits on production servers (Causes instant Blue Screens of Death / Kernel Panics).
  - Logging in with Domain Admin accounts on standard user workstations (Leaves hashes in LSASS RAM).
  - Forgetting to check `sudo -l` on Linux systems (Misses simple NOPASSWD shell escapes).
  - Violating IT Act 2000 Section 70 by laterally pivoting into designated Protected Systems (10 Years Prison).
