1. EXECUTIVE OVERVIEW & THE SCANNING TRIAD
--------------------------------------------------------------------------------
In Phase 2 of ethical hacking, security auditors execute an integrated 3-stage scanning pipeline:

  STAGE 1 : PORT SCANNING        → Discovers active IP addresses and listening TCP/UDP transport ports.
  STAGE 2 : BANNER GRABBING      → Connects to open ports to extract exact software daemon versions.
  STAGE 3 : VULNERABILITY SCAN   → Correlates version banners against CVE databases to identify exploitable bugs.

Together, this triad provides the technical blueprint required for surgical Phase 3 exploitation.

  * Category: Command-Line Web Server Misconfiguration Scanner.

4. CVSS v3.1 SEVERITY SCORING SYSTEM
--------------------------------------------------------------------------------

  * 0.0          → NONE
  * 0.1 - 3.9    → LOW
  * 4.0 - 6.9    → MEDIUM
  * 7.0 - 8.9    → HIGH
  * 9.0 - 10.0   → CRITICAL (Unauthenticated Remote Code Execution without user interaction)

5. THE 5-STAGE VULNERABILITY MANAGEMENT LIFECYCLE
--------------------------------------------------------------------------------

  [ STAGE 1: DISCOVER ]   → Continuously scan network, cloud, and container assets across IP ranges.
  [ STAGE 2: PRIORITIZE ] → Score findings based on CVSS severity and business asset criticality.
  [ STAGE 3: ASSESS ]     → Triage results to eliminate false positives via authenticated re-checks.
  [ STAGE 4: REMEDIATE ]  → Apply vendor patches, configuration changes, or WAF virtual patching rules.
  [ STAGE 5: VERIFY ]     → Rescan endpoints to confirm 100% vulnerability resolution.

7. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL VULNERABILITY SCANNING HABITS:
  1. Use Authenticated Scans for Internal Audits: Inspecting local packages eliminates false positives.
  2. Enforce Rate Limiting (`--max-rate 50`): Prevent scanner traffic from overwhelming production servers.
  3. Deploy Security Headers: Enforce CSP, HSTS, and X-Frame-Options on all web servers.

* COMMON BEGINNER SCANNING MISTAKES:
  - Relying exclusively on unauthenticated network scans (leads to high false positive rates).
  - Scanning live production databases without rate limiting (causes connection pool exhaustion).
  - Leaving server banners set to default (leaks exact minor version strings to attackers).
  - Ignoring CERT-In 6-hour incident reporting rules during active critical vulnerability discovery.
