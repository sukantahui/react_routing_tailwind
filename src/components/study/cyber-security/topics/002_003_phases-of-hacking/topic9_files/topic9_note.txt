1. EXECUTIVE OVERVIEW & THE CARDINAL ETHICAL DIVIDE
--------------------------------------------------------------------------------
Phase 5 (Covering Tracks) represents the fundamental dividing line between malicious cybercrime 
and professional ethical security auditing:

  * BLACK HAT ATTACKERS : Maliciously wipe event logs, timestomp file metadata, and shred binaries 
    to destroy forensic evidence and evade criminal prosecution.
  * WHITE HAT AUDITORS  : NEVER tamper with, modify, or delete client audit logs (doing so violates 
    compliance and destroys legal integrity). Instead, ethical testers systematically remove dropped 
    testing tools, terminate C2 sessions, and document all cleanup actions in the final debrief report.

3. FORENSIC ARTIFACT ANALYSIS & ANTI-FORENSICS DEFEAT
--------------------------------------------------------------------------------

[1. NTFS MASTER FILE TABLE ($MFT) TIMESTOMP DETECTION]
  * `$STANDARD_INFORMATION` : Modifiable by user-mode APIs (Forged by timestomp to show 2018).
  * `$FILE_NAME`            : Updated exclusively by the NTFS kernel driver (Shows true 2026 date!).
  * Result: Discrepancy between the two attributes proves intentional timestamp forgery.

[2. WINDOWS PREFETCH & SHIMCACHE ARTIFACTS]
  * Prefetch (`C:\Windows\Prefetch\*.pf`): Records executable name, run count, and last execution time.
  * Shimcache (`AppCompatCache`) & Amcache: Records file path, size, and SHA-1 hash even after deletion.

[3. NTFS USN CHANGE JOURNAL (`$UsnJrnl`)]
  * Append-only journal recording every file creation, rename, and deletion event on the filesystem.

4. ENTERPRISE IMMUTABLE LOGGING ARCHITECTURE
--------------------------------------------------------------------------------

1. Centralized Immutable WORM Logging:
   - System logs stream in real time over encrypted TLS to an off-site Write-Once Read-Many (WORM) SIEM.
   - Even if an attacker executes `rm -rf /var/log/*` locally, 100% of event records are preserved centrally.

2. CERT-In 180-Day Domestic Log Retention Mandate (Directions 2022):
   - Mandates that all ICT systems in India must retain secure, synchronized logs for at least 180 days.

3. Atomic NTP Clock Synchronization:
   - Synchronizes all server clocks to National Physical Laboratory (NPL) Stratum-1 atomic clocks.

--------------------------------------------------------------------------------
5. INDIAN CYBER LAW & DIGITAL EVIDENCE ADMISSIBILITY
--------------------------------------------------------------------------------

* IT ACT 2000 SECTION 65 (Tampering with Computer Source Documents):
  - Punishes intentionally destroying, altering, or concealing server audit logs with up to 3 years 
    imprisonment and ₹2,00,000 fine.

* INDIAN EVIDENCE ACT SECTION 65B (Electronic Evidence Admissibility):
  - Requires a signed Section 65B Certificate verifying that server logs were captured without 
    tampering, accompanied by an unbroken Chain of Custody and cryptographic SHA-256 hashes.
