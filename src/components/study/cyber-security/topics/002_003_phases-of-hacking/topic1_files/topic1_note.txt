1. EXECUTIVE OVERVIEW & PHASE 1 OBJECTIVES
--------------------------------------------------------------------------------
Reconnaissance (Footprinting) is the initial, foundational phase of any cyber intrusion 
or penetration test. Its primary objective is to systematically map the target's attack 
surface—cataloging IP blocks, domain hierarchies, employees, technological software stacks, 
and cloud assets—before sending a single intrusive exploit packet.

In ethical methodology, 70% to 80% of total assessment time is dedicated to Reconnaissance. 
Thorough footprinting eliminates guesswork and reveals surgical attack vectors.

3. PASSIVE RECONNAISSANCE TECHNIQUES & GOOGLE DORKS
--------------------------------------------------------------------------------

[1. CERTIFICATE TRANSPARENCY LOGS (crt.sh)]
  * Public, append-only cryptographic ledgers of all SSL/TLS certificates issued.
  * Query: `https://crt.sh/?q=%.kolkata-fintech.co.in&output=json`
  * Value: Uncovers hidden staging subdomains (e.g., `dev-payment.kolkata-fintech.co.in`).

[2. ICONIC GOOGLE DORK OPERATORS]
  * `site:target.com filetype:env`                   --> Discovers exposed API secrets & DB passwords.
  * `site:target.com inurl:wp-config.php.bak`        --> Discovers database configuration backups.
  * `site:target.com intitle:"Index of" ".git"`      --> Discovers exposed Git source code repositories.
  * `site:target.com inurl:admin login`              --> Locates administrative management panels.

[3. METADATA & DOCUMENT HARVESTING (ExifTool / FOCA)]
  * Inspects public PDFs, DOCX, and images published on the company website.
  * Extracts: Internal Windows usernames, software versions, file paths, and GPS coordinates.

[4. SHODAN & CENSYS DEVICE SEARCH]
  * Continuous IPv4 port scanner recording service banners.
  * Query: `net:203.0.113.0/24 "Apache/2.4.49"` or `port:502 "Schneider Electric"` (SCADA).

--------------------------------------------------------------------------------
4. ACTIVE RECONNAISSANCE TECHNIQUES
--------------------------------------------------------------------------------

[1. DNS ZONE TRANSFER (AXFR)]
  * Designed to synchronize master and slave DNS nameservers over TCP port 53.
  * Command: `dig @ns1.target.com target.com AXFR`
  * Impact: If misconfigured, dumps the entire internal and external DNS database instantly.

[2. SERVICE BANNER GRABBING]
  * Connecting to open ports to read software version identification strings.
  * Command: `curl -I https://target.com` or `nc -nv 203.0.113.50 21`
  * Impact: Returns `Server: Apache/2.4.49`, allowing testers to match CVE zero-day exploits.

[3. TCP TRACEROUTE (FIREWALL BOUNDARY MAPPING)]
  * Command: `tcptraceroute -n target.com 443`
  * Impact: Bypasses ICMP blocking to map intermediate router hops and perimeter firewalls.

6. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL RECONNAISSANCE HABITS:
  1. Never Touch Target Servers Without a Signed RoE: Use passive OSINT first.
  2. Query Public Certificate Logs: `crt.sh` finds 90%+ of forgotten staging subdomains.
  3. Strip Document Metadata: Run ExifTool on public PDFs before publishing them to the web.

* COMMON BEGINNER RECON MISTAKES:
  - Launching aggressive Nmap port scans against targets before signing an RoE contract.
  - Forgetting to check historical web caches (Wayback Machine) for deprecated API keys.
  - Relying on a single DNS query rather than brute-forcing subdomains with wordlists.
  - Ignoring job postings on LinkedIn (which often reveal exact internal database versions).
