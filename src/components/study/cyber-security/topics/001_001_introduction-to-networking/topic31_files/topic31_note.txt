1. DEFINITION & THE 4-COMPONENT LATENCY FORMULA
--------------------------------------------------------------------------------
Latency is the total elapsed time delay taken for a data packet to travel from its
source node to its destination node across a communication channel (measured in
milliseconds: ms, or microseconds: μs).

The Total End-to-End Latency Formula:
$$D_{\text{total}} = D_{\text{proc}} + D_{\text{queue}} + D_{\text{trans}} + D_{\text{prop}}$$

1. Processing Delay ($D_{\text{proc}}$): Time taken by router/switch ASICs to examine
   packet headers, verify checksums, look up routing tables, and apply ACL rules (<10 μs).
2. Queuing Delay ($D_{\text{queue}}$): Time the packet spends waiting in buffer queues
   before being transmitted on the output link (varies with traffic intensity $I = \frac{La}{R}$).
3. Transmission Delay ($D_{\text{trans}}$): Time required to serialize all packet bits
   onto the physical transmission medium:
   $$D_{\text{trans}} = \frac{L}{R} = \frac{\text{Packet Size (bits)}}{\text{Link Transmission Rate (bps)}}$$
4. Propagation Delay ($D_{\text{prop}}$): Time required for a bit to physically travel
   across the cable medium at the speed of light ($v \approx 200,000\ \text{km/s}$ in glass fiber):
   $$D_{\text{prop}} = \frac{d}{s} = \frac{\text{Physical Distance (meters)}}{\text{Speed of Light in Medium (m/s)}}$$

--------------------------------------------------------------------------------
2. ROUND-TRIP TIME (RTT), JITTER & BUFFERBLOAT
--------------------------------------------------------------------------------
• Round-Trip Time (RTT): Total time taken for a packet to travel to the destination
  and for the ACK response to return back to the sender.
• Jitter: The statistical variation in packet latency over time; critical for VoIP audio.
• Bufferbloat: Huge latency spikes (hundreds of ms) caused by oversized, unmanaged
  buffers inside routers during file uploads. Mitigated by FQ-CoDel and CAKE AQM algorithms.
• TCP BBR (Bottleneck Bandwidth and RTT): Google's modern congestion control algorithm
  that maximizes throughput while keeping buffer queues completely empty.

5. COMMON PITFALLS & PRACTICAL ADVICE
--------------------------------------------------------------------------------
- Never confuse Transmission Delay ($L/R$) with Propagation Delay ($d/s$).
- Enable Active Queue Management (FQ-CoDel / CAKE) on edge routers to eliminate bufferbloat.
- Use constant-time comparison algorithms in security code to prevent timing attacks.
- Budget data center dark fiber cross-connects and edge CDN deployments in Indian Rupees (₹).
