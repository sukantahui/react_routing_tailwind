1. EVOLUTION OF NON-IPSEC VPNS
----------------------------------------------------------------------------------------------------
While IPsec operates at Layer 3 inside network operating systems, modern enterprise environments 
frequently deploy SSL/TLS-based VPNs and next-generation Noise Protocol VPNs for greater flexibility, 
superior firewall traversal, and radically streamlined auditability:
  1. OpenVPN (Userspace TLS Tunneling)
  2. WireGuard (In-Kernel Noise Protocol)
  3. Browser-based SSL VPN (Clientless Web Reverse Proxy)


2. OPENVPN: ARCHITECTURE & OPERATIONAL DYNAMICS
----------------------------------------------------------------------------------------------------
- Execution Model: Runs as a userspace application utilizing virtual TUN (Layer 3 IP) or TAP (Layer 2 Ethernet) drivers.
- Dual-Channel Architecture:
  - Control Channel: Negotiates symmetric encryption keys via a standard OpenSSL TLS 1.3 handshake.
  - Data Channel: Encapsulates and encrypts passenger packets using AES-256-GCM or ChaCha20 with HMAC tags.
- Firewall Traversal: Can run over TCP Port 443, perfectly mimicking standard HTTPS traffic to bypass restrictive firewalls.
- Limitations: Large codebase (~100,000 lines of code); userspace-to-kernel context switching limits throughput to ~800 Mbps per core.


3. WIREGUARD: THE IN-KERNEL NOISE PROTOCOL REVOLUTION
----------------------------------------------------------------------------------------------------
- Execution Model: Implemented directly inside the Linux/Windows kernel network stack (`wg0` interface).
- Cryptographic Opinionation: Replaces complex cipher negotiation with a strictly fixed, modern cryptographic suite:
  - Key Exchange: Curve25519 (ECDH)
  - Encryption: ChaCha20-Poly1305 AEAD
  - Hashing: BLAKE2s
  - Anti-Replay: 64-bit counter sliding window
  - Post-Quantum Protection: Optional 256-bit symmetric pre-shared key (PSK)
- Key Advantages:
  - Ultra-Compact Codebase: ~4,000 lines of code (easily audited for formal mathematical verification).
  - Silent Operation: Drops unauthenticated UDP packets with zero response; port scanners see closed ports.
  - 1-RTT Handshake: Establishes connections in a single round-trip time; achieves 4+ Gbps throughput.


4. BROWSER-BASED SSL VPN (CLIENTLESS WEBVPN)
----------------------------------------------------------------------------------------------------
- Execution Model: Operates as an application-layer reverse proxy accessible through standard HTML5 web browsers.
- Technology: Translates internal web, SSH, and RDP protocols into browser DOM elements and WebSockets.
- Use Case: Contractor and vendor access from unmanaged personal devices where installing corporate software is forbidden.
