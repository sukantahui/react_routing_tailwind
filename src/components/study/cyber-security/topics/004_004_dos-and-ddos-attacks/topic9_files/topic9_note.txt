1. EXECUTIVE OVERVIEW & THE MULTI-LAYERED MITIGATION FRAMEWORK
--------------------------------------------------------------------------------
Effective DDoS mitigation requires a multi-layered defense-in-depth framework combining 
global routing dilution, carrier-grade upstream filtering, and local application rate shaping:

  * THE CORE MITIGATION TRIAD :
    1. BGP ANYCAST ROUTING (RFC 4786) : Announces 1 IP prefix from 300+ global PoPs, diluting a 1.2 Tbps
                                       flood into negligible 4.0 Gbps streams per data center!
    2. ALGORITHMIC RATE LIMITING      : Token Bucket, Leaky Bucket, and Redis Sliding Window Counters
                                       capping sustained request rates while permitting human bursts.
    3. INGRESS FILTERING & GEO-BLOCK  : Strict uRPF (BCP 38) dropping spoofed IPs, and GeoIP2 filtering
                                       dropping non-domestic attack traffic during emergencies.
