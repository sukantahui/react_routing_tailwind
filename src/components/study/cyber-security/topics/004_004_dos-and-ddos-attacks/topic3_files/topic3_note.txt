1. EXECUTIVE OVERVIEW & PROTOCOL STATE EXHAUSTION
--------------------------------------------------------------------------------
Network Protocol DDoS attacks target stateful connection tracking tables (`conntrack`), memory buffers, 
and network appliances (firewalls, load balancers), measured in Packets Per Second (PPS/Mpps):

  * PRIMARY PROTOCOL ATTACK VECTORS :
    1. TCP SYN FLOODS      : Fills half-open TCP backlog queues, consuming TCB memory buffers.
    2. SMURF ATTACKS       : Exploits directed ICMP broadcast amplification on unconfigured subnets.
    3. FRAGGLE ATTACKS     : UDP counterpart to Smurf targeting UDP Echo (port 7) / Chargen (port 19).
    4. ACK & SYN-ACK FLOODS: Forces expensive firewall state table lookups & RST generation.
    5. SOCKSTRESS FLOODS   : Completes handshakes with TCP Window Size 0 to lock socket memory.

--------------------------------------------------------------------------------
2. PROTOCOL STATE-TABLE DYNAMICS & TCB ALLOCATION
--------------------------------------------------------------------------------

A. TRANSMISSION CONTROL BLOCK (TCB) ALLOCATION :
   - Each embryonic half-open TCP socket consumes ~480 bytes of non-pageable kernel RAM.

B. FIREWALL HASH BUCKET COLLISION :
   - Inadequately sized conntrack hash buckets degrade lookup speeds from $O(1)$ to $O(N)$ during floods.

================================================================================

    - Section 66F   : Protocol floods on Critical Infrastructure is CYBER TERRORISM (LIFE IMPRISONMENT).
    - Section 70    : Attacks on PROTECTED SYSTEMS (Up to 10 YEARS IMPRISONMENT + Fine).
    - Section 43(f) : Civil compensation up to ₹1 CRORE for causing Denial of Access.

    - Section 420   : Cheating & Fraudulent Protocol DDoS Extortion (Up to 7 Years Prison).

  * CERT-In MANDATORY INCIDENT REPORTING DIRECTIVE :
    - All protocol DDoS outages must be reported to CERT-In within 6 HOURS.
