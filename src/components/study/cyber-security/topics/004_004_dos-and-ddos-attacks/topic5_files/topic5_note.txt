1. EXECUTIVE OVERVIEW & APPLICATION-LAYER TARGETING
--------------------------------------------------------------------------------
Application Layer (Layer 7) DDoS attacks target web applications, backend APIs, and databases 
by generating legitimate-looking HTTP/HTTPS requests, measured in Requests Per Second (RPS):

  * PRIMARY APPLICATION-LAYER ATTACK VECTORS :
    1. HTTP GET FLOODS     : Target expensive dynamic database queries & un-cached reports.
    2. SLOWLORIS (HEADERS) : Incomplete HTTP headers sent every 15s holding worker threads open.
    3. RUDY (SLOW BODY)    : Large Content-Length headers sent at 1 byte/10s to tie up form threads.
    4. SLOW READ DoS       : Tiny TCP receive windows (32 bytes) forcing servers to buffer responses.
    5. SSL/TLS EXHAUSTION  : Abuses 15x asymmetric CPU decryption overhead in RSA/ECDHE handshakes.
    6. HTTP/2 RAPID RESET  : Stream multiplexing abuse (CVE-2023-44487) reaching 398M RPS.
    7. ReDoS BACKTRACKING  : Crafted inputs triggering exponential $O(2^N)$ regex backtracking CPU lock.

--------------------------------------------------------------------------------
2. SERVER ARCHITECTURE: THREAD-BASED VS EVENT-DRIVEN
--------------------------------------------------------------------------------

A. THREAD-PER-CONNECTION (APACHE PREFORK) :
   - Allocates 1 dedicated process/thread per socket; collapses at 256 Slowloris connections.

B. ASYNCHRONOUS EVENT-DRIVEN (NGINX EPOLL / NODE.JS) :
   - Multiplexes 65,000+ connections per worker thread using non-blocking I/O, immune to Slowloris!
