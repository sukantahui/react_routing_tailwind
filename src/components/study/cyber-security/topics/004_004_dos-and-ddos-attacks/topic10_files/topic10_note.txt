1. EXECUTIVE OVERVIEW & CLOUD SCRUBBING ARCHITECTURE
--------------------------------------------------------------------------------
Cloud-based DDoS Scrubbing Centers provide multi-terabit edge ingestion, hardware silicon filtering, 
and Layer 7 Web Application Firewall (WAF) inspection to deliver clean traffic to customer origins:

  * THE 3-STAGE SCRUBBING PIPELINE :
    1. INGESTION TIER : Ingests multi-terabit floods via 300+ BGP Anycast global Points of Presence (PoPs).
    2. HARDWARE TIER  : FPGA / ASIC silicon drops volumetric UDP/ICMP and evaluates SYN cookies in 4.2ns.
    3. WAF & RETURN   : Layer 7 WAF inspects HTTP/HTTPS, returning clean traffic via GRE/IPsec tunnels.

--------------------------------------------------------------------------------
2. WAF SECURITY MODELS & BOT MANAGEMENT
--------------------------------------------------------------------------------

A. NEGATIVE VS POSITIVE SECURITY MODELS :
   - Negative Model : OWASP Core Rule Set anomaly scoring (blocks known attack signatures).
   - Positive Model : Strict OpenAPI/JSON schema validation (blocks all non-whitelisted parameters).

B. TLS JA3/JA4 FINGERPRINTING & VIRTUAL PATCHING :
   - JA3/JA4 hashes TLS Client Hello parameters, blocking automated botnets regardless of spoofed User-Agents.
   - Virtual Patching blocks zero-day exploits (e.g. Log4Shell CVE-2021-44228) at the cloud edge in minutes.
