1. THE MATHEMATICAL SPECIFICATION OF BIOMETRIC ERROR RATES
----------------------------------------------------------------------------------------------------
Biometric systems compare biometric probe samples against enrolled templates, outputting a continuous 
Similarity Score $s \in [0, 1]$. An authentication decision is made by comparing $s$ to an operating 
decision threshold $\theta$:

- If $s \ge \theta \implies \text{Match Declared (Access Granted)}$
- If $s < \theta \implies \text{Non-Match Declared (Access Denied)}$

The Two Fundamental Error Types:
1. False Acceptance Rate (FAR / False Match Rate FMR - Type II Error $\beta$):
   - The probability that an unauthorized imposter is incorrectly accepted as the legitimate user.
   - Formula:
     $$\text{FAR}(\theta) = \frac{\text{Number of False Acceptances}}{\text{Total Imposter Presentation Attempts}} = \int_{\theta}^{\infty} p_{\text{imposter}}(s) \, ds$$
   - Security Implication: Directly measures the vulnerability to unauthorized entry / security breach.

2. False Rejection Rate (FRR / False Non-Match Rate FNMR - Type I Error $\alpha$):
   - The probability that an authorized legitimate user is incorrectly rejected and denied access.
   - Formula:
     $$\text{FRR}(\theta) = \frac{\text{Number of False Rejections}}{\text{Total Genuine Presentation Attempts}} = \int_{-\infty}^{\theta} p_{\text{genuine}}(s) \, ds$$
   - Usability Implication: Directly measures user frustration, friction, and operational delays.


2. EQUAL ERROR RATE (EER / CROSSOVER ERROR RATE CER)
----------------------------------------------------------------------------------------------------
The Equal Error Rate (EER) is the point where the False Acceptance Rate exactly equals the False Rejection 
Rate at an optimal threshold $\theta^*$:

$$\text{FAR}(\theta^*) = \text{FRR}(\theta^*) = \text{EER}$$

Significance:
- EER is the universally accepted benchmark metric used to compare the intrinsic accuracy of different 
  biometric algorithms and sensor hardware.
- A lower EER indicates a superior, more accurate biometric algorithm.
- Approximate Benchmark EER Values:
  • 2D Optical Facial Recognition : $\text{EER} \approx 1\% - 2\%$
  • Capacitive Fingerprint Sensors : $\text{EER} \approx 0.1\%$
  • 3D Infrared Facial Mesh       : $\text{EER} \approx 0.05\%$
  • Iris Recognition (Daugman)    : $\text{EER} \approx 0.0001\% \ (1 \text{ in } 10^6)$


3. DET (DETECTION ERROR TRADEOFF) & ROC CURVE ANALYSIS
----------------------------------------------------------------------------------------------------
1. ROC Curve (Receiver Operating Characteristic):
   - Plots True Positive Rate ($\text{TPR} = 1 - \text{FRR}$) against False Acceptance Rate ($\text{FAR}$).
   - An ideal biometric curve shoots straight up to $\text{TPR} = 100\%$ at $\text{FAR} = 0\%$.

2. DET Curve (Detection Error Tradeoff):
   - Plots $\text{FRR}$ against $\text{FAR}$ on standard deviation Gaussian (probit) logarithmic scales.
   - Curves closer to the origin (bottom-left corner) represent superior performance.

5. AUXILIARY ACCURACY METRICS: FTE & FTA
----------------------------------------------------------------------------------------------------
1. Failure to Enroll Rate (FTE):
   - Percentage of the population unable to successfully enroll due to worn ridges (elderly manual laborers), 
     cataracts, or missing limbs.
2. Failure to Acquire Rate (FTA):
   - Percentage of verification attempts where the sensor cannot capture a usable image (dirty sensor, glare).
