1. THE AAA SECURITY TRIAD
----------------------------------------------------------------------------------------------------
Enterprise access control and identity governance rest upon the AAA architectural model:
1. Authentication (AuthN):
   - "Who are you?" Validates the claimed identity of a user, device, or service using credentials 
     (passwords, digital certificates, biometrics, hardware tokens).
2. Authorization (AuthZ):
   - "What are you permitted to do?" Enforces granular permissions, privileges, and access boundaries 
     (Role-Based Access Control - RBAC, Attribute-Based Access Control - ABAC).
3. Accounting / Auditing (AuthAcct):
   - "What did you do, when, and for how long?" Logs user session start/stop times, executed commands, 
     data transferred, and system modifications for compliance, forensics, and non-repudiation.

3. 802.1X PORT-BASED NETWORK ACCESS CONTROL (PNAC)
----------------------------------------------------------------------------------------------------
802.1X controls physical and wireless port access through three logical entities:
1. Supplicant: The client device (e.g., Susmita's laptop in Barrackpore) running EAP software.
2. Authenticator: The edge network switch or wireless access point (AP) acting as a gatekeeper.
3. Authentication Server: The centralized RADIUS server (e.g., FreeRADIUS) validating credentials.
- Protocol Wire: Supplicant ──(EAPoL)──> Authenticator ──(RADIUS/UDP)──> RADIUS Server


4. ACCESS CONTROL MODELS: RBAC VS ABAC
----------------------------------------------------------------------------------------------------
- Role-Based Access Control (RBAC):
  • Permissions are bound directly to static organizational roles (e.g., `Auditor`, `NetworkAdmin`, `Teller`).
  • Simple to administer, but inflexible in dynamic environments.
- Attribute-Based Access Control (ABAC - NIST SP 800-162):
  • Permissions evaluated dynamically using boolean rules over Subject (Role, Clearance), Object (Sensitivity), 
    Action (Read, Execute), and Environmental Context (Time: 09:00-17:00, Location: Barrackpore SOC, IP: 10.14.0.0/16).
