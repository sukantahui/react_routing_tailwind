1. EXECUTIVE OVERVIEW & CROWDSOURCED SECURITY
--------------------------------------------------------------------------------
No internal security engineering team can anticipate every novel offensive exploit technique. 
Crowdsourced cybersecurity aligns thousands of independent global ethical hackers to discover 
and remediate vulnerabilities before criminal syndicates or hostile nation-states can exploit them.

Modern organizations implement two complementary crowdsourced models:
  1. VULNERABILITY DISCLOSURE PROGRAM (VDP): A public, legally protected channel for 
     reporting flaws in exchange for recognition (Hall of Fame) without monetary reward.
  2. PAID BUG BOUNTY PROGRAMS: Private or public programs offering cash bounties in 
     Indian Rupees (₹) based on standardized severity ratings.

3. RFC 9116 SECURITY.TXT SPECIFICATION
--------------------------------------------------------------------------------

RFC 9116 standardizes a plaintext configuration file deployed under `/.well-known/security.txt`.

MANDATORY DIRECTIVES:
  * Contact: Official email URI (mailto:security@domain.co.in).
  * Expires: ISO-8601 expiration timestamp (must not exceed 1 year).

RECOMMENDED DIRECTIVES:
  * Encryption: URL to PGP public key for encrypting sensitive bug reports.
  * Policy: URL to the organization's Vulnerability Disclosure Policy & Safe Harbor.
  * Preferred-Languages: Comma-separated list (e.g., en, bn, hi).
  * Canonical: The authoritative URL where the security.txt file is hosted.

4. COORDINATED VULNERABILITY DISCLOSURE (CVD) & 90-DAY TIMELINE
--------------------------------------------------------------------------------

Coordinated Vulnerability Disclosure balances public security with engineering reality:
  * Day 00: Researcher discovers zero-day → Submits private report with non-destructive PoC.
  * Day 01-07: Enterprise triage team validates report and calculates CVSS score.
  * Day 08-60: Engineering squad develops, tests, and deploys patch to production clusters.
  * Day 61-90: Bounty awarded in ₹ INR; coordinated public disclosure blog released.
  * 90-Day Expiry: If vendor fails to respond or patch after 90 days, researcher may disclose publicly.

5. INDIAN BUG BOUNTY ECOSYSTEM & GOVERNMENT RVDP
--------------------------------------------------------------------------------

1. NCIIPC Responsible Vulnerability Disclosure Program (RVDP):
   - Administered under Section 70A of the IT Act 2000.
   - Allows researchers to report flaws in national critical infrastructure (Power, Defense, Banking).
   - Validated researchers receive official Government of India Certificates of Appreciation.

2. CERT-In Vulnerability Disclosure Portal:
   - Central national clearinghouse for zero-day disclosures across Indian cyberspace.

3. Indian Commercial Leaders:
   - Swiggy, Zomato, Razorpay, CRED, and Paytm operate leading bug bounty programs.

7. PROFESSIONAL TIPS & COMMON PITFALLS
--------------------------------------------------------------------------------

* PROFESSIONAL BUG HUNTER HABITS:
  1. Check the Scope First: Never test a domain not explicitly listed in the In-Scope section.
  2. Provide Clear Reproduction Steps: Include cURL commands, video PoC, and remediation code.
  3. Stop at Minimal PoC: Proving a bug requires reading 1 record; dumping the database is a crime.

* COMMON BEGINNER MISTAKES:
  - Firing noisy automated scanners (Masscan/Acunetix) that flood triage queues with false positives.
  - Submitting missing HTTP security headers as P1 critical bugs (Closed as Informative).
  - Threatening public disclosure if bounties are not paid (Criminal Extortion under IPC 384).
  - Testing out-of-scope third-party payment gateways (Invalidates Legal Safe Harbor).
