1. WHAT IS PERIOD-OVER-PERIOD (PoP) GROWTH?
--------------------------------------------------------------------------------
Period-over-Period analytics measures velocity and acceleration of financial 
metrics (revenue, enrollment, active students) across consecutive or seasonal cycles:
- Month-over-Month (MoM): Compares Month $t$ vs Month $t-1$ (LAG offset 1).
- Quarter-over-Quarter (QoQ): Compares Quarter $Q$ vs Quarter $Q-1$ (LAG offset 1).
- Year-over-Year (YoY): Compares Month $M$ this year vs Month $M$ last year (LAG offset 12).

2. THE 3-STAGE CTE AGGREGATION PIPELINE
--------------------------------------------------------------------------------
1. Stage 1 (Grouping Base Transactions):
   Aggregate raw payments into monthly buckets with `GROUP BY`.
2. Stage 2 (Window Offset Projection):
   Pull prior month and prior year revenues with `LAG()`.
3. Stage 3 (Defensive Calculation):
   Calculate percentage growth using `NULLIF(prior_rev, 0)` to avoid division by zero:
   `ROUND(((curr_rev - prior_rev) / NULLIF(prior_rev, 0)) * 100.0, 2)`

3. SYNTAX BLUEPRINT
--------------------------------------------------------------------------------
    WITH MonthlyAgg AS (
        SELECT 
            DATE_FORMAT(payment_date, '%Y-%m-01') AS period_month,
            SUM(amount_paid_inr) AS monthly_rev
        FROM fee_payments
        GROUP BY DATE_FORMAT(payment_date, '%Y-%m-01')
    ),
    OffsetProjection AS (
        SELECT 
            period_month,
            monthly_rev,
            LAG(monthly_rev, 1)  OVER (ORDER BY period_month) AS prior_month_rev,
            LAG(monthly_rev, 12) OVER (ORDER BY period_month) AS prior_year_rev
        FROM MonthlyAgg
    )
    SELECT 
        period_month,
        monthly_rev,
        prior_month_rev,
        -- MoM Growth %:
        ROUND(((monthly_rev - prior_month_rev) / NULLIF(prior_month_rev, 0)) * 100.0, 2) AS mom_growth_pct,
        -- YoY Growth %:
        ROUND(((monthly_rev - prior_year_rev) / NULLIF(prior_year_rev, 0)) * 100.0, 2) AS yoy_growth_pct
    FROM OffsetProjection
    ORDER BY period_month ASC;
