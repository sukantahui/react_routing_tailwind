1. INTRODUCTION TO WITH ROLLUP
--------------------------------------------------------------------------------
In standard business intelligence reports, managers need both fine-grained details 
and multi-level summary subtotals:
- Revenue per Course Stream within each Center Location
- Subtotal Revenue for each Center Location (across all streams)
- Grand Total Revenue for the entire institution

Without ROLLUP, obtaining these figures requires writing multiple queries with 
differing GROUP BY clauses and stitching them together with `UNION ALL`, which 
requires multiple passes over the table.

The `WITH ROLLUP` modifier is an extension to the `GROUP BY` clause that causes 
MySQL to produce extra super-aggregate rows (subtotals and grand totals) in a 
single optimized aggregation pass.

2. MECHANICS & HIERARCHICAL ROLLUP ORDER
--------------------------------------------------------------------------------
When you specify `GROUP BY col1, col2, col3 WITH ROLLUP`, MySQL computes aggregates 
at decreasing levels of granularity from right to left:
1. Detailed groups: `(col1, col2, col3)`
2. Level 1 Subtotals: `(col1, col2, NULL)` → Subtotal across col3 for each (col1, col2)
3. Level 2 Subtotals: `(col1, NULL, NULL)` → Subtotal across col2 & col3 for each (col1)
4. Grand Total: `(NULL, NULL, NULL)` → Grand total across all rows

Total Generated Aggregation Levels = N + 1 (where N is the number of grouping columns).

3. HANDLING AND IDENTIFYING ROLLUP NULLs: THE GROUPING() FUNCTION
--------------------------------------------------------------------------------
Super-aggregate subtotal rows contain `NULL` in the columns that have been collapsed.
However, if a column naturally contains legitimate `NULL` values in the source table, 
distinguishing between a naturally missing value and a ROLLUP-generated subtotal row 
can be ambiguous.

MySQL 8.0+ provides the `GROUPING()` function:
- `GROUPING(col)` returns `1` if the NULL in the row was generated by ROLLUP (a subtotal/grand total).
- `GROUPING(col)` returns `0` if the value (even if NULL) came from the actual underlying data row.

Example with IF() and GROUPING():
    SELECT 
        IF(GROUPING(centre_city) = 1, '>> GRAND TOTAL <<', centre_city) AS centre_location,
        IF(GROUPING(course_stream) = 1, '>> STREAM SUB-TOTAL <<', course_stream) AS course_name,
        COUNT(*) AS total_students,
        SUM(fee_amount_inr) AS total_revenue_inr
    FROM student_enrollments
    GROUP BY centre_city, course_stream WITH ROLLUP;

4. COALESCE VS GROUPING() FOR LABELING
--------------------------------------------------------------------------------
While `COALESCE(centre_city, 'All Centers')` works when source columns are NOT NULL, 
using `GROUPING(centre_city)` with `CASE` or `IF()` is the definitive, industry-standard 
best practice because it is 100% resilient against naturally occurring NULLs.

5. RESTRICTIONS & ORDER BY BEHAVIOR
--------------------------------------------------------------------------------
1. In MySQL 8.0+, `WITH ROLLUP` and `ORDER BY` are mutually exclusive in the same query block 
   (unless ordering by expressions identical to grouping columns or using a derived table wrapper).
2. To sort rollups cleanly, wrap the ROLLUP query in a derived table (CTE / subquery) 
   and apply the `ORDER BY` externally.

6. PRODUCTION CODE EXAMPLES
--------------------------------------------------------------------------------
Example 1: Institutional Tuition Revenue Rollup
    SELECT 
        COALESCE(centre_city, '>> ALL CAMPUSES (GRAND TOTAL) <<') AS campus_city,
        COALESCE(course_stream, '>> ALL STREAMS (CAMPUS TOTAL) <<') AS stream_name,
        COUNT(*) AS student_count,
        SUM(fee_amount_inr) AS collected_revenue_inr,
        ROUND(AVG(marks_pct), 2) AS average_score_pct
    FROM student_enrollments
    WHERE admission_status = 'CONFIRMED'
    GROUP BY centre_city, course_stream WITH ROLLUP;

Example 2: E-Commerce Regional Quarterly Sales Rollup with GROUPING()
    SELECT 
        IF(GROUPING(sales_region) = 1, 'ALL REGIONS', sales_region) AS region,
        IF(GROUPING(fiscal_quarter) = 1, 'ALL QUARTERS', fiscal_quarter) AS quarter,
        COUNT(order_id) AS total_orders,
        SUM(order_value_inr) AS aggregate_turnover_inr
    FROM regional_sales
    WHERE fiscal_year = 2026
    GROUP BY sales_region, fiscal_quarter WITH ROLLUP;

7. SUMMARY OF BEST PRACTICES
--------------------------------------------------------------------------------
1. Order grouping columns hierarchically from broadest category to narrowest subcategory.
2. Use MySQL 8.0 `GROUPING()` function to safely label super-aggregate subtotal and grand total rows.
3. Use derived table wrappers when custom sorting of rollup reports is required.
4. Keep in mind that ROLLUP generates N + 1 grouping levels in a single relational pass.
