1. INTRODUCTION TO GROUP_CONCAT()
--------------------------------------------------------------------------------
`GROUP_CONCAT()` is one of MySQL's most celebrated and powerful aggregate functions.
While standard aggregate functions (SUM, AVG) compress rows into single numbers,
`GROUP_CONCAT()` compresses multiple string values from grouped rows into a single,
formatted, concatenated string list.

Common Use Cases:
- Concatenating all courses/skills enrolled by a student into a single row.
- Listing all ordered product items under an invoice header.
- Aggregating tags, categories, or assigned roles per user.
- Building comma-separated lists for executive CSV exports or UI badge lists.

2. FULL SYNTAX & OPTIONS
--------------------------------------------------------------------------------
Syntax:
    GROUP_CONCAT(
        [DISTINCT] expression [, expression ...]
        [ORDER BY {col_name | expr} [ASC | DESC]]
        [SEPARATOR 'separator_string']
    )

Key Clauses:
1. `DISTINCT`: Removes duplicate values before concatenation.
2. `ORDER BY`: Sorts elements alphabetically, numerically, or chronologically
   *inside* the concatenated string.
3. `SEPARATOR`: Customizes the delimiter string (default is `,`).
   Examples: `SEPARATOR '; '`, `SEPARATOR ' | '`, `SEPARATOR ' -> '`.

3. EXAMPLES IN ACTION
--------------------------------------------------------------------------------
Example 1: Basic Student Skills List
    SELECT 
        student_name,
        GROUP_CONCAT(skill_name SEPARATOR ', ') AS acquired_skills
    FROM student_skills
    GROUP BY student_name;

Example 2: Deduplicated & Sorted Ordered Items
    SELECT 
        order_id,
        GROUP_CONCAT(DISTINCT item_name ORDER BY item_name ASC SEPARATOR ' + ') AS ordered_items_summary
    FROM order_items
    GROUP BY order_id;

Example 3: Multi-Column Formatted Aggregation
    SELECT 
        batch_name,
        GROUP_CONCAT(
            CONCAT(student_name, ' (Marks: ', marks, ')') 
            ORDER BY marks DESC 
            SEPARATOR ' | '
        ) AS rank_roster
    FROM batch_scores
    GROUP BY batch_name;

4. THE CRITICAL `group_concat_max_len` LIMITATION
--------------------------------------------------------------------------------
By default, MySQL limits the maximum string length generated by `GROUP_CONCAT()`.
- Default in older MySQL versions: 1024 bytes (1 KB).
- Default in MySQL 8.0+: 1,048,576 bytes (1 MB).

If the concatenated string exceeds this limit, MySQL silently truncates the
result and generates a warning!

How to inspect and increase the buffer:
    -- Inspect current setting:
    SHOW VARIABLES LIKE 'group_concat_max_len';

    -- Increase for current session (e.g. 10 MB):
    SET SESSION group_concat_max_len = 10485760;

    -- Increase globally (requires ADMIN/SUPER privilege):
    SET GLOBAL group_concat_max_len = 10485760;

5. NULL VALUE HANDLING
--------------------------------------------------------------------------------
- NULL values are automatically ignored during concatenation.
- If all values in the group are NULL, `GROUP_CONCAT()` returns `NULL`.
- To replace NULL with a fallback string within elements:
  `GROUP_CONCAT(COALESCE(phone, '[No Phone]') SEPARATOR ', ')`

6. SUMMARY OF BEST PRACTICES
--------------------------------------------------------------------------------
1. Always specify an explicit `SEPARATOR` for clarity and readability.
2. Use `DISTINCT` when aggregating joined tables to prevent duplicate text strings.
3. Add `ORDER BY` inside `GROUP_CONCAT()` to ensure deterministic string outputs.
4. Verify `group_concat_max_len` when generating long reports on high-volume tables.
