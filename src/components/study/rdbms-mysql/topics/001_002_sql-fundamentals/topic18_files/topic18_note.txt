1. OVERVIEW OF SQL PRACTICAL PROJECTS
--------------------------------------------------------------------------------
Practical database engineering requires synthesizing DDL schema modeling, DML
data manipulation, and DQL data querying to address real-world business scenarios:
  • DDL (Data Definition Language): CREATE TABLE, ALTER TABLE, DROP, TRUNCATE
  • DML (Data Manipulation Language): INSERT INTO, UPDATE, DELETE
  • DQL (Data Query Language): SELECT, WHERE, ORDER BY, LIMIT, OFFSET, AS

3. GOLDEN RULES FOR SQL PRODUCTION SCRIPTS
--------------------------------------------------------------------------------
  • Use Exact Decimals: Always prefer DECIMAL(M, D) over FLOAT for currency and balances.
  • Three-Valued Logic: Use IS NULL / IS NOT NULL; never use '= NULL'.
  • Operator Grouping: Always enclose OR expressions in parentheses when combined with AND.
  • Index Optimization: In queries with ORDER BY, ensure sorted columns align with indexes.
  • Safe Deletions: Distinguish between TRUNCATE (keeps schema) and DROP (destroys table).
