1. WHAT ARE ENUM AND SET DATA TYPES?
--------------------------------------------------------------------------------
`ENUM` and `SET` are specialized string object types in MySQL that restrict column entries
strictly to a predefined list of permitted literal choices.

A. ENUM (Enumeration - Mutually Exclusive Single Choice):
   • A column whose value must be chosen from a predefined list of up to 65,535 distinct elements.
   • Stored internally as a compact 1-byte (for <= 255 items) or 2-byte (for <= 65,535 items) integer index!
   • Example: `city ENUM('Barrackpore', 'Kolkata', 'Ichapur', 'Jadavpur') NOT NULL`

B. SET (Multi-Choice Combinations / Bitmask):
   • A column that can store zero, one, or MULTIPLE values chosen from a list of up to 64 members.
   • Stored internally as a compact bitmask integer (1 bit per member).
   • Example: `skills SET('MySQL', 'React', 'Python', 'Accounting') NOT NULL`


2. INTERNAL STORAGE MECHANICS
--------------------------------------------------------------------------------
1. ENUM Storage:
   - Elements are indexed 1-based (1, 2, 3...).
   - `NULL` has an index of NULL.
   - An invalid string inserted in non-strict mode receives the special "error empty string" `''` with index 0.
   - Sorting in `ORDER BY col` sorts by INTERNAL INTEGER INDEX (declaration order), NOT alphabetically!
     (To sort alphabetically, use `ORDER BY CAST(col AS CHAR)`).

2. SET Storage:
   - Elements represent powers of 2 (1, 2, 4, 8, 16...).
   - Multiple selections are combined using bitwise OR: `'MySQL,Python'` = 1 | 4 = 5.
   - Querying SET members uses `FIND_IN_SET('MySQL', skills)` or bitwise operators (`skills & 1`).


3. REAL-WORLD CASE STUDIES (BARRACKPORE & KOLKATA)
--------------------------------------------------------------------------------
CASE 1: Mamata's Barrackpore Student Enrollment Status & Location Schema
CREATE TABLE student_profiles (
    student_id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    city ENUM('Barrackpore', 'Kolkata', 'Ichapur', 'Jadavpur') NOT NULL DEFAULT 'Barrackpore',
    academic_status ENUM('ENROLLED', 'ON_LEAVE', 'GRADUATED', 'WITHDRAWN') NOT NULL DEFAULT 'ENROLLED',
    hobbies SET('Coding', 'Music', 'Sports', 'Reading', 'Photography') NOT NULL DEFAULT 'Coding'
) ENGINE=InnoDB;

CASE 2: Debangshu's Kolkata E-Commerce Order Fulfillment State Machine
CREATE TABLE order_deliveries (
    delivery_id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    order_id INT NOT NULL,
    delivery_status ENUM('PENDING', 'PACKED', 'SHIPPED', 'OUT_FOR_DELIVERY', 'DELIVERED', 'RETURNED') NOT NULL DEFAULT 'PENDING',
    payment_methods_allowed SET('UPI', 'NetBanking', 'CreditCard', 'CashOnDelivery') NOT NULL DEFAULT 'UPI,CashOnDelivery'
) ENGINE=InnoDB;


4. ENUM VS VARCHAR + CHECK CONSTRAINT (PROS & CONS)
--------------------------------------------------------------------------------
A. ENUM PROS:
   • Ultra-compact storage (1 byte vs 20+ bytes for VARCHAR).
   • Fast numeric comparisons in memory.
B. ENUM CONS:
   • Adding/removing items requires `ALTER TABLE` DDL.
   • Sorting behaves unexpectedly (declaration order vs alphabetical).
   • Not fully portable across different database dialects (PostgreSQL uses custom types).
   • Alternative: `VARCHAR(20) CHECK (status IN ('ACTIVE', 'INACTIVE'))` for standard SQL portability.


5. COMMON PITFALLS & DANGER ZONES
--------------------------------------------------------------------------------
1. Sorting ENUM Columns:
   - `ORDER BY status` sorts by index order. Use `ORDER BY CAST(status AS CHAR)` for alphabetical sorting.
2. Numeric String Elements:
   - Defining `ENUM('1', '2', '3')` creates severe confusion because index 1 maps to value '1', and index 2 maps to value '2'. Avoid numbers as ENUM values!
3. SET Searching with LIKE:
   - Searching `WHERE skills LIKE '%MySQL%'` is slow; use `WHERE FIND_IN_SET('MySQL', skills)` or `WHERE skills & 1`.


6. BEST PRACTICES & SUMMARY CHECKLIST
--------------------------------------------------------------------------------
[x] Use `ENUM` for fixed, stable state machines (e.g. Order Status, Academic State).
[x] Use `SET` for compact multi-attribute checkboxes (e.g. User Roles, Skills).
[x] Provide explicit `DEFAULT` values on all `ENUM` and `SET` columns.
[x] Use `FIND_IN_SET()` for querying multi-value SET members.
[x] Use `ORDER BY CAST(enum_col AS CHAR)` when alphabetical sorting is required.
