================================================================================
MYSQL 8.0 SERVER LOGS, MONITORING & PERFORMANCE SCHEMA
TOPIC 4: The Slow Query Log – Configuration, Microsecond Tuning & log_slow_extra
================================================================================

1. WHAT IS THE SLOW QUERY LOG?
--------------------------------------------------------------------------------
The Slow Query Log is a surgical performance optimization log that records:
- Queries whose total execution time exceeds `long_query_time` seconds.
- Queries executing full table scans or full index scans without index lookups
  (when `log_queries_not_using_indexes = ON`).
- Slow administrative DDL maintenance operations (`log_slow_admin_statements = ON`).

2. CORE CONFIGURATION PARAMETERS IN MYSQL 8.0
--------------------------------------------------------------------------------
A. Enabling & File Path:
   SET PERSIST slow_query_log = 'ON';
   SET PERSIST slow_query_log_file = '/var/log/mysql/slow_query.log';
   SET PERSIST log_output = 'FILE';

B. Execution Time Threshold (`long_query_time`):
   -- Supports microsecond precision (e.g. 0.5 = 500ms, 0.05 = 50ms):
   SET PERSIST long_query_time = 0.5;

C. Capturing Unindexed Queries with Throttling:
   SET PERSIST log_queries_not_using_indexes = 'ON';
   SET PERSIST log_throttle_queries_not_using_indexes = 20; -- Cap at 20/min
   SET PERSIST min_examined_row_limit = 100; -- Skip small tables (<100 rows)

D. Rich Telemetry in MySQL 8.0 (`log_slow_extra`):
   -- Enables deep diagnostics: disk temporary tables, sort passes, bytes sent:
   SET PERSIST log_slow_extra = 'ON';

4. PRODUCTION BEST PRACTICES
--------------------------------------------------------------------------------
1. Set `long_query_time` between 0.2s and 1.0s in production.
2. Enable `log_slow_extra = ON` in MySQL 8.0 for deep sort and temporary table metrics.
3. Always configure `log_throttle_queries_not_using_indexes` to prevent log floods.
4. Set `min_examined_row_limit = 100` to avoid logging small lookup tables.
