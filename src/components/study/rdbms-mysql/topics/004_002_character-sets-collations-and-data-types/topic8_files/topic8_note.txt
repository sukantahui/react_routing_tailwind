1. JSON PATH SYNTAX ESSENTIALS
--------------------------------------------------------------------------------
MySQL JSON paths use the dollar sign (`$`) as the root document anchor:
- `$.key`: Accesses a named object property.
- `$.address.city`: Accesses nested object properties.
- `$.items[0]`: Accesses array elements by 0-indexed position.
- `$.items[last]`: Accesses the last item in an array.
- `$.items[1 to 3]`: Extracts an array slice.
- `$.*` or `$[*]`: Wildcard matching across all keys or array items.
- `$**.zip`: Recursive descent finding all 'zip' keys at any nesting depth.

2. THE `->` (JSON EXTRACT) OPERATOR
--------------------------------------------------------------------------------
`col->'$.path'` is an alias for `JSON_EXTRACT(col, '$.path')`.
- Returns a **JSON-typed value**.
- String values retain their JSON quotes: `"Barrackpore"`.
- ⚠️ Trap: `WHERE portfolio->'$.city' = 'Barrackpore'` evaluates to FALSE
  because `"\"Barrackpore\"" != "Barrackpore"`!

3. THE `->>` (JSON EXTRACT & UNQUOTE) OPERATOR
--------------------------------------------------------------------------------
`col->>'$.path'` is an alias for `JSON_UNQUOTE(JSON_EXTRACT(col, '$.path'))`.
- Returns a **plain SQL string (VARCHAR)**.
- Strips surrounding JSON quotes and resolves escape characters: `Barrackpore`.
- ✅ Best Practice: Always use `->>` for WHERE filters, ORDER BY, and JOIN conditions!
