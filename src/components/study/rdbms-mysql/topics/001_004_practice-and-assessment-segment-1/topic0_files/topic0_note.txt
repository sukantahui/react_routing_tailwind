3. COMMON CONCEPTUAL TRAPS IN SEGMENT 1
--------------------------------------------------------------------------------
- NULL comparisons: Always use `IS NULL` or `IS NOT NULL`, never `= NULL`.
- DROP vs TRUNCATE: DROP removes table structure + data; TRUNCATE resets table data.
- Foreign Key requirements: Data types and signedness must match the referenced PK.
- Composite Keys: Cannot contain NULL values in standard relational integrity.
