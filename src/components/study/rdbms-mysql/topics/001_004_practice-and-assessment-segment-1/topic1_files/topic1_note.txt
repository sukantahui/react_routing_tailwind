1. LAB OVERVIEW: COLLEGE ADMISSION MANAGEMENT SCHEMA
--------------------------------------------------------------------------------
This lab guides students step-by-step through designing, building, constraining,
and seeding a complete relational database for a multi-campus college
in West Bengal (campuses in Barrackpore, Kolkata, and Ichapur).

2. SCHEMA ARCHITECTURE & CONSTRAINTS
--------------------------------------------------------------------------------
1. `departments` table:
   - department_id INT AUTO_INCREMENT PRIMARY KEY
   - dept_code VARCHAR(10) NOT NULL UNIQUE
   - dept_name VARCHAR(100) NOT NULL
   - campus_city VARCHAR(50) DEFAULT 'Barrackpore'

2. `courses` table:
   - course_id INT AUTO_INCREMENT PRIMARY KEY
   - department_id INT NOT NULL (FK -> departments.department_id)
   - course_name VARCHAR(100) NOT NULL
   - duration_years INT CHECK (duration_years BETWEEN 1 AND 5)
   - total_tuition_fee_inr DECIMAL(10,2) CHECK (total_tuition_fee_inr > 0)

3. `students` table:
   - student_id INT AUTO_INCREMENT PRIMARY KEY
   - first_name VARCHAR(50) NOT NULL
   - last_name VARCHAR(50) NOT NULL
   - email VARCHAR(120) NOT NULL UNIQUE
   - phone_number VARCHAR(15) NOT NULL UNIQUE
   - date_of_birth DATE NOT NULL
   - gender ENUM('Male', 'Female', 'Other') NOT NULL
   - blood_group VARCHAR(5) DEFAULT 'O+'

4. `admissions` table:
   - admission_id INT AUTO_INCREMENT PRIMARY KEY
   - student_id INT NOT NULL UNIQUE (FK -> students.student_id)
   - course_id INT NOT NULL (FK -> courses.course_id)
   - admission_date DATE DEFAULT (CURDATE())
   - initial_deposit_inr DECIMAL(10,2) CHECK (initial_deposit_inr >= 5000)
   - admission_status ENUM('Provisional', 'Confirmed', 'Cancelled') DEFAULT 'Provisional'

3. CONSTRAINT TESTING RUNBOOK
--------------------------------------------------------------------------------
- Test 1: Insert valid department and course -> Success.
- Test 2: Insert student with duplicate email -> Error 1062 (Duplicate entry).
- Test 3: Insert admission with initial deposit < ₹5,000 -> Error 3819 (Check constraint violated).
- Test 4: Delete department with active courses -> Error 1451 (Foreign key constraint fails).
