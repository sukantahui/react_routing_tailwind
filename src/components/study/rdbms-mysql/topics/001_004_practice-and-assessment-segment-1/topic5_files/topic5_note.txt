1. PROJECT OVERVIEW: STUDENT GRADING & REGISTRATION SYSTEM
--------------------------------------------------------------------------------
This mini-project brings together all Segment 1 competencies into an end-to-end
academic course registration and grade ledger database for university colleges
in West Bengal (Barrackpore, Kolkata, and Ichapur campuses).

2. SCHEMA ARCHITECTURE & CONSTRAINTS
--------------------------------------------------------------------------------
1. `departments`:
   - dept_id INT AUTO_INCREMENT PRIMARY KEY
   - dept_name VARCHAR(100) NOT NULL UNIQUE
   - campus_city VARCHAR(50) DEFAULT 'Barrackpore'

2. `courses`:
   - course_id INT AUTO_INCREMENT PRIMARY KEY
   - dept_id INT NOT NULL (FK -> departments.dept_id)
   - course_code VARCHAR(15) NOT NULL UNIQUE
   - title VARCHAR(100) NOT NULL
   - credits INT CHECK (credits BETWEEN 1 AND 6)

3. `students`:
   - student_id INT AUTO_INCREMENT PRIMARY KEY
   - roll_number VARCHAR(20) NOT NULL UNIQUE
   - full_name VARCHAR(100) NOT NULL
   - email VARCHAR(120) NOT NULL UNIQUE
   - admission_year INT CHECK (admission_year >= 2020)

4. `course_enrollments`:
   - enrollment_id INT AUTO_INCREMENT PRIMARY KEY
   - student_id INT NOT NULL (FK -> students.student_id ON DELETE CASCADE)
   - course_id INT NOT NULL (FK -> courses.course_id ON DELETE RESTRICT)
   - semester_term VARCHAR(20) NOT NULL
   - UNIQUE (student_id, course_id, semester_term) -- Composite Unique!

5. `grade_ledgers`:
   - grade_id INT AUTO_INCREMENT PRIMARY KEY
   - enrollment_id INT NOT NULL (FK -> course_enrollments.enrollment_id ON DELETE CASCADE)
   - exam_type ENUM('Mid-Term', 'Final-Term', 'Lab-Practical') NOT NULL
   - marks_obtained DECIMAL(5,2) CHECK (marks_obtained BETWEEN 0 AND 100)
   - grade_letter VARCHAR(2) DEFAULT 'F'
   - recorded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP

3. PROJECT DELIVERABLES
--------------------------------------------------------------------------------
- Complete DDL creation script with named foreign key and check constraints.
- Seed data with realistic student profiles (Mamata, Susmita, Abhronila, Debangshu).
- Analytical queries producing multi-course student transcripts and semester GPAs.
